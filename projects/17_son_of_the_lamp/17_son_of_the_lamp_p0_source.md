## 0. v5 스파인 교체 (2026-07-25 사용자 지시 — 이하 구버전 §들보다 우선)

- **메인 뼈대 = 《Bukan Pengawal Biasa》(61화·대본 보유)**: 세계 최강자가 낮은 신분으로 공주 곁에 들어감 · 능청·생활력 제로 · 매번 몰래 구함 · 공주가 정체 추적 · 보호와 로맨스 동시 진행.
- **마법 쾌감 = 《False Weakling, True Power》**: 손가락 마법·타인은 "다른 대마법사 소행" 오인 · 공주는 마법 영웅을 쫓으며 하찮은 하인과 사랑에 빠짐.
- **잠입 미션(Undercover Prison King 축) = 사용자 지시로 제거** — 조사 목적·대신 용의자 라인 없음.
- **새 정체**: 알라딘 = 인간으로 변장한 **진의 왕**·세계 최강 마법사 (진 군단의 왕·사막 전체의 마법 통제·왕실 금고보다 부유·암살자를 먼지로). 왕좌와 전쟁에 지쳐 인간 세상에서 **평범한 삶**(월급·조용한 생활 — BPB 살)을 원함. 마법은 전능한데 인간 생활력 제로 → 왕도의 거지 백수 → 공주 구출 인연이 꼬여 궁전 하인 채용.
- **구버전 축 폐기**: 어머니 나디라 살해·복수 기점 / 부마 간택 대회 / 진왕의 아들 혈통 리빌 / 카딤 각성 서사 / 시험관(타리크) 서사 = 전부 제거. 복수 서브 → 공주를 노리는 세력 응징으로 대체. 말리크·대신관·카심 = 공주를 노리는 외척·정략결혼 세력으로 재배치.
- **램프 (2026-07-25 기능 보강 — "램프는 어디 갔냐"):** 진의 왕이 자기 왕권·힘·정령까지 봉인해 지니고 다니는 신물. ①마법을 쓸 때마다 반응 — 품속에서 빛·김이 새어 급히 눌러 덮는 개그 ②공주 추적의 유일한 물증 체인(금빛 물자국→비 냄새→램프 응시) ③거지가 목숨보다 아끼는 고물("내 목숨은 내어줄지언정 이 램프는 절대 안 돼" 돌변 비트) ④7화 클라이맥스 = 램프가 스스로 빛을 뿜으며 물을 부름. **매회 화면 등장 의무.**
- **지니 카딤 복원 (2026-07-25 — "지니도 안 보인다" + "지니도 한 축"):** 램프에 봉인된 진의 왕의 시종장 — 왕을 따라 인간 세상까지 온 잔소리꾼 정령. 거지꼴 주인을 왕궁 의전으로 모시는 낙차 개그, 정보·경고·뒷정리 담당, 전투 대리 금지(결정타 = 알라딘). **카딤의 축 = 귀환 압박 → 중매 변심**: 매회 "전하, 이제 그만 왕좌로 돌아가시죠" vs "월급날까지는 안 돼" 밑줄 갈등 → 공주를 볼수록 "왕비감이시군요"로 돌아서는 변심 아크.
- **램프 비비기 규칙 (2026-07-25 — 원전 아이콘 시스템화):** 카딤은 주인이 램프를 **문질러야만** 나온다(봉인 규칙 — 나오고 싶으면 램프 속에서 쿵쿵). **위장과 소환이 같은 동작** — 하인이 고물 램프를 닦는 건 자연스러운 일상 동작이라, 알라딘은 만인 앞에서 닦는 척 정령을 부린다(연기가 소매·그림자로 스며 몰래 일처리 — 시그니처 비주얼·시청자만 아는 소환 신호). 남이 문지르면 무반응, 예외 = 소라야가 만지면 김이 살짝 샘(카딤이 미래의 왕비를 알아봄 — 로맨스 복선). 배치: 1화 폐가 첫 문지름("이제 그만 돌아가시죠"/"월급은 받고")·3화 줍는 척 문지름·5화 연회 닦는 척·6화 소라야 접촉 반응·7화 처음으로 대놓고 천천히 문지르며 "카딤." → 정령 현신(페이월 컷).
- **매회 쾌감 패턴 (사용자 예시 verbatim 캐논)**: 암살자가 공주에게 칼을 던진다 → 알라딘이 물주전자를 밟고 넘어진다 → 날아간 주전자가 '우연히' 칼을 튕긴다 → 공주 "너 방금 일부러 그런 거야?" → 알라딘 "제가요? 전 물도 제대로 못 따르는데요." → 공주가 돌아선 뒤 금빛 눈·암살자의 그림자가 바닥으로 빨려 들어간다.
- **1화 오프닝 확정**: 공주의 행렬을 터는 도적떼(40인 연상) → 후드의 알라딘이 물·모래 요술로 경쾌하게 쓸어버림(기름 항아리에 거꾸로 처박힘) → 증발 → 공주 "누구지, 저 사람은?" (매우 강하게).
- **v5 무료 7화 골격**: ①도적떼 오프닝+거지 백수 갭(구직 퇴짜·램프 애지중지) → 하인 모집 방 ②채용 소동(낙제인데 하필 뽑힘)·공주 배정 → 암살 그림자 ③물주전자 첫 구하기 → "대마법사가 있다" 소문 ④공주의 삼중 추적 개시(은인+수호자+하인 = 한 남자·관객만 앎)×정략결혼 압박 ⑤에스컬레이션 구하기·들킬 뻔 ⑥공주의 떠보기 시험·증거 하나 ⑦최대 위기+최대 스펙터클 → 공주 확신 직전 → 페이월.
- 이하 §1~§7의 구버전 기술 중 본 §0과 충돌하는 것 = 전부 §0 우선. 기획안 스펙·docx = v4 기준이라 **stale — 트리트먼트 도장 후 재조립**.

## 3. 코어 스토리·설정 캐논

- 알라딘: 빈민가의 '개짜침' 청년. 실은 진왕의 숨겨진 아들 (본인 모름 — 최종 리빌). **현재 시점 = 이미 각성 완료된 완성형 강자 — 거지 위장은 배후를 캐기 위한 선택 (각성형 설계 금지·v4).** 대회에서는 복면으로 정체를 숨긴 압도적 실력자 (기획안 문면에서 이 이중 신분은 자연어로 서술 — 고유 설정어·코드네임 금지).
- 어머니 나디라: 총독 가문에서 쫓겨난 여인·램프의 수호자. **수년 전 살해당함(병사로 위장) — 2화 플래시백 처리 (v4).** 살해 전모·배후 = 유료 후반.
- 램프: 어머니의 유품 = 진왕의 인장. **주인의 피에만 응답** — 힘은 빌린 것이 아니라 상속. 소원 자판기 구조 금지.
- 지니 카딤: 램프의 정령 — 혈통의 종. 개그 파트너 + 진실의 안내자. 각성·보조까지만, **결정타는 항상 알라딘 본인**. '지니' = 종족어(고유명 금지 룰 — 정령의 이름 = 카딤).
- 공주 소라야(Soraya): 술탄의 딸. EP1 마신 습격에서 복면의 남자에게 구출 → 은인 수배의 주체 → 대회에서 정체 모를 복면 실력자를 공개 선택/옹호.
- 빌런 사다리: 실행범(하수인) → 외숙 말리크 총독(대회 주관·어머니를 내치고 죽음에 관여) → 배후 = 대신관·카심 가문(램프·혈통 은폐 세력) → 시즌 훅 = 마신 세력. 갈등축 신설 금지 — 위기는 이 사다리 안에서.
- 조연: 카심(유력 후보·공주 혼약 경쟁자), 술탄(대회 개최·최종 심판의 입), 타리크(기사단장 — 복면 실력자를 쫓는 추적자 → 후반 조력 전환), 진왕 알바하르(아버지 — 최종 리빌 카드·본편 등장 최소).
- 무대: 가상 사막 술탄국 (국명 가칭 '카마르') · 카프 산(시즌 훅).
- 정보 비대칭 지도 (dramatic irony — 미스터리 금지, EP1부터 시청자 전지): 시청자 = 알라딘=복면 실력자=은인 전부 앎 / 소라야 = 은인을 찾는 중·복면 실력자를 의심 / 원수들 = 복면 실력자만 위협으로 인지·알라딘은 무시 / 알라딘 = 어머니 살해 배후와 자기 혈통을 모름.
- 정체 리빌 3단 사다리: ① 개짜침 ↔ 복면 실력자 ② 복면 실력자 = 공주의 은인 ③ 혈통(진왕의 아들) = 어머니 살해의 진짜 이유. 복수 수사와 정체 리빌 = 같은 사다리.

## 4. 무료 7화 (v4 정본 2026-07-25 — 완성형 히든 아이덴티티 재설계·사용자 확정)
