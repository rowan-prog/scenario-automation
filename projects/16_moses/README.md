## 이 작품의 두 축

- 모세가 아폴론처럼 보이면 안 됩니다. 신이 아니라 기적을 행할 힘이 있는 대언자입니다.
- 그리스풍을 걷어내고 구약·이집트풍으로 옮깁니다.

## 22~50화 공식

**누가 다말을 밟으면, 그 자에게 재앙이 떨어진다.** 왕도 전체가 아니라 그 집·그 손만. 다말은 자기 때문인 줄 모릅니다. 33화에서 델릴라와 다말이 동시에 알아채고, 36화부터 나라 전체 규모로 올라갑니다.

## 문서를 고칠 때

빌더를 고치고 다시 돌립니다. docx를 직접 편집하면 다음 빌드에서 날아갑니다.

```
cd 04_스크립트
python _build_guide_v18.py        # 가이드
python _build_treatment_v3.py     # 트리트먼트 (소스 = 02_기획/..._full_v5.md)
python _build_comments_v11.py     # 작가 회수본에 검수 코멘트 주입

python _guide_factcheck.py        # 가이드가 원작에 대해 하는 주장이 맞는지
```

현재 상태 — 트리트먼트 50화/클리프 50 결번 0 · 22~50화 전편 다말 등장 · 가이드가 원작에 대해 하는 주장 35건 불일치 0.
