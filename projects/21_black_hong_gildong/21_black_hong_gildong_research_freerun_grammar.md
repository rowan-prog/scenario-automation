# 21 무료런 문법 리서치 요지 (2026-08-07 · v12 재기획 근거)

> T1(v11) 플랫폼 DROP("숏폼 문법·결제 유도 감정 자극 부족") 대응 리서치. 소스 4종: Titan Born 52EP 전량 / 약자의 가면 1~10화 미시 리듬 / 망해가는K축구 77EP / CN 고전 IP 短剧 시장. 이 문서는 내부 설계용 — 기획안 본문에 이 용어들 침투 금지.

## 무료런 성립 5불변량 (3작품+CN 교차 검증)

1. **1화에 시청자 우월감 성립** — 회귀+시스템(K축구)·완전체 콜드오픈(Titan)·자막 정체 공개(가면). 방식은 달라도 "시청자가 인물보다 먼저 아는 것"이 1화 안에 선다.
2. **~3화에 천장 부분 검증 1회** — 낙인 직후 실력의 실물을 한 번 보여줘 결제 신뢰 예치(K축구 3화 노룩패스·가면 1화 덩굴 제압). 검증 없는 굴욕 적립 = 충전 안 된 고구마(T1의 병).
3. **굴욕이 떨어지는 그 순간 충전 장치 동봉** — ①직후 재맥락화(가면 3화: 저주 대사 직후 15년 전 진실 플래시백) ②제3자 선인지(황제가 먼저 앎) ③서술 윙크("일부러" 부사·가려진 미소) ④빌런 대사 부메랑. 굴욕 몰빵 화는 허용, 무충전 굴욕은 불허.
4. **정산 이중 트랙** — 미니 부채 = 같은 화 즉결이 기본값(K축구 황장호·18화 C국). 시그니처 상대만 3~6화 의도 지연. 뿌리 부채(제우스급)는 무료런에서 안 건드리고 유보. 최악의 모욕일수록 정산이 빠르다(Titan 8화 서자 저격→9화 즉시).
5. **매 화 엔딩 인월드 훅 + 절단은 정점 한복판** — 해소 직후 컷 0회. 결과 확정 직전에 끊는다.

## 두 검증 경로 (남성향 무료런)

- **①상시 은닉 파워형** (가면·신의한방): 매 화 이기되 정체·인정만 숨김. 굴욕 = 주인공이 선택한 전략(참는 이유가 화면에 서야 함 — 가면은 15년 계획 VO).
- **②봉인→각성형** (Titan): 무료런 8화 중 5화 순수 피학, 완결 승리 0회. 성립 조건 = 콜드오픈 천장 각인 + 물리적 굴욕 에스컬레이션 + 최저점이 정확히 무료 마지막 + **각성 = 결제 첫 화**(9화 이름 탈환). 사용자 교정(2026-08-07)과 일치: "압도적 굴욕 첫컷 → 각성도 가능" — 패턴이 아니라 하위 원리(낙차 양끝 가시화·정산 간격)가 성립 조건.
- v12 = 하이브리드: 밤(활빈당 두목) = 상시 유능 + 잔사이다 / 몸의 비밀 = 봉인→9화 각성.

## 가면 추가 실측

- 화 단위 배분은 몰빵형(2·4·5·6화 쾌감만 / 3·8화 굴욕만) — "매 화 골고루"가 아님.
- 낮/밤 이중생활 = 매 화 왕복이 아니라 **2위상**: 저감시(밤)에서 힘 증명 → 신뢰 저축 → 고감시(낮) 장기 굴욕 아크를 그 담보로 견딤. 왕복 축 = 목격자 밀도. → v12 무료 8화 구조(관아 밤 1-3 → 댁 낮 4-6 → 댁 밤 7-8)가 이 위상 문법과 정합.
- 우월감 장치는 초반 = 직접 설명형(VO·자막) → 후반 = 미시 신호(부사·표정)로 이관.

## K축구 추가 실측

- 1~10화 중 절반이 직접 쾌감 0 — 대신 매 화 엔딩 훅 + 3화 부분 검증 + 9~10화 풀 정산(5:0+무릎).
- 에스컬레이션 = 상대·판돈·목격자 3축 동시 확장·후퇴 없음(빈 벤치→기자회견장→전국→아시아→세계).
- 시그니처 매치마다 "주인공이 진다" 착시 1회 → 반전 낙차.

## Titan 추가 실측

- 무료 8화 = 8사건(화당 1)·공간 4곳(투기장 70%).
- 채찍질 노예주 = 정산 없이 영구 소거 — 정산 예산은 메인 라인에만.
- EP8 최악 대사("mud-born bastard… stepping stone") → EP9 팔 뜯기+이름 선언. 페이월 = 최저점과 최대 카타르시스 사이.

## CN 고전 IP 短剧

- **"각색이 아니라 이식"** — 원작 = ①진입장벽 제거(아는 세계관) ②향수 소품(명대사·상징 몇 개)뿐. 엔진 = 표준 문법(신분반전+낙차+打脸 사이클)을 그대로 꽂음. 원작 충실도와 숏폼다움은 반비례(업계 컨센서스).
- 오프닝 = 3초 골든훅(따귀·무릎·신분 떡밥), 세계관 설명 후순위/생략.
- 결제점 = "최대 굴욕의 정점 직후·신분반전 시작 직전"(~10화). 신화 설정은 무료에 소진, 정체 발현은 유료 초입.
- 동일 구조 검증작 = **《茅山打更人》**(iQiyi 2025 추천작 — 몰락 후계자가 야경꾼 위장 잠입·마을 유지가 괴물의 근원). **강시/동양 뱀파이어 정면 소재 = 미개척 공백**(파급력 있는 유료 히트작 미확인).
- 인프라: 抖音 万象短剧计划이 神话志怪类를 희소 소재로 지정·인센티브 지급 — 고전 오컬트 수요 신호.

## T1(v11) 병명 확정

세계관(관용구 문자화)이 엔진 자리를 차지 — 무료 8화가 설움 적립 + 세계 발견으로만 굴러가고, ①천장 검증 ②굴욕 충전 ③당일 정산 ④각성 상품이 전부 부재. 코미디·아이러니 = 결제 감정 아님(사용자 확인 2026-08-07). v12에서 주정서 = 복수/권선징악으로 교체, 위 5불변량 전량 반영.
