## 확정 고유명사 (무료런에서 락 — 유료도 준수)

- **KIERAN** (성 미공개 — 미스터리 유지) = 베일 홀딩스 회장 = 얼굴 없는 "the Chairman" = 야간 청소부 커버. 코버올 `[janitor: gray coveralls]` → 리빌 후 `[chairman: charcoal suit]`. **커버 동기 = 부를 숨기고 아내가 스스로 성공하도록 조용히 후원(결혼을 믿음). 헌신적 남편·냉정한 관찰자 아님. 불륜은 모른다 → EP4 목걸이로 발각(위 지식표).**
- **LAURA HAYES** = 불륜녀·창업주. 회사 = **Hayes Beauty**(뷰티 스타트업), 베일 타워 세입자.
- **JACE** = 18세 연하 트레이너·정부.
- **WALTER** = 키어런의 아버지(시아버지). 관자놀이 부상·병원(EP6). 심장 약함(유료서 활용 가능 — 원작 S121).
- **EMILY** = 키어런 심복 임원("Chairman" 호칭·집행자).
- **Veil Tower** = 무대 빌딩. **Veil Holdings** = 키어런 제국.

## EP8 종료 상태 (= EP9 seam)

갈라 볼룸. MC가 "the Chairman of Veil Holdings" 호명 → 카트 밀고 등장한 청소부-키어런 앞. Emily가 마이크로 "the Chairman = 이 청소부" 선언 직후. 전원이 청소부를 돌아봄. 로라 잔 떨어짐(깨지기 직전). **EP9 = 이 순간 Continuous로 이어받아 리빌 디토네이션.** 참석: 로라·제이스·Emily·투자자 군중·MC. 키어런 = 아직 코버올(리빌의 임팩트 = 코버올→회장 전환).

## 핵심 소품 (Hard Lock — 추적 필수)

- **와인병** = 키어런이 아버지에게 준 것 → 아버지가 축하하러 들고 옴 → 제이스가 박살(EP3-4) → 유료서 $15M 감정 → felony(EP13). 파괴 후 소멸 상태 추적.
- **$50k 목걸이** = 키어런이 로라에게 준 크리스마스 선물 = 로라가 제이스에게 줌 → 불륜 발각 트리거(EP4-5).
- **도시락** = 아버지 소품(EP1-2). 기능 종료 후 소멸.
- **대걸레 카트** = 키어런 커버의 상징 → EP8 갈라 등장(페이월 이미지).
