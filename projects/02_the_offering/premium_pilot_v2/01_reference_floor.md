## 1. 첫 10초 압박 (Hook Function Floor)

**기능 floor:** EP1 첫 10초 안에 다음 중 ≥3개 동시 식별 가능해야 한다.

- **자리 박탈의 증거** — 인장·이름·왕관·왕국 인장 등이 빼앗기는 물리 행위
- **죽음 임박 신호** — Sacrificial Bride 처분 라인 (드래곤에게 보내짐 = 의례 처형)
- **선택권자 정체의 일부** — 비늘 손등·날개 그림자·검은 망토 자락 (얼굴 X)
- **운명 신호의 첫 작은 깜빡임** — 손목 빛·룬·인장 호응 (audience-only)
- **이솔데 직접 어그러진 가치** — 흰 드레스·왕족 우아·잿빛 황무지 한가운데 (브라이트 vs 다크 첫 대비)

**EP1 첫 10초 X-rule:** 풍경 단독 / 설명 voice-over / 캐릭터 단순 도보 시작 / "오래된 옛날에..." 톤 회피.

**그 외 무료 EP 첫 10초 floor:** 직전 EP의 미회수 비트 (Bond·자세·자리 침범)를 즉시 갱신해서 새 압박을 만들어야 한다. EP 첫 컷이 단순 재개 컷이면 floor 미달.

## 2. 정보 비대칭 (Information Asymmetry Floor)

**기능 floor:** 매 EP에 다음 3 layer 동시 작동.

### Layer A — 관객이 알고 캐릭터가 모르는 것
- Vael의 비늘 빛이 이솔데에게 반응하는 의미 = 운명 짝 신호 (이솔데도, 인간 사절단도 의미 모름. audience만 본다)
- 어머니의 옛 인장이 keep 룬과 같은 박자로 빛난다 (audience-only — 이솔데 모름)
- Vael이 이솔데를 옆자리에 놓는 이유 = 단순 선택 X / 운명 짝 인식

### Layer B — 캐릭터가 알고 다른 캐릭터가 모르는 것
- 인간 왕국의 자객 음모 (Haldren은 위에서 명령 받음 / 이솔데 모름)
- Vael의 가문 100년 약속 (Vael 안다 / 인간 왕국 사절은 모름 / 이솔데 모름)
- Kiran이 keep 안에서 본 이솔데의 첫 며칠 (Vael만 알고 있는 약점)

### Layer C — 모두가 같은 자리에서 보는데 의미를 다르게 읽는 것
- EP2 옆자리 — 이솔데는 굴욕 / Elara는 박탈 / Haldren은 외교 미스 / Vael은 첫 공개 선언 / audience는 운명 짝 인정
- EP6 손목 빛 깜빡임 — Haldren은 본 적 있다 (왕국 기록) / Elara는 의미 모름 / 이솔데는 자기 손목인데 의미 모름 / audience는 신부 선언이 임박했음 안다

**Floor violation 신호:** Vael의 모든 동기를 캐릭터 발화로 설명 / audience와 캐릭터가 같은 정보 받음 / 비밀이 audience에게도 비밀.

## 3. Paywall Force Floor (EP8 페이월)

**기능 floor:** EP8 페이월은 **붕괴 직전** 상태여야 한다. 다음 모두 작동.

1. **신부 선언이 시작되어 끊긴다** — "She is —" / "She belongs —" 같은 미완성 라인. 다음 단어가 audience 머릿속에서 자동 재생.
2. **공개 마킹 표지가 audience 시야에 박힌다** — 손목 빛 영구화·목 옆 잇자국·머리채에 닿은 비늘 손가락 — 사절단·신부 후보·신하 다 보는 자리.
3. **인간 왕국 깃발이 사절단 발 앞에서 태워진다** — 거부 의지의 물리 시그널.
4. **드래곤 무리 첫 포효** — 작품 정체성 시각 자산이 처음 본격 진입. 사절단 호위병 12명 무릎 꺾음.
5. **이솔데의 자발 마킹 첫 비트** — Vael의 비늘 손등을 자기 손으로 감싸기 시작 (mutual claim 첫 시그널). 단 완성 X.

**유료 회수 약속 (page 8에서 만들어두고 EP9+에서 회수):**
- 신부 선언의 완성 단어 (Mate Sealed)
- 공개 키스 (목·입술 모두)
- 옷 안·드레스 끈 풀림 직접 / 침대 비트 / 첫 밤
- 알드릭 왕의 음모
- 이솔데의 진짜 핏줄

**Floor violation 신호:** EP8이 마무리되는 듯한 closure / Vael이 신부 선언을 끝내버림 / 공개 키스 완성 / 첫 밤 비트 직접.

## 4. 감정 압박 강도 (Character Pressure Floor)

**기능 floor:** 매 EP에 이솔데의 처지가 가시적으로 변해야 한다 — 자리·이름·소유·옆 사람·시선. 변화의 방향:

| EP | 이솔데의 처지 변화 (한 줄) |
|---|---|
| EP1 | 인간 왕국 처분 대상 → Vael이 잡아 들어 올린 손목 (선택자가 audience에게 식별됨) |
| EP2 | 도착 의상 (왕국 공주) → Vael이 지시한 새 의상 + 모두 앞 옆자리 (공개 자리 첫 침범 — 이솔데 측) |
| EP3 | 옆자리 → 침실 벽 (단 둘만 — 사적 거리 첫 붕괴) |
| EP4 | 침실 → 회의실 끝 (Vael이 인간 왕국 깃발 태움 = "그들이 너를 그 이름으로 다시 부르지 못한다") |
| EP5 | 회의실 → 테라스 (Vael의 망설임·키스 직전·둘째 잇자국 — Vael 자신이 흔들리는 첫 비트) |
| EP6 | 테라스 → 대연회장 자발 옆자리 (이솔데가 처음 자기 의지로 그 자리에 앉는다) |
| EP7 | 자발 옆자리 → Vael의 무릎 위 (회의실·신하 다 본다 — 공개 자세 강제 첫 시점) |
| EP8 | Vael의 무릎 위 → 한 단 위 옆자리 (사절단·신부 후보·신하 다 본다 — 자리 박탈의 완전 역전 직전 + 신부 선언 끊김) |

**Pressure floor:** Vael 측 압박도 함께 변해야 한다 — 단순 일방 압박은 두 회차에서 시청자 이탈. EP5부터 Vael 자신의 미세한 흔들림·소유욕 강도 단계화·자기 통제 무너짐이 함께 누적.

**Floor violation 신호:** 이솔데가 한 EP를 거리만 둔 채로 통과 / Vael의 강도가 한 회차 통째로 정체 / 처지 변화가 대사 설명으로만 처리.

## 5. 장면 밀도 (Scene Density / Hook Density Floor)

**무료회차 분량 정책 (2026-05-15 사용자 락):** EP1-8 = **편당 2-2.5분 권장** (압축 X / 깊이 우선). 씬 수 = 1-6씬 유동·7씬 제한.

**기능 floor:**

- **EP당 결제 엔진 비트** ≥ 1개 (5.5 Forbidden Touch / 5.2 Possessive Protector / 3.6 거리 붕괴 표지 / 5.4 비인간 신호 / 5.10 Public Recognition — `feedback_v3_17_payment_engines.md` 매핑).
- **EP당 sensual 비트** ≥ 1개 (블루프린트 EP1-8 sensual lock 직접 매핑). EP1·EP2는 lower intensity (Bond Sensed) / EP3부터 본격 / EP5·EP7 미세 폭발 / EP8 페이월 응축.
- **EP당 audience-only 비트** ≥ 1개 (정보 비대칭 Layer A).
- **EP-end hook (END HOOK)** = EP1-7 모두 강한 다음 컷 약속 (대사 라인·시각·자세). EP8 = 페이월 응축.
- **씬당 라인 수** = 3-7 라인. 단 EP1·EP3·EP8처럼 무거운 씬은 7-10 라인까지 허용 (무료회차 분량 여유).

**Floor violation 신호:** EP에 결제 엔진 비트 0개 / sensual 비트가 audience-only 없이 cap 발생 / END HOOK이 단순 컷·"to be continued" 톤 / 씬당 라인 수가 12+ (분량 over).

## 6. Intimacy Heat Floor (다크 로맨타지 high-heat)

**기능 floor:** 매 EP의 sensual 비트는 다음 8 질문 자가 검수 통과.

1. 누가 먼저 다가가는가 (구체 동작 — 손·시선·발걸음)
2. 누가 저항하는가 (구체 반응 — 손목 떨어뜨림·시선 외면·물러섬)
3. 누가 결국 받아들이는가 (변화 시점·동작)
4. 몸의 반응이 관계를 어떻게 바꾸는가 (다음 씬 변화)
5. 이 접촉 이후 권력관계 변화?
6. 이 접촉 이후 소유감 변화?
7. 이 접촉 이후 운명 인식 변화?
8. 이 접촉 이후 공적 관계 변화?

**8 모두 통과 = floor 통과.** 한 개라도 빈 칸 = 비트 약화 / 단순 묘사로 떨어짐.

| EP | Heat 등급 | 비트 본질 |
|---|---|---|
| EP1 | 1 (Bond Sensed) | 손목 안쪽 잡혀 들어올림·맥박 위 손가락 |
| EP2 | 2 (First Claim — public) | 옆자리·머리채 짧은 접촉·검은 비늘 손가락 의자 팔걸이 두 드림 |

## 7. Native English Voice Floor

**기능 floor:** 모든 대사는 다음 기준 통과.

- 북미 배우가 실제로 입에서 낼 수 있는 라인
- 문법 정확성보다 spoken naturalness 우선
- AI dialect 즉시 감점 (em-dash 남용 / "It wasn't X, it was Y" 반복 / 과잉 parallel structure / 과도한 poetic phrasing)
- Stiff fantasy English 즉시 감점 (mock-archaic, "thee/thou", medieval pastiche, "shall not be allowed" 톤)
- 책 narration tone 즉시 감점 (배우가 입으로 못 내는 문어체)

**Vael 톤 floor (캐릭터 voice):**
- Compact declarative possessive — "Mine." / "Stay." / "Inside." / "Not that one." / "She doesn't kneel." / "She belongs here."
- Imperative 우선 / 변명 X / 약함 발화 X
- 8-15 단어 짧은 명령형 라인이 base / 6 단어 이하의 폭발 라인이 punch

**이솔데 톤 floor:**
- 매달리지 않음 / 자기 연민 X / "나는 강해" 자기 선언 X
- 짧고 단단함 / 질문보다 단정·관찰 우선
- "I know what you did." / "I'm not asking." / "Don't lie about her." 톤

**Haldren 톤 floor:**
- 외교 formal 라인 / Imperial 격식 / 12-18 단어 OK
- 결국 균열이 보이기 시작 (EP5+ "Your Grace... if I may." 톤)

**Floor violation 신호:** Vael이 자기 동기 설명 / 이솔데가 호명 X에 매달리는 라인 / 사절단의 외교 라인이 K-drama 식 우회

## 8. Visual Specificity Floor (9:16 vertical)

**기능 floor:**

- **어셋 식별 가능 묘사** — 첫 등장·변경·재착용 시 짧은 식별자 ([VISUAL/ACTION]). 직전 씬과 동일 = 묘사 X.
