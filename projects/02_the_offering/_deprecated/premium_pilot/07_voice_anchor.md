# Step 7 — Voice Anchor

**원칙:** 각 캐릭터의 voice는 *baseline source* + *register source* 합성. d가 spoken naturalness baseline. 다른 source는 cadence·register 보강.

---

## ISOLDE — 능동·박탈 응수·소유 응대

**Voice Anchor:** `version_d baseline + version_a defiant cadence + version_c voice-distinct phrasing`

**핵심 voice rule:**

1. **Minimal declarative** — 첫 응답은 항상 짧음 (3-6단어). "I'll walk." / "Yours." / "I will carry it myself."
2. **박탈 응수는 defiant + 짧음** — "Then it does not need to call me at all." / "Then stop pretending I'm not."
3. **Contraction 사용 자유** — "I'll" / "won't" / "isn't" — modern spoken
4. **감정은 행동으로** — 두려움·욕망 직접 발화 X. 호위병 손 떨치기·자기 발로 걷기·자발 마킹 같은 *행동*으로
5. **EP1→EP8 능동 곡선** — EP1 호위병 떨치기 → EP3 first bite 후 응시 → EP5 적극 응수 → EP8 자발 역방향 마킹

**EP별 voice 표지:**
- EP1: silent + minimal ("I'll walk.")
- EP2: testing ("Don't thank me for it. / I won't.")
- EP3: 짧은 반응 (mostly silent during first bite)
- EP5: defiant + 적극 ("Then stop pretending I'm not.")
- EP6: declarative public ("I will hear it from the seat I am in.")
- EP8: 자발 mark + "Yours." (한 단어)

---

## VAEL — Alpha Compact Possessive + Imperative

**Voice Anchor:** `version_d baseline + version_c imperative + version_a restraint break + version_b alpha ambiguity`

**핵심 voice rule:**

1. **Compact possessive (2-4단어 declarative)** — "Mine." / "Stay." / "Mine to keep." / "Mine to give."
2. **Imperative when alone with ISOLDE** — "Sit." / "Look up." / "Don't."
3. **Ceremonial register when public** — Royal·court 자리에서 약간 long (그러나 단일 호흡, contraction 없음). e의 ceremonial long 라인은 짧게 재작성. 14단어 상한.
4. **Restraint break alpha line** — "Because if I don't stop, I won't." / "I haven't yet decided what you are to me."
5. **Paywall declarative interrupted** — "She is —" / "On my mouth. Not yours."
6. **Silence 의존 X** — b·c·d 모두 declarative line 보유. silence는 ISOLDE의 영역.

**EP별 voice 표지:**
- EP1: minimal alpha ("Open the gates when she stands alone.")
- EP2: public possessive ("Mine to give.")
- EP3: restraint break + mark claim ("Mine to keep.")
- EP4: banner burn declarative ("It is what walked in.")
- EP5: sensual ambiguity ("Not yet your mouth.")
- EP6: public marking statement ("The mark holds.")
- EP7: court intimacy ("She is on my knee.")
- EP8: paywall interrupted ("She is —")

## ALDRIC (인간 왕 / Antagonist) — Cold Adversary

**Voice Anchor:** `version_c primary` (cold-open + adversary anchor)

**핵심 voice rule:**

1. **Cold + clinical** — 감정 0. "She was a mistake too." / "Bring them in armed." (단 이건 VAEL line — ALDRIC version)
2. **Dismissive imperative** — 짧고 명령적. ISOLDE를 사물처럼.
3. **Late-EP threat** — EP7+ 점진 위협 증대. ridges에 두 그림자 / second instrument.

## KIRAN — Vael의 첫 신하 / Witness

**Voice Anchor:** `version_d primary`

**핵심 voice rule:**

1. **Sharp evidence pointer** — "Ask the wrist." / "That is what walked in."
2. **Tilt + lean** (행동) — 무릎 꺾음·고개 기울임으로 인정·각인 신호
3. **Period-flavored but spoken** — formal but natural
4. **EP8 무릎** — Vael 옆 인물 중 첫째로 무릎 (court 사절단보다 먼저)

---

## HALDREN (인간 왕국 사절단장) — Reluctant Witness

**Voice Anchor:** `version_d primary + version_c S#4 위치`

**핵심 voice rule:**

1. **Reverent witness** — "I remember which gate she walked in." (period-flavored spoken)
2. **EP6 첫 이마-바닥 bow** — kingdom 측 인물 첫 굴복
3. **EP8 반절** — 다른 envoy는 무릎, HALDREN은 반절 (이미 EP6에 부분 굴복)

## ENVOY / Sentries / Court — Minor

**Voice Anchor:** 평이한 imperative·short report만. cadence 색채 없음.

---

## Voice Anchor 검수 룰 (Step 10 Rewrite 시)

작성한 라인을 다음 질문으로 검수:

1. ISOLDE 라인이 6단어 초과인가? → 짧게.
2. VAEL 라인이 14단어 초과인가? → 짧게 또는 ceremonial 정당화.
3. ISOLDE가 감정을 직접 말하는가? → 행동으로 대체.
4. VAEL이 설명적인가? → declarative로.
5. e의 ceremonial-long 패턴 잔존하는가? → 짧은 spoken으로.
6. Contraction (I'll·won't·isn't) 사용했는가? → 캐릭터에 맞게 (ISOLDE: 많이 / VAEL: 적게·alpha 거리감)
