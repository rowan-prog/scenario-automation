## 1. Voice Book

### ISOLDE
- **Cadence:** Minimal declarative (3-6단어). Contractions 사용. Silent default.
- **Sigil 라인:** "I'll walk." / "Yours." / "I am." / "Then it does not need to call me at all."
- **Defiant pattern:** "Then [반전 명령]." — "Then stop pretending I'm not." / "Then treat me the way they sent me."
- **공개 발화 (court):** declarative + 자리 명시. "I will hear it from the seat I am in."
- **감정 표현:** 행동 (호위병 떨치기·자기 발로 걷기·자발 마킹). 직접 발화 X.

### VAEL
- **Cadence:** Compact possessive (2-6단어 default). Imperative when alone.
- **Sigil 라인:** "Mine." / "Stay." / "Mine to keep." / "Mine to give." / "She is on my knee." / "On my mouth. Not yours."
- **Restraint break:** "Because if I don't stop, I won't."
- **Ambiguity (paywall):** "Not yet [X]." / "Not yet a name." / "Not yet your mouth."
- **공개 declarative:** "The mark holds." / "Tell your king. / That this is what walked in." / "Bring them in armed."
- **Paywall:** "She is —" interrupted

### KIRAN
- **Cadence:** Sharp evidence pointer. "Ask the wrist." / "That is what walked in." / "Twelve."
- **Role:** Vael's first vassal. Witness. EP8 무릎 first.

### HALDREN
- **Cadence:** Period-flavored but spoken. "I remember which gate she walked in." / "My lord."
- **Arc:** EP6 첫 이마-바닥 bow → EP8 one knee (격하).

### Antagonist (Kingdom Captain / ALDRIC)
- **Cadence:** Stiff military / Cold clinical.
- **Captain:** "My king's terms." / "With her in it."
- **ALDRIC (off-screen, paid 등장 전 references):** Cold. Dismissive.

## 9. Native English Style Rules (Step 4 framing prompt 흡수)

```
역할: native US/Canada dialogue editor
기준: mobile short-form drama (ReelShort·NetShort·DreameShort·MoboReels)
우선순위: performability > grammar

즉시 감점:
- translation smell
- AI dialect (em-dash 남용 / "It wasn't X, it was Y" / parallel structure 과잉 / poetic 과잉)
- stiff fantasy English (mock-archaic, "thee/thou")
- 책 narration tone

판단: "북미 배우가 실제로 입에서 낼 수 있는 라인인가?"
문법 정확성 < spoken naturalness
```

**적용 룰 (paid EP9-50):**
- 라인 3-10 단어 (default). Vael ceremonial은 10-14 단어 상한 (15+ 금지).
- Contractions 자유 (ISOLDE: 많이 / VAEL: 적게).
- 대사 안 em-dash 금지. 지문 em-dash도 자제.
- 평이한 Anglo-Saxon vocabulary 우선.
- 매 대사 입에서 nail 가능 검증.
