## 1. 첫 10초 압박 floor (EP1 first frame ~ first 10s)

**기능 요건 (모두 충족 필수):**

| 항목 | floor 기준 |
|---|---|
| 1.1 명시적 stake | 첫 10초 안에 protagonist에게 *돌이킬 수 없는 결정·박탈·위협*이 가시화. 평온한 일상 시작 X. |
| 1.2 status 박탈 표지 | protagonist의 신분·소속·이름·소유물 중 1+ 항목이 첫 10초에 *공식적으로* 박탈되는 시각 표지 (인장 떨어짐·문 잠김·이름 호명 격하·옷차림 강제 등) |
| 1.3 antagonist 압박 시각화 | antagonist의 권능·위협이 *물리적 시각*으로 제시 — 단순 대사 위협 X. 화염·날개 그림자·다중 인원 압박·신체 반응(상대 위축) 중 1+ |
| 1.4 viewer 정보 우위 비트 | protagonist는 모르지만 viewer만 보는 비트 1+ (운명 단서·숨겨진 인장·차후 빌드업 표지) |
| 1.5 hook line within 10s | 한 라인이 시청자에게 "다음 비트가 궁금하다"를 즉시 형성 — 그 라인은 평이한 narration X / 명시적 declarative or imperative |
| 1.6 시각 reveal pacing | first frame부터 10초까지 *최소 3 cut 이상*. 정적 단일 와이드 의존 X. |

## 6. Intimacy Heat floor (초고수위 적용)

**기능 요건 — 매 EP 누적:**

| EP | heat floor (function-level) |
|---|---|
| EP1 | 시선 충돌 + 첫 신체 근접 (손가락·턱·머리채 중 1) + 옷자락 또는 비늘 접촉. 키스 X / Heat 1단. |
| EP2 | 자세 강제 (옆자리·앞자리·무릎 등) + 신체 위치 강제 비트 1+. Heat 1.5단. |
| EP3 | 폐쇄 공간 단독 + 신체 접촉 강화 (손목 안쪽·턱 강제·머리채 강제). 키스 직전 정지 OR 짧은 강제 키스. Heat 2단. |
| EP4 | 신체에 남는 표지 첫 등장 (잇자국·빛 자국·손목 자국·반지 자국 중 1). 옷 부분 풀림 표지. Heat 2.5단. |
| EP5 | 둘째 표지 (다른 자리 또는 같은 자리 누적) + 옷 안 손 표지 1+. 키스 깊이 강화. Heat 3단. |
| EP6 | *공개 마킹* 첫 등장 (관중 앞에서 표지 노출) + 자세 강제 공개 비트. Heat 3.5단. |
| EP7 | 침실·테라스·왕좌 등 폐쇄 공간 sensual 정점 (강도 4단). 옷 끈 풀림·드레스 어깨 내림·맥박 키스·자세 강제 (벽·문·테이블·왕좌). 키스 풀 강도. Heat 4단. |
| EP8 | 페이월 — *공개 환경*에서 EP1-7의 표지가 *공개 노출*. 자발 마킹 비트 첫 등장. 첫 밤·완전 결합은 paid에 유예. Heat 4.5단 (5단 = paid). |

**표현 룰 (북미 paid vertical 기준):**

- **구체 행동 우선 — 미묘함 X.** 시선·뉘앙스·은밀한 분위기 의존 X. 손이 어디를 잡는가·옷이 어떻게 풀리는가·입술이 어디에 닿는가·자국이 어디에 남는가 명시.
- **샷·라인 레벨 디테일.** "키스한다" 한 줄 처리 절대 금지. 누가 먼저·어떻게·상대 반응·혀 얽힘·신음·손 위치까지. 베드 씬은 [Camera] 블록에 클로즈업 명시 (침대보 움켜쥔 손·등 손톱 자국·잇자국·발끝·옷자락).
- **반복·집착·소유 표지 강제.** 매 화 *동일 또는 누적*되는 신체 표지 (잇자국 자리·빛 자국·자세 강제).
- **공개·비공개 표지 분리.** EP1-5 = 비공개 표지 중심 / EP6-8 = 공개 표지 누적.
- **여주의 wish-fulfillment 방향 보존.** 변태적 강도는 *antagonist가 protagonist에게 압도적으로 매혹·집착·소유*되는 방향. protagonist 굴욕으로 끝나는 방향 X.

## 7. Native English Voice floor

**기능 요건:**

| 항목 | floor 기준 |
|---|---|
| 7.1 spoken naturalness | 모든 대사는 *북미 배우가 입으로 낼 수 있는* 영어. 문법 정확성보다 spoken naturalness 우선. |
| 7.2 dialogue economy | 라인당 3-10 단어. 한 호흡에 끝나는 길이. 다회 왕복 대화 X. |
| 7.3 캐릭터별 분리 | 캐릭터별 cadence·어휘·반응 패턴이 *3 라인 안에서 식별 가능*. |
| 7.4 즉시 감점 | translation smell / AI dialect (em-dash 남용 / "It wasn't X, it was Y" 반복 / 과잉 parallel structure / 과도한 poetic phrasing) / stiff fantasy English (mock-archaic, "thee/thou") / 책 narration tone 모두 floor 미달. |
| 7.5 declarative + imperative 균형 | 다크 로맨타지 alpha male = 짧은 declarative·imperative 우선 ("Mine." / "Stay." / "Look at me." / "Don't."). 긴 설명 X. |
| 7.6 ceremonial register 분리 | 공식 자리 (사절단 앞·왕좌·의식) vs 비공식 자리 (침실·복도·정원) cadence 분리. 같은 cadence로 일원화 X. |
