- [x] 세계 규칙이 일관되는가? — 드래곤 조약 (EP1 룬 호응 단서) / 비늘 빛 (운명 짝 신호 점진) / 드래곤 무리 (EP7 첫 그림자 → EP8 첫 포효) / 인간 왕국 정치 (EP1 cold-open + EP4 맵룸 + EP8 사절단 강경).

- [x] 큰 reveal의 어휘가 작은 reveal에서 소모되지 않았는가? — 신부 호명·공개 키스·옷 안·침대·신부 선언 완성 = 본문 미발화. EP8 "She is —" 미완성으로 어휘 보존.
