## 1. 에이든 (Aiden) · 35 · 주인공

> **2룩 인물.** §1-A 위장 룩(무료 1~9화) · §1-B 진짜 룩(페이월 직후 전환 · 원작 강우현의 정장 입장 슬롯). 전환 트리거 = **용심의 인장을 손가락에 낀다.** 두 룩은 **같은 무채색 세로 직사각 실루엣**이고 갈리는 건 마감뿐 — 같은 남자인 게 실루엣으로 읽혀야 한다.

### 1-A. 위장 룩 — 마탑 지하 서고의 사서 (무료 1~9화)

| 항목 | 내용 |
|---|---|
| **헤어** | 짙은 재빛 갈색. 귀를 덮고 목덜미에 닿는 미디엄 길이를 손으로 뒤로 넘겨, 이마와 눈썹이 그대로 드러난다. 앞머리 몇 가닥만 관자놀이로 흘러내린다. 자연스러운 결. **머리를 떡지게 하거나 눈을 가리지 않는다 — 허름함은 옷이 맡는다.** |
| **피부** | 지하 서고 3년 = 햇빛 안 든 밝은 피부. 모공과 솜털이 보이고 톤에 미세한 편차가 있다(매끈하게 밀지 않는다 · 죽은 회색 피부 금지). 손가락 마디와 손톱 밑에 잉크 얼룩이 상시. |
| **눈** | 짙은 철회색. 눈이 크고 살짝 깊게 자리 잡았으며 윗꺼풀 주름선이 깨끗한데, 늘 반쯤 내리깔고 있어서 감정이 안 새어 나온다 — **시선 자체는 살아 있다(죽은 눈 금지).** 힘을 감추지 않는 컷에서만 홍채 테두리에 얇은 금빛 링이 돈다. |
| **얼굴 인상** | **외모 방향 = 유럽계.** 눈이 깊게 자리 잡고 눈썹뼈가 또렷하며 콧대가 높고 곧다. 얼굴선이 곱고 이목구비가 큰 미남을 먼지와 반쯤 감은 눈으로 덮어둔 얼굴 — 각지지 않았고 턱선이 얇고 깨끗하다. |
| **몸매** | 헐렁한 로브가 완전히 감추고 있는 넓은 어깨·긴 팔·좁은 허리. 옷 밖으로 나오는 건 팔뚝과 목뿐인데, 그 두 군데만으로 체급이 새어 나온다. 웅크린 자세가 기본값이라 서 있을 때보다 항상 작아 보인다. |
| **의상** | 겹은 셋인데 전부 같은 계열이라 화려해지지 않는다 — 성글게 짠 마 셔츠 위에 한 겹 두꺼운 사서 튜닉, 그 위에 무릎까지 오는 앞트임 로브, 허리는 가죽끈 하나. **밀도는 장식이 아니라 마감에서 나온다** — 풀린 소맷단 실밥, 해진 밑단 올, 무릎에 덧댄 색 다른 헝겊, 여러 번 물 먹어 이음선마다 갈린 색, 성긴 마의 짜임이 눈에 보이는 결. 소매는 팔꿈치까지 걷어 올렸다. 색 = 먼지 회색·바랜 갈색 — 전 캐스트 중 유일하게 채도가 없는 인물. 촛농과 잉크 자국이 그대로 남아 있다. **금속·자수·버클 0 — 구조물이 하나도 없는 유일한 인물이고, 그게 이 인물의 실루엣이다.** |
| **노출도** | 사실상 0. 걷어 올린 소매 아래 팔뚝, 풀린 앞섶 사이로 보이는 목선과 쇄골까지. (여왕들의 노출과 붙었을 때 이 대비 자체가 그림이다) |
| **장비/소품** | **가죽끈 하나에 둘이 같이 꿰여 목에 걸린다.** ①**최하위 등급 인장패** — 무광 납회색 원반에 오각별이 새겨진 것. 다른 마법사들의 금·보석 인장과 재질부터 다르다(가슴 앞으로 나와 있는 건 이쪽이다). ②**용심의 인장** — 겉보기엔 낡은 은반지, 용이 감긴 세공. 3년간 손가락에 끼지 않고 셔츠 안쪽에 넣거나 주먹에 쥔다. **다만 화면에서 완전히 사라지면 안 된다** — 3화에서 짓밟히고 B룩에서 그가 끼는 물건이라, 인장패 뒤로 숨더라도 손 클로즈업·앞섶 사이에서는 반드시 읽혀야 한다. |
| **분위기** | 그가 들어오면 화면이 조용해진다. 주변 인물이 화려할수록 그 자리만 채도가 빠지고, 결국 눈이 그 무채색 쪽으로 돌아온다. |

### 1-B. 진짜 룩 — 9서클 대마법사 (페이월 직후~)

> **확정 실물 = `eros_cg_06_aiden_true_archmage.png` (2026-08-01 사용자 제공).** 아래 기술은 그 실물에 맞춘 것 — 문서와 실물이 어긋나면 실물이 정본이다.

| 항목 | 내용 |
|---|---|
| **얼굴·헤어** | **같은 배우·같은 머리.** 위장 룩과 헤어를 바꾸지 않는다 — 둘 다 짙은 다크 브라운의 흐트러진 미디엄 웨이브이고, 이마 위로 몇 가닥이 그대로 떨어진다. **정돈해서 격을 올리지 않는다**(빗어 넘기면 다른 사람이 된다). 얼굴에서 바뀌는 건 딱 둘: **①늘 반쯤 내리깔던 윗꺼풀이 완전히 열려 정면을 본다** ②**홍채 테두리의 얇은 금빛 링이 상시 켜진다**(위장 룩에서는 지정 컷에서만). |
| **피부** | 동일(햇빛 안 든 밝은 톤·모공과 솜털 유지). **손의 잉크 얼룩만 없다** — 위장 룩의 상시 소품이던 잉크가 사라진 게 손 클로즈업의 전환 신호. |
| **자세** | **웅크림 해제.** 어깨가 완전히 펴지고 턱이 수평으로 든다. 위장 룩이 서 있을 때보다 항상 작아 보였다면, 이쪽은 실제 키가 그대로 나온다 — **같은 인물인데 프레임에서 갑자기 커진다.** 걸을 때 상체가 흔들리지 않는다. |
| **실루엣 시그니처** | **어깨 뒤로 크게 세워 올린 각진 하이칼라 + 무릎 아래에서 뾰족하게 갈라지는 코트 밑단.** 역광에 그림자만 떠도 목 뒤에 각진 판이 서고 밑단이 창끝처럼 갈라진 게 읽힌다. 여왕 셋의 시그니처(칼날 견갑·나뭇가지 관·흑요석 뿔)가 전부 **좌우로 벌어지는** 구조인 반면 이 남자만 **위로 선 직선** — 넷이 한 프레임에 서도 실루엣이 안 겹친다. |
| **의상** | 흑단 3층 롱코트. ①**안층** = 몸에 붙는 흑 이너와 흑 슬랙스·흑 부츠 ②**여밈층** = 비늘 세공 라펠이 가슴 앞에서 사선으로 겹쳐지되 **가슴 가운데는 열어 둔다**(완전히 잠그지 않는다 — 목까지 채우면 성직자가 된다) ③**흐름층** = 발목까지 떨어지며 밑단이 뾰족하게 갈라지는 코트. **밀도는 금빛 룬 각인이 낸다 — 옷깃·소매·앞판·등판을 따라 마법식이 금실로 짜여 있고, 빛을 받는 각도에서만 옷 전체가 룬으로 덮여 있는 게 드러난다**(3년간 그가 대신 써준 마법식이 그의 옷이다). 색 = 칠흑·먹빛 + **금 각인**. 보석 0·버클 화려함 0 — 금은 장식이 아니라 글씨로만 들어간다. |
| **노출도** | 가슴 가운데의 좁은 V와 목, 그리고 손. 그 외 전부 덮는다 — 여왕 셋의 노출과 한 프레임에 붙었을 때 이 대비가 그림이다. |
| **장비/소품** | ①**용심의 인장을 손가락에 낀다** — 3년간 안 끼던 걸 낀 상태가 이 룩의 기본값. 은빛 용 세공 반지이고, 낀 순간 죽은 각인이 안쪽부터 금빛으로 차오른다. 뭉갠 구두 굽 자국은 지우지 않는다(비비안이 짓밟은 흔적이 그대로 남은 채 대륙의 열쇠가 된다). ②**그 외 아무것도 안 든다 — 지팡이 없음.** 카타리나는 대검, 탈리아는 생목 지팡이, 프레이야는 뿔을 갖고 서는데 이 남자만 맨손인 게 격이다. ③최하위 등급 납회색 배지 없음(뗀 자리만 남는다). |
| **환경 이펙트** | 발밑에 금빛 다중 동심원 마법진이 깔리고, 주위에 책장과 낱장이 정지한 채 떠 있다. **빛은 전부 그의 바깥에 있다 — 몸이 발광하지 않는다.** 전신을 켜는 순간 여왕들과 같은 급으로 내려간다. |
| **분위기** | 위장 룩이 "화려한 것들 사이에서 채도가 빠진 자리"였다면, 이쪽은 **화면이 그를 중심으로 정렬된다.** 들어서는 순간 다른 인물들의 시선 방향이 전부 한 점으로 모이고, 그는 아무도 안 본다. |
| **전환 연출** | 반지를 손가락에 끼는 한 동작 → 사서 로브의 해진 밑단부터 먹빛으로 잠기며 위로 올라오고 금빛 룬이 옷깃을 따라 켜지며, 마지막에 칼라가 목 뒤로 선다. **원작 10화 슈트 전개와 같은 문법**(리모컨 → 슈트 전신 전개 → 헬멧 폐쇄). 되돌아갈 때는 반지를 뺀다. |

## 2. 카타리나 (Katarina) · 33 · 제국 여제 · 검신 — **차가운 쪽**

| 항목 | 내용 |
|---|---|
| **헤어** | 차가운 백금 애시. 허리까지 오는 직모를 정수리 높이에서 하나로 묶은 하이 포니테일인데, **바짝 당겨 붙이지 않는다** — 정수리에 볼륨이 살고 헤어라인에 잔머리가 남는다. **얼굴 양옆으로 긴 두 갈래가 귀 앞으로 흘러 턱선 아래까지 내려온다.** 모발 끝은 칼로 자른 듯 일직선. |
| **피부** | 햇살에 살짝 익은 옅은 골든 휘트 탠. 모공과 솜털이 살아 있는 진짜 피부(건조·팽팽·매끈 금지). 흉터 없음. |
| **눈** | 옅은 강철 회색. 크고 표정이 실리는 눈이 살짝 깊게 자리 잡았고 윗꺼풀 주름선이 깨끗하며 속눈썹이 길고 짙다. 홍채 테두리만 진해서 시선이 서늘하게 서되, **살아 있는 눈이다(비어 있는 눈 금지).** |
| **얼굴 인상** | **외모 방향 = 북방계.** 백금 애시에 어울리는 밝은 피부와 서늘한 언더톤. 이목구비 비율이 균형 잡힌 미인 — **각진 데가 한 군데도 없다.** 콧대는 높고 곧게 뻗되 코끝이 정돈됐고, 턱선은 타원으로 갸름하게 떨어지며 턱끝이 단정하고, 눈썹선이 또렷하고, 입술은 도톰하고 형태가 좋다. |
| **몸매** | 어깨선이 캐스트에서 가장 곧고 군더더기가 없다. **잔살 하나 없이 조여진 모래시계**(근육을 부풀린 몸 아님) — 곧게 뻗은 어깨에서 극단적으로 잘록한 허리로 떨어지는 V, 그 아래 탄탄한 엉덩이와 길고 매끈한 다리. 배는 평평하고 **탄탄한 복근이 또렷하게 잡힌다**(부풀린 근육 아님 — 조여진 몸에 얹힌 선명한 선). 가슴은 높고 탄탄한 중간~풍만. 강조점 = 어깨→허리의 낙차, 얇은 허리, 긴 다리. |
| **실루엣 시그니처** | **어깨에서 뒤로 뻗은 칼날 견갑 한 쌍.** 역광에 그림자만 떠도 어깨가 뒤로 벌어진 화살촉으로 읽힌다 — 캐스트에서 어깨에 구조물이 얹힌 인물은 이 하나뿐. |
| **의상** | 흑은 하프플레이트 3층. **①안층** = 심연 청흑 가죽 언더수트가 골반에서 발목까지 살갗처럼 붙되, 한쪽 옆선이 허벅지 위쪽까지 시원하게 트인 하이컷으로 갈라져 다리 라인이 그대로 드러난다(허벅지 중간부터 각반). **②구조층** = 몸을 그대로 뜬 흉갑이 쇄골 아래 얕은 넥라인에서 시작해 **갈비뼈 아래에서 깨끗하게 끊기고**(두께 없는 강철이지 뭉툭한 판금이 아니다), 하복부에서 골반으로는 낮게 걸친 짧은 강철 포드런이 받으며, 어깨 관절 바깥에 칼날형 견갑 한 쌍이 얹혀 뒤로 낮게 뻗고(어깨 윗면·팔은 맨살, 아래 모서리에 가는 은사슬), 강철·가죽 벨트가 버클 셋과 리벳 열로 골반을 두 바퀴 낮게 조인다. **③흐름층** = 진홍 벨벳 망토, 안감 청흑, 가장자리 은사 자수. 열림은 **갈비뼈 아래 맨 복부 + 견갑골 사이 좁은 열림** 둘뿐이고, 흉갑 면에는 정복지 문장이 하나씩 각인돼 큰 면이 비지 않되 **목과 쇄골 위는 비운다** — 색 = 진홍 / 은강철 / 청흑 · 소재 = 벼린 강철·무광 가죽·벨벳·은사. |

## 3. 탈리아 (Thalia) · 나이 가늠 불가 · 엘프 여왕 — **신비로운 쪽**

| 항목 | 내용 |

| **실루엣 시그니처** | **머리를 감싸는 금빛 나뭇가지 관 + 몸을 타고 감기는 같은 세공의 가지 넝쿨.** 이마 위로 잔가지와 잎이 얹히고 미간으로 물방울 장식 하나가 떨어지며, 같은 어휘의 금빛 가지가 어깨에서 가슴·허리를 지나 골반으로 감겨 내려간다 — 옷이 아니라 **나무가 몸에 자라 붙은 것**으로 읽혀야 한다. 그 아래로는 초장발과 시폰 자락이 구분 없이 바닥으로 흘러 세로 한 기둥이 된다. |
| **의상** | 얇은 두 겹뿐이라 두께가 안 생긴다. **①안층** = 상아빛 실크 원숄더 시스가 젖은 듯 몸에 붙는다 — 한쪽 어깨와 팔은 완전히 드러내고, 옆선은 **허벅지 위쪽을 지나 골반뼈까지** 갈라져 다리 한쪽이 통째로 나온다. 등은 **어깨뼈부터 허리까지 전부 열려** 있고 가는 금빛 가지 세공만 척추 위로 엇갈려 지난다. **②흐름층** = 옅은 민트·은빛 시폰이 골반에서 바닥으로 퍼져 뒤로 길게 깔린다(반투명이 살아 있는 건 이 자락과 등판뿐 — **정면은 비치지 않는다**). 몸을 타고 오르는 **금빛 나뭇가지 세공**이 유일한 구조물이고, 뼈·늑골 프레임·호박빛 구슬은 넣지 않는다. **맨발.** 색 = 상아·은백 / 옅은 민트 / 금빛 가지 · 소재 = 젖은 실크의 결 × 비치는 시폰 × 무광 금세공. |
| **노출도** | 한쪽 어깨와 팔 전체, **어깨뼈부터 허리까지 완전히 열린 등**, 옆트임으로 **허벅지 한쪽이 골반뼈까지**, 맨발. **정면은 비치지 않는다** — 밀착한 실크가 실루엣만 그대로 드러낸다. |
| **장비/소품** | **①지팡이 1개** — 백금빛 생목이 나선으로 꼬여 올라가는 **제 키보다 큰** 지팡이. 끝에서 가지가 손끝처럼 갈라져 초록 수정을 감싸 안고, 그 안에서 빛이 천천히 돈다. 자루를 따라 잔가지와 잎이 그대로 살아 붙어 있다. **②금빛 나뭇가지 관** — 이마 위로 잎과 잔가지가 얹히고 미간에 물방울 장식 하나가 떨어진다. **③잎 모양 귀걸이** — 긴 뾰족귀를 따라 늘어진다. 그 외 장신구 0. |
| **분위기** | 그녀가 서 있으면 화면이 반 박자 느려진다. 바람도 빛도 그녀 쪽으로만 흐르고, 같은 프레임의 인간들이 자동으로 배경이 된다. |

## 4. 프레이야 (Freya) · 나이 가늠 불가 · 드래곤 퀸 — **야성적인 쪽**

| 항목 | 내용 |
|---|---|

| **장비/소품** | **없음.** 무기도 지팡이도 방패도 왕관도 없다 — 맨손·맨발·맨몸. 몸에 붙은 금속은 전부 의상의 일부다(비늘을 잇는 가는 금선, 골반의 사슬 벨트, 발목 금고리). **뿔은 장비가 아니라 몸이다.** |
| **분위기** | 그녀가 들어오면 공기가 무거워진다. 사람들이 이유도 모른 채 무기를 내려놓고, 프레임 안의 불빛이 전부 한 번 흔들린다. |

## 6. 모르가나 (Morgana) · 51 · 비비안의 어머니 · 전대 마탑주의 미망인 — **농익은 쪽**

| 항목 | 내용 |
|---|---|
| **헤어** | 어두운 와인빛이 도는 흑갈. 어깨에 닿는 굵은 웨이브를 한쪽으로 몰아 넘겼다. 관자놀이에서 흘러내리는 은빛 새치 한 줄기를 감추지 않는다 — 나이가 무기라는 걸 아는 여자의 선택. |
| **피부** | 따뜻한 꿀빛 올리브. 목과 가슴 윗면에 고운 파우더 마감. **주름은 넣지 않는다.** 단 **모공과 솜털은 살린다.** |
| **눈** | 진한 석류빛 갈색. **눈이 크고 살짝 깊게 자리 잡았으며 윗꺼풀 주름선이 깨끗한데** 눈꺼풀이 무겁게 내려와 늘 반쯤 감긴 인상이고 속눈썹이 길고 짙다. 인상 = 상대를 위아래로 한 번 훑고 나서 웃는 눈. |
