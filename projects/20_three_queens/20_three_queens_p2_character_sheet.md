## 0. 시트를 뽑을 때 (전 인물 공통)

| | |
|---|---|
| **캔버스** | **가로 16:9 또는 4:3 · 최대 해상도.** 전신 정면/후면·사측면·얼굴 클로즈·부분 타이트를 가로로 벌려 인물을 크게 앉힌다. |
| **얼굴** | 풀샷에서 얼굴을 기대하지 않는다. **얼굴 클로즈를 먼저 뽑아 확정하고, 그 얼굴을 물고 전신·부분 컷을 파생한다.** |
| **미모 기준** | 기준은 사진 일반이 아니라 **패션 화보·뷰티 캠페인.** '실사'를 스냅 사진으로 잡으면 결과가 일반인 코스프레로 떨어진다 — 톱모델 캐스팅 + 화보 조명(강한 키 + 림 라이트 + 통제된 그림자 · **평평한 정면광 금지**) + 화보 보정 수준까지 간다. |
| **재질** | 코스프레 티는 얼굴보다 재질에서 난다. 폴리 원단·플라스틱 광택·붙여 놓은 장식 금지 — 진짜 벼린 금속, 무게 있는 벨벳, 결이 보이는 가죽. |

## 1. 에이든 (Aiden) · 35 · 주인공

| 항목 | 내용 |
|---|---|
| **헤어** | 짙은 재빛 갈색. 귀를 덮고 목덜미에 닿는 미디엄 길이를 손으로 뒤로 넘겨, 이마와 눈썹이 그대로 드러난다. 앞머리 몇 가닥만 관자놀이로 흘러내린다. 자연스러운 결. **머리를 떡지게 하거나 눈을 가리지 않는다 — 허름함은 옷이 맡는다.** |
| **피부** | 지하 서고 3년 = 햇빛 안 든 밝은 피부. 모공과 솜털이 보이고 톤에 미세한 편차가 있다(매끈하게 밀지 않는다 · 죽은 회색 피부 금지). 손가락 마디와 손톱 밑에 잉크 얼룩이 상시. |
| **눈** | 짙은 철회색. 눈이 크고 살짝 깊게 자리 잡았으며 윗꺼풀 주름선이 깨끗한데, 늘 반쯤 내리깔고 있어서 감정이 안 새어 나온다 — **시선 자체는 살아 있다(죽은 눈 금지).** 힘을 감추지 않는 컷에서만 홍채 테두리에 얇은 금빛 링이 돈다. |
| **얼굴 인상** | **외모 방향 = 유럽계.** 눈이 깊게 자리 잡고 눈썹뼈가 또렷하며 콧대가 높고 곧다. 얼굴선이 곱고 이목구비가 큰 미남을 먼지와 반쯤 감은 눈으로 덮어둔 얼굴 — 각지지 않았고 턱선이 얇고 깨끗하다. |
| **몸매** | 헐렁한 로브가 완전히 감추고 있는 넓은 어깨·긴 팔·좁은 허리. 옷 밖으로 나오는 건 팔뚝과 목뿐인데, 그 두 군데만으로 체급이 새어 나온다. 웅크린 자세가 기본값이라 서 있을 때보다 항상 작아 보인다. |
| **의상** | 겹은 셋인데 전부 같은 계열이라 화려해지지 않는다 — 성글게 짠 마 셔츠 위에 한 겹 두꺼운 사서 튜닉, 그 위에 무릎까지 오는 앞트임 로브, 허리는 가죽끈 하나. **밀도는 장식이 아니라 마감에서 나온다** — 풀린 소맷단 실밥, 해진 밑단 올, 무릎에 덧댄 색 다른 헝겊, 여러 번 물 먹어 이음선마다 갈린 색, 성긴 마의 짜임이 눈에 보이는 결. 소매는 팔꿈치까지 걷어 올렸다. 색 = 먼지 회색·바랜 갈색 — 전 캐스트 중 유일하게 채도가 없는 인물. 촛농과 잉크 자국이 그대로 남아 있다. **금속·자수·버클 0 — 구조물이 하나도 없는 유일한 인물이고, 그게 이 인물의 실루엣이다.** |
| **노출도** | 사실상 0. 걷어 올린 소매 아래 팔뚝, 풀린 앞섶 사이로 보이는 목선과 쇄골까지. (여왕들의 노출과 붙었을 때 이 대비 자체가 그림이다) |
| **장비/소품** | ①**용심의 인장** — 겉보기엔 낡은 은반지. 3년간 손가락에 끼지 않는다. 가죽끈에 꿰어 셔츠 안쪽 목에 걸거나 주먹 안에 쥔 상태가 기본, 손가락에 끼는 건 후반 지정 컷에서만. ②최하위 등급 인장 배지 — 무광 납회색, 보석 0, 다른 마법사들의 금·보석 인장과 재질부터 다르다. |
| **분위기** | 그가 들어오면 화면이 조용해진다. 주변 인물이 화려할수록 그 자리만 채도가 빠지고, 결국 눈이 그 무채색 쪽으로 돌아온다. |

## 2. 카타리나 (Katarina) · 33 · 제국 여제 · 검신 — **차가운 쪽**

| 항목 | 내용 |
|---|---|
| **헤어** | 차가운 백금 애시. 허리까지 오는 직모를 정수리 높이에서 하나로 묶은 하이 포니테일인데, **바짝 당겨 붙이지 않는다** — 정수리에 볼륨이 살고 헤어라인에 잔머리가 남는다. **얼굴 양옆으로 긴 두 갈래가 귀 앞으로 흘러 턱선 아래까지 내려온다.** 모발 끝은 칼로 자른 듯 일직선. |
| **피부** | 햇살에 살짝 익은 옅은 골든 휘트 탠. 모공과 솜털이 살아 있는 진짜 피부(건조·팽팽·매끈 금지). 흉터 없음. |
| **눈** | 옅은 강철 회색. 크고 표정이 실리는 눈이 살짝 깊게 자리 잡았고 윗꺼풀 주름선이 깨끗하며 속눈썹이 길고 짙다. 홍채 테두리만 진해서 시선이 서늘하게 서되, **살아 있는 눈이다(비어 있는 눈 금지).** |
| **얼굴 인상** | **외모 방향 = 북방계.** 백금 애시에 어울리는 밝은 피부와 서늘한 언더톤. 이목구비 비율이 균형 잡힌 미인 — **각진 데가 한 군데도 없다.** 콧대는 높고 곧게 뻗되 코끝이 정돈됐고, 턱선은 타원으로 갸름하게 떨어지며 턱끝이 단정하고, 눈썹선이 또렷하고, 입술은 도톰하고 형태가 좋다. |
| **몸매** | 어깨선이 캐스트에서 가장 곧고 군더더기가 없다. **잔살 하나 없이 조여진 모래시계**(근육을 부풀린 몸 아님) — 곧게 뻗은 어깨에서 극단적으로 잘록한 허리로 떨어지는 V, 그 아래 탄탄한 엉덩이와 길고 매끈한 다리. 배는 평평하고 **탄탄한 복근이 또렷하게 잡힌다**(부풀린 근육 아님 — 조여진 몸에 얹힌 선명한 선). 가슴은 높고 탄탄한 중간~풍만. 강조점 = 어깨→허리의 낙차, 얇은 허리, 긴 다리. |
| **실루엣 시그니처** | **어깨에서 뒤로 뻗은 칼날 견갑 한 쌍.** 역광에 그림자만 떠도 어깨가 뒤로 벌어진 화살촉으로 읽힌다 — 캐스트에서 어깨에 구조물이 얹힌 인물은 이 하나뿐. |
| **의상** | 흑은 하프플레이트 3층. **①안층** = 심연 청흑 가죽 언더수트가 골반에서 발목까지 살갗처럼 붙되, 한쪽 옆선이 허벅지 위쪽까지 시원하게 트인 하이컷으로 갈라져 다리 라인이 그대로 드러난다(허벅지 중간부터 각반). **②구조층** = 몸을 그대로 뜬 흉갑이 쇄골 아래 얕은 넥라인에서 시작해 **갈비뼈 아래에서 깨끗하게 끊기고**(두께 없는 강철이지 뭉툭한 판금이 아니다), 하복부에서 골반으로는 낮게 걸친 짧은 강철 포드런이 받으며, 어깨 관절 바깥에 칼날형 견갑 한 쌍이 얹혀 뒤로 낮게 뻗고(어깨 윗면·팔은 맨살, 아래 모서리에 가는 은사슬), 강철·가죽 벨트가 버클 셋과 리벳 열로 골반을 두 바퀴 낮게 조인다. **③흐름층** = 진홍 벨벳 망토, 안감 청흑, 가장자리 은사 자수. 열림은 **갈비뼈 아래 맨 복부 + 견갑골 사이 좁은 열림** 둘뿐이고, 흉갑 면에는 정복지 문장이 하나씩 각인돼 큰 면이 비지 않되 **목과 쇄골 위는 비운다** — 색 = 진홍 / 은강철 / 청흑 · 소재 = 벼린 강철·무광 가죽·벨벳·은사. |
| **노출도** | 어깨·팔·목·쇄골, **갈비뼈 아래부터 골반 벨트 위까지 맨 복부 — 배꼽 위아래로 탄탄한 복근이 그대로 드러난다**, 망토를 걷으면 견갑골 사이 좁은 등 열림, 한쪽 옆선은 **허벅지 위쪽까지 시원하게 트인 하이컷**으로 다리가 그대로 드러난다. 하의는 그 외엔 발목까지 밀착 가죽. |
| **장비/소품** | **검 1자루뿐.** 은백·백금빛 도신이 빛을 그대로 되쏘는 제 키만 한 대검 — 힐트는 정교한 금세공에 보석이 줄지어 박혀 있고, 가드는 날개(혹은 왕관) 형태로 좌우로 벌어지며, 도신 중앙 홈을 따라 룬 각인이 옅은 푸른빛으로 빛난다. 등에 메지 않고 손에 들거나 돌바닥에 꽂아 세워 둔다. 몸에 걸친 장신구·왕관·보석은 전부 없음 — 제국 여제인데 몸에 붙인 값나가는 건 이 검 하나뿐이다. |
| **분위기** | 그녀가 들어오면 프레임의 온도가 내려간다. 소리가 한 겹 빠지고, 사람들이 뒤로 반 걸음 물러선 자리만 남는다. |

## 3. 탈리아 (Thalia) · 나이 가늠 불가 · 엘프 여왕 — **신비로운 쪽**

| 항목 | 내용 |
|---|---|
| **헤어** | 창백한 연둣빛이 도는 금발. 무릎 아래까지 내려오는 초장발 직모로, 가는 땋기 두 갈래만 뒤로 흐르고 나머지는 전부 풀어놓았다. 걸을 때 머리카락이 몸보다 반 박자 늦게 따라온다. |
| **피부** | 달빛 백자 — 캐스트 중 가장 밝고, 초록 언더톤이 아주 옅게 깔려 있다. 빛이 살을 통과하는(subsurface) 진짜 피부 — 모공과 솜털은 그대로 두고 광택으로 밀지 않는다. 목선 아래 쇄골과 손등으로 이어지는 잎맥 문양이 피부 아래에서 은은히 비친다(**얼굴에는 절대 올리지 않는다**). |
| **눈** | 맑은 옥빛 초록에 금빛 홍채 테. **크고 표정이 실리는 눈, 눈 사이가 살짝 넓고 윗꺼풀 주름선이 깨끗하며, 속눈썹이 길고 짙다.** 시선은 늘 조금 먼 데 걸려 있되 **비어 있지 않다** — 사람을 벌레 보듯 내려다보는데 화도 없이 그런다. |
| **얼굴 인상** | 사람 아닌 것처럼 예쁜 얼굴. **외모 방향 = 인간이 아니므로 지역 무관** — 연둣빛 금발·긴 뾰족귀·창백한 피부가 종족감을 전부 만든다. 균형 잡힌 이목구비 비율, 높고 곧은 콧대에 정돈된 코끝, 갸름한 타원형 턱선, 도톰하고 형태 좋은 입술. |
| **몸매** | 캐스트 최장신이자 가장 가늘다. 목·팔·다리가 길고 어깨는 좁고 골반은 작다 — **뼈만 남은 게 아니라 매끈하게 길다.** 가슴은 크지 않지만 높고 형태가 또렷해 얇은 실크 위로 윤곽이 그대로 잡힌다. 강조점 = 끝없이 긴 다리와 등에서 허리로 떨어지는 척추 라인. |
| **실루엣 시그니처** | **정수리에서 바닥까지 떨어지는 베일.** 두 폭이 척추 양옆으로 갈라져 흘러 등 한가운데는 비어 있다 — 그림자로는 머리부터 발까지 끊기지 않는 한 기둥. |
| **의상** | 3층인데 전부 얇아서 두께가 안 생긴다. **①안층** = 상아빛 실크 시스가 젖은 듯 붙는다 — 가슴 사이로 깊게 갈라진 브이넥이 가슴골을 드러내고, 그 아래는 비치지 않게 짜인 **얇은 한 겹**이고 겹쳐서 두껍게 만들지 않는다(두툼해지는 순간 판타지가 죽는다). **②구조층** = 연녹 실크 드레이프가 한쪽 어깨에서 반대편 골반으로 감기고, 그 위를 **흰 생목·뼈로 짠 늑골 프레임**이 갈비뼈를 따라 흐르다 허리에서 조이며(마디마다 호박빛 수액 구슬), 옆선은 뼈 고리 세 개로 잡되 트임은 **허벅지 위쪽을 지나 골반뼈까지** 올라간다. **③흐름층** = 정수리 뼈 서클릿에서 바닥까지 떨어지는 두 폭 거미줄 베일 — 척추 양옆으로 갈라져 **등 한가운데는 열어 둔다**(밑단에 마른 잎과 씨앗). 반투명이 살아 있는 건 베일·등판·아랫자락뿐이고 **정면은 비치지 않는다** · 다리엔 잎맥 사이하이 스타킹 · **금속 0** — 색 = 연녹·상아 / 생목·뼈 / 호박빛 · 소재 = 실크의 결 × 마른 뼈·생목의 거친 무광 × 비치는 베일. |
| **노출도** | 한쪽 어깨와 팔, 목덜미부터 허리까지의 등(베일 두 폭 사이로 그대로 열린다), 옆트임으로 **허벅지 한쪽이 골반뼈까지**, 브이넥으로 깊게 파인 **가슴골**. **정면은 비치지 않는다** — 밀착한 실크가 실루엣을 노골적으로 그대로 드러낸다. |

| **얼굴 인상** | **외모 방향 = 남유럽 계열.** 꿀빛 올리브 피부에 맞는 이목구비 — 깊게 자리잡은 눈, 높고 곧은 콧대, 또렷한 눈썹선. **비비안과 모녀라 골격(깊은 눈·곧은 콧대·타원형 턱선)이 그대로 읽히되, 피부톤과 머리색으로 갈린다.** **절대 늙어 보이면 안 된다** — 균형 잡힌 이목구비 비율, 갸름한 타원형 턱선과 정돈된 턱끝, 도톰하고 형태 좋은 입술. 이 얼굴로 가장 천한 말을 태연히 뱉는 게 이 인물의 맛이다. |
| **몸매** | 캐스트 중 가장 무르익은 곡선. **가슴은 풍만하되 높게 받쳐져 있고**, 허리는 코르셋으로 조여 잘록하며, 힙은 부드럽게 둥글다. 벨벳으로 흐르는 성숙한 곡선 — **처지거나 두꺼워 보이지 않는다.** 강조점 = 깊게 파인 가슴골, 허리에서 엉덩이로 떨어지는 곡선. |
| **실루엣 시그니처** | **양 팔꿈치에서 바닥까지 떨어지는 흑레이스 슬리브 패널 두 폭.** 팔을 조금만 들면 그림자가 날개가 된다 — 캐스트에서 실루엣이 팔에 걸린 인물은 이 하나뿐. |
| **의상** | 상복을 사교복으로 바꿔 입은 여자. **①안층** = 흑레이스가 데콜테 개구부를 덮고 그대로 양팔로 내려가 팔꿈치 위 긴 장갑으로 이어진다(레이스로 덮는 구조 유지). **②구조층** = 보닝 넣은 짙은 자수정 벨벳 보디스 — **넓은 오프숄더 넥라인이 쇄골과 데콜테를 액자처럼 잡고** V는 **가슴골까지 내려오며**, V는 **가슴골 깊게 갈라지며**, 허리는 흑금 세공 벨트가 조이고 벨벳 표면엔 흑금 덩굴 자수가 허리에서 힙으로 흐른다. 스커트는 가슴·허리·힙을 차례로 뜨고 무릎에 가서야 퍼지는 머메이드에 뒤트임 — 벨벳이 눌러붙어 곡선이 한 뼘도 죽지 않는다. **③흐름층** = 양 팔꿈치에서 바닥까지 떨어져 뒤로 끌리는 흑레이스 패널 두 폭(팔 바깥으로 떨어져 등을 스치지 않는다). 석류빛 보석은 전부 벨트와 장갑 끝단에만 두고 **넥라인 가장자리는 레이스만 남겨 비운다** — 색 = 자수정 보라 / 흑금 / 석류빛 · 소재 = 빛을 먹는 벨벳 × 짜임이 보이는 흑레이스 × 세공 흑금 × 보석. |
| **노출도** | 어깨와 쇄골 전면, **데콜테**(가슴 윗면과 가슴골)를 깊게. 등은 **허리선까지**(레이스 패널은 팔 바깥으로 떨어져 등을 가리지 않는다), 다리는 뒤트임으로 걸을 때만 무릎 위까지. 팔은 레이스와 장갑으로 완전히 덮는다 — **가릴수록 세지되, 가린 천은 전부 몸에 붙는다.** |
| **장비/소품** | ①흑단 부채 — 말할 때 코앞을 가리고, 사람을 가리킬 때 쓴다(캐논 사용처 그대로). ②전대 마탑주의 인장 반지를 검은 리본에 꿰어 목에 건 초커 — 그녀의 권력 출처가 목에 걸려 있는 셈. |
| **분위기** | 그녀가 들어오면 화면이 끈적해진다. 향이 먼저 들어오고, 남자들의 시선이 딸에게서 어머니 쪽으로 반 걸음 옮겨 간다. |
