## 0. 실사판과 갈리는 지점 (전 인물 공통)

| | 3D 애니메이션판 기준 |
|---|---|
| **캔버스** | **가로 16:9 또는 4:3 · 최대 해상도.** 전신 정면/후면·사측면·얼굴 클로즈·부분 타이트를 가로로 벌려 인물을 크게 앉힌다. 얼굴 클로즈를 먼저 확정하고 그 얼굴을 물고 나머지를 파생한다. |
| **조형** | 실사 골격을 따르지 않는다. 눈은 더 크고 사이가 넓게, 콧대는 가늘고 높게, 코끝·턱끝은 더 작게, 목은 더 길게 — **현실에 없는 비율로 예쁜 얼굴**이 목표. 단 인체 비율은 8~8.5등신 실사 범위 안에 두어 SD·데포르메로 넘어가지 않는다. |
| **나이** | **전원 나이 판정 불가.** 실사판의 숫자(35·33·30·51)는 인물의 무게·지위·관계에만 남고 얼굴에서는 지운다 — 모르가나조차 주름·처짐이 아니라 **눈매의 여유와 몸의 곡선**으로만 성숙이 읽힌다. 캐논 나이는 대사·서사에서만 유효. |
| **피부** | 모공·솜털·톤 편차를 재현하지 않는다. **빛이 살을 통과하는 반투명 셰이딩(subsurface) + 정돈된 하이라이트** — 단 플라스틱 광택·인형 질감 금지, 살의 두께가 느껴져야 한다. |
| **화려도** | 실사에서 못 견디던 것을 전부 푼다 — 세공 밀도, 부유물, 발광 각인, 물리 시뮬 천·머리카락, 다층 구조물. **인물마다 상시 켜져 있는 이펙트 레이어 1개**를 가진다(정지 컷에서도 화면이 죽지 않게). |
| **실루엣** | 실사보다 한 단계 과장. 견갑·베일·뿔·트레인 전부 크기를 키우고, **상반신만 잘라도 인물이 판별되게** 어깨~머리 사이에 구조를 둔다. |
| **에이든만 예외** | 위 화려도가 유일하게 적용되지 않는 인물. 전원이 발광하고 부유하는 화면에서 **혼자만 이펙트 0·장식 0**인 게 이 인물의 연출이다. **단 이건 위장 룩(§1-A)의 규칙이고, 진짜 룩(§1-B)에서도 화려해지지는 않는다 — 켜지는 건 반지 낀 손 하나뿐, 전신 발광은 끝까지 금지.** |

## 1. 에이든 (Aiden) · 주인공 · 9서클 대마법사

> **2룩 인물.** §1-A 위장 룩(무료 1~9화) · §1-B 진짜 룩(페이월 직후 전환). 전환 트리거 = **용심의 인장을 손가락에 낀다.** 두 룩은 같은 무채색 세로 직사각이고 갈리는 건 마감뿐. 캐논 = `_p0_source.md` §2.

### 1-A. 위장 룩 — 마탑 지하 서고의 사서 (무료 1~9화)

| 항목 | 내용 |
|---|---|
| **헤어** | 짙은 재빛 갈색. 귀를 덮고 목덜미에 닿는 미디엄을 손으로 뒤로 넘겨 **이마와 눈썹이 완전히 드러난다.** 앞머리 몇 가닥만 관자놀이로 흘러내린다. 결이 굵고 광택은 낮다 — 이 캐스트에서 유일하게 머리카락이 빛을 안 먹는 인물. **떡진 머리·눈 가리는 앞머리 금지 — 허름함은 옷이 맡는다.** |
| **피부·셰이딩** | 햇빛 안 든 밝은 톤. 반투명 셰이딩은 얇게만 — 여왕들처럼 안에서 빛나지 않는다. 손가락 마디와 손톱 밑 잉크 얼룩 상시. |
| **눈** | 짙은 철회색. 크고 살짝 깊게 자리 잡았는데 **늘 반쯤 내리깔고 있어 감정이 안 새어 나온다** — 시선 자체는 죽지 않았다. 힘을 감추지 않는 컷에서만 홍채 테두리에 얇은 금빛 링이 돌고, 그 순간 동공 안쪽에 아주 작은 마법진이 한 바퀴 회전한다. |
| **얼굴 조형** | 조형 방향 = 유럽계. 눈썹뼈가 또렷하고 콧대가 가늘고 높으며 코끝이 작다. 턱선은 얇고 깨끗한 타원 — **각진 데가 없다.** 먼지와 반쯤 감은 눈으로 덮어둔 최상급 미남이고, 컷에서 눈을 뜨는 순간 얼굴이 바뀐 것처럼 보여야 한다. 나이 표식(팔자·이마 주름·수염) 전부 없음. |
| **몸매** | 8.5등신. 헐렁한 로브가 완전히 감춘 넓은 어깨·긴 팔·좁은 허리. 밖으로 나오는 건 팔뚝과 목뿐인데 그 두 군데로 체급이 새어 나온다. 웅크린 자세가 기본값이라 항상 실제보다 작아 보인다. |
| **실루엣 시그니처** | **없음 — 그게 시그니처다.** 어깨에도 머리에도 허리에도 구조물이 하나도 없는 세로 직사각. 전원이 부채꼴·아치·견갑을 달고 선 화면에서 혼자만 매끈한 기둥. |
| **의상** | 겹은 셋인데 전부 같은 계열이라 화려해지지 않는다 — 성글게 짠 마 셔츠 위에 두꺼운 사서 튜닉, 그 위에 무릎까지 오는 앞트임 로브, 허리는 가죽끈 하나. **밀도는 장식이 아니라 마감에서 나온다** — 풀린 소맷단 실밥, 해진 밑단, 무릎에 덧댄 색 다른 헝겊, 여러 번 물 먹어 이음선마다 갈린 색, 성긴 마의 짜임. 소매는 팔꿈치까지 걷었다. 색 = 먼지 회색·바랜 갈색, **전 캐스트 중 유일하게 채도가 0.** 금속·자수·버클·보석 전부 0. |
| **노출도** | 사실상 0. 걷어 올린 소매 아래 팔뚝, 풀린 앞섶 사이 목선과 쇄골. 여왕들의 노출과 한 프레임에 붙었을 때 이 대비가 그림이다. |
| **장비/소품** | **가죽끈 하나에 둘이 같이 꿰여 목에 걸린다.** ①**최하위 등급 인장패** — 무광 납회색 원반에 오각별이 새겨진 것, 보석 0(가슴 앞으로 나와 있는 건 이쪽이다). ②**용심의 인장** — 겉보기엔 낡은 은반지, 용이 감긴 세공. 셔츠 안쪽에 넣거나 주먹에 쥔 상태가 기본이고 손가락에 끼는 건 지정 컷에서만(끼는 순간 죽은 각인이 안쪽부터 금빛으로 차오른다). **화면에서 완전히 사라지면 안 된다** — 3화에서 짓밟히고 B룩에서 끼는 물건이다. |
| **이펙트 레이어** | **평시 0.** 대신 힘을 쓰는 컷에서 한 번에 최대치로 간다 — 발밑에서 위로 솟는 다중 동심원 마법진, 로브 안감에 숨어 있던 금빛 룬 격자가 옷 전체로 번지고, 공기 중 마나가 흰 재처럼 위로 흐른다. **평시와 각성의 낙차 자체가 이 인물의 이펙트다.** |
| **분위기** | 그가 들어오면 화면이 조용해진다. 주변이 화려할수록 그 자리만 채도가 빠지고, 결국 눈이 무채색 쪽으로 돌아온다. |

### 1-B. 진짜 룩 — 9서클 대마법사 (페이월 직후~)

| 항목 | 내용 |
|---|---|
| **얼굴·헤어** | **모델 동일.** 조형도 헤어도 새로 뜨지 않는다 — A와 **같은 짙은 다크 브라운 흐트러진 미디엄 웨이브**, 이마 위 몇 가닥도 그대로 둔다(**빗어 넘겨 정돈하면 다른 사람이 된다 — 금지**). 바뀌는 건 둘뿐: **①반쯤 내리깔던 윗꺼풀이 완전히 열려 정면을 본다** ②**홍채 테두리 금빛 링 + 동공 안쪽의 작은 마법진 회전이 상시**(A에서는 각성 컷 전용). 머리카락은 A에서 빛을 안 먹었는데 B에서는 **가장자리만 얇게 받는다** — 광량이 아니라 재질이 바뀐 것처럼. |
| **피부·셰이딩** | 동일. **손의 잉크 얼룩만 없다** — 손 클로즈업의 전환 신호. |
| **자세** | **웅크림 해제.** 어깨가 완전히 펴지고 턱이 수평. A가 8.5등신을 접어서 작아 보였다면 B는 등신이 그대로 나온다 — 같은 모델인데 프레임에서 커진다. 걸을 때 상체 흔들림 0(여왕들의 천·머리카락은 물리 시뮬로 흔들리는데 이 남자만 안 흔들린다). |
| **실루엣 시그니처** | **어깨 뒤로 크게 세워 올린 각진 하이칼라 + 밑단이 뾰족하게 갈라지는 발목 길이 코트.** A의 "시그니처 없음"을 뒤집는 자리다. 여왕 셋의 구조물이 전부 좌우로 벌어지는 반면 이 남자만 **위로 선 직선** — 상반신만 잘라도 넷이 안 겹친다. |
| **의상** | 흑단 3층 롱코트. ①**안층** = 몸에 붙는 흑 이너·흑 슬랙스·흑 부츠 ②**여밈층** = 비늘 세공 라펠이 가슴 앞에서 사선으로 겹쳐지되 **가슴 가운데는 열어 둔다**(목까지 채우면 성직자가 된다) ③**흐름층** = 발목까지 떨어지며 밑단이 뾰족하게 갈라지는 코트(물리 시뮬 최소 — 거의 안 날린다). **옷깃·소매·앞판·등판을 따라 마법식이 금실로 짜여 있고, 카메라나 광원이 움직일 때만 룬 격자가 옷 전체에 드러난다.** 색 = 칠흑·먹빛 + **금 각인** — 금은 장식이 아니라 **글씨로만** 들어간다. 보석 0·부유 세공물 0. |
| **노출도** | 가슴 가운데의 좁은 V와 목, 손. 그 외 전부 덮는다. |
| **장비/소품** | ①**손가락에 낀 용심의 인장** — 은빛 용 세공 반지, 낀 상태가 기본값, 각인이 안쪽부터 금빛으로 차오른 상태 고정, 뭉갠 구두 굽 자국은 지우지 않는다. ②**그 외 아무것도 안 든다 — 지팡이 0.** 검·지팡이·뿔을 가진 여왕 셋 사이에서 맨손인 게 격이다. ③납회색 배지 없음. |
| **이펙트 레이어** | **빛은 전부 몸 바깥에 둔다.** 발밑에 금빛 다중 동심원 마법진이 깔리고 주위에 책장·낱장이 정지한 채 떠 있으며, 반지 낀 손 주위에만 룬 고리가 느리게 돈다. **몸 자체는 발광하지 않는다 — 전신 발광·가슴 발광·아우라 금지.** 전신을 켜는 순간 여왕들과 같은 급으로 내려간다. |
| **분위기** | A가 "화려한 것들 사이에서 채도가 빠진 자리"였다면, B는 **화면이 그를 중심으로 정렬된다.** 들어서는 순간 다른 인물들의 시선이 전부 한 점으로 모이고, 그는 아무도 안 본다. |
| **전환 연출** | 반지를 끼는 한 동작 → 사서 로브의 해진 밑단부터 먹빛으로 잠기며 위로 올라오고 마지막에 칼라가 목 뒤로 선다. **원작 10화 슈트 전개와 같은 문법**(리모컨 → 전신 전개 → 폐쇄). 되돌아갈 때는 반지를 뺀다. |

## 2. 카타리나 (Katarina) · 제국 여제 · 검신 — **차가운 쪽**

| 항목 | 내용 |
|---|---|
| **헤어** | 차가운 백금 애시. 허리까지 오는 직모를 정수리 높이에서 묶은 하이 포니테일 — **바짝 당겨 붙이지 않는다.** 정수리 볼륨이 살고 헤어라인에 잔머리가 남는다. **얼굴 양옆으로 긴 두 갈래가 귀 앞으로 흘러 턱선 아래까지 내려온다**(이 두 갈래가 그녀의 인상을 여전사에서 미인으로 옮긴다). 모발 끝은 칼로 자른 듯 일직선이고, 빛을 받으면 백금에서 옅은 청빛으로 넘어가는 그라데이션이 돈다. 포니테일은 물리 시뮬 — 검을 휘두른 뒤 반 박자 늦게 따라온다. |
| **피부·셰이딩** | 햇살에 살짝 익은 옅은 골든 휘트 탠. 반투명 셰이딩이 손끝·귀·목선에서 붉게 비친다. 흉터 없음. |
| **눈** | 옅은 강철 회색. 크고 살짝 깊게 자리 잡았으며 속눈썹이 길고 짙다. **홍채 테두리만 진하고 안쪽은 얼음처럼 밝아** 시선이 서늘하게 서되 비어 있지 않다. 검기를 끌어올리는 컷에서만 홍채에 서리 결정 패턴이 잠깐 돈다. |
| **얼굴 조형** | 조형 방향 = 북방계. 백금 애시에 어울리는 밝은 피부와 서늘한 언더톤. **각진 데가 한 군데도 없다** — 콧대는 가늘고 높게 뻗되 코끝이 작고, 턱선은 갸름한 타원으로 떨어지며 턱끝이 단정하고, 눈썹선이 또렷하고, 입술은 도톰하고 형태가 좋다. 나이 판정 불가 — 어리지도 성숙하지도 않은, 대륙 최강자로 굳어버린 얼굴. |
| **몸매** | 어깨선이 캐스트에서 가장 곧고 군더더기가 없다. **잔살 하나 없이 조여진 모래시계**(부풀린 근육 아님) — 곧게 뻗은 어깨에서 극단적으로 잘록한 허리로 떨어지는 V, 그 아래 탄탄한 엉덩이와 길고 매끈한 다리. 배는 평평하고 **탄탄한 복근이 또렷하게 잡힌다.** 가슴은 높고 탄탄한 중간~풍만. 강조점 = 어깨→허리 낙차, 얇은 허리, 긴 다리. |
| **실루엣 시그니처** | **어깨에서 뒤로 뻗은 다중 칼날 견갑.** 실사판의 한 쌍을 3~4매 겹판으로 키워, 뒤로 갈수록 길어지며 낮게 뻗는다. 역광에 그림자만 떠도 어깨가 뒤로 벌어진 화살촉으로 읽힌다. |
| **의상** | 백금·흑은 하프플레이트 3층. **①안층** = 심연 청흑 가죽 언더수트가 골반에서 발목까지 살갗처럼 붙되, **한쪽 옆선이 허벅지 위쪽까지 시원하게 트인 하이컷**으로 갈라져 다리 라인이 그대로 드러난다(허벅지 중간부터 각반). **②구조층** = 몸을 그대로 뜬 백금 흉갑이 쇄골 아래 얕은 넥라인에서 시작해 **갈비뼈 아래에서 깨끗하게 끊기고**(두께 없는 금속판이지 뭉툭한 판금이 아니다), 표면 전면에 정복지 문장이 금 상감으로 얕게 새겨져 각도에 따라 떠오른다. 하복부에서 골반으로는 낮게 걸친 짧은 백금 포드런이 받고, 어깨 바깥에 **다중 칼날 견갑**이 얹혀 뒤로 뻗으며(어깨 윗면·팔은 맨살, 판 사이를 잇는 건 가는 은사슬), 금세공 벨트가 버클 셋과 리벳 열로 골반을 두 바퀴 낮게 조인다. **③흐름층** = 진홍 벨벳 망토 — 실사판보다 길고 무겁게, 안감 청흑에 **제국 문장이 은사로 통짜 자수**되고 가장자리에 금사 테. 물리 시뮬로 항상 조금씩 움직인다. 열림은 **갈비뼈 아래 맨 복부 + 견갑골 사이 등 열림 + 하이컷** 셋이고 **목과 쇄골 위는 비운다** — 색 = 진홍 / 백금·은강철 / 청흑. |
| **노출도** | 어깨·팔·목·쇄골, **갈비뼈 아래부터 골반 벨트 위까지 맨 복부 — 배꼽 위아래로 복근이 그대로 드러난다**, 망토를 걷으면 견갑골 사이 등 열림, 한쪽 옆선은 **허벅지 위쪽까지 트인 하이컷**으로 다리가 통째로 드러난다. |
| **장비/소품** | **검 1자루뿐.** 제 키만 한 대검 — 백금 도신이 거울처럼 주변을 되비추고, 중앙 홈을 따라 룬이 옅은 푸른빛으로 흐른다. 힐트는 정교한 금세공에 보석이 줄지어 박혔고, 가드는 **날개(혹은 왕관) 형태로 좌우로 크게 벌어지며** 끝단에 작은 보석이 물려 있다. 등에 메지 않고 손에 들거나 돌바닥에 꽂아 세워 둔다. 왕관·목걸이·귀걸이 전부 없음 — 제국 여제인데 몸에 붙은 값나가는 건 이 검 하나다. |
| **이펙트 레이어** | **발밑 반경 1미터의 서리.** 서 있기만 해도 돌바닥에 서리 결정이 천천히 번지고, 검을 뽑으면 도신을 따라 흰 검기가 아지랑이처럼 오르며, 벤 자리에는 공간이 늦게 닫히는 것처럼 얇은 흰 선이 잠깐 남는다. |
| **분위기** | 그녀가 들어오면 프레임의 온도가 내려간다. 소리가 한 겹 빠지고, 사람들이 뒤로 반 걸음 물러선 자리만 남는다. |

## 3. 탈리아 (Thalia) · 엘프 여왕 — **신비로운 쪽**

| 항목 | 내용 |
|---|---|
| **헤어** | 창백한 연둣빛이 도는 금발. **바닥에 닿을 만큼 긴 초장발** 직모로, 가는 땋기 두 갈래가 **얼굴 양옆 앞쪽으로** 흐르고 나머지는 전부 풀었다. **끝 10센티가 실체를 잃고 빛 입자로 흩어졌다 다시 모인다.** 물리 시뮬로 몸보다 반 박자 늦게 따라오고, 걸음이 멈춘 뒤에도 한참 더 흐른다. |
| **피부·셰이딩** | 달빛 백자 — 캐스트 중 가장 밝고 초록 언더톤이 아주 옅게 깔렸다. **반투명 셰이딩 최대치** — 역광에서 귀 끝·손가락·목선으로 빛이 실제로 통과한다. **피부 아래 잎맥 문양은 넣지 않는다**(실물 확정 — 종족감은 귀·머리색·관이 전부 만든다). |
| **눈** | 맑은 옥빛 초록에 금빛 홍채 테. **크고 표정이 실리는 눈, 눈 사이가 넓고 속눈썹이 길고 짙다.** 홍채 안쪽에 잎맥을 닮은 갈래 무늬가 아주 미세하게 깔려 있다. 시선은 늘 조금 먼 데 걸려 있되 비어 있지 않다 — 사람을 벌레 보듯 내려다보는데 화도 없이 그런다. |
| **얼굴 조형** | 사람 아닌 것처럼 예쁜 얼굴. 인간이 아니므로 지역 무관 — **연둣빛 금발·길고 뾰족한 귀·창백한 피부**가 종족감을 전부 만든다. 눈이 크고 사이가 넓으며, 콧대는 가늘고 높고 코끝이 작으며, 턱선은 갸름한 타원, 입술은 도톰하고 형태가 좋다. **나이 판정 완전 불가** — 소녀로도 보이고 천 년으로도 보이는 얼굴이 목표. |
| **몸매** | 캐스트 최장신이자 가장 가늘다. 목·팔·다리가 길고 어깨는 좁고 골반은 작다 — **뼈만 남은 게 아니라 매끈하게 길다.** 가슴은 크지 않지만 높고 형태가 또렷해 얇은 실크 위로 윤곽이 그대로 잡힌다. 강조점 = 끝없이 긴 다리와 등에서 허리로 떨어지는 척추 라인. |
| **실루엣 시그니처** | **머리를 감싸는 금빛 나뭇가지 관 + 몸을 타고 감기는 같은 세공의 가지 넝쿨.** 이마 위로 잔가지와 잎이 얹히고 미간으로 물방울 장식 하나가 떨어지며, 같은 어휘의 금빛 가지가 어깨에서 가슴·허리를 지나 골반으로 감겨 내려간다 — 옷이 아니라 **나무가 몸에 자라 붙은 것**으로 읽혀야 한다. 그 아래로는 초장발과 시폰 자락이 구분 없이 바닥으로 흘러 세로 한 기둥이 된다. |
| **의상** | 얇은 두 겹뿐이라 두께가 안 생긴다. **①안층** = 상아빛 실크 **원숄더** 시스가 젖은 듯 붙는다 — 한쪽 어깨와 팔은 완전히 드러내고, 옆선은 **허벅지 위쪽을 지나 골반뼈까지** 갈라져 다리 한쪽이 통째로 나온다. 등은 **어깨뼈부터 허리까지 전부 열려** 있고 가는 금빛 가지 세공만 척추 위로 엇갈려 지난다. **②흐름층** = 옅은 민트·은빛 시폰이 골반에서 바닥으로 퍼져 뒤로 길게 깔린다 — 반투명에 무지개빛 굴절이 얹히고, 자락 끝에서 마른 잎과 씨앗이 떨어지다 바닥에 닿기 전에 빛으로 흩어진다. 몸을 타고 오르는 **금빛 나뭇가지 세공**이 유일한 구조물이고 표면의 잎맥 각인이 숨 쉬듯 밝아졌다 어두워진다 — **뼈·늑골 프레임·호박빛 구슬은 넣지 않는다.** **정면은 비치지 않는다** · **맨발** · 색 = 상아·은백 / 금빛 가지 / 옅은 민트. |
| **노출도** | 한쪽 어깨와 팔 전체, **어깨뼈부터 허리까지 완전히 열린 등**, 옆트임으로 **허벅지 한쪽이 골반뼈까지**, 맨발. 정면은 비치지 않되 밀착한 실크가 실루엣을 노골적으로 그린다. |
| **장비/소품** | **①지팡이 1개** — 백금빛 생목이 나선으로 꼬여 올라가는 **제 키보다 큰** 지팡이. 끝에서 가지가 손끝처럼 갈라져 초록 수정을 감싸 안고, **수정 안에서는 작은 숲의 사계가 아주 느리게 돈다.** 자루를 따라 잔가지와 잎이 살아 붙어 있고 룬이 숨 쉬듯 밝아졌다 어두워진다. **②금빛 나뭇가지 관** — 이마 위로 잎과 잔가지가 얹히고 미간에 물방울 장식 하나가 떨어진다. **③잎 모양 귀걸이** — 긴 뾰족귀를 따라 늘어진다. 그 외 장신구 0. |
| **이펙트 레이어** | **그녀를 중심으로 한 공전.** 잎·씨앗·빛 입자가 항상 몸 주위를 천천히 돌고, 발이 닿은 돌바닥에서는 이끼와 작은 꽃이 피었다가 그녀가 지나가면 도로 마른다. |
| **분위기** | 그녀가 서 있으면 화면이 반 박자 느려진다. 바람도 빛도 그녀 쪽으로만 흐르고, 같은 프레임의 인간들이 자동으로 배경이 된다. |

## 4. 프레이야 (Freya) · 드래곤 퀸 — **야성적인 쪽**

| 항목 | 내용 |
|---|---|
| **헤어** | 녹은 구리·주홍. 뿌리는 검붉고 끝으로 갈수록 불붙은 것처럼 밝아지다 **끝 부분은 실제로 잉걸처럼 발광한다.** 등 중간까지 오는 굵은 웨이브를 손으로 헤집어 놓은 상태 — 정수리 볼륨이 뒤로 눌리고 잔머리가 사방으로 뻗는다. 움직일 때 머리카락 사이로 불티가 몇 점 떨어져 나갔다 꺼진다. |
| **피부·셰이딩** | **햇살을 머금은 골든 탠.** 캐스트 중 가장 진한 톤이되 **딥 브론즈까지 내리지 않는다**(어두워서 이목구비가 뭉개지면 안 된다). 오일 광택 금지 — 반투명 셰이딩 안쪽이 은은하게 붉게 달아 있는 느낌. 목덜미·척추 라인·팔 바깥면을 따라 피부와 같은 톤의 미세 비늘이 깔려, **빛 각도가 바뀔 때만 무지개빛으로 떠오른다.** |
| **눈** | 녹은 금빛. **크고 살짝 올라간 눈매, 눈 사이가 넓고 속눈썹이 길고 짙다.** 홍채 안쪽에서 열이 도는 것처럼 밝기가 미세하게 출렁인다. 인상 = 배고픈 눈 — 사람을 볼 때 얼굴이 아니라 목을 본다. **동공은 둥근 것이 기본값**, 세로 동공은 눈만 잡는 인서트 컷에서만(얼굴 전체 컷에서 쓰면 미모가 즉시 무너진다). |
| **얼굴 조형** | 야성적인데 **험상궂은 게 아니라 압도적으로 예쁜** 얼굴. 인간이 아니므로 지역 무관 — 구릿빛 탠 + 구리 적발의 조합 자체가 방향이다. 눈이 크고 사이가 넓으며, 콧대는 가늘고 높게 뻗고 눈썹선이 강하고, 도톰한 입술이 늘 반쯤 벌어져 있다. 예의를 배운 적 없는 얼굴. 나이 판정 불가. |
| **몸매** | **가는 허리에 볼륨이 얹힌 글래머.** 허리는 극단적으로 잘록하고 다리는 길고 탄탄하게 매끈하며, 가슴은 풍만하되 처지지 않고 높고, 힙은 탄력 있게 둥글다. **두껍거나 육중하지 않다** — 굴곡은 최대, 부피는 최소. 강조점 = 가슴, 허리→힙 낙차, 아무것도 안 걸친 등 전체. |
| **실루엣 시그니처** | **관자놀이 뒤에서 솟아 뒤로 뻗은 흑요석 뿔 한 쌍.** 머리 양옆을 따라 낮게 흐르다 끝이 살짝 올라간다 — 길이는 머리 폭 정도, 표면은 흑요석처럼 광택이 돌고 뿌리에 용금 세공 링이 물렸으며 끝으로 갈수록 안쪽에서 잉걸빛이 비친다. **목과 어깨에는 아무것도 없다** — 목덜미부터 허리 아래까지 통째로 열려 있고 실루엣은 전부 머리 위에서 만든다. 왕관을 안 쓰는 유일한 여왕인데 왕관보다 명확하다. |
| **의상** | 코스튬이 아니라 세공품. **①안층** = 흑요석 용비늘을 한 장씩 세공해 앉힌 보디피스가 가슴부터 골반까지 앞면을 덮되, **양 옆구리와 허리 라인은 앞판과 골반판 사이로 맨살이 그대로 드러난다**(그 사이를 잇는 건 머리카락처럼 가는 금선 몇 줄뿐). 넥라인은 **가슴 사이로 깊게 갈라져 가슴골이 짙게 드러나고**, 비늘 한 장 한 장이 각도에 따라 검정에서 남보라·적동으로 넘어가며, 이음매마다 용금 세공 테두리가 물린다. **②구조층** = **목과 어깨에는 구조물이 하나도 없다.** 골반을 두 바퀴 감아 비늘 판을 당겨 조이는 **용금 사슬 벨트**(마디마다 작은 홍옥)와, 쇄골에서 어깨 뒤로 넘어가 등 한가운데서 만나는 가는 용금 사슬 두 줄뿐 — 당겨진 사슬이 살을 얕게 눌러 어깨선을 그린다. **③흐름층** = 허리에서 발목까지 떨어지는 잉걸 주홍 실크 자락 한 겹, 한쪽만 갈라져 다리 라인을 낸다 — 밑단이 실체를 잃고 **연기처럼 흩어지며 불티를 흘린다.** **등판은 없다** — 목덜미부터 허리 아래까지 통째로 열려 있고 가는 금선 두 줄만 가로지른다. 맨발·발목 금고리 · **목은 앞뒤로 전부 비운다** — 색 = 흑요석 검정 / 용금 / 잉걸 주홍. |
| **노출도** | **등 전면 + 어깨·팔 + 양 옆구리와 허리 라인 + 옆트임으로 다리 한쪽.** 가슴골은 넥라인 사이로 깊게 드러나고, 복부 앞면은 비늘이 덮는다. |
| **장비/소품** | **없음.** 무기도 지팡이도 방패도 왕관도 없다 — 맨손·맨발·맨몸. 몸에 붙은 금속은 전부 의상의 일부다. **뿔은 장비가 아니라 몸이다.** |
| **이펙트 레이어** | **상시 상승 열기.** 몸 주위 공기가 아지랑이로 일렁이고, 등 뒤로 열 왜곡이 얇게 서며, 숨을 뱉을 때마다 잉걸 몇 점이 위로 흐른다. 발을 딛는 돌바닥에는 잠깐 붉게 달았다 식는 자국이 남는다. |
| **분위기** | 그녀가 들어오면 공기가 무거워진다. 사람들이 이유도 모른 채 무기를 내려놓고, 프레임 안의 불빛이 전부 한 번 흔들린다. |

## 5. 비비안 (Vivian) · 주인공의 아내 · 오늘 마탑주 취임 — **화려한 쪽**

| 항목 | 내용 |
|---|---|
| **헤어** | 칠흑. **유리처럼 매끈한 광택의 비대칭 숏 밥** — 한쪽은 턱선에서 날카롭게 떨어지고 반대쪽은 짧게 치고 올라가며, 앞머리가 이마를 사선으로 가른다. **잔머리 한 올 없다** — 사람 손이 몇 시간 들어간 머리라는 게 보여야 한다. 광택 하이라이트가 머리 위에서 띠로 흐른다. **여왕 셋이 전부 장발이라 캐스트 유일의 숏컷이고, 그게 이 여자의 판별점이다.** |
| **피부·셰이딩** | 크림 아이보리. 캐스트에서 가장 정돈된 표면 — 반투명 셰이딩은 얇게, 하이라이트는 또렷하게. 쇄골과 가슴 윗면에 금가루가 뿌려져 각도에 따라 반짝인다. |
| **눈** | 차가운 보랏빛 청색. **눈이 크고 눈썹뼈 아래로 깊게 자리 잡았으며 속눈썹이 길고 짙다.** 아이라인을 날카롭게 빼 올렸고, 아이섀도에 은박이 얹혔다. 인상 = 사람을 값으로 훑는 눈. |
| **얼굴 조형** | 조형 방향 = 유럽계 — **깊게 자리 잡은 눈 · 눈썹에서 곧게 떨어지는 높은 콧대 · 또렷한 눈썹뼈**로 골격을 못 박는다(동양계로 흐르지 않게 이 셋 고정). 돈을 쏟아부어 만든 최상급 미인 — 갸름한 타원형 턱선과 작은 턱끝, 도톰하고 형태 좋은 입술. 다 예쁜데 표정이 항상 반 톤 오만해서, 예쁘다고 인정하는 순간 기분이 나빠지는 얼굴. 나이 판정 불가. |
| **몸매** | 가는 축의 글래머. 어깨가 좁고 허리가 얇고 다리가 곧다. 가슴은 코르셋으로 높고 둥글게 모아 올린 형태, 엉덩이는 작고 탄탄. 강조점 = 목·쇄골·가슴 윗선, 높은 굽 위에서 더 길어 보이는 종아리. 힘이 아니라 관리로 만들어진 몸. |
| **실루엣 시그니처** | **머리 뒤에 기울어진 채 떠 있는 보랏빛 룬 고리 두 겹 + 한쪽 어깨에서만 솟은 은빛 결정 스파이크 견갑.** 관을 쓰지 않는다 — 마탑주의 표식은 머리에 얹는 물건이 아니라 **뒤통수 뒤에서 저 혼자 도는 고리**다. 두 겹이 서로 다른 각도로 기울어 각각 다른 속도로 돌고, 표면에 룬이 순서대로 점등한다. 그림자로는 머리 뒤의 기운 원 두 개와 한쪽으로만 솟은 뾰족한 어깨. |
| **의상** | **①취임식 상태** — 진주 백색 + 칠흑 대비의 마탑주 예복. **안층** = 진주 백색 새틴 시스가 몸을 그대로 떠서 골반·허벅지까지 붙고, **한쪽 면만 칠흑 광택 패널로 갈라져** 흑백이 몸 위에서 사선으로 맞물린다. **구조층** = 목을 감는 은빛 결정 초커에서 시작해 쇄골을 지나 한쪽 어깨로 올라가 **뾰족한 결정 스파이크 견갑**으로 솟는 은세공 — 목선은 **가슴골 깊게** V로 갈라지고 그 중앙에 자수정 보라 결정이 하나 박혀 안에서 빛이 돈다. **한쪽 팔에만 팔꿈치 위까지 오는 칠흑 롱글러브**(반대쪽은 맨팔 — 이 비대칭이 헤어의 비대칭과 짝을 이룬다). **흐름층** = 힙 뒤로 은백 트레인이 길게 깔리고 안감에 **별자리 마법진이 은사로 자수되어 걸을 때마다 순서대로 점등한다.** 등은 **어깨뼈부터 허리까지 완전히 열려** 은빛 격자 세공만 척추를 따라 내려간다. 슬릿은 **허벅지 위쪽을 지나 골반뼈까지.** 색 = 진주 백색 / 칠흑 / 은 / 자수정 보라. **②4~5화 상태(캐논 §5-1)** — 검정 실크 란제리 + 가터 + 실크 로브(밑단·소맷단에만 흑사 자수). **로브를 어깨에 걸치고 허리끈을 묶은 상태**로 잡는다 — 덮되 얇은 실크가 허리와 힙에 감겨 실루엣이 그대로 읽힌다. |
| **노출도** | 예복 = 양 어깨와 쇄골, **어깨뼈부터 허리까지 완전히 열린 등**, **가슴골 깊게**, 슬릿으로 **골반뼈까지**, 글러브 없는 쪽 맨팔. 란제리 = 로브가 실루엣을 덮고 다리와 어깨 선만 열린다. |
| **장비/소품** | ①**머리 뒤 부유 룬 고리** — 보랏빛으로 점등한 두 겹이 서로 다른 각도로 기울어 각각 다른 속도로 돈다. **관 없음.** ②은빛 첨탑형 하이힐 — 반지를 짓밟는 그 굽. ③가슴 중앙과 귀의 자수정 보라 결정. **지팡이를 들지 않는다**(그 자리를 만든 마법식은 전부 남편이 썼다 — 캐논). |
| **이펙트 레이어** | **머리 뒤 룬 고리와 점등하는 별자리.** 뒤통수 뒤 고리 두 겹, 가슴 결정 안에서 도는 빛, 걸을 때 트레인에서 순서대로 켜지는 별자리 — 전부 본인이 쓴 마법이 아니라 예복에 걸린 장치라 **정지 상태에서만 곱게 돈다.** 실전에서는 하나도 반응하지 않는다(그게 이 인물의 진실). |
| **분위기** | 그녀가 들어오면 화면이 갑자기 비싸진다. 조명이 그쪽으로 몰리고, 같은 방 사람들이 자기 옷을 한 번 내려다본다. |

## 6. 모르가나 (Morgana) · 비비안의 어머니 · 전대 마탑주의 미망인 — **농익은 쪽**

| 항목 | 내용 |
|---|---|
| **헤어** | 어두운 와인빛이 도는 흑갈. 어깨에 닿는 굵은 웨이브를 한쪽으로 몰아 넘겼다. 관자놀이에서 흘러내리는 **은빛 한 줄기**를 감추지 않는다 — 늙음의 표시가 아니라 디자인 요소로 읽히게, 은빛만 유독 광택이 세다. |
| **피부·셰이딩** | 따뜻한 꿀빛 올리브. 목과 가슴 윗면에 고운 파우더 마감. **주름·처짐·검버섯 전부 0** — 성숙은 피부가 아니라 눈매의 여유와 몸의 곡선이 만든다. |
| **눈** | 진한 석류빛 갈색. **눈이 크고 살짝 깊게 자리 잡았는데 눈꺼풀이 무겁게 내려와 늘 반쯤 감긴 인상**이고 속눈썹이 길고 짙다. 인상 = 상대를 위아래로 한 번 훑고 나서 웃는 눈. |
| **얼굴 조형** | 조형 방향 = 남유럽 계열. 꿀빛 올리브에 맞는 이목구비 — 깊게 자리 잡은 눈, 가늘고 높은 콧대, 또렷한 눈썹선. **비비안과 모녀라 골격(깊은 눈·곧은 콧대·타원형 턱선)이 그대로 읽히되 피부톤과 머리색으로 갈린다.** **절대 늙어 보이면 안 된다** — 갸름한 타원형 턱선과 작은 턱끝, 도톰하고 형태 좋은 입술. 이 얼굴로 가장 천한 말을 태연히 뱉는 게 이 인물의 맛이다. 나이 판정 불가 — 딸의 언니로 보여도 상관없다. |
| **몸매** | 캐스트 중 가장 무르익은 곡선. **가슴은 풍만하되 높게 받쳐져 있고**, 허리는 코르셋으로 조여 잘록하며, 힙은 부드럽게 둥글다. 벨벳으로 흐르는 성숙한 곡선 — **처지거나 두꺼워 보이지 않는다.** 강조점 = 깊게 파인 가슴골, 허리에서 엉덩이로 떨어지는 곡선. |
| **실루엣 시그니처** | **양 팔꿈치에서 바닥까지 떨어지는 흑레이스 패널 두 폭.** 팔을 조금만 들면 그림자가 날개가 된다 — 물리 시뮬로 항상 뒤로 끌리고, 캐스트에서 실루엣이 팔에 걸린 인물은 이 하나뿐. |
| **의상** | 상복을 사교복으로 바꿔 입은 여자. **①안층** = 흑레이스가 데콜테 개구부를 덮고 그대로 양팔로 내려가 팔꿈치 위 긴 장갑으로 이어진다 — 레이스 무늬가 **덩굴 문양으로 짜여 빛을 받으면 흑금으로 반짝인다.** **②구조층** = 보닝 넣은 짙은 자수정 벨벳 보디스 — **넓은 오프숄더 넥라인이 쇄골과 데콜테를 액자처럼 잡고 V는 가슴골 깊게 갈라지며**, 허리는 흑금 세공 벨트가 조이고, 벨벳 표면의 흑금 덩굴 자수가 허리에서 힙으로 흐르되 **그녀가 화를 낼 때만 자수 끝이 아주 느리게 자란다.** 스커트는 가슴·허리·힙을 차례로 뜨고 무릎에 가서야 퍼지는 머메이드에 뒤트임 — 벨벳이 눌러붙어 곡선이 한 뼘도 죽지 않는다. **③흐름층** = 양 팔꿈치에서 바닥까지 떨어져 뒤로 끌리는 흑레이스 패널 두 폭(팔 바깥으로 떨어져 등을 스치지 않는다). 석류빛 보석은 벨트와 장갑 끝단에만 두고 **넥라인 가장자리는 레이스만 남겨 비운다** — 색 = 자수정 보라 / 흑금 / 석류빛. |
| **노출도** | 어깨와 쇄골 전면, **데콜테**(가슴 윗면과 가슴골)를 깊게. 등은 **허리선까지**(레이스 패널은 팔 바깥으로 떨어져 등을 가리지 않는다), 다리는 뒤트임으로 걸을 때만 무릎 위까지. 팔은 레이스와 장갑으로 완전히 덮는다 — **가릴수록 세지되, 가린 천은 전부 몸에 붙는다.** |
| **장비/소품** | ①**흑단 부채** — 흑금 세공 살에 석류빛 보석이 물렸고, 펼치면 부챗면에 전대 마탑의 문장이 떠오른다. 말할 때 코앞을 가리고, 사람을 가리킬 때 쓴다. ②전대 마탑주의 인장 반지를 검은 리본에 꿰어 목에 건 초커 — 그녀의 권력 출처가 목에 걸려 있는 셈. |
| **이펙트 레이어** | **가라앉는 향연.** 몸 주위로 짙은 보랏빛 연무가 아주 얕게 깔려 발치로 흘러내리고, 부채를 접었다 펼 때마다 그 연무가 한 번 갈라진다. |
| **분위기** | 그녀가 들어오면 화면이 끈적해진다. 향이 먼저 들어오고, 남자들의 시선이 딸에게서 어머니 쪽으로 반 걸음 옮겨 간다. |
