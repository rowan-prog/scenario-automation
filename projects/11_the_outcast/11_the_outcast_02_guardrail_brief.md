# THE OUTCAST — 검수 가드레일 브리프 (agent 동봉용)

> 이 브리프는 **의도된 설계를 결함으로 오보하지 말라**는 가드레일이다. 대본 = `11_the_outcast_source_CN.md` (중국어). 라인번호는 이 파일 기준.

## 1. 무엇인가
- **남성향 사이다 파워판타지** (hidden-OP). AIGC 숏폼 vertical (9:16·AI 영상·AI 음성).
- **타깃 = 북미(NA)·영어 최종본.** 원어 = 중국어 집필. → **NA-calibration**: 원문 강도는 하한선. 동양권-소프트 비트는 기능 등가로 상향 판단하라. "과하다/저속하다"로 깎지 마라(막장 직설 = 자산).

## 2. 지금 검수 범위 (중요 — 착오 방지)
- **돌린다(언어중립):** 엔진/구조/훅/락인/퍼널, 연속성·ledger·논리·타임라인, △ drawability, 대사 **기능/레지스터**(각 비트가 남성향 쾌감을 나르나 — 문장 다듬기가 아니라 기능), CN→NA 각색 리스크.
- **유보(영어 초안 나온 뒤):** 영어 spoken 라인 정밀검수(번역투·문학톤·0.1초). **지금은 영어 라인이 없으므로 영어 워딩 지적 금지.** 중국어 원문의 "문장이 어색하다" 식 지적도 하지 마라 — 어차피 영어로 재집필됨. 지적은 **비트/구조/기능** 층위로.

## 3. 의도된 설계 — 결함으로 신고 금지
- 里文이 폐물 플레이보이로 위장·정체(星云骑士)를 숨김 = 핵심 엔진. "왜 안 밝히나"는 결함 아님.
- 里文은 **무패**(사이다). 진짜 패배/상실 처방 금지. 긴장은 정체 노출 위험·스케일·시간·약자(공주/평민)에 건다.
- 里文이 **자기 손으로** 적을 친다(구출·코치받음 = 누수). 계모/达里安/巴尔坎 응징 = 참교육 연료.
- 빌런이 里文·공주를 "쓰레기/폐물"로 모욕 = 응징 연료지 매력 훼손 아님. 신고 금지.
- 정략혼·운명 정점 커플(里文↔莱拉)·정체 토큰(以太方舟) = 트롭 자산.

## 4. 화자 POV 가드레일 (오보 최다)
