### 3-1. 판독 — 러닝타임 계단

무료런이 **뒤로 갈수록 짧아진다.** EP2 정점(4:56) → EP8 최단(1:45). 페이월 직전 회차가 무료 구간에서 가장 짧다.

- EP1~3 = 4~5분대(세계·인물·엔진 설치 구간)
- EP4~5 = 3분대
- EP6~8 = 2분대 → 1분대 (클리프까지 최단거리로 절단)

우리 《군림》 설계(무료 EP1~8 · 페이월 클리프 EP8)와 무료 구간 길이가 동일하다. 다만 **회차 길이 배분은 우리 트리트먼트에 반영돼 있지 않다** — 대조 필요.

### 3-2. 재생수는 신호로 쓰지 말 것

EP1(26,646)이 무료 8화 중 **최저**다. 실제 퍼널이라면 불가능한 형태. 표기 재생수는 시드값/난수로 봐야 하며 이탈률 근거로 쓸 수 없다.

## 4. 대사 원문 — 미확보 (구조적 사유)

무료 8화 전량의 HLS 매니페스트를 직접 열어 확인:

- 마스터 플레이리스트 없음(variants=0) · **자막 렌디션 0** (`#EXT-X-MEDIA:TYPE=SUBTITLES` 전무)
- 재생 요청 = `main.m3u8` + `.ts` 세그먼트뿐. vtt/srt 요청 0건

→ 대사는 영상 안에만 존재(하드섭 또는 무자막). **스크레이핑으로 원작 대사 확보 불가.** 확보하려면 음성 STT 경로가 필요.

## 5. API 접근 방식 (재수집용)

- SPA(Vue) + 동일 오리진 API. `baseURL = /sarosTv` — 배포 JS에 문자열 없음(빌드 타임 주입), 헤드리스 Chrome CDP 네트워크 캡처로 복원
- 인증 = `POST /sarosTv/app/user/login` 익명 발급 JWT → 이후 `token` + `lang` 헤더
- 회차 전량 = `GET /sarosTv/web/play/{playId}` → `data.series[]` (`ifUnlock`으로 무료 판별)
- 회차 스트림 = `GET /sarosTv/web/play/unlock/{seriesId}` → `data.fileUrl` (m3u8)
- 헤더 없이 호출 시 403
