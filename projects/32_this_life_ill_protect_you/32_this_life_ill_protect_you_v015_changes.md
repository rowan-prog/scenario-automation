## 보고서 지적 5개 (원작 최종고와 대조)

| 지적 | 판정 | 처리 |
|---|---|---|
| 18~21화 루시 유인이 없음 | 맞음 — 원작 23화에 주소 알려주는 통화가 있음 | 18화에 통화 장면 추가. 루시 "대니얼이 라이언 손가락 잘랐다며? 대니얼 지금 어디 있어?" → 그레이스(속) "지난 생엔 라이언, 이번엔 대니얼이야?" → "주소 보내줄게." 손가락 처벌 결과도 여기서 확인됨 |
| 24~26화 스트리퍼 찾기 → 바로 영상 | 안 고침 | 24화 "스트리퍼부터 찾자"를 26화 영상이 바로 받아서 숏폼 생략으로 읽힘. 원작 29~30화 술집 직원 장면은 질투 장면(이미 뺀 것)이 주목적이라 되살리면 중반 분량만 늘어남 |
| 30화 죄책감을 심은 장면이 없음 | 맞음 — 원작 36화 생일 학대 회상 | 23화 루시 대사 한 줄로 심음: "엄마가 어릴 때 너한테 ‘네 아빠는 너 때문에 죽었다’고 한 건 내 탓 아니잖아." 회상 장면 복원은 분량 때문에 안 함 |
| 36~37화 처방약을 왜 삼키나 | 맞음 — 원작 45화는 영양제 오인 | 약병 = "대니얼이 구해 온 약을 옮겨 담은 고급 노화 방지 영양제 병". 수전 "비싼 노화 방지 영양제는 너 혼자 먹으려고 숨겨놨어? 너만 젊어지겠다 이거지?" (26화 영상에서 '쭈그렁 할망구' 소리 들은 수전이라 동기도 붙음) |
| 42~43화 밤 전화 → 낮 현장 | 반만 맞음 | 건물 장면에 자막 "<다음 날>"만 넣음. 납치 동작·"어제 연락해놨어"는 안 살림(라이언 등장 → 묶인 그레이스로 충분히 읽힘). 유리컵 = "휴대폰을 집으려 뻗은 팔꿈치에 유리컵이 밀려"로 동작 분명히 |

덤: 50화 "반년 전 내 대사잖아"는 앞에 받칠 대사가 없었음 → 그레이스 "다른 여자 만나면, 죽어요." / 대니얼 "그거 원래 내 대사잖아."로 바꿔 3화 대니얼 협박("…그땐 손가락이 아니라 목숨이야")을 받게 함.
