## 2. 합친 화 재배치 — 원작의 센 끝 장면 살리기

v007은 원작 두 화를 합치면서 원작에서 세게 끊기던 끝 장면 세 개를 화 중간에 묻었다. 이 세 곳을 다시 떼고, 대신 원작 끝이 약한 화끼리 합쳤다. 합친 화 개수(10개)와 전체 50화는 그대로다.

| v007 | v008 | 무엇이 달라졌나 |
|---|---|---|
| 11화 = 원작 11+12 | **11화 = 원작 11 / 12화 = 원작 12** | 11화가 원작대로 "그레이스 목에 딘의 총·부하들의 칼날 → 창백해진 그레이스"에서 끊긴다 |
| 18화 = 원작 21+22 | **19화 = 원작 21 / 20화 = 원작 22** | 19화가 원작대로 "서로 옷을 벗기는 두 사람"에서 끊긴다 |
| 21·22화 = 원작 25 / 26 | **23화 = 원작 25+26** | 원작 25화 끝("화… 났어?")은 약한 자리라 화 중간으로 들어가도 잃는 게 없다 |
| 25·26화 = 원작 29 / 30 | **26화 = 원작 29+30** | 원작 29화 끝(서로 노려봄)도 약한 자리 |
| 35·36화 = 원작 41 / 42 | **35화 = 원작 41+42** | 원작 41화 끝(현관 노크)은 중간 세기. 이 화는 원작 42화 끝 "대니얼! 문 좀 열어봐요! 괜찮아요?!"로 끊긴다 |
| 38화 = 원작 44+45 | **37화 = 원작 44 / 38화 = 원작 45** | 37화가 원작대로 수전 "내가 이럴 줄 알았어! 너도 니 애비 따라가고 싶어?!"에서 끊긴다 |

- 화 번호가 바뀐 구간은 12~26화와 35~38화뿐이다. 27~34화와 39~50화는 v007과 같은 번호다. 그래서 봉인 정보(대니얼 회귀 = 41화, 로버트 지목 이유 = 32화, 폭탄 생존 = 50화)도 그대로다.
- 자르고 합친 자리마다 장면 번호(S#)를 화별로 1부터 다시 매겼다. 합친 자리 뒤 장면은 v007 방식대로 "앞 장면에 이어."로 시작한다.

## 3. 무료 1~10화 — 원작 대사로 다시 깔기

v007은 사건은 다 있었지만 대사가 원작보다 순해져 있었다(원작 대사 턴 중 그대로 온 것 28%). v008은 원작 대사 173턴을 원작 순서·원작 문장 그대로 다시 깔았다. 원작과 다른 줄은 아래 "유지한 변경"뿐이다.

**대사에서 원작과 다른 것 (전부 의도):**
- 이름·호칭: 언니→그레이스(이름) · "차태경 씨"→대니얼 · 김 비서의 "대표님"→보스 · 조직원의 "차 대표"→브룩스 · 해진건설→브룩스 건설 · 백산파→리버 갱 · 서울→뉴욕 · 조직폭력배→마피아. 1화 라이언 통화의 "형부는 무슨 형부야"는 농담이라 "형부" 그대로.
- 소품: 빵칼→케이크 칼, 중고매장→전당포.
- 1화 그레이스 "언니 혼자 가서 미안해" → "나 혼자 가서 미안해"(미국 설정에서 자기를 "언니"라 부르지 않음).
- 6화 그레이스 속마음 "죽기 직전까지 다쳐서 돌아온 날" → "…다쳤다고 들었던 날". 전생의 그날 그레이스는 라이언의 아내라 직접 볼 수 없었다.
- 7화 대니얼 "(심상치 않다) 회사 로비. 뭐야, 그레이스. 무슨 일이야?" — "회사 로비." 추가. 원작 최종고에서 위치추적 앱 장면이 빠져 그레이스가 위치를 알 길이 이것뿐이다.
- 8화 "김 비서님도 곧 도착하실 거예요!" → "딘도 곧 도착할 거예요!"
- 10화 루시 "…응? 식만 다시 올리면 바로 떠날 수 있대." 추가, 그레이스 "결혼식 다시 올리고, 라이언이랑 스위스로 가면 된다는 거지?" — 식이 깨진 뒤라 원작 "결혼식 마치고"가 어긋나는 걸 메움.
- 10화 그레이스 "루시. 라이언한테 전해. 나 안 간다고." 추가(각색 계약 — 스위스 유인 거절). 그 뒤 원작대로 매몰차게 끊고 "이번엔, 같은 실수를 반복하지 않을 거야."
