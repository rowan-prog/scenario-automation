# 46 B · EP01~08 역대본 바로잡은 곳

- 1화 · 원작 오프닝 = "사흘 뒤" 석조 오두막, 두 여자만 입맞춤 → 설계서 §5대로 "한 달 뒤" 영지 루크 침실로 바꿈. 미아(금 꽃관) → 사브리나(붉은 겉옷) → 그웬(포니테일, 목 끌어안기) 순서, 자막 `ONE MONTH EARLIER`, 속마음 끝 줄 "한 달 전이었어".
- 1화 · 원작 `那三个到底是什么废物?` = 루크가 세 여자를 욕하는 말로 읽힘 → 남들이 왜 저 셋을 버리는지 묻는 말("저 셋은 대체 뭐가 문제길래?")로 옮기고, 이어지는 소개는 "~라더라/~래" 꼴로 소문으로만 받음.
- 1화 · 원작 관리가 방패·칼에 붉은 망토(전사 차림) → 설계서 §2대로 흰 리넨 관리 + 파피루스 두루마리, 단 위 청동 향로.
- 2화 · 원작 단 위 「副官」(설계서 인물표에 없음, 대사 없음) → 관리 곁 서기로 바꿈. 4화에서 인장 셋을 건네는 그 서기와 같은 사람.
- 2화 · 원작은 관리가 향을 가리키기만 함 → 관리가 신전 향에 불을 붙이는 지문 추가. 3화 절반 탐, 3-3 토막만 남음, 4화 첫 장면에서 재로 부서짐 = 시간 흐름이 보이게.
- 2→3화 · 원작은 뚱뚱한 남자가 그웬 손을 잡고 끝나 그웬이 왜 다시 남는지 안 보임 → 3화에서 뚱뚱한 남자가 골반 넓은 다른 여자를 보고 그웬 손목을 내던지고 가 버리는 지문 추가(러프와 같은 흐름).
- 3화 · 원작 `这个是累赘/那个薄得像纸片/白送都没人要` 누구를 두고 한 말인지 불명 → 짐짝·종잇장·바람 = 미아, 공짜로 줘도 = 사브리나로 손가락 지문을 달아 갈라 줌.
- 3화 · 원작은 호감도가 셋 다 +1 오르는 이유가 화면에 없음 → 다들 웃는데 루크만 뚱뚱한 남자를 노려보고, 세 여자가 그걸 보는 지문 두 줄 추가.
- 3화 · 원작 3-1 「石屋前」 → "광장 가장자리 진흙 벽돌 담"으로. 루크 오두막(성벽 밖)과 헷갈리지 않게.
- 3화 · 원작 렉스의 부하 「斯巴达男人只能有一个老婆」 vs 루크 「법에 셋 고르지 말란 말 없다」 → "전통(tradition)"과 "법(law)"으로 갈라 둘이 맞부딪히게 옮김.
- 4화 · 설계서 §4-19 적용: 관리 「Take them. They're yours now.」 + 서기가 진흙 인장 셋을 루크 손에 눌러 쥐여 줌 + 병사가 그웬 발목 사슬·미아 수갑을 풂. 원작 「带走」 자리에 합쳐서 같은 말이 두 번 안 나오게 함.
- 4화 · 원작 4-2 인물 줄에 그웬이 있는데 아무것도 안 함 → 창가에서 코페시 차고 루크를 지켜보는 지문 한 줄.
- 4화 · 원작은 루크가 통조림을 받고 곧바로 김 나는 나무 그릇을 들고 들어옴 → 밖에서 통조림 두 개를 따서 갈대불 위 항아리에 붓고 향신료 넣는 지문 한 줄.
- 4화 · 원작 그웬 「饿得出现幻觉」 앞에 아무 계기 없음 → 문 밑으로 고기 냄새가 스며들어 그웬 코가 실룩하는 지문.
- 4화 · 원작 5-1 사브리나가 "눈물 고인 눈"으로 올려다봄(앞뒤 대사와 안 맞음) → 팔짱 끼고 천장 보는 냉소로.
- 5화 · 설계서 §4-6 적용: 원작 그웬 대사 뒤 판넬 「-4」 삭제. 미아가 스튜 마실 때 원작 판넬 「15」 → `MIA 15 → 20`.
- 5화 · 원작 6화에 사브리나가 아무것도 안 함 → 조심스럽게 한 모금, 다음엔 빠르게 먹는 지문.
- 5화 · 원작 7-1(렉스) → 설계서 §1대로 화 맨 끝으로 옮김. 원작 「波勒蒙的石厅」 → 재상의 궁 렉스의 방(색칠한 기둥·연꽃 연못·금 조각상·청동 화로). 렉스 손에 채찍(§2).
- 6화 · 원작 8-1 루크가 "문 앞 매트에 누워 안을 본다"는데 같은 씬이 실내 → 실내(여자들) / 문밖(루크, 살짝 열린 문틈으로 안을 봄)으로 씬을 갈라 공간 맞춤.
- 6화 · 원작 그웬·사브리나가 "바닥 짚 더미"에 누움(루크가 침대를 내줬는데) → 구석 짚 침대에 눕힘. 미아는 침대 발치 벽에 기대 앉음.
- 6화 · 설계서 §4-17 적용: 미아 혼잣말 뒤 여자들이 잠들고, 루크가 짚 매트에서 일어나 맨발로 들어와 문 닫고 빗장 지르고 작업대 옆 꺼져 가는 불가에 앉는 지문. 그 뒤 시스템·구슬은 전부 오두막 안.
- 6화 · 원작은 구슬이 갑자기 손에 있어 「就给我这个」가 뭘 고른 건지 불명 → 4화 뽑기 때 그 모형 넷이 다시 뜨고, 소총 밑에서 수정 구슬이 빛나 루크가 그걸 집는 지문(7화에 AK가 나오는 것과 이어짐). 여자들이 깨지 않게 속삭임.
- 7화 · 원작 루크 「白色亚麻衬衫·金色卷发」 → 설계서 §2대로 민소매 리넨 상의·짧고 부스스한 검은 머리.
- 7화 · 원작은 루크가 총을 든 채 미아가 다가옴(미아가 총을 보면 8화에 렉스만 모르는 게 어색) → 루크가 소총·탄창을 작업대 밑에 밀어 넣고 곡식 자루로 덮는 지문. 8화에 거기서 꺼냄.
- 7화 · 원작 9-1 미아 대사가 속마음 표시 없이 혼잣말 → `(혼잣말로 속삭이며)`로 명시.
- 7화 · 원작 9-4 "짚 낮은 침대"에서 정사 → 침대엔 그웬·사브리나가 있으므로 화덕 옆 바닥 짚 자리로 통일(커튼은 배경). 사브리나·그웬은 커튼 뒤 침대에서 기둥과 커튼 틈으로 엿봄(§5).
- 7화 · 원작 9-5 사브리나만 나오고 그웬이 사라짐 → 그웬은 벽 쪽으로 돌아누워 눈 감고 주먹 쥔 지문 한 줄. 사브리나 원작 「보라색 천」 → 남색 드레스 자락(§2).
- 7화 · 원작 「门外的人」(누군지 불명) → 렉스의 부하 (소리). 렉스 본인 첫 등장은 8화 문이 열릴 때로 남김. 문 밑 횃불 빛·발 그림자 지문 추가.
- 8화 · 설계서 §4-18 적용: 첫 지문 = 나무 문이 발길질에 부서지듯 열리고 빗장이 부러지며 횃불이 들이닥침. 루크는 리넨 상의를 걸치는 중, 미아는 드레스 앞섶을 여밈. 그웬은 코페시를 뽑아 들고(원작 둥근 방패 자리) 사브리나와 커튼 뒤에서 나와 루크 뒤에 섬.
- 8화 · 원작 렉스 「你碰了那个女人?」 근거가 화면에 없음 → 렉스가 미아의 풀린 드레스와 머리의 짚을 보는 지문.
- 8화 · 설계서 §4-19 적용: 「I have the marriage seals.」에서 루크가 킬트에서 4화 진흙 인장 셋을 꺼내 들어 보임 → 작업대에 내려놓고 작업대 밑 AK를 꺼내 겨눔.
- 8화 · 원작 끝은 「上!」 → 「是你自找的」 → 방아쇠. 그사이 병사들이 칼을 뽑고 달려드는 지문 한 줄(러프와 같음). 끝 = 방아쇠 당기는 지문, 뒤에 반응 없음.
