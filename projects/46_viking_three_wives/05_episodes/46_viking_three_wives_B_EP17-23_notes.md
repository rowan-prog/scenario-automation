# 46 B · EP17~23 역대본 바로잡기 목록

- **17화 (第19集)** · 역대본 한국어판은 사브리나의 소식 보고(재상이 막사·술집·사창가까지 뒤짐)를 렉스(폴레몬) 대사로 적어 둠 → 중문 정리본대로 사브리나 대사로. 술집은 맥줏집으로.
- **17화** · 그웬 「어젯밤 온 놈들도 사자 장군 부하」 → 1일째 밤 그 경비대장이라는 게 보이게 「붉은 깃 단 그 경비대장」을 넣음(§2 합침).
- **17화** · 원작 「恨不得把对方生吞了」(서로 산 채로 삼키고 싶어 함) → 비유를 빼고 「몇 년째 권력 다툼하면서 서로 못 죽여서 안달」로.
- **18화 (第20集)** · 미아 속마음 「오늘 밤 그랑 잘까?」 → 미아는 1일째 밤에 이미 루크와 잤음(7화) → 「오늘 밤에도」로.
- **18화** · 역대본은 루크 속마음(평범한 선물로는 장군 못 움직임 · 이거면 되겠군)을 라일라(사브리나) 대사로 적어 둠 → 루크 속마음으로(중문 정리본 기준).
- **18화** · 떠 있는 물건 중 무엇을 골랐는지 안 보임 → 루크 손가락이 하나에서 멈추고 빛이 너무 세서 안 보인다는 지문으로. 커튼 뒤 갑옷 공개까지 아껴 둠.
- **18화** · 3일째 낮 루크 옷이 「흰 셔츠·검은 조끼·바지」 → 2일째 아침부터 입은 흰 리넨·가죽 벨트·샌들로.
- **18화 (§4-14 · §2 합침)** · 「听说你在找我」(누가 어떻게 찾았는지 없음) + 「중위」가 처음 보는 사람처럼 나옴 → 경비대장이 루크를 알아봄(「북쪽 첩자들 나왔던 그 오두막」) + 「오늘 아침 네 아내 하나, 그 과부가 막사로 찾아왔다」로 사브리나가 다리를 놓았다는 걸 박음. 중위 = 경비대장.
- **18화 (§4-11)** · 「这个怎么样?」가 사브리나를 가리키는 것처럼 읽힘 → 사브리나가 구석 짚 침대 커튼을 걷자 나무 받침대 위 황금 갑옷과 검이 빛남 → 루크 「Captain.」 / 「What do you think of this?」로 나눔.
- **18화·19화** · 갑옷 장면에 그웬이 안 나오는데 20화에서 그웬이 「이젠 신성한 갑옷까지」라고 함 → 그웬을 화덕 옆에 말없이 세워 둠(코페시에 손). 사브리나도 커튼 곁에 둠.
- **19화 (第21集 · §4-13)** · 「真美啊」 화자 = 이름 없는 「여자」 → 미아.
- **19화** · 역대본은 「장군님이 좋아하시겠군」·「더 귀한 게 있다고?」·「여기서 기다려라」를 실버 늑대 장군 대사로 적어 둠(장군이 자기 얘기를 3인칭으로 함) → 전부 경비대장 대사로.
- **19화** · 경비병 1이 쥐고 있던 검이 다음 컷에 경비대장 손에 있음 + 펼쳐 둔 갑옷이 갑자기 상자 안 「붉은 것」으로 나옴 → 경비대장이 경비병 1에게서 검을 받아 드는 지문 + 갑옷이 상자 안 붉은 천 위에 담겼다는 지문.
- **19화** · 「斯巴达王宫」 → 파라오의 궁 / 「太阳神」 → 태양신 라 / 「原始冶炼技术」 → 옛날 청동 기술 / 「斯巴达的田野」 → 이집트 들판 / 「国王」 → 파라오.
- **20화 (第22集 · §4-3)** · 시스템 「셋 다 80 넘음, 이제 라일라만 남았다」 → 「Two targets are over 80. Rewards unlock in stages.」 / 「Only Sabrina is left.」 역대본은 이 대사를 갈색머리여자(미아)로 적어 둠 → 시스템 새끼 고양이 대사로(루크만 봄). 사브리나를 힐끗 보는 지문 한 줄.
- **20화** · 루크 「들어오지 마」(방 하나짜리 오두막인데 루크는 문 밖을 살피러 감) → 「안에 있어. 나오지 마.」 원작의 천 문발 → 오두막 나무 문(§5).
- **20화** · 원작 석조 벽난로 → 흙 화덕(§5 오두막).
- **20화** · 나무 뒤 두 남자 중 누가 경비대 끄나풀인지 엇갈림(22화엔 턱수염이 갑옷, 24화엔 곱슬머리가 늑대 가슴받이) → 곱슬머리 = 붉은 망토 + 경비대 사자 가슴받이(재상의 금을 받는 경비병) / 턱수염 = 붉은 목수건 + 비늘 가죽 조끼. 22화 혼자 남는 사람과 같게.
- **20화** · 첩자들이 「잡으러 가자」 해 놓고 안 움직임 → 장군이 달려오자 나무 뒤로 납작 엎드리는 지문 한 줄.
- **20화** · 역대본 「은빛 전신 갑옷」(21화엔 황금) → 선물받은 황금 갑옷 + 사자 장식 투구로 통일.
- **20화·21화** · 사자 장군 이름 카드 = 20화 말 탄 컷은 투구로 얼굴이 가려져 있고 끝 대사가 「The Lion General?」이라 카드가 먼저 답을 해 버림 → 얼굴이 보이는 21화 입장 컷에 `[NAME CARD]`.
- **21화 (第23集)** · 병사들이 갑자기 칼을 뽑고 장군이 「무례하다! 손가락 하나라도 대면…」 하는데 왜 뽑는지 빠짐 + 다음 컷에 장군이 받아먹는 음식이 어디서 났는지 없음 → 루크가 천 덮은 진흙 그릇을 들고 나와, 대답 대신 한 숟갈을 장군 입에 들이밂 → 병사들이 루크에게 칼을 겨눔 → 장군이 병사들에게 호통(루크를 감쌈). 사건 추가 없이 빈 동작만 채움.
- **21화** · 그웬 「城卫队的统领」 = 장군을 가리킴 → 「도시 경비대 우두머리」로 두고 경비대장과 헷갈리지 않게 함.
- **22화 (第24集 · §4-4)** · 「나도!」 화자 = 제이슨(오류) → 병사 2. 순서 「General, can we try some?」 「Me too!」 「It's gone.」 + 장군이 싹 긁어 먹은 빈 그릇을 보여 주는 지문.
- **22화 (§4-5)** · 장군 「제이슨은 우리를 속인 적이 없다」(방금 만남) → 「He hasn't lied to us yet.」
- **22화** · 장군이 루크에게 감자를 내미는데 감자가 어디서 났는지 없음 → 루크가 설명하면서 문 옆 자루에서 생감자를 꺼내 장군 손에 올려 주는 지문. 루크가 「좋아」 하며 받아 듦.
- **22화** · 호밀 → 보리 / 코린토스식 투구 → 청동 투구 / 농노 → 일꾼 / 국왕 → 파라오 / 「银狼的庇护」 → 사자 장군의 뒷배.
- **22화** · 20화 이후 사브리나 자리가 없음 → 오두막 안쪽 그늘에서 병사들 눈을 피하는 지문 한 줄(23화 「들키기 쉬워진다」 걱정과 이어짐).
- **23화 (第25集)** · 루크 속마음 「어제까지만 해도 오두막」 → 오늘 아침까지 오두막에 있었음 → 「어젯밤까지만 해도 오두막에 끼어 잤는데, 오늘 밤엔 영지」.
- **23화** · 「내가 적어 준 대로」인데 적은 게 안 나옴 → 집사에게 파피루스 한 장을 건네는 지문. 검은 옷 늙은 하인 = 집사(§2).
- **23화** · 역대본은 「네 몸은 아직 너무 약해」를 붉은옷여자(사브리나)로 적어 둠 → 중문 정리본대로 그웬(훈련 담당 · 루크가 그웬 어깨에 손 얹은 컷과 맞음).
- **23화** · 역대본 계단 아래 「검은옷인물」이 여자 셋 중 하나로 잡힘(장부 확인 대사) → 장부 = 사브리나(남편 장부를 다 아는 과부), 「사브리나 도울게요」 = 미아. 중문 정리본 기준.
- **23화** · 사브리나 붉은 드레스 → 남색 리넨 드레스(§2). 루크 「짙은 조끼」 → 흰 리넨 튜닉. 마차 → 검은 말이 끄는 지붕 덮인 나무 수레. 사이프러스 → 대추야자.

## 남은 것
- 18화 끝 ~ 19화 첫 컷: 원작대로 섬광 뒤 갑옷 감탄으로 바로 이어짐. 그 사이 갑옷을 상자에 담는 동작은 19화 중간 지문 한 줄로만 처리함.
