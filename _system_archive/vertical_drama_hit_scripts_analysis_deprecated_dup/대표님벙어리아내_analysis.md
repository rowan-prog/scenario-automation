# 대표님의 벙어리 아내 (지독한 사랑을 받는 벙어리 신부) — 3축 분석

| 항목 | 내용 |

## 2. 1축 캐릭터 분석

### 주인공 (강이나)
- **1화 바닥 (이입 트리거):** 벙어리 + 양녀 + 3년 결혼 + 남편의 내연녀에게 모욕당함 + "죽은 생선" 폄훼 + 아이까지 강제 낙태당함 + 본가 식탁에서 비웃음 + 가정부 통제·외출 금지·집안 갇힘
- **저항 + 무시 패턴:** "이러지 마세요" 류 매달림 없음. 수어로 똑똑히 의사 표현 — "이혼하자" / "심술 부리는 거 아니야" / "나도 너를 사랑하지 않아 너만 아니면 돼" — 그 의사가 매번 무시·억압·통제로 받아침 → 시청자 이입 폭발
- **8-12화 거래:** 가영 친구 만남 → 이혼 협의서 제출 → 클럽에서 무릎 꿇기 → 영민에게 도움 청함 (떨면서도 한 발 전진)
- **30-50화 상승:** 도망 → 임신 → 영민 보호 → 보름 추방 → 어머니의 지분 음모 폭로로 진실 충돌
- **70화+ 정점:** 기억 상실·재발 + 후반 회수 → 결혼식 재현
- **paid vertical 정합:** 완벽한 상승 호 (1화 바닥 → 12화 거래 → 50화 진실 → 100화 정점)

### 메인 빌런 (정민재 + 하수연 이중 구조)
- **이중 메인 빌런 — 정민재 (남편·내부) + 하수연 (내연녀·외부):**
  - 정민재: 통제·강요·격리·폭언·임신 격리 / 끝까지 가치 모름 (감춰진 사랑이라는 작가 트로프 있지만 시청자에게는 가해자로 보임)
  - 하수연: 공개 모욕·"벙어리"·소독 스프레이·무릎 꿇기 강요 → **이졸데 모욕 5-8턴 교환의 교과서**
- **5-8턴 모욕 교환 패턴 충실:** 클럽 11화 = 가영 도발 → 수연 거부 → 민재 침묵 → 가영 사과 거부 → 이나 무릎 꿇음 → 수연 더 까기 → 민재 폭발 → 이나 안고 나옴 (정확한 8턴 시퀀스)

### 보조 빌런 (다수 환경 압박)
- **민재의 어머니:** 임신 강제 낙태 / 결혼 양녀로 차등 / 본가 식탁 모욕 / 50화 지분 음모로 격발
- **민재의 누나 정유미:** "아이는 언제 낳을 거예요?" / 본가 식탁 비꼬기 / 본가에서 양녀 위치 강조
- **가정부·경호원:** 도주 막기 / 외출 금지 / 작은 방 감금 도구화
- **하수연의 조력자들:** SNS / 비교 / "그깟 벙어리"
- → **메인 1 + 보조 다수 = 같은 계통 환경 압박** 패턴 정확 구현

### 남주 (정민재 — 이중 역할)
- **다크 로맨스 남주 가까운 변형:** 첫 1-20화 = 사실상 빌런 가까움 — 짐승 직진 X 단 통제·소유·집착 / 끝까지 사랑한다고 말 안 함
- **멈춤 X 패턴:** 침실 강제 / 강제 키스 / 가두기 / "그 카페 가지 마" / 카드 제거 / 매번 자기 의지대로 통제
- **회수형 남주 (한국 vertical 특유):** 후반 70-100화 = 사랑 회수 + 임신 보호 + 결혼식 재현 — paid vertical 다크 로맨스의 한국형 변형
- **voice 한 줄:** "두 번 말하기 싫어 / 닥쳐 / 알겠어 / 두 번째 안 말해 / 잘했어" — 단답 통제형, 시적 cadence 0

## 3. 2축 이야기 구조

### 압력축 1개 (장르 초월)
> **"이 통제하는 남편이 언제 진심을 인정하고, 이 양녀 출신 여자가 언제 공개적으로 정식 아내·정식 위치를 받는가?"**

→ 100화 끝까지 단일 축. 분산 0건. 모든 사건이 이 축을 키움 (이혼 → 임신 → 도망 → 진실 → 후회 → 재결합).

### 페이즈 4 구조
- **EP1-12 (페이즈 1 — 결혼 지옥):** 양녀 출신 + 벙어리 + 내연녀 + 본가 모욕 → 이혼 결심·무릎 꿇기
- **EP13-32 (페이즈 2 — 도망과 임신):** 영민 등장 → 임신 폭로 → 보름 추방 → 떠남
- **EP33-50 (페이즈 3 — 진실의 도래):** 영민과의 새 생활 → 어머니의 지분 음모 → 50화 = 큰 트위스트 (정민재가 사실 회사 위해 결혼)
- **EP51-100 (페이즈 4 — 회수와 결혼):** 후회 + 회수 + 기억 상실 + 재결합

### 페이월 패턴 (강력 → 미스터리 X)
- **EP12 페이월:** "무릎 꿇은 이나 안고 가는 민재 / 그러나 본가 도착 후 침실에서 다시 통제" — 짧은 보상 + 다시 통제 = 다음 화 결제 의무
- **EP32 페이월:** "이혼 결심 + 영민 도움 + 보름 추방" — 큰 분리·다음 화 더 큰 위기
- **EP50 페이월:** "어머니의 지분 음모 폭로 + 진실 직격" — 결정적 트위스트
- **EP70 페이월:** "기억 상실 진단" — 작품 후반의 큰 사건 카드
- → **행동 직전 페이월** 패턴 정확 (정보 X / 사건 O)

### 모욕 루프 (클립 보상)
- 매 EP 모욕 패턴: 수연·어머니·유미·가정부 → 5-8턴 누적 → 민재의 통제 또는 진실 폭로
- 클립 보상 점진 확장: 사적 모욕 (1-3화) → 공개 모욕 (5-12화) → 본가 모욕 (4-7화) → 회사 모욕 (50화+) → 사회 모욕 (70화+)

### VO/플래시백 도구
- **강이나 VO 핵심 도구:** 벙어리 설정으로 VO가 작품 전반 사용 — 매 씬 강이나 속내가 즉시 청각 전달 → **멀티태스킹 시청자에 최적**
- **플래시백 빈번:** 어린 민재·이나 회상 (오빠 트라우마) / 결혼식 회상 / 임신 회상 / 본가 모욕 회상 → **이입 트리거 + 정서 보강**
- 5 조건 충족도 매우 높음: 구체적 인간·짧은 압축·결정 직전·청각·구체 발화

## 4. 3축 대사 스타일

### 톤 (paid vertical 직격)
- **시적·연극톤 0건:** 단답·일상 통제 어휘 — "두 번 말 안 해 / 닥쳐 / 가지 마"
- **분위기 단어 0건:** 영혼·운명·그림자 류 X
- **VO도 즉시 이해형:** "약속은 어기라고 있는 거였어 / 내 욕심이 너무 큰 거겠지" — 자기 처지 즉시 청각화

### 티키타카 (5-8턴 표준)
- **11화 클럽 모욕 시퀀스:** 가영 도발 → 수연 거부 → 이나 사과 → 수연 더 까기 → 이나 자기 뺨 때리기 → 수연 무릎 강요 → 이나 무릎 → 민재 폭발 (정확한 8턴)
- **3화 가족 식탁 모욕 시퀀스:** 유미 "아이 언제?" → 이나 변명 시도 (수어) → 어머니 "그만 해" → 누나 "벙어리 하나 더?" → 이나 손 내림 → 4턴 + 침묵 압박
- **소품 회피 + 행동 우위:** 이혼 협의서·신용카드 1회 → 도구화 없음

### 브릿지 직관 청각 (멀티태스킹)
- **VO 적극 활용:** 강이나가 수어밖에 못 함 → 모든 내적 상태는 VO 청각 전달 → **멀티태스킹 시청자가 화면 못 봐도 사건 흐름 100% 따라옴**
- 구체 인용: "정민재. 우리 결혼은 할아버지의 유언 때문에 한 거잖아 / 넌 날 사랑하지 않아 / 나도 널 사랑하지 않고" — 1줄에 4 요소 (욕망·상황·선택·다음)
- **수어 + VO 조합 = paid vertical 청각 최적 모델** (특수 사례)

## 5. 종합 평가

### paid vertical 정합도: 95%
- 상승 호 완벽 (1화 바닥 → 50화 정점 → 100화 회수)
- 모욕 루프·클립 보상·압력축 1개 모두 충실
- VO 적극 활용으로 멀티태스킹 적격
- 시적 대사 0건·작가 자아 0건
- 단점: 한국 후회남 모델 — 다크 로맨스의 멈춤 X 짐승 직진과는 다소 다른 결 (단 한국 시장 검증)

### AI 시네마틱 함정 6 점검
1. 부서진 후 미학 — **0건** (실제 흐느낌·울음·매달림 직접 노출)
2. 환경 진동으로 위협 — **0건** (가해자 직접 발화·행동)
3. 절제 에로스 — **0건** (남주가 통제 못 함 / 단 한국형 변형 — 다크 로맨스 짐승 직진과는 결 다름)
4. 상징 누적 의미 — **0건** (매 EP 독립 작동)
5. 2-3턴 인장 — **0건** (5-8턴 표준)
6. 1화 완성형 여주 — **0건** (이나 매달림·울음 + 저항 + 무시 패턴 정확)

### 차용 패턴 (OFFERING·신규 작품 적용)
1. **수어/VO 청각 보강 모델:** 멀티태스킹 시청자 청각 최적화 — VO가 신체적 제약(벙어리)으로 자연스럽게 정당화 + 매 씬 작동
2. **이중 메인 빌런 (남편 + 내연녀) 패턴:** 한국 vertical 표준 — 외부 빌런(여자)이 직접 모욕 + 내부 빌런(남편)이 통제·방관 → 5-8턴 교환 극대
3. **본가 식탁 모욕 시퀀스:** 양녀·신분차 강조 + 가족 다수의 모욕 압박 → 매 회 클립 보상 무한 재포장
4. **신체 결함 + 이입 결합:** 벙어리(또는 절뚝·외모·신분) 결함 → 모욕의 즉시 정당성 + 시청자 즉시 이입
5. **이혼 협의서/카드 1회 도구:** 비반복 / 핵심 사건만 트리거 — 소품 최소화 룰 정확
6. **본가 폭로 시퀀스 (EP50):** 트위스트가 어머니 음모로 진행 = 모욕 누적의 진짜 정점 폭로 — 한국 vertical 핵심 결제 페이월 모델
