## 1축 — 캐릭터 분석

### 여주 황후 심지아 (1화 바닥·2화 죽음 + 빙의·3화 거래 패턴)

**1화 바닥 정의:** 출산 후 90kg 비만 + 의식에서 옷 터짐 망신 + 태자 "어마마마 못생겼어요" 거부 + 황제 외면 + 신하들 비웃음 + 별궁 유배 + 시종에게 목 졸려 죽음. **이입 트리거 = 외모 멸시 + 가족 거부 + 살해**. `feedback_female_lead_rise_arc.md` "처절함 = 저항 + 무시" 정합 — 황후가 거부·반항·"내가 왔도다!"로 늦은 등장에도 자기 자존 시도 → 모두 비웃음·외면·살해.

**2화 죽음 → 3화 빙의 (특수 변형):**
- 한국 의대 졸업생 심지아가 사고로 죽음 → 황후 몸에 빙의
- **빙의 = 1화 바닥에서 즉시 새 자아로 도약 = 한국형 paid vertical 회귀·빙의 클리셰의 정수**
- 메모리 `feedback_female_lead_rise_arc.md` 의 "1화 바닥 → 8화 거래" 변형 — **3화부터 즉시 셈하는 여자 / 단 외형(90kg)은 그대로 = 신체 바닥 + 정신 정상의 모순**

**3-6화 거래 패턴:**
- EP3 빙의 직후: 귀비 뺨치기 (즉시 사이다 보상)
- EP4 귀비 20대 매질 + 황후 직접 추가
- EP5 황제 뺨에 검 → 별궁 유배 (역설적 자유)
- EP6-7 별궁에 스마트폰으로 시간여행 배달원 호출 (포털) → 현대 가구 배달

**여주 voice 한 줄:** 빙의 전 = 황후 톤(공손·반복 "용서해주십시오") / 빙의 후 = 의대생 톤 + 황후 위엄 결합 ("이런 못된 것, 당연히 내가 죽길 바랐겠지") + 현대인 욕설 ("오, 그 쓰레기로군").

### 남주 황제 이현우 (다크 로맨스 X / 안티히어로 → 점진 정복형)

**1-5화 = 남주가 빌런 역할 겸함 (한국 빙의 클리셰 정합):**
- "스스로 목숨을 끊은 줄 알았는데?" (싸늘)
- "황후를 당장 별궁으로 보내 가두어라" (즉시 처벌)
- 귀비 편 / 황후 무시
- **남주가 1차 페이월까지 적대 = 시청자 "남주가 황후에게 굴복하는 날 = 결제 보상"**

**페이월 이후 점진 정복:** 황후의 빙의 후 변화에 점진 매료 → 사랑꾼 전향 (사극 클리셰).

### 빌런 (구체 개인 + 사극 환경 압박)

**메인 빌런 1명:** 귀비 최수아 (황후 자리 노리는 후궁 = 직접 살해 명령). 얼굴·이름·구체 행동 명확.

**보조 빌런 다수:**
- 태후 최영자 (귀비 어머니 = 정치 모략)
- 황제 이현우 (안티히어로 = 빌런 겸함 1-5화)
- 태자 이시후 (어린 친자식이지만 어머니 거부)
- 신하·시종·시녀 (외모 멸시 군중)

**환경 압박 = 사극 궁궐 전체:** 황후를 둘러싼 절대 다수가 외모로 멸시·정치적으로 무시·자리에서 제거하려 함. `feedback_concrete_villain_humiliation_loop.md` "전체가 환경으로 작동" 정합.

**빌런 가치 모름 검증:**
- 귀비: "이런 흉물보다 아래에 있었다니" (외모 멸시 끝까지)
- 태후: "황후가 죽도록 둬선 안 된다" (정치만 이용 / 가치 모름)
- 신하 호부상서: "나라도 저렇게 흉측한 어미와는 함께 다니고 싶지 않겠네"
- → **빙의 후 황후의 실제 능력·지위 회복 직전까지 모두 외모로만 평가**

## 2축 — 이야기 구조 분석

### 압력축 1개 (사극 변형)

**핵심 압력축:** **"외모·정치적으로 박살난 황후가 언제 다시 정식 황후 자리에 복귀하고·빌런들이 차례로 굴복하나"**.

**5단계 압력 누적:**
1. EP1-2: 외모 망신 + 살해
2. EP3-4: 빙의 후 첫 반격 (귀비 뺨)
3. EP5: 황제에게 검 휘두름 + 유배
4. EP6-8: 별궁에서 살 빼기 + 태상황 귀환 정치 카드
5. EP9+: 정치 회복 + 황제 마음 회복 + 빌런 차례 박살

### 페이월 위치 (EP5 끝 / EP6 도입) — 핵심 분석

**EP5 페이월 정확한 위치:**
- EP5 마지막: 황후 검으로 황제 뺨 베고 → "황후를 당장 별궁으로 보내 가두어라" 명령
- EP6 도입: 별궁 유배 + 황량한 폐가 진입 + "오, 이런 폐가라니" 

**페이월 왜 EP5-6 위치인가:**
1. **빙의 + 첫 반격이 EP3-4에서 즉시 보상으로 제공** — `feedback_paid_vertical_4_levers.md` "L1 서사 vs 감정 초반 빠르게 정합"
2. **EP5 페이월 = "유배 = 끝났다?" + 새 자원(현대 지식·스마트폰 포털) 노출 직전** — 시청자 "별궁에서 어떻게 살아남고 다시 권력으로 돌아오나" 결제 동기
3. **시간여행 배달 포털 = EP6-7에서 본격 노출 = 유료 보상의 핵심 매개체**

**대안 페이월 = EP8 끝 / EP9 도입 (태상황 귀환):**
- EP8 = 태상황 귀환 → 황후 별궁 가둠에 분노 → 모두 굴복 직전
- EP9 = 태상황의 정의 회복
- → 한국 vertical 시장의 표준 8화 페이월 가능성도 높음

### 클립 보상 루프

**원초 쾌감 1개:** "외모로 멸시받은 황후가 정치·체력·인맥 모든 자리에서 차례로 복귀".

**점진 확장:**
- EP3 귀비 뺨 (사적 보상)
- EP4 귀비 20대 매질 (공개 보상)
- EP5 황제에게 검 (최상위 권력에 도전)
- EP8+ 태상황 + 정치 + 외모 회복 (전 영역 정복)

### 보상 단계 (3층 구조)

- **1층 (EP3 즉시):** 빙의 + 귀비 뺨 = "곧 복수한다" 즉시 안도
- **2층 (EP4-7):** 시간여행 배달 포털·다이어트·정치 카드 = 자원 누적
- **3층 (EP9+ 유료):** 태상황 + 황제 회복 + 빌런 차례 박살

## 3축 — 대사 스타일 분석

### 시적·연극톤 검증

**사극 톤 ≠ 시적·연극톤:** 시극이라 "마마·폐하·소첩" 등 사극 어휘 사용하나 **대구·라임·은유·punchline 0건**. paid vertical 절대 마지노선 통과.

**예시:**
- "이런 못된 것, 당연히 내가 죽길 바랐겠지. 안타깝게도 지옥에 내 자리가 없더구나. 그래서 다시 돌아왔지." — Pattern A 사실 나열 + 사극 톤 + 직관
- "네 어미도 못 알아볼 정도로 때려줄 테니" — 단답 위협
- "오, 그 쓰레기로군" — 현대 욕설 (빙의 정체성 표지)

### 4 요소 (욕망·상황·선택·다음 장면) 정합

황후 "더 맞고 싶으면, 그냥 맞고 싶다고 말해라" =
- 욕망: 귀비 굴복시키기
- 상황: 귀비 20대 매질 직후
- 선택: 추가 매질
- 다음: 황제 진입

### 멀티태스킹 시청자 친화

- 시녀가 황후 살 찐 것 즉시 청각으로 설명 ("마마, 또 살이 찌셨습니다")
- 신하들 수군거림으로 외부 시선 청각화 ("어쩐지 폐하께서 출산 이후로 황후를 멀리하시더라니")
- 황후 (VO) "내가 정말 빙의한 건가? 그것도 몸무게가 90킬로가 넘는 황후의 몸에?" = 즉시 자가 설명

### 캐릭터 voice 차별

- **황후 (빙의 전):** 공손·자존 시도 ("용서해 주십시오, 폐하")
- **황후 (빙의 후):** 위엄 + 현대 욕설 + 직설
- **귀비:** 가식 + 겁쟁이 (강자 앞 굴복)
- **황제:** 차가운 권력자 → 점차 흔들림
- **태상황:** 직설 어른 ("말도 안 돼. 황후는 절대 그런 짓을 할 아이가 아니다")

## 종합 평가

### 강점

1. **빙의 클리셰 = 1화 바닥에서 즉시 회복 + 점진 권력 회복 = paid vertical 압축 보상 정수**
2. **유머 + 사이다 결합** — 황후의 90kg 비만 + 빙의 후 욕설 = 코미디 + 복수 동시
3. **개인 빌런 + 환경 압박** = 정합
4. **시적·연극톤 0건** (사극 톤 ≠ 시적) = 정합
5. **시간여행 배달 포털 = 한국 vertical 시장의 "현대 지식 + 사극 활용" 핵심 트로프 검증**

### 약점·OFFERING 적용 시 주의

1. **빙의 = 한국·중화권 핵심 클리셰** — 북미 paid vertical에서는 유사 트로프 (Reincarnation·Time Travel) 활용 가능하나 다른 카테고리
2. **사극 톤 = 직접 변환 불가** — 다크 로맨타지·재벌 컨셉으로 직접 적용 X
3. **코미디 비중** — OFFERING (다크 로맨타지)에는 부적합. 무거운 톤 유지

### 다른 작품에 적용 가능한 인사이트

- **1화 = 최악의 망신** → **즉시 2화 죽음 → 3화 새 자아** = 압축형 회복 호. OFFERING도 이졸데가 1화 처절 → 2화 거래 → 3화 단호한 거래자로 압축 가능
- **빌런 가치 모름 (외모 멸시)** = 동일 적용 가능. OFFERING 이복오빠도 끝까지 "폐품" 호칭 유지
- **시청자 정보 비대칭 (시청자만 빙의 알고 빌런들 모름)** = 압력 누적 핵심. OFFERING도 Bael의 진짜 목적·이졸데의 진짜 자원 시청자만 알게 설계
- **외부 자원 (시간여행 배달) 도입 = 페이월 직후 보상 메커니즘** — OFFERING도 Bael의 권력·드래곤 측 자원이 EP9+에서 본격 활용
