## 2. 1축 캐릭터 분석

### 주인공 (서지원)
- **1화 바닥 (이입 트리거):** 절름발이 + 외삼촌 집 양녀 → 대나무 숲에서 독 중독된 태환 구함 (강제 합궁) → 임신 → 외삼촌 가족이 몽둥이로 폭행 + 산속 창고로 추방
- **저항 + 무시 패턴:** "정말 저도 몰라요 누군지" / "이 아이는 제가 낳기로 결심한 거예요 / 아이 아빠와는 상관없어요" / "시집 안 가요!" — 매번 저항하지만 외삼촌·숙모가 무시·체벌·내쫓음 → 시청자 이입 폭발
- **2-11화 바닥 누적:** 폭우 빗속 출산 위기 → 입원비 부족 → 분유 못 사 → 식당 쫓겨남 → 결국 시집 강요 직전
- **12화 거래:** 태환 도착 + 최비서 "사모님" 선언 + 가족 굴욕
- **22화+ 상승:** 혼인신고 → 다리 치료 → 결혼식 → 직장 입사
- **86-87화 정점:** 모든 가족 비참 + 직장 정직원 + 둘째 아이 임신
- **paid vertical 정합:** 완벽한 상승 호 (1화 바닥 → 12화 첫 보상 → 87화 회수)

### 메인 빌런 — 다층 구조 (정확한 1+다수 패턴)
- **메인 빌런 = 외숙모 조귀숙 (혈연 아닌 양육자·악역의 핵심):**
  - 끝까지 가치 모름 / 끝까지 욕망 (돈·딸의 결혼) — "이 뻔뻔하게 우리 집에서 10년 넘게 공짜로 먹고 자더니"
  - 외삼촌(성국)이 표면 중재자 / 실제는 무력 / 숙모가 진짜 통제자
- **보조 빌런 다수 (같은 계통 환경 압박):**
  - 외삼촌 이성국 — 표면 가족 책임 가장 / 실제로는 도구
  - 사촌 이세린 — 비웃음 / 몽둥이 권유 / 직접적 악의
  - 유성그룹 첫째 — 외부 빌런 / 몽둥이 폭력 / 정신 모자란 동생 결혼 강요
  - 유성그룹 셋째 — 외부 빌런 / 정신 모자란 신랑감
  - 황 대표 (강성그룹 가족) — 다른 가족 보조 빌런
  - 학교 동창 여학생1·2 — 절름발이·미혼모 모욕
  - 회사 유 팀장 — 야근 모욕

→ **메인 1 + 다수 보조 = 같은 계통 환경 압박** 패턴 정확

### 남주 (강태환)
- **다친 자 → 재벌 회수형 (한국 vertical 표준):**
  - 1화 = 부상자·여주가 구해줌 (대나무 숲) → 6년 후 = 강성그룹 대표 + 차가운 통제형
  - 12화 = 즉시 보호자·메인 빌런 직접 응징 (발차기) + 명료 선언 ("내 사모님")
- **멈춤 X 패턴:** 다리 치료 결정 + 혼인신고 + 즉시 가족 보호 — 한국 vertical 알파 보호자 표준
- **voice 한 줄:** "당신 누구요? / 좋은 시댁? / 응 / 알아서 처리해 / 내 아이야 / 내가 그 사람이 되고 싶어" — 단답·통제·보호 우위, 시적 cadence 0
- **다크 통제 X / 보호자 알파 O** — 한국 가족극 결

## 3. 2축 이야기 구조

## 4. 3축 대사 스타일

- **시적·연극톤 0건:** 단답·일상 가족 어휘 — "이 아이는 제가 낳기로 / 시집 안 가요! / 도와주세요"
- **분위기 단어 0건:** 영혼·운명 류 X

### 티키타카 (5-8턴 표준)
- **EP1 외삼촌 가족 폭행 시퀀스:** 숙모 "어쩌자고 조심성이 없니?" → 지원 "정말 저도 몰라요" → 숙모 "그걸 대답이라고 해? 오늘 너 죽고 나 죽자" → 몽둥이 → 외삼촌 막음 → 외삼촌 "결혼도 안 한 처녀가" → 사촌 "남부끄러워서" → 외삼촌 "외할머니 창고" → 6턴 누적 (정확한 시퀀스)
- **EP10-12 정신 모자란 셋째 결혼 강요 + 가족 환경 압박 + 태환 도착:**  숙모 "유성그룹 셋째 도련님" → 지원 "싫어요!" → 사촌 "이 절름발이" → 둘째 "내가 지금 바로 널 불구로" → 지원 "안 돼!" → 태환 발차기 → 사촌 "근데, 맞아도 싸 우리 장인어른이잖아?" → 가족 180도 변화 (정확한 5-8턴)

### 차용 패턴 (OFFERING·신규 작품 적용)
1. **대나무 숲 합궁 + 시계 인증 모델:** 1화 강제 만남 + 작은 물건(시계)이 정체 확인 = 2단계 인연 매개체 — 한국 vertical 비밀 아이 트로프 클래식
2. **할머니 = 알파 시댁 보호자 모델:** 시댁 어른이 가족 빌런 응징·시청자 정서 보강의 핵심 도구 (재벌 시댁의 한국식 따뜻함)
3. **외삼촌집 가족 모욕 시퀀스:** 외삼촌·숙모·사촌의 양육 빌미 학대 = 양녀 트로프의 한국식 표준
4. **외부 빌런 결혼 강요 시퀀스 (EP10-12):** 외부 빌런이 정신 결함 있어 시청자 즉시 분노 + 시댁 외부 강요 시도 → 태환 폭력 응징 페이월 결합
5. **신체 결함 (절름발이) + 외모 매력 결합:** 결함이 모욕 트리거 + 다리 치료 = 후반 회수 카드 (작품 페이즈 길게 운영)
6. **시댁 직장 등장 (EP86) = 클립 보상 정점:** 일상에서 갑자기 시댁이 직장에 등장해 공개 인정 — 한국 vertical 청취자 가장 사랑하는 반전 패턴
