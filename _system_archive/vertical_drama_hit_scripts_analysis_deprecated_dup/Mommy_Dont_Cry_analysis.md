### 1차 페이월 위치 추정 근거

- **EP6 끝**: 정신병원에서 4살 권서아가 죽은 엄마와 분리·"고아 주제에" 모욕 누적·권태환 도착 직전
- **EP7**: 권태환이 권서아를 집으로 데려가기로 결정 → "엄마 보고 싶지? 우리 집에 같이 가지 않을래?" → **권서아의 새 집 도착 = 새 가족 약속**
- **EP8 페이월 후크**: 진짜 권서아가 웨딩 사진 발견 → 권태환이 "지아의 딸인가?" 의심 → **하지만 가짜 권서아(최유나)가 울면서 권태환의 마음 가져감** → "이 아이가 누구의 진짜 딸인가?" 시청자 갈증 폭발
- 1-6화: 어린 권서아·죽은 엄마·악역 4년 누명·심장 이식 → **모든 비극의 정체와 진실이 9-10화에서 폭로 시작** (심장이 서지아의 것)

→ **EP7-8 사이가 강력한 paywall hook.** 권태환이 진짜 딸을 옆에 두고도 가짜 딸을 안고 있는 비극이 시각화되며 시청자가 "언제 진실 밝혀지나?" 결제.

## 1축 — 캐릭터 분석

### 여주 — 서지아 / 스칼렛 (이중 정체)

**상승 호 (`female_lead_rise_arc.md` 정합):**
- **1화 바닥**: 4년 정신병원 갇힘 → 의식 없이 누워 죽음 → 4살 딸에게 버림 받는 모습
- 1-6화 = 거의 죽은 사람 (목소리만 VO·편지로 등장)
- **8화 이후 부활**: 심장 재이식·죽었다 살아남 → 스칼렛이라는 이름으로 복수 시작
- **15-30화**: 점진 정체 폭로·전 남편 앞에 정체 가린 채 무력화
- **50화+**: 진짜 정체 공개·악역 완전 박살

**핵심 트리거 — "셈하는 여자" 룰 변형 적용:**
- 1화 = 무력 / 죽은 채 등장 (이입 트리거 최강)
- 8화부터 = 떨면서도 결단 (스칼렛 변신 = 거래의 시작)
- 30화+ = 셈하는 복수자

### 남주 — 권태환

**다크 로맨스 X / 후회·구원자 X 양면**:
- 비주류 다크 로맨스 패턴: **악역+남주 겸직** (서지아 4년 정신병원 보낸 장본인)
- 단, 진실 = 보호 의도 (경찰로부터 보호) → 후반 정체 공개 시 후회·구원자로 전환
- 매력 = **외부적 압도 (수백억 자산가 CEO·심장 이식 환자)** + **내부적 마비 (가짜 딸 키우는 멍청한 아버지)**
- **`dark_romance_male_predator.md` 정합 X** (이 작품은 다크 로맨스 X) — 단 그의 결정·후회·재집착 패턴은 동일 메커니즘

### 빌런 — 최나리 (구체적 개인 빌런 + 끝까지 가치 모름 100% 적용)

- **메인 빌런 = 1명 구체** (`concrete_villain_humiliation_loop.md` 절대 정합)
- 이름·얼굴·말투·구체 행동 (가짜 딸 둔갑·진짜 딸 학대·심장 기증자 행세)
- **끝까지 서지아·진짜 권서아 가치 모름** → "후회물 클리셰" 회피 절대 성공
- 마지막까지 권태환에게 "당신의 약혼녀" "심장 기증자" 행세
- 다층 보조 빌런: 윤혜정(시모)·최유나(가짜 딸)·하녀들·간호사

### 어린 권서아 (4살 친딸)

- **paid vertical 변종 — 아기 viewpoint character**
- 모성·연민·울분 트리거 최강 (한국 가족극 효도 판타지 유사)
- `clip_reward_loop.md` 정합 — "어린 아이가 가짜에게 자리 빼앗기는" 모욕 루프

## 2축 — 이야기 구조

### 압력축 1개 (`pressure_axis_stacking_vs_dispersion.md` 절대 정합)

> **핵심 질문 = "엄마와 딸이 다시 한자리에 모이는 진짜 가족이 언제 회복되나? + 가짜 빌런이 언제 공개 박살나나?"**

**기본 구조 (50화+ 가족 멜로):**
- 가족극 + 신분극 + 복수극 결합
- 압력축 = 진짜 딸·진짜 엄마·진짜 아버지의 분리 → 점진 재결합
- 70화 = 가족극 + 후반 복수 확장으로 길게 잡힘

### 모욕 루프 패턴 (5-8턴 누적 성공 사례)

**EP1 — 정신병원 분리 모욕:**
1. 4살 권서아가 죽은 엄마 시신 붙들고 울음
2. 간호사 1이 권서아를 양팔 잡고 "꼬마야, 네 아빠가 엄마를 여기로 보낸 장본인"
3. "이제 엄마가 죽었으니, 너도 같이 버려지겠지?"
4. 간호사가 권서아를 바닥에 내팽개침
5. "고아 주제에"
6. 두 간호사가 서지아 시신 위로 시트 덮음
7. 권서아 울음이 병실 가득
8. → **이입 트리거 최강** (멀티태스킹 시청자도 즉시 분노)

→ **`vo_flashback_pressure_tools.md` 5 조건 충족**: 구체적 인간·즉시 발화·모욕 시각화·페이월 직전·인지 가능

### 클립 보상 루프 (`clip_reward_loop.md` 정합)

**원초 쾌감 = "진짜 딸(피해자)이 가짜 딸(가해자)을 자리에서 밀어내는 순간"**

| 회차 | 클립 보상 (같은 쾌감 다른 상황) |
|---|---|
| EP1-6 | 진짜 권서아 모욕 누적 (정신병원·새 가족·외면) |
| EP7-15 | 첫 가족 자리 → 즉시 박탈 (방·식탁·아빠 사랑 모두 가짜에게) |
| EP16+ | 계단 추락·죽음 직전·서지아 부활 → 점진 역전 |
| EP28-30 | 가짜 딸 정체 폭로 시도 (스칼렛 등장) |
| EP50+ | 공개적 박살·최나리 무너짐 |

→ 공개성·지위·관계·보상 크기 점진 확장

### 페이월 구조 (행동 직전)

- **약한 paywall 회피** (진실이 뭘까? X)
- **강한 paywall** (행동 직전):
  - 권태환이 가짜 딸 안고 진짜 딸 등 돌릴 직전
  - 가짜 딸이 권서아 계단에서 밀 직전 (16화)
  - 스칼렛이 정체 공개하기 직전 (28-30화)

## 3축 — 대사 스타일

### 직관·기능 100% (`paid_vertical_dialogue_rules.md` 절대 정합)

**채택 패턴 (들으면 장면 즉시 보임):**
- 간호사: "꼬마야. 네가 말하는 그 '아빠'라는 사람이 몇 년 전에 네 엄마를 여기로 보낸 장본인이야." (사실 나열·권력 우위 한 줄에)
- 권서아: "안돼, 우리 엄마 만지지 마! 우리 아빠 곧 올 거야. 아빠가 나랑 엄마랑 같이 집으로 갈 거라고!" (4살 정체성·기다림·결과 즉시 보임)
- 권태환: "(이를 악 물며) 네 죗값을 치르기 전엔, 절대 못 가." (분노·결정·다음 사건 보임)
- 최나리: "네가 여기 오면 공주라도 될 줄 알았니? 멍청하기는... 넌 이 집에서 제일 작고 제일 어두운 방에서 자게 될 거야." (모욕·예고·미래 컷 보임)

### 시적·은유·연극톤 0건 (절대)

- 모든 대사 = 사실·욕망·결과 직접
- 분위기 단어 (영혼·운명·그림자·storm·shadow·soul) **검출 0건**
- 멀티태스킹 시청자가 화면 안 봐도 흐름 이해 가능

### VO 활용 (한국 가족극 정합)

- VO 사용 빈도 높음 — **단 모두 구체적·즉시 이해 가능** (5 조건 충족)
- 권태환 V.O.: "이 아이가 설마... 지아의 딸인가?"
- 최나리 V.O.: "내가 질 게 뻔할 싸움을 할 것 같아?"
- 모두 다음 사건 직접 안내

### 한국 가족극 특수 — 4살 아이 voice

- 권서아 voice = **순수·기다림·믿음 + 모성 자극** 디자인
- "엄마, 일어나!" / "아빠, 우리 엄마야!" / "엄마... 엄마, 보고 싶어"
- 어린 아이 voice가 **이입 트리거 + 모성 trigger 동시** 달성 (한국 멜로 정합)
