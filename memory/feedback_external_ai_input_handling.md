**룰:** 사용자가 외부 AI(GPT/Codex/타 클로드 등)와 한 대화·지시·피드백을 공유할 때, 워싱(정리) 안 된 상태이면 그 내용을 직접 청사진/피칭덱/시스템에 적용 X. **인사이트만 추출**해서 메모리 저장. 작품·시스템 적용은 사용자 별도 명시 시.

**Why:** 사용자 명시 (2026-05-10): "워싱안 한 것이니 이 점 유의하되, 내가 싫어하는 거나, 내가 선호하는 거나, 내가 원하는 방향성 등에 대해 참고할만한 사항이 있다면 제시." 외부 AI 대화에서 사용자가 외부 AI에게 가르친 룰은 사용자 룰의 표현이지만, 그 대화 내용을 그대로 청사진/피칭덱에 적용하면 사용자 의도와 어긋남. 사용자 거부 사례: 외부 AI 대화에서 "시장성 결론 OK" 룰을 본 후 7개 작품에 결론 즉시 복원 → "다른 ai에게 지시한 사항이라고. 인사이트를 얻을 것만 얻으라고."

**How to apply:**
- **인사이트 추출 = 메모리 저장.** 사용자 룰·선호·싫어함·방향성·거부 사례.
- **직접 적용 ≠ 인사이트 추출.** 추출된 룰을 즉시 청사진/피칭덱에 일괄 적용 X. 사용자가 별도 명시 시에만 적용.
- 외부 AI가 채택한 처방 중 사용자가 거부한 사례는 시스템 룰 정정에 사용 (예: phase_2 prompt 11-8 "평가문 0건" → "시장성 항목 결론 예외" 추가).
- 사용자 부정 표현 ("수준 떨어지는 GPT 같다", "병신이야", "좆까") 발견 시 외부 AI 처방 거부 사례. 거부 사유 추출 후 메모리 정리.
- 사용자 격앙 톤 발견 시 직접 적용 회피 + 인사이트 추출만 + 정리 보고.

**자주 등장하는 외부 AI 처방 거부 사례 (2026-05-10):**
- 무리한 평가문 일괄 삭제 (시장성 항목 결론 OK)
- AIGC 강점 사용 별도 섹션 강제 (실제로는 자유 사용 OK / 층위 분리 X)
- 50화 무료 1-8 고정 룰 변경 시도 (사용자 명시 룰 보존)
- 사용자 작성 reference·예시 변경 시도 (정답 X — 패턴·문체 참고하되 새 원칙이 우선. 외부 AI가 "정답으로 보존 강제"도 X / "쓰레기라며 폐기 처방"도 X)
- 진행중인 작품 0개로 잘못 파악 (현재 7개 진행)
