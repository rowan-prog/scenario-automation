# 애니메이션 stylized genre English 허용 룰

## 핵심 (사용자 명시 2026-05-15)

> **"대사 관련 영어 규칙 중, 애니메이션은 캐릭터, 세계관, 타깃에 따라 부분적으로는 stylized genre English여도 괜찮다. (동양풍 시노비 캐릭터라던지 등)"**

기존 룰 (남성향 seinen anime 한정)에서 **확장.** 시노비·사무라이·신화·다크 로맨타지·사이버펑크 등 캐릭터·세계관·타깃이 stylized 톤을 자연스럽게 흡수하는 작품에서 부분 허용.

## 톤 결정 트리

진입 시 자문 3 질문:
1. 작품 **타깃**이 stylized 톤에 익숙한가?
2. **세계관**이 stylized cadence를 자연스럽게 흡수하는가?
3. **캐릭터**의 정체성이 stylized 톤을 요구하는가?

- 3개 모두 Yes → stylized 허용
- 1-2개만 Yes → 부분 허용 (해당 캐릭터·해당 씬만)
- 모두 No → Native English 강제

## 허용 표현

- 양식화된 선언형·과장된 power lines·변신·각성 외침
- 적을 향한 도발·결투 선언·이름 외침
- 고전·신화풍 cadence ("By the gods...", "I claim this...")
- 양식화된 호칭 ("my lord", "elder", "master" — 세계관 fit 시)
- 시노비·사무라이 톤의 절제된 short lines + 양식 cadence

## 매체 무관 절대 금지 (stylized fit 작품에서도 동일)

- 어색한 번역투 (의도 아닌 실수로 들리는 번역 느낌)
- 한국어·일본어 사고 직역
- 직역식 자기 소개 (`"My name is X. I am Y."`)
- honorific 잔존 ("-san", "-sama" 영어 대사 안에 그대로)
- 일본어 문장 구조 그대로 영어 (syntax 영어식 재구성 필요)

## How to apply

- **phase_4 (집필) 진입 시:** 톤 결정 트리 3 질문 자가 답 → stylized OK / Native 강제 결정
- **phase_5 (검토):** persona 04 (English Dialogue) 자동 trigger — fit 안 맞는 stylized = 🟡, 의도된 stylized fit = 🟢
- **04 페르소나 검토 룰:**
  - 현대 모던 여성향에 stylized 잔존 = 🔴 (즉시 수정)
  - 시노비·사무라이 작품에 Western native만 = 🟡 (캐릭터 정체성 약화)
  - 의도된 stylized cadence가 fit하면서 어색하지 않다 = 🟢
