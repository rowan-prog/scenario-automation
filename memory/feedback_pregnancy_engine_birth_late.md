# 임신·출산 위치 — 50화 vertical drama 구조 룰

## 핵심 룰 (THE OFFERING v21→v32 학습)

**출산은 EP48-49. 후반 epilogue ≤ 7화 (14%).**

**Why:** THE OFFERING v31.4까지 출산이 EP25-26에 있었다. 결과: EP27-50 = 24화 (48%)가 afterstory 톤. ReelShort/DramaBox 시청자는 결제 retention이 끊겼다. 사용자 진단: "에피소드 절반이 후일담 수준이다." 시장 표준은 후반 epilogue 3-5화. 22-24화는 *시장에서 작동 안 함*.

**How to apply:**
- 50화 작품 → 출산 EP48-49 권장
- 60화 작품 → 출산 EP56-58 권장
- 70화 작품 → 출산 EP65-68 권장
- 핵심 비율: **post-birth ≤ 14% (1/7)**

## Fantasy device — 비현실 임신 기간 정당화

**룰:** 북미 다크 로맨스 시장은 *마법적 임신 timeline*을 *환영*한다 (Twilight·ACOTAR·werewolf romance 모두 검증).

**기준 device들:**
- **드래곤 자식 = 20 cycles (≈ 20개월).** Body shows after cycle 10. Bond glows from cycle 1.
- **Werewolf 자식 = 7개월 (단축).** 빠른 임신·보호 본능 극대화.
- **Vampire 자식 = Twilight 패턴 (3개월·급속).** 산모 위험·반쪽 hybrid 위기.

→ 작품 시작 시 fantasy device 명시. 시청자 첫 화에서 "이 작품은 인간 임신이 아님" 받아들임. 이후 timeline 자유롭게 설정 가능.

## 거부 패턴 (THE OFFERING v31.4 reverse engineering)

**v31.4가 작동 안 한 이유:**
1. 인간 9개월 임신 = EP13 reveal → EP25 birth (12화 만에) = 너무 빨라서 후반 24화 epilogue
2. 후반 24화에 외부 갈등 없음 (모든 빌런 EP21에 처치 완료)
3. Mireille age beats (newborn→3개월→4개월→11개월→3세→4세) = 시청자 결제 동력 없음

**같은 작품으로 받지 말 것:**
- 인간 임신 timeline (9개월 = 12화 안 됨) + 후반 24화 가족 비트
- 모든 외부 빌런 중반 처치
- Mireille age beat 8개 이상
