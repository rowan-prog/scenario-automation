## 절대 공통 패턴 (24 작품)

### 1. 메인 빌런 1명 + 보조 빌런 5-7명 (구체적 환경)
- 추상 빌런·집단·시스템 = 0건
- 모두 얼굴·이름·구체 모욕·끝까지 가치 모름 (또는 충분히 오래)

### 2. 메인 빌런 2 Type (Subagent D 발견)
- **Type A (단일 명료):** 천재 아기·한류스타·Mommy / **OFFERING 권장 = HARRIN**
- **Type B (환경 다층):** 의붓남매·토깽이·陷入她的热恋

### 3. 여주 1화 = 처절 바닥 + 저항 + 무시 받음
- 완성형 0건 / 무력 매달림 0건
- 신체·사회적 결함 (벙어리·양녀·미혼모·절름발이·뚱뚱·시한부) + 매번 저항 + 빌런 무시
- 매달림·울음 = 정직한 처지 표현 (1-2회)

### 4. 시청자 정보 비대칭 (Subagent C 발견)
- 시청자만 정체·자원·결과 안다 / 빌런 끝까지 모름
- **로맨스 차원:** 시청자만 두 주인공 마음 안다 / 둘은 서로 모름

### 5. 시그니처 호칭 절대 필수 (Subagent D 발견)
- "꼬맹아"·"토깽이"·"사모님"·"이 못 배워먹은 년" 등
- LOCKED OUT: "Boss"·"Sir"·"my lord"
- **OFFERING: "Little offering" → "Mine" → "My bride" 3단계 진화**

### 6. 페이월 = 발화 + 행동 + 결과 (Subagent D 발견)
- 단순 발화 X
- 발화 + 즉시 행동 + 가시 결과 + 다음 훅

### 7. Pattern A·C 페이월 정점 대사 (Subagent E 발견)
- **Pattern A (사실 나열):** "이혼해요. 그런데, 내가 당신을 버리는 거야."
- **Pattern C (최후통첩):** "넌 내 인생 최악의 실수야"

### 8. 보조 빌런 = 매 EP 신규 등장 클립 보상 재포장 (Subagent E)
- 점원·매니저·라이벌·신부 후보 등
- 같은 박살 패턴 다른 인물·다른 상황으로 재포장

### 9. 페이월 위치 결정 패턴 (Subagent C 발견)
- 외부 강자 진입 직전 60%
- 권력 박탈 정점 40%

### 10. 5-8턴 모욕 교환 (24 작품 전체)
- 2-3턴 인장 X / 5-8턴 누적
- 가해자 까기 → 다시 까기 → 추가 모욕 → 여주 굴욕 → 남주 도착 → 폭발 → 후처리

### 11. VO + 플래시백 + 청각 브릿지 (Subagent B 발견)
- 멀티태스킹 시청자 청각 최적
- 보조 인물 2-3명 = 청각 브릿지

### 12. 시적·연극톤 0건 (24 작품 전체)
- 정체성 punchline 1-2/50 한도만
- 일상 어휘·즉시 이해

### 13. 한국형 알파 보호자 vs 서양 짐승 직진 (Subagent B 발견)
- **한국 vertical:** 즉시 보호자 + 통제·후회·회수
- **서양 다크 로맨스 (OFFERING):** 멈추지 못하는 포식자 (절제 X)

### 14. 한국 vertical 3축 (Subagent B 발견)
- 가족(나쁨) → 남주(보호) → 시댁(인정)

### 15. 회귀 + 신분 반전 = 영어 매출 최강 (Subagent A 발견)
- MarriedDon: 회귀자 빌런 + 가난한 남자가 사실 Don = 3중 트리거

## 카테고리별 특수 패턴

## 시청자 결제 동력 정수

### 공통 (장르 무관)
> **"잘못된 사회적 판결이 깨지는 순간"** (오판→증거→공개역전 루프)

### 한국 vertical 정수 (Subagent B)
> **"여주가 양녀·미혼모·결함 있는 처지에서 시댁·재벌 보호자에 의해 정식 안주인 위치를 공개적으로 받고, 모욕한 가족이 공개 박살나는 모습을 보고 싶다."**

3 요소:
1. 여주 정식 안주인 공개 인정 (시댁 발화·외부 모두 인정)
2. 가족 공개 박살 (폭력·재산·체포·사망 4단계)
3. 남주 후회·집착·통제·보호

### 영어 vertical 정수 (Subagent A)
> **"숨겨진 정체가 결정적 순간 폭로되어 빌런이 공개 박살된다."**

회귀 + 신분 반전 + 자제 깨짐 = 매출 최강 트리거
