# 작품 자가 평가 함정 6가지

## 배경

v31.4 평가 시 *"A+/S- 직전"* 판정. 그러나 사용자가 정량 분석으로 진단: 22 화 (44%) afterstory tone. 실제 등급 *"B+~A-."*

이건 *내적 정합성*과 *시장 retention*을 분리 측정 안 한 오판이다. 같은 오판을 회피하기 위한 함정 리스트.

## 함정 1 — 초반 무료회차 인상에 끌림

**증상:** EP01-08이 잘 만들어졌으면 *전체*가 좋아 보인다.

**대응:** 평가 시 EP1-8 / EP9-EP21 / EP22-EP35 / EP36-EP50 *각 1/4 구간 별도 점수*. 한 구간이 9+이고 다른 구간이 7-이면 전체는 7-에 가깝다 (vertical drama 시청자는 약한 구간에서 이탈).

## 함정 2 — 정량 후일담 비율 미측정

**증상:** "후반이 좀 늘어진다" *주관 인상*만 갖고 평가.

**대응:** Post-payoff (출산 후 / 메인 빌런 처치 후) 화수 / 전체 화수 *정량 계산*. 비율:
- ≤ 14% = 권장
- 14-25% = 위험 신호
- > 25% = 즉시 재구조 필요

**규칙:** 후일담 비율 25% 초과 시 평가 등급 *자동 한 단계 하향* (S→A·A+→A 등).

## 함정 3 — 특정 강화된 장면에 가중치 과다

**증상:** EP01 콜드오픈·EP09 paywall·EP50 finale 같이 *튀어 보이는 장면*이 좋으면 전체가 좋아 보인다.

**대응:** *튀는 장면 외 평균 장면*의 디테일·정합성도 별도 점수. 평균 장면이 약하면 전체 작품 retention은 결국 평균에 수렴.

## 함정 4 — 작가 의도와 시장 작동 혼동

**증상:** "작가는 *닫힌 가족 천국*을 원했고 그 의도는 작품에 잘 구현됐다 = 좋은 작품" 판단.

**대응:** *작품 정체성 ≠ 시장 retention*. 두 평가를 *분리*:
- **정체성 평가:** 작가 의도 구현도 (A+ 가능)
- **시장 평가:** ReelShort/DramaBox/NetShort 결제 retention 가능성 (별도 점수)

작가가 "정체성 우선"을 의식적으로 선택하면 시장 약화 인정·수용. 그러나 *시장 약화 사실 자체*는 평가에 반드시 명시.

## 함정 5 — Production lock 단계 잘못 표시

**증상:** "production lock 직전" 표현이 *내적 정합성 lock*과 *시장 lock* 둘 다 의미하는 것처럼 보임.

**대응:** Lock 단계 표기 *명시적 분리*:
- **Internal Lock:** 작품 내적 정합성·캐릭터·plot 모순 0 (= S- 이상)
- **Market Lock:** ReelShort/DramaBox/NetShort 시장 retention 기준 4 구간 (free arc·early paid·mid-arc·late-arc) 모두 ≥ 7.5
- **Production Lock:** Internal + Market 둘 다 통과

→ 평가 시 *어떤 lock인지* 반드시 표기. v31.4의 경우 = Internal Lock yes / Market Lock NO / Production Lock NO.

## 함정 6 — 외부 비판을 *작품 강화 의견*으로 합리화

**증상:** "후반이 길다"는 비판을 받았을 때 "닫힌 천국이 작품 정체성이라 의도된 거임" 같이 *합리화*.

**대응:** 외부 비판이 *정량 데이터*를 동반하면 (예: "22화 = 44%") 합리화 불가. *재구조 권고*를 받아들여야 한다. 합리화 = 다음 평가에서도 같은 함정.

## v31.4 → v32 학습 정리

| 학습 | 적용 |
|---|---|
| **함정 1 회피:** EP01-21 강도에 끌리지 말 것 | 4 구간 별도 점수 도입 |
| **함정 2 회피:** 후일담 비율 정량 측정 | v31.4 = 48% → 자동 등급 하향 |
| **함정 3 회피:** 평균 장면 디테일 별도 평가 | "Bed. Hand on belly. Both quiet." 같은 thin 비트 카운트 |
| **함정 4 회피:** Identity vs Market 분리 | v31.4 = Identity A+ / Market C+ |
| **함정 5 회피:** Lock 단계 명시 | "Internal Lock 직전 / Market Lock 아님" |
| **함정 6 회피:** 합리화 거부 | 22화 epilogue → 구조 재설계 |

## 평가 형식 — 다음 작품부터 권장

```markdown
## 평가 (작품명 vX)

### 정량 데이터
- 총 화수: N
- Post-payoff 화수: M (M/N = X%)
- "I love you" 발화 횟수: Y (목표 ≤ 6)
- 신 평균 길이: 80-100 lines (목표 50-150)
- Thin 비트 ("X. Y. Both quiet." 패턴) 개수: Z

### 구간별 점수 (1-10)
- EP1-1/4 (무료 + 초반 유료): X
- EP1/4-1/2 (mid-arc 진입): Y
- EP1/2-3/4 (mid-arc 후반): Z
- EP3/4-end (후일담): W

### Lock 단계
- Internal Lock: yes/no
- Market Lock: yes/no
- Production Lock: yes/no

### 1 줄 평가
[명확한 한 줄]
```

## 한 줄

> **자가 평가 = 정량 데이터 + 구간별 점수 + Lock 단계 명시. 초반 인상·합리화는 함정.**
