# 🔥🔥🔥 Vertical Drama 핵심 7 룰 (사용자 직접 분석 채택)

## 사용자 명시 (2026-05-17)

> "히트작들은 장르가 달라도 거의 같은 기계를 쓴다. 표면 장르는 다르지만 실제 작동축은 비슷하다. 누군가 주인공을 잘못 판정한다. 그 판정이 말로 박힌다. 모두가 그 말을 듣는다. 시청자는 그 판정이 곧 깨질 증거를 본다. 가해자가 더 깝친다. 공개적으로 뒤집힌다."
>
> **히트작은 "멋진 세계관"보다 "잘못된 사회적 판결이 깨지는 장면"을 판다.**

## 핵심 메커니즘 (절대)

```
1. 오판 (잘못된 사회적 판결)
   ↓
2. 가해자가 얼굴 있는 말로 박음
   ↓
3. 모두 듣는다 (목격자)
   ↓
4. 시청자만 깨질 증거 본다 (정보 비대칭)
   ↓
5. 가해자가 더 깝친다 (5-8턴 누적)
   ↓
6. 증거물 + 권력 등장 (발화 + 행동 + 결과)
   ↓
7. 공개적으로 뒤집힌다 (오판 1개 완전 깨짐)
   ↓
8. 다음 오판으로 이동 (보조 빌런 = 새 모욕 장소)
```

## 7 핵심 룰

### 룰 1 — 페이월은 발화 + 행동 + 결과다 (절대)

❌ **약한 페이월:** 멋있는 발화만
- "나는 네 것이다."
- "나는 돌아왔다."

✅ **강한 페이월:**
- **발화** + **즉시 행동** + **눈에 보이는 결과** + **다음 결제 훅**

**예:**
- "엄마, 이혼해." → 도장 찍음 → 아빠 쫓겨남 → 은행/주식 훅
- "증거 있어?" → 녹음파일 재생 → 악역 도망 못 감 → 더 큰 공개 망신
- "Don't touch what's mine." → 손 막음·계약 위반 발동 → 가해자 공개적 밀림 → 다음 보상

→ **단순 인장 대사 = 페이월 자격 X.** 행동·결과 결합 절대.

### 룰 2 — 첫 N화 안에 "오판 1개"는 완전히 깨져야 한다

- 오판 = 1개 (여러 개 X / 시청자 분산)
- 무료 마지막 회차에 **완전히 깨야 함**
- 우회적 X / 직접 X **공개 판결 깨짐**

**예:**
- 천재 아기 = "저 주식은 망한다" → 뉴스 속보로 올랐다 (단순·완전)
- Demon Lord (실패) = "에블린은 가짜다" → 낙인·루시엔 등장 (우회·불완전)
- 좋은 Demon Lord = 가짜 몰아감 → 계약 원문·제단 기록·사망 공고 모순 → 공식화 → 부정 → 위반 낙인

### 룰 3 — 모욕은 5-8턴 누적 (영화 인장 X)

❌ **영화 인장 (2-3턴):**
- "Get out." / "I will."
- 멋있지만 압력 부족

✅ **vertical 5-8턴 누적:**
1. 가해자 깐다
2. 주인공 작게 저항
3. 가해자 더 깐다
4. 주변 사람 수군거림
5. 주인공 다시 버틴다
6. 가해자 선 넘음
7. 증거/남주/권력 등장
8. 가해자 부정·도망 시도
9. 녹음·카드·뉴스·친자확인서·VIP 권한 나옴
10. 공개 무너짐

→ **참교육 전 가해자 충분히 떠들어야** 시원함.

### 룰 4 — 정보 비대칭 = 결제 동력 씨앗

- **시청자만** 핵심 정보 (정체·자원·결과) 안다
- **악역은 끝까지 모름** (또는 충분히 오래 모름)
- 시청자는 알고 기다림 → "언제 들키냐? 언제 망신당하냐?" = 결제

**예:**
- 저 아이가 미래를 안다
- 저 남자가 사실 재벌이다
- 저 여자가 진짜 아내다
- 저 가난한 남자가 사실 Don/CEO다
- 저 목걸이·사진·아이·문서가 나중에 터진다

### 룰 5 — 시그니처 호칭 = 관계 고정 장치

호칭이 관계·권력·소유·애착을 표시:
- 꼬맹아·토깽이·사모님·아가씨·대표님
- Boss·Sir·my lord
- 우리 엄마·내 아내·내 딸

**원칙:**
- 1-2개 정해서 **반복 사용**
- 관계 변화에 따라 **의미 변화**
- 만화적 X / 작품 톤 정합

**LOCKED OUT 예 (잘 됨):**
- Seraph → Boss / Ariel → Sir / Lilith → my lord (각자 관계 질감)

**Demon Lord 예 (부족):** 루시엔-에블린 고정 호칭 X / "what's mine"은 장면 대사로만

### 룰 6 — 보조 빌런 = 새 모욕 장소 (새 플롯 X)

보조 빌런 기능 = **새 플롯 X / 같은 원초 쾌감 다른 장소 재포장**

**좋은 보조 빌런 패턴:**
1. 집 안에서 무시 → 은행 무시 → 백화점 무시 → 레스토랑 무시 → 투자 설명회 무시 → 회사 무시 → 기자회견 무시 → 법/경찰/재벌가 앞 무너짐
2. 매장 직원·호텔 직원·기자·시댁 식구·라이벌·친척 등 다양

→ **공개성 커진다** (같은 쾌감 다른 무대)

### 룰 7 — 카테고리별 페이월 위치는 참고만

- 빠른 사이다물 = EP5-7
- 정체 폭로물 = EP8-10
- 영어 금기 로맨스 = EP12-14 가능
- 장기 후회물 = 더 늦어도 OK
- 한국 80-100화 = EP7-12
- 동양 사극 빙의 = EP5-8

**🚨 중요:** 회차 숫자가 아니라 — **"첫 결제 잠금 지점에서 시청자가 '다음 장면은 봐야 한다'고 느끼는가?"**가 핵심.
