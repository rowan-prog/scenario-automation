**원작 구조를 빌려 세계를 바꾸는 작업(세계 치환 모드)에서, "원작만큼 세게"는 "원작이 한 짓을 그대로"가 아니다.** 강도·기능·비트 자리는 원작 이상으로 가져가되, **행위는 새 세계가 아니면 못 하는 것으로 발명**해야 한다.

**Why:** 26_get_off_my_ship에서 같은 실수를 두 번 했다. v3에서 사용자 지적("너무 스페시픽하게 동일 금지 — 기능 동일·행위만 다르게")으로 원작 행위를 전부 치환해뒀는데, v8에서 "막장 강도가 약하다"는 지적을 받고 강도를 올린다며 **원작 행위를 도로 가져왔다**(얼음 버킷·깨진 유리 위 무릎·승마 채찍·얼굴 처박기). 원작을 정독해 강도를 재면 손쉬운 답이 원작 행위 자체라서, 강도 보정 라운드가 곧 행위 복사 라운드가 된다. 이게 함정.

**왜 헷갈리나 — 모드가 두 개인데 룰이 정반대다.**
- **각색 모드**(같은 작품을 다른 언어·문화로 옮김 · 13_janitor·16_moses): 원작 대사 verbatim 최대 계승, 억지 변경 금지 = [[adaptation-copy-source-dialogue-verbatim]] [[adaptation-conservative-no-forced-rewrites]]
- **세계 치환 모드**(구조·비트·감정 곡선만 빌리고 세계를 갈아끼움 · 22_the_crown·26_get_off_my_ship): 구조는 1:1, **행위·소품·대사는 전부 새 세계 것으로 재발명**

작업 진입 시 어느 모드인지 먼저 못 박을 것. 섞으면 각색 쪽에선 원작을 훼손하고, 치환 쪽에선 원작을 표절한다.

**How to apply:**
1. 치환 모드에서는 **소품 반입 금지 목록**을 애셋 항목에 명시한다(26번 = "육지 소품(채찍·유리 파편·수조) 반입 금지").
2. 강도 보정 라운드에서 원작을 다시 읽을 때는 **행위가 아니라 기능만 적어서** 대조표를 만든다 — "얼음 버킷"이 아니라 "첫 물리 · 옷과 몰골을 망가뜨려 표식을 만든다". 기능으로 적어야 새 행위가 나온다.
3. 치환하면 원작보다 나아질 여지가 생긴다. 26번 실증: 새 세계 소품(검역 소독→홀리스톤→젖은 밧줄→소금물→배수구→은식기 워머)으로 갈아끼우니 **개별 고문의 나열이 한 사슬**이 됐다. 앞 화 상처가 다음 화 흉기가 된다. 원작엔 없던 인과다.
4. 발상이 막히면 [[occasion-hopping-space-economy]] 컨테이너 안의 물성부터 센다 — 그 공간에 실제로 있는 것만으로 사다리를 짠다.
5. **자극 소재의 1차 관문 = 위험이 그림만으로 읽히는가.** 실제 위험도가 아니라 화면 가독성이다. 원작 전기뱀장어 수조가 무서운 건 화면에 들어오는 순간 관객이 설명 없이 아는 것 + 파란 방전이라는 가시 자극이 있어서다. 26번에서 "밤바다에 밧줄로 매달아 끌기"를 냈는데 실제 위험도는 살인급이 맞아도 **어두운 물은 그냥 물로 보여서 자극이 증발**한다 → 선미 스크루(하얗게 갈리는 물·밤에도 보임·굉음)로 교체. 같은 라운드에 낸 "랍스터 탱크"는 사용자에게 "예능 게임이냐"로 반려됐다 — 소재의 실제 위험도만 보고 그림을 안 본 결과. **위험을 증명하는 1초 컷을 반드시 하나 심을 것**(구두 한 짝이 거품에 닿는 순간 사라진다 = 방전의 대응).
6. **에스컬레이션은 화마다 한 칸씩, 꺾이는 데 없이 — 이게 기본**(사용자). 사다리를 다 짜고 나서 **강도가 내려앉는 화가 있는지 반드시 역검**한다. 26번 실증: 한 화에 두 개를 몰아넣으면 다음 화가 상대적으로 약해져 곡선이 꺾인다 → 분산해서 뒤로 내린다. 축은 하나가 아니다 — 몸에 가하는 것 / **되돌릴 수 있는가**(씻으면 됨→아뭄→영구 흉터→죽음) / 가해자가 직접 하는가 / 구경꾼 반응, 넷이 같이 올라가야 체감된다.
