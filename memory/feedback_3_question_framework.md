## 3 질문 (필수)

### Q1. 시청자가 진짜로 기대하는 것은 무엇인가?
- 작품의 **메인 환상·최종 macro reward**
- 시청자가 "결국 이걸 보고 싶다"는 것
- 작중 인물 시점 X / **시청자 시점**

### Q2. 기본으로 제시되어야 하는 것은 무엇인가?
- **장르 약속** — 초반 (EP1-3·무료회차 전반) 제시 필수
- 유예하면 = 장르 이탈·하수
- 시청자가 "이 작품은 이걸 줄 수 있구나" 즉시 알아야

### Q3. 무엇을 약속하되 유예시킬 것인가?
- **유료 EP9+ macro reward** — 무료에 X
- 무료에서 약속만 / 유료에서 완성
- 시청자가 결제 안 하면 못 견디는 보상 임박

- 3 질문 답 본 청사진에 명시
- Q1·Q2·Q3 별도 섹션

### phase_2 (피칭덱)
- 3 질문 답을 트리트먼트·로그라인·줄거리에 직접 반영

### phase_3 (완성 청사진)
- 3 질문 답 EP별 매핑:
  - Q2 기본 제시 = EP1-3·무료 전반
  - Q3 유예 = 유료 EP9+ 분산
- 청사진 12-2 핵심 엔진에 3 질문 답 통합

### phase_4·protocol Step 3 (집필)
- 매 EP 자가 답: "Q2 기본 제시 충분?" / "Q3 macro reward 노출 X?"
