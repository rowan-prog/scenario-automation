# 시청자/타깃 자료 — 3단계 활용 (검증 + 집필 + 피칭 근거)

## 핵심 룰 (사용자 명시 2026-05-11)

> **지금까지 주던 시청자 관련한 수많은 내용들은, 검증, 집필 둘 다에 활용하는 거야. 청사진의 경우, 작품 설계, 피칭덱의 경우, 작품은 거의 청사진 초안에서 가져오니, '이 IP로 피칭하는 이유'에 대해, 타당한 근거들을 마련하는 것이다.**

## 활용 3단계

| 단계 | 활용 영역 | 자료 사용 방식 |
|---|---|---|
| **1. 집필 (청사진 초안·완성·스크립트)** | 작품 설계 | 카테고리·트로프·결제 동기·5대 엔진·10 결제 패턴·보상 루프 본질·핵심 욕망 직접 설계에 적용 |
| **2. 피칭 근거 (피칭덱)** | **"이 IP로 피칭하는 이유"의 타당한 근거** | 시장 데이터·소비자 통계·검증 사례·카테고리 시장 폭·결제력 근거를 피칭덱 본문에 직접 활용 |
| **3. 검증 (페르소나·검수)** | 검수 단계 진단 | persona_08·09 진단 기준·이탈 코드·자가 검증·LOCK/PATCH/HOLD verdict |

## 피칭덱 = 청사진 초안 본문 + 피칭 사유 근거

**중요 인지:**
- 피칭덱은 청사진 초안에서 본문(인물·줄거리·트리트먼트·로그라인) 거의 그대로 가져옴
- **피칭덱에서 새로 작성하는 핵심 = "이 IP로 피칭하는 이유" 섹션**
- 이 섹션 = **시청자/타깃 자료 + 시장 검증 + 카테고리 결제력 + 변별력의 근거 마련**

## 자료 사용 시 주의

- ❌ **자료 도식적 복붙 X** — 인사이트만 추출. 데이터는 핵심만.
- ❌ **플랫폼명·시장 데이터 본문 박제 X** (참조 `feedback_pitch_marketability_definition.md`)

- ✅ **작품 안 사건과 결합** — 자료는 근거, 사건은 작품 안
- ✅ **위원 가상투표 가중치 인지** — 매력 70%·트로프 15%·결제 10%·QA 5% (참조: `feedback_hook_density_vs_qa_weighting.md`)

## How to apply

- phase_1 (청사진 초안) — 타깃 자료를 작품 설계에 직접 적용 (보상 루프·트로프·결제 동기)
- phase_2 (피칭덱) — 피칭 사유 섹션에 타깃 자료를 근거로 제시. 카테고리 검증·글로벌 IP·결제 동력·시장 공백 4축 활용
- phase_3·phase_4 — 작품 설계 디테일에 타깃 자료 룰 강제
- phase_5 (검수) — persona_08·09 진단 + 타깃 자료 자가 검증
