# 🔥🔥 클립 보상 루프 (paid vertical 보상 메커니즘)

## 핵심 한 줄

> **같은 쾌감을 반복하는 게 아니라, 같은 쾌감을 더 잘 팔리는 장면으로 계속 갈아입히는 형식.**

## 사용자 명시 (2026-05-17 — 천재 아기 인생역전 분석)

> "이 작품의 진짜 엔진은 회귀 복수가 아니라 '효도 판타지'."
> "구조가 고급스럽지 않아도 된다. 시청자가 기다리는 쾌감이 절대 흐려지면 안 된다."
> "매회 새로운 드라마를 만든 게 아니라, 같은 쾌감을 다른 상황에서 계속 재포장했다."

## 핵심 룰

### 1. 반복 ≠ 클립 루프

**반복 (약함):**
> 모욕 → 참교육 → 모욕 → 참교육 → 모욕 → 참교육 (똑같이)
> 리듬만 반복·상태 변화 X

**클립 루프 (강함):**
> 사적 무시 → 매장 무시 → 가족 무시 → 회사·사회 무시 → 공개 인정
> 같은 쾌감·다른 상황·점진 확장

→ **공개성·지위·관계·보상 크기가 매번 조금씩 커져야.**

### 2. 원초 쾌감 1개 선정 (불변)

성공작 = **하나의 원초 쾌감**을 정하고 끝까지 유지.

**천재 아기 인생역전 예시:**
- 원초 쾌감 = "엄마를 무시한 세상 앞에서, 회귀한 아들이 돈·정보·재벌 인맥으로 계속 이겨준다"
- 표면 사건 다양 (주식·부동산·백화점·재벌가·친부·사기) / 시청자 받는 쾌감 = 하나
- 효도 판타지가 진짜 엔진 (복수 < 효도)

### 3. 즉시 이해되는 감정 거래

시청자는 매번 복잡한 플롯 X / 짧은 구간마다 다음 감정 거래:

- "저 사람이 깔봤다."
- "곧 틀렸다는 게 드러난다."
- "망신당할 것이다."
- "내가 보고 싶던 장면이 온다."

→ 단순한 거래·즉시 이해·결제 동기

## 좋은 클립 루프 패턴 (장르 초월)

| 장르 | 결핍 → 반전 보상 |
|---|---|
| **복수극** | 모욕 → 공개 망신 |
| **로맨스** | 밀어냄 → 질투/소유욕 폭발 |
| **계약결혼** | 가짜 관계 취급 → 진짜 감정 노출 |
| **신분극** | 가짜/하급 취급 → 진짜 정체 인정 |
| **남성향 파워물** | 약자 취급 → 압도적 통제권 증명 |
| **여성향 재벌·마피아** | 버림받음 → 더 강한 남자의 선택 |
| **생존·스릴러** | 궁지 몰림 → 예상 밖 탈출/역전 |
| **가족극** | 버려진 사람 취급 → 진짜 가족으로 인정 |

→ 핵심 = 장르 X / **결핍 → 반전 보상**

## 좋은 반복 vs 나쁜 반복

### 좋은 반복 (클립 루프)

> 같은 쾌감을 다른 상황·다른 지위·다른 공개성으로 키운다.

천재 아기 예시 (시퀀스):
1. 사적으로 무시당함 → 단둘이 응징
2. 매장 직원에게 무시당함 → 백화점 부사장 등장 / 직원 해고
3. 가족 앞에서 무시당함 → 친부 등장 / 한민철 굴욕
4. 회사·사회적 자리에서 무시당함 → 재벌 회장 등장 / 모두 굴복

→ **공개성·지위·관계·보상 크기 점진 확장**

### 나쁜 반복

> 똑같이 무시당함 → 똑같이 참교육
> 또 똑같이 무시당함 → 또 똑같이 참교육 (변화 X)

→ 리듬 같음·상태 변화 X = 시청자 이탈
