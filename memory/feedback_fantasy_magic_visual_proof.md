## OFFERING (드래곤 lord 다크 로맨타지) 8 EP VFX 매트릭스

### EP1 — Black Gates / Storm / Dragon Silhouettes
**장르 약속:** "괴물에게 바쳐졌다"가 말이 아니라 **화면으로 보인다.**
- 도로 위 거대 wing-shadow → 호위 말에서 떨어짐
- Storm 위로 dragon silhouettes 비행
- Black Gates 자체로 열림 (마법)
- 인간 왕국 평원 → 멀리 산맥 위 Dragon Keep 압도적 대비
- 인간들이 진짜 겁먹는 스케일

### EP2 — Dragon Court 압도 미감
**장르 약속:** 인간 궁정과 다른 세계.
- Vael 등장 시 성벽 검은 불 한 줄 자동 점화
- Court 천장·기둥 = 인간 궁정 X / 드래곤 keep 압도
- 사신단·신하 무릎 꿇음 (VFX 압력)
- Vael 시선 한 번에 hall 횃불 검게

### EP3 — Vael 분노 = 탑 전체 반응
**장르 약속:** 분노 = 방 X / 탑·성 흔들림.
- Vael 분노 시 탑 전체 불 꺼짐
- 용 울음 성 전체 흔들림 (먼지·돌 떨어짐)

- 암살자 = 만지기도 전 숨 멈춤

### EP4 — Wall of Black Fire / Banner Ash Dragon
**장르 약속:** 사신단 도발 → 황무지 대재앙.
- 손짓 한 번 → 성문 밖 황무지 대지 쩍 갈라짐

- 사절단 뒤 하늘 흑염 뒤덮임

- 사신단 얼굴 벌겋게 익음 (열기 VFX)

### EP5 — 성탑 마법 반응
**장르 약속:** Vael과 Isolde 침실 = 일반 방 X / 드래곤 lord 거처.
- 분노·intimacy 순간 → 탑 전체 진동
- 창밖 멀리 드래곤 비행 그림자
- 마법 빛 = 단 한 번 (intimacy 정점)
- 비늘 등·팔 일부 변형 (Isolde 시점)

### EP6 — Great Hall VFX 압력
**장르 약속:** 공개 hall = 인간 X / 드래곤 lord 영토.
- Hall 횃불 일제 푸르게·검게

### EP7 — Council Chamber 압도

### EP8 — Mountain Dragon Army / Sonic Boom
**장르 약속:** 페이월 = 산맥·왕국·하늘 스케일.
