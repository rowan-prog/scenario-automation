**규칙 (2026-09-23 사용자 · 35 dragon_lord_s2):** 셀링 포인트는 로그라인을 다시 쓰는 자리가 아니다. 기획자에게 **이 작품이 어떤 장치로 시청자를 잡는가**를 장치의 이름으로 말한다. 사용자가 직접 쓴 실물 7개가 모델이다:
1. 시청자와 악역들 간 정보 비대칭, 여주가 당하는 고난
2. 출산 사실을 모르는 남주와 시청자 간 정보 비대칭
3. 여주가 용의 알 출산 ㅡ> 드래곤물에서 많이 워킹하는 알 출산/알/부화/해츨링 소구
4. 핍박받으면서도 알을 지키고, 부화 뒤엔 아이들을 지키려는 여주의 모성애로 시청자 자극
5. 나를 밟던 것들이 내 남편이 누군지 아는 순간 전부 엎드린다 ㅡ> 히든 아이덴티티 역전의 정석
6. 후반부에 남주가 큰 검은 용으로 등장하여 시각적 스케일감 확보(광고 컷 등)
7. 사내 히트작 시즌1 직속 후속 · 시즌1 시청자 승계

**종류(위 7개에서 역산):** 정보 비대칭(누가 무엇을 모르나 · 겹이 여럿이면 각각 한 줄) / 소재 소구(시장에서 지금 워킹하는 것을 이름으로) / 감정 자극(모성애·억울·후회 = 무엇으로 시청자를 건드리나) / 역전 장치(히든 아이덴티티·서열 역전 = 트롭 라벨 허용) / 시각 상품(광고 컷이 되는 스케일·그림) / IP 자산(시즌 승계·원작 히트).

**Why:** 내가 낸 것들은 ①로그라인 문장 재배열("짓밟는 여자가 드래곤 로드의 아내") ②우회 문구("보는 사람만 안다. 반지가 남편 손으로 가고 있다") ③서술문이었다. 사용자: *"셀링포인트를 어떻게 써야 하는지 좀 깨달아"* / *"이딴 우회적인 문구는 왜 쓰는 거야 뭐 어쩌라고"*. 기획자는 셀링 포인트에서 "무슨 이야기냐"가 아니라 "무엇이 팔리냐"를 읽는다.

**How to apply:** 셀링 포인트를 쓰기 전에 줄마다 "이 줄은 어떤 장치를 이름 붙였나"를 위 6종 중 하나로 답할 수 있어야 한다. 답이 "이야기 내용"이면 로그라인 되풀이다 — 지운다. 개수는 2~4가 기본이지만 장치가 실제로 여럿이면 7까지 허용(사용자 실물). 관련: [[t1-page-exemplars-whole-learning]] [[price-defines-the-spec]] [[fix-by-deleting-not-explaining]]
