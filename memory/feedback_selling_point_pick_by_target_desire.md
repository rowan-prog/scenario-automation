**규칙 (2026-10-16 사용자 · Codex가 만든 While My Wife's Away · The Mutant Mating Shelter · I Chose a Slave 시트에 화냄 → "넌 그런 일이 없도록 각별히 주의" → "셀링포인트 작성 스킬을 디벨롭해두라"):** 절차 = skill `/selling-point` · 규격 = `config/40_selling_point_standard.md` §0-2.

1. **고르는 이유는 한 줄 — "이걸 본 타깃이 무엇을 상상하게 되나 / 갖고 싶어지나"(타깃 속말로).** 웃기다·반전·감동·서사상 중요 = 포장이지 이유가 아님. 사용자: *"상황 자체는 코미디 같지만 실제 자극하는건 성적인 욕망이기 때문에 중요하다고 말한건데?"* 남성향 1순위 = 성적 욕망·상상(노출 없이도).
2. **벗지 않고도 야한 컷** = 첫인상 끌림·흥분 속마음 내레이션 + 시선·악수 → 최고 소재 중 하나(Wife's Away EP3·6 · *"노출 없고 성적행위 없이 자극적이라서 … 최고의 장면중 하난데"*).
3. **마지막 화라고 내리지 않는다** — Shelter EP50 "남자야? 남자라고? 남자!?" 여자들 우르르 = 가장 센 소재 중 하나인데 탈출 줄거리로 읽어 별 0. 잘한 것 = Shelter EP7 세라피나 다리 변신(*"섹시하고 신비롭잖아"*).
4. **캐논 설명 금지** — "모세는 신이 아닌 신의 대언자" → *"'신의 대언자'인게 소구포인트임?"* 판정 = 마케터가 알면 광고가 바뀌나. ⚠️ 우리 모세 CD1 v4 CAST에도 "실제로는 신의 대언자로" 줄이 있다(2026-10-16 손 안 댐).
5. **MKT·페이크 = 돈 테스트**(왜 멈추고·앱 깔고·결제하나). *"'논리'만 따진 건 아니고?"*
6. **고르기 = 모델·깊이 섞기(opus low · sonnet medium · opus high, 서로 안 봄) · 최종 감별 1기 = 심각한 오류·부정합만**(등급·소재 못 건드림). *"extra high로만 하면 창의성이 죽는 게 있기 때문임."*
7. **프로그램 코드 필수** — [[program-codes]] · 검증기 G20.

**Why:** Codex는 원문 대조(사실 확인)만 하고 소재 선별을 못 했다. 그리고 사용자가 이유를 설명하자 "반전·욕망·웃음"으로 범주화해 되돌려서 더 화를 돋웠다(*"말귀를 못알아 듣네… 진짜"*).

**How to apply:** 셀링포인트 작업은 `/selling-point`로만 진입. 사용자가 이유를 설명하면 **그 말 그대로** 받아 적고 범주어로 바꾸지 않는다. 빠진 최고 컷 하나를 짚으면 그 하나만 넣지 말고 전편 재선별. 관련: [[selling-point-sheet-format-is-the-spec]] [[selling-points-name-the-device]] [[agent-orchestration-tier-map]]
