## 가장 중요한 7 실패 모드 (섹션 2)

### 2.1 페이월 설계 실패
- 페이월 = "이야기 멈춤 지점" X / **"설계된 미완성 욕망 지점"** O
- 좋은 페이월: 키스·claim·처벌·정체 공개·권력 선언 직전 컷

### 2.2 시적 문체 도망
- "You were never meant to kneel in the dark" X
- "Get up. You're not kneeling to them" O
- 행동 만드는 문장 + 짧고 캐릭터에 맞음

### 2.3 직선 구조
- 사건 → 등장 → 대사 → 반응 → 다음 → 클리프 X
- Cold open / VO / Flashback / Montage / Insert 적극 사용

### 2.4 사건 과다
- 배신→납치→암살→예언→전쟁→비밀→각성 X
- 1개 압력축 + 압력 증대 / 공개성 / 권력 위치 / 욕망 변화

### 2.5 정보 과다
- "나중에 공개 가능" X / **"지금 이 상품 즐기는 데 필요한가"** 판단
- 왕국 역사·마법 체계·가문 계보·예언 구조·과거 전쟁 → EP1-8 회피

### 2.6 여성향 캐릭터 실패
- PC식 "강한 여성" 회피 (남자 필요 없다 / 감정 닫힘 / 욕망 없음 / 흔들림 없음 / 늘 맞는 말)
- 의지·두려움·욕망·이용·흔들림·거절·필요·압도 속 will 유지

### 2.7 트리트먼트 체크리스트화
- AI가 트리트먼트를 가장 직선적으로만 실행 X
- 트리트먼트 = 상태·욕망·보상·압력의 설계도

## 12 Final Core Principles (섹션 18)

1. Paid Vertical = 작품 감상 X / 시청·욕망·결제 상품
2. 페이월 = 발견 X / 설계
3. 무료회차 = 핵심 보상 증명만 / 완성 X
4. 문학적 모호함 X / 장면 구조 영상적
5. 직접 대사 O / 직선 장면만 X
6. 사건 많이 X / 1 압력축 확대
7. 정보 = 후행 공개 가능 X / 즐김 필요 지식량 제한
8. 여성향 = 몰입 가능 여주 + 반할 남주 핵심
9. PC식 닫힌 여주 X / 압력 속 선택·흔들림·욕망 여주
10. 트리트먼트 = 장면 감옥 X / 상업 구조 척추
11. 설계 단단 / 장면 유동 / 대사 직접 / 구성 영상적
12. 모든 장면 = 다음 장면 원하게
