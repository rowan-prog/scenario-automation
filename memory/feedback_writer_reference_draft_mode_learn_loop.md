# 인간-작가 참고초안 모델 + 학습 루프 (2026-06-09 사용자 명시)

## 모델 전환 (이 프로젝트 + 향후 다수 가능성)

산출물의 *사용처*가 "AIGC 직납 최종고" → **"인간 작가가 *참고*해 발전시킬 자료"**로 바뀔 수 있다.

**🚨 핵심 (2026-06-09 사용자 명시·"장난하나"):** **"초안"은 사용자가 산출물을 *어떻게 쓰는지*(인간 작가 참고)를 가리키는 말일 뿐이다. 내 산출 *형식·규칙·rigor는 절대 안 바뀐다.* 늘 우리가 정한 집필 원칙대로 쓴다 — △ AIGC 양식·spoken-english·엔진룰·LOCK 파이프라인.** "인간이 보니 읽는 프로스로 낮춰서" = 완전한 오해(내가 SHE STOLE 무료회차를 프로스로 낮췄다가 질책받음). 사용처는 형식을 바꾸지 않는다.

**🎯🙏 진짜 목표 (2026-06-09 사용자 "제발 제발 제발"):** 인간 작가의 수정/워싱은 *내가 못 써서 생기는 안전망*일 뿐, 목표는 그게 **불필요하게** 쓰는 것이다(사소한 건 제작자-사용자 간단 소통으로 해결). 바 = "작가가 고칠 초안"이 아니라 "거의 손 안 대도 되는 완성급". **그 중에서도 오류 — 논리·공간·행동·연속성·정합성(= 사용자가 반복해 수치당한 그 수준) = 절대 0.** 보장은 내 "괜찮다"가 아니라(그게 그를 속인 것) **게이트를 완료 선언 *전에* 분모와 함께 돌리는 것**(continuity_lint·voice_lint 결정론 + 적대 Track B + per-line 전수 + State Ledger). 분모 없는 "문제없음" 금지·deterministic 최대 이관·잔여 위험은 숨기지 말고 플래그(없는 척이 최악).

## 🛡 보존 (절대 — 뒤집지 마라)

이 전환은 **집필/검토 프로세스를 뒤집는 게 아니다.** 전부 보존:
- LOCK 파이프라인 = `config/lock_pipeline_standard.md` (Track A/B·적대게이트·쇼러너 merge·voice_lint/continuity_lint).
- 모든 엔진 룰·config·메모리.
- 이미 완성/락된 버전(예: **SHE STOLE v48** = LOCK-ready·`07_final/`)·이미 작성한 산출물(작가 초안 포함) = *삭제 X·보존.*
- 산출물은 *늘 풀 프로세스 + 정해진 형식(△ AIGC 양식 등)*으로 뽑는다 — 인간이 참고용으로 받는다고 형식·rigor 절대 안 낮춤. 형식을 사용처에 따라 가르지 않는다.

## 🔁 신규 상시 듀티 — 작가 회수본 학습 루프

인간 작가가 대본을 써오면 매번:
1. **평가** — 엔진/표준 렌즈로 정직하게(잘된 점·약점 둘 다).
2. **학습** — 작가가 더 잘한 게 있으면 *원리* 추출 → 메모리/config 반영.
3. **정밀 비교** — *내가 쓴 초안과 비트/라인 단위로* 1:1 대조.
4. **🎯 내 결함 정확히 짚기 (방어 금지)** — "내 버전이 정확히 *뭐가* 문제였나"를 구체적으로: 어느 비트·왜 약했나·작가는 어떻게 다르게/낫게 풀었나.

## Why
인간 작가 = 벤치마크이자 *내 약점을 가장 정확히 드러내는 거울.* 방어·합리화하면 학습 0(자가평가 신뢰 금지의 연장). 외부가 옳으면 흡수, 단 막장-필터는 유지(논리닫기/세련화/천박깎기형 = 기각).

## How to apply
작가 회수본 받을 때마다 위 4단계 실행. 진성 교훈은 외부 강제 layer로 박는다([[claude-voice-bias-vertical-failure]] 식). 모델이 다른 프로젝트로 확산되어도 동일.
