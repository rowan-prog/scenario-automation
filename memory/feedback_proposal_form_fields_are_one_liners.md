2026-09-04, 29번(A Man Who Sees Your Last Day) 플랫폼 기획안 제출본. 사용자가 내 docx를 직접 열어 **사이다 훅 / 세계관 / 필수 포함 요소 / 금기 1~6번을 통째로 삭제**하고 돌려줬다. *"뺀건, 필요없어서가 아니라, 니가 쓰레기처럼 써서 그냥 없이 주는 게 나아서 그런 것이다."* 진단 = *"AI티가 과도하게 많이 나는 문장, 이상한 동사활용, 주접스러운 제안, 인간 작가에겐 아무짝에도 쓸모없는데 구구절절 길게 써놓은 의미도, 효용도 없는 내용들."*

살아남은 칸 = 로그라인 · 줄거리 · 캐릭터 5인 · 무료 1~8화 트리트먼트. 전부 [[t1-page-exemplars-whole-learning]] 문체로 쓴 것들이다.

**내가 저지른 네 가지 (칸별 재발 방지):**

| 칸 | 내가 쓴 것 | 맞는 것 |
|---|---|---|
| 사이다 훅 | 장면당 3~4문장 = **트리트먼트 재탕**(작가는 트리트먼트를 이미 받는다) | 사용자 셀링포인트 형태 — 명사로 끝나는 한 줄, 화살표·쉼표로 붙임, 40자 이내. `300달러 고물 → 하루 만에 현금 10만 달러` |
| 세계관 | 3문단 + **마무리 수필**(`그래서 이 세계에서는 두 종류의 숫자가 부딪친다`) | 규칙만 한 줄씩 4~5개. `잭 말고는 아무도 못 본다.` `왜 보이는지는 끝까지 나오지 않는다.` |
| 필수 요소 | 항목마다 **왜 그래야 하는지 설계 설명**(`무료 마지막 화가 이 거울 위에서 끝나므로 …겹쳐야 한다`) | 한 줄 = 한 항목 = 한 문장. 장면과 사실만. 이유·효과 금지 |
| 금기 | 항목마다 **부연 한 문장 추가** | 한 줄 = 한 문장. 부연 0. 번호도 안 붙인다 |

**금기 칸 판별 게이트 (2026-09-04 사용자 2차 교정):** 사용자가 내 금기 목록에서 `잭은 클로이, 랜스와 화해하지 않는다`를 *"이런건 필요 없는 내용임"*, `능력이 어디서 왔는지, 왜 보이는지 설명하지 않는다`를 *"이건 필요하지만"*으로 갈랐다. 기준 = **트리트먼트에 이미 사건으로 적혀 있으면 쓰지 않는다.** 금기는 **트리트먼트가 말하지 않는 공백을 지키는 자리**다 — 안 적으면 작가가 자기 상식으로 채워 버리는 것만 적는다.

| 판정 | 예 | 왜 |
|---|---|---|
| ✗ | `클로이·랜스와 화해하지 않는다` | 두 사람이 무릎 꿇고 끌려나가는 장면이 트리트먼트에 이미 있다 — 결말이 적혀 있는데 "안 한다"를 또 쓰는 건 중복 |
| ✗ | `잭이 남의 도움으로 위기에서 빠져나오게 하지 않는다` | 화별 트리트먼트가 이미 잭이 스스로 푸는 걸 다 정해 놨다 |
| ✓ | `능력이 어디서 왔는지, 왜 보이는지 설명하지 않는다` | 트리트먼트 어디에도 없는 **공백** — 안 적으면 작가가 기원 설정을 만들어 넣는다 |
| ✓ | `물건 위에는 값만 뜨고 연도나 나이는 뜨지 않는다` | **표기 규칙** — 트리트먼트만 보면 나이도 붙일 수 있다 |
| ✓ | `카터 인슈어런스를 병원 주인으로 만들지 않는다` | 각색물의 **원작 오염 차단**(원작은 병원 재벌) |
| ✓ | 어려운 말 금지 · 대사 이중 부정·돌려 말하기 금지 | **문체** — 사건이 아니라 쓰는 법이라 트리트먼트가 못 담는다 |

금기에 남는 것 = **① 설명하지 말아야 할 공백 ② 표기 규칙 ③ 원작·구설정 오염 차단 ④ 문체.** 줄거리에 이미 있는 전개는 전부 뺀다.

**Why:** 기획안 표는 읽히는 글이 아니라 작가가 훑는 스펙 시트다. 트리트먼트가 이미 사건을 다 들고 있으니 다른 칸이 사건을 다시 말하면 전부 중복이고, 설계 설명은 작가에게 효용이 0이다. 길이가 늘면 AI티가 그 길이에 실려 나온다.

**How to apply:** phase_p 기획안을 쓸 때 **로그라인·줄거리·캐릭터·트리트먼트만 문장으로 쓴다.** 나머지 칸은 전부 한 줄 목록. 작성 유닛 지시서에 사용자 셀링포인트 실물을 문체 모델로 인라인하고, "항목 안에 두 번째 문장 금지 · 마무리 정리 문장 금지 · 이유 설명 금지"를 못 박는다. 사용자가 승인한 문장이 있으면 글자 하나 안 바꾸고 그대로 둔다.

**같이 잘라낸 꼬리들(전 칸 공통):** 제작 형태 = `AI 실사` 한 단어면 된다(내가 붙인 `· 세로형 9:16 · 총 50화 · 편당 약 1.5분` 삭제) · 레퍼런스 = 작품명과 화수만(뒤에 붙인 해설 두 줄 삭제) · `— 회차는 협의 조정 가능` · `(제안)` · 담당자 칸의 `상태 · 제작 등급` 줄. **빈칸으로 두는 게 낫지, 채우려고 문장을 만들지 않는다.**
