# 규칙

## 0. 메타 분석 어휘 — 작가용 내부 도구로만 사용 (피칭덱·청사진·트리트먼트 절대 금지, 2026-05-10 추가)

작품 분석·시스템 룰 작성·검토자 노트에는 사용 가능. 외부 노출 문서(피칭덱·청사진·트리트먼트)에 사용 절대 금지.

**금지 대상 메타 어휘 (예시):**
- "내 자리 도둑" / "가짜 신부 / 내 자리 도둑" 류 자체 조어
- "팔림 / 버려짐 / 처형 직전" 류 패턴 라벨
- "1층 / 2층 / 3층 보상" / "Mode A·B·C" / "박탈 → 회복 패턴"
- "결핍 / 욕망 / 보상 강화" / "갈망 곡선" / "유예 / 격차"
- "원초적 욕망 / 보상 시스템 / 카타르시스 장치"
- "시작점 / 진입선 / 페이월 응축" 류 구조 분석어

**원칙:** 분석 도구는 분석에서만. 외부 노출 시 작중 사건·자리·물건·몸·권한·시선·문·이름·선언으로 직접 구현.

## 1. 단어급 — 권장 회피 (금지 X, 2026-05-10 규칙 정정)

**사용자 정정 (2026-05-10):** "폐기" / "코어"는 **금지가 아니다.** "대체 가능 용어가 있는데 굳이 쓸 필요 없다" 정도. 검출 시 자동 fail X.

- **폐기 / 폐기된 / 폐기하다** — 자주 남용 → 대체어 권장 ("버려진 / 지워진 / 추방된 / 잘라낸 / 제거된"). 단 작품 톤·장르 정합 시 사용 가능.
- **코어 / Core** (작품 분석문) — 대체어 권장 ("핵심 / 중심 / 본질"). 양식 헤더 ("Core Expectation") 유지 가능.
- **호명 / 호명과 위치 / 호명 변화** — **금지 (추상 학술어).** "이름·자리 / 그녀를 부르는 말 / 그녀가 서는 자리"로 구체화.
- **선언적 / 선언형** (분석문) — 분석 페르소나 내부에서는 가능, 피칭덱·청사진 본문에서 X.

## 2. 문장급 금지 패턴

### A. "이 작품의 핵심은 ~가 아니라 ~이다" 류 빈 문장
**금지 예시:**
- "이 작품의 핵심은 복잡한 기술 설정이 아니라, '내 얼굴로 다른 여자가 내 인생을 산다'는 즉각적인 억울함이다."
- "이건 단순히 X가 아니라 Y인 작품이다."

**왜 금지:** 의미 없는 자기 변명. 시청자에게 설득 안 됨. **주장 없이 설명만** 함. 근거 바탕으로 직접 주장하라.

**대체:** 곧바로 결론을 적시 — "여주가 자기 얼굴로 만든 가짜에게 인생 전체를 빼앗긴다. 약혼 발표·어머니 목걸이·약혼식장 잠입이 무료 8화 안에 배치됨."

### B. 학술 추상어로 장면 대체 (관념어 남용)
**금지 예시:**
- "그녀의 호명과 위치를 바꾸는 남주."
- "회사 시스템과 루프 사이에 남는 작은 균열."
- "차별점은 은밀한 친밀감보다 공식 지위 역전을 중심 보상으로 둔 점."

**왜 금지:** 화면에 아무것도 없음. 배지가 어떻게 반응하는지, 칼이 무엇을 보는지, 어떤 수치·신호·소리가 나는지 — 아무것도 없이 개념만 있음. **장면이 아니라 개념 요약문.**

**대체:** 장면을 **무엇이 일어나는가**로 직접 기술 — "보안 화면에 칼의 배지 번호와 함께 ANOMALY DETECTED가 뜬다."

### C. 중2병식 과도 극화·자체 조어
**금지 예시:**
- "운명이 그를 폐기했지만, 그의 피가 신성을 깨운다." (X — 과도 극화)
- "공식 지위 역전을 중심 보상으로 둔 점" (X — 자체 학술 조어)
- "감정 폭발이 아니라 권한 이동" (✓ — 명료, 분석문에서는 가능)

**원칙:** 이상한 자체 조어 만들지 말 것. 시청자가 모르는 단어로 작품 설명하지 말 것.

### D. PC주의식 회피 표현 (여성향에서 특히 금지)
**금지 예시:**
- "차별점은 은밀한 친밀감보다 공식 지위 역전을 중심 보상으로 둔 점. 침실 긴장감이나 금지된 끌림보다 ~"

**왜 금지:** 침실 긴장감과 금지된 끌림이 여성향에서 **압도적으로 잘 팔린다**. 이걸 일부러 안 하겠다고 하는 건 시장 이해도 부족.

**대체:** 침실 긴장감·금지된 끌림·공개 소유 선언이 **함께 작동**한다고 솔직하게.

## 3. 트리트먼트 내 금지

- **"배지가 무엇인가"를 시청자에게 설명하는 문장** — 트리트먼트는 무슨 일이 일어나는가를 써야지, 그것이 무엇을 의미하는가를 써선 안 됨.
- **"이 장면은 ~를 보여준다"** — 시청자에게 의미 풀이하는 문장 금지.
- **장면 외부에서 작가가 해설하는 톤** — 작가 노트는 별도 파일에.

## Why
2026-05-09 사용자 강한 피드백:
- "왜 못잃어? 금지로 할 필욘 없는데 '폐기'가 자꾸 사용되는 이유는? '코어'가 자꾸 사용되는 이유는?"
- "그녀의 호명과 위치를 바꾸는 남주다. 호명과 위치를 바꾼다는 개병신같은 말을 누가쓰냐."
- "이 작품의 핵심은 복잡한 기술 설정이 아니라 ~ 이런 표현들은 왜쓰는 거냐. 진짜 궁금하지도 않고 아무 의미도 없는 말들"
- "차별점은 은밀한 친밀감보다 공식 지위 역전을 중심 보상으로 둔 점. 이건 쓰레기 같은 거야. 침실 긴장감과 금지된 끌림이 압도적으로 잘 팔리는데 PC주의급."

## How to apply
- 모든 작성·검토 단계에서 위 표현 자동 검사
- **금지 (자동 수정):** "호명과 위치" / "이 작품의 핵심은 ~가 아니라" / "은밀한 친밀감보다" / 자체 학술 조어 / 작가 해설 톤
- **권장 회피 (대체어 사용):** "폐기" / "코어" — 자동 fail X. 대체 가능 시 사용 권장 정도
- 추상어로 장면 대체했는지 자동 검사 — 화면에 무엇이 보이는지 점검
- 장면 외부 작가 해설 톤 검출 시 장면 안으로 번역 또는 삭제
