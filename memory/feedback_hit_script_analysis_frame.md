# Hit script 분석 프레임 — 결제 트리거 중심

## 룰

Hit script 분석 시 다음 프레임으로 진입한다:

1. **"왜 팔렸는가?" 질문**으로 시작. "무엇이 강했는가?" 평론가 프레임 금지.
2. **결제 트리거 단위 분석**: 어느 *라인*이 다음 화 잠금 해제 버튼인가. 장면 단위는 한 단계 coarse.
3. **5줄 매출 엔진 추출**: 작품 전체에서 핵심 5줄을 라인 단위로 식별. 이 5줄이 척추.
4. **대사 품질 원리 추출**: "쉽고 잔인·예쁘게 안 씀·고급스럽지 않다·바로 빡친다·바로 이해된다" 원리를 명시적으로 기술. 라인 인용만 하지 말 것.
5. **USP 운용 분해**: USP를 *매 화 어떻게 써먹는가* 단위로 분해. 구조 카테고리(정당화/비주얼/페이오프)는 분석 보고서용. 작가 운용은 6+ 운용 방식으로.

## Why

2026-05-22 [말할 수 없는 나의 신부] 71화 분석을 두고 사용자 분석과 내 분석을 비교. **두 분석 동등한 수준·서로 다른 렌즈** (사용자 명시 보정 — 처음 내가 자기비하로 사용자 우세라 했지만 실제로는 상보적):

**전술·라인 렌즈** (사용자 분석이 강했던 차원):
- 라인 단위 5줄 매출 엔진 식별 ("말해. 내 이름" / "이혼하자구, 우리" / "하수연을 풀어줘" / "난 한번도 널 사랑한 적 없어" / "내가 없어야 네가 사는구나")
- 대사 품질 원리: "쉽고 잔인·예쁘게 안 씀·고급스럽지 않다·바로 빡친다·바로 이해된다"
- USP의 매 화 운용 분해 (해명 못함/도움 요청 못함/모욕 그대로/이름 못 부름/아이 못 지킴/말 트여도 이름만 못 부름)
- 결제 트리거 단위 프레임 ("왜 팔렸는가")

**구조·경제 렌즈** (내 분석이 강했던 차원):
- 번역 경제학 — (E) 수어 트랙이 더빙 효율 끌어올리는 메카닉
- 3층 빌런 회전 — 분노 분배가 71화 분량 유지의 비결
- 페이월 정확 화 번호 매핑 (11화·16화 컷오프 사건 매칭)
- 시스템 룰 변환 — 분석에서 멈추지 않고 phase_4 집필 룰까지 끌고 옴

둘 다 필수. 라인만 보면 사업 구조 못 봄. 구조만 보면 실제 집필 라인 못 박음.

## How to apply

히트작 분석 시 **0단계 — 캐릭터 결말 위치 확인 필수** (분석 진입 전):
- 작품 결말에서 *여주를 가져가는 자*가 누구인가?
- 작품 전반의 *toxic 행동 캐릭터*와 *결말의 ML*이 동일 인물인가?
  - 동일 → **Type A (redeemed ML)**
  - 다른 인물 → **Type B (discarded abuser + white knight ML)**
- Type 확정 없이 분석 시작 시 — toxic 자원 캐릭터를 romance ML로 잘못 매핑하는 critical error 발생 (2026-05-22 [말할 수 없는 나의 신부] 분석 시 내 미스 학습: 민우=abuser·서진=ML인 Type B를 Type A처럼 분석)
- 관련 메모리: [[na-vertical-ad-creative-principles]] 작품 구조 Type 확정 섹션

히트작 분석 산출물 = **두 렌즈 병행 강제**:

**(전술·라인)**
- 라인 단위 5줄 매출 엔진 식별 — 작품 척추가 될 단일 줄 5개
- 대사 품질 원리 한 문장으로 추출 (예쁜 줄 인용 금지·운용 원리만)
- USP 매 화 운용 6+ 방식 분해 (구조 카테고리 아님)
- 프레임 = "왜 팔렸는가"

**(구조·경제)**
- 번역 경제학·로컬라이즈 비용
- 빌런 회전·분량 유지 메카닉
- 페이월 화 번호 매핑·무료-유료 경계 사건
- 우리 시스템 룰로 변환 (분석 → phase_4 룰)

새 작품 phase_4 집필 EP 점검 시 자문:
- *"이 EP에서 5초 결제 트리거가 될 라인은 무엇? 라인이 즉발·싸구려·바로 빡치는가?"* (전술)
- *"이 EP가 페이월 위치에 맞는 사건인가? 빌런 회전이 살아있는가?"* (구조)

광고 후킹 분석 별도 명시 시만 마케팅 프레임. Default 분석 프레임 = 결제 트리거 + 구조 경제 병행.
