# 웹 리서치 정책

| **ReelShort** | Crazy Maple Studio. 글로벌 최대 paid vertical. 여성향 메인스트림 |

- 2026-05-12 기준 → **2025-11-12 이후** 작품
- 이후 자동 갱신 (날짜 기준 항상 -6개월)

## 주된 용도 — 피칭덱 보강자료·레퍼런스

### 용도 1: 피칭 사유 근거 (가장 자주)
- 카테고리 검증 사례
- 시장 매출 데이터
- 결제력 증거
- 신규 트렌드 (6개월 이내)
- 비교작품 (변별력 강조용)

**예시 활용:**
- "Soft Harem Adventure는 NetShort 2026 Q1 신작 〈XXX〉·〈YYY〉가 직접 검증한 카테고리"
- "Marriage of Convenience는 ReelShort 2026 Q1 톱 10 중 3편 차지"

### 용도 2: 레퍼런스 제시
- 작품 톤·미감·구조 비교용
- 유사 카테고리 검증작 명시
- 변별점 도출 (이 작품 vs 기존 작품)

## 부차적 용도 (드물게)

1. **아이디어 개발 (phase_0)** — 새 카테고리·트렌드 탐색 시
2. **청사진 (phase_1·phase_3)** — 회차 비트·페이월 구조 비교 시
3. **스크립트 (phase_4)** — 톤·대사·미장센 레퍼런스 시

→ 일반적으로 메모리·`config/target_research/` 자료가 우선. 웹 리서치는 보조.

## 작성·인용 시 룰 (필수)

### 본문 활용 시
- 플랫폼명 본문 직접 박제 회피 (참조: `feedback_pitch_marketability_definition.md`)
- 작품명·통계·트렌드만 추출
- **피칭 사유 본문은 작품 안 사건 우선** (참조: `feedback_pitch_principles_master.md`)

### 자료 사용 시
- 출처 (플랫폼·날짜·작품명) 메타에만 기록
- 외부 AI 입력 처리 룰 동일 적용 (`feedback_external_ai_input_handling.md`) — 사용자 워싱 안 됐으면 직접 적용 X / 인사이트만

### 비교작 인용 시
- 변별력 강조용 — "이 작품은 XXX와 달리 YYY로 더 세게 빼앗기고 뒤집힌다"
- 위원 검증 단정 회피 — "검증된 트로프" 단정 X, "검증 중·확장 여지" 톤

## 리서치 실행 시 절차

1. **사용자 명시 후 실행** (자율 X — 사용자가 토픽·플랫폼 한정 명시 후)
2. 실행 도구:
   - **WebSearch** — 단일 쿼리 (플랫폼명 + 카테고리 + 기간 검색)
   - **WebFetch** — 특정 URL (플랫폼 공식 카탈로그·앱 분석 보고)
   - **Agent (general-purpose)** — 심층 다단계 조사 (시간 소요)
3. 결과 저장:
   - `config/target_research/platform_recent/[YYYY-MM-DD]_[플랫폼]_[카테고리].md` (해당 폴더 신규 시 생성)
   - 또는 작품별 `projects/[작품]/06_reviews/cross_ai/[date]_web_research.md`
4. 메타에 출처·날짜·검색 쿼리 기록
