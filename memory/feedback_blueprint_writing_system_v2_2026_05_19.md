> **2026-05-19 시스템 재설계 Phase 3.** OFFERING이 메모리·페르소나·4-Gate 다 통과 후에도 결함 투성이였던 근본 원인 = **검증 작품 본문 직접 흡수 부재** + **자기 baseline으로 자기 평가의 표면성**. 본 시스템 v2에서 해소.

## 룰

**모든 phase_1·3·4·Conversion Runway 진입 시 본 시스템 v2 절대 적용.**

**Why:** 사용자 직접 명시 (2026-05-19): "패턴만 인지하는건 기초중의 기초다. AI는 그 위에 인간을 매료시킬만한 작품을 스스로 세우지 못한다. 구조파악은 기본이고, 구체적으로 참고해야한다." 메모리 인사이트·메타 룰 누적만으로 매료 작품 못 세움.

**How to apply:** 청사진·집필 단계 진입 전 검증 작품 본문 직접 정독·작가 시점 흡수 보고서 작성 강제. 자가 검수는 외부 baseline 강제.

---

## 1. 검증 작품 직접 흡수 룰 (절대)

### 1.1 청사진 진입 전 흡수 보고서 강제
청사진 작성 시작 전 **다음 3 영역 검증 작품 본문 직접 정독**:

**A. 같은 장르 히트작 3편 이상 (`config/vertical_drama_hit_scripts/` + `config/hit_library/`)**
- 같은 desire_engine · conversion_engine 작품 (Hard Rule #4)
- EP1·EP8 페이월·후반 핵심 회차 본문 정독
- 라인 cadence · 블로킹 · END HOOK 패턴 흡수

**B. 같은 타깃 통과 피칭덱 2편 이상 (`config/pitch_references/`)**
- 같은 타깃 (북미 여성·남성) 통과 피칭덱
- 로그라인 · 인물 소개 · 트리트먼트 cadence 흡수

**C. 실패 사례 1편 이상 — Demon Lord 또는 본 작품 옛 정본**
- 실패 패턴 자가 검수 baseline
- 같은 함정 회피 강제

### 1.2 흡수 보고서 양식
```markdown
# [작품명] 청사진 진입 전 흡수 보고서

## A. 같은 장르 히트작 3편 흡수
### 작품 1: [title]
- Genre/Trope: [본문 정독 후 직접 추출]
- desire_engine: [동일]
- conversion_engine: [동일]
- 매료 라인 (본문 인용 3-5건): [라인 직접 인용]
- 블로킹 패턴 (회차당): [본문 관찰]
- END HOOK 패턴: [본문 관찰]

### 작품 2·3: [동일 형식]

## B. 통과 피칭덱 2편 흡수
### 피칭덱 1: [title]
- 로그라인 cadence: [직접 인용]
- 인물 소개 voice: [직접 인용]
- 트리트먼트 1-3화 cadence: [직접 인용]

## C. 실패 사례 1편
### Demon Lord 또는 옛 본 작품
- 9 함정 매칭: [어느 함정·어느 라인]
- 회피 다짐: [본 작품에서 어떻게 회피할지]

## D. 자가 검수
- v3 진단 10 자가 검수 통과?
- 검증 작품 패턴과 일관?
- 매료 라인 본 작품에 어떻게 적용?
```

### 1.3 보고서 없이 청사진·집필 진입 금지
- 보고서 작성 전 청사진·집필 시작 = **시스템 룰 위반**
- 보고서 = 청사진 폴더에 저장 (`projects/[작품]/00_immersion_report.md`)

## 2. 청사진 단계 자가 검수 강화

### 2.1 v3 진단 10 자가 검수 강제 (다크 로맨타지 작품)
청사진 작성 후 시스템 baseline `feedback_dark_romantasy_paid_vertical_v3_diagnosis.md` Section 10의 10 질문 통과 강제.

### 2.2 페르소나 00 사전 검토 옵션 (선택)
청사진 작성 후 페르소나 00 (Genre Identity Auditor) 사전 검토 호출 가능. **메타 결함 청사진 단계에서 조기 발견** 가능.

### 2.3 청사진 V·N 정정 시 흡수 보고서 재작성
- 청사진 v1·v2 등 다중 정정 시 매 정정마다 흡수 보고서 재작성
- 옛 보고서 archive로 이동·새 보고서가 정합 baseline

## 3. 집필 단계 검증 작품 흡수 룰

### 3.1 매 EP 집필 직전 검증 작품 1 EP 본문 정독
- 같은 장르 히트작에서 비슷한 함수의 EP 1편 정독
- 예: 첫 정사 EP 집필 시 같은 장르 첫 정사 EP 1편 정독
- 예: 페이월 EP 집필 시 같은 장르 페이월 EP 1편 정독

### 3.2 5 EP 블록 후 페르소나 00 사전 검토
- EP1-5 / EP6-10 / EP11-15 등 5 EP 블록 후 페르소나 00 호출
- 메타 결함 조기 발견 → 다음 5 EP 재방향

### 3.3 자가 검수 외부 baseline 강제
- 자기 baseline ("내가 청사진 따랐다·시적 톤 회피했다") = 표면성
- 외부 baseline = 검증 작품 본문 직접 비교
- 매 EP 자가 검수 시 같은 장르 검증 작품 라인 1건 이상 인용 강제

---

## 4. "다 했다" 회피 룰

### 4.1 의심 지점 5+ 명시 강제
- 작업 완료 보고 시 의심 지점 5+ 자가 명시
- "결함 0건" 보고 = **부족 표지 → 더 깊이 의심 강제**
- 의심 지점이 안 보이면 = 자가 검수 표면성

### 4.2 "사용자가 보면 결함 발견할 부분 5+" 자가 검수
- AI 자기 baseline으로는 못 보이는 부분 5+ 자가 명시
- 사용자 시점 시뮬레이션 강제

### 4.3 메타 결함 자가 진단 (v3 진단 10 질문)
- 청사진·집필·검토 완료 시 v3 진단 10 질문 자가 답변 강제
- 1개라도 NO = 작업 미완료

---

## 5. 한계 인정 룰

### 5.1 AI 학습 방식 한계 자가 인정
- "패턴 모델링 위 매료 작품 못 세움" = 시스템 자가 인정
- 사용자 검증 없이 LOCK 표기 금지
- LOCK 표기 시 잔존 결함 가능성 명시

### 5.2 검증 작품 직접 흡수 부재 시 작업 중단
- 흡수 보고서 없이 작업 진행 = 시스템 룰 위반
- 작업 중단·먼저 검증 작품 정독·보고서 작성 후 재개

---

## 6. 자가 검수 (작업 진입 시 강제)

1. 청사진·집필 전 흡수 보고서 작성했는가? (검증 작품 3편 + 피칭덱 2편 + 실패 사례 1편)
2. v3 진단 10 자가 검수 통과하는가?
3. 매 EP 직전 검증 작품 1 EP 정독했는가?
4. 5 EP 블록 후 페르소나 00 사전 검토 받았는가?
5. 자가 검수 시 외부 baseline 인용했는가?
6. 의심 지점 5+ 명시했는가?
7. "다 했다" 인정 회피 룰 적용했는가?

→ 1개라도 NO = 작업 미완료.
