**사용자 (2026-08-27):** *"너가 하도 로그라인을 제대로 못써서 예시를 준다."* — 플랫폼 카탈로그 시트(헤더: 타이틀 (영문) - 50words / 로그라인 (한국어) - 70words) 실물 ~250행을 통째로 붙여줌. *"로그라인에 관계/쾌감/핵심트롭/갈등구조/위기/능력/사이다 이런 것들이 다 한 눈에 보여야한다. 중학생이 읽어도 이해 되어야한다. 한문장한문장 꼼꼼히 읽었을 때 재밌고, 대충 띄엄띄엄 읽어도 재밌어야한다. 이런 것들이 제대로 되어있지 않다. 예시는 업데이트해라."*

**무엇이 틀렸었나:** 29번 〈A Man Who Sees Your Last Day〉가 하루에 다섯 판 반려(v1 비유·발명 → v2 → v3 토막 → v4 400자 요약 → v5 "13번 길이" 195자·4문장). 매번 사용자 지적을 룰 문장으로 바꿔 적었고(연결어미 캡·4단 골격·150자) 매번 반대편 벽으로 튀었다. 뿌리 = **내가 실물 규격을 한 번도 안 봤다.** 13번·26번 4단 문단은 로그라인이 아니었고(러프 기획안 로그라인 자리에 쓰면 안 되는 것이었다), 진짜 규격은 `logline_lint.py --stats` 실측 = 중앙값 55자·p90 68·최대 92 · 1문장 74%·2문장 22% · 인명 0명 46%·1명 37%.

**Why:** 로그라인은 기획안 전체에서 문장당 레버리지가 제일 큰 자리고, T1 페이지·CD1 시트·플랫폼 기획안에 그대로 실린다. 슬롯 규격을 모르면 아무리 잘 써도 안 들어간다. 그리고 우리 것이 등재될 때 실제로 이렇게 줄어든다(16_moses: *"동생에게 죽고 삼 년 전으로 회귀한 그녀, 조용히 살려고 고른 거지 남편이 하필 예언자 모세였다!"*).

**How to apply:**
- 로그라인·타이틀 작업 = `config/50_logline_standard.md` + `config/50_logline_corpus.md` **179건 전량 정독** 후 skill `/logline` — 생성(copy-candidate-generator opus·**low** ×3 프레이밍: 관계 직격 P2/P4 · 반전 끝맺음 P1/P3 · 규칙형 P5) → `tools/logline_lint.py` → plain-reader(haiku·low 되감기) → logline-auditor(sonnet·**high** 7요소·캐논) → 메인 선별 3~5 → 사용자. **메인이 직접 쓰지 않는다.**
- 골격 5형 안에서만 · 허용 비유 = 코퍼스에 있는 굳은 말만(사랑이 싹튼다·불이 붙는다·시험대·판을 뒤집는다) · 인명 대신 역할명(전처·회장·배달부) · 조직명 0 · 인용 대사로 시작 0 · 장르 라벨어(사이다·리벤지극) 대신 그 사건.
- 4단 문단(모욕 대사 → 당한 것 → 반전 실물 → 페이오프+장르 이름표)은 **로그라인이 아니고 로그라인 자리에 안 쓴다.** 처음엔 이걸 '도입 문단'이란 이름으로 러프 기획안에 남겨뒀다가 같은 날 사용자 지적(*"러프 기획안 안에 로그라인 들어가잖아"*)으로 삭제 — **옛 룰을 새 이름으로 살려두는 갈래 만들기 금지.** 모욕 대사·경위는 셀링포인트·트리트먼트 몫.
- 반려가 오면 룰을 새로 짜지 말고 **실물 코퍼스를 옆에 놓고 길이·문장 수·명사를 맞춘다.** 실물이 없으면 달라고 한다.

**+ 같은 날 2차 교정 — 엔진 한 줄은 사용자 문장으로.** 첫 라운드에서 내가 캐논 요약에 엔진을 "전처 리벤지"로 적자 판정 유닛이 45 중 21을 "전처 없음"으로 떨궜다. 사용자: *"'전처'가 핵심인가도 의아하다. 보잘것 없던 인간이 특별한 힘을 얻잖아. 이걸로 어머니도 살리고, 개쩌는 여자도 얻고, 부와 명예, 힘 다 얻게 되는 남성향 판타지임. 굴욕을 준 애들에겐 확실한 보복."* 전처 = 보복 대상 중 하나. **엔진을 내가 요약하면 장르가 바뀐다** — 사용자가 한 줄로 말한 게 있으면 그 문장이 엔진, 없으면 묻고 진입. 남성향 파워판타지의 7요소 = 박탈 · 힘 · 얻는 것들(어머니·여자·부·명예·힘) · 보복 대상(복수). 본문 = `50_logline_standard.md` §7 1단계 · `logline-auditor` 7요소 행.

**+ 2026-09-01 (29번 v20) — 로그라인과 셀링포인트의 일 분담이 확정됐다.** 사용자: *"로그라인은 스토리를 구구절절 설명하는 게 아니다. 스토리는 트리트먼트에서 드러난다. 로그라인은 직관적이고 쉽고, 쓸데없는 비유는 걷어내되, 후킹력있게."* + *"셀링포인트는 더 압축적이고 더 짧고, 명료하면서 실제로 사람들이 누구나 공감/이해되어야한다. 명사, 명사형 어미, 명사 어미 등을 활용하고 직관적으로."*
**로그라인 = 굴욕 → 능력 → 아이러니 셋만.** 각성 경위·능력 두 번째·이름·과장어(「개처럼」)·`?!`는 전부 뺀다. 173자 3문장 → **68자 2문장**. 판정 = *"이게 줄거리 요약인가, 아이러니 한 방인가."*
**셀링포인트 = 명사구 한 줄 × 4. 동사 서술 금지.** 한 줄 = 한 쾌감 축(능력 / 돈 / 응징 / 신분 역전)이고, 낙차는 **화살표와 쉼표**로 보인다 — 「300달러 고물 → 하루 만에 현금 10만 달러」 / 「어머니 보험금을 자른 상간남 임원, 그 어머니 병실에서 즉석 해고」. 서술문으로 쓰면 아무리 줄여도 길어지고, 축 두 개를 '및'으로 묶게 된다(그러면 축 하나가 사라진다).
**두 개를 같이 볼 것 — 로그라인이 능력을 두 개 다 지고 있으면 셀링포인트 1번이 할 일이 없어진다.** 물건 감정 능력은 셀링포인트로 내리고 로그라인은 수명 하나만 진다.

**+ 2026-09-01 (29번 v23) — 🚨 로그라인 갈래가 두 개다. 나는 계속 잘못된 갈래를 쓰고 있었다.** 사용자가 모델을 줬다: *「날개 없는 결함으로 낙인찍혀 가족에게 버려진 여자가, 하룻밤의 인연으로 용주의 아이를 낳고 온갖 음모를 뚫고 살아남아, 수백 년에 한 번 태어나는 '고대룡'으로 각성해 자신의 자리를 되찾는 이야기.」* + *"이렇게 짧으면서도 명확하게 **이 이야기가 무슨 이야기인지**를 보여야한다고."*
**실측 대조 — 길이도 사건 수도 문제가 아니었다.** 모델 = **110자·사건 5개**. 내 판 = 92자·사건 4개. **모델이 더 길고 사건도 더 많다.** 차이는 넷: ①**한 문장**, 주어 하나가 끝까지 끌고 간다(내 건 2문장이고 두 번째에서 주어가 바뀐다) ②**「~하는 이야기」 종결** ③**작품 전체 아크**(내 건 무료 8화 초반만) ④**최종 도달점이 있다**(「자신의 자리를 되찾는」). 내 문장엔 도달점이 없어서 "무슨 이야기냐"에 답이 안 됐다 — 그게 사용자가 「?? 뭐는 뭐고 뭐는 뭔데」라고 한 것의 정체다.
**골격:** `[낙인·처지]인 [주인공]이, [계기로 얻은 능력]에 눈떠, [핵심 반전 행위]하고 [최종 도달점]하는 이야기.` — 한 문장 · 주어 하나 · 쉼표 2개 · 100~110자.
**⚠️ `tools/logline_lint.py`의 자수 상한 95는 이 갈래에 쓰면 안 된다** — 사용자 모델이 110자로 FAIL한다. 95는 **플랫폼 카탈로그 슬롯**(179건·중앙값 55) 규격이고, **기획안 로그라인은 아크형 100~110자**다. 두 갈래를 구분해서 쓸 것(`50_logline_standard.md` 개정 안건).
**검증 질문지도 갈래에 맞춰야 한다:** 아크형은 「**이게 무슨 이야기인지 네 말로 한 문장** / **이 사람은 결국 어떻게 되나** / 한 번에 읽히나 / ?? 걸린 자리 / 볼 마음」. 「줄거리인가 한 방인가」로 물으면 **모델조차 '줄거리 느낌'으로 찍힌다** — 실제로 그 질문지로 한 라운드를 통째로 날렸다.
**남는 교훈:** 사용자가 「줄거리를 써놓은 것 아닌지 점검하라」고 했을 때 나는 **사건 수를 줄이는 방향**으로 갔는데, 정답은 **도달점을 붙이는 방향**이었다. 지적을 받으면 내 가설로 방향을 잡지 말고 **모델 실물을 달라고 하거나 코퍼스에서 찾아 나란히 놓을 것.**
