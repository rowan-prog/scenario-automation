**사용자 (2026-08-27):** *"너가 하도 로그라인을 제대로 못써서 예시를 준다."* — 플랫폼 카탈로그 시트(헤더: 타이틀 (영문) - 50words / 로그라인 (한국어) - 70words) 실물 ~250행을 통째로 붙여줌. *"로그라인에 관계/쾌감/핵심트롭/갈등구조/위기/능력/사이다 이런 것들이 다 한 눈에 보여야한다. 중학생이 읽어도 이해 되어야한다. 한문장한문장 꼼꼼히 읽었을 때 재밌고, 대충 띄엄띄엄 읽어도 재밌어야한다. 이런 것들이 제대로 되어있지 않다. 예시는 업데이트해라."*

**무엇이 틀렸었나:** 29번 〈A Man Who Sees Your Last Day〉가 하루에 다섯 판 반려(v1 비유·발명 → v2 → v3 토막 → v4 400자 요약 → v5 "13번 길이" 195자·4문장). 매번 사용자 지적을 룰 문장으로 바꿔 적었고(연결어미 캡·4단 골격·150자) 매번 반대편 벽으로 튀었다. 뿌리 = **내가 실물 규격을 한 번도 안 봤다.** 13번·26번 4단 문단은 러프 기획안 도입부였지 카탈로그 슬롯이 아니었고, 슬롯은 `logline_lint.py --stats` 실측 = 중앙값 55자·p90 68·최대 92 · 1문장 74%·2문장 22% · 인명 0명 46%·1명 37%.

**Why:** 로그라인은 기획안 전체에서 문장당 레버리지가 제일 큰 자리고, T1 페이지·CD1 시트·플랫폼 기획안에 그대로 실린다. 슬롯 규격을 모르면 아무리 잘 써도 안 들어간다. 그리고 우리 것이 등재될 때 실제로 이렇게 줄어든다(16_moses: *"동생에게 죽고 삼 년 전으로 회귀한 그녀, 조용히 살려고 고른 거지 남편이 하필 예언자 모세였다!"*).

**How to apply:**
- 로그라인·타이틀 작업 = `config/50_logline_standard.md` + `config/50_logline_corpus.md` **179건 전량 정독** 후 skill `/logline` — 생성(copy-candidate-generator opus·**low** ×3 프레이밍: 관계 직격 P2/P4 · 반전 끝맺음 P1/P3 · 규칙형 P5) → `tools/logline_lint.py` → plain-reader(haiku·low 되감기) → logline-auditor(sonnet·**high** 7요소·캐논) → 메인 선별 3~5 → 사용자. **메인이 직접 쓰지 않는다.**
- 골격 5형 안에서만 · 허용 비유 = 코퍼스에 있는 굳은 말만(사랑이 싹튼다·불이 붙는다·시험대·판을 뒤집는다) · 인명 대신 역할명(전처·회장·배달부) · 조직명 0 · 인용 대사로 시작 0 · 장르 라벨어(사이다·리벤지극) 대신 그 사건.
- 4단 문단(모욕 대사 → 당한 것 → 반전 실물 → 페이오프+장르 이름표)은 **'도입 문단'**이라 부르고 로그라인 아래에 둔다 — 로그라인 필드에 안 넣는다.
- 반려가 오면 룰을 새로 짜지 말고 **실물 코퍼스를 옆에 놓고 길이·문장 수·명사를 맞춘다.** 실물이 없으면 달라고 한다.
