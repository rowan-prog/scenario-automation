# 외부 AI 피드백 평가 — 개별 타당성 (2026-05-17)

## 사용자 명시

> **"내가 외부 ai 피드백을 주면, 너는 공통된 의견만 타당하다고 평가하는 경향성이 있어 보인다. 개선해라."**
> **"모두 공통되도 틀릴 수 있고, 어느 하나만 주장해도 맞는말일수도 있다."**

## 핵심 룰 (절대)

**다수결·공통성 = 타당성 ≠ 동치.**

- ✅ 공통 의견이라도 = 틀릴 수 있음 (예: 모두 만점 / 실제 양식 위반)
- ✅ 단독 의견이라도 = 맞을 수 있음 (예: 한 AI만 메타 문구 검출 / 실재 위반)
- ✅ 단독 의견이라도 = 틀릴 수 있음 (예: 검증 후 0건 = 거짓 양성)
- ✅ 공통 의견이라도 = 맞을 수 있음 (검증 통과 시)

→ **항목별 분리 → 직접 검증 → 개별 판정.**

## How to apply

### 1. 피드백 수령 즉시 — 항목 분해
- 각 AI의 주장 항목을 단위로 분리
- 누가 무엇을 주장했는지 표로 정리 (공통/단독 표시)

### 2. 항목별 직접 검증
- **수치 주장:** Grep / Bash로 실제 카운트 검증
- **양식 주장:** 파일 패턴 직접 확인
- **대사 자연성:** 영어 자연도 + 작품 정합성 분리 검토
- **분량 주장:** 실제 단어 수·런타임 측정
- **메모리 룰 충돌:** 기존 baseline과 대조

### 3. 4 판정 카테고리
- **수용 (확정):** 검증 통과 + 메모리 룰 정합
- **부분 수용:** 일부 타당 + 일부 거부
- **거부 (거짓 양성):** 검증 실패 (실재 X)
- **거부 (기능 정당):** 검증 통과되어도 작품 기능·룰 정당화 시

### 4. 보고 형식
- 표로 모든 항목 (주장자·검증 결과·판정·사유)
- 핵심 발견 (공통이라도 X / 단독이라도 X 사례)
- 채택 범위 + 거부 범위 분리

## 회피 패턴

❌ "3개 AI가 공통으로 지적했으니 수용"
❌ "1개만 지적했으니 미수용"
❌ "다수결로 판정"
❌ "공통 의견 = 신뢰성 높음"

✅ "단독 지적이지만 실재 확정 — 수용"
