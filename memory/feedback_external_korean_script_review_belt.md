# 외부 한국어 대본 검토 belt (2026-07-01 사용자 명시)

**룰:** 외부(한국어) 대본 검토 시 ①프로세스 다이어트하되 ②검수 대상 성격에 맞춰 **agent를 목적별로 다양한 모델에 분배**하고 ③**한국어 히트작(로맨스 계열) 3-4편과 벤치마크 비교**를 반드시 붙인다. "단일패스로 허접하게" 금지.

**Why:** opus가 모든 분야 최강 아님. 반복 수렴 역할(뇌오프 cold-read·단순귀)은 sonnet이 오히려 프록시로 더 맞고, 단독 정밀 발견(정합성·앵커 히트작)은 opus. 히트작 대조 없이는 "왜 안 되는지"가 프레임워크 추정에 그침 — 검증 매출작 DNA와 갭을 대야 처방이 산다.

**How to apply:**
- **belt 표준 (외부 한국어 로맨스 대본 1편):**
  - fresh-eyes-auditor = **opus** (정합성/세계관룰/시간선 Track B·단독 정밀 발견, 가드레일 동봉 필수)
  - 한국 신규시청자 cold-read ×3 = **sonnet** (연령/취향 다르게 — 20대 로판헤비·30대 라이트·40대 사극/신파. 뇌오프·이탈/결제 수렴). ⚠️ funnel-cold-reader는 NA baked라 general-purpose에 한국타깃 커스텀 프롬프트.
  - 한국어 단순귀 ×1 = **sonnet** (대사 유치/설명과잉/연극톤/비문. native-ear-reviewer는 영어 baked → 커스텀).
  - 히트작 DNA 추출 = **앵커(가장 근접 검증히트) opus + 보조 sonnet ×2-3** (8축: 초반훅·페이월·남주유형·여주호·빌런/응징·사이다loop·특수설정처리·화당밀도).
  - **병합·per-line 대조·최종 판정 = 메인(opus) 직접** (위임 금지).
- **🚨 모델-fit 교정 (2026-07-01 사용자 실증): 좁은 패턴 탐지(비문·오탈자·특정 표현 전수)엔 opus 쓰지 마라 — 느리고 토큰 많고 리콜 낮음(빼먹음). sonnet 등 빠른 모델이 오히려 정확·빠름.** 실증: opus 대사분류 chunk가 21·27화 비문("모든 너의 모든 처음"·"살아있음을 느껴")을 놓쳤고 sonnet 단순귀가 잡음. 정리 — opus = *판단 무거운* 발견(정합성·논리·엔진충돌·막장필터), sonnet = *좁은 rubric 탐지*(비문·유치·설명과잉·번역난)+수렴(cold-read). 누락 최소화 = 잘게 쪼개 병렬(구간 6개 등)이 큰 chunk보다 리콜↑.
- **🚨 오탐 주의 — 캐릭터의 거짓말≠정합성 오류 (2026-07-01 사용자 지적):** 화자가 사실과 다른 말을 해도, **관객이 진실을 이미 알고(선행 VO/장면) + 화자에 tell(주춤 등) + 상대가 간파하는 반응**이 있으면 그건 극적 아이러니 블러핑이지 오류 아님. 실증: 8화 아리 "염라 허락"을 belt(fresh-eyes '신호 없으면 오류'로 조건부)와 외부 AI가 '정합성 오류·필수수정'으로 올렸으나, 2화 VO("내 독단·서류상 보류")+아리 주춤+강호 "…아리야" 간파 = 의도된 블러핑. **fresh-eyes의 조건부 flag를 선행 씬 확인 없이 '필수수정'으로 승격 금지.** 대사 정합성 flag는 항상 "관객 시점에서 모순인가(오류) vs 인물이 거짓말하는가(정상)" 판별 후 집행.
- **기계 게이트:** `voice_lint.py`(영어 입말)·`continuity_lint.py`·"한국어 0" = 한국어 대본에 **전량 오탐→무효.** 대신 한국어 grep(화 수·End Hook 수·Hard Cut·씬넘버·등장인물 vs 화자·이름 일관성).
- **.docx 추출:** `unzip -p file word/document.xml | sed 's|</w:p>|\n|g; s/<[^>]*>//g'` + entity 디코드. 브래킷/공백 경로는 따옴표.
- 히트작 라이브러리 = `config/vertical_drama_hit_scripts/` (INDEX.md), 분석 = `..._analysis/` + `_analysis_deprecated_dup/`. 로맨스+운명+집착+초자연 매치로 선별.
- 외부 대본 = 평가/인사이트만, 작품 폴더 등재 X. [[external-ai-input-handling]] [[token-diet-70-percent]] [[vertical-repetition-emotional-not-procedural]] 연동.

**🚨 정량 게이트 필수 (2026-07-01 사용자 지적 "니가 인간 작업물을 어떻게 정성평가"):** AI의 자리는 취향/정성 판정이 아니라 **측정 + 검증 히트작 데이터 대조.** 정성 평가 앞세우지 말 것. 대본 검토 시 반드시 계산:
- **형식 무관 지표로 히트작 N편과 직접 대조:** 총글자·화수·**글자/화·어절/화** (wc -m / wc -w ÷ 화수). 히트작 총글자 wc -m ÷ INDEX 화수.
- **대사 수 교차비교는 형식 불일치로 신뢰 불가** (히트작=볼드 화자명·산문형·콜론 미사용, 우리 △대본=`화자:`). 대본 자체 대사만 정확 산출하고 히트작과 억지 비교 금지.
- **VO(내면 독백) 비율 = 숏폼 적합성 킬러 지표.** `VO:` 카운트 ÷ 전체 대사. 40%↑ = 나레이션/웹툰 톤(안 숏폼스러움). 발화-forward여야 함.
- △컷/화, 씬/화, **런타임 추정 = △cuts×3.24 + 대사어절×0.54 (화당 ≥60초, 숏폼 스윗스팟 60~90초)**. 화당 글자/컷 과다 = 화당 과밀.
- **분량 진단 함정:** "화수 적음=내용 부족→확장"은 오진 가능. 총글자가 히트작 중간권인데 화당 과밀이면 처방은 **확장이 아니라 재분할(re-cut)**. (왕관 실증: 181k자/46화=3,933자/화 = 히트작 2,138~2,880 전부 초과 → 확장 아닌 재분할+VO다이어트). 정량이 외부검토(Codex)의 정성 추정을 교정한 사례.

**실증 2라운드 (왕관을 찾아줘 수정본 53화 · 2026-07-06):** 재분할 처방 반영 확인(46화@3,933자→53화@1,399자/화·히트 991~1,270 상단 근접) + cold-read 3인 만장일치 EP10 결제·전원 완주 = 페이월/중반 절차극 처방 폐쇄. **교훈 ①구조 수술은 반영돼도 라인 지적은 잔존한다("모든 너의 모든 처음" 비문 2라운드 연속 검출) → 재검 진입 시 이전 라인 지적 grep 선행. ②맥거핀 물리모순은 수정 후 형태를 바꿔 재발한다(왕관: 44↔45-46 모순 → 51 접합↔52-53 별개물체 모순) → 맥거핀 소재 타임라인 재구성은 매 라운드 필수. ③프레임워크(응징/사이다 부재) vs 콜드리드(전원 결제·완주) 충돌 시 콜드리드 우선하되, 양쪽 수렴 항목(빌런 약함)만 1순위 처방으로 승격.**
