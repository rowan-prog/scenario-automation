**Why:** 모욕 씬이 "아무튼 메타적으로 모욕씬임" 수준으로 형식만 채우면 분노 몰입이 안 생기고 장르 엔진(억울함→사이다)이 공회전한다. 폭행 성별 룰은 NA 여성향 시청자 수용 한계 — 남성의 고수위 물리 폭력은 로맨스 판타지를 깨고 이탈을 만든다.

**룰:**

1. **토큰 모욕 금지.** 모욕·핍박 씬은 시청자가 몰입해 악역에게 분노할 수준이어야 한다. **1~2비트 수준 금지 — 비트 4+ · 길이 확보.** 가해 발화·군중 반응·주인공의 무력(또는 절제)·잔혹의 구체 디테일이 쌓여야 분노가 산다. "모욕당했다"가 줄거리상 존재하는 것 ≠ 시청자가 분노하는 것.
2. **폭행 성별 룰 (절대):**
   - **남자 → 여주:** 강도 높은 **언어**폭력 + **애매모호한(강도 낮은) 육체적** 폭력까지만 (붙잡기·끌어내기·연행 수준·직접 타격 X).
   - **고수위 물리 폭행 (뺨·가격·약물·사고 연출급) = 같은 여성에 의해서만.**
3. 모욕의 결 다양화 — 같은 "당함"이라도 기능 분화 (조롱/연민-프레임/콘텐츠-소비/배제 등). 반복 굴욕은 엔진이되 같은 모양 반복은 피로.
