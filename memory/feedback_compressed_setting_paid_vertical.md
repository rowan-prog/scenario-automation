# 🔥 씬 수·공간 변화 ≠ 작품 강도 (paid vertical 핵심)

## 사용자 명시 (2026-05-17 — 정정)

> **"에피소드마다 에피소드마다로 전개를 하려고 너무 힘을 주면 문제가 생기는 거야. 심지어는 paid vertical은 단 하루, 단 한 공간의 이야기로 50화씩 쓰는 경우도 있는데."**
>
> **(정정 2026-05-17):** "무슨 재판 만찬이야. 단 하나의 공간으로 쓰란 뜻은 아닌데. 자꾸 무지성으로 룰을 받아들이고 그러지마라. 결혼식/약혼식으로 한 공간을 써 진짜. **이건 제작비 아낄려고 실사vertical에서 하던 방식이야. 좋아서가 아니라고.** 그런데도 불구하고 성공한 케이스가 있다? = **씬이 많을수록, 공간이 자주 바뀔 수록, 다양한 에피소드가 있을수록 좋다는 뜻이 아니란 말일 뿐이다.**"

## 핵심 룰 (정확)

### 1. 씬·공간·EP 다양성 ≠ 작품 강도

❌ **잘못된 강박:**
- "EP마다 새 사건이 있어야 한다"
- "씬이 많을수록 풍부하다"
- "공간이 자주 바뀌어야 시청자 안 지루하다"
- "다양한 에피소드가 있을수록 매출이 잘 나온다"

✅ **본질:**
- 씬 수·공간 수·EP 다양성 ≠ 작품 강도 (무관)
- 강도 = **압력 깊이**로 측정
- EP마다 새 전개 강제 X = 작가 힘 주기 = 분산 위험

### 2. 단일 공간 50화 = 권장 X / 사례 O

⚠️ **오해 회피:**
- 단 하루·단 한 공간 50화 = **실사 vertical의 제작비 한계 사례**
- 좋아서 그렇게 만든 X / 어쩔 수 없이 그렇게 한 결과
- 그런데도 성공한다 = 씬·공간·EP 다양성과 매출은 무관함의 **증거**일 뿐
- "결혼식·재판·만찬 50화" 류 무지성 적용 = ❌

✅ **올바른 적용:**
- 시간·공간·인물 변화의 **자유도는 작품 카테고리·제작 환경에 따라**
- 단 EP마다 변화를 **강제할 필요 X**
- **압력 깊이가 본질**이고 변화는 그 도구일 뿐

### 3. 다양성 강박 회피 4 원칙

1. **새 사건 추가 ≠ 작품 강화** — 같은 사건의 깊이가 강화
2. **새 공간 변화 ≠ 시청자 흥미** — 같은 공간의 새 정보·새 행동·새 권력 변화도 흥미
3. **새 인물 도입 ≠ 풍부함** — 같은 인물의 다른 면이 드러나는 것도 풍부함
4. **새 비트 강제 ≠ 매출** — 같은 압력축의 점진 누적이 매출

### 4. 새 인물 도입 = 거의 100% 같은 압력축 보조 빌런 (2026-05-17 정정)

> **사용자 명시:** "새 인물 도입은 텐션이 낮아지려는 순간 사실상 '같은 역할', 주로, 아니 거의 100% 새로운 악역의 등장이다. 빌런. 메인 악역이 있지만, 이를 보조하는 악역이 추가로 하나 둘 씩 등장한다던가, 뭐 이런 경우가 있겠다. 이야기를 완전히 다른 방향으로 이끌어가거나, 새로운 다른 이야기가 시작되는 식이 아니다."

paid vertical 새 인물 도입 룰:

✅ **채택 (거의 100%):**
- 텐션 낮아지려는 순간 = **새 빌런 추가**
- 메인 악역 보조하는 추가 악역 1-2명 등장
- **같은 압력축 안에서 텐션 보강용**
- 새 빌런 역할 = 메인 빌런이 못 하는 다른 각도의 압력 (예: 메인 = 외부 공격 / 보조 빌런 = 내부 배신·여성 라이벌·다른 가문)

❌ **회피:**
- 새 인물이 이야기 완전 다른 방향으로 이끔
- 새 이야기·새 사건축이 시작됨
- 새 인물이 동맹·조력자 위주 (텐션 낮춤)
- 새 인물이 압력축과 무관한 풍부화 장식

→ **즉 새 인물 = 압력 강화 (빌런) / 압력 분산 X.**
