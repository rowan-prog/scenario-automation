신분/얼굴 강탈 복수물의 연료는 **"남들이 끝까지 도둑(가짜)을 진짜로 믿는다 = 주인공만 억울하다"** 이다. 주변인이 중반에 진실을 알아차리면 억울함이 풀려버리고, EP49까지 버틸 이유가 사라진다. (SHE STOLE v30 vertical 불합격 진단 2026-05-29.)

룰:
1. **EP09~EP48까지 거의 아무도 주인공을 안 믿는다.** 진실을 아는 건 주인공 + 남주 둘뿐. 가짜는 끝까지 "공식 본인"이다. "조용한 진실 연합(allies)"·"나도 알고 있었다(가족)"·"다들 안다"를 중반에 만들면 안 된다. 사적인 의심(예: 약혼남이 속으로 이상해함)은 OK — 단 공개로 안 번지고 판이 안 뒤집힌 채로.
2. **중간 보상 = 진실 인정이 아니라, 판이 안 뒤집힌 채 주인공이 장면 단위로 이기는 것.** 가짜가 훔친 것(옷·펜던트·남자·자리·충성)을 보는 앞에서 하나씩 빼앗아 온다. 빼앗은 뒤에도 세상은 여전히 가짜를 본인으로 안다. 가짜는 맞서 폭로하면 자기 비밀이 터지니 못 싸운다 = 덫.
3. **남주 = 감시·정보망·doctor 매수·feed가 아니라**, 매 블록 "이 여자가 진짜다·건드리면 나랑 싸운다"를 더 크고 비싸고 공개적으로 박는 사람. 단순·강함·소유.
4. **가해자(가짜)는 끝까지 미워야 한다.** 불쌍한 빵집 여자로 조용히 퇴장 X. 마지막까지 훔친 얼굴/이름/남자/자리 중 하나라도 다시 잡으려 발악하다 박살. 추락 행동 비트(사진에 와인·드레스에 힐·증명서 찢기·유리 위 피·거울 깨기)는 좋다 — 단 "정체성 붕괴 예술극"이 아니라 훔친 삶을 지키려는 추한 발악으로 보여야 함.
5. **진짜 인정·진짜 삶 회수·가짜 공개 붕괴는 EP49-50에 몰아라.** EP44에 "다들 안다"면 진짜 climax가 거기로 당겨져 50화가 죽는다.
6. **행정·법·이사회 회수(hold order·board vote·birth cert·boardroom 숫자 브리핑)는 원초적 보상이 아니다.** 회수 = "사람들이 처음으로 본인 이름을 부르는 것". 보드룸 무대는 가능하나 표결·서류·변호사 말 빼고 인간 인정으로. [[vertical-no-admin-power]]

**Why:** 시청자 결제 연료는 "억울한데 아무도 안 믿어줌"의 압력. 그 압력을 중반에 풀면 볼 이유가 사라진다. 점잖은 전략·감시·상류층 회복극은 이 장르가 아니다.

**How to apply:** 새 복수/신분도용 vertical 청사진·집필·검토 시 매 블록 자문 — "지금 세상은 아직 가짜를 진짜로 믿는가? 주인공은 판을 안 뒤집고 장면을 이겼는가? 가해자는 여전히 미운가?" 하나라도 NO면 너무 빨리 푼 것. **검토할 때 line-level 다듬기보다 이 장르 엔진을 먼저 본다** — SHE STOLE 검토에서 174건 line 검수를 돌리고도 이 #1 구조 이탈을 놓쳤다(over-tooling 실패·통찰 0). 관련: [[no-theater-tone]] [[claude-voice-bias-vertical-failure]] [[token-diet-70-percent]]

## Lena 주체성 룰 — 꺾이지 않고·머리 쓰고·빌드업 (2026-05-29 사용자 명시·81점 리뷰)

중반 주인공이 "또 공개장 가서 또 당함"의 수동 반복 = 멍청해 보임·피로(중반 지속력 점수 최저). 주인공은 **당하되 꺾이지 않고·주체적이고·중간중간 머리를 쓰고·빌드업**한다.
- 중반 패배는 **반복이 아니라 축적.** 매 장면 *기능을 다르게*: 공개 폭로 실패 / 사적 증인 확보 실패 / 증거 모았으나 편집당함 / 남주 쪽 사람들이 *믿기 시작* / 빌런 약혼자 *흔들림* / 빌런이 *실제로 실수* / **주인공이 일부러 패배를 미끼로 사용.**
- 중반 이후 주인공 = 그냥 돌진 X → 증거를 남기거나·남주와 미끼를 설계하거나·빌런 반응을 끌어낸다.
- **최종 폭로 = 빌런이 알아서 자멸 X.** 주인공/남주의 빌드업이 회수되고, **빌런의 결핍을 정확히 찔러** 터뜨린다(=정확히 찔려서 터진 것이지 편의적 자폭 아님).
- 남주도 "I know" 반복 의존 X → 중반 이후 "믿어주는 남자"에서 **판을 바꾸는 남자**로 이동.
- 피해자 쇼(자해 등) 논리 박기: 카메라 사각·앵글로 "왜 아무도 진실을 못 봤나"를 반드시 정합하게.
