# 피칭덱 마스터 — 통합 룰

> **본 메모리는 피칭덱 관련 10개 메모리의 핵심을 압축 통합 (2026-05-12).**
> 상세 본문은 기존 메모리에 보존됨: `feedback_pitch_principles_master.md`·`feedback_pitch_planning_logic.md`·`feedback_pitch_marketability_definition.md`·`feedback_pitch_deck_format.md`·`feedback_pitch_reasoning_density.md`·`feedback_pitch_reasoning_rules.md`·`feedback_pitch_deck_quality_root_cause.md`·`feedback_pitch_deck_review_auto.md`·`feedback_pitch_market_conclusion.md`·`feedback_pitch_entry_threshold.md`

## 1. 최상위 락 (작성 원칙)

**작품 밖에서 말하지 말 것.** 작품 안 실제 사건만.

세 가지 회피:
1. 작성자 평가 ("시장성이 있다" / "후킹이 좋다")
2. 구조 해설 ("구조 보유" / "작동한다" / "권력 이동")
3. 메타 알려주기 ("광고 컷으로 잘라 쓰기 쉽다" / "강한 후킹")

## 2. 금지어 35종 (검색 후 우선 의심)

구조 보유 / 작동한다 / 기능한다 / 가능하다 / 확장 가능 / 시장성 보유 / 결제 질문 / 중심 보상 / 핵심 보상 / 후킹 / 시각적 증거 / 화면에 남긴다 / 방향이 보인다 / 첫눈에 잡힌다 / 광고 컷으로 잘라 쓰기 쉽다 / 차별점은 ~라는 점 / 단순한 ~이 아니라 / ~로 기능 / ~의 축 / ~포지션 / 변수 / 자산 / 폐기 / 코어 / 호명 (외 35종)

## 3. 7 최종 검수 (모든 문장 통과 필수)

1. 실제 사건이 있는가?
2. 사람이 움직이거나·물건이 넘어가거나·자리가 바뀌는가?
3. 작품 안의 사실인가? (작성자 평가 X)
4. "구조/기능/작동/가능/보유" 없이도 의미 전달되는가?
5. "그래서 뭐가 벌어지는데?" 묻지 않는가?
6. 무료 구간에서 첫 증거만 주고 더 큰 보상은 남겼는가?
7. 외부 피칭에 그대로 들어가도 부끄럽지 않은가?

## 4. 양식 표준 (피칭덱 형식)

- **포맷 항목 필수:** AIGC Live-action vs Animation 3D/2.5D/2D + 세로형 9:16 vs 가로형 16:9 (남성향 애니 = 가로형 표준)
- **로그라인 한국어** (타이틀만 영어)
- **로그라인 2-3문장** / 절 3개 이하 압축
- **제목 3초 직관성** (형식 자유 — 명사형·분사형·문장형·콜론형 모두 OK / 부제 의무 X / 영문 전체 50 words 이하)
- **키워드(Tropes) = 검증된 영어 트롭** (Forbidden Love·Chosen Bride·CEO Romance·각성·하렘 등 / 자체 용어 X)

## 5. 피칭 사유 작성 룰 (양식 강제 X)

### 양식 자유 — 강점 다각도 서술
"왜 제작 / 시장성 / 변별력" 3문 양식 절대 고정 X. 추상·중복·논리 약화 위험.

**서술 옵션 (작품에 맞게 3-6개 선택):**
1. 정량 데이터 (원작 IP 조회수·매출 — 있을 때만)
2. 완벽한 한 줄 훅 (제목·설정·예고편 10초 일치)
3. 장르 변주 / 무한 쾌감 루프
4. 캐릭터 chemistry / 진짜 버디물
5. 직관적 설정
6. 단일 hook / 페이월 광고 1컷
7. 검증된 트롭 동시 적재
8. AIGC 적합성
9. 장르 안전 락 / 명확한 약속
10. 뾰족·명확 niche 타깃

### 금지 (피칭 사유)
- ❌ **숏폼 시장 성장 근거** ("Sensor Tower 매출 ○○억" / "vertical drama 시장 빠르게 성장")
- ❌ **레퍼런스 약한 작품** (정석급·글로벌 검증만 — Solo Leveling·ACOTAR·Fourth Wing·God of War 등 OK)
- ❌ **전제를 근거로** (위원이 첫 줄에 "이거 누구나 아는 소리"로 거절)
- ❌ **플랫폼명 본문 박제** (ReelShort·DramaBox·NetShort·DramaWave 박제 X — 참조용)
- ❌ **도식화·매트릭스·표**

### 권장
- 작품 자체의 단일 hook / 페이월 응축 / 경쟁작 대비 변별력 (구체)
- 매우 강력한 소재 / 정석급 골격 (글로벌 검증)
- 뾰족·명확 niche 타깃 (결제층 좁지만 강함)
- 검증된 결제 트리거

## 6. 시장성 결론 사용 룰

- "시장성이 있는가?" 항목 결론으로 **"충분한 시장성이 있다"** 또는 변형 사용 OK
- 근거 뒤 결론 = 평가문 X
- 단 **7개 작품 동일 표현 복붙 X** — 작품별 사건·톤·소재 살린 변형 필수

## 7. 시장성 정의 (중요)

- 시장성 = **결제유도력 X** / **장르·트롭·소재 검증**
- 시장성 = 시장 검증 + IP 변환 + 결제 동력
- 남성향 = 게임·애니 reference 추가 OK

## 8. 변별력 작성 룰

- ❌ "차별점은 ~라는 점" (추상)
- ✅ "보통 ~지만 이 작품은 ~" + **구체 사건 + 시각 자산 + 차별점**

## 9. 피칭 사유 밀도 룰

- **줄글로 작성** (표·엑셀 X)
- 충분한 분량
- 직관적·쉬운 언어 (분석적 어휘·BM 언어 X)
- "해야만 하는 쉐어하우스 시즌3 형식" 예시 = 좋은 참고

## 10. 진입선 vs 본체 분리 (피칭덱)

- **피칭덱 진입선 가볍게** (위원이 1초 안에 식별)
- **작품 본체 두께 보존** (mythology·SF·니치 본체 단순화 처방 거부)

## 11. 위원 가상투표 가중치

- **매력 70% / 트로프 직관성 15% / 결제 동력 10% / QA 5%**
- 위원은 얼핏 봄 — QA 미세 흠은 거절 사유 X / 매력·재미·트로프·결제가 거절 사유
- 위원 7인 중 4인 이상 찬성 필요

## 12. 자가 검수 자동 워크플로우 (필수 — 통과 전 보고 X)

피칭덱 작성 = **4단계 자동 1 사이클:**

1. **본문 작성** (메모리 룰 정합)
2. **비문 + 내적 정합성 검수** (조사 오류·시제·주술 호응·중복·인물 동선·소품 위치)
3. **위원 7인 (A-G) 통과 가능성 평가** — 4표 미만 시 **자동 디벨롭** (3 라운드 이내)
4. **시청자 페르소나 진단** (남=08, 여=09 / 활성 + sub-persona 비중 적용)

→ **위 모두 OK 시에만 "피칭덱 작성 완료" 보고.**

### 페르소나 호출 명시

## 13. 피칭덱 7대 근본 결함 (자가 검증 필수)

외부 AI 비교 검수에서 일관 발견된 결함 — 작성 후 자가 검증:

1. **글로벌 IP 스타일 + 페이드 결제 엔진 결합** (자기광고 룰 X — 매 EP 능동성 강제 X / 자연 곡선)
2. **회차별 다층 진척** (외부 변수 + 내부 진척 동시 — 종적 압축 > 횡적 확장)
3. **포맷 표준 점검** (남성향 애니 = 가로형 16:9 표준, 페이드 미스매치 X)
4. **카테고리 검증 단정 회피** ("검증된 카테고리" X → "확장 여지·emerging" 톤)
5. **미시 정합성** (신규 인물 EP6+ 도입 시 EP1-5 빌드업·메인 히로인 감정 곡선·시스템 일관성·동시 합류 캐릭터 깊이)
6. **한국어 표기·문체** (THORNE → 쏜 / 코메디 → 코미디 / "성단 은행" → Galaxy Bank 류 고유명)
7. **AI 자가 비교 검수** (다른 AI가 동일 input으로 작성 시 약점 시뮬레이션)

## 16. 재피칭 피칭덱 양식 (필수, 2026-05-12)

1차 피칭 탈락 후 재피칭 시 피칭덱에 **두 섹션 추가 필수:**

### 16-1. 피칭 회의 내 피드백
- 1차 피칭에서 위원별 거절 사유·통과 사유 요약
- 사용자 추가 질문 (위원의 보충 의견) 명시
- 위원 인지 한계·작품 본질·디벨롭 가능 영역 분리 기록

### 16-2. 피드백 이후 개선 방향 (1차 Drop된 경우 기재)
- 위원 거절 트리거 대응 방향 (수용/거부 명시)
- 수용 사항: 어떻게 청사진·피칭덱에 반영했는지
- 거부 사항: 왜 거부했는지 (시청자 자료·작품 본질 근거)
- 디벨롭 후 추가된 트로프·레퍼런스·AI 강점·메인 카테고리 교육 섹션 등

### 작성 위치
재피칭 피칭덱(`02_pitch_deck.md` 또는 새 버전 `02_pitch_deck_v2.md`) 끝에 두 섹션 명시.

### 활용
- 위원이 1차 피칭 기억하지 못해도 디벨롭 노력·반영 사항 명확
- 위원 신뢰 회복 (위원 거절 → 디벨롭 → 재피칭 흐름 명시)
- 폐기 vs 디벨롭 판단 근거 보존 (참조: `feedback_pitch_pass_fail_judgment.md`)

## 17. "IP 제작 사유" 작성 양식 (필수, 2026-05-12 — 가독성·두괄식)

### 핵심 룰
1. **두괄식** — 결론·핵심 강점 첫 줄에. 위원이 1-2초 안에 파악
2. **가독성 우선** — 다 문장형 X. **가벼운 불렛 + 명사 어미 적극 활용**
3. **레퍼런스 1개 이상 필수** — 구체 작품명·수치 명시
4. **일목요연** — 한 눈에 알 수 있게
5. **세 섹션 (왜 제작? / 시장성? / 변별력?) 분리 = 권장이나 필수 X**
   - 내용 겹치거나 어거지면 **하나로 통합**
   - 세 섹션이 자연스럽게 분리되면 분리 OK

### 작성 패턴 (권장)

**두괄식 + 불렛 혼합:**
```
**[작품 한 줄 핵심 — 매력 결론]**

- 검증: [레퍼런스 1+ — 작품명·수치]
- 결제 동력: [페이월·후킹 핵심 한 줄]
- 변별력: [경쟁작 대비 한 줄]
```

**명사 어미 활용 (적극):**
- ❌ "Werewolf Romance 포맷에 맞춰 Mate 라는 운명적 얽힘을 추가하여 몰입감 강화"
- ✅ "Mate 운명·임신·신분 반전 = US 검증 결제 트로프 3종 동시 작동"

**문장형 + 불렛 혼합 OK** (다 문장형 X):
- 결론 줄 = 문장형 가능
- 근거·디테일 = 불렛·명사 어미

### 회피
- 모든 문장이 줄글 (가독성 ↓)
- 결론 없이 디테일 나열
- 세 섹션이 내용 중복·억지 분류
- 레퍼런스 0개

## 18. 트리트먼트 작성 룰 (필수, 2026-05-12 — 핵심)

### 트리트먼트 본질
- **사건의 흐름** (누가 무엇을 하고 / 어떤 일이 벌어지고 / 어떻게 끝나는가)
- **핵심 비트 + 클리프행어**
- **인물 처지 변화 + 정보 변화**

### 트리트먼트 ≠ 묘사
- 동작 디테일 X
- 미장센 디테일 X
- 시각·소품 디테일 X
- 표정·시선·호흡 디테일 X
- → 이 모든 건 **스크립트 단계 (phase_4)** 에서 처리

### 회피 (잘못된 트리트먼트)
- ❌ "검은 비늘 손가락이 의자 팔걸이에 천천히 놓인다" (동작 묘사)
- ❌ "그녀의 손목 안쪽에서 가는 은빛 빛이 한 번 깜빡인다" (미장센 묘사)
- ❌ "사절단장의 가죽 장갑이 그녀의 왼손에서 왕국 인장을 빼앗는다" (시각 디테일)

### 올바른 (사건 흐름)
- ✅ "베일이 이솔데를 자기 옆자리에 앉힌다. 사절단·신부 후보들이 굳는다. Public Selection 첫 비트"
- ✅ "사절단이 이솔데의 왕국 인장을 빼앗고 떠난다. 이솔데가 성문 앞에 혼자 남는다"
- ✅ "베일이 인간 왕국 깃발을 사절단 발 앞에 태운다. 신부 선언 직전 드래곤 무리 첫 포효. 사절단 무릎"

### 압축·명료 vs 이상한 표현 (분리)

**압축·명료 = 좋음** (필요 시 적극)
- 한 줄로 핵심 사건만 명시
- 군더더기 X

**회피 (이상한 표현):**
- ❌ 이상한 비유 ("그녀의 영혼이 어둠에 잠긴다")
- ❌ 이상한 상징 ("운명의 그림자가 그를 부른다")
- ❌ 이상한 조어 ("호명과 위치를 바꾸는")
- ❌ 이상한 축약어
- ❌ 이상한 개념어·관념어 ("결핍의 정점")

### 트리트먼트 한 회차 구성 (권장)

```
EP[N]:
- [주 기능 한 줄 — 사건 핵심]
- 사건 흐름 (3-5 비트, 사건 단위)
- 클리프행어 (한 줄)
```

**예시 (OFFERING EP3 — 올바른 트리트먼트):**
```
EP3: Possessive Protection 첫 비트
- 자객이 이솔데 침실 침입. 베일이 자객 검을 부러뜨림
- 자객 옷에서 인간 왕국 사슬 인장 발견. 이솔데가 왕국 음모 인지
- 베일이 이솔데를 침실 벽으로 키스. 이후 한 발 떨어짐
- 클리프행어: 이솔데 입술 끝 베일 흔적
```

**vs 잘못된 (현재 청사진 — 묘사 위주):**
```
EP3:
한밤. 검은 성채 깊은 곳, 이솔데의 침실에 횃불 하나만 낮게 타오른다. 검은 모피 망토는 의자 위에 걸쳐져 있다. 그녀가 침대로 다가서는 순간, 천장 들보 위 어둠 한 조각이 움직인다. (...)
```

→ 잘못된 = 시나리오 지문에 가까움. 트리트먼트 X.
