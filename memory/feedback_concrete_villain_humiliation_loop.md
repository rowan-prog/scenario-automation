## 핵심 룰

### 1. 빌런 구조 (절대 — 정정 2026-05-17)

> **사용자 명시:** "개인 vs 집단도, 주인공을 둘러싼 환경 모두가 주인공을 무시하고 거절하고 거부하고 가치를 못 알아보는 환경이어야 한다는거지 빌런이 애매모호하게 익명의 집단들로 처리되도 된다는 뜻이 아니란 말이다. 메인 빌런이 '반드시' 있어야 해 장르 불문하고. 단 하나의 점으로서. 이를 보조하는 수많은 보조 빌런들이 있는거고. 메인빌런이 딱 이 사람 한 명이 못나서 대립구도인 게 아니라, **절대 다수가 이 계통으로 주인공을 압박**한다니까? 장르에 따라 강도·빈도는 다르지만."

#### 빌런 = 메인 1명 + 다수 보조 (전체 환경 압박)

❌ **회피 (애매모호한 익명 집단):**
- "왕국·제국·의회·사절단" — 얼굴 없는 시스템
- "운명·저주·예언" — 추상 권력
- 메인 빌런 부재 / 보조 빌런만 다수
- 메인 빌런 1명만 외로이 대립 (보조 빌런 X)

✅ **채택 (메인 1 + 다수 보조 = 같은 계통 환경):**
- **메인 빌런 1명 (단 하나의 점)** — 얼굴·이름·말투·습관·구체적 행동 / **장르 불문 반드시**
- **다수 보조 빌런** — 메인 빌런과 같은 계통의 압박 (가족·궁정·후보녀·사절·하인·군중)
- **전체가 환경으로 작동** — 주인공을 둘러싼 절대 다수가 무시·거절·거부·가치 못 알아봄
- 강도·빈도 = 장르별 가변

#### 구조 예시 (장르 불문)

**다크 로맨타지 (OFFERING):**
- 메인 빌런 1명 = 이복오빠 (또는 전 약혼자·왕의 사생아 사절 중 1)
- 보조 빌런 다수 = 계모·왕·궁정 신하·전 약혼자·후보녀들·사절단·하인·군중
- 전체 압박 = "저 폐품" "팔린 몸" "고기 방패" "괴물에게 던져진 짐"

**복수극:**
- 메인 빌런 1명 = 동생·가장 가까웠던 배신자
- 보조 빌런 다수 = 동료·상사·가족 구성원·이웃
- 전체 압박 = 비웃음·헛소문·평판 박살

**계약결혼:**
- 메인 빌런 1명 = 시어머니·전 약혼녀·가짜 정실
- 보조 빌런 다수 = 시댁 식구·가문 신하·사교계
- 전체 압박 = 무시·하대·자리 빼앗기

**남성향 능력물:**
- 메인 빌런 1명 = 라이벌 가문 가주·배신한 사부
- 보조 빌런 다수 = 그 가문 자제·동문·관리
- 전체 압박 = 약자 취급·자리 박탈

→ **장르 불문·메인 1 + 다수 보조 = 절대.**

#### 시청자가 결제하며 기다리는 것

> "메인 빌런 + 보조 빌런들 언제 다 망하지?"
> "주인공이 둘러싼 환경이 언제 뒤집히지?"

### 2. 빌런 = 가치 모름 충분히 오래 유지 (정정 2026-05-17)

> 옛 "끝까지 가치 모름·후회물 0건" = **틀린 절대화**. 사용자 정정.
> 한국 vertical 다수가 후회물 (벙어리 아내·하키스타·너의 심장·지독한 사랑·Mommy 등).

❌ **나쁜 후회물 (회피):**
- 악역·남주가 여주 가치를 깨닫고 다시 탐내는 이야기
- 후회가 너무 빨리 와서 시청자 손실 누적 X
- "아, 보석을 놓쳤구나" 류 후회만 잔뜩

✅ **좋은 vertical 후회물 (채택):**
- 오판 때문에 **이미 돌이킬 수 없는 손실** 발생
- 그 손실을 **공개적/감정적으로 갚아야** 함
- 가해자 오판이 **충분히 오래 유지**
- 깨달음은 **손실 이후**에 옴

→ 후회물 자체 = 금지 X / **타이밍·손실 누적·깨달음 위치**가 중요.

### 3. 5-8턴 모욕 교환 패턴 (필수)

❌ **회피 (2-3턴 자른 인장):**
- 빌런: "넌 제물이야"
- 여주: "닥쳐"
- 끝

✅ **채택 (5-8턴 누적):**
1. 가해자 까기: 빌런이 여주 모욕
2. 다시 까기: 여주 반응 보고 더 깐다
3. 추가 모욕: 옆 인물 동조·증인 늘어남
4. 여주 굴욕: 여주가 한계까지 몰림 (떨면서 버팀)
5. 남주 도착: 남주가 상황 인지
6. 가해자 다시 깔보다가: 빌런이 남주 앞에서도 여주 멸시 (오만)
7. 짓밟힘: 남주 폭발 → 빌런 공개 박살
8. 후처리: 빌런이 끌려가며 비명·여주 시점 마지막 컷

**시간 분배:**
- 1-4 (모욕 누적): 씬의 60-70% / 분노 게이지 채우기
- 5-7 (반전): 씬의 20-30% / 카타르시스
- 8 (마무리): 짧은 후처리

### 4. 사이다 루프 (압력축 + 클립 보상 정합)

> 모욕당함 → 바엘과 거래함 → 여주는 떨면서도 선택함 → 빌런은 끝까지 오해함 → 바엘의 소유욕이 터짐 → 공개적 박살

이 루프가 매 EP·매 아크에서 반복 (같은 쾌감 다른 상황 = 클립 보상 루프).

### 5. 빌런 다층 구조 (정정 2026-05-17 — 메인 빌런 단일 고정 X)

> 옛 "메인 빌런 1명 고정" = **틀린 절대화**. 사용자 정정.

**히트작 실제 빌런 구조 (복합):**
- **1차 상처 제공자** (얼굴 있음·1화 첫 모욕)
- **대체 여자/가짜 가족** (보조 빌런 핵심)
- **가족 빌런** (한국 vertical)
- **사회적 보조 빌런** (매장 직원·기자·하인·라이벌)
- **후회/회수 축 남주** (초반 가해자 → 후반 후회·보호)

**중요한 원칙 (단일 메인 빌런 고정 X / 복합 구조 OK):**
- 반드시 "**첫 상처를 준 얼굴**" 있음
- 단 그 얼굴이 **끝까지 단일 메인 빌런으로 남는 것 X**
- 가해자 오판 **충분히 오래 유지**
- 깨달음 = **손실 이후**

**작품별 차이:**
- 단순 사이다물 = 메인 빌런 1명 고정 가능
- 후회물 = 1차 가해자 → 후회 전환·새 빌런 추가
- 신분극 = 메인 빌런 + 대체 여자 + 가짜 가족 복합
- 다크 로맨스 = 외부 가해자 + 남주 자체 빌런 이중

**보조 빌런 다수 = 같은 계통 환경 압박 (1-2명 한도 X / 다수 OK)**
- 가족·궁정·라이벌·후보녀·사절·하인·군중
- 같은 계통으로 주인공 압박 (메인 빌런과 같은 방향)
- 절대 다수가 환경으로 작동 — 무시·거절·거부·가치 못 알아봄
- 강도·빈도 = 장르별 가변
- **다수 OK** — 1-2명 한도 X / "전체 환경 압박"이 본질
- 새 인물 도입 = 거의 100% 새 보조 빌런 (`feedback_compressed_setting_paid_vertical.md`)

**남주 = 빌런 역할도 겸함 (다크 로맨스 한정)**
- 여주가 살기 위해 잡아야 하는 가장 위험한 괴물
- 외부 빌런 = 잔챙이 / 진짜 빌런 = 남주
- 단 — 다크 로맨스 외 장르 = 남주 빌런 X / 메인 외부 빌런이 진짜
