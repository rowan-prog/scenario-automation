## 진짜 실패 원인 (이 파일 기준 — 사용자 직접 분석)

### 1. 초반 1-5화 관심축 이동 (가장 큰 문제)

1화 = 케일럽·베인 가문 분노 생성  
2-5화 = 루시엔 등장·낙인 생성·낙인 규칙·궁전·복수 거래·훈련·세라핀/자히르/발타자르 소개로 이동

→ **시청자 첫 감정 "케일럽 저 새끼 언제 쪽팔리나?" 식는다.**
→ 히트작은 초반 가해자 화면에 계속 붙들어 둠 (천재 아기 은행 루프·Hallyu Divorce·Easy to Comfort Her). Demon Lord는 잠시 다른 장르로 이동.

### 2. 에블린 너무 빨리 완성형 (EP6 검은 심판 변신)

EP1 첫 대사 강함 ("You don't get to decide when I'm finished.")

→ 상승감 X / 스타일 변신만 / **무너졌다가 다시 세우는 거리 부재**

### 3. 가해자 모욕이 너무 품위 있음

케일럽: "Families like ours survive because we do what's necessary." — 논리적 악역
필요한 대사: "네 부모가 죽고 우리가 널 먹여 살렸어. 네 피 하나쯤은 갚아야지." — **천박하고 직접적·댓글 부르는 쓰레기**

### 4. 낙인 = 베인 가문 범죄 증거로는 우회적

낙인 = "에블린이 살아남았고 루시엔에게 속함" 증거
**케일럽이 에블린을 제물로 판 직접 증거 X**

EP8 보상 = "에블린 진짜이고 루시엔의 것" / **케일럽 죄 완전 까발려지는 보상 X**

### 5. 루시엔 위험성 = "행동"보다 "존재감"

EP2 루시엔 = 낙인 부여·규칙 설명·안정화 → 장면 박살 X
필요한 EP2 = 케일럽 손가락 꺾기·제단 베인 문장 불태우기·로드베인 계약 위반 벌금 즉시 새기기

### 6. 조연 너무 빨리 많아짐 (EP6 세라핀·자히르·발타자르)

초반 보상 전 이름 있는 조연 늘어남 → 초점 흐림
히트작 조연 = 초반 기능 매우 단순 (경호원·비서·아이·기자)

### 7. EP8 보상 약간 우회적

현재 = 낙인 공개 + 루시엔 등장 + "Don't touch what's mine"
필요 = 케일럽 가짜 몰아감 → 계약 원문/제단 기록/사망 공고 모순 → 계약 위반 낙인 케일럽 손에 뜸 → 베인 가문 죄 공식화 → 그래도 부정 → "그럼 네 피로 확인하자" → 위반 낙인

→ **첫 보상 루프 완결 X / 죄의 공개 판결 X / 우회**
