scenario-automation 청사진(phase_3) + 집필(phase_4)에서 **일반 소도구** 갯수 최소화.

**대상 — 일반 소도구:** 문서·서신·열쇠·꽃다발·전화기·기기·식기·서류·일회용 도구·미장센 소품 등. AIGC 영상에서 회차 간 등장/소실/이동/교환 추적 까다로움 → 연속성 오류 빈발.

**비대상 (제한적 추가 가능):**
- 캐릭터 정체성 장신구 (디아뎀·사슬·반지·가면·핀·귀걸이) — 히로인 시각 매력 추가 목적 OK.
- 핵심 무기 (검·창·갑주 등).
- 권능 도구 (작품 핵심 메커니즘).

**Why:** 사용자가 2026-05-08에 명시 + 명확화. 일반 소도구(문서·열쇠·꽃·전화기 등 미장센)가 다수일수록 AIGC 모델이 일관성 있게 그릴 가능성 감소. 그러나 히로인의 시각 매력을 더하는 장신구는 제한적으로 추가 가능 — 매력 차별화 기능.

**How to apply:**
1. 새 일반 소도구 도입 시 자문 3가지:
   - 이 비트가 이 소도구 없이도 성립하는가? (성립 시 도입 X)
   - 이미 등장한 소도구로 같은 기능 가능한가? (가능 시 기존 재활용)
   - 회차 간 일관성 유지 가능한가? (어디서 얻고 어디로 가는지 명확해야)
2. **회차당 신규 일반 소도구 1-2개 한도** 권장.
3. 정당화되는 경우만 도입:
   - 정보 운반 (서신·봉인 인장·계급장 — 권력 이동 시각 표지)
   - 핵심 비트의 단일 매개체
4. **히로인 매력 장신구는 별개** — 페플로스 핀·황금 사슬·귀걸이 등 필요 시 추가 OK. 추가된 장신구도 청사진 룩 변형 락에 등재 (회차 일관성 유지).
5. phase_3·phase_4 prompt + CLAUDE + PORTING § L에 등재됨 — 메모리는 백업.
6. 본 프로젝트만이 아니라 모든 작품·트랙에 동일 적용.
