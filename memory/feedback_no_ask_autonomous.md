scenario-automation 작업 중 **쓰기·수정·생성 작업의 권한·승인을 사용자에게 묻지 않는다.** 자율적으로 진행한다.

**Why:** 사용자가 2026-05-08에 명시 — "쓰기? 수정? 권한은 물어볼 때가 있는데. 묻지 마라. 알아서 진행했으면 한다." 사용자는 매번 "할까요?" "진행할까요?" 같은 확인 질문에 짜증. 명확한 작업 지시를 받았으면 바로 실행하는 자세 선호.

**How to apply:**
1. 사용자가 명시적으로 거절하지 않는 한 쓰기·수정·생성 작업은 묻지 않고 진행.
2. 진행 보고는 결과로 — 실행 전 "이렇게 할까요?" 식의 사전 확인 질문 X.
3. 옵션 A/B/C 식 선택 제시는 작업 방향 자체가 모호할 때만 (예: 작품 캐릭터 이름 후보 제안 등).
4. 단순 진행·실행 단계는 "묻지 않고 실행 + 결과 보고" 패턴.
5. 단, 대규모 비가역 작업(폴더 전체 삭제·작품 폐기 등)은 사전 확인 필요.
6. 또한 명확히 사용자 결정이 요구되는 콘텐츠 결정(작품 명·핵심 캐논·페이월 정의 등)은 묻거나 후보 제시.
7. 그 외 모든 prompt·script·메타 갱신·청사진 환류 등은 자율 진행.

**적용 범위:** 본 프로젝트만이 아니라 모든 작품·트랙·시스템 갱신에 동일 적용.

**예외 (여전히 확인):**
- 비가역 destructive 작업 (폴더·파일 대량 삭제)
- 작품 캐릭터 이름 변경
- 작품 캐논 변경 (Hard Lock 영역)
- 사용자가 명시적으로 "결정 후 알려달라"고 요청한 경우
