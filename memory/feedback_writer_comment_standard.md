**2026-07-25 제정.** 사용자 실물 코멘트 3종(TEAM_E 울프스 메이트·The Beast I Chose Over the God)과 AI(Codex) 코멘트 중 사용자가 무시/변형한 것을 대조 분석해 `config/30_writer_feedback_standard.md`로 명문화. 목표 = 대본 수령 시 메인이 사용자 관점으로 자율 코멘트.

**Why:** AI 코멘트의 절반 이상이 헛다리로 판명 — 나노 연속성 지적·미스터리 보존 훈수·수위 자제 권고·로직 프레임은 사용자 최종본에서 전부 버려지거나 정반대로 뒤집혔다("고수위 자제" → "더 늘려보시지요"). 같은 결함도 사용자는 "복선이 없다"가 아니라 "여주가 멍청해 보인다"로 말한다.

**How to apply:**
- 코멘트 전 workspace `config/30_writer_feedback_standard.md` 정독 (4대 관점·형식 법칙·§4 헛다리 필터).
- 판정 한 줄 + 대안 한 줄·대사는 교체 실물 제시·질문형 활용·태그 금지·오탈자 코멘트 금지·첫 코멘트 = 총평.
- 수위 방향은 항상 '더 세게·더 길게'. 정보는 아끼지 말고 직관 우선("수수께끼 느낌은 최대한 덜어야").
- 작가 회수본 대조로 §4 사례를 계속 환류 — 사용자가 내 코멘트를 고치면 그게 최신 기준.
