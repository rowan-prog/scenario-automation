## AI 자동 빠지는 6 함정

### 함정 1 — 부서진 *후*의 미학

❌ "Her face is set the way a face is set when its owner has already finished crying." — 우는 *얼굴*만 / 우는 *행위* X

- 흐느낌·소리·눈물·붕괴 = 화면에 직접

### 함정 2 — 위협을 환경 진동으로 시각화

❌ 의자가 저절로 미끄러짐·바닥이 1/4인치 들썩임·토치 흑염 → 주황
❌ AI 생각: "이게 위협이야"
❌ 시청자 인지: "그냥 의자 미끄러짐"

✅ paid vertical = **얼굴이 위협하는 컷**만 위협으로 인식
- 빌런이 직접 모욕·남주가 직접 살기
- 환경 변화 = 보조 (메인 X)

**예외:** 거대 VFX (산맥 = 드래곤 군단·Wall of Black Fire·sonic boom) = 다른 차원. 메모리 `feedback_fantasy_magic_visual_proof.md` 거대 = 메인 / 미세 환경 진동 = 잔마법 X.

❌ Vael이 자국 하나 남기고 strap 다시 올려줌

❌ 입술 quarter inch 떨어짐
