# Vertical 자체 룰 — 행정/법/정치 어휘·행위 절대 금지

## 0. 핵심 룰

**Vertical drama 자체의 정체성 = TV/HBO 변호사 드라마 아님. 정치 스릴러 아님. 법정극 아님. 행정극 아님.**

성별 무관, 캐릭터 신분 무관 (주인공·악역·왕·여왕·신분 누구든), 작품 장르 무관 (다크 로맨스·power fantasy·werewolf·드래곤·신화 등 모두).

행정·법·정치·외교·hearing·계약·재정·exile·정책 = vertical 본문에 **절대 등장 X**.

사용자가 *명시적으로* "이번 작품은 정치 드라마·행정 드라마·법정 드라마로 가자"라고 지시한 경우에만 예외.

## 1. 배경 (THE OFFERING v33 실패 history)

- v32 작업: queen-administrator 비트 다수 (charter·hearing·exile·writes letter)
- 사용자 1차 지시: "정치 스릴러는 정신병자야"
- 사용자 2차 지시: "악녀 회개 금지·이상한 법·계약·징벌·회계·장부 도입 마라"
- 사용자 3차 지시: "행정파워해라고 명시하지 않는 한 vertical에서는 절대금지"
- 사용자 4차 지시: "여성향 여주 행정 파워 이딴 개념이 없다. 어디에도. 남성향도 마찬가지. 무슨 HBO 변호사 드라마 찍냐?"

→ 4차에 걸쳐 명시. 이제 룰 lock.

## 2. 금지 어휘 (vertical 본문 자동 alarm)

다음이 본문 (대사·서술·VO·dialogue tag) 어디에든 등장하면 즉시 reframe:

**행정·법:**
charter / decree / treaty / policy / doctrine / law / statute / clause
treasury / accounts / ledger / chamber of finance / budget / tariff
hearing / trial / tribunal / verdict / sentence / judgment (formal)
administration / governance / regency / chancellery / council vote / ruling
writ / petition / formal request / appeal / motion
diplomatic / envoy negotiation / accord / pact / alliance treaty
exile / imprison / banish (formal/legal frame)
registry / lineage record / formal mark / certification
investigation / inquiry / audit

**정치 절차:**
council meeting / convene / adjourn / quorum / table the motion
appoint / depose / impeach / sanction / censure
ratify / amend / repeal / enact

**관료 procedural:**
"by the law of ___" / "by my decree" / "I hereby ___"
"the next session" / "the council recommends" / "the chamber finds"
"I sentence ___ to ___" / "I exile ___ to ___"
"formal apology" / "formal recognition"
"writes one letter each season" / "land charter / fishing rights / trade caravans"

→ 발견 즉시 *personal violence + visceral claim + immediate visual* 로 교체.

## 3. 대신 — Vertical 정체성

### 남성향 vertical
**파워 = 직접 폭력·압도적 힘·일격 처치·신분 즉각 역전.**

- ❌ "I, the dukedom of ___, sentence you to ___"
- ✅ 한 마디·한 손가락·적 죽음 또는 굴복

- ❌ council vote에 의해 inheritance 인정
- ✅ 적이 인정하지 않다가 한 발로 부서지며 결국 인정

### 여성향 vertical
**파워 = 알파 남주의 절대 헌신·obsession·소유욕·공개 claim.**

- ❌ "I, queen of ___, decree ___"
- ✅ "My lord. ___." → 알파가 즉시 실행

- ❌ 정치적 협상으로 status 쟁취
- ✅ 모욕한 자가 알파의 한 손에 부서지고, 알파가 그녀를 공개 키스함으로써 status 확정

### 공통 (모든 vertical)
- **갈등 해소 = procedural X / immediate violent or sexual claim O**
- **status 변화 = paperwork X / 행동·violence·키스로 즉각 시각화**
- **빌런 처벌 = 법적 sentence X / personal violence + 영원 굴욕**
- **외부 위협 = 외교 협상 X / 즉시 부상·죽음 또는 폭력적 굴복**
- **시간 흐름 = formal report X / 시각적 변화·신체 변화로 표현**

## 5. 작품 진입 시 적용 룰

**phase_0 (아이디어) 진입 시:**
- 작품 소재에 *정치·법·행정·외교·계약·hearing* 비중 검사
- 비중 30%+ = 사용자에게 *"vertical 정체성 위반 위험 — 정치극 작품인가 확인"* 즉시 물음
- 사용자 동의 없으면 *비중 5% 이하로 압축* + 모든 비트 *personal violence + visual claim*으로 교체

**phase_1 (러프 청사진) 진입 시:**
- 회차당 *행정·정치·hearing* 비트 1개 이상 = warning
- 회차당 2개 이상 = 즉시 *재구성 권고*

**phase_3 (완성 청사진) + phase_4 (집필) 진입 시:**
- 본문 매 EP 작성 후 *위 금지 어휘* grep
- 1개 이상 hit → 즉시 *reframe* + 다음 EP 진행 보류

**phase_5 (검토) 진입 시:**
- 페르소나 검토 외에 *vertical 정체성 검토*도 의무
- 행정 비트 *비중·반복성·노출도* 정량 측정
