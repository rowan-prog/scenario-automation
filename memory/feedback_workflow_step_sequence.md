# 워크플로우 단계 순차 — 절대 단계 생략 금지 (필수, 2026-05-11)

## 발생 사고 (2026-05-11)

사용자 "종합적으로 판단해서, 피칭덱까지 작성 진행하라" → 청사진 (phase_1) 건너뛰고 피칭덱 (phase_2)부터 작성. 사용자 비판: "왜 건너뜀?"

## 원인 분석

1. **"까지" 해석 오류** — "피칭덱까지"는 누적 진행 (phase_1 → phase_2) 의미. "피칭덱만"이 아님.
2. **신규 작품 트리거 누락** — CLAUDE.md "새 작품 시작" 패턴: 폴더 생성 → phase_1 → 메타. 폴더 만든 직후 phase_1 자동 진입해야 했음.
3. **빠르게 ≠ 단계 생략** — 빠르게는 한 단계 안에서 압축. 단계 자체 건너뛰기 X.

## 룰

### 1. 신규 작품 = phase_1부터 무조건 시작
- 신규 폴더 생성 직후 자동으로 phase_1 (러프 청사진) 진입
- 사용자가 "피칭덱·집필·최종고" 등 후속 단계 명시해도 **그 단계까지 누적 진행** (선행 단계 모두 수행)

### 2. "까지" = 누적 진행 (필수 해석)
- "피칭덱까지" = phase_1 → phase_2 (둘 다 수행)
- "최종고까지" = phase_1 → phase_2 → phase_3 → phase_4 → phase_5 → phase_6 → phase_7 (전부)
- "까지" = 최종 도달점이지 시작점 X

### 3. 자가 검증 (작업 진입 시 매번)
- [ ] 사용자가 명시한 단계 전에 선행 단계가 있는가?
- [ ] 선행 단계가 모두 완료된 상태인가? (작품 파일·메타 확인)
- [ ] "까지" 명시면 선행 단계부터 누적 진행하는가?

### 4. 빠르게 모드 적용 범위
- ✅ 한 단계 안에서 압축 (예: 청사진 v1 빠르게)
- ❌ 단계 자체 생략 (예: 청사진 건너뛰고 피칭덱)
- ❌ 검토 라운드 생략
- ❌ 정합성 검사 생략

### 5. 메인 트랙 워크플로우 순서 (CLAUDE.md 기준)
```
phase_1 (러프 청사진) — 작품 본질·회차 락·페이월 정의
  → phase_2 (피칭덱) — 외부 노출용 압축본
    → 03_pitch_outcome.md (사용자 작성 — 피칭 결과)
      → phase_3 (완성 청사진) — 전 화수 화별 락
        → phase_4 (에피소드 집필) — 전 화수 자동
          → phase_5 (페르소나 검토) ↔ phase_6 (패치) [라운드 5회 한계]
            → phase_7 (최종고 게이트 4-Gate)
              → 07_final/ ✅
```

1. 작품 폴더 내 기존 파일 점검 (어느 단계까지 완료?)

3. 사용자가 "건너뛰어라" 명시한 경우만 단계 생략 OK
