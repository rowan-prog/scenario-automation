# 최상위 원칙

**모든 숏폼 콘텐츠는 결핍-욕망-보상 시스템.** 단, 핵심은 **"보상 유예"가 아니라 "보상 단계 설계".**

> 초기 보상은 줘야 한다. 최종 보상은 남겨야 한다. 그 사이에서 시청자의 욕망을 더 커지게 만들어야 한다.

**핵심은 "유예"가 아니라 "격차" — 이미 받은 보상과 아직 못 받은 보상 사이의 격차에서 결제 욕망이 나옴.**

상세 3층 보상 구조 + 장르별 매트릭스 + 모드 분류는 **`feedback_genre_reward_modes.md`** 참조.

# 핵심 보정 (사용자 통합 인사이트, 2026-05-10)

## 1. 숏폼의 핵심은 "보상을 안 주는 것"이 아니다

장르에 따라 **초반에 반드시 줘야 하는 보상**이 있다. 안 주면 시청자가 "이 장르 맞나" 의문 → 다음 화 결제 X → 이탈.

## 2. 보상은 1층/2층/3층 구조

- **1층 장르 진입 보상 (EP1-2 즉시):** 이 장르의 약속 증명. 유예 X.
- **2층 상승 보상 (EP3-5 누적):** 작품 신뢰 형성. 너무 안 주면 답답.
- **3층 최종 보상 (유료 유예):** 페이월은 곧 나올 것처럼 보이는 지점. 완전히 주면 안 됨.

## 3. "유예"가 아니라 "격차"

> 이미 맛을 봤다. 그런데 더 큰 것이 보인다. 아직 그것은 손에 들어오지 않았다. 그래서 다음 회를 눌러야 한다.

## 4. 욕망 강화 방식은 장르마다 다름 (단일 패턴 강제 X)

| 장르 | 욕망 강화 방식 |
|---|---|
| 여성향 복수극·재벌가 역전극 | **패배 누적** (가짜·적의 뻔뻔함, 자리 박탈 심화) |
| 다크 로맨타지 | **거리 차단** (가까워지지만 확정되지 않음 + 다른 후보 견제) |
| 남성향 무쌍·먼치킨·하렘 | **승리 확장** (더 큰 먹잇감·통제 범위 확장 — 패배 누적 X) |
| 루프·재난 | **정보 확장 + 자기 변화 인지** (더 멀리·더 큰 진실) |
| 코스믹 호러 복수 | **의식 자리 전환** (의식·공간·권한의 방향 전환) |

**여성향 사이다 패턴(고난·핍박·박탈 강화)을 남성향 작품에 강제하면 망가짐. 남성향 무쌍 패턴(승리 확장)을 사이다 작품에 강제해도 망가짐.**

## 5. 남성향 핵심 보정 (매우 중요)

남성향에서 "갈망"은 **결핍 악화보다 스케일 확장**에서 온다.
- 복수극: "더 당해서 더 복수하고 싶어지는" (패배 누적)
- 남성향 먼치킨: "이미 이겼는데 더 큰 걸 먹고 싶어지는" (승리 확장)

**남성향 페이월 설계:**
- ❌ "주인공이 아직 약해서 더 강해져야 한다"
- ✅ "주인공은 이미 강하다. 첫 적을 압도했다. 그런데 그 승리로 더 큰 왕좌·더 큰 여자·더 큰 군대·더 큰 도시가 열린다."

# 적용 영역

## 1. phase_1 (러프 청사진) 작성 시
- 1층 보상이 EP1-2 안에 즉시 들어가는지 점검
- 2층 보상이 EP3-5에 누적되는지
- 3층 보상이 유료 구간에 남고 페이월 직전 신호만 있는지
- 욕망 강화 방식이 장르 매트릭스와 일치하는지

## 2. phase_2 (피칭덱) 작성 시
- 트리트먼트에서 위 매트릭스가 사건으로 직접 보여야
- 메타 표현 0건

## 3. phase_3 (완성 청사진) 작성 시
- 12-2 핵심 엔진 = 1층 + 2층 + 3층 매핑
- 12-6 정보 설계 = 무료-유료 구간 한도 점검
- 50화 화별 락 = 1층/2층/3층 구분

## 4. phase_5 (페르소나 검토) 시
- 05 Commerciality / 07 Genre Pleasure 페르소나가 1층/2층/3층 점검
- 1층 부재 시 자동 🔴 (시청자 이탈)
- 3층 누설 시 자동 🔴 (유료 동력 사라짐)

## 5. LOCKED OUT 레퍼런스 (정답 패턴 — 남성향 무쌍 Mode B)

- **1층 (EP1-2):** EP1 굴욕 충격 → EP2 시스템 동기화 즉시 각성
- **2층 (EP3-5):** Cross 잔당 도살 (첫 무쌍) + 여성 캐릭터 합류 시작 + 시스템 권한 단계 회수
- **3층 (유료 EP44):** Cross 옥좌 추방 / 절대 지배 / 하렘 완성 — EP1 데칼코마니
- **욕망 강화:** 승리 확장 (더 큰 시스템·더 많은 여성 캐릭터·더 큰 영토)
