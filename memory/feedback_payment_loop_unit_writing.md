## 핵심 한 줄

> **vertical drama 집필 단위 = 회차 X / 결제 루프 (오판→누적 모욕→증거→공개역전) O.**

## 결제 루프 정의

**한 결제 루프 = 5 단계:**

```
1. 오판 (잘못된 사회적 판결)
   = 구체 가해자가 얼굴 있는 말로 박음 ("저 폐품" / "가짜 아내" / "넌 못 배운 년")
   ↓
2. 누적 모욕 (5-8턴)
   = 가해자 + 보조 빌런 + 주변 수군거림 + 주인공 저항 + 한계 누적
   ↓
3. 시청자 정보 비대칭
   = 시청자만 핵심 정보 앎 (정체·증거·결과) / 악역 끝까지 모름
   ↓
4. 증거물 등장 + 권력 등장
   = 기능 상징 (반지·계약서·VIP 카드·녹음·낙인 등)
   ↓
5. 공개역전 = 발화 + 행동 + 결과 + 다음 훅
   = 단순 발화 X / 즉시 행동·가시 결과·다음 결제 훅
```

## 1 결제 루프 = N 회차 (자연 발생)

- 짧은 루프 = 1-2 회차
- 보통 루프 = 2-4 회차
- 긴 루프 = 5-8 회차
- 작품 전체 = 결제 루프 N개 (작품 길이 따라)

→ **회차 수 자연 결정 / 청사진에서 화수 고정 X**

## 청사진 구조 (체질 개선)

### 옛 청사진 (폐기)
```
| EP | 주 기능 | 열리는 정보 | 닫히는 정보 | 절단 방식 | 다음 화 훅 |
|----|---------|------------|------------|----------|----------|
| EP1 | ... | ... | ... | ... | ... |
| EP8까지...
```

### 새 청사진 (결제 루프 매트릭스)
```
| 루프 # | 오판 (구체 대사) | 가해자 (얼굴) | 누적 모욕 (5-8턴) | 증거물 (기능) | 공개역전 (발화+행동+결과) | 다음 루프 훅 |
|--------|-----------------|--------------|-------------------|--------------|--------------------------|------------|
| 루프 1 | "저 폐품이 살아있네" | 이복오빠 | 사슬·침 뱉기·웃음·체벌·외삼촌 비웃음·하객 수군거림·동의 손짓 | 가문 인장 (위반 sigil 발현) | 루시엔 등장+ 손목 꺾기 + 위반 낙인 + 베인 가문 죄 공식화 | 알드릭 음모 |
| 루프 2 | "가짜 신부야" | 사절단 | ... | ... | ... | ... |
| 루프 N | ... | ... | ... | ... | ... | ... |
```

→ **회차 수 X / 결제 루프 단위**

## 4 페이즈 함수 (청사진에 유지)

| 페이즈 | 함수 | 결제 루프 |
|---|---|---|
| **기** | 오판 누적·첫 보상 | 루프 1-N개 |
| **승** | 큰 진실·새 빌런 | 루프 N개 |
| **전** | 트위스트·정체 폭로 | 루프 N개 |
| **결** | 회수·HEA | 루프 N개 |

→ 각 페이즈 함수만 락 / 회차 수 가변

## 집필 방식 (체질 개선)

### 옛 집필 (폐기)
1. EP1 청사진 따라 집필
2. EP2 청사진 따라 집필
3. ...
4. EP8 청사진 따라 집필
5. 회차 수 강제 → 작가 매 EP 새 비트 만들기 → 분산 위험

### 새 집필 (결제 루프 단위)
1. **결제 루프 1 집필** (오판 → 누적 모욕 → 증거 → 공개역전)
   - 자연 흐름으로 N 회차 발생
2. **결제 루프 2 집필** → N 회차 추가
3. **결제 루프 N 집필** → 자연 회차 수 결정
4. 무료 구간 = 결제 루프 N개 완료 시점 (자연 1차 페이월)
5. 회차 수 = 집필 후 결정

→ **회차 단위 강제 X / 결제 루프 자연 흐름**
