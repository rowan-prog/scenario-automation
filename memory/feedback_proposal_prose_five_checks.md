1. *"무슨 말인지 모르겠음. 침대를 사수? 비유적 암시적 표현이 너무 많음. 상황이 직관적으로 제시되지 않음."*
2. *"'직관적 설정 설명: 치매 걸린 어머니가 중얼거리던 용 조상…' 이 부분은 원작에 없고, 없어도 이해가 되고 그냥 받아들여서 가는데, 굳이 개연성을 위해 추가해서 불필요한 장면이 생겨나고, 이후의 스토리를 '용과 관련된 것'으로 기대하게 만들어 기대불일치가 일어남."*
3. *"능력은 수명/물건의 가치를 알아보는 거면 충분함. 카운트다운이나 이런 복잡한 능력을 다 넣으면 비직관적이게 됨."*
4. *"'목숨을 구해준 대가로 보험 왕조 여회장의 남편이 되어' — 누가 누구의 목숨을 구해줬는데? 보험 왕조가 비직관적임. 걍 초중딩도 알아듣게 해야 함."* + *"트리트먼트도 너무 구구절절 이해 안 되게 써놓음."*

**Why:** 네 지적이 전부 한 뿌리다 — **원작(Countdown King)이 설명 없이 굴러가는 걸 Claude가 '개연성'과 '셀링'을 명분으로 덧칠했다 — 다른 워크스페이스였지만 내 기본값도 같다([[my-prose-defaults-abstract-euphemistic]]).** 용 조상(출처 설명) · 보험 왕조(세계 라벨 교체) · 시계/12만/19-74/유리 패널/갈라/가문 타이머(원작 수치·장치 임의 교체) · "침대를 사수·매장·튀겨내다"(기획 프로즈에 은유). 원작은 병원 재벌·1794 은화·23/80·차 폭발·팔순 잔치였고 전부 더 단순했다. 그리고 이 기획안은 **작가가 그대로 쓰는 스펙**이라([[proposal-is-the-writers-spec]]) 반려가 안 됐으면 대본이 그렇게 나왔다.

**⚠️ 2차 교정 (같은 날) — 설정이 아니라 문장이다.** 내 v2는 설정(용·보험·숫자)만 원작으로 돌려놓고 문장은 「」 컷 재현 + 전보체로 썼다. 사용자: *"자꾸 이야기의 '설정'만 끌고 가지 마라. 회차별 트리트먼트·로그라인의 문장 자체가 전달력이 떨어지고 이해력을 과하게 요구하고 쾌감을 떨어뜨린 문제가 심각하다. 딴 이야기만 하니."* v1 문장의 실패 형태 = 한 문장에 사건 셋(-고/-어 연쇄·주어 증발) / 관형절 더미 뒤에 감정 / 모욕 대사를 보고체로 파묻음 / 추상 명사·은유 동사. 문장 규격 = 로그라인 4문장 골격(모욕 대사→당한 것→반전 실물→페이오프+장르 이름표 · 모델 = 13번 채택 로그라인) · 트리트먼트 = 26 v18 §0-⑤(첫 문장 못 박기·컷 재현 금지·몸이 어떻게 되는지·따옴표 1~2줄·마지막 = 훅). **설정을 고쳐도 문장이 이러면 반려된다 — 반려가 오면 먼저 문장을 보라.**

**⚠️ 3차 교정 (같은 날 · 세 번째) — 직관 ≠ 짧게 끊기.** 2차 교정을 받고 나는 "문장당 주어 1 · 연결어미 ≤1 · 문장당 그림 하나"를 룰로 적고, ✅ 예문을 *"2분 뒤 죽을 여자를 살린다. 그 여자가 병원 주인이었다. 그녀가 키스한다."*로 달았다. 그대로 쓴 v3 로그라인을 사용자가 반려: *"로그라인도 강박이 너무 심해. 짧게 끊어친다. 직관성이라는 말을 오인한 듯? 짧고 끊어 치면 직관적이라고 착각한 듯? 이해가 안 간다. 재미도 없다. 앞문장과 뒷문장 연결도 매끄럽지 않다."* 사용자 채택 모델(13·26)을 다시 보니 문장이 길고 연결어가 다 살아 있다 — 26은 학대 넷을 -고로 한 문장에 쌓고 짧은 아이러니 태그로 받는다. **직관 = 읽는 사람이 재구성할 게 없다**는 뜻이고, 인과를 나르는 연결어(하지만·사실·-자·-는데·-니까)는 직관의 도구라서 지우면 되감기가 생긴다. 반대 방향으로 두 번 틀린 것(v2 전보체 → v3 토막) = 내가 교정을 받을 때마다 **문장 규격을 숫자 제약으로 바꿔 적는 버릇**이 원인. 교정은 모델 문장 verbatim으로 적고 숫자 캡은 달지 말 것.

**⚠️ 4차 교정 (같은 날 · 네 번째) — 로그라인 ≠ 줄거리 요약.** 3차에서 "문장 수는 세지 않는다"로 풀자 v4 로그라인이 무료 8화 비트 열 개(전화→사고→능력→동전→현금→2분→차 폭발→병원 주인→해고→키스)를 사슬로 엮은 400자 요약이 됐다. 사용자: *"진짜 점프 존나 심해서 로그라인 이해가 되지도 않네. 진짜 로그라인이 줄거리 요약임?"* 13번 = 150자 4문장에 사건 하나+반전 하나+페이오프 하나. v5 = 그 길이로 복귀. 오늘 네 번 = 반려 → 설정 복귀(v2) → 토막(v3) → 요약(v4) → 모델 길이(v5): **내 교정은 매번 반대편 벽으로 튄다. 교정을 받으면 룰을 새로 짜지 말고 모델 문장 옆에 내 문장을 놓고 길이·사건 수·문장 수를 맞춰라.**
