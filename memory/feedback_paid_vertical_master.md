# 본문

## Section 1 — 시청자 심리 baseline

### 핵심 (사용자 명시 2026-05-16)

> **"paid vertical drama는 보통, 아주 가까운 사이면서 paid vertical drama를 보는 사람 아니면, 익명이 아니면 공유 안 한다."**
> **"부끄러운 건 욕망만이 아니다. 욕망이 부끄러운 경우도 있지만, 욕망의 해결·해소 방식이 더 부끄러울 때도 있다."**

본 Section = **모든 paid vertical 작품의 기본 baseline.**

### 1-1. 부끄러움 2 차원

**1차원 — 욕망 자체 부끄러움**
- 위험한 남자에게 끌림 (사회 금기)
- 금기 결속·신체 욕망 (다크 로맨타지)
- 강제 받아들임·소유 (사회 금기)

**2차원 — 욕망의 해소·해결 방식 부끄러움**
- 극한 통쾌·사이다 (현실에서 못 하는 정도)
- 압도적 사랑받음·집착받음 (현실 X 환상)
- 정복·하렘·소유 (현실 X)
- 공개 망신·자리 회수 통쾌
- 강제 받아들임 + 결국 사랑받음

→ **2 차원 모두 매출 동력.** 욕망이 점잖아 보여도 (예: 정의 회복·복수) **해소 방식이 사적 통쾌·압도·소유**면 부끄러움 발생.

### 1-2. "정의"의 paid vertical 정의 (사용자 정정 2026-05-16)

> **"'정의'란 무엇인가? 사회적, 법률적, 도덕적 악인들을 벌준다는 거야? 이건 매력적이지 않다. '정의'는 '나'의 가치를 못알아보고, 모욕/멸시/핍박하던 자들을 참교육하는 게 맞지 않냐?"**

paid vertical에서 "정의" ≠ 사회·법·도덕 정상화 (외부 / 매출 약)
paid vertical에서 "정의" = **시청자 동일시 — "나를 무시·모욕·핍박한 자들이 결국 내 가치 인정하고 굴복"** (사적 환상 / 매출 강)

**회피:**
- ❌ "사회적 정의 회복"
- ❌ "법적 처분"
- ❌ "도덕적 악인 응징"
- ❌ "사회 시스템 정상화"

**채택 (시청자 환상):**
- ✅ **"나를 모욕·멸시·핍박한 자들 참교육"**
- ✅ **"내 가치 못 알아본 자들이 결국 굴복·인정"**
- ✅ **"내 자리·이름·증표·아이 공개 회복·인정"**
- ✅ **사적 통쾌·자기 가치 인정 환상**

### 1-3. 장르별 매핑

| 장르 | 1차원 (욕망) | 2차원 (해소) |
|---|---|---|
| **다크 로맨타지·high-heat** | 강 (금기·신체·소유) | 중-강 (mutual claim·공개 선언·라인 디테일) |
| **복수극·재벌가 역전** | **강 (참교육 욕구·내 가치 인정 분노)** | **강 (극한 통쾌·공개 굴복·가해자 망신)** |
| **후회남** | **강 (압도적 사랑받음 + 후회남 인정 환상)** | **강 (후회남 굴욕·집착·구애·인정)** |
| **남성향 무쌍·먼치킨·(준)하렘** | **강 (정복·소유·인정 욕구)** | **강 (압도·하렘·정복·굴복)** |
| **계약 결혼·임신·아이** | 강 (강제·금기·후일 인정) | 강 (받아들임 + 결국 사랑받음·공적 인정) |

→ 모든 장르 **욕망 + 해소 모두 강.** 옛 분류 "복수극 욕망 약 / 해소만 강"은 잘못된 분류 — "정의" 단어를 사회적 의미로 잘못 사용한 결과.

### 1-4. 시청자 행동 패턴

**사실:**
- 익명 환경(앱·플랫폼) 내에서 결제·시청
- 가까운 사람·동일 시청자 외 **시청 사실 공유 X**
- 사회적으로 "내가 이걸 본다"라고 말 안 함

**함의:**
- 시청자 = **욕망에 충실한 타입**
- 돈을 쓰면서 즐기지만 사회적으로 자랑·공유 X
- 사회적 인정·자랑용 X / **사적 만족용**

### 1-5. 매출 함의 — 작품 톤 결정

**채택 (매출 ↑):**
- **사적으로 몰래 즐기는 톤** — 시청자가 혼자 결제할 만큼 강한 욕망·해소 자극
- **직접 욕망 자극** — 우회·은유·상징 X / 신체·소유·금기 직접
- **극한 해소 방식** — 점잖은 화해·정중한 승리 X / **부끄러울 만큼 통쾌·압도·소유**
- **부끄러움 무릅쓰고 결제할 자극** — 약한 자극 X

**회피 (매출 ↓):**
- **사회적 자랑용 톤** — 우아·예술·art-house
- **논설·도덕 우위** — 강한 여주 옳은 말 / 정의·평등 강조
- **고급 톤·literary cadence**
- **점잖은 해소·정중한 처분·합의 통한 화해**
- **사회적 인정·교훈** — "옳은 메시지" 전달

### 1-6. 왜 도덕 우위·예술 톤이 매출 약화하는가

- "내가 옳은 메시지 콘텐츠를 봤다" = 자랑 가능 → 그러나 paid vertical은 애초에 공유 안 함
- 즉 도덕 우위·예술 톤은 **시청자가 굳이 결제할 매력이 없다**
- 시청자가 결제하는 이유 = **"부끄러운 욕망 만족시키고 싶어서"**

### 1-7. 장르별 "부끄러운 욕망" 매출 트리거

**다크 로맨타지 / High-heat**
- 욕망: 금기 결속·소유·신체 / 위험한 남자에게 끌림
- 해소: mutual claim·공개 소유 선언·키스·잇자국·옷 끈·침대 (점잖 X)

**후회남**
- 욕망: 압도적 사랑받음 환상
- 해소: 후회남 굴욕·집착·구애 (극한 — 점잖은 화해 X / 사적 통쾌한 굴욕)

**복수극·재벌가 역전**
- 욕망: 참교육 욕구·내 가치 인정 분노·자리 회수 (사회 정의 X / 개인 환상)
- 해소: **극한 통쾌·공개 굴복·가해자 망신·내 가치 공개 인정** ("이렇게까지 해도 되나?" 수준)

**계약 결혼·임신·아이**
- 욕망: 강제·금기
- 해소: 강제 받아들임 + 결국 사랑받음 + 공적 인정

**남성향 무쌍·먼치킨·(준)하렘**
- 욕망: 권력·정복·소유 욕망
- 해소: **압도·하렘·소유·정복** (점잖한 승리 X / 노골 정복·시청자 자랑 X 수준)

### 1-8. 작품 톤 자가 검수 (2 차원 8 질문)

**욕망 차원:**
1. 시청자가 이 작품을 사적으로 결제할 만큼 강한 욕망 자극인가?
2. 욕망의 직접성·강도가 충분한가?

**해소 차원:**
3. **해소 방식이 점잖은가? (점잖으면 매출 약화)**
4. **해소가 "이렇게까지 해도 되나?" 수준의 통쾌·압도·소유인가?**
5. **시청자가 사적 통쾌·만족 느낄 만큼 극한인가?**

**공통:**
6. 사회적 인정 받으려는 톤이 누적되어 있는가? (있으면 톤다운)
7. 도덕 우위·논설·교훈 cadence가 있는가? (있으면 약화)
8. 시청자가 "혼자 몰래 즐기는" 감 받는가?

### 1-9. 외부 자료·평가 처리
