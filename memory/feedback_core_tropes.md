**조합 패턴 인사이트:**
- **Romance** = 가장 빈번한 핵심 (대부분 조합에 포함)
- **Hidden Identity / Billionaire** = 두 번째 빈번 (재벌 / 정체 숨김)
- **Forbidden Love** = 강도 부여용 (Steamy·Mafia·Age Gap과 결합)
- **Second Chance / Comeback** = 회귀·재결합 동력
- **남성향 단독 조합:** `Dystopia + Awakening + Munchkin` (35번) — 남성향 무쌍·먼치킨 카테고리

## B. 개별 트롭 — 영어 명칭 + 한국어 + 메커니즘

### Romance 핵심 트롭

| 영어 명칭 | 한국어 | 핵심 메커니즘 |
|---|---|---|
| **Flash Marriage** | 선결혼 후연애 | 외형 결혼·약혼·신부 호명 먼저 → 진심·감정 나중. 외형 묶임 + 내면 미완 = 응원 + 결제. ACOTAR / 드래곤 mate / 정략 결혼. |
| **Hidden Identity** | 정체 숨김 | 한쪽이 진짜 신분(재벌·CEO·왕족·각성자·진짜 약혼녀 등) 숨김. 시청자만 진실 인지 = 정보 비대칭 + 폭로 시점 결제 동력. |
| **Forbidden Love** | 금지된 사랑 | 적대 가문 / 신분 차이 / 금기 관계 (스승-제자·약혼자 가족 등). 외부 압력 = 응원 + 답답함. |
| **Love Triangle** | 삼각관계 | 두 남자 사이에서 여주 갈등 또는 두 여자 사이 남주 갈등. 단, paid vertical에서는 진짜 갈등보다 시청자 응원용. |
| **Hate Love** | 적대→사랑 | Enemies to Lovers. 처음 적대 → 점진 사랑. 단, paid vertical 숏폼에서는 빠른 전환. |
| **True Love** | 진정한 사랑 | 운명적·일생일대 사랑. 다른 모든 관계는 가짜·임시. |
| **Sweet Love** | 달달한 사랑 | 가벼운 톤 / 십대·청춘 / Coming of Age와 결합. |
| **Second Chance** | 재결합 | 헤어진 두 사람 다시 만남. 회귀·시간 점프 변형 가능. |
| **Love Affair** | 외도·불륜 | Affair / 비밀 관계. Forbidden Love와 결합 자주. |
| **Contract Love** | 계약 연애·계약 결혼 | Marriage of Convenience. 계약 → 진짜 사랑. Flash Marriage와 결합 자주. |
| **Age Gap** | 나이 차 | Older man·younger woman (또는 역). Forbidden Love·Steamy와 결합. |
| **Destiny** | 운명 | Fated Mates. 운명 단서 = 시청자만 인지 (`feedback_female_target_romance.md` 섹션 6). |

## D. 적용 가이드

**피칭덱 키워드 작성 시:**
- 한국어 의역 X / **정확한 영어 트롭 명칭** 사용
- 위 35개 조합 중 작품에 매칭되는 조합 선택
- 위원이 즉시 식별 가능한 검증 트롭 우선

**작품 설계 시:**
- 트롭 조합 = 작품 정체성 + 결제 동력
- 메인 트롭 1개 + 서브 트롭 2개 = 검증된 paid vertical 구조
- 새로운 조합 시도보다 검증된 35개 조합 우선

**위원 검증:**
- 위원 D (타깃 적합 장르 언어) = 트롭 명칭 정확성 검수
- 위원 E (흥행 가능성) = 검증 트롭 조합 선호
- 위원 F (BM·결제 구조) = Flash Marriage / Hidden Identity / Revenge 같은 결제 트리거 트롭 우선

## F. 트롭 적용 핵심 가이드

**작품에 정확히 매칭되는 트롭만:** 사용자 명시 (2026-05-10) "어거지로 장르/키워드 부여하지 마라."
- 작품 사건·캐릭터·관계에 실제 존재하는 트롭만 키워드 등재
- 시장 인기 트롭이라도 작품에 없으면 X

**최소 5개 / 최대 7-8개:** 키워드는 위원이 즉시 식별 가능한 핵심 트롭으로 압축.

**메인 트롭 1-2개 + 서브 트롭 3-5개 구조:**
- 메인 트롭 = 작품의 결제 동력 핵심 (예: 04 HEIR — Revenge / 02 OFFERING — Flash Marriage)
- 서브 트롭 = 작품 정체성·캐릭터·배경 (예: 04 HEIR — Billionaire / Hidden Identity / Betrayal / Comeback)
