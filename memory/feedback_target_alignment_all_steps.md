# 타깃 맞춤 강제 — 모든 단계

## 핵심 룰 (사용자 명시 2026-05-11)

> **아이디어 생성 제출, 청사진 초안 작성, 피칭덱 작성, 청사진 완성, 스크립트 집필은 '타깃' 맞춤이 제대로 되어야한다. 구조 설계, 소재, 미감, 비주얼 등.**
>
> **이런 관점에서 집필 규칙에, 타깃에 대한 정보가 많이 필요하다. 북미의 남성 시청자, 여성 시청자를 말한다. 또한 검수 차원에서도 타깃 페르소나 또한 보강하여 업데이트해야한다.**

## 타깃 정의 (필수)

작품 타깃 = **북미 남성 시청자 OR 북미 여성 시청자** (한쪽 선명).

- ❌ "혼합" / "전연령" / "남녀공용" 등 모호 타깃 X
- ❌ 두 타깃 동시 만족 시도 X (양쪽 다 잃음)
- ✅ 한쪽 명확히 선택 후 그 타깃에 모든 차원 정렬

## 5차원 정렬 (필수 — 모든 단계 적용)

타깃 맞춤 = 다음 5개 차원이 **모두 동일 타깃에 정렬**:

| 차원 | 정의 |
|---|---|
| **1. 구조 설계** | 보상 루프·페이월·결제 트리거·회차 비트 매트릭스 |
| **2. 소재** | 장르·트로프·카테고리·세계관 |
| **3. 미감** | 톤·분위기·언어 사용·대사 cadence |
| **4. 비주얼** | AIGC 포맷·9:16 vs 16:9·색감·캐릭터 비주얼·룩 |
| **5. 결제 동기** | 다음 화를 누르게 만드는 것 |

**하나라도 어긋나면 타깃 자체를 잃음.** 예: 여성향 작품에 남성향 결제 동기(랭킹·시스템·먼치킨)가 들어가면 둘 다 못 잡음.

## 타깃별 핵심 욕망 (필수 인지)

### 북미 남성 시청자
- **핵심:** "나를 무시하던 세계에서, 내가 판을 읽고, 내 것을 키우고, 강자들이 나를 인정하게 만든다"
- **결제 동기:** 매 3-5화마다 무엇을 얻는가? (새 스킬·랭크·장비·기지·동료·여자·권한·이름값·적의 인정·시장)
- **5대 엔진:** Progression / Competence Porn / Ownership / Status Reversal / Dangerous Female Recognition
- **보상 루프 본질:** 강해진다·해금된다·장비 좋아진다·거점 커진다·판을 읽는다·강자가 인정한다·위험한 여자가 붙는다

### 북미 여성 시청자
- **핵심:** "공개적으로 압도적인 남자에게 선택받고, 무시했던 모두 앞에서 자리·이름·지위를 되찾는"
- **결제 동기:** 회차마다 공개 지위 회복 + 거리 변화 + 남주 비언어 발화 + 여주 능동성
- **Tier 1 트로프:** Alpha CEO / Marriage of Convenience / Secret Baby / Mafia / 외도 복수 / Forced Proximity / Enemies to Lovers
- **시청층 4축:** 출판 카테고리 로맨스 (할리퀸·버클리·발렌타인) + paid vertical (ReelShort 등) + 다크 로맨타지 (ACOTAR·Fourth Wing) + 팬픽 (Wattpad·AO3)

## 단계별 적용

### phase_0 (아이디어 제출)
- **타깃 자료 강제 참조:** 남성향 → `config/target_research/male_target_research.md` / 여성향 → `config/target_research/female_target_research.md`
- 아이디어 4-8개 모두 동일 타깃 정렬
- 카테고리 분산 (남성향: 16 카테고리 중 5개 분산 / 여성향: Tier 1-3 트로프 5개 분산)
- 5차원 자가 점검 명시

### phase_1 (러프 청사진)
- 타깃 자료 + 메모리 + 페르소나 모두 정독 후 진입
- 5차원이 청사진 본문에 모두 정합되는지 검수
- 남성향: 보상 루프 본질 7개 중 회차당 1-2개 작동 / 여성향: 공개 지위 회복·거리 변화·남주 비언어·여주 능동성 회차마다

### phase_2 (피칭덱)
- 시청자 페르소나 (해당 성향) 활성 — 남=08·여=09
- 위원 평가 시 매력·재미 70% / 카테고리 직관성 15% / 결제 동력 10% / QA 5% 가중치 (참조: `feedback_hook_density_vs_qa_weighting.md`)
- 4표 미만 시 자동 디벨롭

### phase_3 (완성 청사진)
- 전 화수 화별 락 — 매 회차 타깃 핵심 욕망 1-2개 비트 강제
- 무료 1-8 페이월 비트 강도 = 타깃별 결제 동기 응축

### phase_4 (스크립트 집필)
- 매 회차 강한 후킹 비트 다발 (90초 3-5개 / 2-3분 5-8개) + 타깃 핵심 욕망 비트 자연 곡선
- 남성향: 매 회차 즉시 충족 (각성·압도·여성 매력·시각 보상) / 여성향: 회차마다 거리·공개 지위 비트

### phase_5 (검수)
- 페르소나 01-07 모두 적용
- **타깃 페르소나만 활성** (남=08만 / 여=09만 / 혼합 X)
- 잘못된 타깃 페르소나가 검수 개입 시 작품 정체성 흔들림

## 잘못된 타깃 정렬 사례 (회피)

### 사례 1: 여성향 작품에 남성향 결제 동기
- ❌ 여성향에 "랭킹 시스템·먼치킨 각성·시스템 창" 추가 — 두 타깃 다 잃음
- ✅ 여성향은 공개 지위 회복·거리 변화·남주 비언어 발화에 집중

### 사례 2: 남성향 작품에 여성향 핵심 보상
- ❌ 남성향에 "남주가 사적 친밀로 여주를 위로함·자기 감정 길게 설명" — 남성 시청자 즉시 이탈
- ✅ 남성향은 행동·압도·여성 인정으로 보상

### 사례 3: 혼합 타깃 시도
- ❌ "남녀 모두 좋아할 수 있는" 작품 시도 — 양쪽 모두 약함
- ✅ 한쪽 선명 → 다른 쪽도 부수적으로 따라옴 (예: 강한 여성향 작품을 남성도 일부 봄)

### 사례 4: 미감·비주얼 미스매치
- ❌ 여성향에 어두운·황량한·과학적 톤 → 시청자 정서 불일치
- ❌ 남성향에 부드러운·핑크·로맨틱 톤 → 시청자 정서 불일치
- ✅ 타깃별 톤·미감 일치 (여성: 따뜻·드라마틱·VFX 부드러움 / 남성: 강렬·압도·VFX 다이내믹)

## 자동 검수 트리거

각 단계 진입 시 다음 trigger 자동 발동:

1. **타깃 미명시 작품** → phase_0 진입 차단
2. **5차원 자가 점검 미수행** → 다음 단계 진행 차단
3. **잘못된 타깃 페르소나 활성** → 페르소나 보고서 무효 처리
4. **혼합 타깃 시도** → 사용자 결정 요청 (한쪽 선택 강제)

## How to apply
