# paid vertical 비주얼 원칙

## 핵심 룰 (사용자 명시 2026-05-12)

> **paid vertical 시장에는 노골적인 욕망, 선입견과 차별, 극단적인 여성성과 남성성이 선호된다. PC주의적이지 않다.**

## 1. 공통 원칙 (전 장르·전 타깃)

### 노골적 욕망
- 알파남 압도·재벌·드래곤·werewolf·고수위·하렘·각성·먼치킨
- "이런 게 욕망이다"를 직설적으로
- 욕망 회피·정치적 우회 X

### 선입견·차별
- 작품 안 선입견·계급·신분·가족 차별·미모 차별·인종·종족 차별 등 그대로
- "공정한 사회" PC주의 X
- 차별 자체가 결제 동력 (모욕 → 역전 사이클)

### 극단적 여성성·남성성
- 여성 = 우아·여성스러움·매력·아름다움 강조
- 남성 = 압도·강함·소유·치명적 강조
- 모호한 중성 X / 양극 강조

### PC주의 X (필수)
- "나는 강한 여자야" 자기 선언 X (남주가 발화)
- "나는 제물 아냐" 자기 선언 X (그가 인정)
- "정치적 올바름" 발화 X
- 욕망 그대로 (할리퀸 Presents·BookTok 다크 로맨타지·페이드 버티컬 검증)

## 2. 장르별 비주얼 룰 분기

### A. 다크 로맨타지 (여성향)
**작품:** OFFERING·Wolfless Mate·ACOTAR류

**시각 대비:** 브라이트 (여주 — 흰·아이보리·실버·진주) vs 다크 (남주 — 검은·붉은·은빛 차가운)
**정서 대비:** 우아·가련·순수 (여주 — 양립) vs 치명적·Possessive·Beast (남주)
**여주:** 우아 + 가련 + 순수 (3 양립) / 강하지만 취약·운명 받음·매달림 X·자제력
**남주:** 검은·비인간 표지·소유적·공개 선언

상세: `feedback_dark_romantasy_engine.md` 대비 원칙 섹션

### B. SF 아포칼립스 / 하렘물 (남성향)
**작품:** LOCKED OUT·하렘물 일반

**남주 중심 다중 여성:** 남주가 시각 중심·다중 여성이 각자 다른 매력
**남주:** 압도적·강함·각성·먼치킨·다양한 매력 (다크만 X / 액션·기능·권력)
**여성들:** 각자 다른 강력 매력·각자 다른 외모 톤·다양한 색·노출 OK·서비스컷
- 엘리트 여성 장교 = 차가운·전술적 미모
- 해커 = 신비·테크 매력
- 의사 = 부드러운 케어
- 전투원 = 강력 매력
- 라이벌 = 위협적 섹시
- AI = 디지털 매력

**시각 키:** 액션·VFX·총기·갑주·우주·아포칼립스 + 노골적 욕망 (서비스컷)
**대비:** 남주 = 강함 / 여성들 = 다양한 매력·각자 다른 외모

### C. 모던 재벌극 (여성향)
**작품:** HEIR (폐기)·SHE STOLE류

**정장·현대·세련:** 모든 캐릭터 모던 톤·재벌·기업 미감
**알파남 (남주):** 정장·시계·날카로움·재벌·위협
**우아한 여주:** 정장·드레스·우아·세련 + 가련함 (외도·시댁 박해·내연녀 등)
**적대자 여성:** 화려·도드라짐·천박함 가능 (내연녀·계모·시댁 적대)
**대비:** 모던 알파남 vs 우아한 여주 / 적대자 여성 = 다른 톤 (천박·계산적)

### D. 남성향 신화·각성 액션
**작품:** TITAN BORN·NetShort 남성향 14편

**남주 (Bastard Son·God Mode·Hidden Heir):**
- 짐승 출발 → 단계적 각성·황금 갑주·왕좌 등극
- 검은 (시작) → 검붉은 (각성) → 황금 (왕좌) 단계
- 어깨 사슬 자국·번개·각성 표지

**여성 (가문 후계·정보 중개·라이벌 등):**
- 각자 다른 강력 매력·각자 다른 외모 톤·노출 OK (장르 톤)
- 가문 색감 (헤라 = 황금 + 핏빛 / 하데스 = 은·검은 / 아레스 = 청동·붉은 / 아프로디테 = 비단·향유)
- 압도적 외모·각자 다른 매력 (남성 시청자 보상 컷)

### E. Identity Theft·Doppelgänger (여성향)
**작품:** SHE STOLE MY FACE

**동일 얼굴 다중 신원:** 진짜·가짜 시각적 동일 (시술 흉터로만 구별)
**진짜 (여주):** 우아·정제됨·순수·자제력
**가짜 (적대자):** 동일 얼굴이나 계산적·차가운 미소·시술 흉터
**시각 키:** 어머니 목걸이·시술 흉터·라이브 카메라 신호

## 3. 우아함과 가련함의 양립 (다크 로맨타지 핵심)

### 양립 가능 (검증 사례)
- ACOTAR Feyre — 우아한 드레스 + 인간·취약·죽을 뻔함
- Crimson Peak Edith — 흰 드레스 우아 + 치명적 위협
- Twilight Bella — 평범 우아 + 뱀파이어 위협
- Hades & Persephone — 봄의 여신 우아 + 죽음의 신에게 끌려감
- Demon Lord's Marked Bride — 우아한 여주 + 데몬 로드 위협

### 양립 메커니즘
- **우아** = 정제된 외모·실루엣·소재·고귀
- **가련** = 처지·취약·위협받는 위치·운명에 끌려감
- → 둘은 다른 차원 (외모 vs 처지) — 양립 가능
- **순수**도 함께 양립 = 우아 + 가련 + 순수 (다크 로맨타지 여주 3 양립)

### 적용 룰
- 외모는 우아·정제·고귀 유지
- 처지·상황은 가련·취약·위협 (작품 안)
- 행동은 자제력·관찰력·매달림 X (취약하지만 자기 자제)
- → 시각 = 우아 / 상황 = 가련 / 행동 = 강함 = 3 양립 완성

## 4. 회피 (모든 paid vertical)

### 의상·비주얼
- ❌ 여주 "타락한 창녀" 톤 (다크 로맨타지)

- ❌ 우아함 강조하다 가련함·순수 부재

### 캐릭터

- ❌ 작품 안 차별 회피 (차별 자체가 결제 동력)
- ❌ 욕망 회피·우회

- ❌ 강한 여주만·취약함 부재
- ❌ 부드러운 남주만·치명적 위협 부재
