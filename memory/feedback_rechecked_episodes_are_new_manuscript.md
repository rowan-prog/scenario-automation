작가 회수본을 검수할 때, **이전 라운드에 이미 검수한 회차를 "지난 코멘트 미반영 목록"으로 축약하지 않는다.** 전 회차를 처음 보는 원고처럼 같은 밀도로 다시 읽는다.

**Why:** 사용자 교정(2026-08-11, 16_moses 최종 대본) — "1-30화는 대충하란 의미가 아니었다. 31-50화는 처음이니 더 꼼꼼하게 하란 의미였지." 나는 이미 두 라운드 돈 1~30화를 미반영 24건 리스트로만 처리했고, 31~50화만 회차별로 팠다.

실제로 재검수하니 1~30화에서만 신규 발견이 30건 넘게 나왔다. 그중 결정적인 것 셋:
- **작가가 고치면서 맞던 걸 틀리게 바꾼다.** 1화 새 의식 문구가 가이드 확정문("새가 내려앉은 자가 너희의 배필이 될 것이다")에서 "이 새가 선택한 자"로 바뀌어 있었다. 지난 원고엔 맞게 들어 있었다. 선택 주체가 새로 옮겨가 4화 "내가 이 남자를 선택했으니까"와 정면 충돌.
- **작가가 새로 넣은 컷이 새 위반을 만든다.** 2·3화에 비둘기 주변 황금빛 모래·날개 광채가 신설돼 있었다(원고 diff에만 보임).
- **전제를 무너뜨리는 구멍은 라인 코멘트 라운드에서 안 잡힌다.** 26화에서 왕궁 사자가 모세의 은신처 안으로 걸어 들어와 이름을 부른다 → 유료 구간 전체가 서 있는 "파라오는 모세를 못 찾는다"가 붕괴. 두 라운드를 지나도록 아무도 안 짚었다.

**How to apply:** 회수본 검수 = ①전 회차 정독(기검수 구간 포함) ②직전 판본과 diff를 떠서 *바뀐 자리*를 따로 본다 — 신규 오류는 거의 거기서 난다 ③미반영 목록은 재검수 결과에 [지난 코멘트] 태그로 합쳐서 내보내지, 별도 축약 섹션으로 만들지 않는다.
