## 2. 위원 반응 패턴 (9개 작품 raw data 분석)

| 패턴 | 특징 | 작품 설계 시 |
|---|---|---|
| **통과 강력** | 트로프 결합 + 검증 + 메타 후킹 | 검증 트롭 3+ 결합 |
| **턱걸이** | 니치 + 라인업 확장 + 자생 팬덤 (원작 IP 한정) | 원작 검증 자료 강조 |

## 3. 작품 설계 6 체크리스트 (위원 통과 가능성)

6. **결제 동기 명확?** (F 위원)

## 4. 제목 룰 (피칭덱 평가 detail)

- **제목 형식 자유** — 명사형·분사형·문장형·콜론형 모두 OK
- **영문 전체 (메인 + 부제) 공백 포함 50 words 이하**
- **부제 의무 X** — 메인 타이틀로 갈등·장르·후킹 소재 읽히면 부제 없음
- **부제는 메인에 빠진 필수 후킹 소재 보강용으로만** (예: "LOCKED OUT: I Rule the World With My AI Girls")
- **남성향 작품에서 하렘은 필수 평가 기준 X** — 작품 정체성 = 권력 획득·위계 전복·스케일 보상이면 그 기준으로 (준하렘 보정 별도)

### 위험 예 (모호·추상 — 부제 검토)

## 5. 거절 어휘 (회피)

피칭덱·청사진에 다음 표현 사용 시 위원 즉시 거절:
- "차별점은 ~라는 점" / "단순한 ~이 아니라"
- "광고 컷으로 잘라 쓰기 쉽다" / "강한 후킹"
- "구조 보유" / "작동한다" / "기능한다"
- "시장성이 있다" (근거 없이 결론만)
- "구조가 선명해진다" / "의미를 알 수 있다"

## 6. 1차 오해 시뮬레이션 (필수 자가 검증)

작성 후 자가 시뮬레이션:
- "위원이 첫 줄 보고 무엇으로 오해할까?"
- "1초 안에 장르·갈등·결제 동기 식별 가능한가?"
- "추상 어휘로 오해되는 부분 0건?"

→ 오해 가능성 1%+ 발견 시 재작성.

## 7. 위원 판단 정정 (필수)

### 잘못된 위원 시뮬레이션 회피
- **위원은 일반 남성향 (Mafia·CEO·복수극) 잘 알고 있음** — 그건 "식상" 아님
- **위원이 모르는 건 딥 장르만** (이세카이·LitRPG·Progression Fantasy 등 niche)
- 다른 AI가 "위원이 이건 식상할 것"이라고 잘못 추측 시 무시
- 검증 장르 = 식상감 추측 X / 식상감 = 위원이 직접 말한 경우만

### 검증 룰
- 위원 7인 (A-G) 시뮬레이션 시 각자 판단축 정확히 적용
- 추측·일반화 X / 위원별 명확한 거절 이유·통과 이유

## 8. 페르소나 vs 위원 분리 (필수 인지)

- **위원 7인 (A-G)** = 피칭덱 평가 (phase_2)
- **페르소나 01-07** = 스크립트 검토 (phase_5) — 피칭덱 X
- **페르소나 08-09 (시청자)** = 피칭덱 + 스크립트 양 단계

→ 페르소나 7인을 피칭덱 평가에 호출 X. 위원 7인 A-G가 피칭덱.

## How to apply

- 페르소나 호출 시 위원 vs 페르소나 분리 인지
