## 2. 본문 섹션

- **해당 IP 피칭 사유 (Core Expectation):** 왜 제작 / 시장성 / 변별력 — **줄글로 작성** (엑셀·표 X)
- **주요 인물 소개:** 캐릭터별 한 문단. 외모 + 시작 위치 + 관계 + 변화 방향
- **줄거리:** 한 페이지 분량. 시작 → 페이월 → 후반 방향
- **초반 회차 트리트먼트 (1화~Paywall 화):** EP1 ~ EP6/EP8 각 회차 별 트리트먼트 + 클리프행어

## 사용자 최종 워싱 14 인사이트 (필수, 2026-05-11)

5작품 (TITAN/OFFERING/HEIR/FACE) 사용자 최종 워싱에서 추출. 향후 피칭덱 작성·검수 시 자가 검증.

### 1. 타이틀 한 단어 = 작품 본질 좌우
- "짐승이 **된** 반신" (변신) vs "짐승이라 **불린** 반신" (호명 박탈)
- 작품 핵심 메커니즘에 정합하는 어휘 정확 선택

### 2. 장르 = 큰 카테고리부터, 좁은 서브 회피
- "신화 액션·다크 판타지·남성향 복수극" (좁은 서브) → "판타지·신화·액션·남성향 파워 판타지" (일반)
- 좁은 분류는 키워드·줄거리에서 다룸

### 3. 키워드 = 검증 일반 트롭 + 작품 모티프 명시
- "Slave-to-King" (좁음) → "Munchkin" (검증된 큰 트롭)
- "Demigod·Greek Mythology·The Chosen One" 같은 소재 명시 트롭 추가
- Munchkin·Hidden Identity·Demigod·Greek Mythology·The Chosen One 같이 7-8개까지 가능

### 4. 로그라인 = 단순·직접·직관 (추상·세부 단위 제거)
- "신들의 **권한**을 한 **가문씩**" (추상+세부) → "신들의 **힘**을 **하나씩**" (직접+단순)

### 5. 레퍼런스 별도 양식 항목
- 왜 제작 본문 안 인용 작품 → "**레퍼런스:**" 항목 분리 가능
- 형식 줄 아래 "레퍼런스: 갓 오브 워 등 (기타 그리스 신화 소재 액션물 등)" 식

### 6. 세로형/가로형 = 작품 비주얼 우선
- 페이드 버티컬 = 세로형 기본이나 드래곤·성채·VFX 스케일 큰 작품은 가로형 OK
- OFFERING (드래곤 로맨타지) = 사용자 최종 가로형 결정
- TITAN (신화 액션 격투장) = 가로형
- HEIR·FACE (현대 복수극) = 세로형 (모바일)

### 7. 피칭 사유 양식 자유도 (작품별 결정)
- 셋이 자연 한 흐름이면 1단락 통합 (OFFERING·HEIR·FACE)
- 셋이 명확히 다른 각도면 3섹션 유지 (TITAN)
- 핵심: "왜 이 IP를 피칭하는가?" 답

### 8. 작품 전체 단어 통일 (필수)
- 같은 의미 다른 단어 = 정합성 위반
- FACE 사례: "클리닉" → "시술" 전면 통일 (클리닉 파일 → 시술 기록, 클리닉 정보 → 시술 정보, 클리닉 예약표 → 시술 예약표)
- 작품 최종본 작성 시 단어 통일 grep 검사 필수

### 9. 인물 소개 첫 문장 = 인물 핵심 관계
- 마라 = "레나의 친구" (배신 본질) — 빠뜨리면 작품 정체성 흐림
- 인물 관계 (친구·시동생·부친 등) 우선 명시

### 10. 원본 vs 조작본 구분 명시 (정체성 작품)
- "원본 시술 기록" vs "조작된 시술 사후관리 기록"
- 작품 핵심 자료의 진위 구분 = 폭로 비트의 핵심

### 11. EP 단순화 = 한 동작 흐름 ("~다가 ~한다")
- 두 별도 동작 → 한 흐름 자연 연결
- 예: "TV로 손 뻗는다 + 얼굴 붕대 닿음" → "TV를 향해 손을 뻗다가, 곧 자기 얼굴의 붕대를 만진다"

### 12. 한국어 동사·조사 자연화
- 과한 동사 → 일반 동사: "묶인다 → 잡힌다" / "돌려놓다 → 돌리다"
- 강조 조사 과용 회피: "할드렌만은 → 할드렌은"
- 어색 한자어 회피: "가사망 확인서 → 사망 확인서" / "정밀 사인 검진 → 정밀 사인 확인"

### 13. EP 사물 동선·위치 명확화
- "검이 카엘 발자국 따라간다" → "카엘 쪽으로, 모래 위에서 발자국 따라" (방향·표면·동선 3단)

### 14. EP 어휘 시대감 정합
- 시대 어긋남 회피: "프레스코" (이탈리아·르네상스) → "벽화" (그리스 시대 정합)
- 작품 시대 배경에 맞는 어휘 선택

## 페이드 버티컬 톤 (필수, 2026-05-11 추가)

피칭덱 전체 톤은 **ReelShort·DramaBox·NetShort·GoodShort** 같은 북미 페이드 버티컬 숏폼 플랫폼의 검증 양식을 참고. HBO·Netflix 같은 프리미엄 드라마 톤·레퍼런스 금지.

### 장르 (Genre) — 최대 3개, 가장 잘맞는 순

- 최대 3개. 가장 잘맞는 것부터 순서대로 입력.
- 페이드 버티컬 검증 카테고리 명칭 사용 (광범위 "판타지/액션" X, 구체 카테고리 ○).
- **장르 ≠ 트롭** — 장르와 트롭은 구분되어야. 같은 단어가 양쪽에 들어가면 X (예: 장르 "Power Fantasy" + 트롭 "Power Fantasy" = 중복).
- **장르 금지어 (2026-05-11 사용자 명시):**
  - ❌ **"스릴러"** — 너무 광범위·진부. 작품 본질을 더 정확히 잡는 한국어 카테고리로 (예: 음모극·역전극·드라마·복수극)
  - ❌ **"미스터리"** — 진짜 니치한 작품에만. 일반 작품에 쓰지 말 것
- 작품별 적용 사례 (2026-05-11 최신):
  - TITAN: "신화 액션 / 다크 판타지 / 남성향 복수극"
  - OFFERING: "다크 로맨타지 / 고딕 판타지 / 여성향 로맨스"
  - HEIR: "여성향 현대 복수극 / 재벌물 / 유언장 역전극"
  - FACE: "여성향 현대 복수극 / 재벌물 / 신분 음모극"

- **카테고리 명칭 정정 (2026-05-11 사용자 명시):** "재벌가 드라마" → **"재벌물"**. 한국 페이드 버티컬 검증 카테고리 명칭으로 통일.

### 트롭 (Tropes) — 최대 5개, 가장 잘맞는 순

- 최대 5개. 가장 잘맞는 것부터 순서대로 입력.
- 페이드 버티컬에서 검증된 영어 트롭 명칭 사용:
  - 남성향 액션/판타지: Revenge / Hidden Bloodline / Awakening / Power Fantasy / Slave-to-King / Munchkin / Mythological Setting / System / Dungeon
  - 여성향 로맨타지: Sacrificial Bride / Dragon Romance / Fated Mates / Forbidden Love / Possessive Male Lead / Werewolf / Fake Mate / Public Claim
  - 여성향 현대 복수극: Heiress Comeback / Cheating Husband / Pregnant Mistress / Hidden Will / Identity Theft / Fake Fiancée / Wronged Woman Returns / Regret Male Lead / Second Chance
- 작품별 적용 사례:
  - TITAN: Revenge, Hidden Bloodline, Awakening, Power Fantasy, Slave-to-King
  - OFFERING: Sacrificial Bride, Dragon Romance, Possessive Male Lead, Forbidden Love, Fated Mates
  - HEIR: Heiress Comeback, Cheating Husband, Pregnant Mistress, Hidden Will, Revenge
  - FACE: Identity Theft, Fake Fiancée, Wronged Woman Returns, Regret Male Lead, Revenge

### 로그라인 — 후킹력 분명 (설명충 X)

- 3줄 이내. 한국어. 평어체.

- 작품별 적용 사례 (사용자 OK):
