scenario-automation의 모든 외부 노출 문서(로그라인·줄거리·트리트먼트·인물 소개·페이월 응축 등)는 다음 6종 anti-pattern을 자동 검수해야 한다. 위반 시 작성자(또는 AI)가 "잘 썼다"고 착각하지만 사용자·위원·시청자는 "이게 뭐야"라고 외면한다.

**Why:** 사용자가 2026-05-10 03 EMPIRE 로그라인 v3.1에 대해 격렬한 거부감 표현 — "이름을 지웠다는 게 은유,암시적이잖아 / 도착한 어둠은 어디야 / 손등 문양에 응답해? 이상한 표현이야 / 왜 회수하러 왔어? 버려놓고? 진짜 답답하다. 궁금하게 만드는 게 아니라, 이게 뭐야 하고 외면하게 만든다." 사용자 명시: "당장 해당건만 수정하는 게 아니라, 이런 일이 발생하지 않도록 해야 한다."

기존 메모리(`feedback_pitch_principles_master.md` / `feedback_intuitive_visualization.md` / `feedback_directness_density.md` / `feedback_logline_rules.md`)가 있음에도 발생한 이유 = 검수 항목이 추상적이고 anti-pattern 카탈로그가 명시되지 않음. 본 메모리는 **anti-pattern 카탈로그 + 검수 룰**.

## 7종 Anti-Pattern (검출 시 즉시 재작성)

### A1. 은유·암시 (실제 사건이 아닌 표현)

**증상:** 작가는 "강한 표현"이라고 착각하지만 독자는 "이게 무슨 뜻이지?"
- "이름을 지웠다" — 실제로 이름을 어떻게? 코드네임만 남긴 거? 호명 금지? 모호.
- "그를 잘라냈다" — 실제로 자른 게 뭐? 권한? 직위? 관계?
- "그의 자리를 비웠다" — 비유. 실제 사건 없음.
- "그의 빛이 꺼졌다" — 추상.

**대체:** **사실 그대로 명시.** 본문 사실 인용.
- "이름을 지웠다" → "코드네임만 남기고 인간 이름을 회수했다" / "호명을 금지했다"
- "잘라냈다" → "직위에서 해임하고 통제권을 회수했다"

### A2. 장소 모호 (어디서 일어나는가 안 보임)

**증상:** "도착한 어둠 속" / "그곳" / "그 너머" / "어딘가" — 어디인지 안 보임.
- "어둠 속에서 깨어났다" — 어둠은 어디?
- "그곳에서 만났다" — 그곳이 어디?

**대체:** **구체적 장소 명시.** 좌표·지명·건물·공간 명사.
- "어둠 속" → "사라진 함대 좌표 / 황실 통제권 밖 정찰 좌표 / 우주 끝의 잊혀진 행성"
- "그곳" → "검은 성채 / 격투장 모래 위 / 호텔 로비 / 회의실 식탁"

### A3. 추상·인격화 동사 (시각적이지 않은 동사)

**증상:** "응답해 / 호응해 / 동조해 / 화답해 / 함께 떨고 / 같은 결로 / 같은 빛으로 / 자아내 / 환기시킨다 / 구현된다 / 기능한다 / 작동한다" — 사물이 인격을 가진 듯한 추상.

**대체:** **시각적 동사·구체적 사실 동사.**
- "그의 손등 문양에 응답해 깨어난다" → "그의 손등 회로 문양과 같은 빛으로 깨어난다" / "그의 손등 문양과 동일한 패턴으로 점등된다"
- "그녀에게 호응해 떨린다" → "그녀의 디아뎀이 함께 짧게 흔들린다"
- "운명에 화답한다" → 사용 금지 (구체 X)
- "구현된다 / 기능한다 / 작동한다" → 사용 금지 (메타 표현 — `feedback_pitch_principles_master.md`)

### A4. 인과 모순·누락 ("왜?"가 안 보임)

**증상:** A → B인데 A와 B의 인과가 모순되거나 빠져 있음.
- "버려진 그를 회수하러 왔다" — 버려놓고 왜 회수? (모순처럼 읽힘)
- "처분한 자에게 명령을 내렸다" — 처분한 자가 어떻게 명령?

**대체:** **본문 사실 인과 그대로 노출.** 전제·이유 명시.
- "버려진 그를 회수하러 왔다" → "정찰 임무로 보내진 그가 거대한 전함을 깨우자, 회수 명령을 받은 함대가 진입한다" (인과: 정찰 → 전함 깨움 → 회수 명령)
- 또는 사실 자체를 명시: "처분 임무로 보냈다" 명시 후 "그러나 그가 X를 발견하자 함대가 회수하러 왔다"

### A5. 만연체·종속절 다수 (한 문장에 정보 과잉)

**증상:** 한 문장에 종속절 3개 이상 / 30단어 이상 / 정보 5개 이상.
- "제국이 마지막 병기로 부린 뒤 이름조차 지우고 황실 통제권 바깥으로 보낸 RAVEN-9는, 어두운 좌표 너머에서 자기 손등 회로 문양과 같은 패턴으로 깨어나는 거대한 검은 전함을 만난다."
- 종속절 3개 + 만연 + 30단어 = 답답.

**대체:** **단문 분리.** 한 문장 = 1-2 정보.
- "제국이 정찰 병기 RAVEN-9에게 남긴 이름은 코드네임뿐이었다." (1 정보)
- "사라진 함대 좌표로 보내진 그 앞에서 거대한 고대 전함이 그의 손등 회로 문양과 같은 빛으로 깨어난다." (2 정보)

### A6. 세계관·고유명·구체 사건 누락

**증상:** "그 / 그녀 / 그곳 / 어떤 / 무언가" 같은 추상 지시어로 대체되어 세계관·인물·물건이 안 보임.
- "그가 그곳에서 무언가를 발견했다" — 누가 / 어디 / 무엇? 안 보임.

**대체:** **고유명·세계관 어휘·구체 물건 노출.**
- "RAVEN-9가 사라진 함대 좌표에서 거대한 고대 전함을 발견했다."
- 인물 = 이름. 장소 = 좌표/공간 명사. 물건 = 구체 명사 (반지·계급장·기함·디아뎀).

### A7. 방향·대상·감정 없는 물리 동작 (클리프행어·반응 동사 특히 빈발)

**증상:** 물리적 동사이지만 **누구를 향해 / 어디로 / 어떤 감정으로**가 누락되어 의미가 흐릿. 클리프행어·반응 컷에서 자주 발생.
- "고개를 돌린다" — 어디로? 누구로부터? 감정?
- "물러난다" — 어디로? 왜?
- "한 발 비킨다" — 누구를 위해?
- "고개를 숙인다" — 누구에게? 어떤 감정?
- "선언 앞에서 고개를 돌린다" — "선언 앞"은 추상 위치 + "고개를 돌린다"는 방향 없음 = 이중 추상.

**Why:** 2026-05-11 OFFERING EP8 클리프행어 "사절단장이 바엘이 끝맺지 못한 선언 앞에서 고개를 돌린다" 거부. 사용자: "아 왜 자꾸 추상 남기는거야." A1-A6 검수에서 빠지는 사각지대 — 동사가 물리적이라 추상으로 인식 안 됨.

**대체:** **방향 + 대상 + 감정/의미** 동시에 명시.
- "고개를 돌린다" → "이솔데를 두려운 눈으로 돌아본다" (대상 + 감정 + 방향 함의)
- "물러난다" → "황금 디아뎀을 만지며 한 발 뒤로 물러난다" (소품 + 방향)
- "한 발 비킨다" → "이솔데가 앉을 자리를 비우려 비단 자락을 정리하며 비킨다" (이유 + 동작)
- "고개를 숙인다" → "이솔데 앞에서 처음으로 시선을 내린다" (대상 + 신호)

**검수 질문:** 이 동작의 **대상**(누구)·**방향**(어디로) ·**감정/의미**(왜)가 한 줄에 모두 있는가? 1개라도 빠지면 추상.

## 검수 강제 적용 (필수)

작성자(또는 AI)는 외부 노출 문서 작성·재작성 시 다음 7 검수 항목을 모든 문장에 적용:

1. ❓ 이 문장에 **은유·암시**가 있는가? → 사실로 교체.
2. ❓ **장소가 명확**한가? → 구체 장소 명시.
3. ❓ **추상·인격화 동사**(응답·호응·동조 등)가 있는가? → 시각적 동사로 교체.
4. ❓ **인과**가 명확한가? "왜?"가 답하는가? → 전제·이유 명시.
5. ❓ **만연체**인가? 한 문장 30단어 이상 / 종속절 3개 이상? → 단문 분리.
6. ❓ **세계관·고유명·구체 사건**이 보이는가? → 추상 지시어 → 고유명.
7. ❓ **물리 동작에 대상·방향·감정**이 모두 있는가? (특히 클리프행어·반응 컷) → 1개라도 빠지면 명시.

**검수 통과 기준:** 7 항목 모두 통과해야 외부 노출 가능. 1개라도 위반 시 재작성.
