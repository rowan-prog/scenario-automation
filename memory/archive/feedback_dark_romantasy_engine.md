# 다크 로맨타지 결제 메커니즘

## 핵심 룰 (사용자 명시 2026-05-12)

> **Humiliated → Chosen → Protected → Revealed → Vindicated → Desired 공식은 일반 여성향(재벌 모던·외도 복수·CEO 로맨스). 다크 로맨타지는 다른 공식.**
> **다크 로맨타지 = Fated Bond 발현 + Possessive Claim + 비인간 운명. 인간 정치 X / 운명적 결속 강도가 결제 동력.**

## 두 공식 분리

### 일반 여성향 공식 (재벌 모던·외도 복수·CEO 로맨스·HEIR·SHE STOLE)
> **Humiliated → Chosen → Protected → Revealed → Vindicated → Desired**

- 핵심: **공개 지위 회복** + 인간 사회 정치 복수
- 결제 트리거: 가족·시댁·전남편 굴복·공개 자리 회복
- 적용 작품: HEIR·SHE STOLE·CEO·외도 복수·후회남·Hidden Heiress

### 다크 로맨타지 공식 (Dragon·Werewolf·Monster·Fae·Vampire Mate)
> **Fated Encounter → Forbidden Bond Sensed → Possessive Claim → Bond Deepens → Public Recognition of Bond → Mate Sealed/Crowned**

- 핵심: **운명 짝 발현 사이클** (비인간 결속)
- 결제 트리거: Bond 신호 점진·Possessive Protection·거리 붕괴·Mate Sealed
- 적용 작품: OFFERING (Dragon)·Wolfless (Werewolf)·ACOTAR (Fae)·Fourth Wing (Dragon Rider)

## 다크 로맨타지 핵심 결제 트리거 6개

### 1. Fated Bond 점진 발현 (가장 중요)
- **운명 짝 신호 누적**: 비늘 빛·날개 그림자·mate mark·향기·심장 박동 동조
- 회차마다 신호 강도 증가 (희미 → 영구적·강함)
- 결제 동력: 다음 화에 Bond가 더 강해질 것 = 보고 싶음

### 2. Possessive Protector (필수)
- 위험할 때 그가 직접 움직임
- 자객 검 부러뜨림·날개 그림자·비늘 빛·화염 반응 손
- 일반 여성향 "Protected"와 다름 — **비인간 본능적 보호** + **운명 짝 인식**

### 3. 거리 붕괴 물리 표지
- 키스 직전 정지·손목 잡힘·뜨거운 숨·비늘 닿는 온도
- 입술 닿기 직전 놓고 한 발 떨어짐 (긴장 누적)
- 회차마다 거리 좁아짐 / 단 완전 결속은 후반

### 4. 위험한 비인간 신호
- 부분 비늘·비인간 눈 (분노 시 변색)·날개 그림자·화염 반응 손
- 작품 정체성 시각 자산 (AIGC 강점 극대)
- 인간 형태 + 비인간 신호 = 다크 로맨타지 비주얼 핵심

### 5. Forbidden Touch + Erotic Permission
- 금지된 끌림·고수위 친밀
- "위험한 남자가 나에게만 안전" 정서
- 고수위 다크 로맨타지 (할리퀸 Presents·Berkley·Ballantine Outlander 톤)

### 6. Public Recognition of Bond (지위 X / Bond)
- 일반 여성향 "Public Vindication" = 인간 사회 공개 지위 회복
- 다크 로맨타지 "Public Recognition" = **운명 짝 인정의 공개 의식**
- 예: 드래곤 무리 포효·pack ceremony·Luna mark·Mate Sealed 의식

## 작품별 매핑

### OFFERING (Dragon Romance)
- **EP1 = Fated Encounter** — 베일 비늘 빛이 이솔데에게만 반응 / Sacrificial Bride 출발
- **EP2 = 첫 Possessive Claim** — 베일 옆자리·검은 비늘 손가락 의자 팔걸이
- **EP3 = Possessive Protection** — 자객 검 부러뜨림 + 침실 벽 키스
- **EP4-7 = Bond Deepens** — 깃발 태움·테라스 손목·자객 인장 폭로
- **EP8 (페이월) = Public Recognition of Bond 시작** — 드래곤 무리 첫 포효·사절단 무릎
- **유료: Mate Sealed → Crowned** — 신부 선언·Crowned Bride·Dragon Queen 즉위

### Wolfless Mate (Werewolf Romance)
- **EP1-2 = Fated Encounter + Humiliated 결합** (Werewolf는 두 공식 결합 — Pack rejection이 Humiliated)
- **EP3-7 = Bond Sensed (mate mark·향기)**
- **EP8 = Damon이 Elena를 mate로 공개 선언**
- **유료: True Luna ceremony → Pack 인정**

### ACOTAR / Fourth Wing (책 — vertical로 변환 시)
- **Mate Bond → Possessive Claim → Public Recognition → Crowned**

## 다크 로맨타지 + Public Vindication 결합 가능성

일부 다크 로맨타지는 두 공식 결합:
- **Wolfless Mate** — Werewolf Pack 내 Humiliated (rejected mate) + Fated Bond
- **OFFERING** — 인간 왕국 Sacrificial Bride (Humiliated 부수) + Dragon Fated Bond (메인)
- **다른 다크 로맨타지** (예: 가짜 약혼 + Vampire) — 결합 가능

**판정 기준:**
- 메인 결제 동력 = Fated Bond·Possessive Claim·Mate Sealed → **다크 로맨타지 공식 우선**
- Humiliated → Vindicated는 부수적 사이클
- 일반 여성향 공식 = 인간 사회 정치 메인일 때

## 자가 검증 (다크 로맨타지 작품 기획·검수 시)

- [ ] Fated Bond 점진 발현 시각 표지 (비늘·날개·mate mark·향기) 회차마다?
- [ ] Possessive Protector 신호 (위험 시 직접 움직임) 명확?
- [ ] 거리 붕괴 물리 표지 (시선·손목·키스 직전) 회차마다?
- [ ] 위험한 비인간 신호 (부분 비늘·비인간 눈·날개) 등장?
- [ ] Forbidden Touch + Erotic Permission 고수위 표지?
- [ ] Public Recognition of Bond (운명 짝 공개 인정 의식) — 페이월·중반·후반?

→ 다크 로맨타지 작품은 6개 모두 작동해야 결제 동력 강함.

## 일반 여성향 공식 잘못 적용 사례 (회피)

다크 로맨타지 작품에 "Humiliated → Chosen → Vindicated" 일반 여성향 공식만 적용 시:
- Fated Bond 빌드업 부재 → 다크 로맨타지 핵심 카타르시스 손실
- 인간 사회 정치 복수에 집중 → 비인간 운명 결속 약화
- 작품 정체성 손실 → 일반 모던 후회남으로 변질

**예시:** OFFERING의 EP1-2 (Fated Encounter + Possessive Claim 빌드업)를 "Humiliated → Chosen 사이클"로만 해석 시 EP1-2의 진짜 가치 (운명 짝 신호 빌드업) 누락.

## Why

사용자 명시 (2026-05-12):
> "Humiliated → Chosen → Protected → Revealed → Vindicated → Desired 이 구조가 적합한 장르인가? 다크 로맨타지도 그런가? 웹소설이나 vertical 기준 검토 필요하다. 다크 로맨타지는 조금 다르지 않은가?"

→ 다크 로맨타지 공식 별도 정의. OFFERING·Wolfless 등 적용.

## How to apply

- 여성향 작품 진입 시 **작품 카테고리 판정** (일반 여성향 vs 다크 로맨타지)
- 일반 여성향 = Humiliated → Chosen → Protected → Revealed → Vindicated → Desired
- 다크 로맨타지 = Fated Encounter → Forbidden Bond Sensed → Possessive Claim → Bond Deepens → Public Recognition → Mate Sealed/Crowned
- 결합 작품 (Wolfless 등) = 두 공식 동시 적용 (단 다크 로맨타지 메인)
- 페르소나 09-B (니치 다크 로맨타지) 진단 시 본 공식 기준

## 핵심 한 줄 결론

> **일반 여성향 = 공개 지위 회복 / 다크 로맨타지 = 운명 짝 발현. 다른 공식, 다른 결제 동력.**
