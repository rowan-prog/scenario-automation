# 규칙

피칭덱 "해당 IP 피칭 사유 (Core Expectation)" 섹션은 **3대 질문**(왜 제작 / 시장성 / 변별력)에 답하되 다음 형식 강제.

## 1. 줄글 (양식·표·엑셀 금지)

- **줄글 작성** — 글머리 기호·표·엑셀 형식 X
- **3 질문 각각 한 단락 이상** — 충분한 분량으로 (한 단락 4-6 문장)
- **흐름 있는 산문** — 단순 키워드 나열 X

## 2. 밀도·논리·쉬운 언어

- **밀도:** 작품 자체의 강점·시장 정합·차별 포인트가 빈 문장 없이 줄줄. 추상어로 부풀리지 않음.
- **논리:** 근거 → 주장 흐름. 전제(시장 성장·숏폼 트렌드 등)를 근거처럼 쓰지 않음.
- **쉬운 언어:** 위원이 첫 줄 보고 즉시 이해. niche 어휘·자체 조어 X. 학술 표현 X.
- **직관:** 시청자 입장에서 "왜 클릭하고 왜 결제하는가"가 즉시 보이게.

## 3. 좋은 피칭사유 예시 (참고용 — "해야만 하는 쉐어하우스 시즌3" 패턴)

**[왜 제작해야 하는지?] [시장성이 있는지?]**

> 검증된 흥행 IP의 시즌 확장
> '해야만 하는 쉐어하우스'는 비글루 내에서 이미 시즌1, 2를 통해 성과가 검증된 대표 IP. 신규 IP 대비 리스크가 낮고, 기존 팬층을 기반으로 안정적인 초기 트래픽 확보 가능.
>
> 연애 리얼리티 포맷의 지속적인 수요
> 환승연애는 시즌이 거듭될수록 화제성과 시청 성과를 유지하며 시즌제 연애 리얼리티의 대표 성공 사례로 자리잡음. 나는 SOLO 또한 기수만 바뀌는 구조임에도 꾸준히 제작되며 지속적인 시청 수요를 증명. 이는 연애 리얼리티 장르가 "인물 교체만으로도 반복 소비가 가능한 구조"임을 보여줌.
>
> '해야만 하는 쉐어하우스 in Japan'
> 캐스팅을 제외한 포맷을 거의 그대로 구현한 일본판 역시 성과를 내며 구조 자체가 작동하는 콘텐츠임이 입증됨.
>
> 코인 매출에 최적화된 IP
> 해만쉐는 특정 사건(고백, 갈등, 고자극 게임 등)을 중심으로 결제 트리거를 명확하게 설계할 수 있는 장르임을 확인. 에피소드 확장 기반 매출 극대화 가능. 시즌1·2 대비 약 20~30% 회차 확장 예정. 비글루 오리지널 콘텐츠는 1·2차 페이월 이후 평균 98% 이상의 높은 돌파율을 기록.
>
> 자극적 관계 소재의 높은 바이럴 효율
> 최근 마케팅 트렌드상 BDSM 등 강한 관계성·긴장감을 가진 소재가 숏폼 및 SNS에서 높은 반응을 보이며 클릭과 유입을 효과적으로 견인.

**[크리에이티브에 변별력이 있는지?]**

> 더 극단적인 캐릭터 조합을 통한 초반 훅 강화
> 시즌3는 이전 시즌 대비 성향이 더 대비되는 출연자 구성을 통해 초반부터 관계 충돌과 감정 대립을 빠르게 발생시키는 구조. 이를 통해 초기 몰입도를 극대화.
>
> 주도적인 여성 캐릭터 중심 서사
> 기존 시즌 대비 수동적인 관계 흐름에서 벗어나 여주가 좀 더 주도적으로 움직이는 설정.
>
> 관계별 서사 확장을 통한 후반부 밀도 강화
> 관계별 서사를 후반부에 확장 배치하여 후반부까지 긴장감을 유지.

**왜 좋은 예시인가:**
- 각 주장에 **소제목** + **구체 근거 / 검증 사례 / 수치**가 따라옴
- 흐름이 자연스러움 — "왜 만들어야 하는가" → "어떻게 시장에서 작동하는가" → "어떻게 차별화하는가"
- 줄글이지만 단락 단위로 정리되어 위원이 빠르게 읽을 수 있음
- 위원이 모를 위험 있는 niche 어휘 X
- 자체 조어·학술어 X
- 추상적 주장 X — 구체 근거로 입증

## 4. 잘못된 피칭사유 예시 (절대 금지)

**나쁜 예시 1 — 의미 없는 자기 변명:**
> "이 작품의 핵심은 복잡한 기술 설정이 아니라, '내 얼굴로 다른 여자가 내 인생을 산다'는 즉각적인 억울함이다."

→ "X가 아니라 Y" 형식의 빈 문장. 구체 근거 없음.

**나쁜 예시 2 — 학술 추상어:**
> "차별점은 은밀한 친밀감보다 공식 지위 역전을 중심 보상으로 둔 점."
> "그녀의 호명과 위치를 바꾸는 남주."

→ 자체 조어. 시청자 입장에서 무의미.

**나쁜 예시 3 — 무의미한 구조 묘사:**
> "각 신전 가문을 하나씩 장악하는 구조라 이해하기 쉬움. 여신 혈통 캐릭터가 단순 로맨스 보상만이 아니라, 가문 진입 키로 기능한다."

→ "각 신전 가문을 하나씩 장악하는 구조"가 왜 피칭사유인가? 위원이 보면 "그래서?" 반응. 구체 보상 / 비주얼 / 결제 트리거가 없음.

## 5. 작성 자가 점검 (필수)

피칭사유 작성 후 다음 점검:

- [ ] **줄글로 작성되어 있는가?** (표·글머리 X)
- [ ] **각 질문에 충분한 분량으로 답했는가?** (4-6 문장 한 단락 이상)
- [ ] **금지 어휘 0건?** (폐기·코어·호명·"이 작품의 핵심은 ~가 아니라" 등)
- [ ] **자체 조어 0건?**
- [ ] **위원이 첫 줄 보고 즉시 이해되는가?**
- [ ] **구체 근거가 주장에 따라붙는가?** (검증된 트로프·정석급 작품·결제 트리거 등)
- [ ] **숏폼 시장 성장 일반론 0건?**
- [ ] **"X가 아니라 Y" 형식의 빈 문장 0건?**

## Why
2026-05-09 사용자 강한 피드백:
- "정보 줄테니까 밀도 높게 논리적으로 충분한 분량으로 직관적이고 쉬운 언어로 다시 써서 줘라. 줄글로 주면 된다 이건. 엑셀 만들필요 없이."
- "각 신전 가문을 하나씩 장악하는 구조? 이딴게 뭔 왜 해당 IP 피칭사유가 됨? 이해하기 힘듬."
- "좋은 예시도 준다 [왜 제작해야하는지?][시장성이 있는지?] 검증된 흥행 IP의 시즌 확장 ~"
- "너무 밀도도 없고 논리도 우습고, 사유에도 적합하지 않음."
- "그리고 설명을 한다. 주장을 하지 않고. 근거를 바탕으로 주장을 하질 않는다."

## How to apply
- phase_2 작성 시 줄글 강제 + 자가 점검 8개 항목 모두 통과
- 양식 고정 X — 작품 정체성에 맞게 단락 분할
- 좋은 예시 패턴 (해야만 하는 쉐어하우스) 참고
- 빈 문장 검출 시 즉시 구체 근거 보강 또는 삭제
- 자체 조어 검출 시 일반 언어로 변환
