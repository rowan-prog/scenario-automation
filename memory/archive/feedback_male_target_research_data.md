무시 → 폐급 자산 → 위기 → 규칙 잘 이해해서 돌파 → 첫 보상 → 더 큰 미래

- 5-6화: 첫 장비·거점·동료 업그레이드

## paid vertical 핵심 설계 룰 4

1. **"클리프행어"보다 "잠긴 보상"** — 보스전·금고·랭킹전·장비 테스트 직전 끊기

3. **주인공 = "시스템을 잘 쓰는 자"** (선택받은 자 X) — 남들이 쓰레기로 본 능력의 진짜 사용법
4. **여성 캐릭터 = 인정 보상 + 기능 보상** (예쁜 보상 X) — 진영·능력·자원·정보·전투 기능·감정
