# 피칭덱 퀄리티 근본 결함 — 7대 룰 (필수)

## 발생 사고 (2026-05-11)

MOST WANTED SHIP 피칭덱이 외부 AI 3건 비교 검수에서 일관되게 비교작품 (THE FAE PRINCE'S WEDDING DRESS CHOSE ME) 아래로 평가됨. 위원 기준 없이도 보편적으로 떨어진다는 판정.

비교작품도 "비한국인·비인간 글" 수준이지만, 내가 쓴 게 그것보다도 떨어진다는 사용자 판정.

## 룰 1: 글로벌 IP 스타일 + 페이드 결제 엔진 결합 (사용자 본질 정정 2026-05-11)

**사용자 명시 (2026-05-11):**
> "매 EP면 1분~2분마다 능동성을 드러낸다는 게 작위적임 이상한 룰임. 글로벌 IP 스타일을 숏폼에 이식해야 함. 스케일이 커지고 장르폭이 커지고 AIGC로 화려하고 멋진 미감의 영상을 제작하지만, 그 내부 엔진은 분명하게 유료결제형이어야 한다. 매 에피마다 능동성을 억지로 드러내면 '난 엄청 능동적인 사람이야!!!!' 라고 자기광고한다."

### 두 축 분리

| 축 | 작품 외관·스타일·톤 | 내부 엔진·결제 동력 |
|---|---|---|
| **기준** | 글로벌 IP (가디언즈 오브 갤럭시·카우보이 비밥·Firefly 등) | 페이드 버티컬 (ReelShort·DramaBox 결제 모델) |
| **요소** | 스케일·장르폭·AIGC 화려 미감 영상·다종족·우주·VFX·코메디 톤 | 회차 갱신·페이월·다층 진척·EP8 결제 동기 |
| **자연 여부** | 자연 (작품 정체성 그대로) | 자연 (회차 흐름에 박힘) |

### 남주 능동성 = 자연 곡선 (매 EP 강제 X)

**잘못된 룰:** 매 EP 남주 능동성 비트 1+ 필수 (자기광고 트리거)

**올바른 룰:** 남주 능동성 = 작품 전체 자연 곡선
- 작품 전체에서 남주가 자기 능력·결단·판단으로 사건 해결하는 핵심 비트 **2-3개** 분포
- 매 EP 강제 X — 자연스러운 위치에 박힘
- 시스템·아이템·운이 남주를 돕는 것도 OK (글로벌 IP 톤)
- 단 작품 클라이맥스·페이월 직전·핵심 전환점에는 남주 직접 결단 1+ 필수

**자가 검증:**
- [ ] 남주가 작품 전체에서 자기 능력을 쓰는 핵심 비트 2-3개 있는가?
- [ ] 페이월 (EP8)에 남주 직접 결단이 있는가?
- [ ] 매 EP 강제 능동성 비트로 자기광고 톤 되지 않는가?

**MOST WANTED SHIP 사례:**
- 글로벌 IP 스타일: 가디언즈 오브 갤럭시·카우보이 비밥 톤 ✓
- 페이드 결제 엔진: EP8 ACCEPT + 진짜 이름 절반 + 현상금 #1 ✓
- 남주 능동성: EP8 ACCEPT (직접 결단) ✓
- 단 작품 전체에 남주 결단 비트가 EP8 외 1-2개 더 있으면 좋음 (예: EP2 황실 금고에서 라일라 만류에도 손바닥 댐 / EP5 노바 발화에 답함). 매 EP 강제 X.

**원칙 정정:**
- ❌ "매 EP 남주 직접 능력 증명 비트 1+ 필수" (자기광고 룰)
- ✅ "글로벌 IP 스타일 (자연 톤) + 페이드 결제 엔진 (다층 진척) 결합. 남주 능동성은 작품 흐름에 자연스럽게 누적"

## 룰 2: 회차별 다층 진척 (Multi-axis Progression)

**잘못된 패턴:** 외부 변수 갱신만 (좌표·인물·아이템·랭킹)으로 회차 동력 인정.

**올바른 패턴:** 외부 변수 + 내부 진척 (긴장·관계·감정·신뢰 변화) 동시 누적.

**페이드 버티컬 원칙:**
- **종적 압축 (긴장 깊어짐) > 횡적 확장 (세계 넓어짐)**
- 회차 안에서 두 보상이 동시 진척 = 결제 동력 누적
- 비교 사례 (FAE PRINCE): (a) 신체 접촉 강도 (손가락→허리→입술→허리 붙잡힘) (b) 궁정 압박 강도 (도둑→법정→강제 결혼→공개 폭로) 두 축 동시

**자가 검증:**
- [ ] 매 EP에 외부 변수 갱신 + 내부 진척 둘 다 있는가?
- [ ] 메인 히로인의 감정·관계 곡선이 EP1과 EP8 사이에 분명히 변하는가?
- [ ] 회차 합류 캐릭터 동시 진입 시 각자 감정선이 얕아지지 않는가?

## 룰 3: 포맷 표준 점검 (Format Standard Check)

**페이드 버티컬 = 세로형 99%.**

**가로형 결정 시 카테고리 미스매치 위험 자동 평가:**
- 작품 본질이 가로형 요구하는가 (스케일·VFX·다종족 등)?
- 페이드 버티컬 플랫폼이 가로형 콘텐츠를 결제 모델로 운영하는가?
- 가로형이면 페이드 외 다른 플랫폼 (TVOD·OTT) 더 적합한가?

**자가 검증:**
- [ ] 페이드 버티컬 = 세로형 표준 인지하고 결정했는가?
- [ ] 가로형 결정 시 페이드 플랫폼 적합도 평가했는가?
- [ ] 작품이 페이드보다 다른 플랫폼이 더 적합한가?

**MOST WANTED SHIP 사례:**
- 작품 본질 = 우주 스케일·외계 행성·VFX = 가로형 요구
- 페이드 버티컬 = 세로형 표준
- 미스매치. 페이드 플랫폼보다 TVOD·OTT가 더 적합할 수도

## 룰 4: 카테고리 검증 단정 회피 (Category Validation Caveat)

**잘못된 패턴:** 미검증 카테고리를 "직접 소비 라인" / "이미 검증된 시장" 단정.

**올바른 패턴:** 글로벌 IP 검증 ≠ 페이드 결제 모델 검증. 두 시장 구분 명시.

**자가 검증:**
- [ ] 페이드 버티컬 (ReelShort·DramaBox·NetShort·DramaWave) 실제 누적 작품 있는가?
- [ ] 없으면 "확장 여지" / "emerging" 톤으로 표현
- [ ] 글로벌 IP (가디언즈·ACOTAR·Fourth Wing)는 카테고리 검증 자료지 페이드 검증 자료 X

**MOST WANTED SHIP 사례:**
- ❌ "우주 함선·외계 행성·다종족 크루·하렘 비트는 직접 소비 라인이다"
- ✅ "스페이스 오페라는 가디언즈·카우보이 비밥 등 글로벌 대중성 검증. 페이드 버티컬에는 정통 사례 적으나 SF·메카·게임 시스템 기반 남성향이 등장하며 확장 여지 있음"

## 룰 5: 미시 정합성 자동 점검 (Micro-coherence Audit)

**자동 점검 항목:**
1. **신규 인물·세력 EP6+ 도입 시** = EP1~5 빌드업 단서 있는가
2. **메인 히로인 감정 곡선** = EP2~8 모든 회차에 진척 비트 있는가
3. **시스템·메커닉 기준** = 일관 적용되는가 (예: 함선 이름 "절반" vs 문장 "끝까지" 차이 모호)
4. **동시 합류 캐릭터** = 각자 감정선 깊이 유지되는가

**MOST WANTED SHIP 사례:**
- ❌ EP6 외계 공주 캐스카 갑작스러움 (EP1~5 빌드업 0)
- ❌ 아스트라 EP3+ 감정 곡선 사라짐
- ❌ 함선 진짜 이름 "절반" vs 가문 문장 "끝까지" 기준 차이 모호

## 룰 6: 한국어 표기·문체 표준 (Notation Polish)

**표준 외래어 표기:**
- **코메디 → 코미디**
- **THORNE → 쏜** (손 X)
- **VAUGHN → 본** (정확)
- **GLASS → 글래스**
- **CROSS → 크로스**

**번역투 회피:**
- ❌ "성단 은행" (직역)
- ✅ "Starbank" / "Galactic Bank" / "Orion Credit Guild" (고유명)

**한영 표기 일치:**
- 영어 성·이름과 한국어 표기 음운 일치 검사

**자가 검증 (피칭덱 완성 전):**
- [ ] 외래어 한국어 표기 표준 확인
- [ ] 영-한 표기 음운 일치
- [ ] 번역투 어색 표현 점검

## 룰 7: AI 자가 비교 검수 (Self vs External Comparison)

**작품 작성 후 자가 시뮬레이션 필수:**

"이 작품을 다른 AI(GPT-5·Gemini·Claude 다른 인스턴스)가 동일 input으로 작성했다면 어떤 부분이 다를까?"

**점검 항목:**
- [ ] 컨셉 한 줄의 강도 (한 줄에 시각 메커닉까지 들어가는가?)
- [ ] 회차별 진척 다층성 (외부 + 내부 동시?)
- [ ] 남주/여주 내면 곡선 분명함
- [ ] 미시 정합성 (인물 도입·시스템 일관성)
- [ ] 포맷·카테고리 미스매치 여부
- [ ] 표기·문체 폴리시

**자가 약점 진단 후 보강:** 다른 AI가 짚을 만한 약점이 발견되면 본문 정정.

## Why (2026-05-11 사고)

외부 AI 3건 (AI1·AI2·AI3) 비교 검수에서 일관 패턴:
- MOST WANTED SHIP < FAE PRINCE WEDDING DRESS
- 보편적 평가 (위원 기준 무관)
- 사용자 판정: "비교작품도 비한국인·비인간 글 수준이지만, 내가 쓴 게 그것보다도 떨어짐"

→ 시스템 룰로 등재. 향후 모든 피칭덱 작성 시 7대 룰 자가 검증.
