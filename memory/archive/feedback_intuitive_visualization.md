# 핵심 가치 (사용자 직접 명시, 2026-05-10)

**뇌 빼고 읽어도, 뇌 빼고 상상해도, 대충 읽어도 이해 잘 되어야 한다. 머릿속에 그림처럼 잘 그려져야 한다.**

> "이건 모든 작품 1-7만이 아니라 앞으로도 그렇고 핵심 가치 중 하나야. 피칭덱 쓸 때 말하는거야. 그럴려면 근본도 그래야겠지."

피칭덱·청사진·트리트먼트뿐 아니라 **작품 근본 자체**에도 적용. 영구 룰.

---

# 적용 원칙

## 1. 한 문장 = 한 그림

- 한 문장 안에 사람·물건·자리·움직임·색·소리 중 최소 한 가지가 있어야 함.
- 추상어·개념어로 그림을 대체하지 말 것.
- 시청자가 그 문장을 30초 안에 머릿속 그림으로 옮길 수 없으면 다시 써야 함.

## 2. 작품 근본에도 적용

- 작품의 시작점·갈등·페이월 보상이 모두 그림으로 잡혀야 한다.
- "주인공이 ~를 한다 (그림 보이는 동작)" ✅
- "주인공이 ~의 정체를 깨닫는다 (그림 안 보이는 추상)" ❌
- 페이월 응축 = 한 컷·한 동작·한 발화로 그려져야 한다.

## 3. 위원 대충 봐도 작품이 보일 것

- 외부 평가자(위원·CM·시청자)가 대충 훑어도 첫 컷·핵심 갈등·페이월이 그림으로 떠올라야.
- 위원이 한 번 더 읽어야 이해되는 문장은 약함.

# 직관성 검증 7 검수 (모든 문장 통과 필수)

1. 사람이 보이는가? (누가 어디에서 무엇을 하는가)
2. 물건·자리·문·이름이 그림으로 잡히는가?
3. 움직임·시선·접촉이 보이는가?
4. 추상어·개념어 없이 의미 전달되는가?
5. 30초 후에도 그 장면이 머릿속에 남는가?
6. 다른 사람에게 한 마디로 설명할 수 있는가?
7. 위원이 대충 봐도 작품이 보이는가?

# 검출 자동 trigger

다음 표현 검출 시 자동 🟡 → 그림으로 다시 쓰기:

- "정체를 깨닫는다 / 진실을 알게 된다 / 본질이 드러난다" (추상)
- "이 작품의 핵심은 ~이다" (해설)
- "X하는 자 / Y로서의 Z" (라벨)
- "구조적으로 / 시스템적으로 / 본질적으로" (분석어)
- "가능하다 / 작동한다 / 기능한다 / 보유한다" (개념어)
- "흥미롭다 / 강력하다 / 매력적이다" (평가어)

이런 어휘가 들어가면 그 문장은 그림이 안 그려진다.

# 좋은 예 vs 나쁜 예

❌ 나쁨: "그녀는 자신이 단순한 도구가 아니라 봉인의 진짜 대상이었다는 진실을 깨닫는다."
- 그림 X. 추상·해설.

✅ 좋음: "그녀가 손가락으로 페이지의 자기 이름을 따라가자, 그녀의 왼쪽 눈 문양이 처음으로 검게 번진다. 페이지 끝에 'last key'가 적혀 있다."
- 그림 ✅. 손가락·페이지·이름·문양·색 변화·문자 모두 보임.

❌ 나쁨: "RAVEN-9는 자기 코드를 만든 시스템을 자기 코드 아래로 옮기는 인물이다."
- 그림 X. 분석문.

✅ 좋음: "RAVEN-9가 손가락을 한 번 펴자 검은 전함의 갑주가 한 칸씩 열린다. VESS의 함대 신호가 검은 전함 옆에서 한 번 흔들린다."
- 그림 ✅. 손가락·갑주·신호 흔들림 보임.
