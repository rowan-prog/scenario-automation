## 룰 1: 피칭덱 "메인 남성향이란 무엇인가" 짧은 교육 섹션 명시 (필수)

### 명시 항목

1. **메인 남성향 정의 (한 줄)**
   - 예: "글로벌 검증된 시스템·각성·먼치킨·하렘 남성향 = paid vertical 메인 카테고리"

2. **초대박 레퍼런스 명시 (필수 — 1-3 작품)**
   - **글로벌 mega hit:** Solo Leveling (웹툰 14억+ 조회·웹소설·Netflix 애니·2024 Crunchyroll 9개 어워드)·갓 오브 워·Cradle (NYT #1 Kindle)·Dungeon Crawler Carl (600만 부)
   - **NetShort/GoodShort 검증작:** One Move God Mode (HeiPi 2M views)·Legend of A Bastard Son·God Mode: Apocalypse!·Titan Era 등 14편
   - **카테고리 글로벌 검증:** "북미 paid content 5대 시장 (게임 607억 달러·LitRPG·Audible military SF·HaremLit·Tabletop)"

3. **트로프 매핑 (필수)**
   - 작품 트로프가 검증 8 후킹 소재 중 어느 것에 매칭되는지 명시
   - 예: "Village Fool God Mode (NetShort 1순위 검증) + System + Hidden Exclusive Access"

4. **시장 위치 명시 (필수)**
   - 예: "페이드 버티컬 남성향 라인업 약함 = **시장 공백 진입 기회** (NetShort·GoodShort 등 신규 라인 빠르게 성장)"

God Mode ON!〉·〈Legend of A Bastard Son〉(HeiPi 2M views) 14편 검증 트로프 패턴 직접 매칭 (Village Fool God Mode + System + Hidden Exclusive Access). 페이드 버티컬 남성향 라인업 약함 = 시장 공백 진입 기회.

## 룰 5: 위원 인지 한계 = 작품 책임 (피칭덱 보강 필수)

위원이 작품을 오인할 수 있다 → 피칭덱이 위원의 오인 가능성을 사전 차단해야:

1. **메인 남성향 정의** (1줄)
2. **글로벌 검증 레퍼런스** (1-3 작품, 구체적)
3. **트로프 매핑** (검증 트로프와 직접 매칭)
4. **시장 위치** (공백 진입 기회·매출 가능성)

→ 4 항목 누락 시 위원 자유 해석 → 만장일치 탈락 위험 (MY MAP 사례)
