## 1. 강한 여주 오진 방지 (필수)

### Demon Lord 사례 — 오진 정정

Demon Lord의 여주 = 사실 강하고 능동적. 옳은 말 / 자기 권리 주장 / 복수 주도 / 자기결정권 주장.

**문제 = "여주 수동성"이 아니다.** 다음이 진짜 문제 후보:

1. **강한 여주 자체는 충분하지 않다.** 권리 주장 + 복수 주도만으로는 paid vertical 여성향 구매 욕망 X.
2. **욕망보다 개념이 앞서면 약화.** 계약·장부·채무·동의·시장·지워진 딸들 같은 구조 언어가 너무 커지면 "위험한 로맨스"가 아니라 "계약형 복수 논설"로 읽힘.
3. **표식은 설정 X / 관계 변화 O.** mark는 "힘이 생겼다"가 아니라 남녀 관계·소유권·보호권·공적 지위·육체적 끌림을 실제로 바꿔야.
4. **강한 여주도 욕망 가져야 한다.** "나는 네 소유물이 아니다"만으로는 부족. "원하지 않으려 했지만 끌린다" / "위험한 걸 알면서도 받아들인다" / "내가 직접 선택한다"까지 가야.
5. **복수극이 로맨스 엔진 잡아먹으면 X.** 가족 응징·장부 폭로·계약 반전이 강해질수록 남주와의 금기적 끌림·mutual claim·육체적 긴장은 더 의식적으로 보강해야.
