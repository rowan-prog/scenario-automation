# 피칭덱 작성 자동 검수 워크플로우 (필수)

## 핵심 룰

**피칭덱 작성 = 단순 본문 작성 X.** 다음 4단계가 **자동 1 사이클**로 완결되어야 "작성 완료" 보고 가능.

### 단계 1: 본문 작성
- 인물 소개·줄거리·트리트먼트·로그라인·왜 제작·시장성·변별력
- 메모리 룰 정합 (양식·금지 표현·캐릭터 이름 충돌·로그라인 광고 카피 톤 등)

### 단계 2: 비문 + 내적 정합성 검수·수정
- 조사 오류 (받침 X 명사 + 이/가 같은 비문)
- 시제 일관성 (트리트먼트 현재형)
- 주술 호응 (주어·술어 일치)
- 중복 표현 / 만연체
- 인물 동선·소품 위치·시간 흐름 정합

### 단계 3: 피칭덱 투표위원 7인 (A-G) 통과 가능성 평가
**기준:** `config/evaluators.md` Section 9 (거절 트리거) + Section 10 (3초 게이트) + Section 14 (공통 함정)

- A 초반 체감: EP1 첫 사건 / EP3 안 관계 가시화
- B 보편 번역: 설정 벗기면 남는 감정선
- C 카테고리·시각: AIGC 시각 강점 + 카테고리 열감
- D 타깃·장르 직관성: 단일 장르 + 한 줄 패키징 + 대사 직관
- E 포맷·AIGC 시너지: 실사 부담 큰 비주얼 AIGC 해결
- F 상품·결제: free hook → first payoff → paywall 전환점
- G 전략·자산: 라인업 의미 + 비주얼/구조 자산

### 단계 4: 해당 성향 타깃 페르소나 반응 점검
- **남성향 작품** → 시청자 페르소나 08 (제너럴 + 니치). 이탈 코드 M-A ~ M-J 점검
- **여성향 작품** → 시청자 페르소나 09 (제너럴 + 니치). 이탈 코드 F-A ~ F-L 점검
- 혼합·전연령 작품 → 둘 다 비활성 (제작 페르소나만)

## 4표 미만 시 자동 디벨롭

위원 7인 중 **4표 이상 통과 가능성 낮으면 자동 디벨롭**:
1. 약점 위원 식별 (어느 거절 트리거 발동?)
2. 본문 정정 (장르·인물·EP 비트·로그라인·왜 제작)
3. 재평가 (정정 후 4표 이상 가능한가?)
4. 통과까지 반복 (단 무한 루프 회피 — **3 라운드 이내**)
5. 3 라운드 후에도 4표 미만 = 사용자 보고 + 판단 요청

## 완료 보고 조건 (필수 모두 충족)

- [ ] 위원 4표 이상 통과 가능성 명시
- [ ] 시청자 페르소나 (해당 성향) 통과 점검 완료
- [ ] 비문 0건
- [ ] 내적 정합성 OK (인물·소품·시간·동선)
- [ ] 메모리 룰 정합 (양식·금지 표현·로그라인·캐릭터 이름·다크 로맨타지 수위 등)

→ **위 모두 OK 시에만 "피칭덱 작성 완료" 보고.**

→ 통과 전 "작성 완료" / "피칭덱 썼다" 보고 = **룰 위반**.

## 페르소나 7인 = 피칭덱 단계 X

**페르소나 01-07 (제작 검토 페르소나)** = 스크립트 (대본) 검토 단계 (phase_5)에서만 사용. **피칭덱 단계 진단에 사용 금지.**

- 01 Intimacy Auditor
- 02 AIGC Production Director
- 03 Continuity Logic Auditor
- 04 English Dialogue Voice Auditor
- 05 Commerciality Marketing Auditor
- 06 Visual Appeal Character Lock Auditor
- 07 Genre Pleasure Realization Auditor

→ 이들은 phase_4 (집필) 완료 후 phase_5 (페르소나 검토)에서 EP 대본 단위 검수. 피칭덱 단계엔 호출 X.

**시청자 페르소나 08·09**는 자기 타깃 건의 **피칭덱 + 스크립트(대본) 양 단계** 모두 사용.

## "스크립트" 용어 정의 (필수)

- **스크립트 = 대본** (EP 단위 본문 — 장면·대사·지문)
- **글 (단순 텍스트 작성) X**
- phase_4 = 에피소드 집필 = 대본 작성
- phase_5 = 페르소나 검토 = 대본 검토 (단순 글 검토 X)

## Why
2026-05-11 사용자 명시:
> "피칭덱에선 스크립트 검토 페르소나 7인 필요없다. step5_1에서 쓰이는 스크립트(글을 말하는 게 아니라 대본을 말한다.) 검토자다."
> "타깃 2인은 자기 타깃(남성 or 여성) 건의 피칭덱, 스크립트를 검토하는 위원이다."
> "피칭덱은 기본적인 비문 및 내적 정합성 검수, 수정. 피칭덱 투표위원 7인 기준 통과 가능성 평가 및 4표 이상 가능성이 낮을 경우 디벨롭. 해당성향 타깃 페르소나 반응 참고. 불합격일 경우는 디벨롭 필요."
> "이건 자동으로 진행해야한다. 이게 해결되기 전까진 피칭덱을 썼다고 보고하면 안 되는거다."
