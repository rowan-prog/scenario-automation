# v3 12 HARD RULE

`config/master_guide_v3.md` PART 1 발췌. **paid vertical 결제 욕망이 무너지는 지점을 막는 최소 규칙.**

## 12 룰

1. **첫 컷은 욕망 게임을 시작해야 한다** — 분위기 X. 낮은 위치·자리 침범·거짓 판결·금지된 관계·선택권자·뒤집기 증거·처분·복수·검증·탈출 중 최소 하나 보여야.
2. **제목·광고·첫 장면 약속 분리 X** — 제목이 신부·왕·악마·회귀·아이·폐기·복수·각성·권한·남편·배신을 약속하면 첫 장면이 그 약속의 대상·위기·증거·첫 실행·폭발 직전 구도 중 하나를 보여야.
3. **1화 안에 대표 엔진 실제 작동** — 세계관 소개 X. 선택·보호·자리 침범·권한 반응·거짓 판결·처분·검증·복수 대상 죄 확정·다음 보상 예측 중 하나 발생.
4. **무료 회차 = 하나의 큰 질문** — 여러 질문 나열 X. 페이월에서 터질 단일 결제 질문 누적. 세계관 설명·훈련·설정·별도 사건으로 욕망 분산 X.
5. **페이월 = 중단점 X / 붕괴 직전** — 증거 공개·공개 선택·보호 개입·첫 반격·권한 회수·대체자 균열·관계 확정·처분 실행·시스템 승인 임박. 보상은 예측 가능하나 아직 안 줌.
6. **핵심 타격 문장 순화 X** — 해고·이혼·폐기·파산·소유·보호·대체자 거부·공개 망신·권한 박탈·관계 철회·복수 시작·검증 내기. 로컬라이즈 가능, 칼날은 보존.
7. **자리 침범·거짓 판결·가치 역전 = 물리 시각화** — 대체자가 의자·방·침실·왕좌·증표·이름·기록·옆자리·공적·권한 UI 차지. 추상적 배신 X.
8. **각색·리스킨 = 사건 순서 X / 기능 슬롯 이식** — 보존할 것: 실제 가치·거짓 판결·빼앗긴 자리·대체자·선택권자·공개 복권 무대·페이월 보상·핵심 타격 문장·광고 컷 기능.
9. **AIGC 비주얼은 욕망 구조 대체 X** — 미모·VFX·신화·수인·왕실·시스템·거대 공간은 활용. 감정 장부·결제 구조 없으면 비주얼 쇼.
10. **AIGC 대본 = 추상 의도 X / 화면 가능 행동** — 미세 심리·모호 표정·긴 대화·복잡 군중 X. 감정은 손·문·증표·자리·몸 방향·UI 반응·보호막·공개 화면·오브젝트로 번역.
11. **타깃별 핵심 보상 기계적 이식 X** — 여성향 선택받음·보호받음을 남성향에 그대로 옮기면 약함. 남성향 지배·권한·소유를 여성향에 그대로 옮기면 로맨스 깨짐. **타깃 결핍·보상 먼저 정의 후 엔진 설계.**
12. **모든 장면은 욕망 게임을 밀어야** — 거짓 판결 강화·실제 가치 단서·자리 침범·관객 우월 인식·감정 장부·관계 압박·선택 예고·증거 심기/회수·행동 압력·보상 직전 밀어붙이기·유료 보상 확장 중 하나. 아무 기능 없으면 삭제·병합·재배치.
