**Why:** 사용자가 9개 작품 위원 반응 raw data 제공 (2026-05-10). 어느 위원의 어느 응답인지는 모르지만, 작품별 동의/비동의 합계와 표현 패턴에서 위원단 판단 패턴을 직접 추출 가능. 추상 룰이 아닌 실전 case-based 보정.

## 통과 강력 패턴 (5-7표 만장일치 가능)

**핵심 공식:** 트로프 결합 + 명확한 정량 레퍼런스 + 북미 직접 검증 + (메타 후킹 또는 안정 제작팀)

### 사례
- **My Werewolf Stepbrother's Secret**: Werewolf + Stepbrother + YA 트로프 결합 + My Stepbrother's Dirty Secret 13.3M view
- **My Ex's Uncle Wants Me as His Bride**: CEO + Forbidden + Age Gap + Mafia 트로프 결합 + 타플랫폼 AI 변주 검증
- **Check-In, It's Haunted**: 계약 로맨스 + 호텔 누아르 + 귀신 보는 여자 메타 후킹 + 커친사맛 누적 매출 6위
- **19금은 본부장에게**: 오피스 + 스티미 + 19금 코칭 메타 후킹 + 안정 제작팀

### 적용
- 새 작품 설계 시 **검증 트로프 2-3개 결합**을 먼저 시도.
- 단일 트로프 작품은 **메타 후킹 또는 정량 레퍼런스로 보강**.
- 정량 레퍼런스 (조회수·매출·자생 팬덤) **반드시 피칭덱에 명시**.

## 턱걸이 패턴 (3-4표 통과 가능성)

**핵심 공식:** 니치 시장만 워킹 / 블루오션 시도 / 라인업 확장 / 자생 팬덤(원작 IP 한정)

### 사례
- **마녀의 심판 (GL)**: 블루오션 + AI 첫 시도 + 저비용 정당화 + TikTok 자생 팬덤(원작 IP 기반)
- **악역 영애 19금 이벤트**: 글로벌 OK / 미국 메인 X / 일본 NetShort 1위 검증
- **황태자에게 간택**: 사극 애니 일본 검증 + 레퍼런스작 차별화

### 적용
- 니치 작품은 **G 위원의 라인업 판단**이 통과 키.
- "**저비용 + 저리스크 + 라인업 확장 차원**" 정당화 필요.
- 자생 팬덤(TikTok·BookTok·Reddit) 데이터는 **원작 IP 또는 이미 외부 팬덤 있는 소재일 때만** 가산. 오리지널 기획에는 해당 없음.

## 거절 패턴 (4-5표 비동의)

### 거절 유형 A — 검증 트로프지만 차별 한끗 부족
- **사례:** I Slept with My Ex's Dad — "묻지도 따지지도 않고 보는 스토리"이지만 "타플랫폼에서 이미 많이 하는 스테디 셀러 + AI로 1순위로 제작할 타이틀 X"
- **거절 사유:** 추가 자극·메타 설정·트로프 결합 중 하나 부족
- **회피책:** 트로프 결합 강화 (단순 Ex's Dad → My Ex's Uncle + Mafia + Age Gap), 메타 후킹 추가, AI 메리트 명확화

### 거절 유형 B — 각색 난이도 × 원작 흥행도 낮음
- **사례:** 불티 — "각색 많이 필요 + 스토리 복잡 + 원작 IP 인지도 낮음 + 좁은 타깃 + 숏폼 드문 소재"
- **거절 사유:** 12-5 매트릭스 (각색 난이도 높음 × 원작 흥행도 낮음) 자동 거절
- **회피책:** 원작 IP 기반 작품은 글로벌 검증 IP만 진행. 또는 오리지널로 재제작.

### 거절 유형 C — 자사 플랫폼 적합성 부재
- **사례:** 불티 — "비글루 플랫폼 안에서는 소비가 되지 않을 것 같아"
- **거절 사유:** 작품-플랫폼 매칭 실패 (한국 남성향 사이비 스릴러 = 비글루 부적합)
- **회피책:** 작품 기획 시 자사 플랫폼 사용자 카테고리 적합성 사전 점검.

## 작품 설계 체크리스트 (피칭 통과 안전성)

작품 설계 후 다음 6개 항목으로 통과 안전성 자가 진단:

1. **검증 트로프 결합 1+개?** (Werewolf + Stepbrother / CEO + Mafia 등)
2. **명확한 정량 레퍼런스?** (조회수·매출·자생 팬덤 — 단 자생 팬덤은 원작 IP/외부 팬덤 보유 소재 한정)
3. **북미 직접 검증?** (릴숏·DramaBox·Mydrama 사례)
4. **메타 후킹 또는 트로프 변주?** (19금 코칭·귀신 호텔·우연 원나잇·계약 결혼)
5. **AI 메리트 명확?** (실사로 구현하기 어려운 장르/장면을 AI로 가능하게 하는가 — 단순 비용 절감 X)
6. **각색 작품이면 12-5 매트릭스 통과?** (원작 흥행도 vs 각색 난이도, 각색 프로젝트 한정 적용)

**4+개 OK = 통과 강력 / 2-3개 OK = 턱걸이 / 1개 이하 = 거절 위험.**
