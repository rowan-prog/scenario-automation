**룰:** 트리트먼트(러프 청사진·피칭덱·완성 청사진)에서 인물의 **의심·악의·동기·감정**을 직접 발화나 해설 문구로 "설명"하지 말 것. 행동·시선·소품·자리 이동·신체 동작으로 보이게 해서 **읽는 사람이 느끼게** 만들어야 한다.

**Why:** 사용자 명시 (2026-05-10): "'며느리가 그 시간에 곁에 있었던 건 우연이 아니다'를 읽는 사람이 느끼게 해야지, 설명을 하냐? 이런 식은 곤란하다. 트리트먼트에서는 '설명'하면 안 돼. '설명'하고자 하는 게, 읽는 사람이 '느끼게끔' 드러나야지."

**금지 패턴 (직접 설명):**
- 인물이 자기 의심·악의를 발화로 못 박음 — "비비안은 '며느리가 그 시간에 곁에 있었던 건 우연이 아니다'라고 못 박는다"
- 인물이 자기 뻔뻔함을 발화로 표현 — "미라가 '엄마, 자리가 좀 좁네요'라고 비비안에게 웃는다"
- 인물이 자기 자리 인식을 발화로 — "미라가 '이 방, 색이 좀 어둡네'라고 흘린다"
- 외부 해설 — "(가족 내부 첫 균열)" 같은 괄호 메타

**채택 패턴 (행동·시선·소품·자리로 보이게):**
- **의심·낙인** → 시선·자리 지시 — "비비안은 의사가 사망 진단서를 들고 나오자 리비아의 손목을 한 번 응시한 채, 직원에게 리비아의 방을 정리해 두라고 지시한다"
- **뻔뻔함·자리 점령** → 핸드백·의자·식기 이동 — "미라는 리비아의 자리에 자기 핸드백을 올려두고, 비비안 옆자리로 의자를 끌어와 앉는다"
- **자기 방 인식** → 향수병·결혼 사진·옷걸이 조작 — "미라는 화장대 위 리비아의 결혼 사진을 뒤집어 놓는다. 돌아서며 화장대 서랍을 열어 자기 향수병을 꺼내 그 자리에 올려 둔다"
- **가족 균열** → 자리 이동 — "라이더가 처음으로 비비안 옆이 아니라 데클런 옆에 자기 자리를 잡는다" (괄호 메타 X)

**How to apply:**
1. 작성 시 의도(의심·악의·뻔뻔함 등)를 먼저 잡는다.
2. 그 의도를 직접 발화로 적지 말고, **행동·시선·소품·자리 이동·신체 동작**으로 옮긴다.
3. 자가 검수 — 작성한 트리트먼트 문장에서 인물의 발화·해설을 모두 빼도 의도가 전달되는가? 안 되면 행동을 더 강화.
4. 발화는 **장르 보상의 핵심 한 줄** (남주 선언형·남주 경고·남주 약속 등 production_guide 9-1 5조건 통과)에만 사용. 인물 의심·악의·동기 설명용 발화 X.
5. 외부 해설(괄호 메타·"가족 내부 첫 균열") 0건.

**적용 범위:** 모든 작품 트리트먼트 (EP1~EP8 본문, 클리프행어, 줄거리, 인물 소개). 사건·관계 노출 시 "설명 X / 보이게 O" 절대 룰.

**자가 시뮬레이션:** "이 문장에서 인물 발화를 빼도 그 인물의 의도가 시청자에게 전달되는가?" 안 되면 행동을 추가하거나 시각 동작으로 재작성.

## 추가 룰 — 행동·시각이라도 비유스러우면 X (필수, 2026-05-10)

행동·시각으로 옮긴 문장도 **다음 3 검수 통과 필수.**

1. **직관성** — 시청자가 한 번 읽고 즉시 그림이 그려지는가? "주접스러운 비유"가 끼어 있지 않은가?
2. **작중 쾌감·핵심 드러남** — 이 행동이 작품의 어떤 쾌감/핵심 비트(보상·반전·관계 발전·정체성 변화·정복 등)를 직접 보여주는가?
3. **만약 시청자가 "그래서 뭐?"라고 묻는다면 답이 한 줄로 나오는가?** 안 나오면 핵심이 안 드러난 것.

**거부 패턴 사례 (2026-05-10 사용자 명시 거부):**
- ❌ "다음 루프에서 칼은 처음으로 자기 노선이 아니라 슬론의 발걸음을 따라간다."
  - 직관 X (자기 노선 vs 슬론 발걸음 = 추상)
  - 비유 (실제 행동 X / 두 인물의 동선 비교 추상화)
  - 작중 쾌감 X (학습이 어떤 보상으로 전환되는지 안 보임)
- ✅ "다음 루프에서 칼은 슬론이 매번 죽는 사거리에 그녀보다 먼저 도착해 그녀의 팔을 잡고 다른 골목으로 끌어당긴다."
  - 직관 OK (사거리·팔 잡기·다른 골목 = 한 번에 그림)
  - 비유 X (실제 동작)
  - 작중 쾌감 OK (학습한 정보 → 슬론 구조 → 동행 시작 = 게임형 루프 보상)

**작성 절차 보완:**
1. 행동·시각으로 옮긴다 (기존 절차).
2. 그 문장이 "주접 비유"인지 검수 — 추상화된 비교·추상 동사 X.
3. 작중 쾌감·핵심을 한 줄로 답할 수 있는지 검수 — 안 되면 행동을 더 구체화.
4. 시청자 시뮬레이션 — "그래서 뭐?" 답이 즉시 나오는가.
