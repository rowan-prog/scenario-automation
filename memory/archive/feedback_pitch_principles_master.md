# 최상위 원칙

피칭덱은 작품을 **해설**하는 문서가 아니다. 위원이 작품을 **직접 본 것처럼 이해**하게 만드는 문서다.

문장은 다음 세 가지를 피해야 한다:
1. 작성자가 작품을 평가하는 말
2. 작성자가 작품의 구조를 해설하는 말
3. 읽는 사람에게 "이렇게 이해하면 된다"고 알려주는 말

피칭덱 문장은 **작품 밖에서 말하면 안 된다.** 작품 안에서 실제로 벌어지는 일, 인물의 처지, 빼앗기는 것, 뒤집히는 자리, 남겨지는 갈등만 써야 한다.

(피칭덱이 1차 적용 영역이지만, 청사진·러프·트리트먼트 모든 외부 노출 문서에 동일 적용.)

# 1. 문체 금지 락

## 1-1. 개념어로 사건을 대체하지 마라

**금지 표현 (개념어):**
구조 보유 / 작동한다 / 기능한다 / 장치다 / 확장된다 / 가능하다 / 시장성 보유 / 결제 질문 형성 / 중심 보상 / 핵심 보상 / 시각적 증거 / 권력 이동 / 정서적 축 / 관계성 확장 / 이해 비용 / 방향이 보인다 / 한눈에 잡힌다 / 첫눈에 잡힌다 / 화면에 남긴다

**나쁜 예:**
- "복수·각성·정복 구조 보유."
- "사적인 끌림과 공개적인 선택이 동시에 작동한다."
- "디아뎀과 인장이 권력 확장을 보여주는 시각적 증거로 기능한다."
- "죽음은 다음 시도에서 살아남기 위한 정보로 남는다."

**문제 진단:** 개념어가 전문 용어라서 금지인 게 아님. 실제 사건을 말하지 않고 작성자의 머릿속 정리를 그대로 문장에 내보내기 때문. 읽는 사람이 "그래서 누가 뭘 하는데?", "뭐가 빼앗기는데?", "어떤 장면이 벌어지는데?" 다시 묻게 만들면 실패.

## 1-2. 메타 해설을 쓰지 마라

**금지:**
- "세계관을 길게 설명하지 않아도 방향이 보인다."
- "이 설정은 초반 이해 비용이 낮다."
- "광고 컷으로 잘라 쓰기 쉽다."
- "유료 전환에 유리하다."
- "강한 후킹을 만든다."
- "시청자가 궁금해진다."
- "결제 질문이 형성된다."

**문제 진단:** 작품 설명이 아니라 작성자가 옆에서 해설하는 말. 외부 피칭에서 "이 사람이 작품을 보여주는 게 아니라 작품이 잘 팔린다고 주장하고 있구나"로 읽힘.

**나쁜 예:** "병원에서 깨어난 레나가 TV 속 자기 이름의 가짜 약혼녀를 보는 장면은 광고 컷으로 잘라 쓰기 쉽다."

**좋은 방향 (판단 X, 대립 자체):**
"병원 침대 위의 진짜 레나와 TV 화면 속 가짜 레나가 같은 이름으로 동시에 존재한다."

## 1-3. "좋다 / 쉽다 / 강하다 / 선명하다"로 설득하지 마라

**금지 빈말:**
시장성이 있다 / 후킹이 좋다 / 변별력이 선명하다 / 보상이 강하다 / 장면이 강하다 / 전환이 쉽다 / 클릭을 유도한다 / 몰입도가 높다

**문제 진단:** 작성자의 평가. 피칭덱은 평가를 주장하는 문서가 아니라, 평가가 가능하도록 근거를 놓는 문서. 삭제해도 정보 거의 안 줄어드는 빈 문장이라면 빈 문장.

## 1-4. "단순한 A가 아니라 B다" 남발 금지

**금지 패턴:**
- "단순한 제물 서사가 아니라…"
- "단순히 남자를 빼앗긴 이야기가 아니라…"
- "초자연 로맨스가 아니라…"
- "복잡한 기술 설정이 아니라…"
- "평범한 성장물이 아니라…"

**문제 진단:** 방어적. 읽는 사람이 아직 A라고 하지도 않았는데 작성자가 먼저 변명. **하지 않는 것**보다 **실제로 벌어지는 것**을 먼저 써야 함.

## 1-5. 사람을 물건처럼 만드는 단어 금지

**금지 (캐릭터 소개에 특히):**
폐기된 / 처리된 / 자산 / 변수 / 장치 / 도구로 기능 / 포지션 / 축

**나쁜 예:** "폐기된 반신"
**좋은 예:** "이름과 권리를 빼앗기고 신전 격투장에 던져진 반신"

**나쁜 예:** "칼은 월요일을 끝낼 수 있는 유일한 변수다."
**좋은 예:** "칼의 배지 기록만 리셋 뒤에도 남는다."

## 1-6. "화면"이라는 단어로 도망치지 마라

**금지:**
화면에 남긴다 / 화면으로 보여준다 / 시각적으로 증명한다 / 장면으로 구현된다 / 이미지 자산 / 시각 보상

**문제 진단:** 장면을 말해야 하지만 "화면에 남긴다"라고 쓰면 작성자가 연출 효과를 해설하는 말이 됨.

**나쁜 예:** "반지, 검, 이름, 문장이 권력의 이동을 화면에 남긴다."
**좋은 예:** "반지는 카엘의 손으로 넘어가고, 검은 주인을 바꾸며, 귀족들은 그를 내려다보던 자리에서 뒤로 물러난다."

# 2. 항목별 작성 원칙

## 2-1. 로그라인

설정 설명 X. **누가 무엇을 빼앗기고, 어디서 어떻게 뒤집는가**가 보여야 함.

**금지:** 세계관 설명 / 능력 설명 / 장르 설명 / 후반부 확장 설명 / "~하게 된다"만 반복

**필수 조건:**
- 주인공의 현재 처지가 바로 보임
- 빼앗긴 것이 분명함
- 적대자가 누구인지 보임
- 초반 전환점이 들어감
- 유료 구간으로 넘어갈 더 큰 갈등이 남음

**나쁜 예:** "그는 반복된 죽음을 생존 경로로 바꾸며 시스템에 접근한다." (생존 경로·시스템 흐림)
**좋은 예:** "그는 죽을 때마다 괴물이 나타나는 길과 닫히는 문을 기억하고, 마침내 자신의 사망 기록이 남은 Asterion 통제구역에 도착한다."

## 2-2. 인물 소개

설정표 X. **그 인물이 주인공에게 무엇을 빼앗고, 무엇을 유혹하고, 무엇을 막는지** 써야 함.

**금지:**
~을 보여준다 / ~로 기능한다 / ~의 기준이 된다 / ~의 축이다 / ~의 상징이다 / 후반부의 핵심 인물이다

**나쁜 예:** "RHEA는 카엘이 올림포스 무력 질서를 무너뜨리는 과정에서 중요한 전투 기준이 된다." (인물이 하는 일 없음, "기준"으로 정리만)
**좋은 예:** "레아는 아레스의 청동 검을 들고 카엘을 직접 시험한다. 그러나 카엘의 피가 검을 흔들자, 그가 아레스 가문에도 묶이지 않을 존재임을 알아본다."

**핵심 질문:**
- 이 인물은 누구 편인가?
- 주인공에게 무엇을 요구하는가?
- 주인공을 어떻게 흔드는가?
- 초반에 어떤 장면으로 기억되는가?

## 2-3. "왜 제작해야 하는지"

줄거리 재요약 X. 사업어 늘어놓기 X.

**해야 할 말:**
- 이 IP가 어떤 관객에게 바로 읽히는가
- 초반 무료 구간에서 어떤 첫 증거를 주는가
- 가장 큰 보상은 무엇을 남기는가
- 제작했을 때 어떤 장면이 반복해서 나올 수 있는가
- 기존 유사 소재와 비교해 어떤 자리가 다른가

**금지:**
시장성이 있다 / 광고 컷으로 잘라 쓰기 쉽다 / AIGC 실사형으로 구현 가능하다 / 무료 구간에서 전환 질문이 형성된다 / 세계관을 길게 설명하지 않아도 방향이 보인다

**작품 안 근거 우선:**
"리비아는 시아버지의 죽음 옆에 있었다는 이유로 범인처럼 몰리고, 남편은 임신한 내연녀를 가족 앞에 세운다. 그런데 실라스의 유언장은 애드리언이 아니라 리비아를 상속자로 지목한다."

**결론문 ("따라서 시장성이 있다") 금지** — 장면과 갈등이 제대로 놓이면 읽는 사람이 판단함.

## 2-4. "시장성이 있는지"

시장 판단은 가능. 단 빈 주장 금지.

**금지:**
충분한 시장성 보유 / 유료 전환이 좋다 / 클릭을 유도한다 / 광고 소재화가 쉽다 / 타깃 수요가 있다

**대신 써야 할 것:**
- 무료 구간 마지막에 무엇이 아직 안 끝났는가
- 어떤 굴욕/폭로/역전/소유/정복이 유료 구간에 남는가
- 시청자가 다음 회에서 확인해야 할 사건이 무엇인가

**핵심:** 무료 구간은 **보상을 완성**하는 구간이 아니라 **보상이 실제로 존재한다는 첫 증거**를 보여주는 구간.

**금지:** "무료 구간 안에서 핵심 보상을 끝까지 보여준다."

**작품별 무료 한도 (사용자 명시):**
- TITAN BORN: 신성 반지 강탈까지만. 신전 장악·제우스 대면은 남김.
- THE OFFERING: 신부 선언까지만. 바엘의 이유·인간 왕국의 약속은 남김.
- I AM THE HEIR: 첫 상속 권한 공개까지만. 회사 장악·사망 진실은 남김.
- THE LAST KEY: 봉인이 되돌아갈 수 있다는 첫 역전까지만. 가족 전체 붕괴·고대 신의 요구는 남김.
- SHE STOLE MY FACE: 증거 발견까지만. 공개 폭로·후회남 반응은 남김.
- EVERY MONDAY: 회사가 알고 있었다는 화면까지만. 루프의 목적·칼의 특이성은 남김.

## 2-5. "크리에이티브 변별력"

"차별점이 있다" 쓰는 칸 X. 비슷한 소재와 달리, 이 작품에서 **무엇이 더 세게 빼앗기고 무엇이 더 세게 뒤집히는지** 써야 함.

**금지:**
차별점은 ~라는 점이다 / 기존 문법과 변별력이 있다 / 일반적인 소재보다 선명하다 / 흔한 장르와 다르다

**좋은 방향:**
- 이 작품은 누구의 무엇을 빼앗는가
- 비슷한 장르보다 더 즉각적인 굴욕은 무엇인가
- 다른 작품에는 없는 공개 장면은 무엇인가
- 주인공이 되찾는 것이 남자/돈/권력/이름/몸/기억 중 무엇인가

**좋은 예:** "마라는 레나의 약혼자만 빼앗는 것이 아니라, 레나의 얼굴, 이름, 흉터, 어머니 목걸이, 어린 시절 영상까지 자기 것으로 사용한다."
("차별점"이라는 말 없이도 변별력이 보임)

## 2-6. 줄거리

내부 구조 설명 X. **이야기가 실제로 어떻게 벌어지는가**만.

**금지:**
유료 구간에서는 ~로 확장된다 / 후반부에는 ~가 연결된다 / 각각 다른 기능을 대표한다 / 핵심 보상이 강화된다 / 구조가 선명해진다 / 인물의 위치가 바뀐다

**필수 표현 톤:**
누가 죽는다 / 누가 밀려난다 / 누가 들어온다 / 무엇이 공개된다 / 누가 무엇을 빼앗는다 / 누가 그 자리에서 밀려난다

**원칙:** 줄거리는 논평이 아니라 **사건의 흐름**.

## 2-7. 트리트먼트

회차별 정보 요약 X. **각 회차에서 처지가 어떻게 악화되거나 뒤집히는지**가 보여야 함.

**금지:**
~라는 사실을 알게 된다 / ~의 단서를 발견한다 / ~의 구조가 드러난다 / ~가 기능한다 / ~을 암시한다

**약한 클리프행어 (단서 발견만으로 끝남):**
- "기록에 새로운 이름이 적혀 있다."
- "화면에 특정 코드가 뜬다."
- "도면에 봉인선이 있다."

→ **정보가 인물의 처지를 바로 바꾸지 않으면 약함.**

**회차별 질문:**
- 이번 화에서 주인공은 더 불리해졌는가?
- 아니면 첫 반격을 했는가?
- 누가 주인공의 자리를 빼앗았는가?
- 어떤 물건/권한/이름이 이동했는가?
- 마지막 컷에서 다음 화를 봐야 하는 이유가 생기는가?

# 3. 금지어 리스트 (전 문서 검색 후 우선 의심)

구조 보유 / 작동한다 / 기능한다 / 가능하다 / 확장 가능 / 구현 가능 / 제작 가능 / 시장성 보유 / 결제 질문 / 전환 질문 / 이해 비용 / 중심 보상 / 핵심 보상 / 후킹 / 페이월 전환 / 시각적 증거 / 화면에 남긴다 / 장면으로 구현된다 / 이미지 자산 / 방향이 보인다 / 첫눈에 잡힌다 / 한눈에 잡힌다 / 광고 컷으로 잘라 쓰기 쉽다 / 클릭을 유도한다 / 차별점은 ~라는 점 / 단순한 ~이 아니라 / ~로 기능 / ~로 작동 / ~의 축 / ~의 장치 / ~포지션 / 변수 / 자산 / 폐기

(전부 무조건 금지는 아님. 그러나 이 단어가 나오면 사건을 쓰지 않고 평가·해설로 도망간 문장일 가능성 높음.)

**기존 메모리(`feedback_banned_expressions.md`)와 함께 검수**: 폐기 / 코어 / 호명 / 호명과 위치 / "이 작품의 핵심은 ~가 아니라" / "은밀한 친밀감보다 공식 지위 역전" 도 모두 금지.

# 4. 5 최종 검수 기준 (필수, 모든 문장 통과)

피칭덱·청사진 문장을 쓴 뒤 다음 7 질문을 모두 통과해야 함:

1. 이 문장에 **실제 사건**이 있는가?
2. 사람이 움직이거나, 물건이 넘어가거나, 자리가 바뀌는가?
3. 작성자의 평가가 아니라 **작품 안의 사실**인가?
4. "구조 / 기능 / 작동 / 가능 / 보유" 없이도 의미가 전달되는가?
5. 읽는 사람이 "그래서 뭐가 벌어지는데?"라고 묻지 않는가?
