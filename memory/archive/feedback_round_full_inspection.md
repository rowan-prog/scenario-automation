scenario-automation 검토 사이클(phase_5)의 **각 라운드는 작품 전 화수에 대해 일괄 전수검사**한다. 직전 라운드 패치된 화만 선별 검토하지 않는다.

**Why:** 사용자가 2026-05-08에 명시 — "라운드는 이전 라운드에서 수정한 에피소드만 선별하여 검토하는 것이 아니다. 일부 에피소드 변경시, 전체의 관점에서 다른 부분의 논리/정합성/기타 오류, 약점들이 발생할 수 있는 게 시나리오다. 따라서 라운드마다 전수검사다."

시퀀스 작품에서 일부 화 패치는 다음 ripple 영향:
- 정보 설계 (한 화의 정보 공개 시점·강도 변경 → 다른 화의 정보 장벽·reveal 어휘 분리 변화)
- 시각 표지 (한 화의 권능·룩 변형·소품 변경 → 다른 화의 단계 누적·일관성 변화)
- 캐릭터 캐논 (한 화의 행동·대사 변경 → 다른 화의 캐논 곡선 변화)
- 관계 변화 (한 화의 관계 발전 강도 변경 → 다른 화의 관계 진화 단계 변화)
- 광고 컷 / 페이월 응축 (한 화의 시각 강화 → 페이월 응축 단일성 변화)

**How to apply:**
1. phase_5 호출 시 라운드 N의 검토는 **작품 전 화수 일괄 수행**.
2. 직전 라운드 패치된 화는 패치 후 상태로 검토. 패치되지 않은 화도 ripple 영향 확인 위해 재검토.
3. 매 라운드 독립 검토 — 이전 라운드 결과 복사 금지.
4. 효율성 위해 통합 보고서(Arc-level / 전체 batch) 가능하나, 검토 범위는 항상 전 화수.
5. 라운드 카운트(5회 한계)는 전수검사 라운드 카운트.
6. 자연 종료 조건: 전수검사 결과 모든 화 무결(🔴·🟡 0건) + 4-Gate 모든 화 통과 → 최종고 확정.
7. phase_5·phase_6 prompt에 등재됨 — 메모리는 백업.
