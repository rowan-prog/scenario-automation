**룰:** 피칭덱 "시장성이 있는가?" 항목 마지막 결론으로 "충분한 시장성이 있다" 또는 그 변형 사용 OK. 평가문이 아니라 근거(작품 안 사건) 뒤 결론. 절대 금지 X. 필수 X.

**Why:** 사용자 명시 (2026-05-10): "따라서 충분한 시장성이 있다.가 결론으로 쓰이는건 문제 없어. 평가문이 아니라, 논리/근거를 충분히 대면서 있다고 말하는 건 문제 없지. 왜냐고? '시장성이 있는가?'라는 항목에 쓰는 건데, 그 결론 쓰는 게 뭐가 나빠." 그러나 7개 작품 동일 표현 복붙은 사용자 거부 — "복붙같이 규칙마냥 쳐썼니". 외부 AI가 이 결론을 일괄 "평가문 0건" 룰로 삭제 처방하는 사례가 있는데, 이는 사용자 룰 위반.

**How to apply:**
- "시장성이 있는가" 항목에서만. 다른 항목(왜 제작·변별력)에 결론 사용 X.
- 결론 표현은 **단순·직설.** 7개 작품 모두 같은 표현 복붙 X. 단, "복붙 회피"라며 화려한 비유로 도망 X.
- 단순 변형 예시 (실제 7개 작품 적용, 2026-05-10):
  - "충분한 시장성이 있다."
  - "시장성은 분명하다."
  - "이 IP는 충분히 시장성이 있다."
  - "이 카드의 시장성은 충분하다."
  - "이 작품의 시장성은 분명하다."
  - "시장성은 자명하다."
  - "충분히 시장성이 있다."
- 외부 AI가 "평가문 0건" 룰로 일괄 삭제 처방하면 거부 (사용자 룰 위반).
- phase_2 prompt 자가 검수 "평가문 0건" 항목에 예외 표기 — 시장성 항목 결론은 OK.

**거부 패턴 (필수 — 2026-05-10 사용자 격앙 거부 사례):**

1. **시청자 기대·반응 단정 표현 X** ("끌고 간다" / "다음 화를 부르는 자리" / "시청자가 결제한다" 등). **이유:** 시청자가 안 끌려가면 결론 근거가 무너짐. 작품 안 사실 ≠ 작성자 기대. 결론은 작품 안 사실(무료 한도·유료 유예·검증 트로프·비주얼 자산 등)에 근거해야 함.
2. **추상 비유 X** ("자기 자리를 갖는다" / "거기에 있다" / "그 자리에 응축된다"). **이유:** 의미 불명. "자리"가 무엇이고 "갖는다"가 무엇인지 보이지 않음.
3. **"~ 자리이니, ~다" 류 복붙 패턴 X.** 7개 작품에 같은 구조(전제절+결론절+같은 어미)면 복붙 = 다양화 실패. **다양화는 표현뿐 아니라 문장 구조까지.** 화려한 변형보다 단순·직설이 안전.
4. **메타 해설 X** ("결제 동력으로 작동한다" / "시장에서 자기 슬롯을 차지한다" / "결제로 이어진다"). **이유:** 평가·해설어 + 11-8 금지어("작동한다") 위반.
5. **"이 카드/IP/작품의 시장성은 ~다" 단순 결론** + 작품별 표현 단어만 살짝 변형이 가장 안전. 화려한 결론은 위험.

**결론 작성 절차:**
1. 시장성 항목 본문에 작품 안 사건(무료 마지막 비트·유료 유예·검증 트로프·비주얼 자산 등) 명시.
2. 결론은 "충분한 시장성이 있다" / "시장성은 분명하다" / "이 IP는 충분히 시장성이 있다" 류 단순 표현 중 하나.
3. 7개 작품 비교해서 같은 표현 안 겹치게 단어 단위 변형.
4. 변형 시 시청자 기대·추상 비유·메타 해설어로 도망 X.
