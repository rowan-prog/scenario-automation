# v3 8 핵심 용어 — paid vertical 공통 lexicon

`config/master_guide_v3.md` PART 3 발췌.

## 8 용어

| # | 용어 | 정의 | 작품 진입 시 자가 답 |
|---|---|---|---|
| 1 | **실제 가치** (Real Value) | 주인공이 실제로 가진 가치 (능력·관계·아이·운명·권한). 작중 세계가 못 보거나 부정하거나 잘못 부여한 가치. | 주인공의 실제 가치는 무엇인가? |
| 2 | **거짓 판결** (False Verdict) | 작중 세계가 주인공에게 내리는 잘못된 판단. "자격 없다 / 가짜다 / 무능하다 / 사랑받을 가치 X". | 누가 어떤 거짓 판결을 내리는가? |
| 3 | **빼앗긴 자리** (Stolen Place) | 주인공에게 속해야 했지만 악역·라이벌·가짜·공동체가 빼앗은 자리. 관계·명예·공적·아이·사랑·권한·이름·인정. | 무엇을 빼앗기고 누가 차지했는가? |
| 4 | **선택권자** (Chooser) | 주인공의 가치를 확정·뒤집을 수 있는 존재. 여성향 = 알파메일 / 남성향 = 시스템·권력·전장·여성 캐릭터. | 누가 선택권자인가? 등장은 언제? |
| 5 | **대체자** (Replacement) | 주인공의 자리에 대신 앉은 존재. 라이벌 여성·가짜 약혼자·가짜 영웅·배신 동료. **"주인공이 대체될 수 있다는 공포"**를 만듦. | 누가 대체자인가? 어떤 자리에? |
| 6 | **공동체** (Community) | 주인공을 잘못 판단하는 주변 세계. 가족·회사·왕실·사교계·법·시스템. **대표 인물 2-4명 + 군중**으로 압축. | 어떤 공동체가 거짓 판결에 동참하는가? |
| 7 | **감정 장부** (Emotional Ledger) | 주인공이 당한 고통·모욕·손실·배신·자리 침범이 관객에게 쌓이는 정서적 부채. "당한 만큼 돌려받아야". | 어떤 장부가 쌓이는가? 어떻게 회수? |
| 8 | **관객 우월 인식** (Audience Superior Knowing) | 관객은 진실을 알고 작중 인물은 모름. 시청자가 "왜 저렇게 평가하지?"를 느끼게. | 관객만 아는 진실은? 언제 작중 인물에게 공개? |

## phase_1 8 슬롯 강제

phase_1 (러프 청사진) 진입 시 8 용어 슬롯 모두 채워야 phase_2 진입.

```
## 8 핵심 용어 슬롯

1. 실제 가치: [한 줄]
2. 거짓 판결: [누가 → 누구에게 → 무엇으로]
3. 빼앗긴 자리: [무엇 → 누가 차지]
4. 선택권자: [누구 + 첫 등장 시점]
5. 대체자: [누구 + 어떤 자리]
6. 공동체: [어떤 세계 + 대표 2-4명]
7. 감정 장부: [쌓이는 부채 + 회수 방식]
8. 관객 우월 인식: [관객만 아는 진실 + 공개 시점]
```

## 검토·피칭덱 lexicon 통일

- 피칭덱 작성 시 8 용어로 일관 표현 — 위원 인지 빠르게
- phase_5 페르소나 검토 시 8 용어 기반 판정
- 외부 평가·피드백 처리 시 8 용어 mapping

## How to apply

- **phase_1 진입 시 자동 strict** — 8 슬롯 채우지 않으면 phase_2 진입 불가
- **phase_2 피칭덱:** 트리트먼트 안에 8 용어가 사건으로 보이는지 자가 검수
- **phase_5 검토:** 페르소나가 "거짓 판결이 약함" "감정 장부 누적 안 됨" 식으로 8 용어 기반 진단

## 핵심 한 줄

> **paid vertical은 8 용어로 분석된다. phase_1 8 슬롯 강제 = 청사진 정합성 자동 확보.**
