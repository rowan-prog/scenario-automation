# 남성향 피칭덱·작품 개발 인사이트

## 최상위 원칙 — 메이저 = 구조 + 욕망 + **소재** 모두 메이저 (필수, 2026-05-12 사용자 보강)

> "욕망과 보상 구조, 갈등 구조는 메이저여도, 진짜 메이저는 소재도, 욕망도 메이저여야 한다. 웹툰·웹소설·paid drama/animation 시장에서."

남성향 메인 = **소재(직업·세계·아이콘) 자체가 글로벌 대중 욕망과 직접 결합**해야 함. 구조·욕망·결제 곡선이 정석이어도 소재가 niche·뜬금이면 메이저 진입 X.

**망한 소재 (실측 — paid vertical 남성향):**
- 요리사 최강 / 낚시꾼 최강 / 정비공 최강 / 배달원 최강 (MY MAP) / 청소부 최강 (단독 소재일 때)
- → 직업 자체가 글로벌 남성 판타지 핵심이 아님. 메인 한국 웹툰·웹소설·paid drama/animation에서도 이런 직업 단독 메인 X
- → 메커니즘이 정교해도, 보상 구조가 깔끔해도, **소재가 메이저 아니면 메이저 안 됨**

**메이저 소재 (글로벌 검증 — 욕망 자체가 메이저):**
- 신화 영웅·전사·왕·황제·헌터·각성자·검사·마법사·기사·드래곤 라이더·우주 함장·SF 군 사령관
- → "되고 싶은 자기상"이 직접적·즉각적

**Village Fool / Janitor / Farmer / Carpenter God Mode 트로프와의 구분 (필수):**
- 직업이 메인 정체성이 X = **시작점일 뿐**. 곧바로 신·황제·각성자·검사로 변신
- 직업 그 자체가 끝까지 정체성 = 망함 (요리사로 끝까지 요리하며 강해짐 X)
- → "낮은 출발 → 신적 변신"의 출발점으로만 직업 사용. 그 직업의 스킬셋이 메인 X

**자가 검증 (남성향 phase_0·phase_1):**
- [ ] 주인공 메인 정체성이 글로벌 메이저 자기상인가? (전사·황제·검사·헌터·마법사 등)
- [ ] 소재가 "되고 싶은 욕망"과 직접 결합? (니치 직업 단독 X)
- [ ] 한국·중국·미국 웹툰·웹소설·paid 시장에서 동일 소재 메인 히트작 있나?
- [ ] 직업 시작이면, 곧바로 메이저 정체성으로 변신하는가?

→ 모두 ✅ = 메이저 소재 / 1개라도 X = niche 위험

**사용자 메모 (보존):** 사용자가 절대 룰 아님 명시 — "사실은 다를 수 있으므로 무조건 수용할 필요 없음." 단 위원 F·B 거절 사유와 정합. 반례(요리 만화 등 一般 시장 히트작) 있으나 paid vertical 남성향 한정 강한 신호.

**미검증 카테고리 (위험):**
