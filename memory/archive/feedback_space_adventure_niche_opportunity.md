# Space-set Sci-Fi — 진입 기회 + 결제 엔진 결합 룰

## 핵심 룰 (사용자 명시 2026-05-11)

> **장르중에 '스페이스 어드벤처'의 경우, 북미권에서 최상위권급은 아니나, 동아시아권과 두드러지게 선호되는 경향이 있다. 분명하게, 한국/중국/일본에 비해선 메이저쪽이다. 이건, 북미 타깃, 특히 paid vertical drama/animation 쪽은 북미시장에서 남성향 시장이 공백이 좀 있어서, 이곳을 뚫는 데 있어 유효할 것 같다는 판단이 든다.**

## 시장 위치

| 시장 | 스페이스 어드벤처 위치 |
|---|---|
| **북미 일반 대중** | **메이저** (가디언즈 오브 갤럭시·Star Wars·Mass Effect·Starfield·Star Trek·Firefly·카우보이 비밥 영문 더빙 BOOM) |

| **동아시아 (한국·중국·일본)** | **북미가 압도적 메이저** (해외 IP 수입형 소비) |

## 진입 기회의 본질

### 왜 공백인가
- 북미 paid vertical drama = 35-54세 여성 시청층 중심 (Crazy Maple CEO 명시)
- 남성향 라인업 자체가 약함
- 정통 스페이스 오페라 paid vertical 사례 거의 없음
- 따라서 **남성향 paid vertical/animation 시장 진입 시 경쟁자 적음**

### 왜 진입 기회인가
- AIGC Animation 3D + 가로형 16:9 = 남성향 애니 표준 (페이드 미스매치 X)
- 글로벌 IP 톤 = 검증된 시장 (가디언즈 오브 갤럭시·Mass Effect 등)
- 게임 → vertical 변환 시 시각 보상 강함 (우주 함선·외계 행성·VFX = AIGC 강점)
- 동아시아 시청층은 북미 SF IP 익숙 → 글로벌 동시 공략 가능

## 진입 전략

### 1. AIGC 강점 살림
- 우주 함선·외계 행성·다종족 캐릭터·우주 전투 VFX = 실사 거의 불가능
- **AIGC Animation 3D / 가로형 16:9** 표준 포맷

### 2. 글로벌 IP 톤 + paid vertical 결제 엔진 결합
- **외관:** 가디언즈 오브 갤럭시·카우보이 비밥·Firefly·Mass Effect·Star Wars Outlaws
- **내부 엔진:** paid vertical 회차 갱신·페이월·랭킹 상승·시스템 진척

### 3. Source Market 활용
- **게임:** Mass Effect / Star Wars Outlaws / Starfield / Borderlands / No Man's Sky / Star Citizen 결제 패턴
- **LitRPG:** System + Space 결합 (Dungeon Crawler Carl 후반 우주 진입·Ex-Heroes 류)

### 4. 7 이식 모델 매칭
스페이스 어드벤처에 가장 적합한 이식 모델:
- **2위 Survival Base-building** — 함선·기지·우주 정거장 확장
- **3위 Combat Ranking League** — 현상금 헌터·검투 리그·우주 전투 랭킹

### 5. 회차 갱신 5요소 (스페이스 어드벤처 특화)
