피칭덱의 "해당 IP 피칭 사유 (Core Expectation)" 아래 3 섹션은 **장면 요약도 아니고 BM 구조 설명서도 아니다.** 위원이 보는 것은 "그래서 이거 첫인상에 재밌나? 어떤 장면이 돈 되나? 왜 이걸 지금 만들지?" 단 3가지. 문서가 회차 설계를 설명하면 위원은 "알 바 아니다"라고 닫는다.

**Why (2단계 누적):**
- **2026-05-11 1차:** 5개 작품 모두 "EP 사건 나열"로 채워짐 — 사용자 "왜 만들어야 하는지를 설득하는 건데 논리, 기획적인 측면이 접근이 안 되어있다."
- **2026-05-11 2차:** 1차 피드백 기반 재작성도 또 다른 함정에 빠짐 — "유료 구간으로 남는다 / 결제 질문에서 나온다 / 무료 보상이 정점 / 라인업 슬롯 / 저위험 카드" 같은 **내부 BM·편성 언어**로 채워짐. 사용자 "다 틀렸어 씨발. 개빡친다." → BM 언어는 기획자에게는 맞지만 위원에게는 알 바 아님.

**How to apply:** phase_2 작성·재작성 시 다음 강제.

## 대체 원칙: 장면형 끝맺음

**"남긴다"가 아니라 "끝난 장면이 다음 장면을 부른다"로 써라.**

✅ "EP8은 카엘이 반지를 빼앗는 순간에서 끝난다. 이제 관객이 확인하고 싶은 것은 하나다. 제우스가 직접 움직이는가."  
✅ "EP8은 바엘이 '신부'라는 말을 끝내기 직전 멈춘다. 다음 회차의 질문은 선언의 완성이 아니라, 인간 왕국 앞에서 이솔데가 어떤 지위로 불릴 것인가다."  
✅ "EP8은 리비아가 저택의 지시권을 손에 넣는 장면으로 끝난다. 하지만 비비안은 식당을 나가며 라이더에게 새 봉투를 넘긴다."

핵심: **마지막 무료화의 장면 + 그 장면이 부르는 다음 회차 질문**. "유료 구간" 단어 0회 사용해도 된다.

## 설명어 → 장면어 치환표

| ❌ 설명어 (기획자 BM 언어) | ✅ 장면어 (위원 시점) |
|---|---|
| 권력 이동 | 의자가 빠진다 / 계급장이 손등 위에 올라간다 |
| 결제 질문 | EP8 끝의 한 컷 + 다음 회차 질문 한 줄 |
| 보상 누적 | 회차마다 추가되는 구체 사물 (반지·서류·깃발) |
| 호명 역전 | "제물"이라고 불리던 자리에서 "신부"로 불리기 직전 |
| 지위 회복 | 직원들이 가족이 아니라 리비아의 지시를 기다린다 |
| 콘텐츠 강점 | 격투장·검은 성채·저택 식탁이 반복 자산으로 작동 |
| 시장성 보유 | 첫 클릭은 ~ 장면에서 생기고, 무료 구간 유지는 ~의 반복으로 생긴다 |

## 섹션별 역할 분리 (필수, 2026-05-11 3차 정정)

**왜 제작해야 하는지?** = **메타 기획서 only.** 인물·장면·EP·사건 0건. 1단락 3-4문장.
- 포맷 (Live-action/Animation·2D/3D·세로형/가로형)
- 타깃 (국가 + 성별 + 나이대)
- 장르·시장 위치 (북미 paid vertical 안에서 어떤 카드, 검증 트로프인지)
- 차별 카드 (중국 시스템 애니메이션을 북미 맞춤으로 옮김 / 검증 재벌가 복수극을 정체성 탈취로 강화 등)
- AIGC 적합성 (왜 실사가 아니라 AIGC인가, 또는 왜 애니가 아니라 실사인가, 어떤 자산을 양산하기 적합한가)
- **금지:** 인물 이름·EP 사건·장면 묘사·대사·트리트먼트 반복

**시장성이 있는지?** = **첫 클릭 + 결제 동기 메타.** 장면은 최소.
- 첫 클릭은 어디서 (제목·로그라인 한 컷의 즉시 후킹)
- 무료 구간 보상 누적 방식 (구체 사물 명사 짧게)
- EP8 끝 장면 + 다음 회차 질문 한 줄

**변별력?** = **라인업 안 차별 메타.** 한 컷 명시.
- 같은 장르와 다른 한 컷
- 반복 가능한 시각 자산 명사 나열

**핵심 원칙:** 로그라인·줄거리·트리트먼트·인물 소개에서 이미 했으니 IP 사유 섹션은 **반복하지 말고 메타 정보만**. 인물·장면을 또 설명하면 위원에게 "구구절절"로 읽힌다.

(2026-05-11 3차 사고: 사용자 명시 교체문조차 EP1·EP3·EP8 장면 반복이 들어 있었음. 사용자 추가 피드백 — "특정 장면들을 왜 설명하냐고. 로그라인, 줄거리, 트리트먼트에서 구구절절 반복해서 똑같이 다 한 건데." 5개 작품 "왜 제작" 메타 기획 1단락으로 재축약.)

**구조:**

## "왜 제작" — 작품마다 출발점이 다르다 (필수, 2026-05-11 9차 결정)

**핵심:** "왜 제작해야 하는가"는 도식적 패턴으로 답할 수 없다. 작품마다 **5 변수**에 따라 출발점·구조·답 자체가 다르다.

### 5 변수 (작품 검토 시 5개 중 가장 강한 것 1-2개 선택):

1. **장르** — 익숙한 IP 진입성 (TITAN: "Greek myth는 익숙하지만 길게 풀면 X")
2. **작품** — 작품 고유 한 컷·핵심 사건 (사용자가 OK한 한 컷 강조)
3. **타깃** — 시청자 피로·욕망·기대 (EMPIRE: "남성향 SF 시청자는 약한 곡선에 지쳤다")
4. **내용** — 보상 방식·구조 차별 (HEIR: "이 작품의 보상은 사물 중심")

## "왜 제작" 톤 — 메모식·기획서식 + 레퍼런스 IP 인용 (필수, 2026-05-11 5차)

사용자 명시 톤 (TITAN 예시):
> Greek myth는 북미 시청자에게 익숙하지만, 계보와 설정을 길게 풀면 이탈 위험 큼. 이 작품은 신화 소재를 차용하되 "짐승 취급받던 남자의 신전 권력 강탈" 핵심 갈등을 빨리 제시해 몰입을 높임. 타깃 맞춤으로 남성 시청자가 좋아하는 격투장·사슬·파워 판타지·역전을 결합. 북미 대히트작 '갓 오브 워'가 자연스럽게 떠오르도록 유도하는 IP.

**4 패턴:**
1. **장르 카테고리 약점/위험 명시** — "익숙하지만 ~하면 이탈 위험 큼", "검증되었으나 ~ 약함"
2. **이 작품의 차용 + 핵심 갈등 빨리 제시** — "차용하되 [핵심 갈등 한 줄]을 빨리 제시"
3. **타깃 맞춤 결합 요소 명사 나열** — "타깃 맞춤으로 [성별] 시청자가 좋아하는 [요소들]을 결합"
4. **북미 대히트 레퍼런스 IP 떠올리도록 유도** — "[IP명]이 자연스럽게 떠오르도록 유도하는 IP"

**문체:** 명사형 압축 (~함, ~ 큼, ~ 결합, ~하도록 유도하는 IP). 길게 풀어쓴 시적 톤 X. 메모·기획서 느낌.

**금지:**
- "이 IP를 골라야 하는 이유는 ~ 때문이다" 류 길게 풀어쓴 결론문
- "~할 수 있기 때문이다 / ~하기 때문이다" 반복
- 시적·묘사적 표현
- AIGC 강점 길게 풀기 ("매주 반복 자산화" 류는 변별력 섹션으로)

**작품별 적용 (2026-05-11):**

- THE OFFERING: 'A Court of Thorns and Roses'·'Fourth Wing' 떠오르는 IP

## 사용자 직접 교체문 다루기

**1차 룰:** 사용자가 "수정 위치 + 교체문"을 직접 명시하면 **그대로 적용.** 임의 강화·디테일 추가 금지. 의도적으로 짧게 쓴 압축을 늘리면 위반.

**2차 룰 (2026-05-11 추가):** 단 사용자 교체문도 더 큰 메타 원칙(인물·장면 반복 금지·메타 기획 only 등)을 위반하면 사용자 추가 피드백으로 정정 대상이 될 수 있다. 처음 제공된 교체문이 절대적 정답은 아님 — 사용자가 자기 텍스트를 보고 추가 깨달음을 줄 수 있다.

**"기계적으로 받지 말고 인사이트 얻어 최선"** = 사용자 텍스트의 **원칙**(장면어·압축·BM 언어 0·메타 기획 only)을 이해해 사용자 미명시 영역에도 같은 원칙을 적용. 텍스트 자체를 변경·보완하라는 의미는 아님. 새 피드백이 들어오면 사용자 1차 텍스트도 함께 정정.

(2026-05-11 두 사고:
- Round 2 강화 추가 → 사용자 격분 → 롤백
- Round 1 사용자 텍스트 그대로 적용 → 며칠 뒤 사용자가 자기 텍스트도 EP 반복이라고 추가 피드백 → 메타 기획 1단락으로 재축약)
