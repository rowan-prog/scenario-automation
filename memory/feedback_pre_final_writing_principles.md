# 최종고 산출 전 집필 가이드 (간소화 10 카테고리·사용자 명시)

**사용자 명시 (2026-05-26):**
"진단 항목이 아니라, 간소화해서, 집필 규칙 내지 참고 가이드로 적용하라."

원본 35 항목을 10 카테고리로 그룹화. 매 EP 작성 시·LOCK 직전 *집필 기준*으로 참고. 진단 체크리스트 X.

## 1. 타깃·매출·수위 (항목 1·2·3·26·27·29)

작품은 *타깃 시장*이 돈을 내고 보고 싶어하는 *핵심 쾌감*을 *반복 제공*한다.
- 굴욕·반격·구원·로맨스·섹슈얼 텐션·복수·획득·반전 = 적절 간격·꺼지지 않게
- 성적 수위 = 장르 정합 (다크 로맨타지 = T4-T5)·필요 없는 장르는 억지로 X
- 폭력·자극 = 리스크 대비 리턴 (하이리스크 로우리턴 X)
- 광고·클립 가능성 = 첫 5초·굴욕·반전·보호·처벌·욕망·reveal·보상 시각 분명 (대본 안 광고 표기 X)

## 2. 락인·결제 견인 (항목 4·5·6)

- **EP01 첫 컷·3초·15초·60초** = 이탈 막을 강한 시각/대사/상황 훅·USP 즉시 전달
- **무료 구간 (EP01-08)** = 빠른 중독·결정적 보상 발화는 paywall 뒤로
- **Paywall EP (EP08)** = cliffhanger·다음 화 결제 견인
- **첫 paid EP (EP09 first scene)** = 결제 직후 즉시 보상 (`feedback_paywall_declaration_timing.md`)
- **모든 EP End Hook** = 질문·폭로·위협·굴욕·선택·신체 접촉·반전·처벌·보상 중 하나. 분위기 컷·애매한 정지 X.

## 3. 주인공 소유 (항목 7·8·12)

- 주인공의 대사·선택·행동·욕망·분노·판단·승리가 *장면 중심*
- 조연·빌런·설정이 주인공 장면 *훔치기 X*
- 주인공이 과묵한 조연처럼 X
- 주인공 대사·VO 충분·VO = 욕망/분노/판단/결핍 직접·설명문 X
- 캐릭터별 말투 분리 (나이·계급·욕망·불안·성격·관계)

## 4. Vertical Voice (항목 9·10·11·30)

- 영어·현지어 = 배우 발화 가능·번역투/문어체/과한 고풍체 X
- 대화 흐름 = 인물 서로 반응·선언문 읽기 X·turn-taking 자연
- 대사 스타일 = AI 멋진 문장·시적 선언·법정 판결·의식문 X
- 자막 친화성 = 즉시 이해·번역 의미 손실 X·길이 짧게

## 5. 직관성·행동 중심 (항목 13·14·15·16)

- **0.5초 이해 가능해야** — 시청자 추론/해석 구조 X
- **은유 사용 룰:**
  - ❌ 금지 = 은유가 사건 본체 *대신*하는 것 (`The lamp goes out` = sex 대신)
  - ✅ 허용 = 사건 명확히 보인 *뒤* 반응 보조 (`The room goes silent.`)
  - 판정 3 질문: 은유 빼도 사건/누가/관계 보이는가
  - 핵심 거래 (키스·섹스·claim·refusal·aftermath) = literal 먼저
- 행동 중심 지문 = 누가/어디서/무엇/어떻게·정서 해석 X
- 설정어/고유명사 (cycle·keep·house·council·mark·bloodline·law·name) = 정보 전달 제한적·감정 잡아먹기 X
- 감정 고점에서 = 직관적 말과 행동 우선

## 6. 장르·분량 (항목 17·18·28)

- 장르 이탈 금지 (다크 로맨타지 → 정치극·PC 걸크러시·세계관극 변질 X)
- 분량 = 숏폼 러닝타임 정합·기계적 절감 X·장면 호흡 우선
- 반복/낭송 제거: 같은 호칭·보상어·위협·mirror dialogue 반복 X·체크리스트처럼 보상 읊기 X (`My wife / Your wife / My mate / Your mate` 6쌍 mirror = 금지)

## 7. 내부 정합성 (항목 19·20·21·22·23)

- **공간 논리** = 위치·이동·출입·거리·시선·문·방·차량·전장 일관
- **행동 논리** = 캐릭터 욕망·공포·목표 정합·납득 가능
- **감정 논리** = 변화 자연스러움·비약 X·장면 안 충분히 연결
- **내부 정합성** = 시간·나이·임신·상처·소품·약속·복선 회수
- **의상/비주얼 정합성** = 대본 ↔ 비주얼락 충돌 X·의상 불필요 변화 X

## 8. 시각 구현·9:16 (항목 24·25·31)

- 지문 = 촬영팀/AIGC 바로 구현 가능·미세 표정/군중 의존 X
- 9:16 세로 화면 = CU·Mid·Wide·OTS·Low/High Angle 장면 기능에 맞게
- 핵심 장면 [KEY CAMERA] shot list 명시
- 비선형 (Flashback·Intercut·Montage·Flash-forward) = 장면 기능에 맞게·은유 도망 X

## 9. 실패작 회피·문서 위생 (항목 32·33·34)

- **실패작 유사성 0** — 참고 실패작 (Demon Lord's Marked Bride 등) 문체·말투·어휘·장면 구조 흡수 X
  - 세계관 명사만 바꾼 같은 대사 X
  - 자가 grep 점검 (twelve years + wrist-as-brand·tri-colon anaphora·breath stabilization 등)
- **청사진/비주얼락 동기화** = 이름·설정·의상·소품·장소·자막 룰 충돌 X·대본 변경은 양쪽 환류
- **최종 문서 순도** = product note·paywall note·review note·marketing label·obsolete name·workflow metadata 0건

## 10. 최종 판단 (항목 35)

- 모든 수정 = "더 재밌게·더 팔리게·돈 내고라도 다음 화 보게" 방향
- 오류 제거가 *더 안전하지만 덜 팔리게* 만들면 잘못된 방향
- LOCK 가능 판정 = 위 9 카테고리 모두 정합 + 매출 견인 방향 일관

## How to apply

- **매 phase_4 (집필) 진입 시:** 본 메모리 정독·각 EP 작성 중 카테고리별 self-check

- **LOCK 직전:** 카테고리 1·2·9·10 strict 검토 + always-load 1-7번 통합 적용
- **새 작품 phase_0 / phase_1 진입 시:** 본 메모리 + always-load 1-7번 모두 정독
