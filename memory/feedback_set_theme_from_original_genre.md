리메이크 러프 세트를 만들 때 외피(테마·세계)는 **원작 스토리 구조에 맞는 것**으로 입힌다. 사용자가 준 테마 목록(엘프·하이틴·크리스마스·오빠들·애기 등)을 원작마다 두 칸씩 채우는 배분으로 쓰지 않는다. 맞는 외피가 하나뿐이면 억지로 둘 만들지 말고 그렇다고 말한다.

**Why:** 2026-10-06 사용자: *"원작의 장르적 특징과는 전혀 맞지 않게 억지로 입힌 기획 천지인데..."* → *"장르적 특징은 정확히 말하면, 원작 스토리 '구조'와 맞지 않거나, 아예 신경도 안 썼거나"* → *"원작 스토리 구조와 좀 맞을법한 것들로 외피를 입혔어야지. 바꿔서 ㅡㅡ"* → *"Rejected at Moon Academy 이거 하이틴 잘 붙냐? 신부 교환이잖아? 어케 하이틴?"* 첫 지시(2026-10-01)부터 *"안 맞는 걸 억지로 끼워 넣듯이 하지 마라"*였다.
- 억지였던 것:
  - 40B 하이틴 아카데미: 원작은 팩 동맹 신부 교환·새엄마 집안·의식으로 고르는 가디언이다. 학교로 옮기니 집안 정치가 학교에 얹혔다(대강당 생일 파티에서 채찍 50대).
  - 41A 크리스마스: 중세 왕국에 현대 크리스마스를 씌웠다.
  - 39B 현대 재벌가: 드래곤 왕궁 원작을 현대로 옮겼다.
- 판정 실수(나중에 정정): 처음엔 '톤·제목 훅'으로 재서 40A 엘프(요정족 짝 = 「가시와 장미의 궁정」류 판타지 로맨스의 원래 장치), 39A 엘프(불사라 아기를 안 키워 봐서 보모 시험을 다른 종족에게도 연다 = 구조에 맞는 이유), 38B 오빠들(오빠들 팀 → 라이벌 팀으로 넘어감 = 구조에 맞음)까지 억지로 몰았다. 잣대는 구조다.

**How to apply:**
1. 세트 설계 전에 원작마다 구조를 적는다: 주인공 처지 / 관계 축(누가 누구를 오해·배신) / 판(경기·시험·정략결혼 등) / 클라이맥스 장치(불 시험·전광판 폭로 등).
2. 외피 후보를 그 구조에 대 본다. 구조의 장치가 새 외피에서 원래 있는 것처럼 돌아가면 OK(예: 41 불 시험 → 용의 피 왕가 = 장치가 더 자연스러워짐). 구조 위에 얹히기만 하면 버린다.
3. 테마 분포를 고르게 맞추려고 억지 배정하지 않는다.
