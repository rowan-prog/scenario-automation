# 🚨🚨🚨 Conversion Runway 집필 (체질 개선 v3)

## 사용자 명시 (2026-05-17 절대)

> **"현재 구조의 근본 문제는 무료회차를 '파일/단계/게이트상 하나의 완성 블록'으로 다루는 것이다. 그러면 작가가 무의식적으로 EP1-8 안에서 기승전결을 닫는다. Paid vertical에서 EP8은 완결점이 아니라 끊기는 지점이어야 한다."**
>
> **"EP8을 목표로 쓰면 안 되고 EP9 장면을 목표로 써야 한다. EP8은 문 닫는 곳이 아니라, 문이 열리기 직전에 끊기는 곳이다."**
>
> **"지금 시스템은 '좋은 무료블록 완성'을 만들도록 유도한다. 앞으로는 'EP9을 누르게 만드는 EP1-8 절단면'을 만들도록 바꿔야 한다."**

## 핵심 원리

### 1. EP1-10 한 호흡 집필 (EP1-8 분리 X)

- 옛: EP1-8만 집필 → EP9 별도 → 분리·억지 완결
- **새: EP1-10 한 호흡** → EP8 paywall cut → EP9 즉시 보상 → EP10 더 큰 미지급 부채

### 2. EP9 = 집필 출발점

```
EP9에서 뭘 보게 만들 것인지
  ↓
EP8을 어디서 끊을 것인지 (paywall cut)
  ↓
EP01-EP07이 그 행동을 어떻게 압박할 것인지
```

→ **EP9 장면 = 청사진·집필의 진짜 목표.** EP1-8은 그 목표를 향한 압박 설계.

### 3. EP10·12 미지급 부채 (더 큰 훅)

- EP9 = 즉시 보상 (EP8 끊김 회수)
- EP10 = 더 큰 미지급 부채 (다음 결제 동력)
- EP12 = 두 번째 paywall cut

→ **2차 페이월·3차 페이월도 같은 패턴**

## 새 7 단계 (집필 시스템)

> 사용자 명시: "사실 청사진-스크립트 단계에서 필요한 건 이것뿐이다."

### 단계 1 — Hit Function Intake
히트작에서 **기능만** 추출 (표면 복사 X):
- 첫 모욕이 어떻게 박히는가
- 몇 턴 동안 가해자가 깔보는가
- 증거물이 언제 움직이는가
- payoff 직전 어디서 끊는가
- 대사가 얼마나 직접적인가

### 단계 2 — Reward Loop / Antagonist / Proof Ledger (청사진 중심)
```
원초 보상:
메인 가해자 (얼굴 있음):
반복되는 오판 (구체 발화):
증거물 (기능 상징):
소유권/권한 이동:
EP8에서 미완성으로 남길 행동:
EP9에서 즉시 줄 보상:
EP10에서 더 큰 부채:
```

### 단계 3 — EP01-EP10 Conversion Runway 설계
```
EP1-7: 압박과 기대 (5-8턴 모욕·증거 누적·시청자 정보 비대칭)
EP8: paywall cut (행동 직전·발화+행동+결과 시작·미완성 남김)
EP9: 즉시 보상 (EP8 미완성 회수·EP1-7 압박 폭발)
EP10: 더 큰 미지급 부채 (2차 페이월 향한 설계)
```

### 단계 4 — Visual Lock (AIGC 어셋용)
**세계관 설명서 X / 보상 루프가 화면에서 보이게 하는 설계서:**
- 누가 낮아 보이는가
- 누가 자리를 차지했는가
- 어떤 물건이 권한을 증명하는가
- 남주의 스케일이 어떻게 보이는가
- 고수위·열감·소유·위험이 어떤 블로킹으로 보이는가

### 단계 5 — Single-Voice Script Draft (한 호흡)
**한 명의 Writer가 EP1-10을 한 호흡으로:**
- 여러 seed (a_visual·b_voice·c_paywall·d_heat) 조립 X
- 좋은 부분만 합치기 X
- 작가가 한 호흡으로 밀고 가는 힘
- 북미 spoken English = 캐릭터 입에서 같은 체온으로 계속

### 단계 6 — Three-Gate Review (3개로 충분)
1. **Commercial Gate**: 결제 보상 루프 작동 여부 (오판→증거→공개역전·EP8 절단면이 EP9 행동 팔리는가)
2. **Native Spoken English Gate**: 북미 배우가 말할 수 있는 대사인지 (영어 히트작 대사 스타일 정합)
3. **AIGC Visual/Production Gate**: 화면이 크고 선명하게 구현되는지 (거대 VFX·9:16·미감·스케일)

→ 페르소나 9명·매트릭스·듀얼·treasure·hybrid 모두 **부차적**.

### 단계 7 — Rewrite
Three-Gate 결과 따라 재작성. 라운드 5 한계 강제 X.
