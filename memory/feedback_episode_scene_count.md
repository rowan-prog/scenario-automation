scenario-automation 에피소드 집필(phase_4)의 씬 수는 **1~6씬 유동, 7씬은 제한적 허용**. 청사진·피칭덱·트리트먼트에는 씬 수 표기 금지 — 집필 단위 결정 사항이지 기획 단계 결정 사항 아님.

**Why:** 사용자 갱신(2026-05-10): "씬 갯수는 씬의 중요도, 밀도에 따라 다름. AIGC라서 씬은 비트단위. 스크립트의 에피소드당 씬 갯수는 유동적임. 중요도나 밀도, 클리프행어 구성 등에 따라서 씬이 1개일수도 있고 6개일 수도 있다. 원칙적으론 6개가 최대. 7개를 해야하는 경우는 제한적으로만 허용. 단, 이때는 매우 짧고 빠른 비트로 7개가 되어야한다." 이전 룰("기본 2-4 / 최대 6-7")보다 유연하게 갱신.

**How to apply:**
1. 회차 씬 수 = 회차의 중요도·정보 밀도·클리프행어 구성에 따라 1~6씬 자유 결정. 응축이 강한 회차는 1씬도 가능, 분기·전환이 많은 회차는 6씬까지.
2. 7씬은 매우 짧고 빠른 비트일 때만 제한적으로 허용. 1씬당 분량을 평소보다 짧게 절단. 정당한 사유 집필 시 명시.
3. 8씬 이상은 비표준 — 회차 분할 또는 비트 응축 검토.
4. 1씬 = 1 단일 비트 원칙 유지 (도입·진행·반응·전환 한 씬에 안 넣음). AIGC 영상 단위 비트 = 1씬.
5. **청사진·피칭덱·트리트먼트에는 씬 수 표기 금지** — 집필 단계 결정 사항. 기획 문서에 "EP3 = 4씬" 식 표기 X.
6. phase_4 prompt 갱신 완료 — 동일 규칙 등재.
