## ⚡ 광고 카피라이팅 톤 (필수, 2026-05-11 사용자 최종 명시)

**사용자 명시:**
> "로그라인은 강력한 시청자 후킹이 있어야 해. 광고용 카피라이팅처럼. 1줄짜리면 곤란해 2~3줄은 되어야함."

**핵심 룰:**
1. **광고 카피라이팅 톤** — 한 줄마다 시청자 멈춤·관심·클릭 동기 만들기. 평이한 묘사 X.
2. **2-3줄 필수** — 1줄 X. 단 너무 길어도 X (압축 한도 = 3줄).
3. **강력한 후킹** — 첫 줄에서 박탈·충격·반전 한 컷 즉시. 평범 시작 X.
4. **페이드 버티컬 광고 카피 검증 어휘:**
   - 박탈: 빼앗았다 / 도둑맞았다 / 끌려나갔다 / 짐승이라 불렸다 / 살인범으로 몰렸다
   - 반전: 그러나 / 하지만 / 그 순간 / 그날 / 죽으라고 보냈다
   - 운명·후킹: 깨어났다 / 옆에 앉혔다 / 뒤흔든다 / 부른다
5. **줄 단위 후킹 구조:**
   - 1줄: 박탈·시작 충격 (시청자 즉시 멈춤)
   - 2줄: 반전·전환 (호기심 유발)
   - 3줄: 클리프행어·페이월 시그널 (다음 보고 싶게)

## 사용자 워싱 4작품 광고 카피 패턴 (2026-05-11)

**TITAN (3줄, 박탈→반전→상승):**
> 1) 신들은 그를 짐승이라 불렀고, 처형장에 던졌다.
> 2) 하지만 그의 피가 닿자 올림포스의 유물이 깨어났다.
> 3) 이제 짐승은 신들의 힘을 하나씩 빼앗고 제우스의 왕좌를 향해 올라간다.
→ 박탈(처형장)→반전(유물 깨어남)→상승(왕좌 향함). 광고 카피 정합.

**OFFERING (3줄, 박탈→반전→클리프행어):**
> 1) 왕국은 이솔데를 드래곤 로드에게 제물로 바쳤다.
> 2) 그러나 베일은 그녀를 죽이지 않고 모두가 보는 자리에서 자기 옆에 앉힌다.
> 3) 그가 그녀를 신부라 부르려는 순간, 드래곤 무리의 첫 포효가 성채를 뒤흔든다.
→ 박탈(제물)→반전(옆자리)→클리프행어(포효로 끊김). 페이월 시그널 강력.

**HEIR (3줄, 박탈→반전 시그널→클리프행어):**
> 1) 시아버지가 죽은 그날, 남편은 임신한 내연녀의 손을 잡고 리비아를 살인범으로 몰았다.
> 2) 시어머니는 리비아의 결혼반지를 손가락에서 빼앗아 내연녀에게 끼우고, 직원들 앞에서 그녀를 도둑처럼 끌어내라 지시한다.
> 3) 그 순간, 죽은 시아버지의 비밀 유언장이 공개된다. 상속자는 남편이 아니라 리비아였다.
→ 막장 박탈 누적(살인 누명·결혼반지 강탈·도둑 끌어내기)→유언장 반전→상속자 = 리비아. 광고 카피 후킹 강력.

**FACE (2줄, 박탈+발견→반전):**
> 1) 약혼 발표 전날 사고를 당한 레나 스털링은 병원 TV에서 자기 이름으로 이선 크로스 옆에 선 마라를 본다.
> 2) 진짜 레나는 직원으로 자기 약혼식장에 들어가, 브라이덜 룸 마라의 가방에서 가짜 약혼녀 마라 명의의 시술 기록을 찾아낸다.
→ 첫 줄 박탈+발견 동시 (TV로 본 자기 이름 도둑) / 둘째 줄 능동 잠입 + 본명 발견. 2줄 압축.

### 인사이트 (4건 워싱에서 공통 추출)

1. **인물명 직접 사용** — "그녀/그" 대명사 회피. 이솔데·바엘·카엘·리비아·레나 스털링·이선 크로스 같은 작품 인명 직접 사용. 위원이 작품 정보를 즉시 받음.

2. **사건 진행 순서 직선** — 시간 순/인과 순. 도식적 압축 X, 사건 흐름 그대로:
   - TITAN: 짐승 호명 → 처형장 → 피 닿음 → 유물 깨어남 → 권한 강탈 → 왕좌 향함
   - OFFERING: 왕국 제물 바침 → 바엘이 옆에 앉힘 → 신부 부르려는 순간 → 하울링
   - HEIR: 시아버지 사망일 → 살인범 누명 → 결혼반지 강탈 → 유언장 공개
   - FACE: 약혼 발표 전날 사고 → 병원 TV → 약혼식장 잠입 → 클리닉 파일

3. **시각·청각 비주얼 강화** — 약한 동사 X. 구체 비주얼 ○:
   - "드래곤들이 울기 시작한다" (약) → "드래곤 무리의 하울링이 성채를 뒤흔든다" (강)
   - "내 약혼자 옆에 섰다" (약) → "이선 크로스 옆에 선 마라를 본다 (병원 TV)" (강)

4. **의인화·은유·비유 절대 금지** — 사실 그대로:

5. **약한 표현·AI 조어 회피**:

6. **3줄 강제 X** — 2-3줄 가변. 작품 본질에 따라:
