# 남성향 NTR 선 긋기 — 배신은 연료, 점유 화면화는 폭탄 (2026-06-12)

**배경:** TITAN BORN 中 개편본의 배신 연인(칼리스토 — 절정 프롤로그에서 남주를 묶어 신에게 넘김)에 cuckold/NTR 느낌이 시청 동력인지 이탈 리스크인지 사용자 질문.

## 룰

**작동(분노 엔진):** 남주가 약한 순간 여자가 더 강한 자를 택해 넘기는 **신뢰의 배신** = 남성향 표준 점화장치. 보상 3박자 = 그녀가 후회하며 기어 돌아옴 → 차가운 거절 → 그녀의 새 남자 공개 박살 + 그녀 몰락 (페이월 뒤 대형 보상).

**이탈 폭탄(NTR) — 넘으면 안 되는 선 4개:**
1. 그녀와 라이벌의 성적 장면 lingering 금지 — 갈아타기는 권력·지위로만(빌런 옆에 서기·휘장 받기·공개 굴종 장면에서 내려다보기). 침실 0.
2. 남주가 모른 채 사귀는 상태 다화 지속 금지(관객만 아는 cuckold) — 폭로 빠르게·단절 같은 화. 장기 기만(후회남)은 여성향 전용 장치, 남성향 남주에게 쓰면 독. 남주의 굴욕 = 힘의 박탈이지 성적 기만 아님.
3. 라이벌의 성적 조롱 = 폭로 시점 1회만 연료, 반복 = NTR 포르노 레지스터 → 이탈.
4. **복귀 절대 금지** — 다른 남자에게 간 여자 재수용 = 치명타. 배신 연인 = 영구 악역/후회 오브제. 로맨스 가치는 2번 포지션(소유욕 퀘스트기버)에 EP2-4 조기 투입으로 이관.

## 🚨 핵심 판정 기준 = 혐오의 화살 방향 (2026-06-12 사용자 직접 — 가장 중요)

**NTR 실패의 본질 = 관객 혐오가 빌런이 아니라 *주인공*에게 꽂힌다.** 뺏는 남자·배신한 여자에게 분노가 가면 그건 연료(OK). 그런데 주인공이 **"자기 여자의 마음과 순결(chastity)"을 지켜내지 못하면** = 관객은 빌런이 아니라 **주인공을 루저로 보고 혐오** = 즉시 이탈 지점. 북미 남성향에서 이걸 못 지키는 주인공 = 루저 낙인.

**따라서 두 여자를 분리 설계:**
- **버리는 여자(배신 연인·칼리스토型):** 적에게 가도 됨 = 영구 악역/후회 오브제. 그녀의 향방은 주인공 격(格)과 무관(그녀가 떠난 게 그녀 손해). 단 그 장면을 *성적으로 화면화*하면 위 4선 위반.
- **지키는 여자(엔드게임 연인·충성 포지션):** **마음과 순결을 절대 뺏기면 안 되고, 그걸 끝까지 지켜내는 게 주인공의 의무.** 다른 남자에게 정서적·성적으로 넘어가는 비트 0. 위협이 오면 주인공이 *이겨서 지킨다*(빼앗긴 뒤 되찾기조차 위험 — 애초에 안 뺏기는 게 정석). 이 여자 = 독점·소유·서열 판타지의 본체.

**관객이 주인공에게 이입·승리감을 느끼려면 = "내 여자는 내가 지켰다"가 성립해야.** 지켜냄 실패 = 카타르시스가 혐오로 뒤집힘.

**Why:** 서구 남성 오디언스에서 NTR = 장르 불문 최상위 혐오 태그. 만드는 감정이 분노가 아니라 역겨움+무력감이라 복수 동력 전환 불가. 'cuck' = 미국 정치 멸칭 수준의 충전어 → 커뮤니티/마케팅 리스크 추가. + 분노는 행동 가능해야 엔진: 모욕마다 카운트다운 퀘스트와 연결해 진행 도파민으로 즉시 전환(무력한 분노 다화 적체 = 그것대로 이탈).
