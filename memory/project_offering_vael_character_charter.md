**Vael 본질 (v34 진입 사용자 명시 — 2026-05-22):**

- **거칠고 강압적·차갑고 위압적 Dragon Lord**.
- 강압성 = Isolde를 비참하게 누르는 방식 **X**.
- 강압성 = Isolde를 **모욕·무시·낮은 자리에 두려는 자들을 절대 용납하지 않는 방식**으로 드러남.

**Isolde에게만 지극 (행동으로):**
- 최고의 방·옷·음식·보호·대우.
- Isolde를 함부로 대하는 자 = **즉시 엄벌**.
- Isolde를 고통스럽게 한 **Veine 왕국조차 압박·멸망시킬 수 있을 정도로 위험한 남자**.
- 사랑은 **부드러운 말보다 행동으로**.
- 말투 = **짧고 차갑고 거칠게**.

**여자 라이벌 (Sera 등) 통제:**
- Vael을 좋아하는 다른 여자들 (특히 Sera)이 **질투심 때문에 Isolde의 심기를 거스르는 것**도 절대 용납 X.
- Sera·여자 라이벌 = Vael이 직접 박살 (Isolde가 부탁 안 해도).

**압도적 권력 + 무력:**
- **Dragon shadow** (벽·바닥에 드래곤 그림자가 깜박임)
- **강력한 dragon presence** (방 공기가 무거워짐·다른 사람들 숨을 못 쉼)
- **말 한마디로 사람들을 강제로 무릎 꿇게 만드는 언령 같은 힘** (`"Down."` → 모두 무릎)
- **hall 전체를 침묵시키는 위압감**
- 정치적으로도 강함·육체적으로도 압도적·**침실에서도 Isolde를 본능적으로 끌어당기는 남자**

**Vael의 사랑 표현 = 행동 (말 X):**

- Isolde에게는 부드러운 말 거의 안 함.
- 대신 행동:
  - 가장 좋은 방을 Isolde에게 줌
  - 가장 좋은 옷·음식 Isolde에게만
  - Isolde 모욕한 자 = 즉시 손/혀/눈/지위 박살
  - Isolde 다친 비트 = Vael 손이 떨림·턱이 굳음·눈이 한 번 검게 깊어짐
  - 다른 사람이 Isolde를 만지려고 하면 = Dragon presence 폭발
  - Isolde 자는 동안 = Vael 깨어 의자에 앉아 지킴
  - Isolde가 위험할 뻔 = Vael 그 자리에서 사람 죽임 (Isolde가 알기 전에)

**말투 룰:**
- 1-5 단어 default.
- 명령·선언·소유.
- 형용사·시적 표현 0.
- 부드러운 칭찬 0. 사랑 고백 0 (EP46까지).
- 그러나 Isolde 위에서는 = "Mine." / "Yours." / "Stay." / "Eat." / "Sleep." 같은 짧은 소유어.

**Why:**
> v33.5 Vael 일부 비트가 너무 부드럽거나 설명조로 흐른 부분 있었음. v34 Vael = **dragon lord 본능 + Isolde에게만 짐승**. 다른 모든 사람에게는 차갑고 잔혹. Isolde에게도 말은 차갑지만 행동은 지극. 이 **격차가 여성 시청자 wish-fulfillment의 핵심**. 다른 모든 사람보다 자기를 특별 대접하는 위험한 남자 = paid vertical 매출 엔진.

**How to apply (매 EP 작성 시 점검):**

1. Vael 발화 = **1-5 단어 default**·짧고 차갑게.
2. Vael 사랑 표현 = **행동만**, 부드러운 말 X.
3. Isolde 모욕·무시·낮춤 시도 발생 = Vael **즉시 박살** (말 1-2 줄 + 행동).
4. Dragon shadow·dragon presence·언령·hall 침묵 위압감 = **매 3-5 EP마다 1번 이상 폭발** 비트.
5. 다른 여자 (Sera 등) Isolde 거스름 = Vael 직접 차단 (Isolde 부탁 X).
6. Veine 왕국·다른 왕국이 Isolde 위협 = Vael **압박·멸망 가능 위협** 비트.
7. 침실에서 = Vael 본능적 끌어당김 (Isolde가 부정하면서도 무너지는 트리거).
8. Vael 부드러운 칭찬·사랑 고백 = EP46까지 **금지**. EP46 첫 "I love you" (Isolde 출산 직전).

**금지 톤:**
- 부드러운 칭찬·시적 사랑 발화 (EP46 전까지)
- 설명형 긴 발화
- 시적 은유·유려한 묘사
- Isolde 앞에서 약한 모습 (Isolde 다친 비트 정도만 — 약함 X·분노로)
