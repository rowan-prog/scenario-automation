# 🥈 LOCKED OUT — 중박 이상 성공작 (남성향 baseline)

## 성공 패턴 (남성향 baseline)

### 1. 남성향 즉시 충족 (메모리 `feedback_male_target_master.md` 정합)
- 주인공 약함 시간 < 2화
- 첫 각성·첫 무쌍·첫 히로인 비주얼 EP1-2 즉시
- 패배 누적 X / **승리 확장 O**

### 2. 권한·소유·지배·통제 이전 축
- 시스템 락 (Entry Code Chip / Commander Authority / Core Unlock Sequence) 점진 강탈
- "I AM X" / "I Rule X" 1인칭 정복 선언
- 작품 = 권한·통제권 점진 확장 압력축 1개

### 3. 4 씬 / 회차 + 4 블록 포맷
- EP당 4 씬 표준 (밀도)
- [Visual] / [Camera] / [Dialogue] / [FX] 4 블록 (단 FX = 메모리 v2 룰에 따라 폐기·EP 양식 v2 정합)
- 짧은 단언형 대사

### 4. 하렘 확장 = 같은 권력축 안 (메모리 `feedback_compressed_setting_paid_vertical.md` 정합)
- 새 매력 여성 = 별도 사건 X
- 같은 권력축 안에서 "누가 주인공의 힘을 인정하고·누구의 편이 바뀌는가"로 붙음
- 산만 X / 압력축 강화

### 5. Stylized Line 5 조건 충족 사례
- EP58 "Shivering in the ash, aching to be claimed." (사용자 컨펌)
- 5 조건 모두 충족 (`feedback_stylized_line_allowed_conditions.md`)
- 정체성 punchline 1-2/50 한도 내

## Demon Lord 실패 vs LOCKED OUT 성공 대비

| 항목 | Demon Lord (실패) | LOCKED OUT (성공) |
|---|---|---|
| 타깃 | 여성향 | 남성향 |
| 대사 | 시적·연극톤 (자아실현) | 짧은 단언형 |
| 여주/주인공 | 처음부터 완성형 | 약함 시간 < 2화 → 즉시 충족 |
| 빌런 | 추상 (집단·국가) | 시스템 락·구체 인물 |
| 압력축 | 분산 (드래곤·왕국·핏줄) | 1개 (권한 강탈 확장) |
| 보상 | 절제·유예 (시네마틱) | 즉시 충족 + 확장 |
| AI 작법 | 시네마틱 영화 (90분) | paid vertical 50화 정합 |

→ **다른 장르·타깃이지만 paid vertical 핵심 룰은 동일.** LOCKED OUT = 룰 정합 / Demon Lord = 룰 위반.
