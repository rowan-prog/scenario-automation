4. **여성 캐릭터 = 인정 보상 + 기능 보상** (예쁜 보상 X) — 진영·능력·자원·정보·전투 기능·감정

#### 7-10. 이식 시 버려야 할 4가지

1. 로맨스 cliffhanger로 결제 — 중심 결제 엔진 X
2. 여캐 많이 = 남성향 — 기능·인정 없으면 싸 보임
3. 우주·SF·액션 자체 = 남성향 결제 — 성장·보상·증명 루프 없으면 X
4. 설정 크기 = 유료성 — 1화 핵심은 "내가 뭘 얻었고 다음에 뭘 얻을 수 있는가"

#### 7-11. 자가 검증 (작품 기획 시 필수)
