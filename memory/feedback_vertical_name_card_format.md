인물 첫 등장 시 화면 자막(네임카드) 양식. 사용자 지시(2026-06-13) + 실제 히트작 자막 예시: "Jeremy Whitmore / Bears Captain", "Naomi Sinclair / Bears Manager".

**양식: 풀네임 / 짧은 직함·관계(1-2단어).** chyron처럼 한 눈에 읽히게 짧게.
- 주인공 = 이름만으로 충분(직함 잉여면 생략).
- 잉여 정보 금지: 주인공에 "bride-to-be" 같은 기계적 설명 = 쓰레기.
- 서술형 역할 금지: "the investigator who knows the truth" 같은 문장형 역할 = 드라마 화면자막에 병신짓.
- 핸드오프의 드라마틱 on-screen title("MARA / THE FACE THIEF")은 내부 제작메모용이지 화면 네임카드가 아님.
- 본문 영어 100% 룰 → 네임카드도 영어.

**예(SHE STOLE MY FACE v54):** `[NAME] Lena Sterling`(이름만) · `[NAME] Mara Voss / Lena's Friend` · Ethan Cross / Lena's Fiancé · Noah Keene / Investigator · 첫 등장 1회만.

**Why:** 화면 자막은 한 눈에 읽히는 직함이지 인물 소개 에세이가 아님. 내가 처음에 "Mara Voss · Lena's best friend of twenty years", "Noah / who knows the truth"로 과설계 → 사용자 강한 교정("기계적이잖아", "드라마 화면자막에 개병신인가").
