2026-06-23 사용자: "왜 다크를 자꾸 쳐붙여? 다크는 피폐·폭력·잔인함 속의 로맨스, 둘 관계가 가학적 사랑이다."

**구분:**
- **다크 로맨스** = *커플의 사랑 자체가* 가학적·피폐·폭력적. 남주가 여주에게 **위험한 존재**(OFFERING 베일 = 여주를 옥죄는 포식자). 어둠이 *둘 사이*에 있음.
- **젠틀 비스트/몬스터 로맨스(hurt/comfort)** = 야수가 **안전지대**(만지기 전 묻고 안 뺏음). 피폐·잔인·학대는 *빌런이 여주에게 가하는 것* → 어둠이 *바깥*에 있고, 둘 관계는 **상처→치유.**

09 〈야수왕의 상처입은 신부〉 = 후자. 펜리르=안전지대, 학대=칼더/미렌/궁정 몫. **따라서 "다크 로맨스" 라벨 금지** — 붙이면 야수를 *여주에게 위험한 남자*로 오해시켜 "괴물=유일한 안전지대" 엔진과 충돌. 라벨 = 몬스터 로맨스·미녀와야수 역전·젠틀 비스트·hurt/comfort(고수위이되 가학 X).

**주의:** 70/30 관계중심 *구조* 룰([[dark-romance-relationship-centered-v2-3]])은 *다크 전용이 아니라* 몬스터 로맨스에도 적용 — 구조는 유지하되 톤을 "다크"로 부르지 마라. **How to apply:** 작품 톤 판정 시 "어둠이 둘 사이냐(다크) / 바깥이냐(hurt-comfort)"를 먼저 물어라.
