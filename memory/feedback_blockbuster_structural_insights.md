## 룰 1. 1화 감정 채무 다층 적재 (비트 3배 밀도)

**관찰:** 한국 대박작 1화 = **18-19 비트** 압축 (수갑·위임장·강지윤 모욕·항변·위임장 찢기·관계 폭력·양육비 착복 폭로 / 회상 몽타주 도혁의 죄책감·서연 오열 / 인지 충격·절규·강제 지장·고독사 거짓말 / 자살 위장·NA 회한 / 회귀·거울).

**일반 숏폼 1화 = 5-7 비트.** 대박작 = 약 3배 밀도.

**룰:** 1화는 **단일 사건 X / 다층 비트 적재.** 시청자가 "왜 돌아와야 하는가 / 왜 이 인물에게 붙어야 하는가"를 1화 안에 모두 납득하도록 비트 단계별 배치:

- 비트 A (현재 박탈): 인물의 현재 처지 — 박해·위협·부당
- 비트 B (과거 폭로): 누적된 박탈 / 거짓말 폭로
- 비트 C (자기 죄책감): 인물 자신의 후회·미안함 (모성·관계 채무)
- 비트 D (인지 충격): 진실 깨달음 / 거짓말 직시
- 비트 E (최종 절단): 죽음·이별·사회적 단절
- 비트 F (재시작): 회귀·각성·반전 트리거

각 비트당 1-3 sub-비트. 총 15-20 비트 = 1화.

**적용:** phase_1·phase_3 EP1 트리트먼트 검수 시 비트 카운트. 7비트 미만이면 보강 검토.

**금지:** "EP1에 첫 사건 1개"라는 단순 룰을 기계적 적용 X. 단일 사건만 있으면 감정 채무 부족.

## 룰 2. 페이월 3중 구조 (사회적 판정장 + 시간 압박 + 동시 다발)

**관찰:** 한국 대박작 7화 페이월 = 3 요소 동시 도착:
- **A. 사회적 판정장:** 은행 로비 (공개 공간 + 다수 증인)
- **B. 시간 압박:** 시계 째깍 ("3분 남았네" → "2분" → "1분" → "정각" → "땡! 시간 다 됐습니다")
- **C. 동시 다발:** 강지윤이 서연을 끌고 가려는 순간 + 모든 TV 동시 붉은 속보 + 운미사이언스 상한가 + 모든 사람이 "샀어야지!" 외침

**한 비트 안에 3 요소 동시 도착.** 단순 "사회적 판결 직전 절단"보다 한 단계 정교.

**룰:** 페이월 비트 설계 시 3 요소 모두 적재 권장:

- **A 사회적 판정장:** 공개 공간 + 증인 다수 (대연회장·식탁·약혼식·통제실·이사회 등)
- **B 시간 압박:** 명시적 카운트다운 (시계·발화·물리적 진행) — 정적 비트 X
- **C 동시 다발:** 결정적 사건 2-3개가 한 컷에 동시 도착

**작품별 점검 결과 (7작품):**
- ★ 모두 정합: 02 OFFERING (대연회장+깃발 소각+드래곤 울음+사절단 무릎+끊긴 단어), 04 HEIR (식탁+의결권+저택권+회중시계+직원이 리비아 지시 기다림), 05 LAST KEY (의식실+봉인선+신의 손+잠긴 문+말라키 손목 잡음), 06 SHE STOLE (약혼식+무대 발화+클리닉 파일)
- △ 부분: 01 TITAN BORN (시간 압박 부재), 03 EMPIRE (시간 압박 부재), 07 EVERY MONDAY (시간 압박 부재 — 8:07 반복으로 보완 가능)

**디벨롭 가능 영역:** 01·03·07 페이월 비트에 시간 압박 요소 추가 검토 (작품 본질 보존 한정).

## 룰 3. 이중 구원자 기능 분리 (가족극·하이브리드 작품 한정)

**관찰:** 한국 대박작은 도혁(전략가) + 차현준(집행자) 기능 분리. 명품관 시퀀스 = 도혁 항의 → 차현준 권력 행사 (VVIP 카드 → 부사장 → 매니저 해고) → 도혁 화룡점정 (방향제 칙칙). 한 비트씩 교차.

**룰:** 가족극·하이브리드 작품에서 두 주인공 기능 분리 권장:
- **전략가:** 판 짜기·미래 지식·작전 설계
- **집행자:** 권력 행사·공개 보호·계급 집행

분리 기능 = 단일 주인공이 모든 걸 다 하는 것보다 시청자 어필 폭 ↑ (남성 시청자=전략가 / 여성 시청자=집행자 보호 둘 다 어필).

**작품별 점검:**
- ★ 정합: 04 HEIR (리비아+데클런), 06 SHE STOLE (레나+노아)
- △ 부분: 05 LAST KEY (아르디스+말라키 / 말라키 페이월 후 합류), 02 OFFERING (이솔데+바엘 / 바엘 단일 집행자)
- ✗ 단일 주인공: 01 TITAN BORN, 03 EMPIRE, 07 EVERY MONDAY (남성향 무쌍 / 정복 / 루프 — 단일 주인공이 작품 본질이라 적용 X)

**적용 범위:** 가족극·하이브리드 작품만. 남성향 무쌍·먼치킨에는 적용 X (장르 본질).

## 룰 4. 모욕→증명→공개역전 N회 사이클 (보상 카테고리 다양화)

**관찰:** 한국 대박작은 5번의 동일 사이클 반복:
1. **은행** (3-9화): 강지윤 변기 내기 → 주식 상한가 → 무릎 사과
2. **명품관** (11-14화): 매니저 거지 깽깽이 → VVIP 카드 → 매니저 해고
3. **부동산** (20-30화): 한민철 호구산 비웃음 → 자극동 발표 → 한민철 폐허
4. **테라니스** (39-55화): KS 형들 코웃음 → FDA 반려 → 형들 폭망 + 한민철 횡령 발각
5. **친자** (63-65화): 한민철 친아빠 주장 → 유전자 검사 → 한민철 정신 붕괴

**같은 구조 + 매번 다른 보상 카테고리** (금융 / 계급 / 부동산 / 회사 / 혈통).

**룰:** 작품 전 화수 설계 시 모욕-역전 사이클 N회 + 매 사이클 다른 보상 카테고리 권장. 같은 구조 다른 결 = 시청자 익숙함 + 매번 다른 충족.

**작품별 점검:**
- ★ 정합 (5+ 사이클): 01 TITAN BORN (가문 4종 + 제우스), 03 EMPIRE (함대·외계·계급장·황좌·진짜 이름), 05 LAST KEY (가족 도구화·말라키·12세대·테론·전체 봉인), 07 EVERY MONDAY (루프 6+ 사이클)
- △ 부분 (1-2 사이클 / 페이월까지): 02 OFFERING, 04 HEIR, 06 SHE STOLE — 페이월까지는 1 사이클 / 후반 유료 구간에 추가 사이클 등재

**디벨롭 가능 영역:** 02·04·06 후반 유료 구간 사이클 명시 보강 가능 (청사진 단계).

## 룰 5. 회귀·시스템물 능력 위장 (진지 설명 X / 일상 어휘 위장)

**관찰:** 도혁의 미래 지식 노출 = "꿈에서 봤어" / "촉이 좋아요" 어린이 어휘로 위장. 김비서 농담 "너 인생 2회차라도 돼?" → 도혁 멈칫 → 김비서 "농담 그만하고 젤리나" 즉시 무력화. 무당이 정확히 맞힘 → 한민철이 "사기꾼!"으로 거부 (관객만 진실 인지).

**룰:** 회귀·시스템·미래 지식 작품에서 능력 노출 시 다음 룰 적용:
1. **진지 설명 X** — 능력 출처를 진지하게 설명하면 시청자 이탈
2. **일상·어린이 어휘 위장** — "꿈" / "촉" / "감" / "예감"
3. **진실 노출 시 캐릭터가 농담으로 무력화** — 관객만 인지
4. **결과로 증명** — 화면 안 시각적 사실 (앱·TV 속보·서류·검사지)

**시청자 우월감 + 코믹 효과:** 시청자만 진실 알기 = 다른 캐릭터 위 정보 비대칭에서 오는 만족감.

**작품별 점검:**
- ★ 적용: 06 SHE STOLE (레나 정체 위장 — 직원 출입증), 07 EVERY MONDAY (칼만 기억 / 다른 사람들은 모름)
- △ 부분: 02 OFFERING (어머니 인장 시청자만 봄), 05 LAST KEY (아르디스 진실 점진적 인지)
- ✗ 위장 불필요: 01 TITAN BORN, 03 EMPIRE, 04 HEIR (능력 자체가 즉시 시각화 / 회귀·미래 지식 X)

## 룰 6. 광고 컷 다층 추출 (한 작품 N개 광고 후보)

**관찰:** 한국 대박작 = 5개 광고 컷 후보 추출 가능:
- 1화: 교도소 강제 지장 + 자살 위장 (감정 채무)
- 7화: 강지윤 변기 약속 + TV 속보 + 패닉 얼굴 (페이월)
- 9화: 변기 약속 녹음 재생 + "다시 제대로 사과 하시죠" (사이다)
- 12-14화: 매니저 해고 + 도혁 방향제 (계급 역전)
- 65화: 유전자 검사지 클로즈업 + "내가 10년 동안 남의 자식 키운 거냐" (혈통 반전)

**5개 광고 컷 = 5가지 다른 보상 카테고리.** 한 작품에서 광고 소재 다층 추출 = 롱테일 광고 효율의 핵심.

**룰:** 청사진 단계에서 작품의 광고 컷 후보를 EP별로 명시 + 카테고리 다양화 검수:
- EP1 후보: 감정 채무 비트
- 페이월 후보: 사회적 판정 + 결정적 컷
- 사이다 회수 후보: 모욕 도구를 그대로 되돌려주는 비트
- 권력 역전 후보: 계급·자리·서류 이전 시각 표지
- 반전 후보: 진실 폭로 (혈통·배신·정체)

**최소 5개 광고 컷** 후보가 청사진에서 식별 가능해야 함. 미만 시 광고 효율 약화 신호.

**작품별 점검:** 7작품 모두 ★ — 5+ 광고 컷 후보 식별 가능.
