scenario-automation의 시청자 페르소나(08 남성 / 09 여성)는 단일 시청자 모델이 아니라 **두 sub-persona로 분리**한다 (제너럴 + 니치). 작품 장르·소재에 따라 비중을 조절하고, **두 sub-persona 모두 진단에 참여**하되 비중에 따라 가중치 적용. 한쪽이 전체 판정을 독점하지 않는다.

**또한 시청자 페르소나는 phase_5 스크립트 검토만이 아니라 phase_2 피칭덱 작성/검토 단계에서도 사용한다.**

**Why:**
- 사용자 명시(2026-05-10): "북미 남성 제너럴 타깃을 니치 계로만 판단하거나, 니치 계통을 제너럴 타깃 의견으로만 판단하면 곤란".
- 기존 08은 Crunchyroll·Solo Leveling·이세카이 하렘에 편중되어 있어 모던 마피아·재벌·Alpha CEO 같은 mainstream 남성향 작품 진단 시 잘못된 기준 적용 위험.
- 09는 ACOTAR·Wattpad/AO3 + ReelShort 70% 여성으로 비교적 균형이지만 sub-persona 분리·비중 룰 명시 약함.
- 위원 자료 추론(조심스럽게): B 위원의 "평균 시청자 번역 가능성"은 제너럴 시청자 모델, D 위원의 "타깃 장르 문법"은 니치+제너럴 비중. 단, 위원 사고를 시청자 페르소나에 강제 이식하면 시청자 페르소나가 분석적이 되어 본래 역할(즉각 반응) 상실 — 분리 정당성까지만 차용.
- 피칭덱이 위원 4표를 받아도 시청자가 받지 않으면 매출 안 남. 시청자 시점에서 피칭 본문(로그라인·인물 소개·줄거리·트리트먼트) 진단 단계가 별도로 필요.

**How to apply:**

1. **남성향 작품 = 08만 활성 / 여성향 작품 = 09만 활성** (기존 룰 유지). 잘못된 시청자 페르소나 활성화는 잡음 + 타깃 상실.

2. **Sub-persona 비중 룰 (작품 장르·소재 기반):**

| 작품 카테고리 | 제너럴 (A) | 니치 (B) |
|---|---|---|
| **08 남성향:** 신화·SF·이세카이·하렘·먼치킨·시스템물 | 30% | 70% |
| **08 남성향:** 모던 마피아·재벌·Alpha CEO·복수극·범죄·도시 액션 | 70% | 30% |
| **08 남성향:** 혼합·중간 | 50% | 50% |
| **09 여성향:** 다크 로맨타지·드래곤·shifter·monster·고딕·코스믹 호러 | 30% | 70% |
| **09 여성향:** 재벌가 복수극·후회남·외도 남편·계급 역전·일상 후회남 | 70% | 30% |
| **09 여성향:** 혼합·중간 | 50% | 50% |

3. **두 단계 사용:**
   - **phase_2 피칭덱 작성/검토:** 로그라인·인물 소개·줄거리·트리트먼트만 보고 5항목 진단. 본격 씬·VFX·대사 X.
   - **phase_5 스크립트 검토:** 회차 EP 본문 6+항목 진단 (기존).

4. **이탈 코드 신규 (각 1건 추가):**
   - **M-K (남성):** 제너럴 진입 비용 — niche 어휘·niche 설정 의존도 너무 높음. 현실 매개체(돈·여자·자리) 없음. 주로 08-A 이탈.
   - **F-M (여성):** 제너럴 진입 비용 — 다크 로맨타지·드래곤·shifter·코스믹 어휘 의존도 너무 높음. 현실 매개체(가족·결혼·재산·회사) 없음. 주로 09-A 이탈.

5. **위원 사고와 시청자 페르소나 분리 유지:** 위원은 시청자를 추측, 시청자는 직접 반응. 시청자 페르소나가 위원처럼 분석적이면 본래 역할 상실. 진단 표현은 "내 몸이 끌렸는가 / 끊겼는가"로 유지. 위원 사고에서 가져온 것은 "제너럴 vs 니치 분리의 정당성"까지.

6. **두 sub-persona가 서로의 진단을 부정하지 않음** — 한쪽 시점이 다른 쪽 시점을 무시하지 않고 종합 가중 평균. 진단 보고서에 두 sub-persona의 판정을 분리해 표기 + 종합(가중) 컬럼 추가.

- 02 THE OFFERING: 09-B 70 / 09-A 30 (드래곤 로맨타지 niche)
