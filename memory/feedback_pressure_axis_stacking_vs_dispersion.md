# 🔥🔥🔥 압력축 중첩 vs 분산 (paid vertical 상위 원칙)

## 핵심 한 줄

> **paid vertical = 많은 일이 아니라, 하나의 일이 더는 버틸 수 없을 만큼 커지는 과정.**

## 사용자 명시 (2026-05-17)

> "문제는 씬 수가 아니라 사건 축 수다."
> "좋은 무료구간은 여러 사건을 벌이는 게 아니라, 하나의 질문을 여러 씬으로 계속 키우는 것이다."

## 3 핵심 룰

### 1. 사건 축 = 1개 (장르 초월)

| 장르 | 핵심 질문 |
|---|---|
| 로맨스 | 둘이 언제 선을 넘나? |
| 복수 | 저 사람이 언제 공개적으로 무너지나? |
| 신분극 | 가짜가 언제 들키고 진짜가 인정받나? |
| 생존극 | 언제 탈출/반격 기회가 생기나? |
| 경쟁물 | 누가 보는 앞에서 실력을 증명하나? |
| 판타지/능력물 | 힘의 주인이 언제 바뀌나? |
| 가족/상속극 | 누가 공식적으로 선택받나? |
| 스릴러 | 숨겨진 위험이 언제 눈앞에 드러나나? |

→ **여러 씬은 그 질문의 압력을 키우는 데 써야 한다.**

### 2. 중첩 O / 분산 X / 반복 약

**중첩 (좋음):**
> 모욕 → 더 공개적인 모욕 → 더 불리한 조건 → 더 많은 증인 → 반격 직전
> = 같은 압력이 더 공개적이고·더 불리하고·더 되돌릴 수 없게 커짐

**분산 (나쁨):**
> 주인공 모욕 → 갑자기 유괴 → 갑자기 출생비밀 → 갑자기 회사 인수전 → 갑자기 살인 누명
> = 시청자 기다림 흩어짐

**반복 (약함):**
> 모욕 → 참교육 → 모욕 → 참교육 → 모욕 → 참교육
> = 쾌감은 있지만 긴장 리셋

→ **단 예외: 클립 보상 루프 (같은 쾌감 다른 상황 재포장)는 OK.** `feedback_clip_reward_loop.md` 참조.

### 3. Paywall = 정보보다 행동 앞이 강하다

**약한 paywall:**
- 진실이 뭘까? / 과거가 뭘까? / 설정이 뭘까?

**강한 paywall:**
- 문이 열린다 / 손이 올라간다 / 이름을 말하려 한다 / 키스 직전 / 폭로 직전 / 선택 직전 / 처벌이 시작되려 한다

→ **결제를 만드는 건 설명이 아니라 다음 행동의 결과.**

## 남성향 전용 인사이트

> 남성향 핵심 축 = **권한·소유·지배·통제의 이전**

- 초반 보상 = 빨라야 하지만 **반복 소비 X** → 첫 승리는 다음 승리의 스케일을 키워야
- 좋은 무료구간 = "주인공이 언제 이기나?" X / **"이 권한이 어디까지 주인공 쪽으로 넘어오나?"** O
- 악역 바로 죽이는 것 X / 악역의 부하·무기·계급·여자·영토·조직·명령권이 주인공 쪽으로 넘어오는 것 O (오래 간다)
- 준하렘·매력 여성 = 별도 사건 X / **같은 권력축 안에서 "누가 주인공의 힘을 인정하고·누구의 편이 바뀌는가"로 붙어야**
- 남성향 paywall = "비밀 공개" X / **첫 명령·첫 장악·첫 처벌·첫 탈취·첫 공개 인정 직전** O

## 작업 단계별 적용 (필수)

### 아이디어 단계
- 핵심 사건축 1개가 있는지 먼저 확인
- 없으면 아이디어 거절

### 피칭덱 단계
- "왜 팔리나"를 이 사건축 1개로 설명
- 사건축 X / "내가 좋은 스토리 썼다" 톤 회피 (`feedback_pitch_reason_show_not_tell.md`)

### 청사진 단계
- EP1-8이 같은 질문을 키우는지 확인
- 4 아크 페이즈 각각이 같은 축 위에서 판돈 (Scale) 키우는지 확인
- 새 축 분산 = 🔴

### 스크립트 단계
- 새 사건 추가 X / 같은 장면의 압력·증인·선택·행동 키우기
- 매 씬 = 압력축 누적 또는 클립 보상 재포장

### 검수 단계 (필수 6 질문)
1. 지금 시청자가 기다리는 질문이 하나로 유지되는가?
2. 이 씬은 그 질문의 압력을 키우는가?
3. 새 사건축을 열고 있지는 않은가?
4. 보상을 너무 빨리 소비해서 긴장을 리셋하지 않는가?
5. paywall이 정보가 아니라 행동 앞에 걸려 있는가?
6. 남성향이면 권한·소유·지배·통제의 이전이 눈에 보이는가?
