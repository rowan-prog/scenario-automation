## 1. 여주 나이 = 23-25 (절대 — 플랫폼·헤비 독자)

❌ **17세 = 절대 금지** (옛 OFFERING v3·v6 설정).
❌ **22세 = 부족 (북미 다크 로맨스 헤비 독자 이탈 한도).**

✅ **23-25세** = 농밀·끈적한 초고수위 텐션 끝까지 push 가능 + 플랫폼 심의 안전 + 다크 로맨스 헤비 독자 배덕감 OK.

**Why:** 17세 여주 = 플랫폼 (TikTok·YouTube Shorts·ReelShort 등) 심의 즉시 차단. 22세 = 다크 로맨스 헤비 독자 (북미 paid vertical 핵심 결제층) "배덕감 선 넘었다" 이탈. 23-25세 = 성숙·농염·죄책감 X.

**How to apply:** 새 작품 phase_3·phase_a_1 단계 여주 나이 입력 시 23-25 default. 17세·18세·19세 입력 시 즉시 정정. 22세도 권장 X. OFFERING = EP12 "She died when you were seven. She did not die of fever." + "I found out five years later. I did nothing for the ten years after that." = 7+5+10 = **22세** → **23세** 정정 (7+6+10 또는 8+5+10).

## 2. 표지·텐션 시각화 다양화·강화 (절대)

❌ **반복 폐기:**
- 어깨끈 끊기 (strap snapping)
- 셔츠 깃 잡아당기기 (shirt collar pull)
- 목 자국 (crescent mark) 반복
- "Doesn't ask" 수준 묘사
- Fade-to-black / 아침 짹 수준

→ 초고수위 다크 로맨스 X / "건전한 PG-13."

✅ **노골적 통제욕 (Possessiveness) 묘사:**
- **외부 시선 발생 → 즉시 폭발**: 아버지·옛 약혼자·다른 남자가 여주를 쳐다보았다 → 남주 이성 잃고 그녀를 밀어붙임.
- **용의 완력·그림자**: 여주 반항·도망 시도 → 남주가 완력·그림자로 옭아맴.
- **여주 무너짐 묘사 (감각 3축)**: 촉각 (skin 압박·scales 거칠음·체온 차이) + 거친 숨소리 (panting·gasping·breath catching) + 붉어진 피부 (flushing·red marks·sweat sheen).
- **여주 탐닉**: "She hates that she wants it" / "Her body answers before she does" / 그가 강제 자세 잡고 그녀 거부하다 무너짐.

**Why:** 옛 v11 = "He bites her crescent" / "He pulls the strap" / "He kisses her" 반복 = paid vertical 시청자 (헤비 다크 로맨스 독자) "다 봤다 / 다음 화 안 본다." 초고수위 다크 로맨스 = 매 EP **새로운 통제·새로운 무너짐**.

**How to apply:** 모든 다크 로맨스 EP 진입 시 본 EP 새 통제 비트가 옛 EP와 다른가? 자가 검수. 같으면 다시 작성. 매 EP 감각 3축 (촉각·숨소리·피부) 최소 1회 명시.

## 3. 임신 = Breeding/Overprotective 트롭 (절대 — 다정 아빠 X)

❌ **다정 아빠 금지:**
- 여주 배에 귀 대고 "딸일까 아들일까"
- 손 잡고 산통 견딤
- 다정한 husbandly cadence
- 가족애 (family love) 톤

→ 옛 v11 EP44-50 = 다 다정 아빠 톤. 다크 로맨스 남주 매력 X.

✅ **Breeding (번식·각인) + Overprotective (병적 과보호):**
- **광기 어린 집착**: 임신 = 그녀를 더 자기 것으로 만든 사건. 그녀의 몸·세계가 자기 아이로 봉인됨.
- **공유 질투**: "내 여자의 몸을 아이와 공유하는 것조차 질투" 비트. 임신 = 그녀가 더는 자기만의 것이 아니지만, 동시에 그녀가 그의 아이를 품음으로 영원히 자기 것 = 광기 충돌.
- **출산 비트 = 통제 상실**: 산파들 옆에 있는 것 자체에 분노 / "내 여자가 다른 사람 손에" → 흑염·용 본성 통제 X / 그녀가 고통스러워하면 남주가 산파 죽이겠다 / 그가 광기로 자기 손이 부서지도록 stone 부순다.
- **임신 후 더 강한 소유 표지**: 그녀의 배에 자기 표지·자기 손 자국·자기 sigil = 가족애 X / 광기 표지.

**Why:** 다크 로맨스 paid vertical에서 임신 = 가장 큰 페이월 트리거. **광기 보존**이 결제 동력. 다정 아빠로 톤 바뀌면 = 시청자 "이 작품 끝났다." 후반 ARPPU 박살.

**How to apply:** 임신 build (EP26+) 시작 시 남주 voice·행동이 EP1-25와 다른 톤 X 자가 검수. 동일 짙은 알파·동일 광기 톤 유지. 다정 아빠 비트 0건. 출산 EP는 극단적 텐션 (남주 광기·산파 죽이겠다·흑염 통제 X) 필수.

## 4. 후반부 정치 씬 완전 소거 (절대)

❌ **EP30-40 외부 서사 폐기:**
- Dragon 영주들 무릎
- 남부 가문 편지
- 외교 합의
- 봉토 결정
- 동맹 결성
- council·assembly·dais·crown

→ 옛 v11 EP44-50 = council·water rights·iron mines·assembly·far-east ships·neutral seat = v3 진단으로 일부 정정했으나 v2.4 = 모두 완전 소거.

✅ **카메라·서사 포커스 = 둘만 갇힌 사적 공간:**
- **침실** (둘만의 잠자리·아침·밤)
- **욕실** (그녀가 목욕할 때 그가 옆·통제 비트)
- **밀실** (남주의 사적 공간·다른 이 들어올 수 없는)
- **사적 정원·테라스** (외부 시선 차단된 둘만의 공간)

**Why:** 다크 로맨스 후반 paid pull = **그녀를 다른 이의 시선으로부터 완벽히 차단·소유**. 정치 처리는 한 줄 대사로 끝남 ("Aldric handles it." / "Kiran took care of it." / "The houses signed it yesterday."). 후반 러닝타임 100% = 둘만의 사적 공간 + 임신 build + 출산 + 광기 보호.

**How to apply:** EP30+ 본문에 council·assembly·dais·외부 영주·외부 가문·외부 편지 등장 시 = 즉시 정정. 정치는 1 줄 대사로 처리. 둘만의 침실·욕실·밀실 비중 ≥ 80% 강제.

## 5. 자가 검수 4 질문 (다크 로맨스 모든 EP)

1. **여주 나이 23-25인가?** (16-19·22 = 즉시 fail)
2. **이 EP 표지·텐션이 이전 EP와 다른 통제·다른 무너짐인가?** (반복 = fail)
3. **임신 EP (EP26+)인 경우 다정 아빠 비트 0건·광기 보존인가?** (다정 톤 = fail)
4. **EP30+인 경우 정치·외부 처리 ≤ 1 줄 대사·사적 공간 ≥ 80%인가?** (정치 큰 비중 = fail)

→ 1개라도 NO = 다크 로맨스 실패. 즉시 정정.
