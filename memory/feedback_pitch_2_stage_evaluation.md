# 피칭덱 2단계 평가 룰

## 핵심 (사용자 명시 2026-05-15)

> **피칭덱 평가 기준 1: "잘팔릴 것 같은가?"**
> 피칭덱만 보고도 잘 팔릴 것 같으면 1차 통과.
>
> **2차: 위원 가상투표 엄격 판단 시 4표 이상 확보 가능한가?**
> 1차 통과해도 위원 4표 미확보 = 불완전 피칭덱. 보강 필요.
>
> **레퍼런스작 필수.** 피칭덱 내에 반드시 레퍼런스작 포함.

## 평가 흐름

```
피칭덱 작성 완료
  ↓
[1차 평가] "잘팔릴 것 같은가?"
  ├─ Yes → 2차 진행
  └─ No → 보강 또는 완전히 새로운 아이템으로 다시 작성
        (불완전 피칭덱 — 절대 통과 X)
  ↓
[2차 평가] 위원 7인 가상투표 (엄격)
  ├─ 4표+ → 통과
  └─ <4표 → 보강 또는 재작성 (불완전 피칭덱)
  ↓
[3차] 문체·문장 다듬기 (필수)
  ↓
완성 피칭덱
```

## 1차 평가 — "잘팔릴 것 같은가?"

### 자가 검수 (위원 시점 가상)

피칭덱만 처음 본 외부 위원이 다음 인지를 빠르게 한다 가정:

1. **첫 컷·첫 장면이 욕망 게임을 시작하는가?** (광고 컷 후보 즉시 식별 가능?)
2. **로그라인이 누가 무엇을 빼앗기고 어떻게 뒤집는지 1-3문장에 직접 들어 있는가?**
3. **트리트먼트가 화면이 그려지는가?** (한 동작 = 한 그림 / 5단 구조 작동)
4. **레퍼런스작이 글로벌 paid vertical 시장 검증 작품인가?** (라이브러리 매핑)
5. **무료 구간 한도 = 첫 증거만, 가장 큰 보상은 유료** 인가?
6. **인물 매력이 행동으로 보이는가?** (분석 라벨 X)
7. **금지 표현·관념어·자체 조어 0건인가?**

### 통과 기준
- 7개 중 6+ Yes → 1차 통과 → 2차 진행
- 4-5 Yes → 보강 후 재평가
- <4 Yes → **완전히 새 아이템으로 재작성** (보강만으로 안 됨)

### 통과 안 됨 → 폐기 후보
- 카테고리 본질이 niche
- 위원 거절 원인이 구조적 (메모리 `feedback_pitch_pass_fail_judgment.md`)
- 디벨롭 후에도 차별성 안 보임

## 2차 평가 — 위원 가상투표 4표+ (엄격)

### 위원 7인 + 가중치 (메모리 `feedback_hook_density_vs_qa_weighting.md` 매력 70% / 트로프 15% / 결제 10% / QA 5%)

| 위원 | 성향 |
|---|---|
| A | 매력·후킹·hook 다발 |
| **B (vertical 작가 출신 마케팅 리더)** | 글 자체 품질·페이월 압력·캐릭터 욕망·트리트먼트 직관성 |
| C | 카테고리 열감·시각 매력 |
| D | 타깃 장르 문법·직관성 |
| E | 포맷 실행성·AIGC 시너지 |
| F | 시장성·결제 동력 |
| G | 시청자 페르소나 (작품 타깃 정렬 — 남성향 08 / 여성향 09) |

### 엄격 가상투표 — 채점 룰

각 위원 시점에서 **메모리 `feedback_evaluator_master.md` + `feedback_committee_response_patterns.md`** 기반으로:

1. 그 위원의 거절 트리거가 작동하는가?
2. 그 위원의 강하게 받는 작품 유형과 매치되는가?
3. 그 위원의 표면 발화 vs 실제 보는 것 — 실제 보는 것 기준으로 채점

### 4표 기준
- **4표+ 통과 가능 = 1차 통과 (2차 정식 통과)**
- **3표 이하 = 보강 또는 재작성**

### 위원 B 가중치 (2026-05-15 갱신)
- B는 vertical drama 작가 출신 + 마케팅 리더. **좋은 글·팔리는 글에 이해도 깊음** (메모리 `evaluators.md` 3-0 참조).
- B의 통과/거절 신호는 다른 위원보다 무게 두기.
- B가 통과한 피칭덱 = 시장성 신호 강함.

## 3차 — 문체·문장 다듬기 (필수)

1차·2차 통과해도 피칭덱 문장에 다듬을 부분 있을 수 있음. 핵심 점검:

- 한국어 언어습관에 맞는가?
- 과도한 개념어·관념어·자체 조어 없는가?
- 동사가 관계·행동 보이는 동사 위주인가?
- 인물 소개·트리트먼트가 분석체 X / 한 단락 줄글인가?
- 레퍼런스작이 작품명 + 정량 + 매핑 키워드 형식인가?

상세: 메모리 `feedback_pitch_style_master_v2.md`.

## 레퍼런스작 필수 (사용자 명시)

### 룰
- **피칭덱 내 레퍼런스작 반드시 포함.**
- 작품명 + 정량 (조회수·랭킹·기간) + 매핑 키워드 형식.
- 타깃 플랫폼 한정 (ReelShort/DramaBox/NetShort/Flickreels/ShortMax).
- 레거시 드라마 인용 X (글로벌 paid vertical 시청자에게 무의미).
- **히트작 라이브러리 `config/hit_library/vertical_hit_library_2026-05-15.xlsx` 적극 활용** — 288작 + 76 후보 + 81 ranked tropes.

### 권장 인용 수
- 메인 레퍼런스: 2-4편 (작품 핵심 엔진·소재·타깃 매핑)
- 보조 레퍼런스: 1-3편 (특정 비트·페이월·캐릭터 매핑)

### 좋은 인용
> "북미 대히트작 게임 '갓 오브 워' 등이 자연스럽게 떠오르도록 유도하는 IP."
