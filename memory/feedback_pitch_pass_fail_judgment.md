# 피칭 탈락작 폐기 vs 디벨롭 판단 기준

## 핵심 룰

> **카테고리 본질이 검증 영역 + 위원 인지 한계가 거절 원인 = 디벨롭 가능**
> **카테고리 본질이 약점 영역 (AI 부적합·트렌드 지남) + 디벨롭 후 다른 작품과 중복 = 폐기 적합**

## 판단 매트릭스

| 항목 | 디벨롭 | 폐기 |
|---|---|---|
| **카테고리 본질** | 검증 영역 (글로벌 IP·NetShort/GoodShort 검증 트로프·시장 트렌드) | AI 약점 영역 / 트렌드 지남 / 시장 부적합 |
| **위원 거절 원인** | 피칭덱 작성 부족·위원 인지 한계 (작품 본질은 OK) | 작품 본질 약점 (AI vs 실사·소재 트렌드 X) |
| **디벨롭 후 차별성** | 다른 작품과 명확히 차별 (새 카테고리·새 트로프) | 다른 통과작과 중복 (예: AI 강점 추가 시 기존 작품과 겹침) |
| **위원 평가 분포** | 거절도 있지만 일부 통과 (3-4표) | 만장일치 부정 (0-1표) |
| **시간 비용** | 디벨롭 ROI 명확 (작품 본질 강함) | 디벨롭 = 사실상 새 작품 작성 |

## 사례 1: MY MAP (디벨롭 결정)

### 분석

| 항목 | 평가 |
|---|---|
| **카테고리 본질** | ✅ 메인 남성향 검증 카테고리 (Solo Leveling 톤 + NetShort 14편 트로프 매핑) |
| **위원 거절 원인** | △ **피칭덱 메인 남성향 교육 부재 + 위원 인지 한계** (작품 본질 X) |
| **디벨롭 후 차별성** | ✅ Village Fool God Mode + System + Hidden Exclusive Access = 명확 |
| **위원 평가 분포** | ❌ 0/7 만장일치 거절 |
| **시간 비용** | ✅ 디벨롭 = 본질 유지 + 피칭덱 보강 (제목·로그라인 변경 가능) |

→ **카테고리 본질 OK + 피칭덱 부재가 핵심** → **디벨롭 결정** (사용자 명시)

### 디벨롭 방향
1. **제목 변경 가능** (사용자 명시) — 메인 남성향 정체성 명확히
2. **피칭덱 "메인 남성향 교육 섹션" 추가** (`feedback_pitch_male_target_education.md`)
3. **Solo Leveling·NetShort 14편 검증작 매핑 명시**
4. **세부 메커니즘 단순화** (배달앱·헌터 회사 = 보상 구조 직접)
5. **소재·작품 본질 유지** (Village Fool God Mode + System + Hidden Exclusive Access)

## 사례 2: HEIR (폐기 결정)

### 분석

| 항목 | 평가 |
|---|---|
| **카테고리 본질** | ❌ AI 약점 카테고리 (모던 현실 코드 + 여주 감정 몰입) |
| **위원 거절 원인** | ❌ 카테고리 본질 약점 (AI vs 실사 경쟁력·트렌드 지남) |
| **디벨롭 후 차별성** | ❌ AI 강점 추가 시 SHE STOLE MY FACE와 중복 (Identity Theft) |
| **위원 평가 분포** | ❌ 1/6 (위원 C만 Yes, 다른 모든 위원 거절) |
| **시간 비용** | ❌ 디벨롭 = 사실상 새 작품 작성 |

### 폐기 근거

1. **AI 약점 카테고리** — 모던 현실 코드 + 여주 감정 몰입 = 실사 라이브 액션이 강함 (위원 E·G)
2. **AI 감정 몰입 한계** (위원 D) — 모던 여성향 = AI 약점
3. **유행 지난 페이월** (위원 F) — 시아버지 유산·복수·역전 = 트렌드 X
4. **디벨롭 시 중복 위험** — AI 강점 추가 → SHE STOLE과 중복
5. **위원 신뢰 부족** — 1/6 거절 = 디벨롭 후 위원 신뢰 회복 어려움
6. **남성향 변경 (위원 A 의견)** — 완전 새 작품 = 비효율

→ **카테고리 본질 약점 + 디벨롭 후 중복 + 시간 비용** → **폐기 결정**

## 폐기 vs 디벨롭 자가 검증

피칭 탈락작에 대해 다음 5개 자가 검증:

- [ ] **1. 카테고리 본질이 검증 영역인가?** (글로벌 IP·NetShort/GoodShort 검증 트로프·시장 트렌드 매칭)
- [ ] **2. 위원 거절 원인이 작품 본질 X / 피칭덱 부재 또는 위원 인지 한계인가?**
- [ ] **3. 디벨롭 후 다른 통과작과 차별성 명확한가?**
- [ ] **4. 위원 평가 분포가 일부 긍정 (3-4표 이상)인가?**
- [ ] **5. 디벨롭 시간 비용 vs 다른 작품 우선순위 합리적인가?**

→ **3+개 ✅ = 디벨롭** / **2개 이하 ✅ = 폐기 권장**

## 단계별 행동

### 디벨롭 결정 시
1. 피칭덱 보강 (메인 남성향 교육·AI 강점 명시 등)
2. 작품 메타 갱신 (디벨롭 진행 상태)
3. phase_2 재진입 (재피칭 준비)
4. 위원 거절 트리거 사전 차단

### 폐기 결정 시
1. 작품 폴더 보존 (인사이트 자료·향후 참고)
2. 메타 갱신 (폐기 상태·이유·인사이트 명시)
3. 작품 진행 정지
4. 폐기 사례 메모리 추가 (다른 작품 개발 시 참고)

## Why

사용자 명시 (2026-05-12):
> "Heir의 경우, 폐기가 적합하다고 나는 생각하고 있다. 위원들의 반응 등을 고려해서 하면 된다. (...) 단순히 내가 폐기 의견을 줘서 폐기하는 것이 아니어야 한다."

→ 폐기 판단 = 카테고리 본질 분석 + 디벨롭 vs 폐기 5 기준 + 시간 비용. 단순 사용자 의견 수용 X.

## How to apply

- 피칭 탈락작에 대해 5 자가 검증 적용
- 3+개 ✅ = 디벨롭 / 2개 이하 ✅ = 폐기
- 작품 폐기 시 인사이트 메모리 보존 (다른 작품 개발 시 참고)
- 디벨롭 시 피칭덱 보강 영역 명확화 (`feedback_pitch_male_target_education.md` 등)

## 핵심 한 줄 결론

> **카테고리 본질 + 위원 거절 원인 + 디벨롭 후 차별성 = 폐기 vs 디벨롭 판단 기준.**
