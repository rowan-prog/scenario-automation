# Vertical은 주인공이 말로 장면을 소유한다

**룰:**
1. 주인공의 dialogue가 가장 많아야 한다. 남성향·여성향 무관·장르 무관.
2. VO도 적절히 써야 한다 (주인공의 내면 voice가 장면을 지휘).
3. 연출을 위해 장면도 간헐적으로 비선형적 구성 필요.
4. **Reveal은 물건이 설명하면 약하다. 주인공이 말로 찢어야 한다.**
5. **🆕 어지간하면 소품에 목매여 전개하지 않는다.** Props·objects (pin·반지·token·mirror·bird·letter·brand·seal 등) = 보조 증표·analog. Plot driver·reveal trigger·관계 변환 anchor로 **반복 사용 금지**.

**Why:**
- 2026-05-26 사용자 명시 (THE OFFERING v48 EP46 reveal 정합 turn).
- v47 EP46 reveal에서 `silver pin + wooden bird + jaw angle` 조합으로 reveal trigger 작동 → "단서가 맞네" 퍼즐 톤·감정 reveal 약화.
- v48 수정: jaw 매칭 sequence 삭제 + Vael "You told me to earn it / I have been trying since dawn" 약속 직접 회수 → 감정 reveal 강화.
- v48 추가 (line 4864 VO 교체): `The same bird. Twice. One I left on the table the morning after. One his mother carved.` (단서 정리 VO) → `I thought I buried that night. He kept it alive.` (감정 보상 VO·주인공이 reveal 소유).
- 사용자 인사이트: vertical은 짧은 시간·세로 화면·집중력 낮은 환경. 주인공이 *말로* 장면을 끌고 가야 audience 몰입. 물건/단서 매칭은 영상·드라마(가로)에서 작동하지만 vertical에서는 약함.

**How to apply:**
- 매 phase_4 집필 시 → 주인공 dialogue 비율 체크. 다른 캐릭터 dialogue가 더 많으면 redistribution.
- 모든 reveal 장면 (truth reveal·정체 reveal·배신 reveal·사랑 reveal) → trigger = 주인공의 dialogue 또는 VO. 물건/단서 매칭은 *증표*로 보조 가능하나 *trigger*로 사용 X.
- VO 활용: 주인공이 행동/말 못하는 상황 (감정 폭발 직전·생각 정리·시간 압축)에서 적극 사용.
- 비선형 장면 (flashback·flashforward·intercut·montage): 매 EP 1-2회 정도 간헐적 활용. 연속 사용은 혼란.
- 자가 점검 (매 EP): "이 장면에서 누가 말 가장 많이 했나? 주인공인가?" → NO면 재분배.

## 🆕 룰 5 상세: 소품 의존 금지 (2026-05-27 사용자 명시)

> **사용자 명시:** *"어지간하면 '소품'에 목매여 전개하지마라."*

### Why

- Paid vertical = 짧은 시간·세로 화면·낮은 집중력 환경.
- 시청자는 **사람의 얼굴·말·감정 거래·관계 변화**를 보러 온다.
- **Props 반복 등장·prop-anchored reveal·prop-driven plot = 가로 영상 드라마(HBO·Apple TV+) 문법**. Vertical = 작동 X.
- 작가가 *상징·motif·시각적 anchor* 욕심으로 prop을 반복 박으면 **plot이 prop 중심으로 정렬** = 캐릭터 deflation·매출 driver 약화.
- 이미 학습된 실패: THE OFFERING 능선 드래곤·EP13 hair pin·silver bird pin·black mirror·jaw-matching 등 prop-anchored reveal 다수 → reveal 톤 약화·사용자 분노 반복.

### 금지 패턴

❌ **Plot driver로 prop 반복:** 같은 prop이 3+ 장면에서 trigger·reveal·anchor로 사용 (silver bird pin = EP01 등장·EP24 재회·EP46 reveal trigger 류)
❌ **Reveal trigger로 prop:** 캐릭터가 prop을 *보고* 깨닫거나 정체 reveal (jaw·tattoo·mark·ring·pin 매칭 reveal)
❌ **관계 변환 anchor로 prop:** prop을 주고받음 = 관계 격상·prop 떨어뜨림 = 단절 (vertical 문법에서 약함)
❌ **갈등 동력으로 prop:** prop 분실·도난·진위 검증 = arc 추진 (가로 영상 미스터리 문법)
❌ **시적 motif로 prop 반복 등장:** 같은 prop이 다른 시점에 반복 등장하며 "의미 누적" 시도

### 허용 패턴

✅ **단발 증표:** 한 장면 한 컷 prop으로 정보 보조 (감정 reveal은 캐릭터 dialogue/VO가 끌고 prop은 시각 보조)
✅ **기능적 prop:** 무기·도구·문서 등 그 장면 행동에 필요한 도구로 등장 (반복 의미 누적 X)
✅ **Paywall hook 1회:** EP08/09 paywall 도구로 prop 1회 사용 가능 (반복 motif X)
✅ **Setup 5화 룰 정합 prop:** payoff 5화 전 setup된 prop이 *payoff 1회*에만 등장

### 판정 룰

매 phase_4 집필·검토 시 자가 점검:
1. 이 장면 plot driver = 캐릭터의 말·행동·감정 거래인가? 아니면 prop인가?
2. 같은 prop이 작품 전체 몇 장면에 등장? **3+ 장면 = 자동 🟡 (재설계 검토)**.
3. 이 reveal trigger = 캐릭터 dialogue·VO인가? 아니면 prop matching인가? Prop matching = 약함.
4. 이 prop을 빼도 장면이 작동하는가? YES = 그 prop은 over-relied (삭제 가능).
5. 작가가 motif·상징 욕심으로 박은 prop인가? YES = 즉시 삭제.

### 검토 규칙 (페르소나·Gate)

- **페르소나 04 / 07 / 05** 매 EP scan 시 prop 등장 빈도 grep 의무
- 동일 prop 3+ EP 등장 = 자동 🟡 (구조 검토)
- Reveal trigger = prop matching 발견 = 자동 🔴 (캐릭터 dialogue·VO로 교체)
- LOCK 평가 직전 작품 전체 prop motif 빈도 audit·3+ 반복 prop = 보류
