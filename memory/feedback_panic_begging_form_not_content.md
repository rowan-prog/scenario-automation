2026-07-03 buried_heir 45화 데이먼 문밖 애걸에서 사용자 강교정. 내 초안("아니야… 이거 아니야" / "나한테만 내던 소리잖아") 판정 = "존나 약해·존나 설명조·리얼하지 않아·존나 느리고 감정이 없어. 대사가 느릿하게 나올 수가 있나? 호흡이?"

**Why:** 극한 감정의 인간은 자기 감정을 서술하지 않는다. 분석 문장("나한테만 내던 소리")은 작가의 관찰이지 그 순간의 입이 아니다. 말줄임표(…)는 지면에서 시적으로 보이지만 낭독 호흡을 느리게 설계하는 표기다 — 패닉엔 여백이 없다. 감정의 리얼리티는 내용이 아니라 **형식**에서 나온다: 속도·반복·파편·서로 밟는 말·끝까지 간 적 없는 문장. ([[english-vertical-hit-dialogue-tone]]의 "감정=라벨 아닌 form" 원칙의 극한 케이스·언어 무관.)

**How to apply:**
- 붙여쓰기 = 속도 표기: `안돼안돼안돼안돼—` `제발제발제발—` / 이름 연타 `레일라. 레일라레일라레일라 문열어. 어? 어? 문 열어봐—`
- 애원이 앞말을 밟는다: `내가 잘못했어 내가 잘못했어 내가 다, 다 잘못했으니까, 그러니까—`
- 설명조·관조·완성 문장·"…" 저속 호흡 전면 금지.
- **자극→발작 물림**: 트리거(문틈 소리 등)가 새어들 때마다 애걸이 비명으로 치솟았다 흐느낌으로 꺼진다 — 교차 컷과 맞물리게.
- 톤 지문 = 호흡 지시: (숨도 못 쉬고, 쏟아내듯) (말이 서로 밟히며).
- 붕괴의 끝만 느려진다: 목이 쉬어 무음 — 입 모양만 이름을 만든다. 침묵이 마침표.
- 판정 기준: **대사가 멋있으면 실패다.**
- **아련 어미 금지 (전 대사 보편·같은 세션 후속 판정 — 기준 = 어미가 아니라 감정의 세기):** 미묘한 떨림·아련한 여운용 말끝 흐리기(`~잖아…` 류) 금지. 판정 = **느낌표 또는 ㅜㅜㅜㅜ를 붙여도 안 이상한가**. 펑펑 쳐울면서 내뱉는 대사는 `~잖아`도 오히려 좋음(ㅜㅜ 호환 = 통과). 사용자: "숏폼에선 제발, 대사를 아련 터지게 하지 마라 / 미묘한 떨림과 슬픔 전달이 아님, 펑펑 쳐울면서 하는 대사여야 함."
- 붕괴 종착("레일라. 레일라. 레일라…" 이름만 남는 언어 붕괴 + 무음)은 사용자 직접 승인("이건 좋음") — 이 패턴은 정답 레퍼런스.
