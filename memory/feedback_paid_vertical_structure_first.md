## 무엇이 바뀌었나

- **판정 순서 = 엔진 → 구조 → 서사 → 라인.** 구조 판정을 서사 칭찬("이야기는 재밌다")으로 대체 금지 — 서사가 좋아도 뼈대가 장편이면 안 팔린다.
- **S0 (전제) = 공력 배분 + 결제 동인.** 가중치 = 1화≫≫≫2화>3화>마지막 무료회차>나머지 무료>유료 / 컷 = **1화 오프닝 > 1화 엔딩 > 마지막 무료회차 엔딩**. 3화를 넘긴 시청자는 대개 무료 끝까지 온다 → 이탈 방어 전장 = 1~3화. **결제 = 비싼 돈이고 예술로는 못 뽑는다** — 원초·금기·천박·더러움·궁금함·윤리 이탈이 **극단으로**. "그럭저럭 만족"은 결제 0. "품위·세련·정제" 교체 제안 = 정면 위반.
- **구조 7항(S1~S7)** = 첫 씬 안에 전제가 사건으로 성립(도입 씬 허용) / 화의 단위 = 쟁점·물건 하나(씬/화 2.1) / 다음 화 씨앗 = 같은 공간의 다음 물건 / 화의 끝 = 그 화 승자의 짧은 대사 / 주인공이 매 화 되받아침(일방 굴욕 = 선택지지 기본값 아님) / 관객 선지 + 밝히지 않기로 하는 선택 / 인물 불변·결심 강도만 상승·감정 증거는 작은 디테일.
- **붕괴 3축** = ①속도(도입 있는 화·요약으로 흘러가는 화·막(幕) 라벨) ②인과(연결어미 2+·원인이 화면 밖·계획→준비→실행) ③감정선(아크/내면 서술·"점차·서서히·마침내·한참 뒤에").
- **검수에 기획 문서 모드가 없었던 게 근본 원인** — 대본 렌즈(per-line·ledger·drawability)는 기획 문서에 안 걸려서 기획안·트리트먼트가 사실상 무검수로 하류에 내려갔다. `20_review` §1③ 신설로 메움.
- **§C-1 숫자 정정** — 구 "무료 8화 = 사건 3~4개 / 50화 = 아크 10~14개, 각 3~6화"는 히트작 실측(50화 = 사건 2~5개·한 사건 12~41화·무료 8화 = 사건 1개)의 3~4배였다. 이 숫자가 기획 단계로 상속돼 "전개가 장편 같다"의 산술적 뿌리가 됐다. ([[hit-script-event-count-measured]]가 2026-08-03에 이미 제기해둔 안건)

## 재발 방지 시 주의

- **장르 캐논인 지연은 결함이 아니다** — 후회남의 후회 지연·무료런 정보 자본 유보(§C-4-2). 유보되는 건 정보와 감정 종결이지 자극이 아니다. 이 예외로 FLAG를 기각하려면 어느 장르 캐논인지 이름을 대야 한다.
- **처방 방향 주의:** "개연성·경위·동기를 더 설명하자" = 축 2 감염을 처방으로 되돌리는 최빈형(= §4 논리 닫기형).
- **기계 계수는 하한 추정기** — `--shortform` 0이 통과 증거가 아니다(§0.3 면죄부 금지). 캐릭터 필드 형태·기승전결 회계는 사람이 읽는다.
