# 보상 단계 설계 (필수, 2026-05-10 사용자 통합 인사이트 + 시스템 정리)

## 핵심 표현 변경

**"보상 유예"라는 말만 쓰면 위험하다.** 정확한 표현은:

> **초기 보상은 줘야 한다. 최종 보상은 남겨야 한다. 그 사이에서 시청자의 욕망이 더 커지게 만들어야 한다.**

**핵심은 "유예"가 아니라 "보상 단계 설계".** 보상을 안 주는 것이 아니라, 어떤 보상은 즉시 주고 어떤 보상은 남길지 설계하는 것.

---

## 3층 보상 구조 (필수, 모든 작품 적용)

### 1층 — 장르 진입 보상 (Genre Entry Reward)

**시청자가 "아, 이 장르 맞네"라고 느끼기 위해 초반에 반드시 받아야 하는 보상.** 유예 X — 안 주면 시청자가 다음 보상을 기다리지 않고 즉시 이탈.

| 장르 | 1층 (즉시) |
|---|---|
| 복수극 | 억울함·빼앗김·반격 단서 |
| 얼굴 도용극 | 얼굴·이름·자리 박탈의 충격 |
| 다크 로맨타지 / 로맨스 | 선택받을 가능성·남주의 보호·소유감 |
| 남성향 무쌍 | 첫 승리·첫 각성·첫 압도감 |
| 하렘 / 섹스어필 | 매력적 여성 등장·시각적 서비스 |
| 루프물 | 죽음 뒤 기억 남음·다음 루프 더 멀리 가는 성취 |
| 괴물 / 재난물 | 첫 압도적 위협·생존 경로 발견 |
| 코스믹 호러 복수 | 이용당한 증거·반전 가능성 |

**이걸 안 주면 시청자가 이탈. "이 장르 맞나?"의 의문이 들면 다음 화 결제 X.**

### 2층 — 상승 보상 (Escalation Reward)

무료 구간 안에서 조금씩 줘도 되는 보상. **"이 작품은 약속을 지킨다"는 신뢰를 형성.** 너무 안 주면 답답하고, 너무 많이 주면 유료 동력 사라짐.

예시:
- 첫 증거 확보
- 첫 적 제압
- 첫 권한 이전
- 첫 히로인 동맹화
- 첫 키스 직전 거리
- 첫 문·무기·전함·통제구역 개방
- 첫 공개 망신 직전 상황
- 첫 단계의 무쌍 / 첫 정복지

### 3층 — 최종 보상 (Final Reward — 유료 유예 필수)

**유료 구간으로 남겨야 하는 보상.** 페이월은 이 최종 보상이 곧 나올 것처럼 보이는 지점이어야 하나 완전히 주면 안 됨.

| 장르 | 3층 (유료 유예) |
|---|---|
| 여성향 복수극 | 공개 폭로·완전 복수 |
| 현대 재벌 역전극 | 가문·회사 완전 장악 |
| 다크 로맨타지 | 공식 신부·연인 선언 |
| 남성향 무쌍 | 최종 왕좌·세계 장악 |
| 하렘 | 완전 소유·하렘 완성 |
| 루프 / 재난 | 루프 탈출·시스템 붕괴 |
| 호러 복수 | 완전 봉인 역전 |

---

## 핵심은 "유예"가 아니라 "격차" (Gap, Not Withholding)

좋은 숏폼 초반부 작동 원리:

> 이미 맛을 봤다. (1층·2층 보상 받음)
> 그런데 더 큰 것이 보인다. (3층 단서 노출)
> 아직 그것은 손에 들어오지 않았다.
> 그래서 다음 회를 눌러야 한다.

**초반부의 힘은 결핍에서만 오는 것이 아니라, 이미 받은 보상과 아직 못 받은 보상 사이의 격차에서 온다.** 격차가 클수록 결제 욕망 증가.

## 장르별 욕망 강화 방식 (매우 중요 — 단일 패턴 강제 X)

### 여성향 복수극 / 역전극

**결핍:** 억울함·배신·모욕·자리 박탈·가짜가 진짜 행세·이름·집·남자·권리 상실.

**욕망 강화 = 패배 누적형:**
> 더 빼앗긴다 → 더 폭로하고 싶어진다.
> 더 모욕당한다 → 더 무너뜨리고 싶어진다.
> 가짜가 더 설치친다 → 진짜가 돌아오는 장면을 더 원한다.

**해당:** 04 I AM THE HEIR / 06 SHE STOLE MY FACE.

### 다크 로맨타지 / 여성향 로맨스

**결핍:** 버려짐·선택받지 못함·사랑받을 자격 없다고 취급·낮은 자리에서 높은 남주를 바라봄·위험하지만 매혹적인 남자의 보호·소유.

**욕망 강화 = 거리 차단형 (모욕만 X):**
> 그는 나를 죽이지 않는다.
> 그는 나를 숨기지 않는다.
> 그는 나를 자기 옆에 둔다.
> 그런데 아직 "나의 여자·신부"라고 완전히 말하지 않는다.

**페이월은 "선언 직전"이 가장 강하다.** 신부 선언을 완성하는 순간보다, 모두가 그 선언을 예상하는데 아직 안 나온 상태가 더 결제 만듦.

**해당:** 02 THE OFFERING.

### 남성향 무쌍 / 먼치킨 / 하렘

**결핍:** 현실에서 힘 없음·통제력 없음·여자에게 욕망받지 못함·인정받지 못함·세계 장악 못함.

**핵심 보상:** 압도적 힘·즉시 승리·통제권·지배권·여성들의 시선·호감·복종·성적 끌림·시각적 서비스·더 큰 무기·기지·영토·군대.

**욕망 강화 = 승리 확장형 (패배 누적 X):**
> 이긴다 → 더 큰 적이 보인다.
> 얻는다 → 더 큰 것이 잠겨 있다.
> 한 명이 붙는다 → 더 높은 여자가 주인공을 본다.
> 첫 무기를 얻는다 → 무기고 전체가 보인다.
> 첫 기지를 얻는다 → 도시 전체가 보인다.

**1층 (즉시 필수):** 첫 각성·첫 승리·첫 무쌍·첫 히로인 비주얼·첫 여성 끌림·첫 통제감·첫 무기·권한 획득.

**3층 (유예):** 최종 왕좌·제국 완전 장악·최종 보스 굴복·최고 등급 히로인 완전 귀속·하렘 완성·도시·세계 완전 지배.

**남성향 페이월 설계 — 매우 중요:**
- ❌ 나쁨: "주인공이 아직 약해서 더 강해져야 한다."
- ✅ 좋음: "주인공은 이미 강하다. 첫 적을 압도했다. 그런데 그 승리로 더 큰 왕좌·더 큰 여자·더 큰 군대·더 큰 도시가 열린다."

**남성향에서 "갈망"은 결핍 악화보다 스케일 확장에서 온다.**

**해당:** 01 TITAN BORN / 03 HE COMMANDS THE STARS / **레퍼런스: LOCKED OUT.**

### 루프 / 재난 / 괴물 스릴러

**결핍:** 이번엔 더 멀리 가고 싶음·원인 알고 싶음·살아남고 싶음·시스템 주도권 빼앗고 싶음·반복 죽음 구조 깨고 싶음.

**욕망 강화 = 정보 확장 + 자기 변화 인지형:**
> 죽는다 → 기억한다 → 더 멀리 간다 → 더 큰 통제구역을 본다 → 내가 이용당했다는 증거를 본다.

단순 "또 죽음" 반복 X. 죽을 때마다 더 멀리 가고, 시스템이 주인공을 데이터로 쓰고 있었다는 분노 누적.

**해당:** 07 EVERY MONDAY.

### 코스믹 호러 / 가족 봉인 복수

**결핍:** 가족이 나를 이용했다는 분노·의식 진실 알고 싶음·내 자리에 저들이 앉는 거 보고 싶음·봉인이 되돌아가는 공포와 쾌감.

**욕망 강화 = 의식 자리 전환형 (단순 고난 X):**
> 내가 앉던 의자.
> 내가 묶였던 봉인.
> 내 눈에 있던 문양.
> 그 선이 가족 쪽으로 흐르기 시작한다.

**해당:** 05 THE LAST KEY.

## 작품 진입 게이트 (필수, 신규 작품 진입 시 자동 점검)

phase_1·phase_2·phase_3 진입 시 작품 메타로 다음 점검:

```
1. 장르 식별 → 1층 보상 항목 매칭
2. 1층 보상이 EP1-2에 즉시 들어가는지 확인
   ❌ 안 들어감: 자동 🔴 — 작품 망가짐 (시청자 이탈)
3. 2층 보상이 EP3-5에 점진적으로 누적되는지 확인
   ❌ 정체: 자동 🟡
4. 3층 보상이 페이월 직전에 "곧 나올 것처럼" 보이는지 확인
   ❌ 무료에 누설: 자동 🔴
   ❌ 페이월에 신호 없음: 자동 🟡
5. 욕망 강화 방식이 장르 매트릭스와 일치하는지 확인
   ❌ 사이다 패턴을 무쌍 작품에 / 무쌍 패턴을 사이다 작품에: 자동 🔴
```

## 자동 trigger (페르소나 07 검토용)

### 모든 작품 공통
- 1층 보상이 EP1-2에 즉시 X: 자동 🔴
- 3층 보상이 무료에 누설: 자동 🔴
- 페이월 직전이 3층 신호 X: 자동 🟡
- 장르 매트릭스 욕망 강화 방식과 작품 패턴 불일치: 자동 🟡

### 여성향 (Mode A — 누적 강화형)
- 회차별 결핍 강도 곡선 평탄: 자동 🟡
- 가짜·적의 뻔뻔함 회차마다 강화 X (사이다·복수극): 자동 🟡
- 거리 닿을 듯 안 닿음 표지 부재 (로맨타지): 자동 🟡

### 남성향 (Mode B — 즉시 충족 + 승리 확장형)
- 주인공 약함 시간 2화 초과 (EP3까지 첫 무쌍·각성 안 옴): 자동 🔴
- 회차마다 즉시 보상 0건 (무쌍·파워업·여자·시각 압도): 자동 🔴
- 시각적 매력 히로인·서비스컷 부재: 자동 🟡
- 페이월 직전이 "더 큰 적·새 차원" 등장 X: 자동 🟡
- "주인공 자기 변명·자기 약함" 발화 한 화 이상: 자동 🟡

### 호러·루프·미스터리 (Mode C — 정보 확장 + 자기 변화)
- 진실 무지 강도 회차마다 증가 X: 자동 🟡
- 자기 변형·자기 인지 표지 부재 (코스믹 호러): 자동 🟡
- 동료·가족 신뢰 변화 부재 (반복 정체): 자동 🟡

## 메타 표현 절대 금지 (필수)

이 분류는 **작가·검토자용 메타 도구.** 피칭덱·청사진·트리트먼트에 그대로 적으면 안 됨.

❌ 잘못된 예시:
- "이 작품은 Mode B (남성향 무쌍 즉시 충족 모드)로 작동한다."
- "결핍 강도 곡선이 EP1에 정점, 이후 단계별 충족."
- "유예되는 것은 최종 보상이고 단계별 보상은 즉시."
- "원초적 욕망의 보상을 유예한다."
- "결핍을 강화한다."
- "시청자의 갈망을 증폭한다."

✅ 올바른 예시 (작중 사건·자리·물건·몸·권한·시선·문·이름·선언으로):
