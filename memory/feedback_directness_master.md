## 1. 핵심 원칙 (모든 작품·문서 영구 적용)

> **뇌 빼고 읽어도 그림처럼 그려지는 직관성.**
> **한 문장 = 한 그림.** 추상어·라벨 X. 화면에 무엇이 보이는지 직접 적시.

## 2. 직관성 anti-pattern 7 검수 (필수 통과)

모든 문장 (로그라인·줄거리·트리트먼트·인물 소개·페이월 응축) 7 검수:

| 번호 | anti-pattern | 회피 | 대체 |
|---|---|---|---|
| **A1** | 은유·암시 | "이름을 지웠다" / "잘라냈다" / "자리를 비웠다" | 사실로 |
| **A2** | 장소 모호 | "어둠 속" / "그곳" / "어딘가" | 구체 장소 명시 |
| **A3** | 추상·인격화 동사 | "응답해 / 호응해 / 동조해 / 화답해 / 함께 떨고 / 같은 결로" | 시각적 동사 |
| **A4** | 인과 모순 | "왜?" 답 X | "왜?" 답되게 |
| **A5** | 만연체 | 한 문장 30+ 단어 / 종속절 4+ | 30단어 이하 / 종속절 3개 이하 |
| **A6** | 세계관 누락 | "그 / 무언가 / 어떤" 추상 지시어 | 고유명·구체 명사 |
| **A7** | 방향·대상·감정 없는 물리 동작 (2026-05-11 추가) | "고개를 돌린다" 단독 / 반응 컷 빈발 | 방향·대상·감정 명시 |

**자가 시뮬레이션:** "사용자가 '이게 뭐야 / 답답하다 / 외면하게 만든다' 반응할 가능성 0%인가?" 1%라도 있으면 재작성.

## 3. 작품 직관성·밀도·명쾌함 (영구 적용)

- **숏폼 vs 영화 구분** — 회차당 직선 쾌감 비트 필수. 영화처럼 풀어지는 인과·내적 심리 비트 누적 X
- **트리트먼트 = 장면 기술** — 무엇이 일어나는가를 써야지, **무엇을 의미하는가를 쓰지 말 것**. 화면에 보이는 것·들리는 것·움직이는 것 직접 적시
- **핵심 갈등·구조 회차마다 명료** — 누가 누구에게 무엇을 빼앗기고 / 이 회차 어떤 비트 / 다음 회차 어떤 질문
- **인물 행동 줄줄이 묘사 X** — 갈등·관계 구조가 보이게

## 4. 트리트먼트 설명 금지 — 행동·사건으로 보이게

### 원칙
- 인물 의심·악의·동기를 **직접 발화로 "설명" X**
- **행동·시선·소품·자리 이동으로 "느끼게"** O
- 발화는 **장르 보상 핵심 한 줄에만**
- **외부 해설(괄호 메타) 0건**
- **행동·시각이라도 비유스러우면 X**

### 3 검수
1. **직관성** — 한 문장 = 한 그림
2. **작중 쾌감** — 장르 보상 작동
3. **"그래서 뭐?" 답** — 사건이 인물 처지를 바꾸는가

### 나쁜 예 vs 좋은 예
**❌ 나쁜:** "그녀가 그를 의심하기 시작한다." (설명)
**✅ 좋은:** "그녀가 그의 책상 서랍을 슬쩍 연다. 손목시계가 두 개." (행동·시각)

## 5. 트리트먼트 작성 7 원칙 (사용자 작성 5 예시 보존 — 판타지·현대 멜로·K-pop·성인 서바이벌·학원 학짱극)

### 원칙
1. **비트 분리** — 한 문단 = 한 비트
2. **시각 디테일** — 캐릭터 외모·소품·미장센·VFX 구체
3. **대사 인용** — 핵심 발화 영어 직접 인용 가능
4. **정보 자연 노출** — "설정 설명" X / 사건 안에서 자연 노출
5. **클리프행어 정지·암전** — 시각·동작이 정지하는 순간
6. **작품별 톤** — 통일된 보이스·미감
7. **인물 내면** — 외부 행동·시선·반응으로 드러냄 (내면 독백 X)

### 클리프행어 = 물리적 정지 컷
- 이름 호명·감정 비트·인물 깨달음만으로 약함
- **나쁜:** "자객의 검이 부서지고, 그가 처음으로 그녀의 이름을 부른다."
- **좋은:** "그가 그녀의 손목을 잡은 채 공간이 멈춘다. 자객의 검이 두 동강 나 바닥에 떨어진다."
