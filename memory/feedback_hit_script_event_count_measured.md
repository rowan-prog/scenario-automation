**2026-08-03 사용자 지시로 raw 직접 계측.** 발단 = 《흑길동》 러프 무료 8화 트리트먼트를 내가 **사건 8개(1화 1사건)**로 써 놓고 "숏폼 구조 지켰냐"는 질문을 받은 것. 사용자가 먼저 총량 기준을 줬다: *"50개 에피면 사건은 5개에서 10개면 되는 거야. 10개도 사실 많아. 연결이 어려워서. 그래도 최대 10개라는 거야."* 그리고 *"사건 갯수들에 대해선 좀 히트작 대본들 참고하면서 파악할 필요가 있어보인다."*

## 실측 (회차별 첫 씬 공간 헤더 추출)

| 작품 | 화수 | 구간 | 사건 수 |
|---|---|---|---|
| **신의한방** | 46 | 도입 1~4 / **콜로세움 5~45 (41화 연속)** / 마무리 46 | **2~3** |
| **False Weakling, True Power** | 50 | 도입 1~7 / 토너먼트 아레나 8~20 / 저택의 밤 21~33 / 왕궁 옥좌실 34~50 | **4** |
| **약자의 가면 강자의 힘** | ~50 | 도입 / 무투대회 = 한 오후 한 경기장 8~20 / 주루 대결 = 한 건물 한 밤 22~38 / 후반 | **4~5** |

**결론: 50화물 = 사건 2~5개 · 한 사건이 12~41화.** 사용자 기준(5~10)보다 히트작이 **더 적다.** 무료 8화는 사건 **1개**가 정상이고, 2개면 이미 많다.

## 세는 법 — 공간이 아니라 인과로 센다

컨테이너(공간+시간 단위)와 사건(하나의 판)은 다르다. 흑길동 무료 8화는 컨테이너 3개(관아 첫밤 / 그 낮 홍판서 댁 / 그 밤 홍판서 댁)인데 **사건은 1개**다 — 관아를 털었더니 추적이 집으로 왔고 → 그래서 문간에 세워졌고 → 그래서 자기 집을 털게 되고 → 거기서 아버지가 알아본다. **인과가 한 번도 끊기지 않으면 공간이 바뀌어도 한 사건이다.** 반대로 공간이 같아도 판이 새로 깔리면 다른 사건.

## 🚨 구조 개정 안건 (실무 세션 권한 밖 — Fable 전환 시 처리)

**`10_writing_standard.md` §C-1이 히트작 실측과 충돌한다.** 현재 문서: *"50화 = 큰 상황(아크) 10~14개, 각 아크 = 3~6화"* / *"무료 8화 = 사건 3~4개가 정상"*.
- 실측은 **아크 2~5개 · 각 12~41화**다. 문서 숫자가 히트작보다 **3~4배 잘게 썰려 있다.**
- 같은 문서 §C-3은 이미 컨테이너 12~15화를 인정하고 hit_dna #9도 "콜로세움 45화"를 적고 있다 — **§C-1의 숫자만 구버전으로 남아 서로 모순.**
- 이 숫자가 AI를 사건 과다로 몰고 있을 가능성: 지시서가 "아크 3~6화"를 주면 50화에 아크 10개 이상이 나오고, 그게 곧 [[occasion-hopping-space-economy]] ①번 행사 순회다.
- 사용자 감각(5~10개)이 문서(10~14개)보다 히트작에 가까웠다.
