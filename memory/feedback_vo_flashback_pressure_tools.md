## 왜 VO·플래시백이 paid vertical에 강한가

### 1. 멀티태스킹 시청자에게 직격

paid vertical 시청자 = 집중 X / 배속 O / 딴짓 O.
- 미세한 현재형 압력 = 인지 X
- **0.5초 플래시백 + VO** = 즉시 인지·즉시 분노

### 2. 분노 게이지 즉시 누적

- 사슬·끌림·욕설·찢김 = 직접 보임
- "그러게, 죽이려고 보냈는데" 류 VO = 즉시 분노 트리거
- 8화 페이월 직전 = 분노 정점 = 카타르시스 폭발

### 3. 모욕의 구체성 확보

- "이졸데가 핍박받았다" 설정 X
- **이복오빠가 사슬 당기며 "울지 마. 드래곤이 네 목소리까지 태워주면 우리 집안 체면도 좀 살겠지."** = 분노 즉시
- 0.5초씩 5개 컷 압축 = 모욕 5건 인식

### 4. 시청자 이입 트리거

- 1화 매달림·울음 = 이입 트리거 (`feedback_female_lead_rise_arc.md`)
- VO·플래시백 = 8화에서도 이입 가능
- 페이월 직전 짧은 회상 = "이 여자가 이걸 견뎌온 거구나"

## 5 조건 (모두 충족 시 적극 도입)

### 조건 1 — 구체적 인간의 구체적 행동
- ❌ 추상 모욕 ("그들이 그녀를 멸시했다")

### 조건 2 — 0.5초씩 압축 컷 (5-8 컷)
- ❌ 긴 회상 (10초+ = 시간 흐름 깸)
- ✅ **0.5초씩 5-8 컷 압축** = 분노 응축 폭발

### 조건 3 — 페이월 직전·결정 직전 배치
- ❌ 작품 중간 분위기용
- ✅ **페이월 직전·여주 결정 직전·발화 직전** = 압력 정점

### 조건 4 — 멀티태스킹 시청자도 인지 가능
- ❌ 미묘한 분위기·뉘앙스
- ✅ **얼굴·사슬·옷 찢김·구체 행동** = 화면 안 봐도 소리로 인지

### 조건 5 — VO 대사도 구체 (작가 자아실현 X)
