# 규칙

사용자에게 질문하거나 결정을 요청해야 하는 모든 시점에서, **반드시 `PushNotification`으로 알람을 함께 발송**한다.

대상 시나리오:
1. `AskUserQuestion` 도구 사용 직전
2. 진행 중 결정/선택 요청 (입력값 요청, 분기 선택)
3. 블로커 보고 (Round 5 초과 등 진행 중단 사유)
4. 장시간 작업 후 사용자 확인이 필요한 시점

**Why:** 사용자가 다른 작업/회의/식사 중일 때 Claude의 질문을 놓쳐서 대기 시간이 길어진 경험이 잦았음. 사용자가 명시적으로 "알람을 줘라"고 지시.

**How to apply:** 
- 질문할 때 `PushNotification` 호출을 같은 응답에 포함
- 메시지는 200자 이내, 한 줄, 핵심 액션 우선 ("결정 필요: Round 2 진행 또는 패치 추가" 식)
- "묻지 마라. 알아서 진행하라" 규칙과 충돌하지 않음 — 자율 진행이 원칙이지만, 불가피하게 질문이 필요한 경우(권한·핵심 분기·블로커)에는 질문+알람 동반
- 단순 진행 보고에는 사용 금지 (잡음 누적 방지)
