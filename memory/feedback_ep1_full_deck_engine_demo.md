# EP1 = 패 선포 + 엔진 실연 (2026-06-12 — 3버전 비교 + 中 TITAN BORN 개편 실증)

**배경:** 같은 기획(드래곤 로드 원나잇)의 3버전 중 우리·GPT 원본(VER3)이 "정적·지루·맛없음" 판정, 타사 VER1/2가 우세. TITAN BORN도 중국어 개편본이 원본 우세 — 사용자: "이런 방식으로 잘 팔린 것들이 북미에도 많다."

## 보편 원리 2 (장르 무관)

1. **패 선포 — 미스터리 아껴두기 금지.** 전제·박탈·보상 룰·관계 스택을 EP1 안에 전부 깐다. 가족 배신 스택은 플래시백 1개로 일괄 적재 가능(병상 인질 엄마 + 가짜 눈물 동생 + 모욕 약혼자 + 협박 왕 = 한 씬). 잃을 게 "다음에 뭐가 나올까"가 아니라 "선포된 판이 어떻게 터질까"로 끌고 간다.
2. **엔진 실연(實演).** 작품의 쾌감 기제(저주 진정·이름 박탈 등)는 EP1에서 **화면+대사로 작동시켜 보여준다** — 암시(손목 떨림 1컷)는 0점. 화면: 비늘이 썰물처럼 사라짐 / 대사·OS: "저주가… 잠잠해졌어. 대체 어떤 여자를 내 침대로 보낸 거지?"

## VER3(패배 원고)의 패인 — 전부 현행 표준이 이미 금지한 것

무성 키스 안무 20컷(§대사-forward 위반) · 동의 신사 남주("먼저 네가 원하는 걸 말해" = 순둥이 금지 위반) · 엔진 서브리미널 처리 · 디졸브 수위 회피 · 독백형 주체성. **교훈: THE OFFERING 시대 원고는 현행 표준 검수로 그 자리에서 죽는다 — 표준이 작동한다는 역증.**

## 다크 로맨스 레슨 (OFFERING 리부트용)

- **양측 송곳니:** 여주 주체성 = 대사 독백이 아니라 행동(물고·무릎 차고·넘어뜨려 올라타고·"입 닥쳐, 그리고 날 만족시켜" 명령). 남주 = 포식 개시 → 여주 반격에 충격+집착 전환.
- 섹스 = 매 물리 비트에 소유·도발 대사를 박아 드라마화(끈 찢기·깨물기·피 OK — 무성 안무가 되는 순간 포르노).
- 운명 연결고리(저주 진정)는 살 맞닿는 순간 화면으로 + 남주 OS로 즉시 명명.

## 남성향 레슨 (TITAN BORN 리부트용 — 中 개편 실증)

1. **절정 프롤로그 → 박탈 → 바닥:** 풀파워로 개막(신산 습격 = 광고 컷+천장 약속) → 배신(연인이 묶음) → 신이 **이름+기억 박탈** + 추방. 바닥에서 시작하면 천장 약속이 없어 미스터리가 된다(원본의 패인).
2. **로어 대신 룰:** 예언/시질(lore) 금지 — 빌런 입으로 선언되는 게임 룰("이름을 되찾지 못하는 한 너는 짐승") + **숫자 카운트다운 퀘스트**("100승이면 이름 반환" — 현재 99승에서 개막).
3. **기대 붕괴 훅:** EP1 END "나는 이름이 있다!" → EP2 첫 컷: 기억나지 않음.
4. **한 사건 다화:** 최종 결투 1개 = 6화(난입 괴수→빌런 파워 시위→받아내기→신력 강신→사슬 기습→공개 굴종 강요→각성).
5. **여성 2포지션:** 배신 연인(메인 그리번스) + 소유욕 퀘스트기버("내 곁에 남으면 이름을 주겠다" → 거절 = 남주 격 증명).
6. **모욕→각성→절단 보상:** 채찍·신발 핥기 강요·군중 하이에나 콜 → 각성 일갈("내 이름은 X다!") → 사지 절단급 보상 + 신상(神像)에 금 가는 상징 컷. 남→남 폭력 상한 없음(F-5).

**Why:** 같은 기획이 정보 출납 속도·엔진 가시화·양측 송곳니에서 갈렸다. 숨기는 원고는 "세련"이고, 선포하고 실연하는 원고가 팔린다.

## 남성향 추가 실증 (2026-06-12 — 신의한방 46화·K축구 77화 역대본 정독)
