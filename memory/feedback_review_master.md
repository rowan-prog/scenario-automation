## 4. 검토 공격성 프로토콜 (필수)

페르소나 구성은 충분 — 검토 모드의 공격성·증거 요구·통과 기준이 약하면 통과가 쉬워짐.

**모든 phase_5·phase_7 검토에 강제:**

1. **의심 지점 사전 스캔 5+건** — 검토 시작 시 의심 지점 5건+ 먼저 스캔
2. **모든 판정에 원문 FIND 인용** — 등급(🔴/🟡/🟢) 또는 통과 모두 EP/S#/블록/원문 인용 동반. 추상 평가 ("좋다", "작동한다") 금지
3. **"검토했으나 유지" 1-3건 필수** — 의심해서 스캔했으나 검증 후 문제 아닌 지점 별도 섹션 기록 — "그냥 통과" 차단
4. **취향과 결함 분리** — 취향 개선은 🟢 또는 "검토했으나 유지" / 실제 결함만 🔴/🟡
5. **시청자 페르소나 (08/09) "작동" 판정 단독 통과 사유 X** — 05·07·04 중 최소 2명 원문 근거로 재판정 후 통과
6. **최종 verdict 3-tier (phase_7)** — LOCK / PATCH THEN LOCK / HOLD. HOLD 잔존 시 4-Gate 진입 불가
7. **전체 재작성 제안 금지** — 최소 수정 단위만 제안. 재설계는 phase_3 단계

## 5. 검토 채택 필터 (필수)

검토 결과의 권장 패치는 phase_6에서 **두 단계 필터**로 채택 판정.

### 필터 1 (채택 필수)
- 공간 논리 / 시간 논리 / 소품 위치 / 인과 논리 / 정합성 오류 / 언어 일원화 위반
- → 무조건 수정

### 필터 2 (채택 거부)
- 프로덕션 가이드 위반 / 작품 핵심 쾌감 약화 / 캐릭터 매력 약화 / 안전·밋밋 누적 처방
- → 거부, 보류 항목에 사유 명시

**판정 흐름:** 필터 1 매칭 → 즉시 채택 (필터 2 검사 X). 필터 1 미매칭 → 필터 2 검사. 의심 시 부분 채택 가능.

## 6. 라운드 = 전수검사 (필수)

- 매 라운드 검토는 작품 **전 화수 일괄**
- 패치된 화만 선별 검토 X
- **ripple 영향 점검 필수** — 한 화 패치가 다른 화에 영향

## 7. 라운드 독립 검토 (필수)

- 각 라운드는 이전 라운드와 **완전히 독립** Fresh 검토
- Round N은 Round N-1의 발견·판정 **참조 금지**
- "이 작품을 처음 보는 마음"으로 평가
- 이전 패치 부분도 특별 취급 X — 동일하게 fresh 검토

### 이유
- **AI는 같은 페르소나로도 다른 결과 산출** (확률적 출력)
- 같은 라운드 다른 결과 ≠ 잘못 / 작품 다각도 진단의 본질
- 라운드마다 다른 페르소나 결과 = 작품 결함 발견 확률 ↑
- 선별 호출 (예: "이번엔 03만") = 사각지대 위험

### 패치 후 재검토 시
- phase_6 패치 → phase_5 재진입 시 **다시 전 페르소나 전수 호출**
- 이전 라운드 통과한 페르소나도 다시 호출 (라운드 독립 + AI 확률성 보정)
- 패치된 화만 보면 안 됨 / 전 화수 일괄 + 전 페르소나 적용

### 비변경 원칙
- 토큰 절감 명목으로 페르소나 선별 호출 X
- 라운드 단축 명목으로 페르소나 일부 생략 X
- 같은 결과 재발견 명목으로 페르소나 호출 중복 회피 X
- **이 룰은 토큰 비용보다 우선** (사용자 명시 절대 룰)
