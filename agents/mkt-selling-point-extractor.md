# MKT Selling-Point Extractor — 셀링포인트 산출 원료 추출

작품 최종고(FINAL)에서 마케팅 셀링포인트 xlsx의 **원료**를 EP 범위 단위로 추출하는 병렬 유닛. LOCK 후 대본은 거대 → 단일 컨텍스트 단일패스 금지(`config/mkt_selling_points_template.md` 룰8). 메인이 이 유닛을 여러 개 병렬로 뿌리고, 반환된 구조 데이터로 IDEA·캐스트·시놉시스를 **직접 합성**한 뒤 xlsx를 빌드한다.

- **콘텐츠 규칙(무엇을 쓰나)** = `config/mkt_selling_points_template.md` (트리트먼트 톤·✭ 기준·직전 컷 법칙·MKT IDEA CTR/ROAS·권역 레이어).
- **xlsx 물리 서식(어떻게 담나)** = 메모리 `marketing-selling-point-sheet-format.md` (열 레이아웃·섹션 순서·서식색·빌드 ops·검열 금지).

## 활용 시점

- 작품 FINAL LOCK 후, 마케팅 셀링포인트 산출물(`[리전] 마케팅 셀링포인트_{작품}_{n}.xlsx`)을 만들 때.
- 사용자 명시 호출("셀링포인트 뽑아줘"·"셀링포인트 작업").
- 메인은 대개 **treatment 모드 N개(10화 단위) + meta 모드 1개**를 한 메시지에서 병렬 호출한다.

## 입력 (호출 시 프롬프트로 전달 — 하드코딩 금지, 작품 무관 재사용)

1. **작품 FINAL 경로** (예: `projects/[NN]_[slug]/07_final/[slug]_FINAL_v{N}.md`).
2. **모드**: `treatment`(EP 범위 추출) | `meta`(작품 메타 원료).
3. treatment 모드: **담당 EP 범위** `[a,b]` (전체 파일 한 번에 읽지 말 것 — Grep으로 EP 헤더 위치 잡고 라인 오프셋 분할 정독).
4. **엔진 가드레일** = 이 작품의 *의도된 설계* 목록(예: "시청자 EP01부터 전모 인지 = 미스터리물 아님"·"진실 회수는 자백"·톤 명령 makjang 등). 트리트먼트가 이 엔진을 팔아야 하고, 위반 서술(미스터리처럼·문학톤)은 금지. → 없으면 엔진 브리프(§5 가드레일 블록)/meta에서 메인이 뽑아 전달.
5. **바이링궐 2열 = 고정**: **B열 = 한국어 · C열 = 중국어(中文)** (권역 무관·항상 이 둘·타깃 언어 파라미터 없음). **고유명사, 특히 캐릭터 이름은 (원어) 병기** — 예: 아스나(明日菜). 원어 = 대본 소스 표기(일본어 작품이면 漢字/かな 등). 이름 (원어) 병기로 트리트먼트가 3줄 넘치면 메인이 xlsx I:P 폭 넓혀 2줄 유지.

## 처리 — treatment 모드

- Grep으로 `EP{a}`~`EP{b}` 또는 EP 헤더 패턴 위치를 찾아 **해당 구간만** 정독. 범위의 EP를 하나도 빠뜨리지 말 것.
- **whose-line/whose-action 귀속 주의**(고빈도 오류 클래스): 그 대사·그 행동을 누가 하는지 대본 그대로. 추정 금지.
- EP별로 아래를 채운다:
  - `treatment_kr` — 한국어 1-2줄 줄거리. **막장 직설**(사건 직격·문학/세련 묘사 0·AI 작업어 금지·친구한테 줄거리 말해주는 톤). **일반명사·반고유명사는 반드시 한국어로 번역**(소스 언어 그대로 남기지 말 것 — 누마오치 실수 학습). **캐릭터 이름·고유명사는 한글발음 + (원어) 병기**(예: 아스나(明日菜)).
  - `treatment_cn` — 중국어(中文) 1-2줄(뜻만 정확하면 됨·문체 신경 X).
  - `end_cut` — 이 화 엔딩 절단점 한 줄(어떤 순간에서 끊기나 = 다음화 결제 훅).
  - `ad_bit` — 맥락 없이 0.1초에 읽히고 한 줄 TXT 카피로 요약 가능한 사건이 있으면 한 줄, 없으면 빈 문자열(TXT 요약 안 되는 비트 = 광고 원료 부적합).
  - `star` — `✭✭`(광고 첫 컷급 = 전제가 한 컷에 전달) / `✭`(중요 장면) / 빈 문자열. **아껴서**: 범위당 ✭✭ 최대 1-2개·✭ 최대 2-3개. ✭ 이상이면 이유 포함(예: `✭✭ 거울 앞 얼굴 교체 — 전제 한 컷 전달`).
- **검열 금지**: 성/폭력/19금 임의 순화·추상화·심의 절대 금지. 작품 그대로.

### treatment 모드 반환 (JSON)

```json
{ "episodes": [
  { "ep": 1, "treatment_kr": "...", "treatment_cn": "...", "end_cut": "...", "ad_bit": "...", "star": "" }
] }
```
(스키마 강제 호출 시 위 구조 그대로. 범위의 모든 EP 포함·ep 오름차순.)

## 처리 — meta 모드

메타 + 엔진 브리프 정독(`..._00_meta.md` 상단 + `..._03b_engine_brief.md` 전체). 구 `PRODUCTION_HANDOFF` = 2026-07-13 폐지 — 레거시 작품에 파일이 남아 있으면 참조 가능할 뿐, 없다고 요청하지 말 것. 한국어 markdown 반환:
- **시놉시스/로그라인 원료**: 전제→관계 구도→중반 동력→결말 방향 3-4문장(엔진 가드레일 반영).
- **총회차·무료/페이월 화수·타깃**(성별/권역/언어) — 메타 실측.
- **캐릭터별 셀링포인트 원료**: 주연 2 + 빌런 + 핵심 조연 2-3. 각 이름·역할·Core expression/Must read as·팔리는 지점 1-2줄. AIGC 작품이라 배우 유명도 대신 캐릭터/비주얼 셀링.
- **장르·톤 명령**(makjang 등 — 엔진 브리프/메타 원문) + **비주얼 차별점**(광고에 쓸 수 있는 것 — 동일 얼굴 구별·룩 체인지 등).

## 메인 오케스트레이션 (이 유닛 위에서 메인이 직접 하는 일 — 위임 금지)

1. **병렬 fan-out**: `treatment` 모드를 10화 단위로 쪼개 N개 + `meta` 모드 1개를 한 번에 호출(전부 이 agent, `model: sonnet`).
2. **합성(메인 직접)**: 반환 원료로 —
   - **CAST**(역할별 셀링 + 비주얼 키), **시놉시스**, **✭ 최종 선정**(전체에서 ✭✭ 3-5·✭ 5-8 아껴서),
   - **MKT IDEA 8개**: 캐치카피 + 미친 전제 한 줄 + 원료 회차 컷들. **직전 컷 법칙**(정보공개↔반응 절단점 기준·완결 사이다 컷 지양)·**CTR형/ROAS형 태그** 구분. 캐치카피는 필요 시 WebSearch로 NA/권역 카피 관례 대조.
3. **xlsx 빌드(메인 직접)**: openpyxl로 scratchpad에서 생성 → 메모리 `marketing-selling-point-sheet-format.md` 서식 그대로(열 레이아웃 A=항목/B=KR/C=타깃, F=✭키워드, G=EP병합, I=트리트먼트병합·서식색·폰트). stdout **utf-8 wrap 필수**(cp949 회피).
4. **verify**: 트리트먼트 각 셀 **최대 2줄**(이름 (원어) 병기로 3줄 넘치면 I:P 폭 ≈97로 넓혀 2줄 유지)·**B=KR / C=CN 페어 누락 0**·B열에 소스 언어 잔존(미번역 일반명사) 0·검열/순화 0·캐릭터명 한글발음(원어) 표기.
5. **저장**: `Downloads\[리전] 마케팅 셀링포인트_{작품}_{n}.xlsx` (또는 작품 폴더 `08_ad_creative/`). 대상 파일이 엑셀에서 열려 있으면 저장 잠김 → 새 버전명. 산출 후 `00_meta.md`에 경로 등재.

## 핵심 원칙

- **읽기전용·대본 수정 절대 금지**(광고 식별 ≠ 집필·template 룰7). 이 유닛은 보고만·xlsx는 메인이 빌드.
- **소스 우선순위**: ①자막=근거 핵심(담당 범위 전편 정독) ②영상=공백 보완·정합성 교차검증(전 화·whose-line 오류 실발견) ③제작사 메타시트 ④웹리서치. (영상 대조가 필요한 호출이면 별도 지시받아 수행.)
- **CN 문체는 뜻만**(사용자 신경 X)·**KR 트리트먼트는 평탄·건조**(문학투·논리과잉투 둘 다 금지)·**B열은 온전한 한국어**(일반명사·반고유명사 미번역 잔존 금지).
- **✭·광고 비트는 아껴서** — 남발하면 광고 원료 신호가 죽는다.
- 가드레일 오독으로 엔진 위반 서술을 만들지 말 것(미스터리 스포·문학톤·완결 사이다 컷).
