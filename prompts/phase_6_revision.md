패치를 적용한 전체 스크립트.

## 수정 원칙
- FIND는 실제 스크립트의 정확한 문장. 기억으로 쓰지 않는다.
- REPLACE는 바로 붙여넣을 수 있어야 한다.
- 하나의 패치는 하나의 문제를 해결한다.
- 패치가 새 문제를 만들 가능성이 있으면 보류한다.
- 상위 구조 결함을 대사 한 줄로 봉합하지 않는다.
- 캐릭터 매력을 약화시키는 수정은 하지 않는다.
- 안전하지만 밋밋해지는 수정은 하지 않는다.

## 검토 채택 필터 (필수)

검토 보고서의 모든 권장 패치는 **다음 두 단계 필터로 채택 여부를 판정**한다. 강도 높은 검토라 해도 무차별 적용 X.

### 필터 1 — 채택 필수 (반드시 수정)
다음 영역의 결함은 **무조건 수정**한다 (필터 2와 무관):
- **공간 논리** — 캐릭터 위치·이동 경로·공간 배치 모순.
- **시간 논리** — 시간 줄·이벤트 순서 모순.
- **소품 위치 논리** — 회차 간 소품의 위치·소유·이동 모순.
- **인과 논리** — 사건 ↔ 원인 ↔ 결과 모순.
- **정합성 오류** — 청사진 락 vs 본문 모순, EP 간 캐릭터 상태 모순, 비주얼 락 vs 본문 모순.
- **언어 일원화 위반** — 영어 일원화 작품의 한국어 잔존 (한국어 메타·footer 잔존).

이 영역은 시청자에게 직접 노출되는 기본 논리 공백 — 수정하지 않으면 작품 신뢰도 손상.

### 필터 2 — 채택 거부 (수정 금지)
다음 영향이 있는 권장 패치는 **거부**한다:
- **프로덕션 가이드 위반** — `config/production_guide.md`의 Hard Lock·Soft Lock 영역 침범.
- **작품 핵심 쾌감 약화·소실** — 작품의 장르 약속·정복 보상·친밀 핵심·페이월 spectacle을 약화시키는 처방.
- **캐릭터 매력 약화** — 캐릭터 voice·정체성 약화.
- **안전·밋밋 누적** — 위험 회피용 수정이 누적되어 작품이 무색무취해지는 처방.

거부된 권장 패치는 패치 로그 "보류 항목"에 **거부 사유 명시**.

### 판정 흐름
1. 검토에서 등급(🔴/🟡/🟢) 받은 결함을 영역별로 분류.
2. **필터 1 매칭 → 즉시 채택** (필터 2 검사 X — 정합성·논리는 핵심 쾌감보다 우선).
3. **필터 1 미매칭 → 필터 2 검사** → 핵심 쾌감 영향 없으면 채택, 약화 처방이면 거부.
4. 거부된 권장 패치는 보류 항목에 사유 기록.

### 흔한 거부 사례
- "캐릭터의 face break 묘사가 multi-emotion → single dominant로 명료화" — 핵심 쾌감(시각 보상의 두께) 약화 가능. 거부.
- "권력 line을 modern English에서 archaic으로" — 캐릭터 voice 자율성 약화. 거부 가능.
- "페이월 spectacle wide shot을 컷 분리" — [Camera] 컷 분리만 채택, [Visual] 묘사 유지 (spectacle 보존).

### 흔한 채택 사례
- "EP6 epaulet S#5에서 deck plate에 떨어졌는데 [End Image]에서 RAVEN-9 손에 있음" — 소품 위치 논리. **채택 필수.**
- "EP18 surgical implement EP19 시작 시 위치 미확정" — 소품 위치 논리. **채택 필수.**
- "EP44 ceremonial gavel DRAVEN 손에서 후속 화 위치 미확정" — 소품 위치 논리. **채택 필수.**
- "청사진 락 vs 본문 단계 진화 불일치" — 정합성. **채택 필수.**

## 패치 우선순위 (말맛 보존 원칙)

> "사소한 오류는 없다 — 오류는 사이즈 무관 수정. 동시에 말맛은 최대한 살려야 한다."

1. **물리·논리·정보 오류 (🔴 catastrophic + 🟡 03/05/07/08/09 자동 trigger)** — 무조건 수정.
2. **시각 표지·소품 일관성 (🟡)** — 수정. 룩 변형 락 위반 시 즉시.
3. **광고 응축·페이월 강도 (🟡 05)** — 수정.
4. **대사 cadence·톤 (🟡 04)** — **신중 수정.** 캐릭터 voice 손상 위험 우선 점검. 말맛 죽이는 수정 금지. 가능하면 cadence 유지 + 단어 한두 개만 정정.

말맛 보존이 가장 중요한 영역: 캐릭터의 단언형 대사·짧은 명령형·자제력 표현·문어체 cadence. 이것들이 캐릭터 정체성. 의미 명료화를 위해 cadence 무너뜨리지 말 것.

### 처방 결정 규칙
1. 시청자 코드 기준 1차 처방 영역에 해당하는 제작 페르소나의 검토 보고서와 교차 검증.
2. 두 보고서 모두 결함 인정 시 즉시 패치.
3. 시청자만 코드 표기, 제작 페르소나는 결함 없음으로 판정 시 — **시청자 코드를 우선 채택** (시청 반응이 정합성보다 결제 동력에 가깝다). 단, Soft Lock 영역 위반 의심 시 보류 (예: F-G 다른 여성 잔혹 처리는 작품 톤 자율 영역일 수 있음).
4. 시청자 코드를 보류 시 패치 로그 "보류 항목"에 사유 기록.

## 라운드 한계

패치 라운드는 **최대 5회**까지 진행한다. 5회 이후에도 같은 문제가 반복되면 사람 판단으로 넘긴다 (production_guide Section 22).

### 주의 — 라운드 한계는 창의성 잠금 도구가 아니다 (Section 0-3)

5회 한계는 **무한 루프 방지를 위한 Hard Lock**이다.
그러나 그 안에서 **Soft Lock 영역(톤·대사 방식·인티머시 강도·캐릭터 매력 등)을 강제 표준화하지 않는다.**

"라운드를 채우기 위해" 안전하지만 밋밋한 수정을 누적하지 않는다.
과도한 락은 작품을 무색무취하게 만든다 (수정 원칙 — 나쁜 수정 / production_guide Section 22).

### 라운드 카운트 판단 기준

- **새 문제가 발견되어 패치** → 정상 라운드 카운트.
- **같은 페르소나의 같은 문제가 3회 반복되면** → "작품 자율 영역(Soft Lock)" 또는 "취향 차이"로 분류해 보류. 라운드 소비하지 않음.
- **5회 도달 시** → 라운드 6 진행 전 사람 판단 요청. "Round 5 완료. 같은 문제가 반복되어 사람 판단이 필요합니다." 라고 안내.

### 라운드 = 전수검사 (필수)

각 라운드 검토(phase_5 호출)는 **작품 전 화수 일괄 수행**. 직전 라운드 패치된 화만 선별 검토 X.

**근거:** 시퀀스 작품에서 일부 화 패치는 다른 화에 ripple (정보 설계·시각 표지·캐릭터 캐논·관계 변화·광고 응축) 영향. 패치 안 한 화도 매 라운드 독립 재검토 필요.

**자연 종료 조건:**
- 전수검사 결과 모든 화 무결 (🔴·🟡 0건) + 4-Gate 모든 화 통과 → 최종고 확정.
- 또는 라운드 5 도달 + 결함 반복 → 사람 판단 요청.

### 사람 판단 후 분기

라운드 5 도달 → 사람이 판단한 후 다음 중 하나로 진행:

- **A. 추가 라운드 진행** (사람이 명시적으로 권한 부여 시) → phase_5 재검토 → phase_6 재패치. Soft Lock 강제 표준화 위험에 유의.
- **B. 최종고 게이트 진입** → phase_7 (최종고 게이트 평가). 4-Gate 통과 여부 평가 후 통과 시 최종고 확정.
- **C. 청사진 단위 재작업** → phase_3 (메인) 또는 phase_a_1 (각색)으로 돌아가 캐릭터 캐논·세계 규칙 단위 재설계.
- **D. 작업 보류 / 폐기** → 사람 판단으로 작업 종료.
