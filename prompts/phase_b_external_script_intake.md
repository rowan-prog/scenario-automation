# Step B-1 — 외부 AIGC 대본 등재·평가 프롬프트 (부가 트랙 B)

## 역할
외부에서 만들어진 AIGC용 대본(인간 작가 / 외부 AI / 협력사 / 위탁 등)을 받아서 다음을 수행한다:
1. 작품 폴더에 등재
2. 1차 게이트 평가 (production_guide Section 23 4-Gate 기반)
3. 후속 작업(검토→수정 루프) 진입 가능 여부 판정

**대본만 가지고 평가한다.** 청사진·러프 청사진은 요구하지 않는다.

  - Section 3 (핵심 제작 원칙)
  - Section 3-2 (쾌감 전달 방식 분류)
  - Section 5-3 (포맷 선택 — 실사형 vs 애니메이션 일관성 체크)
  - **Section 5-5 (회차 설계 ROI 게이트 — 외부 대본의 편당 길이·총 화수·총 러닝타임이 기준 범위 내인지 점검. 2026-05-15: 편당 ≤2분 / 총 ≤90분 / 50화 / 무료 1-8화)**
  - Section 6 또는 7 (포맷별 원칙)
  - Section 9-1 (남성향 선언형 대사 5조건 — 남성향 작품일 때)

## 작성 원칙

### 대본만으로 평가 (청사진 불필요)

외부 대본은 청사진을 동반하지 않을 수 있다.

- 청사진 정합성 체크(phase_5의 일부)는 보류.
- "캐릭터 캐논 위반"은 **대본 안에서 같은 캐릭터의 행동·대사가 일관되는지**로 판정.
- "세계 규칙 위반"은 **대본 안에서 같은 규칙이 다르게 작동하는지**로 판정.
- "정보 공개 순서"는 대본 안에서 reveal의 단어 분리가 유지되는지로 판정.

### Hard Lock 위반만 결함 (Section 0-3)

평가는 **Hard Lock 영역**에 집중한다.

- 포맷 분류 (실사형/애니메이션 일관성)
- 씬 끝 변화 룰
- Visual 물리 정보 룰 (추상 감정 지문 비중)
- 무료 구간 수렴 룰
- AIGC 구현 가능성

**Soft Lock 영역(톤·대사 방식·인티머시 강도·캐릭터 매력·대사 길이·카메라 직접성)은 평가 대상이 아니다.**
"이 톤이 다크해서 / 인티머시가 약해서 / 대사가 짧아서" 같은 지적은 하지 않는다 — 이것은 작품 자율 결정.

### 즉시 발견 결함 우선

종합 등급보다 **즉시 발견된 핵심 결함**을 더 강조한다.

- 패치 가능한 결함과 구조 재설계가 필요한 결함을 명확히 분리.
- 한 가지 결함이 여러 게이트에 영향을 미치면 가장 상위 게이트에서 보고.

### 9-1 5조건 적용 (남성향 작품일 때)

남주의 선언형 대사는 시점·구간으로 일률 잠금하지 않는다.
**5가지 작동 조건(누가/언제/장르/톤/다음 행동)을 통과하는가**로 판정.
3개 이상 통과면 OK, 통과 안 되면 결함으로 분류.
