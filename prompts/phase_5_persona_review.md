## Verdict 4단계 (필수 산출)

각 페르소나는 검토 후 반드시 4 verdict 중 하나 산출:

| Verdict | 의미 | 발생 조건 |
|---|---|---|
| **통과** | 결함 0건 | 🔴·🟡·🟢 모두 0건 |
| **조건부 통과** | 미세 개선 영역 | 🟢만 발견 (페르소나별 가변 적용) |
| **패치 필수** | 수정 의무 | 🔴 또는 🟡 발견 |
| **재설계** | 구조 결함 | 청사진 단위 재작업 필요 (Hard Lock 다수 위반) |

전수검사 시 모든 페르소나의 verdict 합산 — **하나라도 "패치 필수" 또는 "재설계" → 4-Gate 진입 불가** (phase_6 패치 후 재검토 강제).

## 공격적 검증 프로토콜 (필수 — 최종고 검토 시 우선)

페르소나 구성 자체가 부족한 게 아니라 **검토 모드의 공격성·증거 요구·통과 기준이 약하면 통과가 너무 쉬워진다.** 다음을 강제한다.

### 1. 의심 지점 사전 스캔 (필수)
검토 시작 시 **반드시 최소 5건 이상의 의심 지점을 먼저 스캔하고 나열**한다. 그 후 검증을 거쳐 실제 문제인 것만 🔴/🟡/🟢로 분류한다. 스캔 지점이 5건 미만이면 검토가 너무 가볍다는 신호 — 다시 스캔.

### 2. 증거 기반 판정 (필수)
**모든 등급 판정은 원문 인용을 동반**한다. 다음 형식으로:

```text
위치: EP[N] / S#[번호] / [Visual|Camera|DIALOGUE|FX]
원문 FIND: "<해당 라인 또는 단락의 정확한 인용>"
왜 문제: <인용을 근거로 한 진단>
수정 필요 여부: 🔴 / 🟡 / 🟢 / 검토했으나 유지
수정 방향 (있을 때만): <최소 수정 단위, 취향 개선 X>
```

추상 평가(`"좋다"`, `"작동한다"`, `"자연스럽다"`, `"이대로 통과 가능"`) 금지. 통과 판정도 **원문 근거 없으면 무효**.

### 3. "검토했으나 유지" 항목 (필수)
의심해서 스캔했으나 검증 후 문제 아닌 것으로 판정된 지점 **1-3건을 별도 섹션으로 기록**한다. 이는 검토자가 실제로 의심해 봤다는 증거 — "그냥 통과"를 차단한다.

```text
## 검토했으나 유지
1. EP[N] / S#[번호] — 의심: <무엇이 문제일 수 있다고 생각했는가>
   검증 결과: <왜 문제 아닌가, 원문 FIND 동반>
```

### 4. 추상 평가·전체 재작성 제안 금지
- "전반적으로 좋음" 류 추상 평가 금지.
- "이 회차를 다시 써야 함" 류 전체 재작성 제안 금지. **최소 수정 단위만 제안.**
- 취향 개선과 실제 결함을 분리 — 취향은 🟢 또는 "검토했으나 유지", 결함은 🔴/🟡.

### 5. 시청자 페르소나(08/09) → 제작 페르소나 재판정 (필수)
시청자 페르소나는 진단만 — 처방 권한 없음. 그러나 **08/09가 "작동/약함" 판정을 내려도 그 판정은 단독 통과 사유가 아니다.** 다음 페르소나가 재판정한다:
- 08/09 "작동" → **05 (Commerciality) + 07 (Genre Pleasure) + 04 (Dialogue Voice)** 중 최소 2명이 같은 부분에 대해 **원문 근거**로 작동 확인.
- 08/09 "🟡 약함" → 이탈 코드(M-A~J / F-A~L)를 처방 영역에 매핑 (메모리 `feedback_question_alarm.md` 외 — 위 자동 trigger 표 참조). 매핑된 페르소나가 패치 처방.

### 6. 활성화 페르소나 재확인 (작품 타깃 정렬)
"전체 순차" 호출 시 활성화 페르소나는 작품 타깃에 정렬한 1개 시청자만:
- 남성향: 01-07 + 08. **09 비활성화 (검토 X).**
- 여성향: 01-07 + 09. **08 비활성화 (검토 X).**
- 혼합·전연령: 01-07만.
잘못된 시청자 페르소나 활성화는 잡음 + 타깃 상실 위험.

## 라운드 = 전수검사 + 독립 검토 (필수 규칙)

각 라운드의 검토는 **작품 전 화수(예: 50화)에 대해 일괄 수행 + 이전 라운드와 완전히 독립**한다.

**독립 검토 원칙:**
- Round N은 Round N-1의 발견·판정·결과를 **전혀 참조하지 않는다.**
- Round N은 **"이 작품을 처음 보는 마음"**으로 fresh 검토.
- Round N은 작품의 **현재 상태**(이전 라운드 패치 적용 후)를 중립적으로 평가.
- 이전 라운드에서 발견된 결함이 패치로 해소되었는지 확인하는 게 아니라, **현재 상태에 결함이 있는가**를 검토.

**근거:**
- 이전 라운드 결과를 참조하면 "이미 고친 거니까 OK" 식 편향 발생.
- 각 패치는 ripple 영향으로 새 결함을 만들 수 있음 — fresh 검토만 그것을 잡음.
- 시퀀스 작품의 정합성은 매 라운드 독립 평가가 최선.

**적용:**
1. Round N 검토 시작 시 Round N-1 보고서 참조 금지.
2. 패치된 부분도 다른 부분과 동일하게 fresh 검토 (특별 취급 X).
3. Round N에서 같은 결함이 다시 발견되면 정상 — 패치가 충분치 않았거나 새 ripple 발생.
4. phase_6 라운드 한계(5회) 카운트는 독립 검토 라운드 수.

**근거:** 시나리오는 시퀀스 작품. 일부 화 변경 시 다른 화에 다음 ripple 영향이 발생:
- **정보 설계 ripple** — 한 화의 정보 공개 시점·강도 변경이 다른 화의 정보 장벽·reveal 어휘 분리에 영향.
- **시각 표지 ripple** — 한 화의 시각 신호(권능 발현·룩 변형·소품 등장)가 다른 화의 단계 누적·시각 일관성에 영향.
- **캐릭터 캐논 ripple** — 한 화의 캐릭터 행동·대사 변경이 다른 화의 캐논 곡선에 영향.
- **관계 변화 ripple** — 한 화의 관계 발전 강도 변경이 다른 화의 관계 진화 단계에 영향.
- **광고 컷 / 페이월 응축 ripple** — 한 화의 광고 컷 강화가 페이월 응축의 단일성에 영향.

**적용:**
1. 모든 라운드(Round 1·2·3·...)는 **작품 전 화수 일괄 검토**.
2. 직전 라운드 패치 적용된 화는 패치 후 상태로 검토.
3. 패치되지 않은 화도 ripple 영향 확인 위해 재검토 (이전 라운드 검토 결과 그대로 복사 X — 매 라운드 독립 검토).
4. 효율성 위해 통합 보고서(Arc-level 또는 전체 batch) 가능하나, 검토 범위는 항상 전 화수.
5. 라운드 카운트(5회 한계)는 전수검사 라운드 카운트.

## 검토 원칙

### 단일 사건축 / 분산 검토

- 먼저 Conversion Runway 구간 (EP1-페이월·자연 흐름)의 핵심 질문을 한 줄로 적는다. 한 줄로 적히지 않으면 구조가 분산된 것이다.
- 각 회차가 같은 압력을 키우는지, 아니면 서로 다른 사건축을 추가하는지 검토한다.
- 반복 보상은 기본적으로 감점한다. 같은 모욕과 같은 참교육이 반복되면 긴장이 누적되지 않는다.
- 단, 반복되는 숏폼 보상 루프를 자동 결함으로 보지 않는다. 먼저 `결핍 -> 반전 보상`의 원초 보상축이 고정되어 있는지 확인한다. 매 루프가 무대, 증인, 증거물, 지위, 금액, 관계 판정, 공개성, 보상 크기를 바꾸면서 같은 시청자 욕망을 지불하면 사건 분산이 아니라 클립 보상 반복으로 본다.
- paywall이 정보·과거·설정 궁금증에 기대면 약점으로 본다. 행동의 결과를 보게 만드는지 확인한다.
- 남성향은 권한·군대·영토·무기·여성 캐릭터가 주인공의 지배/소유/통제 확장으로 묶이는지 본다.
- 판타지/AIGC 애니는 같은 압력축 안에서 대형 VFX·스케일 보상이 커지는지 확인한다.
- Section 20의 수정 우선순위를 따른다.
- 진짜 오류 / 약점 / 선택 개선 / 취향 차이를 반드시 구분한다.
- 모든 문제를 고치려 하지 않는다. 우선순위를 명확히 한다.
- 청사진과 충돌하는 내용은 무조건 🔴 즉시 수정으로 분류한다.

### 분위기/상징 vs 감정 거래 검토

- 장면이 분위기, 상징, mark, 침묵, 고급 문장, 세계관 암시로만 강해 보이고 paid vertical 감정 거래가 비어 있으면 결함으로 본다.
- 다음 질문에 답한다: `누가 모욕/오판/위협했는가? 정확히 뭐라고 했거나 무엇을 했는가? 누가 봤는가? 시청자는 무엇이 되갚히길 기다리는가? 여주/주인공은 무엇을 선택했는가? 장면 뒤 관계·지위·안전·위험·권한 중 무엇이 바뀌었는가?`
- 국가, 제국, 가문, 의회, 문서, 법, 예언, seal이 빌런 역할을 대신하고 구체적인 얼굴/목소리의 가해자가 없으면 🟡 또는 🔴로 본다.
- 여주/주인공의 모욕과 핍박이 설정 설명이나 문서 언어에만 있고, 현재 장면 또는 짧은 플래시백/몽타주로 체감되지 않으면 paid vertical 압력이 약한 것이다.
- 여성향 다크 로맨스에서 여주 agency가 남성향식 `군림/갑질/전쟁 선포`로 바뀌면 장르 오독으로 본다. 공포 속에서도 선택·거래·거절·counter-claim을 하는지 본다.
- 접촉 장면은 관계 규칙을 바꿔야 한다. 목, 손목, bite, mark, hair, lap, near-kiss가 반복되는데 leverage, consent/refusal, public status, protection, threat, next action이 안 바뀌면 분위기 과잉으로 본다.
- `Yours`, `Mine`, `Wife`, `Mate`, `Chosen`, `Body`, `Kneel` 같은 결정 대사가 사전 압력 없이 나오면 치명적인 대사가 아니라 작위적 선언으로 본다.
