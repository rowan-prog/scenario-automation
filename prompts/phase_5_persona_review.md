# Phase 5 — 검수 (LOCK 전 패널·구간 검수)

> **v4 (2026-06-05 전면 재작성):** 9/10-페르소나 전수 라운드·페르소나 00 verdict·자동 전수 호출·시청자→제작 재판정 체인 = 전부 폐기 (token-diet 룰3·운용 룰). 현행 = **fresh-context agent 패널 + 쇼러너(메인) 통합 판단.** 운용 단일 진실 = `config/agent_operating_rules.md`.

## 역할

집필/수술이 끝난 구간(또는 전편)을 fresh 눈으로 검수한다. **검수는 정기 라운드가 아니다** — 투입 시점은 운용 룰 §4 (무료부 완성 시·LOCK 전·대수술 후·사용자 명시 시).

## 적용 순서 (고정 — 운용 룰 §1)

**① 엔진 판정 → ② 구조/쾌감 → ③ 대사 → ④ 정합성/포맷.** 엔진 미확정 상태에서 ③④ 투입 금지. 이 순서가 무너지면 line-polish만 하다 핵심 쾌감을 놓친다 (실패 전례 v34·v37).

### ① 엔진 판정 (쇼러너 직접 — 최우선)

- 기준 = 작품 **engine brief** (`[작품]_03b_engine_brief.md` §1·§5). 없으면 먼저 작성.
- 질문: 이 구간에서 장르 쾌감 엔진이 살아 있는가? 엔진 금지 목록 위반은 없는가? 장르 정체성 변질(예: 막장 복수극 → 수사 스릴러 드리프트)은 없는가?
- 엔진 결함 발견 = ②③④ 진행 전 먼저 처리.

### ② 구조/쾌감 — funnel-cold-reader (독립 3회+) / persona-reviewer 패널 (3-4인·LOCK 전)

- cold-read: 구간 채점 + 이탈/결제 판정. 1회 점수는 노이즈 — 수렴으로만 판단.
- persona 패널: 페르소나 시점 구조 판정 (검토 첫 섹션 = 엔진 생사·완주/결제 여부).
- **시청자 타깃 정렬:** 작품 타깃(meta·청사진 12-1)에 맞는 시청자 페르소나만. 남성향 = 08 계열·여성향 = 09 계열. 잘못된 타깃 페르소나 = 잡음.

#### 결제 루프 7 질문 (구조/쾌감 세부 — 보존)

1. **오판** — 누가 누구를 잘못 판정하는가? 구체 대사 인용.
2. **가해자 얼굴** — 얼굴 있는 가해자인가? (집단·국가·시스템 추상 빌런 X)
3. **누적 모욕 (5-8턴)** — 모욕이 누적되는가? (2-3턴 인장 X)
4. **시청자 정보 비대칭** — 시청자만 알고 빌런은 모르는 정보가 있는가?
5. **증거물 기능** — 상징 X / 즉시 기능하는 것만? (단, prop-anchored reveal = 금지)
6. **공개역전 = 발화 + 행동 + 결과** — 단순 발화 X.
7. **시그니처 호칭** — 관계·권력·소유 표시 호칭?

→ 3건 이상 ❌ = 결제 루프 미작동 = 🔴 (③④ 진행 전 정정).

#### 분위기/상징 vs 감정 거래 검토 (보존 — load-bearing)

- 장면이 분위기·상징·mark·침묵·세계관 암시로만 강해 보이고 감정 거래가 비어 있으면 결함. 질문: `누가 모욕/오판/위협했는가? 정확히 뭐라고 했나? 누가 봤나? 시청자는 무엇이 되갚히길 기다리나? 주인공은 무엇을 선택했나? 장면 뒤 관계·지위·안전·위험·권한 중 무엇이 바뀌었나?`
- 국가·가문·문서·법·예언·seal이 빌런을 대신하고 얼굴 있는 가해자가 없으면 🟡/🔴.
- 접촉 장면은 관계 규칙을 바꿔야 한다. 접촉 반복인데 leverage·consent/refusal·public status·protection·threat·next action이 안 바뀌면 분위기 과잉.
- `Yours/Mine/Wife/Mate/Kneel` 류 결정 대사가 사전 압력 없이 나오면 작위적 선언.
- **반복 보상 판정:** 같은 압력축에서 무대·증인·증거물·지위·공개성·보상 크기를 바꾸며 같은 욕망을 지불하면 = 사건 분산이 아니라 정상 클립 보상 반복. 자동 결함 아님.

## 검수 프롬프트 의무 (운용 룰 §5)

- fresh-context·사전 결론 비공유. **가드레일 동봉:** 엔진 요약 + 의도된-설계 목록 (engine brief §5 복붙).
- 의심 지점 사전 스캔 5+건 → 검증 후 분류. 0건 발견 = 검사 강도 의심.
- **모든 판정에 원문 FIND 인용 + 위치** (`EP[N] / S#[번호] / 인용`). 추상 평가(`좋다·작동한다`) 금지. 통과 판정도 근거 없으면 무효.
- **"검토했으나 유지" 1-3건 기록** (그냥 통과 차단).
- 전체 재작성 제안 금지 — 최소 수정 단위만. 취향과 결함 분리.

## 역할 권한 (운용 룰 §2 — 침범 = 대본 너덜)

- **검수자(agent)는 보고만 한다.** 등급(🔴/🟡/🟢) + 원문 인용 + (있으면) 한 줄 처방까지. 패치 명령·구조 설계 금지.
- viewer류(cold-reader·persona) = 반응 진단만 / dialogue류 = 대사만 / fresh-eyes = 정합성만.
- **쇼러너(메인)가 전 지적을 원문 1:1 대조 → 진성만 선별 → 통합 판단.** 상충 지적은 엔진 기준으로 중재.

## 출력 (compact — 대형 보고서 폐기)

- 검수자 출력 = compact 표 (위치 | 원문 인용 | 문제 | 등급 | 한 줄 처방) + 검토했으나 유지 + verdict 한 줄.
- 쇼러너 종합 = 대화 내 **수용 N / 기각 N + 기각 공통점 한 줄** + 집행 목록. 별도 보고서 파일은 사용자 요청 시만 (`06_reviews/`).
