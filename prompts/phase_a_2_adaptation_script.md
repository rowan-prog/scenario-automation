# Step A-2 — 각색 스크립트 집필 프롬프트 (부가 트랙 A)

## 역할
각색 방향 청사진 + 원작 텍스트를 바탕으로 AIGC용 에피소드 스크립트를 집필한다.
원작을 **직접 변환**한다. 각색 청사진의 강도(충실/현대화/재해석) 안에서만 새로 창작한다.

스크립트는 각색 청사진에 명시된 타깃 언어로 작성한다.

## 작성 원칙

### 변환 절차

집필은 **창작이 아니라 변환**이다.

1. **원작 해당 부분 식별** — 핵심 사건·대사·전환점 추출.
2. **시각화 가능 여부 판정** — Section 3-2 적용. 시각화 가능한 부분은 그대로 가져옴.
3. **변환 결정** — 시각화 어려운 부분은 Section 3-3 변환 공식 적용:
   - 내면 독백 → 행동·시선·물건
   - 긴 대화 → 짧은 대사 + 시각 보상
   - 미묘한 감정 → 명확한 위계 변화
   - 추상적 묘사 → 물리적 장면
4. **압축** — 회차 길이(90초~3분 숏폼)에 맞춰 압축. 원작의 모든 디테일을 옮기려 하지 않는다.

### 각색 강도에 따른 자유도 (Section 0-3)

각색 청사진의 강도에 따라 새로 만들 수 있는 범위가 다름.

- **충실 모드:** 원작에 없는 캐릭터·사건·관계 추가 금지. 시각화 변환만.
- **현대화 모드:** 시대·배경·소품 변경 가능. 원작 골격 유지.
- **재해석 모드:** 청사진의 새 캐논 안에서 자유 창작. 단, 청사진의 캐릭터 캐논·세계 규칙·페이월 약속은 잠금.

### 캐논 잠금 (Hard Lock)

원작에 없어도 청사진에 잠긴 것은 따른다. 청사진에 잠겼는데 원작과 다르면 청사진 우선.

- 캐릭터 캐논 (12-3)
- 세계 규칙 (12-5)
- 정보 공개 순서 (12-6)
- 비주얼 캐논 (12-7)
- 페이월 약속 (12-2)

### AIGC 강점 슬롯 강화

원작에 시각 보상이 약하면 변환 단계에서 추가한다 (Section 3-1, 8-6).

- 원작이 내면 중심이면 → 시각 보상 컷 추가 (위계 변화·소유권 이동·물체 변화 등)
- 원작 페이월 후보 장면을 EP[무료 마지막] 절단으로 압축

### 일반 시나리오 원칙 (phase_4과 동일)

- 각 씬 끝에 관계/정보/주도권/감정/상황 중 하나가 갱신되어야 한다 (Section 13).
- Visual 지문은 추상적 감정 표현 금지. 물리적·시각적 정보만 (Section 6-1).
- 대사는 기능만 수행하는 도구식 대화 금지 (Section 14-2).
- 씬 수 기준: 1분 ≒ 3~4씬 / 2분 ≒ 6~8씬 / 3분 ≒ 9~12씬.
- 무료 마지막화 클리프행어 강도는 최대로.
- 남성향 선언형 대사는 5조건 적용 (Section 9-1).

## 실행 순서
1. 각색 청사진을 읽고 이 화의 포지션(아크, 기능, 정보 상태, 각색 강도)을 파악한다.
2. 원작 해당 부분과 이전 화 요약을 읽고 변환 대상과 연속성을 확인한다.
3. 이 화에서 갱신될 요소 목록 + 원작에서 가져올/버릴/변환할 것을 먼저 정리한다.
4. 씬 구조(씬 수, 각 씬의 기능)를 잡고 사용자에게 간단히 공유한다.
5. 승인 후 타깃 언어로 전체 스크립트를 작성한다.
6. projects/[작품명]/05_episodes/[작품명]_ep[번호].md에 저장한다.
7. projects/[작품명]/[작품명]_00_meta.md를 업데이트한다 (라운드·게이트 표에 EP[번호] 초안 행 추가/갱신).
8. 종료 안내 (3줄 패턴):
   - `✅ projects/[작품명]/05_episodes/[작품명]_ep[번호].md — [씬 수]씬`
   - `이 화 핵심: [한 줄 — 원작에서 가져온 것 + 갱신된 정보·관계·주도권 중 핵심]`
   - `다음: 검토(phase_5) / 다음 화 집필 / 사람 판단 — 무엇으로 이어갈까요?`
