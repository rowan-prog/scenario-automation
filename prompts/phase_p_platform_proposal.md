# phase_p — 플랫폼 기획안 (러프 → 정식 제출본 · 2026-07-16 제정)

**트리거:** 사용자가 러프 기획안(담당자·장르·로그라인·무료회차 줄거리·레퍼런스 등)을 주고 플랫폼 제출용 정식 기획안을 요청. 산출 = 플랫폼 템플릿 구조의 **KR/中文 병기 docx** (기준 = Vigloo AI Drama Proposal Template). 실제 대본(phase_4)의 상류 문서다 — 여기서 박은 엔진·금기·트리트먼트가 집필 지시서의 씨앗이 된다.

**실증 레퍼런스:** My Million-Dollar Reset (2026-07-15~16). 1차 실패 2종(외부 빌런 축 발명 → 폐기 / 원안 트리트먼트 요약 재작성+비트 발명 → "주접" 판정·전면 재작업)이 아래 대원칙의 근거.

---

## 대원칙 (위반 = 재작업)

1. **원안 = 정본.** 사용자가 쓴 로그라인·무료회차 줄거리·대사 = verbatim 계승 대상이지 요약 원료가 아니다. 빈 필드만 채우고, 원안이 있는 필드는 사용자가 지정한 축(예: 룰 쫀쫀함·긴장·로맨틱·코미디/섹슈얼)의 **어절 단위 보강**만 — 신규 사건·소품·개그·대사 발명 금지, 화당 신설 ≤1문장, 분량 ±10%. (메모리 [[develop-means-intensify-not-add-events]])
2. **로그라인 = 2~3문장, 5요소 전부 legible:** 시청자 쾌감 / 동기 / 목표 / 관계 / 수위.
3. **갈등축 발명 금지 기본값.** 특히 2인 엔진 작품에 빌런/연적 제3자 축 신설 = 무료런이 판 상품의 바꿔치기 + 남성향 쾌감 누수. 시놉시스 유료구간 위기는 엔진 내부(두 주인공의 게임)에서 발생시킨다. 결말 = 타깃 문법 준수(남성향 = 무패·회개 프레임 금지).
4. **무료런 자본 게이트 + 인월드 클리프** (`config/10_writing_standard.md` §C-4-2·§C-2-2): 정보 자본(정체 전모·배후)·감정 종결(용서·화해)은 페이월 뒤. 수위/육체 진도는 자본이 아니라 상품 — 고수위물은 무료런 풀 에스컬레이션. 회차 클리프행어 = 카메라에 찍히는 것만(원안 마지막 비트의 반 발짝 연장·다음 화 선결제 금지·내레이터 요약/수사의문 금지).
5. **능력/세계 규칙 정합.** 클리프·보강뿐 아니라 **시놉시스 결말 비트**까지 룰 스테이징을 위반하지 않는지 머지에서 심문 — 특히 능력 기반 작품의 "감성적 렌더링" 결말(예: "처음으로 세이브를 안 누른다")은 기계적으로 정반대 효과를 낼 수 있다. 실증(My Million-Dollar Reset): "그녀를 가진 첫 아침 세이브를 안 누른다"는 감성 비트가 규칙상 앵커를 과거(그녀 없던 시점)에 방치 → 다음 로드 시 그녀 상실 → 논리 붕괴. 교정 = 버튼 의미 반전("되돌리려"가 아니라 "지키려" 세이브·앵커 전진). 예: 인플레이스 되감기 연출 vs "로드 = 세이브 포인트 복귀".

6. **정보 비대칭 = dramatic irony (미스터리 금지).** 엔진 핵심 비밀(정체·이중생활·능력)을 시청자에게 반전으로 숨기지 말 것 — 버티컬은 추리물이 아니다. 1화(오프닝 몽타주·분할컷)에서 시청자에게 먼저 공개하고, 인물이 뒤늦게 따라잡는 구조로 짠다. 기획안에 **3자 정보 비대칭 지도**(누가 무엇을 알고 모르나)를 명시 — 그 격차가 코미디·긴장의 엔진이다. 실증(My Million-Dollar Reset→개제 The Infinite-Reset Billionaire's Guide): 클로이 이중생활을 EP7~8 시청자 반전으로 배열했다가 1화 오프닝 공개(레오만 모르는 irony)로 교정. (메모리 [[vertical-truth-reveal-must-be-dramatic-irony]])

## 분업 (병렬 3기 · 메인 = 쇼러너)

| 유닛 | 담당 | 핵심 가드레일 |
|---|---|---|
| opus ① 창작 코어 | 로그라인(5요소)·사이다 훅 4축·필수 포함/금기 (+타이틀 후보 — 사용자 미확정 시만) | 원안 로그라인 = 업그레이드 베이스 |
| opus ② 트리트먼트 | 원안 회차 verbatim + 지정 축 보강 + 인월드 클리프 | 대원칙 1·4·5 전문 인용해 브리프 |
| sonnet 프로즈 벌크 | 시놉시스 500자(기승전결+결말 발명)·세계관·캐릭터(조연 발명 최소·무료/유료 기능 명시) | 대원칙 3 |
| haiku 메타 | 장르·키워드·회차·타깃·레퍼런스·일정(미확정 = TBD+제안치 병기) | 원안 데이터 누락 금지 |

메인(쇼러너)은 캐논 고정 브리프(인명·능력 규칙·화수·페이월 클리프)를 각 유닛에 동일 주입하고, 머지에서 ①원안 대사 전수 verbatim 대조 ②3언어 인명 표기 통일 ③섹션 간 정합(시놉시스↔캐릭터↔트리트먼트)만 수행. 프로즈 직접 생산 금지.

## 기계 게이트 (docx 조립 후 필수)

①원안 대사 verbatim 전수 in-doc 대조(1건이라도 누락 = 실패) ②발명 비트 grep(브리프에 금지 유형 명시했던 목록) ③클리프 개수 = 무료 화수·요약형 마커("~이 시작된다"·"~일까" 등) 0 ④KR/中文 쌍 수 일치 ⑤HTML 이스케이프(`&lt;`)·구버전 인명 잔재 0 ⑥일정/회차/타깃 = 원안 값.

## 빌더 & 출력 규격

- 빌더 = `tools/build_vigloo_proposal.py <spec.txt> <out.docx>` — spec 형식(#DOCTITLE/#SECTION/#ROW)은 스크립트 docstring 참조. 콘텐츠는 spec 파일에만 두고 스크립트는 불변.
- 파일명 = `Vigloo AI Drama Proposal_<EN TITLE>.docx`. 전 필드 한국어+中文 병기(타이틀은 KR/EN/CN 3종).
- Vigloo 템플릿 필드 순서: 프로젝트 기본 정보(타이틀/담당자/제작 형태/장르/키·트로프/로그라인/총 회차·무료회차/타깃층/AI Type/레퍼런스) → 시놉시스(줄거리 500자·기승전결·주요 인물 결말) → 캐릭터 소개(주요 인물 → 서브/빌런) → 핵심 아이디어(사이다 훅/세계관) → 내용요건(필수 포함/금기) → 초반 회차 트리트먼트(1화~페이월·회별 200~300자+클리프행어) → 제작 적절성(제작비/납품 기일/릴리즈) → 샘플 대본(범위/납품일/비용) → 검토 자료(각색 원작 대본 유무).
