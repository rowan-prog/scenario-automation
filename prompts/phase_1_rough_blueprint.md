# Step 1-1 — 러프 청사진 프롬프트

## 역할
신규 작품의 러프 청사진(=청사진 초안)을 생성한다.
러프 청사진은 **피칭덱 작성의 기반이 되는 1차 작품 설계 문서**다. 피칭덱 작성에 필요한 모든 정보를 갖춰야 한다.
반드시 한국어로 작성한다.

## 출력 구조

러프 청사진은 피칭덱 작성에 필요한 모든 정보를 정리한 1차 설계도. 다음 항목을 모두 포함:

1. **제목 / 가제** (영어 + 한국어 두 줄, 정답 양식)
2. **장르** (한국어)
3. **키워드** (한국어, 5-7개)
4. **타깃** (국가 + 성별 + 나이 + 선호 카테고리)
5. **포맷** (AIGC Live-action vs Animation 3D / 2.5D / 2D + 세로형 9:16 vs 가로형 16:9)
6. **플랫폼**
7. **총화수 / 편당 길이 / 무료-유료 구조**
8. **제한 수위 / 톤**

9. **로그라인** (한국어, **2-3문장 권장 / 한 문장당 정보 5개 이하**)
   - 누가 무엇을 빼앗기는가
   - 어디서 어떻게 뒤집는가
   - 적대자 누구인가
   - 유료 구간으로 넘어갈 더 큰 갈등 남김
   - **본문 페이월 정합성 필수** — 본문이 EP6에서 핵심 보상을 유예하도록 설계됐다면 로그라인도 동기화. "X라고 선언한다" 완료형 X / "X 선언을 시작한다 — 그 단어는 ~에 끊긴다" 진행형 O. 로그라인이 무료 보상을 다 약속하면 결제 동기 사라짐 (참조: `feedback_logline_rules.md`)

10. **메인 타깃 페르소나** (구체적 인물상)

11. **주요 인물 소개** (각 인물 한 단락, 작품 안 사건 기반)
    - 외모 (시각적 표지)
    - 시작 위치 (처지)
    - 그 인물이 주인공에게 무엇을 빼앗고/유혹하고/막는지
    - 초반에 어떤 장면으로 기억되는가
    - **금지:** ~을 보여준다 / ~로 기능한다 / ~의 기준이 된다 / 후반부의 핵심 인물이다 / 폐기된 / 자산 / 변수 / 포지션 / 축

12. **핵심 결핍** (주인공이 잃은 것)

13. **핵심 욕망** (주인공이 되찾으려는 것 — 남자/돈/권력/이름/몸/기억)

14. **핵심 보상** (회차마다 시각적으로 회수되는 것)

15. **핵심 갈등** (주인공 vs 적대자, 무엇이 부딪히는가)

16. **줄거리** (한 페이지 분량, 사건의 흐름)
    - 시작 → 페이월 → 후반 방향
    - 누가 죽는다 / 누가 밀려난다 / 누가 들어온다 / 무엇이 공개된다 / 누가 무엇을 빼앗는다
    - **금지:** 유료 구간에서는 ~로 확장된다 / 후반부에는 ~가 연결된다 / 구조가 선명해진다

17. **무료회차 트리트먼트** (EP1~EP8 고정, 회차별 — 무료 1-8 표준 / 페이월 EP8)
    - 각 회차의 처지 변화·사건·클리프행어 명시
    - **단서 발견만으로 끝나는 약한 클리프행어 X** — 정보가 인물 처지를 바로 바꿔야 함
    - 핵심 발화는 영어 직접 인용 가능 ("Tell Zeus his beast is awake" / "The seal is yours now")
    - **금지:** ~라는 사실을 알게 된다 / ~의 단서를 발견한다 / ~의 구조가 드러난다 / ~을 암시한다
    - **EP1 비트 밀도 (필수, `feedback_blockbuster_structural_insights.md` 룰 1):** EP1은 단일 사건 X / 다층 비트 적재. 일반 1화 = 5-7비트, 대박작 = 15-20비트. EP1 트리트먼트 작성 시 비트 카운트 — 7비트 미만이면 감정 채무 적재 부족. 비트 단계: A 현재 박탈 → B 과거 폭로 → C 자기 죄책감 → D 인지 충격 → E 최종 절단 → F 재시작.
    - **페이월 3중 구조 (필수, 룰 2):** EP6/EP8 페이월 = 사회적 판정장(공개 공간+증인) + 시간 압박(카운트다운) + 동시 다발(결정적 사건 2-3개 한 컷) 모두 적재.
    - **모욕-역전 사이클 (룰 4):** 작품 전 화수에 사이클 N회 + 매 사이클 다른 보상 카테고리 (금융·계급·관계·혈통 등). 무료 구간에는 1 사이클 + 유료에 N-1 사이클 분배.

18. **무료 구간 한도 (필수, 11-8-2 시장성 항목)**
    - 무료 구간 마지막에 무엇이 안 끝났는가
    - 유료 구간에 남는 굴욕·폭로·역전·소유·정복은 무엇인가
    - 무료 구간이 보상을 완성하면 결제 동기 사라짐 → **첫 증거만**

19. **상업적 훅 / 변별력**
    - 비슷한 소재와 달리 무엇이 더 세게 빼앗기고 뒤집히는가
    - 다른 작품에 없는 공개 장면은 무엇인가
    - **금지:** 차별점은 ~라는 점이다 / 단순한 ~이 아니라

20. **비주얼 방향** (AIGC 구현 방향, 2-4줄, 작품 안 사건 기반 — "화면에 남긴다" 표현 X)
    - 판타지·로맨타지·다크 판타지·신화·수인·드래곤·마법·던전·왕실 장르는 대형 시각 보상을 별도 명시한다.
    - 성채·거대한 문·왕좌·드래곤·괴물·마법·군대·하늘·불/얼음·의식·세계 위계 중 무엇이 EP1-3 또는 무료 초반에 실제로 보이는가.
    - 작은 소품·seal·문장 반응만으로 판타지 장르 약속을 처리하지 않는다.

21. **피칭용 강점** (평가위원 설득 포인트, 작품 안 근거)
    - 결론문 ("따라서 시장성이 있다") 금지

## 작성 원칙

### A. 새 원칙 (필수, production_guide 11-8)
- 작품 밖에서 말하지 말 것. 작품 안 실제 사건만.
- 평가·해설·메타 0건. 빈 결론문 0건.
- 금지어 35종 검색 후 의심.
- "단순한 A가 아니라 B" 패턴 0회.
- 사람을 물건처럼 ("폐기된" / "자산" / "변수") 0건.
- 7 최종 검수 모든 문장 통과.

### A0. 직관성 anti-pattern 6 검수 (필수, `feedback_directness_master.md`)
- **A1 은유·암시 0건** ("이름을 지웠다" / "잘라냈다" / "자리를 비웠다" → 사실로)
- **A2 장소 명확** ("어둠 속" / "그곳" → 구체 장소)
- **A3 추상·인격화 동사 0건** ("응답해 / 호응해 / 동조해 / 화답해 / 함께 떨고 / 같은 결로" → 시각적 동사)
- **A4 인과 명확** ("왜?" 답해지는가)
- **A5 만연체 X** (한 문장 30단어 / 종속절 3개 이하)
- **A6 세계관·고유명·구체 사건 노출** (추상 지시어 X)

자가 시뮬레이션: "사용자가 '이게 뭐야 / 답답하다' 반응할 가능성 0%인가?"

### B. 무료 구간 한도 (필수)
- 무료 6화 또는 8화는 **첫 증거만**. 가장 큰 굴욕·역전·폭로는 유료 구간에 남김.
- 작품별 무료 한도는 production_guide.md 11-8-2 시장성 항목 참조.

### C. 트리트먼트
- 회차마다 처지 변화·사건·클리프행어 명시.
- 클리프행어가 단서 발견만으로 끝나면 약함 → 인물 처지 변화 동반.
- 핵심 발화는 영어 인용 가능.

### D. 회차 설계 게이트 (🚨 MEMORY 0-2 절대 룰 우선·2026-05-28 정정)
- **default = 50화 · 총 70-80k chars · 편당 ~1.5분 · 페이월 EP8.** 다른 값은 사용자 명시 시만. (구 "가변 50-60화·EP5-15" 프레이밍 = 폐기)

### E. 인물 이름 충돌 검사 (필수, `feedback_character_name_diversity.md`)
- 기존 진행 중 모든 작품 이름·성씨와 충돌 검사. 충돌 시 신규 작품 측 양보.

### F. 단일 사건축 / 압력 중첩 게이트

- 러프 청사진은 Conversion Runway 구간 (EP1-페이월·자연 흐름)을 여러 사건의 나열로 만들지 않는다.
- 먼저 한 줄로 적는다: **시청자는 무엇이 터지기를 기다리는가?**
- 각 회차는 새 사건축을 추가하는 대신 같은 압력을 키운다: 더 공개적인 자리, 더 많은 증인, 더 불리한 조건, 더 가까워진 접촉, 더 강한 권한 이동, 더 되돌릴 수 없는 선택.
- 반복 보상은 기본적으로 경계한다. 같은 모욕과 같은 참교육을 여러 번 복사하지 말고, 한 상황의 의미가 계속 뒤집히게 한다.
- 단, 숏폼 사이다/효도/가족 역전극은 `클립 보상 반복`이 상품성일 수 있다. 반복되는 것이 장면 모양인지, 아니면 같은 원초 보상축인지 구분한다. 예: "엄마를 무시한 사람들이 회귀한 천재 아들 때문에 공개적으로 쪽팔린다"가 은행, 백화점, 부동산, 투자장, 가족 비밀에서 계속 새 증거와 새 증인을 얻으면 허용한다.
- 분위기와 상징은 감정 거래를 대체하지 못한다. 청사진 단계에서 `구체적 가해자`, `정확한 모욕/오판/위협`, `목격자`, `주인공/여주의 선택`, `장면 뒤 바뀌는 관계·지위·권한`을 적는다.
- 왕국, 제국, 가문, 의회, 문서, 법, seal이 적대축이면 반드시 얼굴과 목소리를 가진 대리 가해자를 붙인다. 시청자가 기다릴 대상은 추상 시스템이 아니라 방금 모욕한 그 사람의 되갚음이다.
- 다크 로맨스/로맨타지에서 결정 대사(`Yours`, `Mine`, `Wife`, `Mate`, `Chosen`, `Body`)는 초반부터 모욕/거절/거래/금지어로 적립한 뒤 페이월 전후에 뒤집어 쓰도록 설계한다.
- 남성향 무쌍·정복·군단·준하렘은 “무엇이 주인공의 명령·소유·통제 아래로 넘어오는가”를 회차마다 선명하게 만든다.

### G. 🚨 paid vertical 구조 게이트 (2026-08-20 사용자 · 본문 = `config/00_vertical_dna.md` 'paid vertical 구조 7항')

**사용자: "핵심은 장르/트롭에 있지 않다. 구조에 있다. 그 다음 서사다. paid vertical drama 다운 구조가 존재해야 한다."** 러프 청사진에서 먼저 **S0 + 구조 7항**을 세운다 (근거 = 히트작 코퍼스 전량 정독·2026-08-20): S0 공력 배분(1화≫≫2화>3화>마지막 무료>나머지>유료 · 컷 = 1화 오프닝>1화 엔딩>마지막 무료 엔딩) + **결제 = 비싼 돈**(원초·금기·천박·윤리 이탈이 극단으로 · 실물은 **가해자의 천박한 모욕 대사** · 무료 8화 = AD LOOP 1) → **S1** 1화 첫 1분에 파는 것이 실물로 실행(3형태: 정점→회상→복귀 / 최강 시연→추락 / 밑바닥 굴욕 실시간) / **S2** 화의 단위 = 쟁점·물건 하나 / **S3** 다음 화 씨앗 = 같은 공간의 다음 물건 / **S4** 화의 끝 = 대사(페이월은 행위 직전+금기+위협 한 컷) / **S5** 주인공이 매 화 되받아침 / **S6** 관객 선지 + 밝히지 않기로 하는 선택 / **S7** 인물 불변·결심 강도만 상승·감정 증거는 작은 디테일.

**🚨 조건 0 + S0-4·5·6 (2026-08-26 신설 · 본문 = `config/00_vertical_dna.md`).** **조건 0 = 가격이 규격을 정한다** — 우리 분당 단가가 영상 시장 최고가라 '고급감·완성도·품위'를 경쟁 축으로 잡으면 자동 패배다(영화·OTT가 1/10 값에 100배를 준다). 판정 문장 = *"이 장면이 넷플릭스에 있어도 안 이상하다" = 결함 / "거긴 이런 걸 못 판다" = 정상.* **S0-4** 매 화 파는 **원초 욕망을 한 단어로**(성욕·배덕 / 응징 / 서열 역전 / 소유·강탈 / 관음 / 굴욕 관람+억울 / 생존 위협 / 혈육 / 탐욕) — 욕망을 주제로 올리거나 이름으로 말하면 장편 문법. **S0-5** **맥락 0으로 잘라 광고로 틀 컷**이 무료 화당 1개 이상, 그것도 광고용 신설 씬이 아니라 그 화의 최대 상품 지점에서 나올 것(반전·정체·복선은 광고 컷이 못 된다). **S0-6 세 관문** = 후킹(첫 3~10초·컷) / **락인(1화 첫 씬 — 첫 1분에 파는 것이 실물로 실행 + 권력 역전 1회 · `hit_dna_priority8.md` §0-1 ①②. 가중치 = 첫 컷 > 첫 씬 > 1화 엔딩 · 엔딩 계약서·2~3화 첫 이행은 보조. 수수께끼·설정이면 실패)** / 결제(마지막 무료 엔딩 = 궁금함이 아니라 "여기서 끄면 못 견딘다") — **셋은 서로 대체 불가다.** **+ 조건 1-1 시청자 전지(같은 날):** 캐릭터 설정·트리트먼트에 각 인물의 관계·목표·동기·정체가 **시청자에게 어느 채널(네임카드/밀담/VO·독백/회상)로 언제 도착하는지**를 적는다 — 인물끼리는 몰라도 시청자는 첫 행동 전에 안다. 사용자 판정: **"기획안이 숏폼 드라마가 아니라 무료형 콘텐츠나 장편 영화 같다 — 전개 속도·인과관계·감정선, 그리고 트리트먼트·캐릭터 설정·기승전결에서."** 특정 작품 지적이 아니라 산출 전반의 기본값 결함이라 러프 단계에서 먼저 막는다. 러프 청사진은 피칭덱·기획안·트리트먼트의 상류다 — 여기서 장편으로 설계되면 하류에서 못 고친다.

- **①속도 (→ 트리트먼트 #17):** EP1 트리트먼트는 세계·인물 소개가 아니라 **이미 벌어진 정점**에서 연다(히트작 4종 EP1 첫 대사 = 본문 첫 줄, 실측). 화마다 "이 90초에 시청자가 받는 자극"이 적혀 있어야 한다. 준비·이동·결심·경위·설명이 한 화의 본체면 그 화는 없는 화다. **유료 구간을 "제1막/제2막" 막(幕)으로 뭉개지 말 것** — 컨테이너 + 화 범위 + 그 안에서 한 칸씩 오르는 것으로 적는다(#16 줄거리도 동일).
- **②인과 (→ 줄거리 #16 · 기승전결):** **1홉.** 원인은 직전 화면 안에 있다. 한 문장에 연결어미 2개 이상("~해서 ~하게 되고, 그로 인해 ~한다")·행동의 이유가 과거사/성격/트라우마(=화면 밖)·계획→준비→실행 2~3단 = 전부 장편 사슬. 기승전결은 **막 구조가 아니라 결제 회계**로 쓴다: 부채 적립(무료) → 상전이(페이월) → 정산 사다리(유료·무엇이 한 칸씩 오르나) → 종착. (인과를 없애라가 아니라 짧게 하라는 것 — 통째로 없으면 그건 개연성 방치라는 다른 결함.)
- **③감정선 (→ 인물 소개 #11 · 핵심 보상 #14):** 인물은 안 변한다. **변하는 건 지위와 관계다.** 인물 소개 = *매 화 시청자에게 주는 것(한 단어: 굴욕·통쾌·설렘·전율·욕정·억울) + 첫 등장 장면 + 대표 대사 1줄*. 아크·내면·주제 서술("~의 상처가 그를 만들었다") 금지 · 백스토리 문장이 기능 문장보다 길면 재작성 · "점차·서서히·마침내·한참 뒤에" 금지. **예외 = 장르 캐논인 지연**(후회남의 후회 지연·무료런 정보 자본 유보 §C-4-2) — 유보되는 건 정보와 감정 종결이지 자극이 아니다. 이 예외로 기각하려면 어느 장르 캐논인지 이름을 대야 한다.

자가 점검 3문: ①1화에 도입이 있는가(있으면 재작성) ②각 비트의 원인이 직전 화면 안에 있는가 ③각 인물이 매 화 주는 것을 한 단어로 즉답할 수 있는가.
