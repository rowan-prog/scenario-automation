# Step A-1 — 각색 방향 청사진 프롬프트 (부가 트랙 A)

## 역할
원작(소설·만화·외부 시나리오·게임·기타 IP)을 AIGC 숏폼으로 각색할 때의 **방향**을 결정하는 청사진을 생성한다.

원작을 그대로 옮기지 않는다. AIGC가 잘하는 방식으로 재구성하는 결정 문서다.
한국어로 작성한다.

## 부가 트랙 A 워크플로우 (필수)

```
step_a_1 (각색 청사진)
  → step_2_1 (피칭덱 — 메인 트랙 prompt 그대로 사용)
    → 03_pitch_outcome.md (사용자 작성 — 피칭 결과)
      → step_a_1 재진입 (피칭 반영 수정 — 수정 사항 없으면 그대로 진행)
        → step_a_2 (각색 스크립트 집필)
          → 메인 트랙 검토 루프 (step_5_1 ↔ step_6_1 → step_7_1)
            → 07_final/ ✅
```

각색 청사진(01_adaptation_blueprint.md)은 피칭덱(02_pitch_deck.md)·피칭 결과(03_pitch_outcome.md) 작성에 필요한 1차 설계 정보를 모두 갖춰야 한다 (인물·트리트먼트·페이월·로그라인 포함). 메인 트랙의 러프 청사진(01_blueprint_rough.md) 역할을 겸한다.

## 필수 입력값
- 원작 정보: 제목 / 매체 (소설/만화/드라마/게임 등) / 원작자 / 분량 / 저작권 상태
- 원작 자료 (전문 또는 핵심 챕터·회차)
- 각색 조건:
  - 타깃 국가 / 언어 / 성향
  - 총화수 / 편당 길이
  - 무료회차 수 / 유료 시작 회차
  - 포맷 (AIGC 실사형 / AIGC 애니메이션)
  - 제한 수위
- 각색 강도 (사용자 선택): **충실 / 현대화 / 재해석**
- 라이선스 / 저작권 처리 방식

## 출력 구조

1. **원작 정보**
   제목 / 매체 / 원작자 / 분량 / 저작권 상태 / 라이선스 처리 방식

2. **원작 핵심 매력 (3가지)**
   원작이 검증한 결제 트리거 / 팬덤 동력 — 각색 후에도 보존되어야 할 매력 신호

3. **AIGC 적합성 판정** (Section 5-4 체크리스트 적용)
   - **적합도 높은 요소:** 시각 폭로, 위계 변화, 군중 리액션, 명확한 권력 차이, 공개장 장면 등
   - **적합도 낮은 요소:** 미묘한 눈빛, 긴 대화, 작은 표정 변화, 복잡한 카메라 연속성 등

4. **각색 방향 (3분류)**
   - **가져올 것:** 원작에서 보존할 캐릭터·사건·미감·트롭
   - **버릴 것:** AIGC 부적합 요소 + 숏폼 호흡에 안 맞는 부분
   - **변환할 것:** 소설적 묘사 → 시각 요소 / 내면 독백 → 행동·소품 / 미묘한 감정 → 위계 변화

5. **핵심 엔진 재정의**
   - 핵심 결핍 (원작 vs 각색 후 비교)
   - 핵심 욕망
   - 핵심 보상
   - 페이월 약속 (무료→유료 전환 이유)

6. **AIGC 숏폼 구조 매핑**
   - 원작 N장/N권 → AIGC EP1~[총화수] 분할
   - **페이월 절단 위치:** 원작의 어떤 사건이 EP[무료 마지막] 페이월 절단이 될지
   - 무료 구간 / 유료 Arc별 분배

7. **캐릭터 캐논 (각색 후)**
   각 주요 캐릭터에 대해:
   - 원작 vs 각색 후 차이점
   - 절대 하면 안 되는 행동 (각색 정당성 한계선)
   - 비주얼 락 방향

8. **비주얼 방향**
   - 원작 미감 → AIGC 변환 전략
   - 포맷 선택 이유 (실사형 vs 애니메이션 — Section 5-3)
   - AIGC 강점 슬롯 (Section 3-1, 3-2)

9. **각색 위험 요소**
   - 저작권 / 라이선스 이슈
   - 팬덤 반발 가능성 (원작 변경 정도에 따라)
   - 상업적 리스크

10. **피칭덱 진입 자료** (필수 — step_2_1 직접 입력값)
    - 영어 + 한국어 통 타이틀 (메인 + 부제)
    - 장르·키워드(Tropes) / 타깃 / 포맷 / 회차·길이·무료-유료 구조
    - 한국어 로그라인 (2-3문장)
    - 메인 타깃 페르소나 (구체적 인물상)
    - 주요 인물 4-6명 (각 한 단락 — 외모·시작 위치·결제 트리거 행동)
    - 핵심 결핍 / 욕망 / 보상 / 갈등
    - 무료회차 트리트먼트 EP1-EP8 (회차별 처지 변화·사건·클리프행어)
    - 페이월 EP8 응축 (사회적 판정장 + 시간 압박 + 동시 다발)
    - 무료 구간 한도 (유료에 남기는 것)

## 작성 원칙

### 각색 강도 — Soft Lock 영역 (Section 0-3)

원작 충실성과 AIGC 적합성 사이의 위치는 **작품 자율 결정**.
사용자가 입력한 각색 강도에 따라 다르게 작동한다.

- **충실 모드:** 원작 캐릭터·사건·결말 보존. AIGC가 잘하는 장면만 강조 변환.
- **현대화 모드:** 원작 골격 유지. 시대·배경·일부 캐릭터 현대화.
- **재해석 모드:** 원작은 영감의 출발점. 핵심 트롭만 가져오고 자유롭게 재구성.

### Hard Lock — 절대 락 (Section 0-3)

- **저작권 위반 금지** — 라이선스 없는 원작의 직접 사용 금지.
- **원작 핵심 매력 손실 금지** — 원작이 검증한 결제 트리거를 모두 빼면 각색 동력이 사라짐. 3가지 핵심 매력 중 최소 2개는 보존.
- **AIGC 부적합 장면 강행 금지** — 원작이 좋다고 AIGC가 못 만드는 장면을 그대로 옮기지 않는다 (Section 3-2, 5-4).

### 변환 공식 (Section 3-3)

원작 → 각색 변환:
- 내면 독백 → 행동·시선·물건
- 긴 대화 → 짧은 대사 + 시각 보상
- 미묘한 감정 → 명확한 위계 변화
- 추상적 묘사 → 물리적 장면

## 실행 순서
1. config/production_guide.md 지정 섹션과 원작 자료를 읽는다.
2. 원작의 핵심 매력 3가지와 결제 트리거를 식별한다.
3. AIGC 적합성 체크리스트(Section 5-4)를 적용해 가져올 것 / 버릴 것 / 변환할 것을 분류한다.
4. 각색 강도(충실/현대화/재해석)에 따라 변환 정도를 결정한다.
5. 원작을 AIGC 숏폼 회차 구조에 매핑하고 페이월 절단 위치를 결정한다.
6. 출력 구조 9개 항목을 모두 채운다.
7. projects/[작품명]/[작품명]_01_adaptation_blueprint.md에 저장한다.
8. projects/[작품명]/[작품명]_00_meta.md를 생성한다 (트랙: 부가 A · 작품 메타 · 진행: step_a_1 완료).
9. 종료 안내 (3줄 패턴):
   - `✅ projects/[작품명]/[작품명]_01_adaptation_blueprint.md — [작품 가제]`
   - `각색 강도: [충실/현대화/재해석] · EP[무료 마지막] 페이월: [한 줄]`
   - `다음: 피칭덱(step_2_1)으로 진행할까요?`
