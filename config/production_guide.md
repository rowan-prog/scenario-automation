# AIGC 숏폼 시나리오 워크플로우 MASTER GUIDE v2

## 0. 이 문서의 역할

이 문서는 AIGC 애니메이션 / AIGC 실사형 드라마의 시나리오 개발, 피칭덱 작성, 검토, 수정, 최종고 완성까지의 전체 작업 기준이다.

매 작품마다 새로 쓰는 문서가 아니다. 한 번 만들어두고 계속 사용하는 고정 기준이다.
작품마다 바뀌는 정보는 별도 프로젝트 입력값으로 관리한다 (Section 2-2).

이 문서의 목적: AI가 매번 다른 방향으로 흔들리지 않도록 모든 작업의 기준선을 고정한다.

### 프로젝트 폴더 네이밍 규약

`projects/` 하위 작품 폴더는 **생성 순서에 따라 `넘버_타이틀` 형식**으로 관리한다.

- 형식: `[2자리 번호]_[영문_소문자_언더스코어_타이틀]`
- 예시: `01_titan_born`, `02_the_offering`, `03_black_core`
- 번호는 0 패딩 2자리. 타이틀은 영문 소문자 + 언더스코어.

prompt 파일은 `projects/[작품명]/...` placeholder를 사용한다. 새 작품 생성 시 사용자에게 다음 번호와 타이틀을 확인 후 폴더 생성한다.

### 작품 폴더 내부 파일 구조

**파일명 규칙:** 모든 파일은 `[작품 폴더명]_` prefix를 사용한다. 파일 자체로 어느 작품의 어느 단계인지 식별 가능하도록.

형식: `projects/[작품명]/[작품명]_[단계 번호]_[단계 이름].md`

예시 (작품명이 `02_the_offering`인 경우):

```
projects/02_the_offering/
├── 02_the_offering_00_meta.md              ← 작품 진행 추적 메타
├── 02_the_offering_01_blueprint_rough.md   ← 메인 트랙 러프 청사진 (또는 _01_adaptation_blueprint.md — 부가 A)
├── 02_the_offering_02_pitch_deck.md        ← 메인 트랙 피칭덱
├── 02_the_offering_03_pitch_outcome.md     ← 피칭 결과·평가위원 피드백 (사용자 작성)
├── 02_the_offering_04_blueprint_full.md    ← 메인 트랙 완성 청사진
├── 05_episodes/                            ← 회차 스크립트 (초안 + 패치 라운드)
│   ├── 02_the_offering_ep01.md             ← 초안
│   ├── 02_the_offering_ep01_r1.md          ← 라운드 1 패치 후
│   ├── 02_the_offering_ep01_r2.md
│   └── 02_the_offering_ep01_external.md    ← 부가 B (외부 대본 원본 보관)
├── 06_reviews/                             ← 검토·패치 보고서
│   ├── round0/                             ← 부가 B 1차 게이트
│   │   └── 02_the_offering_initial_gate.md
│   ├── round1/
│   │   ├── 02_the_offering_persona_01_ep01.md
│   │   └── 02_the_offering_patch_log_ep01_round1.md
│   ├── round2/
│   └── 02_the_offering_final_gate_ep01.md  ← 최종고 게이트 평가 보고서 (phase_7 산출)
└── 07_final/                               ← 최종고만 (4-Gate 통과 후 복사)
    └── 02_the_offering_ep01.md
```

**번호 의미:**
- 폴더 번호 (`projects/02_...`): 작품 생성 순서 (식별자)
- 파일명 prefix (`02_the_offering_`): 파일 자기 식별을 위한 작품 ID
- 파일 단계 번호 (`_00_`, `_01_`, `_02_` 등): 워크플로우 단계 순서

파일 prefix와 폴더명이 일치하므로, 파일을 폴더 밖으로 옮겨도 어느 작품인지 즉시 식별 가능하다.

**하위 폴더 (05_episodes, 06_reviews, 07_final) 자체는 prefix 없음** — 모든 작품에서 동일한 워크플로우 단계 의미를 갖는 표준 폴더이므로.

### 용어 정의

- **AIGC 실사형 드라마** — 인공지능으로 생성한 실사 드라마. "실사풍"이라는 중간 표현은 쓰지 않는다 (Section 5-3).
- **AIGC 애니메이션** — 인공지능으로 생성한 2D / 2.5D / 3D 애니메이션. 양식화된 판타지를 시청자와 사전에 약속하는 포맷.
- **비주얼 락 (Visual Lock)** — 캐릭터 외형이 한 컷에서 다른 캐릭터와 구분되도록 잠그는 작업 (Section 6-3, 12-7).
- **페이월 (Paywall)** — 무료 회차의 마지막 절단 지점. 시청자가 결제 결정을 내리는 순간.
- **캐논 (Canon)** — 작품 내에서 변경 불가능한 고정 설정 (Section 12-3, 12-7).
- **레이어 (Layer)** — 성적·폭력적 표현 등 기본 서사 위에 선택적으로 얹히는 표현 층위 (Section 17).
- **소보상 / 큰 보상** — 회차 안의 작은 시각·관계 갱신 / 페이월 직전 또는 유료 초반의 누적 결제 보상 (Section 13, 15).

## 0-3. 락(Lock)과 열어둠(Open) — 이 가이드의 적용 원칙

이 가이드는 모든 항목을 동일하게 잠그지 않는다.
어떤 원칙은 절대 락(Hard Lock)이고, 어떤 원칙은 작품·인물·맥락에 따라 열려 있다(Soft Lock).

- **잘못된 락**은 작품을 무색무취하게 만든다. 모든 규칙을 절대화하면 캐릭터와 장르가 죽는다.
- **잘못된 열림**은 작품의 상품성을 깨뜨린다. 타협 불가한 핵심을 작품 자율로 두면 무료→유료 전환이 무너진다.

### 반드시 락을 걸어야 하는 것 (Hard Lock)

작품·인물·장르에 무관하게 절대 잠긴다. 무너지면 시청자가 즉시 이탈하거나 상품이 성립하지 않는다.

- **포맷 분류** — 실사형 vs 애니메이션. 섞을 수 없다 (Section 5-3).
- **씬 끝 변화 룰** — 모든 씬은 끝날 때 관계 / 정보 / 주도권 / 감정 / 상황 중 하나가 반드시 갱신되어야 한다 (Section 13).
- **Visual 지문 물리 정보 룰** — 추상 감정 금지, 물리 정보만 (Section 6-1).
- **무료 구간 수렴 룰** — 무료 구간은 하나의 결제 이유로 수렴해야 한다 (Section 1).
- **상위 단계 권한 룰** — 청사진은 시나리오보다, 시나리오는 연출보다 상위 권한 (Section 4, 18).
- **AIGC 구현 가능성 룰** — AIGC가 구현할 수 없는 지문은 좋은 지문이 아니다 (Section 24).

### 열어둬야 하는 것 (Soft Lock)

가이드의 권장 방향은 있지만, 작품·인물·맥락에 따라 자율 결정한다.
모든 작품에 동일하게 적용하면 작품이 무색무취해진다.

- **남주의 대사 방식과 선언형 대사 허용 시점** — 증명 단계·장르·인물 성격에 따라 다름 (Section 9-1).
- **톤의 밝기·다크 정도** — 작품 컨셉에 따라 다름 (Section 5-1).
- **성적 표현의 강도와 방식** — 타깃·제한 수위·장르 조합에 따라 다름 (Section 8-5, 9-2, 17).
- **대사 길이와 리듬** — 캐릭터 성격에 따라 다름.
- **카메라의 직접성** — 포맷·장르에 따라 다름.

### 의심 시 판단 기준

- 이 원칙이 무너지면 시청자가 즉시 이탈하는가? → **Hard Lock**.
- 이 원칙은 작품 컨셉이 다르면 다르게 적용될 수 있는가? → **Soft Lock**.

가이드의 권장이 곧 절대 락은 아니다.
**권장과 락을 구분해서 읽는다.** 락을 어기면 상품이 무너지고, 권장을 무조건 따르면 작품이 무색무취해진다.

# Part I — 기준선 (Foundation)

# 1. 최상위 목적

AIGC 숏폼 콘텐츠의 목적은 짧은 시간 안에 시청자의 결핍을 자극하고, 보고 싶은 보상을 빠르게 고정한 뒤, 무료 구간을 강한 유료 전환 이유로 수렴시키는 것이다.

모든 개발, 검토, 수정은 다음 질문에 답해야 한다.

* 이 작품은 시청자에게 무엇이 부족하다고 느끼게 만드는가?
* 시청자는 무엇을 보고 싶어지는가?
* 무료 마지막에서 왜 돈을 내고 다음 회차를 봐야 하는가?
* 그 보상은 각 회차와 장면에서 누적되고 있는가?
* AIGC가 그 장면을 안정적으로 구현할 수 있는가?

무료 구간은 여러 번 낚는 구조가 아니다.
무료 구간은 하나의 핵심 질문, 하나의 핵심 보상, 하나의 강한 결제 이유를 향해 수렴해야 한다.

중간 회차는 독립 절정의 반복이 아니라, 최종 무료 절단의 압력을 누적하는 과정이다.

단, 무료회차 수와 유료 시작 회차는 작품마다 다르다. 따라서 이 문서에 고정하지 않는다 (Section 2-2).

# 3. 핵심 제작 원칙

* 시청자는 지문을 읽지 않는다.
* 관객이 이해해야 하는 정보는 반드시 화면에 보이거나, 대사·음성·UI·자막 등으로 직접 전달되어야 한다.
* 지문 속 설명만으로 성립하는 정보는 유효한 서사 정보로 보지 않는다.
* 제작자와 연출가가 기획자 및 집필가와 같은 그림을 상상할 수 있어야 한다.
* 크리에이티브한 해석 여지를 과도하게 열지 않는다.
* 감정, 설정, 관계 변화, 권한 이동, 시간 경과, 공간 이동, 소유권 변화는 화면 또는 대사로 확인 가능해야 한다.
* 중요한 정보는 관객이 완성 영상에서 인지할 수 있어야 한다.

**AIGC 콘텐츠는 설명문이 아니라 구현물이다.**
멋있는 말을 쓰는 것보다, 멋있는 상황을 만드는 것이 먼저다.

단, 시청자가 놓치면 망하는 정보는 캐릭터 목적 안에서 분명히 짚어도 된다.

## 3-1. AIGC 콘텐츠 핵심 강점 원칙

AIGC의 강점은 다음에 있지 않다:

* 미묘한 감정선
* 서늘한 암시
* 심리적 뉘앙스
* 인상파적 연기 디렉팅

AIGC의 강점은 다음에 있다:

* 직관적이고 물리적인 충격
* 현실에서 구현 불가능한 스케일
* 극도로 완성된 비주얼 미감
* 화려한 VFX와 파티클 이펙트
* 초인적 존재감과 압도적 실루엣
* 즉각적이고 명확한 화면 보상

모든 장면은 화면에서 즉시 이해되고 즉시 보상이 와야 한다.
설명보다 화면이 먼저. 암시보다 직접 보상이 먼저.

AIGC가 구현하기 어려운 방식으로 쾌감을 설계하지 않는다.
AIGC가 압도적으로 잘할 수 있는 방식으로 장면을 설계한다.

## 3-2. AIGC 쾌감 전달 방식 분류

"실사형이냐 애니메이션이냐"는 1차 질문이 아니다.

**1차 질문:**
이 이야기의 쾌감이 배우의 복잡한 연기에서 오는가, 아니면 직관적 장면·증거·상징·구도·위계 반전에서 오는가.

배우 연기형 (AIGC에 불리):

* 미묘한 눈빛
* 침묵과 망설임
* 후회의 얼굴
* 감정의 잔향

장면 구조형 (AIGC에 유리):

* 서류 공개
* 대형 스크린 폭로
* 군중의 시선 반전
* 악역의 가면 붕괴
* 인물의 무릎 꿇음
* 주인공의 퇴장

쾌감이 배우 얼굴에 있으면 AIGC 실사형은 위험하다.
쾌감이 증거·상징·구도·공개 반전·위계 변화에 있으면 AIGC가 정공법이 된다.

같은 장르라도 쾌감 전달 방식이 다르다.
시나리오를 설계하기 전에 이 분류를 먼저 한다 (적용형 체크리스트는 Section 5-4).

## 3-3. AIGC 감정-시각 변환 원칙

AIGC에서는 추상적 감정을 물리적 오브젝트와 장면 절차로 변환해야 한다.

**변환 공식:**

* 감정 → 물건 (소품, 오브젝트)
* 관계 → 공간 점유 (누가 어디에 서있는가)
* 진실 → 화면 / 문서 (스크린, 서류, 기록)
* 후회 → 몸의 위치 (무릎, 고개, 손의 방향)
* 권력 반전 → 군중의 시선 방향

**나쁜 설계:**
남편은 뒤늦게 그녀가 얼마나 소중했는지 깨닫는다.

**AIGC식 설계:**
남편이 대형 스크린 아래 무릎을 꿇고,
여주는 이혼서류를 접어 검은 봉투에 넣은 뒤 그를 지나쳐 문밖으로 나간다.
군중의 휴대폰은 이제 남편을 향한다.

AIGC는 미묘한 감정보다 오해 없는 감정에 맞는다.
누가 위에 있고 아래에 있는지, 누가 버려졌고 떠나는지가 화면에서 명확해야 한다.

(장면 단위 적용은 Section 13-1.)

# 5. 첫 분기 판정

모든 프로젝트는 시작할 때 먼저 아래 항목을 판정한다.

1. AIGC 애니메이션인가, AIGC 실사형 드라마인가?
2. 북미 타깃인가, 일본 타깃인가, 한국 타깃인가, 글로벌 타깃인가?
3. 남성향인가, 여성향인가, 혼합 타깃인가?
4. 몇 화인가?
5. 편당 길이는 어느 정도인가?
6. 무료회차는 몇 화인가?
7. 제한 수위는 어느 정도인가?
8. 플랫폼은 무엇인가?

이 판정이 끝나기 전에는 다음을 확정하지 않는다.

* 대사 톤
* 지문 밀도
* 성적 표현 강도
* 폭력 표현 강도
* 카메라의 직접성
* 감정 표현 방식
* 캐릭터 반응 강도
* 무료 / 유료 전환 방식

## 5-1. 유료 콘텐츠 톤 원칙

유료 숏폼 콘텐츠는 시청자가 돈을 낸 보람을 매 화에서 즉각 느껴야 한다.

문제는 다크한 톤 자체가 아니다.
다크한 미감 위에서 주인공이 압도하고 카타르시스가 터지면 작동한다.
문제는 다크함이 오락성과 쾌감을 억누를 때다.

피해야 할 것:

* 보상 없이 억압과 고통만 반복되는 구간
* 쾌감이 지나치게 유보되는 심리 드라마
* 무거운 도덕적 무게감이 주인공의 매력을 덮는 방향

작동하는 것:

* 다크한 세계 위에서 주인공만 압도적으로 빛나는 구조
* 어두운 미감 + 즉각적이고 유쾌한 카타르시스
* 길티 플레저 — 혼자 볼 때 짜릿한 감각

## 5-2. 남성향 애니메이션 타깃 원칙

남성향 AIGC 애니메이션의 핵심 타깃은 일본 애니메이션과 게임 문법에 익숙한 성인 남성이다.

**레퍼런스 프레임:** Solo Leveling, Overlord, 이세계 하렘물, 고인물 판타지.

이 타깃이 기대하는 것:

* 압도적이고 화려한 스케일 (전함, 폭발, 각성 VFX, 궤도 전투)
* 즉각적인 주인공 각성과 시각 보상
* 캐릭터별 선명한 매력과 구분성
* 여성 캐릭터의 명확하고 강한 시각적 매력
* 태도 변화와 함락의 명확한 보상
* 장르 문법의 쾌감 (각성, 정복, 하렘, 압도)

다크는 미감의 방향이지 오락성의 제거가 아니다.
어두운 세계관과 가볍고 짜릿한 쾌감은 공존한다.

## 5-3. AIGC 포맷 선택 원칙

AIGC 제작 포맷은 크게 둘로 나뉜다:

* AIGC 실사형 드라마
* AIGC 애니메이션 (2D / 2.5D / 3D)

이 둘은 완전히 다른 포맷이다. "2.5D 실사풍" 같은 중간 포맷은 존재하지 않는다.
포맷 선택은 기술 문제가 아니라 시청자와 맺는 계약이다.
포맷이 결정되면 애매하게 운용하지 않는다.

**AIGC 실사형 드라마의 위험:**
리얼리즘을 약속하는 순간, 작은 오류가 장르 몰입을 깨는 치명타가 된다.
손·서류·군중 얼굴·물리 액션·얼굴 일관성이 동시에 필요한 장면은 AIGC 실사형에서 깨질 확률이 높다.
쌩실사라면 강점인 장면이 AIGC 실사형에서는 약점이 될 수 있다.

**AIGC 애니메이션 (2D·2.5D·3D)의 강점:**
시청자에게 이렇게 말하는 포맷이다 — "이건 현실 재현물이 아니라 양식화된 판타지다."
이 약속이 걸리면 과장된 악역, 공개 망신, 군중 리액션, 대형 스크린 폭로가 장르로 흡수된다.
애니메이션은 과장을 오류가 아니라 장르 문법으로 바꾼다.

포맷을 섞거나 중간에 두면 위험하다:

* AIGC 실사형: 왜 얼굴이 이상하지? 왜 손이 이상하지? → 몰입 파괴
* AIGC 애니메이션: 이건 원래 양식화된 복수극이다 → 과장이 장르로 흡수됨

## 5-4. AIGC 기획 적합성 체크리스트

원작 또는 기획을 고를 때, 장르보다 쾌감 전달 구조를 먼저 본다 (Section 3-2 적용형).

**AIGC 적합도가 높은 기획:**

* 감정이 오브젝트로 드러난다
* 진실이 화면 / 문서 / 기록으로 폭로된다
* 시선 반전이 있다
* 공개장·재판장·파티장·왕좌방처럼 위계가 보이는 공간이 있다
* 인물이 많이 말하지 않아도 위치와 물건으로 이해된다
* 악역의 거짓말이 한 컷 안에서 깨진다
* 주인공의 승리가 재결합 / 설득보다 퇴장 / 처형 / 소유 / 권한 획득으로 보인다

특히 **"증거극"** 은 AIGC 친화 장르다 — 서류 클로즈업 그래픽화, 대형 스크린 폭로, 타임라인 UI, CCTV 프레임, 군중 정지 리액션. 이 구조는 AIGC가 잘 처리한다.

**AIGC 적합도가 낮은 기획:**

* 감정이 거의 눈빛과 침묵에만 있다
* 사건보다 대화의 미묘함이 중요하다
* 한 공간에서 두 사람이 오래 말한다
* 작은 표정 변화가 결정적이다
* 현실 배우의 자연스러운 생활감이 장르 쾌감이다
* 액션은 많은데 카메라 연속성이 복잡하게 요구된다

## 5-5. AIGC 숏폼 회차 설계 원칙 (편당 길이·총 화수·ROI 게이트)

> Universal 원칙. 모든 AIGC 숏폼 / 회당 결제 모델에 통용됨. 특정 작품·트랙 한정 아님.

AIGC 숏폼 / 회당 결제 모델에서 **화수는 매출의 직접 곱셈 인자**다.
같은 총 러닝타임이라면 **화수가 많을수록 ROI가 높다** — 회당 결제 단가 × 결제 회차 수가 매출이기 때문이다.

따라서 STEP 1 (메타데이터 / 러프 청사진) 단계에서:

- **편당 길이는 보수적으로 짧게** 설계한다 (작가·연출가는 회차가 진행될수록 길이를 늘리는 경향이 있음).
- **총 화수는 공격적으로 많게** 설계한다 (분할 가능한 단위로).

### STEP 1 게이트 (매 신규 작품 점검)

러프 청사진 단계에서 다음 3가지 질문에 모두 답할 수 있어야 한다.

1. **편당 평균 길이 × 총 화수 = 예상 총 러닝타임. 이 값이 룰 범위 내인가?**
   (편당 ≤2분 / 총 ≤90분 / 50화 고정. 바람직 = 75분 내외 — 장르·소재·타깃 가변.)

2. **편당 길이가 늘어날 가능성을 감안했는가?**
   (작가·연출가는 보통 회차 진행에 따라 편당 길이가 늘어나는 경향. 이를 사전에 인지하고 설계했는가?)

3. **편당 길이가 늘어나면 총 화수도 같이 늘릴 수 있는 분할 단위로 설계되었는가?**
   (예: 한 회차 분량이 두 회차로 분할 가능한 사건 단위 구성. 클리프행어 가능 지점이 회차 안에 여러 곳 있어 분할 재편 가능한가?)

### 화수 늘리기 전략 (편당 길이가 늘어났을 때 대응)

- **클리프행어 단위 분할** — 한 사건 안에서 클리프행어 가능 지점이 여러 곳이면, 그 지점마다 회차 절단으로 화수 ↑.
- **장면 단위 분할** — 한 회차가 6~8씬이면, 핵심 장면 직전 절단으로 2~3 회차로 분할.
- **반응 회차 분리** — 큰 사건 직후 캐릭터 반응을 별도 회차로 분리 (관계·감정 갱신 명시).
- **소보상 분산** — 한 회차에 소보상 2개가 묶여 있으면 분리해 화수 ↑.

### 안티패턴 (회차 과소·과대 설계 — 회피)

- **편당 2분 초과 설계** → 룰 상한 위반 / 결제 회차 수 줄어 ROI 손실.
- 편당 90초 미만 설계 → 결제 단가 정당성 약화.
- **총 러닝타임 90분 초과** → 룰 상한 위반.
- 총 러닝타임 60분 미만 → 작품 분량 부족, 광고 컷 풀 부족, 시청자 이탈 압력 ↑.
- **총 화수 50화 이탈** → 룰 위반 (50화 고정).
- **무료 회차 1-8화 이탈** → 룰 위반 (1-8화 고정).
- 한 회차에 클리프행어 가능 지점 2~3개를 묶어 한 회차로 처리 → 화수 손실.

그는 보고, 반응하고, 명령하고, 가져간다.

### 영어 대사 예시 — 작동 vs 죽음

영어로 집필할 때 직접 참조할 수 있는 톤 기준.

**작동하는 대사 (Spoken English · 짧음 · 즉각 반응):**

- `"Don't."` — 한 단어 명령.
- `"Try me."` — 도발 즉답.
- `"You're done."` — 결과 통보 (선언 아님).
- `"Get up."` — 명령.
- `"Walk away."` — 짧은 위협.
- `"I told you."` — 확인.
- `"Sit down."` — 행동 지시.
- `"Mine."` — 한 단어 소유 선언 (행동 후).

**죽은 대사 (자기 설명 · 시적 선언 · 가짜 알파):**

- `"I am the storm that is approaching."` — 자기 설명·시적.
- `"My destiny has brought me to this place."` — 운명 자기 설명.
- `"You don't understand the weight I carry."` — 자기 부담 호소.
- `"I am the alpha now."` — 가짜 알파 선언 (증명 없는 호명).
- `"I have always been the one chosen for this."` — 선택받음 자기 설명.
- `"Some men are born to rule."` — 시적 일반화.

**원칙:** 그는 보고, 반응하고, 명령하고, 가져간다 — He looks, reacts, commands, takes. 자기를 설명하는 동사(`I am ...`, `My destiny ...`, `You don't understand ...`)는 setup에서 거의 항상 약하다. 9-1 5조건이 통과될 때 (증명 누적 후 / 장르 톤 / 톤 정확) 만 살아난다.

## 8-6. 성향별 AIGC 비주얼 보상 원칙

> 시장·포맷 무관 범용 원칙.

AIGC의 시각적 강점(스케일, VFX, 괴물, 전장, 변신)은 모든 성향에 동일하게 작용하지 않는다.
성향에 따라 무엇이 보상으로 느껴지는지가 다르다.

### 남성향

스케일과 힘 자체가 보상이다.

직접 보상으로 작동하는 것:

* 초현실 스케일, 전장, 폭발, 괴물, 권능, 변신, 신화적 공간
* 캐릭터 디자인 쇼, 무기, 거대 전투

남성향의 핵심 쾌감이 이쪽이기 때문이다 —
내가 강해진다 / 압도한다 / 빼앗는다 / 지배한다 / 세계의 위계를 뒤집는다.

→ 스케일과 VFX가 그 자체로 보상이 된다.

### 여성향

스케일은 관계 변화와 지위 역전을 크게 보여줄 때만 보상이 된다.

여성향의 핵심 쾌감:

* 내가 버려졌다 / 선택받지 못했다
* 그런데 위험한 남자가 나를 선택한다
* 모두가 보는 앞에서 내 지위가 뒤집힌다
* 나를 버린 사람들이 후회한다
* 나를 무시한 사람들이 이제 나를 두려워한다

→ 비주얼 보상은 전장 스케일이 아니라 관계와 지위 변화가 눈에 보이는 장면이다.

여성향에서 잘 작동하는 장면:

* 남주가 모두 앞에서 여주를 옆에 세운다
* 여주를 짐승 취급하던 자들이 처음으로 그녀를 두려워한다
* 여주를 버린 가족이 문밖에 세워진다
* 공개 선언, 반지, 최고석, 증거 공개

여성향에서 VFX / 괴물 / 변신이 작동하는 조건:
단순히 크고 멋있으면 안 된다. 그것이 관계 변화를 보여주는 장치일 때만 보상이 된다.

**나쁜 방향 (여성향에 맞지 않음):**
용이 하늘에서 불을 뿜는다 / 성채가 무너진다 / 전쟁이 벌어진다.

**좋은 방향 (여성향에 맞음):**
Dragon Lord가 조용히 일어난다 / 벽 전체에 날개 그림자가 드리운다 /
그가 여주를 자기 옆으로 끌어올린다 / 사절들이 처음으로 여주를 두려워한다.

VFX는 관계 변화를 크게 보이게 만드는 장치다. VFX 자체가 목적이 아니다.

### 여성향 AIGC 콘텐츠 방향 분류

이 분류는 제작 포맷(실사형 / 애니메이션)이 아니라 콘텐츠 설정 방향이다.
같은 콘텐츠 방향이라도 AIGC 실사형 드라마로 갈 수도, 애니메이션으로 갈 수도 있다.

**리얼리즘 여성향** (판타지 설정 없음): VFX·괴물·변신 없이도 작동한다.
- 핵심 장치: 저택, 파티장, 결혼식장, 기자회견, 대형 스크린 폭로, 계약서, 반지, 법정, 회사 로비.
- 핵심 구조: 공개 모욕 → 증거 공개 → 지위 역전 → 버린 자들의 후회.

**로맨타지·판타지 여성향** (판타지 설정 포함): 괴물, 드래곤, 성채, 변신 가능.
- 단, 전투 자체가 보상이 아니라 선택됨, 보호받음, 지위 상승, 위험한 남자의 공개 선언, 여주를 버린 집단의 후회가 핵심이다.

**한 줄 원칙:**
여성향 AIGC에서 중요한 건 화려한 세계가 아니라, 여주의 위치가 화면 안에서 확실히 바뀌는 순간이다.

## 9-1. 남성향 원칙

남성향의 핵심은 다음이다.

* 시각 즉시성
* 힘의 격차
* 소유 / 지휘 / 선택권
* 보상 회수
* 여성 캐릭터의 매력
* 여성 캐릭터의 자발적 반응
* 적의 굴복
* 주인공의 우위

남성향 주인공은 무감정 기계가 아니어야 한다.
그러나 여성향식 인정·구원·위로 중심으로 가면 안 된다.

**좋은 방향:**

* 본다
* 몸으로 반응한다
* 짧게 받아친다
* 바로 명령한다
* 바로 가져간다
* 결과로 증명한다

**여성향식 어휘 — 사용 금지** (남성향 어휘 코드 위반. 선언형 대사 작동 조건과 무관하게 차단):

* 너는 도구가 아니라 너 자신이다
* 내가 너를 인정한다

### 선언형 대사 — 도구로서의 작동 조건

선언형 대사("나는 지배자다", "내 운명이 나를 이곳으로 불렀다", "넌 내 것이야", "해적왕이 될 거야" 등)는 그 자체로 좋거나 나쁜 게 아니다.

**작동 조건이 모이면 어떤 종류든 살아난다. 조건이 빠지면 어떤 종류든 공허해진다.**

#### 작동 조건 5가지

1. **누가 말하는가** — 캐릭터의 위치·권력·인식 한계가 그 말을 할 자격을 만드는가.
2. **언제 말하는가** — 증명 전이냐 후냐. setup이냐 payoff냐.
3. **장르가 요구하는가** — 신화·고전 비극·오페라적 톤이라면 선언형이 장르 문법.
4. **어떤 톤인가** — 진지한 무게 / 자기 인식 / 풍자 / 자조. 톤이 의미를 바꾼다.
5. **무엇이 따라오는가** — 행동·침묵·반응. 말 뒤에 아무것도 없으면 죽음.

#### 예시 재검토 (한국어 / 영어 병기)

**"내 운명이 나를 이곳으로 불렀다" / `"Fate brought me to this place."`**

- 그리스 비극 주인공이 운명을 마주한 순간 → 살아남.
- 신화 무게의 빌런이 자기 정당화로 → 캐릭터 코드로 작동.
- 현대 장르 주인공이 맥락 없이 → 공허. (단, 개그물 등에서는 캐릭터의 매력으로 사용 가능.)

**"나는 지배자다" / `"I am the king."`**

- 절대 악역의 진심 → 캐릭터 코드.
- 주인공이 왕좌에 앉아 → payoff.
- 정복 직전 자기 다짐 → 작동.
- 캐릭터 소개하면서 → 공허. (장르에 따라선 빠른 세계관 설명용으로 사용 가능.)

**"해적왕이 될 거야" / `"I'm gonna be the King of Pirates."`**

- 직후 행동이 따라오면 → 작동.
- 말만 하고 멈추면 → 공허. (장르에 따라서, 허용 가능.)
- 비꼬는 톤이면 → 다른 의미.

#### 적용

남성향에서 선언형 대사를 일률적으로 금지하지 않는다.
**5가지 작동 조건을 통과하는가**를 본다. 통과하면 살아 있다. 통과하지 않으면 빼거나 다시 쓴다.

장르·인물·맥락·톤에 따라 정답이 달라지므로, 이 원칙은 **Soft Lock**이다 (Section 0-3 참조).

# 11. 피칭덱 작성 원칙

피칭덱은 작품 설명서가 아니다.
**피칭덱은 평가위원을 설득하는 문서다.**

**핵심 기준:** 평가위원이 표적 시청자가 아니어도 **"내가 보지 않더라도 뭐가 재밌는지는 알겠다"** 가 즉시 떠올라야 한다.
이해되는 것이 1차가 아니다. **매력이 식별되는 것**이 1차다.

피칭덱은 다음 질문에 답해야 한다.

* 이 작품은 무엇인가?
* 누구를 타깃으로 하는가?
* 왜 지금 필요한가?
* 왜 이 플랫폼에 맞는가?
* 왜 돈이 될 수 있는가?
* 왜 AIGC 제작에 적합한가?
* 어떤 비주얼로 팔 수 있는가?
* 무료회차에서 어떻게 붙잡는가?
* 유료회차로 어떻게 넘기는가?

피칭덱은 길게 설명하기보다 명확하게 설득해야 한다.
피칭덱은 고정된 평가위원 / 피칭 대상 정보에 맞춰 조정한다.

**예:**

* 평가위원이 시장성을 중시한다면 수익화 구조를 앞세운다.
* 평가위원이 제작 가능성을 중시한다면 AIGC 제작 안정성을 앞세운다.
* 평가위원이 IP성을 중시한다면 캐릭터, 세계관, 확장성을 앞세운다.
* 평가위원이 플랫폼 적합성을 중시한다면 회차 구조와 유료 전환 설계를 앞세운다.

**피칭덱에서 피해야 할 것:**

* 추상적 찬사
* 장황한 세계관 설명
* 작품 줄거리만 길게 나열
* 비주얼 근거 없는 "매력적" 주장
* 유료 전환 이유가 없는 무료회차 설명
* AIGC 제작 적합성 없이 "AI로 만들 수 있다"는 주장

## 11-1. 피칭덱 양식 표준 (필수, 2026-05-09 update)

**기본정보 항목 (필수, 누락 시 자동 fail):**

- 타이틀 (Titles): **영어 + 한국어 두 줄**
- 담당 CM: @Rowan Lee
- 장르 (Genre): **한국어**

- 타깃층: 국가 + 성별 + 나이 + 선호 카테고리

  - **세로형 (9:16)** vs **가로형 (16:9)** — 모바일 vertical 기본 9:16, 액션·게임 친화 남성향은 16:9 가능

- 특이사항·피칭 회의 피드백·개선 방향: 빈 칸 (사용자가 채움)

## 11-2. 금지 표현·어휘 (필수, 2026-05-09)

**단어급 금지:**
- 폐기 / 폐기된 / 폐기하다 → "버려진 / 지워진 / 추방된 / 잘라낸"
- 코어 / Core (분석문에서) → "핵심 / 중심" (단 "Core Expectation" 양식 헤더는 유지 가능)
- 호명 / 호명과 위치 → "이름·자리 / 그녀를 부르는 말 / 그녀가 서는 자리"

**문장급 금지 패턴:**

A. "이 작품의 핵심은 ~가 아니라 ~이다" 류 — 의미 없는 자기 변명. 곧바로 결론 적시.

B. 학술 추상어로 장면 대체:
- 금지: "그녀의 호명과 위치를 바꾸는 남주"
- 금지: "회사 시스템과 루프 사이에 남는 작은 균열"
- 대체: 화면에 무엇이 보이는지 직접 — "보안 화면에 ANOMALY DETECTED가 뜬다"

C. 자체 조어·중2병 과도 극화 — 시청자가 모르는 단어로 작품 설명 X.

D. PC주의 회피 표현:
- 금지: "차별점은 은밀한 친밀감보다 공식 지위 역전을 중심 보상으로 둔 점. 침실 긴장감보다 ~"
- 이유: 침실 긴장감·금지된 끌림이 여성향에서 압도적으로 잘 팔린다. 회피 X. 함께 작동한다고 솔직히.

**원칙:**
- 주장 없이 설명만 하지 말 것 — 근거 바탕으로 직접 주장
- 추상어 부풀리기 금지 — 화면에 무엇이 보이는지 직접 적시
- 자체 조어 만들지 말 것

## 11-3. 피칭사유 작성 — 밀도·논리·줄글 (필수, 2026-05-09)

피칭사유 (왜 제작 / 시장성 / 변별력) 작성 강제:

- **줄글로 작성** — 표·엑셀·글머리 X
- **충분한 분량** — 각 질문 4-6 문장 한 단락 이상
- **밀도 + 논리:** 빈 문장 X, 추상어 부풀리기 X, 근거→주장 흐름
- **쉬운 언어:** niche 어휘 X, 자체 조어 X, 학술어 X
- **직관:** 위원이 첫 줄 보고 즉시 이해 / "왜 클릭하고 결제하는가" 즉시 보이게

**좋은 예시 (참고용 — 해야만 하는 쉐어하우스 시즌3 패턴):**
- 각 주장에 **소제목 + 구체 근거 / 검증 사례 / 수치**가 따라옴
- 흐름 자연스러움 — "왜 만들어야 하는가" → "어떻게 시장에서 작동" → "어떻게 차별"
- 줄글이지만 단락 단위로 정리되어 빠르게 읽힘

**잘못된 예시 (절대 금지):**
- "각 신전 가문을 하나씩 장악하는 구조" 류 — 위원이 보면 "그래서?" 반응
- "이 작품의 핵심은 ~가 아니라" 류 빈 문장
- 자체 학술 조어 ("호명과 위치 바꿈" / "공식 지위 역전")

## 11-4. 트리트먼트 = 장면 기술 (필수, 2026-05-09)

**원칙:** 트리트먼트는 **무엇이 일어나는가**를 써야지 **무엇을 의미하는가**를 써선 안 됨.

**잘못된 예 (시청자에게 의미 풀이):**
- "이 배지는 회사 시스템과 루프 사이에 남는 작은 균열을 보여준다."
- "그녀의 호명과 위치를 바꾸는 남주."

**올바른 예 (장면 직접 기술):**
- "보안 화면에 칼의 배지 번호와 함께 ANOMALY DETECTED가 뜬다."
- "바엘은 사절단의 말을 끊고 일어선다. 그는 이솔데를 자기 옆으로 끌어올리고, 그녀가 더 이상 제물이 아니라 자신의 신부라고 선언한다."

**필수 요소 (회차마다):**
- 누가 누구에게 무엇을 빼앗기고 있는가 (갈등)
- 이 회차에 어떤 비트가 추가되었는가 (구조)
- 다음 회차로 어떤 질문이 열리는가 (클리프행어)

**금지:**
- 인물 행동 줄줄이 묘사만 (갈등·관계·구조 보이지 않음)
- 의미·해석·시청자 풀이 문장
- 관념어로 장면 대체 (개념만 적고 실제 장면 누락)

## 11-5. 작품 직관성·밀도·명쾌함 (필수, 2026-05-09)

**원칙:** 피칭덱·청사진·트리트먼트만이 아니라 **작품 그 자체**가 직관·밀도·명쾌해야.

- **명쾌:** 회차마다 갈등·위치·인물 관계가 한 눈에
- **밀도:** 중요한 비트만 남기고 빼냄. 자잘한 묘사·해설 누적 X
- **직관:** 시청자가 "지금 누가 뭘 빼앗았고 누가 뭘 되찾는가" 회차마다 명확

**숏폼 vs 영화 구분:**
- 영화 흐름 (천천히 풀어지는 인과·내적 심리 비트 누적): 금지
- 숏폼 vertical (50화 × 2분): 회차당 1-3개의 강한 비트, 직선 쾌감 — 모욕·각성·정복·공개 역전, 회차 끝 클리프행어가 다음 화 질문으로 직접 연결

**직선 쾌감 — 작품 코어:**
- 남성향: 모욕→각성→압도→강탈→정복→공개 굴복
- 여성향: 추락→무시→증거 발견→공개 역전→남주의 공개 소유 선언

**금지:** 핵심 쾌감을 우회·분산·PC주의·안전·밋밋 처리

## 11-6. 여성향 로맨스 필수 (필수, 2026-05-09)

여성향 작품(타깃 여성)은 **장르 무관 로맨스 트랙 필수**. 메인 아니어도 비워두지 않음.

**남주 필수 조건:**
- 압도적 외모 + 좋은 몸매 + 섹시함
- 강한 능력 + 높은 지위·재력 (재벌·가주·드래곤 로드·초능력자)
- 알파남 — 통제권을 쥔 남자
- **여주에게만 홀딱 빠짐** — 다른 여자에게 한눈팔지 않음

**로맨스 톤 (작품 톤 따라 가변):**
- 집착적인 남자 (광기·소유욕)
- 전긍정 남자 (모든 면에서 여주 편)
- 차갑지만 여주에게만 무너지는 남자
- 위험한 남자지만 여주만 안전권에 두는 남자
→ 성격 다양해도 **여주에게만 약한 점** 공통

**로맨스 발생 조건:**
- 돈·능력·가문 인과 X
- 여주의 성격·태도·기개·고유 매력에 끌림
- 결과적으로 그 남자가 마침 재벌·가주·로드일 뿐 — **마침 돈도 많은 백마탄 왕자** 연출

**침실 긴장감 + 금지된 끌림 (필수, 회피 금지):**
- 손등 비늘·낙인·흉터를 통한 신체 접촉
- 키스 직전의 정지 / 뜨거운 숨
- 가까워지는 거리 (close shot)
- 어깨 끌어당김·손목 잡힘
- 위험한 남자가 여주에게만 보이는 무방비
- 공개 소유 선언 (모두 앞에서 그녀를 자기 옆에 세움)

**작품 메인이 복수극이어도 로맨스 트랙은 비워두지 않음.**

## 11-8. 피칭덱 작성 원칙 마스터 (필수, 2026-05-09 사용자 직접 작성)

피칭덱은 **작품을 해설하는 문서가 아니다.** 위원이 작품을 직접 본 것처럼 이해하게 만드는 문서. 청사진·러프·트리트먼트 등 외부 노출 문서 모두 동일.

**최상위 락:** 작품 밖에서 말하지 말 것. 작품 안에서 실제로 벌어지는 일·인물의 처지·빼앗기는 것·뒤집히는 자리·남겨지는 갈등만 쓸 것.

### 11-8-1. 문체 금지 락

**A. 개념어로 사건 대체 금지:**
- 금지: 구조 보유 / 작동한다 / 기능한다 / 가능하다 / 확장 가능 / 시장성 보유 / 결제 질문 형성 / 중심 보상 / 핵심 보상 / 시각적 증거 / 권력 이동 / 정서적 축 / 관계성 확장 / 이해 비용 / 방향이 보인다 / 한눈에 잡힌다 / 첫눈에 잡힌다 / 화면에 남긴다

문제: 전문 용어라 금지인 게 아님. 실제 사건을 말하지 않고 작성자의 머릿속 정리를 그대로 내보내기 때문.

나쁜 예: "복수·각성·정복 구조 보유." → 좋은 방향: "카엘은 처형대 위에서 집행자의 검을 맨손으로 붙잡고, 그의 손에서 번개가 터진다."

**B. 메타 해설 금지:**
- 금지: "세계관을 길게 설명하지 않아도 방향이 보인다." / "광고 컷으로 잘라 쓰기 쉽다." / "강한 후킹을 만든다." / "시청자가 궁금해진다."

작성자가 옆에서 해설하는 말이므로 외부 피칭에서 거절됨.

나쁜 예: "병원에서 깨어난 레나가 TV 속 자기 이름의 가짜 약혼녀를 보는 장면은 광고 컷으로 잘라 쓰기 쉽다." → 좋은 방향: "병원 침대 위의 진짜 레나와 TV 화면 속 가짜 레나가 같은 이름으로 동시에 존재한다."

**C. 빈 평가 금지:**
- 금지: "시장성이 있다." / "후킹이 좋다." / "변별력이 선명하다." / "보상이 강하다." / "전환이 쉽다."

피칭덱은 평가 주장이 아니라 평가가 가능하도록 근거 놓는 문서.

**D. "단순한 A가 아니라 B다" 패턴 남발 금지:**
- 금지: "단순한 제물 서사가 아니라…" / "단순히 남자를 빼앗긴 이야기가 아니라…"

방어적. 읽는 사람이 아직 A라고 안 했는데 작성자가 먼저 변명하는 모양.

**E. 사람을 물건처럼 만드는 단어 금지 (캐릭터 소개):**
- 금지: 폐기된 / 처리된 / 자산 / 변수 / 장치 / 도구로 기능 / 포지션 / 축

나쁜 예: "폐기된 반신" → 좋은 예: "이름과 권리를 빼앗기고 신전 격투장에 던져진 반신"

**F. "화면" 단어로 도망치지 마라:**
- 금지: 화면에 남긴다 / 화면으로 보여준다 / 시각적으로 증명한다 / 장면으로 구현된다 / 이미지 자산 / 시각 보상

나쁜 예: "반지·검·이름·문장이 권력의 이동을 화면에 남긴다." → 좋은 예: "반지는 카엘의 손으로 넘어가고, 검은 주인을 바꾸며, 귀족들은 그를 내려다보던 자리에서 뒤로 물러난다."

### 11-8-2. 항목별 원칙

**로그라인:**
- 설정 설명 X
- 누가 무엇을 빼앗기고 / 어디서 어떻게 뒤집는가 / 적대자 누구인가 / 초반 전환점 / 유료 구간으로 넘어갈 더 큰 갈등 남김
- 나쁜 예: "그는 반복된 죽음을 생존 경로로 바꾸며 시스템에 접근한다." → 좋은 예: "그는 죽을 때마다 괴물이 나타나는 길과 닫히는 문을 기억하고, 마침내 자신의 사망 기록이 남은 Asterion 통제구역에 도착한다."

**인물 소개:**
- 설정표 X
- 그 인물이 주인공에게 무엇을 빼앗고/유혹하고/막는지
- 금지: ~을 보여준다 / ~로 기능한다 / ~의 기준이 된다 / ~의 축이다 / ~의 상징이다 / 후반부의 핵심 인물이다
- 핵심 질문: 누구 편인가 / 무엇을 요구하는가 / 어떻게 흔드는가 / 초반 어떤 장면

**왜 제작해야 하는지:**
- 줄거리 재요약 X / 사업어 X
- 작품 안 근거 우선. "따라서 시장성이 있다" 결론문 금지
- 좋은 예: "리비아는 시아버지의 죽음 옆에 있었다는 이유로 범인처럼 몰리고, 남편은 임신한 내연녀를 가족 앞에 세운다. 그런데 실라스의 유언장은 애드리언이 아니라 리비아를 상속자로 지목한다."

**시장성:**
- 빈 주장 금지
- 무료 구간 마지막에 안 끝난 갈등 / 유료 구간에 남는 굴욕·폭로·역전 / 다음 회 확인해야 할 사건 명시
- **무료 구간 한도 (필수):** 무료 구간 = 첫 증거만. 가장 큰 굴욕·역전·폭로는 유료 구간에 남김
- 작품별:
  - TITAN BORN: 신성 반지 강탈까지만. 신전 장악·제우스 대면 남김.
  - THE OFFERING: 신부 선언까지만. 바엘 이유·인간 왕국 약속 남김.
  - I AM THE HEIR: 첫 상속 권한 공개까지만. 회사 장악·사망 진실 남김.
  - THE LAST KEY: 봉인이 되돌아갈 수 있다는 첫 역전까지만. 가족 전체 붕괴·고대 신 요구 남김.
  - SHE STOLE MY FACE: 증거 발견까지만. 공개 폭로·후회남 반응 남김.
  - EVERY MONDAY: 회사가 알고 있었다는 화면까지만. 루프 목적·칼 특이성 남김.

**크리에이티브 변별력:**
- "차별점은 ~라는 점" X
- 무엇이 더 세게 빼앗기고 더 세게 뒤집히는지
- 좋은 예: "마라는 레나의 약혼자만 빼앗는 것이 아니라, 레나의 얼굴, 이름, 흉터, 어머니 목걸이, 어린 시절 영상까지 자기 것으로 사용한다."

**줄거리:**
- 내부 구조 설명 X
- 사건의 흐름 (누가 죽는다/밀려난다/들어온다/공개된다/빼앗는다/밀려난다)
- 금지: 유료 구간에서는 ~로 확장된다 / 후반부에는 ~가 연결된다

**트리트먼트:**
- 회차별 정보 요약 X
- 처지가 어떻게 악화되거나 뒤집히는지
- 단서 발견만으로 끝나는 클리프행어 약함 — 정보가 인물 처지 변화 동반
- 회차별 질문: 더 불리해졌나 / 첫 반격했나 / 누가 자리 빼앗았나 / 무엇이 이동했나 / 다음 화 봐야 할 이유

6. 무료 구간에서 첫 증거만 주고 더 큰 보상은 남겼는가?
7. 외부 피칭에 그대로 들어가도 부끄럽지 않은가?

이 7 검수를 통과하지 못하면 다시 써야 함.

## 11-9. 보상 유예의 본질 (필수, 2026-05-09 사용자 직접 명시)

**모든 숏폼 콘텐츠는 근본적으로 '원초적 욕망의 보상'.** 현대인의 보편적 결핍에 기초한 욕망의 보상. 무료회차에서 보상 X. 보상이 이뤄질 걸 시청자가 예상하지만 계속 안 나와서 답답해함. 페이월 화 엔딩이 가장 강하게 설계.

### 11-9-1. 보상 유예 = 단순 시간 유예 X

**잘못된 이해:** 보상을 단순히 뒤로 미룸.

**올바른 이해:** 작품의 내용이 욕망의 해소를 더욱 강하게 느끼게끔 함. 작중 인물의 처지가 욕망 해소를 점점 더 갈망하게 된다.

### 11-9-1-A. 갈망 강화 방식은 장르·작품마다 다르다 (필수, 2026-05-09 사용자 명시)

**한 가지 방식("고난·핍박·폭력·모욕 강화")을 모든 작품에 강제 X. 절대 안 된다.**

사용자 명시:
- "'고난, 핍박, 폭력, 모욕 이런 것들의 빈도/강도가 더더욱 쌔지는 것'은 예시에 불과하다. 주로 역전극, 복수물 이런 류의 예시이다."
- "장르와 작품 스토리, 서사에 따라, 시청자들이 원하는 욕망이 다르다."
- "어떤 보상의 유예를 오직 주인공에게 고난을 주거나, 핍박을 하거나, 폭력과 모욕을 선사하거나 이런 방식으로만 하는 것은 절대 안 된다."

연기해야 할 장면을 보여지는 절차로 바꿔야 한다.

**나쁜 설계 (감정 목표):**
남편이 후회한다.

**AIGC식 설계 (장면 절차):**

여주는 한마디만 한다.

처형 절차를 먼저 설계하고, 감정은 그 결과로 읽히게 한다.
절차가 명확하면 감정 지문이 없어도 시청자가 감정을 읽는다.

# 14. 시나리오 작성 원칙

시나리오는 타깃 언어로 작성한다.

* 북미 타깃이면 영어
* 일본 타깃이면 일본어
* 한국 타깃이면 한국어

대사와 지문 모두 타깃 언어에 맞춘다.

각 화는 1분~3분 숏폼에 맞게 압축한다.

각 화에는 다음이 있어야 한다.

* 명확한 시작 상황
* 눈에 보이는 사건
* 캐릭터의 선택 또는 충돌
* 시청자가 다음 화를 보고 싶게 만드는 끝점

## 14-1. Script 우선순위

시나리오는 다음 우선순위를 따른다.

1. 청사진과 충돌하지 않을 것
2. 시청자가 화면 또는 대사로 이해할 수 있을 것
3. AIGC가 만들 수 있는 물리적 지문일 것
4. 캐릭터가 자기 인지 한계 안에서 말할 것
5. 대사가 기능만 수행하지 않고 살아 있는 반응을 가질 것
6. 장면 끝에서 관계 / 정보 / 주도권 / 감정 / 상황 중 하나가 갱신될 것

## 14-2. 대사 원칙

대사는 다음 중 하나로 작동해야 한다.

* 명령
* 거절
* 확인
* 위협
* 도발
* 유혹
* 거래
* 반응
* 정보 고정
* 관계 변화
* 압박

**죽은 대사:**

* 화면 정보 낭독
* 세계관 브리핑
* 주제 설명
* 모든 캐릭터가 Yes / No로만 받는 구조
* 멋있는 척하는 선언형 대사
* 기능만 수행하는 도구식 대화
* 반복되는 평가 발화

**살아 있는 대사:**

* 정보 확인 뒤 반응이 있다.
* 상황을 보고 즉흥성이 있다.
* 인물이 자기 성격대로 받아친다.
* 말이 다음 행동을 만든다.
* 장면의 관계나 주도권을 바꾼다.

## 14-3. 정보 대사 원칙

시청자가 놓치면 망하는 정보는 대사로 짚을 수 있다.
단, 캐릭터 목적 안에서 말해야 한다.

**좋은 방향:**

* 지금 화면에 보이는 것에 반응한다.
* 캐릭터가 당장 필요한 정보를 말한다.
* 대사가 다음 행동으로 이어진다.
* 정보가 감정이나 갈등과 함께 전달된다.

**나쁜 방향:**

* 캐릭터가 관객을 위해 설명한다.
* 세계관을 강의한다.
* 이미 보이는 화면을 그대로 읽는다.
* 대사가 장면을 멈추게 만든다.

# 15. 정보 공개 원칙

큰 reveal은 한 장면에서 모두 해결하지 않는다.

가능하면 다음 단계로 분산한다.

1. **Setup**
   관객과 인물이 특정 기대를 갖는다.

2. **First Contact**
   예상과 다른 시각 정보를 준다. 단, 정답은 주지 않는다.

3. **Re-read**
   두 번째 사례를 통해 처음 본 정보를 다시 읽게 한다.

4. **Confirmation**
   데이터, 행동, 시스템, 결과, 대사로 확정한다.

5. **Payoff**
   확정된 정보가 더 큰 의미로 폭발한다.

작은 reveal에서 큰 reveal의 단어를 쓰지 않는다.
같은 단어가 반복되면 큰 reveal의 무게가 죽는다.

# 16. 내부 핍진성 원칙

현실적으로 완벽할 필요는 없다.
하지만 작품 내부에서는 설명 가능해야 한다.

**검토 기준:**

* 이 사건은 세계 규칙 안에서 가능한가?
* 이 캐릭터는 이 정보를 알고 있는가?
* 이 선택은 직전 압력에서 나왔는가?
* 강한 행동 뒤에 결과와 잔향이 남는가?
* 물건 위치가 이어지는가?
* 공간 동선이 이어지는가?
* 상처 / 피로 / 비용이 사라지지 않는가?
* 같은 규칙이 다른 장면에서 다르게 작동하지 않는가?
* 권한 / 소유권 / 시스템 상태가 장면마다 일관되는가?

핍진성은 장르 쾌감의 적이 아니다.
핍진성은 쾌감이 무너지지 않게 받치는 내부 구조다.

# 17. Layer / 수위 관리 원칙

Layer는 자동으로 켜지지 않는다.
Layer는 기본 서사와 기본 미모를 대체하지 않는다.

Layer를 사용할 경우 먼저 정한다.

* Layer의 기능
* 적용 대상
* 강조 포인트
* 금지 포인트
* 빈도 상한
* 캐릭터별 우세 포인트
* 플랫폼 제한
* 국가별 제한

수위는 작품마다 다르다. 따라서 제한 수위는 프로젝트별 입력값에서 결정한다 (Section 2-2).

## 17-1. Layer 사용 시 주의

* 성적 표현은 장면 기능과 연결되어야 한다.
* 폭력 표현은 장르 쾌감과 연결되어야 한다.
* 관계 변화 없는 자극은 줄인다.
* 특정 부위나 특정 행위에 반복 집착하지 않는다.
* 일반 타깃을 좁히는 과도한 페티시화는 피한다.
* 플랫폼 제한을 넘지 않는다.

## 17-2. 섹슈얼 씬 샷·라인 레벨 디테일 (필수)

섹슈얼 씬은 행위 단위 설계로 끝나지 않는다. **샷·라인 레벨까지 디테일하게** 적시한다. "키스한다" "안는다" "베드 씬" 같은 한 줄 처리 절대 금지.

이유 — AIGC 영상으로 박히는 수위·sensual 강도는 *그 행위가 어떻게 진행되는가*의 라인·샷 디테일에서 결정된다. 한 줄 처리하면 AIGC는 평범한 입맞춤·평범한 베드 씬으로 생성한다. 함량이 휘발된다.

### 키스 씬 — 수위 높을수록 디테일 필수

라인 레벨 명시 항목:

* 누가 먼저 다가오는가 (턱을 잡고·까치발로·부딪치듯)
* 입술이 어떻게 닿는가 (스치고 떨어졌다가·깨물듯이·짓누르듯이)
* **혀가 어떻게 얽히는가** — 누가 먼저 혀를 넣고, 상대는 받아들이는지·저항하는지·결국 따라오는지
* 상대의 반응 — 숨이 막힘·신음이 새어 나옴·손이 어디로 가는지 (셔츠 잡음·머리채 잡힘·옷자락 움켜쥠)
* 깊이의 변화 — 가볍게 시작 → 깊게 / 처음부터 강제로 깊게
* 끝나는 방식 — 떨어졌다 다시·한쪽이 거세게 끝냄·입술이 부어오른 채

금지 처리:

* "그가 그녀에게 키스한다."
* "두 사람이 키스한다."
* "깊은 키스가 이어진다."

권장 처리 예시:

* `He grips her jaw, tilts her face up, presses his mouth against hers. Her lips part — his tongue pushes in, and she gasps into his mouth before her hands fist in his collar.`

### 베드 씬 — 클로즈업·신체 부위 명시 필수

[Camera] 블록에 **매 컷 무엇이 잡히는지** 적시:

* 침대보를 움켜쥔 여주의 손 (CLOSE: HER FINGERS — knuckles white, gripping the silk sheet)
* 등에 손톱 자국이 남는 남주의 어깨 (CLOSE: HIS BACK — red welts where her nails dragged)
* 베개에 묻힌 여주의 옆얼굴 (CLOSE: HER PROFILE — mouth open, hair stuck to sweat on her temple)
* 침대 가장자리에 떨어지는 드레스 / 헤드보드에 부딪히는 그림자 / 흔들리는 캐노피
* 발끝이 시트를 차는 컷·허벅지가 떨리는 컷·목에 남는 잇자국 클로즈업

카메라 거리·각도 명시: CLOSE / EXTREME CLOSE / OVER-THE-SHOULDER / LOW ANGLE / MACRO FOCUS.

[FX]에 사운드 디테일: 숨소리·헤드보드 소리·시트 마찰음·신음.

금지 처리:

* "두 사람이 사랑을 나눈다."
* "베드 씬이 이어진다."
* "정사 장면."

### 다른 sensual 씬도 동일

* 옷 벗기는 장면 — 어느 손가락이 어떤 끈을 푸는지·끈이 떨어지는 컷·드러나는 어깨 라인 클로즈업
* 목 깨물기 — 입술이 목에 닿는 클로즈업·이가 박히는 순간·자국이 남는 풀샷
* 강제 자세 — 누가 누구를 어디에 어떻게 밀어붙이는지·손이 어디를 잡는지·여주의 발끝·허벅지

### 자가 검수 (매 sensual 씬 통과 필수)

1. 한 줄 요약(키스/안음/사랑)으로 처리한 부분이 있는가? → 즉시 디테일 추가
2. 누가 먼저·어떻게·상대 반응이 적혀있는가?
3. [Camera]가 무엇을 잡는지 명시되어 있는가?
4. 시청자가 한 컷씩 머릿속에 그릴 수 있는가?
5. AIGC 생성 시 평범한 입맞춤·평범한 베드 씬으로 빠질 여지가 있는가?

### 적용 범위

* 모든 여성향 sensual 작품. 특히 북미 paid vertical·다크 로맨타지·초고수위 작품에서 강제.
* 남성향에서도 sensual 씬 등장 시 동일 — "안는다" 한 줄 처리 X.
* 17-1의 "장면 기능 연결" 원칙은 그대로 유지 — 디테일이 풍부해도 서사 기능 없는 sensual은 약점.

### 검토 trigger

phase_5 검토에서 페르소나 01 (Intimacy)·02 (Production Director)가 한 줄 처리 발견 시 자동 🟡.

# Part VI — 제작 (Production)

# 18. AIGC Production Direction 원칙

Production Direction은 제작자와 연출가에게 주는 구현 가이드다.
이 문서는 Script를 바꾸는 문서가 아니다.

## 18-1. 제작자가 조정 가능한 것

* 카메라 거리
* 샷 사이즈
* 컷 길이
* 렌즈 감각
* 조명 세기
* 표정 강도
* 액션 타이밍
* 소품 디테일
* 배경 밀도
* FX 강도
* 렌더 질감

## 18-2. 제작자가 임의 변경하면 안 되는 것

* 캐릭터 핵심 실루엣
* 캐릭터 간 위계
* 대사의 의미
* 정보 공개 순서
* 아이템 소유자
* 아이템 기능
* 세계 규칙
* 권한 구조
* 관계 변화
* 페이월 보상
* payoff 어휘

## 18-3. Script와 연출의 관계

Script의 대사와 사건은 기준이다.

Visual / Camera / FX는 연출 참고로 조정 가능하다.
하지만 정보 전달 기능을 훼손하면 안 된다.

연출가는 표현 방식을 바꿀 수 있다.
연출가는 시청자가 받아야 하는 정보를 바꿀 수 없다.

## 18-4. 핵심 오브젝트 동시 설계 원칙

AIGC에서는 대본만 먼저 쓰면 안 된다.
핵심 쾌감이 오브젝트와 구도로 전달되기 때문이다.

소품은 감정선의 일부다. 나중에 정하면 늦다.

**초반부터 잠가야 할 핵심 오브젝트 목록:**

* 주요 캐릭터별 기본 룩과 시그니처 아이템
* 감정 비트를 전달할 핵심 소품 (서류, 반지, 봉투, 상자, 기록물 등)
* UI / 그래픽 요소 (스크린 디자인, 타임라인, CCTV 프레임 등)
* 감정 역전 장면의 공간 배치와 군중 구도
* 각 캐릭터의 위계를 나타내는 위치 코드

대본 집필 → 오브젝트 설계 → 장면 설계를 동시에 진행한다.
오브젝트가 확정되지 않은 장면은 완성된 장면이 아니다.

# 20. 검토 원칙

검토자는 취향 개선이 아니라 문제 발견을 우선한다.

검토할 때는 다음을 구분한다.

* 진짜 오류
* 약점
* 선택 가능한 개선점

* 취향 차이

모든 문제를 고치려고 하지 않는다.

**수정 우선순위:**

1. 제작 중단급 오류
2. 정합성 / 연속성 / 논리 오류
3. 시청자가 이해하지 못할 정보 누락
4. 유료 전환 약화
5. 캐릭터 매력 훼손
6. 타깃 언어 부자연스러움
7. AIGC 제작 불가능 지문
8. 제한 수위 위반 가능성

# 21. 패치 / 수정 원칙

수정은 작고 정확해야 한다.

**좋은 수정:**

* 문제 지점을 정확히 짚는다.
* 왜 문제인지 설명한다.
* 어디를 바꿀지 제시한다.
* 바꿀 문장을 바로 붙여넣을 수 있게 준다.
* 기존 장면의 쾌감을 유지한다.
* 새 설정을 불필요하게 추가하지 않는다.

**나쁜 수정:**

* 전체를 다시 쓰자고 한다.
* 새 설정을 함부로 추가한다.
* 캐릭터 매력을 약화시킨다.
* 대본을 안전하지만 밋밋하게 만든다.
* 시각적 쾌감을 줄인다.
* 문제보다 큰 수정을 만든다.

**패치 형식 기준:**

* FIND는 실제 대본의 정확한 문장이어야 한다.
* REPLACE는 바로 붙여넣을 수 있어야 한다.
* EP 번호, Scene 번호, Scene 제목, Block 이름을 명확히 쓴다.
* 수정은 가능한 한 최소화한다.
* 하나의 패치는 하나의 문제를 해결한다.
* 패치가 새 문제를 만들 가능성이 있으면 보류한다.

# 22. 재검토 원칙

패치 후에는 반드시 재검토한다.

**재검토의 목적:**

* 원래 문제가 해결되었는가?
* 새 오류가 생기지 않았는가?
* 캐릭터 매력이 약해지지 않았는가?
* 시각적 쾌감이 줄어들지 않았는가?
* 유료 전환이 약해지지 않았는가?
* 대사가 더 부자연스러워지지 않았는가?
* 제작 명료성이 좋아졌는가?

재검토 결과가 계속 반복되면 사람 판단으로 넘긴다.
AI가 무한 수정하면서 작품을 무색무취하게 만들면 안 된다.

# 23. 최종고 판단 기준

최종고는 아래 4개 게이트를 모두 통과해야 한다.

## 23-1. Structure Gate

* 시청자 결핍이 초반에 선명한가?
* 욕망이 한 줄로 고정되는가?
* 무료 구간이 하나의 보상으로 수렴하는가?
* 페이월 직전 절단이 강한가?
* 유료 초반에 약속한 보상을 회수하는가?

## 23-2. Narrative Gate

* 캐릭터 캐논이 흔들리지 않는가?
* 관계 원리가 유지되는가?
* 세계 규칙이 일관되는가?
* 정보 공개 순서가 설계되어 있는가?
* 큰 reveal의 어휘가 작은 reveal에서 소모되지 않았는가?
* 캐릭터가 알 수 없는 정보를 말하지 않는가?

## 23-3. Script Gate

* 대사가 기능만 수행하지 않는가?
* 캐릭터가 살아 있게 반응하는가?
* 주제 설명 대사가 아닌가?
* Visual 지문은 물리적인가?
* AIGC가 만들 수 있는가?
* 장면 끝에 관계 / 정보 / 주도권 / 감정 / 상황 중 하나가 갱신되는가?

## 23-4. Production Gate

* 공간 동선이 이해되는가?
* 아이템 위치가 이어지는가?
* 캐릭터 외형 락이 유지되는가?
* 권한 / 시스템 / UI 정보가 충돌하지 않는가?
* 섹슈얼 포인트가 장면 기능과 연결되는가?
* 페티시 과잉으로 일반 타깃을 좁히지 않는가?
* 연출 변경이 정보 전달 기능을 훼손하지 않는가?

# 24. 최종 핵심 규칙

## 단계별 잠금

- **상위 구조**로 욕망을 잠근다.
- **청사진**으로 캐릭터와 세계를 잠근다.
- **회차 설계**로 보상과 정보 공개 순서를 잠근다.
- **시나리오**로 물리적 장면과 살아 있는 대사를 구현한다.
- **Production Direction**으로 AIGC가 안정적으로 만들 수 있게 제한한다.

## 한 줄 요약

**AIGC 콘텐츠는 설명문이 아니라 구현물이다.**

멋있는 말을 쓰지 말고, 멋있는 상황을 만든다.
그러나 시청자가 놓치면 망하는 정보는 캐릭터 목적 안에서 분명히 짚는다.

## 8가지 기본 원칙

1. 짧게 보여준다.
2. 화면으로 이해시킨다.
3. 필요한 정보는 대사로 고정한다.
4. 캐릭터는 자기 성격대로 반응한다.
5. 각 장면은 끝날 때 무언가를 바꾼다.
6. 무료 구간은 하나의 결제 이유로 수렴한다.
7. AIGC가 구현할 수 없는 지문은 좋은 지문이 아니다.
8. 최종고는 아름다운 문서가 아니라 제작 가능한 대본이어야 한다.
