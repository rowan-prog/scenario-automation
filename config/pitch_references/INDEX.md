## 작성 원칙 (통과작 공통)

1. **로그라인 1문단:** 누가 무엇을 빼앗기고 / 어떤 상황에서 / 어떤 변화가 시작되는가 (사건 중심 묘사)
2. **인물 소개:** 행동·관계·욕망 위주 (분석어 X)
3. **레퍼런스 명시:** 검증된 IP·플랫폼 성과 수치 (예: "원작 125M+ 뷰", "RS 신작 1위", "REDICE 웹툰 1,854만")
4. **피칭사유 3축:** 왜 제작 / 시장성 / 변별력 — 각각 사실 진술 우선
5. **초반 트리트먼트:** EP1 ~ Paywall화. 각 회차 명확한 사건·클리프행어 표기
6. **AI 변별력 명시:** 일반 실사로 못 만드는 비주얼 요소 구체 나열 (변신·VFX·시대극 세트 등)
7. **시대극 / 판타지 변환:** 현대 학교·기업 배경의 검증 IP를 AIGC 강점 살리는 판타지 시대극으로 재해석

## 비통과 회피 원칙 (Sealed Bride 분석)

1. **정보량 폭격 회피:** EP1-7에 새로 이해해야 할 mythology 설정 1-2개로 제한
2. **종교 IP 직접 차용 회피:** 666·휴거·일곱 봉인 등 직접 차용 X (Twilight·Lucifer 톤 회피 학습)
3. **시장성 근거 정확 매핑:** Bible 시청자 ≠ supernatural romance 시청자 (시장 혼동 X)
4. **트리트먼트 문체:** "I've died for you eleven times" 류 시적·문어체·연극톤 절대 X (행동 생성 대사 O)
5. **페이월 = 구체 행동 직전 컷:** "함께 추락 시작" (사건 진행 중) X / "내 짝(Mate)" 선언 직전 컷 O
6. **여주 능동성:** 두 남자 사이 끌려다님 X / 자기 욕망·선택·will 명확
7. **9:16 세로형 적합 스케일:** 우주·휴거·도시 전체 정전 등 거대 스케일 자제 → 친근한 감정 거래·접촉·공개 장면 중심
