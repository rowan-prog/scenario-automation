> **2026-05-21 사용자 비판:** "예측 모델의 문제인가? 가상 투표결과는 하나도 맞질 않는다. 심각하게 다 틀린다."

### E-1. 실패 원인 (8가지 가설)

**1. 샘플 사이즈 절대 부족**
- 위원당 ~10-14 데이터 포인트. B는 8 (abstain 빼면). 통계적으로 안정된 패턴 추출 불가능.
- 어떤 단일 verbatim도 *그 위원의 결정 함수*로 일반화 위험.

**2. CM/PM/Presentation 효과 무시**
- 2026-05-21: Rowan 3건 모두 약함 (4·2·1) / Lily 1건 만장일치 (7) / Emika·Bonnie 정규 (1·6).
- 동일 컨셉도 *누가·어떻게* 피칭하느냐에 따라 위원 반응 크게 달라짐.
- 가상투표는 *컨셉만* 보고 판단 → presentation 변수 누락.

**3. 회차별 위원 mood/recency 무시**
- 2026-05-12 OFFERING 7/7 → 2026-05-19 SHE STOLE 4/7. 비슷한 여성향이지만 결과 달라짐.
- 위원도 사람. 그날 mood·이전 피칭 상대·시장 분위기 영향 크다.

**4. 잘못된 추상화 (over-generalization)**
- 위원 B "검증 megalithic IP만" → 사실 OFFERING (오리지널)·SHE STOLE (창의)도 Y. 더 정확히는 "*상업적으로 입증된 경로* + *각색 리스크 낮음*".
- 위원 F "가장 BM 본다" → 사실 *Netshort 트렌드 align*이 더 결정적.

**5. Binary verdict over-fitting**
- Y/N으로만 본 결과 — 조건부 Y, 약한 N, abstain의 미세 신호 누락.
- 예: HEIR에서 B abstain은 *반대 신호*가 아니라 *판단 자체 안 함*. 이걸 N으로 잘못 카운트한 경우 다수.

**6. Verbatim 없는 4 작품 누락**
- 2026-05-12: Wolfless·Hero Beneath·First Love·MY MAP은 verdict matrix만 있음. verbatim 없으면 *왜* Y/N 했는지 모름. → 패턴 추출 시 검증 안 된 추측 가능성.

**7. 2026-05-19 11 작품 verdict 데이터 부재**
- 11 작품 (Lost Boy·Matchplay·Vampire Brother·Sister Picked·Villain's Daughter·Dear Nemesis·Teach Me Desire·Beast Lord·Sealed Bride·White Wolf Queen·Fight for Love) = PASS/FAIL label만 있고 per-위원 데이터 없음.
- 11 작품 (전체 데이터의 44%)의 *per-위원 결정 패턴* 보지 못함 = 큰 blind spot.

**8. 위원 베이스라인 무시**
- C·G는 베이스라인이 79·64%. 이를 무시하고 작품 평가만으로 점수 매김 → C·G 자주 Yes로 예측되어야 하는데 N으로 예측한 경우 있을 수 있음.
- 반대로 B 베이스라인은 45% + 27% abstain. *Yes로 예측한 경우 자주 틀림*.

### E-2. 향후 정확도 개선 액션

**즉시 (모델 수정):**
1. **확률 + uncertainty 출력** (binary Y/N 금지)
2. **베이스라인 적용 우선** — 신호 없으면 베이스라인대로
3. **abstain 명시** (B·E)

**중기 (데이터 확장):**
