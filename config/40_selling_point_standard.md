## 0. 이 문서가 지키는 것

작품 기획자·제작자가 마케팅팀에 **"이 작품은 이런 물건이고 여기를 잡으면 팔린다"**를 넘기는 문서다. 마케터의 문서가 아니다. 성과 지표·예산·채널 운용·수위 판단과 리젝 대응은 마케팅팀이 한다.

작품은 유료 세로형 숏폼. 미국·글로벌이 주 타깃. 광고로 후킹 → 랜딩 → 무료 회차로 락인 → 페이월에서 결제. 시트의 모든 칸은 이 흐름의 재료다.

**읽는 사람은 대본을 안 읽는다. 각 칸은 그 칸만 읽고 이해되어야 한다.**

**🚨 톤 = 재료를 건네는 쪽이지 지시하는 쪽이 아니다 (2026-08-25 사용자).** 우리는 "이 작품은 이런 물건입니다, 여기 잡으시면 됩니다"를 넘기는 것이고, **명령·훈계·교육하는 뉘앙스는 안 된다.** "이렇게 해." / "이건 이거고 저건 저거야." / "알아둬라." 같은 결로 읽히면 그 문장은 틀린 것이다. 뉘앙스가 이미 부탁·제안 쪽이어야 하고, 마케터가 알아서 판단할 것(수위·리젝·채널·예산)에 우리가 훈수를 얹지 않는다.

세 가지가 이 문서의 전부다. 나머지 규칙은 전부 이걸 지키려고 있다.

1. **실제로 팔릴 것을 쓴다.** 서사상 중요한 게 아니라 잘라서 광고로 쓰면 1초 안에 붙잡는 것.
2. **직관적으로 쓴다. 짧다고 직관적인 게 아니다.** 직관적 = 읽는 순간 그림이 선다. 짧아도 그림이 안 서면 실패고(→ "위선의 가면을 벗겨내는 그녀의 마지막 심판"), 길어도 그림이 서면 성공이다(→ "무릎 깊이 물에서 허우적대는 여자를 둘러싸고 학생들이 웃으며 촬영한다").
3. **돌려 말하지 않는다.** 특히 정사·폭력. 대본에 있는 동작을 그 이름으로 쓴다. 완곡어는 스타일이 아니라 결함이다 — 편집자가 그 문장으로는 컷을 못 찾는다.

## 0-1. 🚨 반복 사고 6종 — 쓰기 전에 이걸 먼저 거른다 (2026-08-25 사용자 · My Billion-Dollar Reset 실사고)

**같은 실수를 매 라운드 반복했다.** 아래는 실제로 시트에 박혀 나간 문장들이다. 새 칸을 쓸 때마다 이 여섯을 자기 문장에 대본다.

**① 작품을 한두 축으로 총괄 선언하지 않는다.**
작품에는 축이 여러 개 있다. 하나를 골라 "이게 전부"라고 쓰면 나머지를 마케터에게서 빼앗는 것이다.
> ✗ `목줄과 사슬이 이 작품의 전부다.` (목줄은 24화부터 붙는 자산이고, 무료 8화를 끄는 건 다른 축이었다)
> ✗ `밀 수 있는 축이 둘이다.` — 축을 1개에서 2개로 바꾼 것도 같은 병이다. 숫자를 세지 마라.
> ○ 있는 축을 있는 대로 **나열해서 넘긴다.** 고르는 건 마케팅팀이다.
금지어: `~이 전부다` · `핵심은 ~다` · `축이 N개다` · `가장 ~하다` · `유일한` (사실 계측이 아닌 한).

**② 한 문장이면 될 것에 설명 꼬리를 붙이지 않는다.**
후킹되게 짧게 쓰든가, 아니면 그냥 사실만 쓴다. 그 중간의 구구절절이 제일 나쁘다.
> ✗ `굴욕 컷은 그가 스스로 무릎 꿇거나 웃는 컷과 붙었을 때 살아난다. 억지로 당하는 컷만 이어 붙이면 소구가 죽는다.`
> ○ `굴욕 컷과 그가 스스로 무릎 꿇거나 웃는 컷이 대본에 짝으로 있다.`
같은 말을 다르게 두 번 하는 것도 여기 해당한다 (`목줄을 차고 무릎 꿇는` + `여자에게 소유당하는` = 한 번이면 된다).

**③ 내가 만든 동사·조어를 쓰지 않는다.**
읽는 사람이 무슨 뜻인지 되물어야 하면 그 문장은 실패다.
> ✗ `여성 타깃에도 그대로 태워 본다` · `남주의 몸이 화면의 대상이 된다` · `전면에 세운다`
> ○ `여성 타깃으로도 쓸 재료가 있다` · `벗고 묶이는 쪽이 남주다`
판정: 그 표현을 대본이나 일상 대화에서 쓰는가. 나만 쓰면 지운다.

**④ 마케터에게 가르치지 않는다.**
톤은 재료를 건네는 쪽이다(§0). `~해야 한다` · `반드시 ~쓴다` · `~하면 죽는다` = 전부 다시 쓴다.

**⑤ CAST를 회차 연표로 쓰지 않는다.**
> ✗ `3화에서 업어치고, 12화에서 채찍질하고, 24화에서 목줄을 채우고, 26화에서 하인으로 삼고, 43~45화에서…`
> ○ **성격 → 대표적인 행동·선택 → 주인공과의 관계**, 요약으로. 회차를 붙이는 건 **빌런의 가해 장면과 몰락**뿐이다(§3-5).

**⑥ 페이크는 20초 안에 상황이 성립해야 한다 — 자극 단어만 나열하면 안 된다.**
자극적인 명사를 늘어놓고 인과가 비면 시청자는 궁금해지는 게 아니라 어리둥절해진다.
> ✗ 실제 사고 — `지하 경매장에 포브스 1위가 상품으로 올라와 있다 → 시작가 1달러 → 아무도 안 부름 → 여왕이 "1달러도 아까워" 하고 그냥 데려간다.`
> 왜 세계 1위 부자가 경매대에 올랐는지 없고, 낙찰도 없이 상품을 들고 나가고, "1달러도 아까워"는 그를 깎는 말이라 파는 물건까지 깎는다. **셋 다 20초 안에 시청자가 알아채고 이탈한다.**
> 판정 3문: **ⓐ왜 이 상황이 벌어졌는지가 화면 안에 있는가 ⓑ그 세계의 규칙대로 끝나는가(경매면 값이 붙어야 한다) ⓒ마지막에 남는 질문이 "저게 뭔 소리야"가 아니라 "그래서 어떻게 됐는데"인가.**

## 1. 작업 순서

각 단계는 게이트를 통과해야 다음으로 간다. 실패하면 그 단계로 되돌아간다.

### 1단계 — 대본 파싱
```bash
extract-text script.docx > script.md      # "# Episode N" 헤더로 분할
```
회차별 라인 범위와 등장인물 목록을 뽑아 `episodes.json`으로 저장한다.
**게이트:** 회차 번호 1..N 연속, 누락 0.
docx 변환은 표·텍스트박스 대사를 흘린다. 결번·공란이 보이면 원본 docx의 `document.xml`을 raw로 대조한 뒤 보고한다([[docx-conversion-drops-table-textbox-text]]).

### 2단계 — 전편 실독
대본 전편을 처음부터 끝까지 실제로 읽는다. 요약본·인접 회차 추론으로 대신하지 않는다. 읽은 라인 범위를 `read_receipts.json`에 기록한다.
**게이트:** 모든 회차의 읽은 범위가 그 회차 전체를 100% 덮는다.
실제 사고: EP2를 건너뛰고 읽은 뒤 뒤 회차 흐름으로 역추론해 없는 장면을 지어냈다. EP52는 끝까지 안 읽어 감정 피크 대사가 통째로 빠졌다.

### 3단계 — 회차 카드 작성
회차 하나씩 독립적으로 쓴다. 한 번에 여러 회차를 쓰면 회차 혼입이 반드시 생긴다. 입력은 그 회차 텍스트만. 인접 회차를 함께 주지 않는다.
회차당 산출: `{ 키워드[], 장면|null, 트리트먼트, 등급 }`

### 4단계 — 등급 산정
전체 카드를 모은 뒤 등급을 재조정한다. 개별 회차 작성 시점에는 전체 비율을 알 수 없다.

### 5단계 — Overview · CAST · Reference
전체 회차 카드 + 대본 전문을 입력으로 생성한다.

### 6단계 — MKT Idea (실제 장면 묶음)
★ 회차에서만 뽑는다. 새 장면을 발명하지 않는다.

### 7단계 — Fake MKT Idea
두 종류를 각각 만든다. 한 소재에 섞지 않는다.

### 8단계 — 시트 생성
```bash
python tools/build_cd1_sheet.py spec.json --template "C:\Users\Rowan\Downloads\[EN_AI] Selling Point_Template (1).xlsx" -o out.xlsx
```
빌더는 템플릿 탭을 복사한 뒤 **모든 칸의 병합·채우기·글꼴을 명시적으로 초기화하고** 규격대로 다시 칠한다.
실제 사고: 템플릿 원본의 남색 fill이 남아 컷 하나가 남색 배경에 검정 글씨로 안 보였다. 값만 덮어쓰고 서식은 건드리지 않았기 때문이다.
손으로 만들지 않는다. 손으로 만들면 §2 서식이 반드시 어긋난다.

### 9단계 — 검증
```bash
python tools/cd1_validate.py out.xlsx script.md --tab "TITLE" --receipts read_receipts.json
```
전 항목 통과할 때까지 되돌아간다. **통과 후 반드시 파일을 열어 실제로 들어간 값을 눈으로 확인한다.** 작업한 데이터와 시트에 채워진 데이터가 다르면 그 작업은 없었던 것이다.

## 2. 시트 해부 — 좌표·색·폰트·사이즈

### 2-1 섹션 순서와 기본 좌표

행 번호는 규격이 아니다. **섹션의 순서와 각 섹션의 모양이 규격이고, 행 번호는 회차 수·캐스트 수·블록 수에 따라 빌더가 계산한다.** 아래는 템플릿 원본(회차 60·캐스트 9·블록 1+1)의 기본값.

| 좌표 | 내용 | 병합 |

| `D1` | **작성 상태** — `⚪ 작성대기 / Not Started` · `🟡 작성중 / In Progress` · `🟢 작성완료 / Complete` 셋 중 하나. Arial 11 Bold·칠 없음. 넘길 때 🟢로 바꾼다 | — |

### 2-2 서식 규격 (템플릿 실측)

| 요소 | 채우기(fill) | 글꼴 | 글자색 | 정렬 | 테두리 |
|---|---|---|---|---|---|
| 섹션 밴드 | `FF1F3864` | **Arial 15 Bold** | `FFFFFFFF` | 왼쪽·위·wrap | 없음 |
| 소제목 행 | `FFBFBFBF` | Arial 10 Bold | 검정 | **가운데**·위·wrap | thin `FFC9C9C9` |
| 항목 라벨 (A열) | `FFF2F2F2` | Arial 10 Bold | 검정 | 왼쪽·위·wrap | thin `FFC9C9C9` |
| 값 칸 (B·C·D·G·H) | 없음 | Arial 10 | 검정 | 왼쪽·위·wrap | thin `FFC9C9C9` |
| 회차 번호 칸 (F열, MKT/Fake A열) | 등급색 또는 없음 | Arial 10 | 검정 | **가운데**·위·wrap | thin `FFC9C9C9` |

- **워크북 기본 글꼴 = Arial 10.** 사이즈를 지정하지 않으면 10이 된다. 섹션 밴드만 15다.
  실제 사고: 밴드 글자를 사이즈 지정 없이 써서 15여야 할 헤더가 전부 10으로 나갔다. 다른 탭과 나란히 놓으면 바로 티가 난다.
- **칠(fill)과 글자색은 한 쌍으로만 바꾼다.** 남색 칸에 검정, 흰 칸에 흰색 → 글자가 사라진다. 값만 덮어쓰고 서식을 초기화하지 않으면 반드시 난다.
- 전 칸 `wrap_text=True`, `vertical="top"`. 행 높이는 지정하지 않는다(자동).
- 템플릿의 회색 예시문은 **우리 값을 채우면 지운다.** 지울 때 회색 9pt 이탤릭 서식도 같이 검정 10pt로 되돌린다. 남겨두면 우리 문장이 주석처럼 보인다.

## 3. 섹션별 작성 규칙

### 3-1 Title Overview (A4:C19)

16항목 고정. A열 항목명은 템플릿 문구 그대로 둔다.

**B = 한국어, 전 항목 필수.** C열은 원래 템플릿의 회색 예시문 열이다. 두 가지로 갈라 쓴다.

  단 **공개 순서 때문에 아직 못 쓰는 컷**(순차 공개작의 미공개 회차, 정체 리빌 이후 컷)은 예외 — 그건 일정 문제라 기획자가 알려줘야 한다. `기타 주요 정보`에 한 줄로 적는다.

### 3-2 Episodic Breakdown — G열 (편집자가 잘라 쓰는 컷)

두 라벨로 나눈다. 등급 별표는 **첫 줄에 단독으로**, 본문 중간에 중복으로 박지 않는다.

```
★★★
[키워드] 정사신 · 여주주도 · 정체반전
[장면] 괴물에게 팔려가기 전날 밤, 이솔데가 자기를 벽에 몰아세운 남자의 입술을 물어뜯고
       침대로 밀어 넘어뜨린 뒤 위에 올라앉아 셔츠를 찢는다. "Shut up... and serve me."
```

**[키워드] — 전 회차 필수**

초압축 태그 2~4개를 ` · `로 나열. 사이다·고구마·혐관·순애·달달·컷오프 등 통용 용어 그대로. 스크롤하며 이 줄만 읽어도 판단되어야 한다. 있는 대로 다 넣지 않는다. **사건을 정확히 가리키면서 후킹되는 것만.**

| 빼는 것 | 예 |
|---|---|
| 사실과 안 맞는 자극 태그 | 제물로 시집가는 것을 "인신매매" |
| 후킹 안 되는 태그 | 긴장감 · 오해 · 회복 · 심경변화 · 결의 |
| 위치·소재 나열 | 신방 · 결혼식 · 하늘정원 |
| 중복 | "애무 · 섹슈얼", "고난 · 굴욕" |

사건을 정확히 가리키게 바꾼 예: 고난 → 독주입 / 또다른위기 → 심장상실 / 질투 → 가짜신부폭로

**[장면] — 별 붙은 회차만**

130자 이내. 앞 상황 설명절을 붙이지 않는다. 화면에 보이는 컷만. 무별점 회차는 `[키워드]` 한 줄로 끝낸다.
대사를 넣을 때는 **대본 원문 그대로.** 설정 디테일은 넣지 않는다 — 그건 복선이지 광고로 쓸 사건이 아니다.

| 넣지 마라 | 대신 |
|---|---|
| 비늘이 돋았다 도로 들어간다 | (H열로) |
| 독 자국이 그의 심장으로 옮겨간다 | (H열로) |
| 혈석이 타오르며 저주를 밀어낸다 | 눈에서 핏빛이 사라진다 |

대괄호 라벨 남발 금지. `[콜드오픈 · 로그라인]`은 마케팅팀에 정보값 0이다.

### 3-3 Episodic Breakdown — H열 (그 컷이 왜 그렇게 됐는지)

현재형 종결(`~한다`), 과거형 금지. **2~4문장**(열 머리글이 "2-3문장"이다. 3문장이 기본, 4문장은 별 회차에서 회수까지 붙일 때만). 마지막 문장은 컷오프. 설정 디테일과 복선은 전부 여기 쓴다.

- 그 회차에서 실제로 벌어진 일만. 대본에 없는 인과·결말을 만들지 않는다.
- 대명사 최소화, 인물명을 계속 쓴다.
- **주연(FL·ML·주요 빌런)은 그 회차에 이름이 안 나와도 시트 전체에서 이름으로 부른다.** 읽는 사람은 회차별 호칭 규칙을 모른다. 주인공을 그 회차 호칭("드래곤 로드")으로 바꿔 부르면 오히려 딴 사람처럼 읽힌다.
- 그 회차 호칭으로 부르는 건 **아직 정체가 안 밝혀진 인물과 이름 없는 조연**뿐이다(기사·자객·원로·사신).
- 평가어(강렬하다·감동적이다) 금지. 행동과 화면으로만.
- 번역 대본은 오역을 의심한다. 부정/긍정, 화자, 행위 주체를 원문과 대조한다.

### 3-4 별 등급

기준은 "서사적으로 중요한 회차"가 아니라 **"잘라서 광고로 쓰면 1초 안에 붙잡는 컷"** 이다.

**컷 판정 3요건 — 소재보다 먼저 본다 (2026-08-25 사용자 · 근거 = TITAN BORN × Lost Wolfless Mate IG 비교대조 실측)**

아래 소구력 순서가 "무엇을 찍었나"(소재)라면, 이 셋은 "그 컷이 실제로 붙잡나"(형태)다. 소재가 목록에 있어도 셋이 안 서면 별을 못 준다.

1. **대립 구도가 첫 프레임에 보인다** — 누가 누구와 붙어 있는지가 설명 없이 읽힌다.
2. **갈등이 밖에 나와 있다** — 눈빛·분위기·속으로 참는 것이 아니라 입 밖으로 나온 말과 손으로 한 짓.
3. **이후 전개가 확 궁금해지는 지점이 있다** — 저걸 어떻게 갚나 / 저 사람이 알면 어떻게 되나. 해소까지 다 보여준 컷은 완결이라 클릭이 안 난다.

**실측 근거:** TITAN BORN 고성과 3편은 전부 대립 구도가 한눈에 잡히는 컷으로 열었고(EP6 창을 받아 되던짐 34.5만 · EP8 부상 남주와 적의 대립 · EP2 갑옷 남주와 제우스의 대립), 저성과 3편은 풍경·신체 클로즈업으로 열거나 **싸우고는 있는데 상대가 불명확**했다(EP1 5.3만). LWM도 같은 방향 — 고성과 EP3·5·11 = 결혼식 대치 / 임신한 여주 / 쓰러진 여주, 저성과 EP4·8·티저 = 아기를 안거나 간호하는 정적인 장면.

**섹슈얼·고수위는 이 3요건과 경쟁하지 않는다 — 겹칠 때 최상급이다.** 노출·베드신·초고수위는 그 자체로 팔리고(아래 소구력 1위·최소 ★★ 규정 그대로), 여기에 대립·갈등·궁금이 겹치면 최상급이다. ⚠️ **다만 대립이 없는 성적 컷 단독은 약하다** — 같은 실측에서 최저 성과가 `풍경 → 여성의 옷을 벗기는 씬` 티저(6만·남성 23.5%)였다. 벗기는 그림만으로는 안 되고 **누가 누구를 상대로 벗기는지**가 같이 보여야 한다.

**대립 구도는 필요조건이지 충분조건이 아니다.** EP2·EP8도 대립은 명확했는데 5만대에 머물렀고 EP6만 34.5만으로 튀었다 — 차이는 **한 컷 안에서 동작이 완결되는 볼거리**(무기가 화면 쪽으로 날아오고 그걸 받아 되던진다)였다. 대치(정지) 상태면 스킵은 면하고, 동작이 얹히면 터진다. `[장면]`을 쓸 때 정지한 대치로 끝내지 말고 **그 컷 안에서 끝나는 동작 하나**를 넣는다.

**소구력 순서**
1. 섹스신 — 수위가 높을수록, 여주가 위에서 이끌수록 강하다
2. 강도 높은 여주의 고난·모욕·굴욕
3. 모욕받은 그 자리에서 바로 되돌려주는 여주의 당당함
4. 빌런 처단 사이다
5. 고제작비급 판타지 비주얼

여주의 주체성은 조용한 장면에 붙으면 어거지가 되고 매력이 없다. **자극이 센 장면에 직접 붙어 발휘될 때만** 의미가 있다.

노출과 키스 장면에는 최소 ★★. 작품의 메인 축이 아니어도 팔리는 물건이다. **수위가 높다는 이유로 등급을 내리지 않는다.** 수위 높은 장면이 대개 가장 센 후크다. **여성향에서도 낮춰 잡지 않는다** — 가장 센 정사 장면이 그 작품 최고 후크인 경우가 흔하고, 남주의 몸이 카메라의 대상이 되는 컷·여주가 주도하는 컷은 여성향에서 팔리는 물건이다. 다만 **위계는 낸다**: 폭력·지위 역전이 주축인 작품에서 인티머시는 ★★, 그 작품의 주축이 되는 장면이 ★★★.

**등급을 내리는 유형** — 서사상 중요해도 광고 컷으로는 약하다.
남주 자기희생 / 감정 해소·고백 회차 / 조력자 사망 같은 비극 / 정보 공개 위주 회차 / 남주 과거 회상 / 결말 노출 회차.
실제 사고: 어머니가 자기 심장을 찌르고 죽는 회차에 ★★★을 줬다. 슬픈 회차지 클릭 나는 회차가 아니다.

**비율** — 전체 회차의 40% 이하. 비율을 맞추려고 센 장면 등급을 내리지 않는다. **약한 별을 먼저 지운다.**

제작 완성도는 대본에서 나오지 않는다. 제작팀·PD에게 들으면 등급에 반영하되, 시트에 "이 장면은 제작이 잘 됐다" 같은 문장은 쓰지 않는다. 판단은 등급과 소재 선정에만 남긴다.

### 3-5 CAST

인물 소개가 아니라 셀링 포인트다. A열 = `이름 (원어) / 역할`(FL·ML·Rival·Villain·Sub), B/C/D = KR/EN/CN.

- **정체와 지위 / 주인공과의 관계 / 행동의 동기**, 세 가지를 쓴다. 외모 형용사만 나열하지 않는다.
- 빌런은 **광고로 쓸 가해 장면을 명시**한다. 언제 어떻게 무너지는지도 회차와 함께.
  - 나쁜 예: "협박하고 회유하는 실무 담당자"
  - 좋은 예: "쓰러뜨린 뒤 발로 차고 머리채를 잡는다(EP.19). EP.38 광장에서 브레스에 날아간 뒤 다시 나오지 않는다"
- 여주 칸은 **"이 작품에서 팔리는 그림은 전부 이 인물에게서 나온다"** 수준으로 정리한다.
- 인물 설명 안에 `[광고 활용]` 같은 마케팅 표시를 넣지 않는다.
- 실사는 배우 정보로, AI 작품은 캐릭터 정보로. 칸은 같다.

### 3-6 Reference

같은 시장·같은 포맷 작품을 먼저 찾는다. 숏폼 중에 없으면 없다고 쓰고, 다른 매체에서 문법을 가져온 경우 **무엇을 가져왔는지를 장면 단위로** 적는다. 작품 이름만 적으면 쓸모가 없다. 성과 데이터와 인지도는 쓰지 않는다.
레퍼작이 여럿이면 `Reference` 밴드를 통째로 복사해 아래에 잇는다(실례 있음).
광고소재 링크(유튜브·Meta 광고 라이브러리·공유 페이지)를 확인할 수 있으면 그 칸에 URL 그대로.

### 3-7 MKT Idea — 실제 장면 묶음 (필수 섹션)

**빠뜨리기 쉬운 섹션이다. 실제로 두 번 통째로 빠뜨렸다.** G열이 회차별 단서라면, 이 섹션은 **캠페인 단위 묶음**이다. 마케터는 여기서 소재 하나를 통으로 집어 간다.

```
[남색 밴드·A:D 병합] MKT Idea (Copy this format if there's more than 1) - 첫날밤을 자기가 고른다
[회색 소제목]        EP | 추천 장면 (KR) | Recommended Scene (EN) | 推荐场景 (CN)
[데이터]             EP1 | 촛불 앞에서 눈을 감는다. "소울메이트 하나만 보내주세요." ...
[데이터]             EP9 | ...
(빈 행)
[다음 블록]
```

**이 섹션은 스토리텔링이 아니다 (2026-08-25 사용자 교정).** 파는 축 하나에 해당하는 **실물 컷을 모아 놓은 묶음**이고, 마케터가 여기서 골라 간다. 컷과 컷이 이야기로 이어질 필요도, 순서가 편집 순서일 필요도 없다. 이야기를 만드는 건 Fake 쪽 몫이다(§3-8).

- **블록 = 파는 축 하나. 3개 안팎, 많아야 5개.** 많이 준다고 좋은 게 아니다 — 블록이 늘수록 마케터는 뭘 먼저 쓸지 모르게 되고, 축이 겹치면 둘 다 흐려진다. 같은 회차가 두 블록에 나오면 합친다.
- **밴드 문구 = 블록 이름을 쓴다.** 템플릿 원문(`MKT Idea (Copy this format if there's more than 1) - 핵심 키워드`)을 그대로 두고 뒤에만 덧붙이는 팀 탭이 있으나, 모범 탭은 통째로 갈아 끼운다: `기존 장면 활용 MKT IDEA 1 — 매일 밤 남편을 침대에 눕히는 여자 - 정사신·여주주도`.
- 축은 감정/사건으로 잡는다: 정사·인티머시 모음 / 여주 굴욕→반격 / 정체 반전 / 빌런 처단 / 임신·출산 / 액션.
  **정사·키스 모음 블록은 무조건 하나 만든다.** 실제로 가장 많이 쓰이는 묶음이다.
- 행 하나 = 회차 하나 = 컷 하나. A열은 `EP12`, 여러 화가 한 시퀀스면 `EP 24~25`.
- 재료는 **★ 붙은 회차에서만.** 여기서 새 장면을 발명하지 않는다(그건 Fake 몫).
- 한 블록 안에서 EP 오름차순.
- 무료 마지막 화·페이월 직후 화에는 `(무료회차 엔딩)` `(과금포인트)`를 문장 끝에 붙인다.
- 본문 = G열 `[장면]`보다 길어도 된다. 대사를 넣어 컷이 그대로 서게 쓴다. 실제 좋은 예:
  > 응급실에 쳐들어온 빌런 미라가 수술용 메스를 집어 든다. 한나의 뺨을 그어버리고, 눈을 겨냥해 다시 칼을 치켜드는 순간 — 응급실 문이 부서지듯 열린다. "그 손 치워." (무료회차 엔딩)
- 나쁜 예 — 같은 워크북에 실제로 있는 줄들이다. 편집자가 이걸로는 아무 컷도 못 찾는다.
  > 굴욕의 와인 세례 속에서도 흔들리지 않는 그녀의 눈빛 / 위선의 가면을 벗겨내는 그녀의 마지막 심판

### 3-8 Fake MKT Idea

본편과 무관해도 된다. **클릭 유도와 원초적 욕구 자극이 유일한 목적이다.** 윤리·정치적 올바름에서 벗어난다. 천박해도 되고 막장이어도 된다. 강하게 자극할수록 좋다.

두 종류를 만들고 **한 소재에 섞지 않는다.** 한 작품에 두 종류를 모두 만든다.

#### ① AI 신규 생성 페이크

UA 소재(5~10분) 앞에 붙는 10~30초 프리롤. 원작 컷 없이 전부 새로 만든다. **자극 강도에 상한이 없다는 것이 이 종류의 존재 이유다. 자체 검열을 걸면 만들 이유가 없다.**

헤더는 제목 한 줄로 끝낸다.
```
AI 신규 생성 페이크 1 — 남자들을 줄 세워 놓고 오늘 밤 잘 상대를 고르는 여자 [21초 · 4컷]
```
- 총 10~30초, 컷 3~4개, 컷당 3~7초. **컷마다 초를 배분해 적는다** (A열 = `컷1 · 0-5초`).
- 대사는 전체 6줄 이내. **첫 3초 안에 금기를 하나 보여준다.** 상황 설명 컷을 앞에 두지 않는다.
- **🚨 여기가 스토리텔링이 걸리는 유일한 자리다 (2026-08-25 사용자).** 새로 생성해 붙이는 20~30초짜리라서 **그 안에서 이야기가 압축적으로 완결**되어야 한다. 판정 셋:
  ①**컷별로 스토리텔링이 선다** — 컷 하나가 이야기의 한 단계다. 예쁜 그림 4장이 아니다.
  ②**컷과 컷의 연결이 자연스럽다** — 나레이션VO가 앞 컷을 받아 다음 컷으로 넘긴다. 실증(Dragon Lord 페이크 1): 배신(0-5) → *"그래서 그녀는 첫날밤의 섹스 상대는 스스로 고르겠다고 결심했다"*(5-10) → 정사(10-16) → *"그 남자가... 드래곤 로드였다"*(16-21). 네 컷이 한 문장처럼 이어진다.
  ③**대사가 맛깔나다** — 컷마다 물고 늘어질 한 줄. 밋밋하면 그 컷은 없는 것과 같다.
- **대본에 없는 내용이어도 된다.** 그게 이 종류의 존재 이유다 — 원작 컷에 묶이지 않으니 이야기를 처음부터 설계해서 짠다.

**3초 안에 무슨 상황인지 알게 만든다 — 가장 많이 틀리는 지점.**
- **무게 잡는 짧은 대사 금지.** *"은화 스무 닢부터"* 는 아무것도 전달하지 않는다. → *"오늘 새로 잡아들인 인간 여자들입니다! 은화 스무 닢부터!"* — 무엇을 파는 자리이고 무엇이 상품인지가 한 줄에 들어간다.
- **대사가 상황을 설명하게 둔다.** 인물이 자기 처지와 감정을 입으로 말한다. 나레이션·해설 VO도 적극적으로 쓴다. ⚠️ **이건 맥락 0에서 20초 만에 상황을 세워야 하는 프리롤 한정이다** — 본편 대사 규칙(설명조 금지·§4)에 이걸 끌어다 쓰지 않는다.
- **반응을 화면에 넣는다.** 여자들이 떨고, 관중이 웃고, 경매인이 굽신거린다. 반응이 없으면 상황의 크기가 안 전달된다.
- **그 작품 대본의 대사 톤을 먼저 읽고 맞춘다.** 대본이 느낌표를 쓰고 노골적으로 말하는 작품이면 소재도 그렇게 쓴다.
- 값을 매기는 소재라면 **숫자를 그대로 넣는다.** 값이 붙으면 자극이 구체적으로 선다. 값이 안 붙는 소재에 숫자를 지어 붙이지는 않는다.
- **한 소재 안에서 욕망하는 쪽과 통제하는 쪽을 섞지 않는다.** 20초 안에 둘이 뒤바뀌면 누가 위인지가 안 읽힌다. ⚠️ **어느 성별이 어느 쪽인지는 공식으로 정하지 않는다** — 그 작품이 실제로 파는 구도를 따른다(예: My Billion-Dollar Reset = 남성향 문법이지만 팔리는 컷은 전부 여주가 통제하는 쪽).
- **상위 존재는 말로 굴복시키지 않는다. 물리적으로 아래로 내린다.**
- 지문에는 화면에 보이는 것을 그대로 쓴다. "직접 보여주지 않는다" 같은 연출 제한을 우리가 붙이지 않는다.
- **마지막 컷은 자막으로 닫는다 — 질문이거나 반전 선언.** "질문으로만"이 아니다: 모범 탭의 실제 마감은 *"그 남자가... 드래곤 로드였다"* · *"괴물을 무릎 꿇린 여자, 다음 날 왕비가 됐다"* · *"그 방에서 살아 나온 첫 번째 신부"* — 전부 선언형이다. 뒤에 붙는 UA 소재를 계속 보게 만드는 게 이 자막의 일이다.
- **결말은 보여주지 않는다.** 역전과 되갚기는 *시작되는* 지점에서 끊는다.
- 본편과의 연결점 하나는 남긴다. 세계관 룩, 주인공 외형, 핵심 단어 중 최소 하나.

#### ② 기존 장면 활용 페이크

원작 컷만 쓰고 순서와 결과를 바꿔 다른 이야기처럼 보이게 한다. **자극 강도는 원작이 가진 만큼이 상한이다.** 그 이상이 필요하면 AI 신규 생성으로 만든다.

헤더는 두 줄.
```
기존 장면 활용 페이크 2 — 첫날밤마다 신부를 찢어 죽인다는 남자 [4컷 · EP1·5·8·34]
실제 서사: 바엘은 이솔데에게 폭력을 쓰지 않는다. 태워 죽이는 대상은 전부 그녀를 해치러 온 자들이다.
```
- **컷마다 출처 회차를 개별 표기한다** (A열 = `컷2 · EP8`). "EP2·EP4·EP9"처럼 묶지 않는다. 편집자가 찾아야 한다.
- 원작에 없는 컷을 하나라도 섞지 않는다. 회차 번호를 못 붙이면 그건 AI 신규 생성으로 옮긴다.
- **대사는 원작 원문 그대로.** 새로 지으면 립싱크가 어긋난다.
- 대본이 노출과 폭력을 그대로 쓴 장면이면 소재에도 그대로 쓴다. 수위를 깎지 않는다.

#### 공통

- **쓰기 전 자문 2줄 — 통과 못 하면 그 소재는 만들지 않는다.** ①이 소재가 파는 것은 무엇인가 ②어떤 욕구를 자극하는가. 아이디어가 좋아 보여도 이 둘이 안 써지면 버린다.
- **단 그 2줄을 시트에 옮겨 적지는 않는다.** 헤더에 "파는 것"·"자극하는 욕구"를 따로 쓰지 않는다 — 제목이 이미 그걸 말하고, 밑의 컷이 실물이다. 마케터에게 자기 소재를 브리핑하는 투로 부연하지 않는다. (`기존 장면 활용 페이크`의 `실제 서사:` 한 줄만 예외 — 이건 부연이 아니라 페이크와 본편을 혼동하지 않게 하는 사실 고지다.)
- 나레이션은 3인칭 나레이터 보이스. 1인칭 캐릭터 보이스 금지.
- **성적 내용은 직접 명시한다. 돌려 말하지 않는다.**
  - 나쁜 예: "마지막 밤을 자기가 고른 남자와 보내기로 했다"
  - 좋은 예: "그래서 그녀는 첫날밤의 섹스 상대는 스스로 고르겠다고 결심했다"
- 대사 사이 논리 연결이 끊기면 안 된다. "가족이 날 팔았으니 오늘 밤 누가 날 만질지는 내가 정한다"는 안 이어진다.
- 대본 포맷 그대로: `△ 지문` / `인물: 대사` / `나레이션VO:` / `【화면 자막】`
- 컬럼: B=KR / C=EN / D=CN. 세 열 다 채운다.
- 컨셉 하나당 훅 문장 3종, 수위 상·하 2버전.

#### 아이디어는 트리거에서 뽑는다

점잖은 아이디어는 아무리 잘 써도 클릭을 못 만든다. **문장을 고치기 전에 아이디어부터 센 것으로 바꾼다.**

> 🚨 **아래 목록은 판정 기준이 아니라 막혔을 때 꺼내 보는 예시 창고다 (2026-08-25 사용자).** 소재는 목록에서 고르는 게 아니라 **그 작품의 엔진에서 나온다.** 목록에 있다는 이유로 그 작품에 없는 자극을 만들어 붙이면, 페이크가 본편과 아무 연결도 없는 딴 물건이 된다. 목록을 다 훑고도 이 작품 고유의 것이 더 세면 그쪽을 쓴다.

남성향 트리거: 눈앞에서 여자를 빼앗기는 굴욕 / 인신매매와 소유 / 나를 짓밟던 여자의 몰락 / 최상위 존재(신·왕·사제·재벌)의 노예화 / 공개 굴욕과 목줄, 그리고 같은 장소에서의 역전 / 근친 능욕에 대한 복수 / 가정 폭력 / 도망치는 상위 존재를 끌어내려 물리적으로 훼손 / 정체 은폐

여성향 트리거: 나를 버리고 무시하던 남자가 무릎을 꿇는 것(사과가 아니라 물리적으로 낮아지는 자세) / 최상위 남자(재벌·왕·알파·신)의 복종 — 목줄과 명령 / 남주의 몸을 화면의 대상으로 쓰는 것(옷이 벗겨지고 자국이 남고 참는 얼굴 클로즈업) / 여자가 주도하는 정사(위에 올라타고 명령하고 끝낼 때를 정한다) / 나를 짓밟은 여자들 앞에서 그 남자가 내 것임을 선언 — 목격자 있는 자리 / 나를 버린 집안과 전 남자가 내가 올라선 자리를 보게 만드는 것 / 임신·출산을 무기로 빼앗겼다가 그대로 돌려주는 것 / 여주가 죽거나 죽을 뻔한 것을 남자가 눈앞에서 보는 것(무너지는 그 얼굴이 핵심 컷) / 정체 은폐 — 하찮게 취급하던 여자가 그 자리의 주인이었음을 그 자리에서 알게 되는 순간

**두 목록은 성별을 바꿔 써도 된다.** 한 소재는 이 중 하나를 정면으로 밀고 간다. 두 개 이상 섞으면 둘 다 흐려진다.

**지향에 따라 달라지는 것은 수위가 아니라 구도다.** 누가 주도하고, 누구의 몸이 화면의 대상이고, 굴욕과 역전이 누구에게 일어나는가 — 이것만 작품에 맞춘다. 어느 쪽이든 수위 자체는 깎지 않는다. **지향이 한쪽으로 안 떨어지는 작품**(주인공 POV·세계관 문법은 한쪽인데 팔리는 컷은 반대쪽)은 억지로 하나를 밀지 말고 **문법이 어느 쪽이고 컷이 어느 쪽인지 나눠서 적는다.** 마케팅팀이 양쪽에 테스트한다.

**기대를 정면으로 겨냥한다.** 젊은 여자를 전부 사들이는 장면에서 남성 시청자가 기대하는 건 정의가 아니고, 억만장자가 목줄을 차고 기어가는 장면에서 여성 시청자가 기대하는 건 교훈이 아니다. 그 기대를 나레이션·대사·장면 중 하나로 직접 건드린다. **착한 이유를 붙여 소재를 순화하면 그 소재를 만든 목적이 사라진다.**

다 쓴 뒤 자문한다. **이게 점잖은가. 점잖으면 실패다.** 아이디어부터 다시 잡는다.

#### 수위 — 우리가 미리 자르지 않는다 (🚨 2026-08-25 사용자)

**수위 판단과 플랫폼 리젝 대응은 마케팅팀 몫이다.** 셀링 포인트 작업에서는 **윤리·도덕 필터를 걸지 않고, 심의 리스크도 계산하지 않는다.** 야한 것·폭력·범죄 무엇이든 대본에 있는 대로, AI 신규 생성이면 대본보다 더 나가는 쪽으로 쓴다. 규칙을 하나 잘못 걸면 그 작품 최고 후크가 통째로 사라진다.

- 대본에 있는 장면은 **대본에 있는 대로.** 안 읽고 수위를 깎지 않는다.
- **확인하지 않은 규칙을 만들어 "이 컷은 쓰지 마라"를 시트에 쓰지 않는다.** 내가 만든 제한은 전부 지운다(§7).
- 소재는 **수위 상·하 2버전**으로 만들어 넘긴다. 리젝되면 그때 교체하는 것이지, 미리 낮춰 만드는 게 아니다.

유일한 선 = **미성년으로 보이는 외형.** 어느 버전에도 쓰지 않는다.

## 4. 문장 규칙

### 4-1 기본 동사만 쓴다

관용어와 비유·암시로 쓴 동사 금지. "핵심을 찌른다" 류.

```
가라앉는다→사라진다 / 되받아친다→똑같이 돌려준다 / 몰아붙인다→다가온다
못박는다→분명히 말한다 / 쏘아붙인다→말한다 / 들이닥친다→들어온다
문을 박차고→문을 열고 / 얼어붙는다→굳는다 / 옭아매려→붙잡아 두려고
다독인다→안심시킨다 / 캐묻는다→묻는다 / 튕겨 나간다→뒤로 날아간다
소멸시킨다→태워 없앤다 / 휩싸여→빛에 싸여 / 빨려·흘러 들어간다→들어간다
한 치도 밀리지 않고→밀리지 않고 / 사경을 헤맴→죽어감 / 강림한→나타난
무릅쓰고→알면서도 / 짓밟으며→발로 밟으며 / 치켜든다→들어 올린다
훑는다→본다 / 응징→처단 / 폭주→저주에 삼켜짐·자기를 못 알아봄
```

### 4-2 정사신·폭력에 완곡어법 금지

대본에 있는 동작을 그대로 쓴다. **무엇을 잡고 무엇을 물고 어디를 만지는지.**

| 쓰지 마라 | 대본에 있는 그대로 |
|---|---|
| 손이 닿는 자리마다 | 그녀가 만지는 곳마다 |
| 자세와 속도를 그녀가 전부 정한다 | 입술을 피가 나도록 물고 침대로 밀어 넘어뜨린 뒤 위에 올라앉는다 |
| 옷 속으로 손이 들어간다 | 치맛단 아래로 손을 넣는다 |
| 몸을 맞댄 채 | 젖은 실크가 허리와 다리에 그대로 달라붙은 채 |
| 밤을 주도한다 / 주도권을 놓지 않는다 | 허리를 잡는 손을 떼어 침대에 붙여 놓는다 |
| 제압당한다 | 발로 차고 머리채를 잡아 얼굴을 들어 올린다 |

### 4-3 비유로 뭉갠 명사 금지

`마지막 밤의 자유` → 뭔 자유인지 아무도 모른다. 대본에 답이 있다. → `새벽까지 자기 몸은 자기 것이라는 조건`

### 4-4 설정 용어에는 뜻을 짧게 붙인다

각 칸은 그 칸만 읽고 이해되어야 한다.
`혈석` → `진짜 사랑하는 사이만 불을 밝히는 혈석` / `생사결계약` → `목숨을 반씩 나누는 금지된 계약`

### 4-5 그 밖에

- 업계·기획자 용어 금지: 폭주, 인티머시, 콜드오픈
- 종결은 평서(`-다`/`-한다`)나 명사형. 존댓말 금지. (단, MKT IDEA 설명문은 "~합니다")
- 만능 형용사 금지: "강렬한", "압도적인". 무엇이 어떻게 그런지 쓴다
- 판단 회피 금지: "~일 수 있다", "~로 보인다"
- 보고서체 금지: "~로 예상됨", "~하기 좋을 것으로 보임". 기획자가 마케터에게 넘기는 문서지 리포트가 아니다
- 근거 없는 수치·비율 금지: "절반", "대부분", "가장 많이"는 실제로 세었을 때만
- 없는 것을 굳이 없다고 쓰지 않는다: "로맨스 아님", "정사 장면 없음"
- 명사를 세 개 이상 붙여 쓰지 않는다
- **압축과 부연을 섞지 않는다.** 압축할 거면 확실하게, 부연할 거면 제대로. 파편 나열에 설명이 붙으면 별이 셋인 이유가 안 보인다

## 5. 검증

```bash
python tools/cd1_validate.py out.xlsx script.md --tab "TITLE" \
    --receipts read_receipts.json \
    --alias alias.json          # {"이솔데": "Isolde", "바엘": "Vael"} — G4용
```

`--receipts`·`--alias` 를 안 주면 G2·G4는 "미검사"로 통과 처리된다. 통과로 착각하지 말 것.

| G4 | 언급한 인물명이 그 회차 등장인물 목록에 존재 |
| G5 | 금지 동사·관용어 0건 |
| G6 | 완곡어법 0건 |

| G8 | `[키워드]` 전 회차, `[장면]`은 별점 회차에만, 본문 중복 별표 0 |
| G9 | 키워드 2~4개, `[장면]` ≤130자, 트리트먼트 2~4문장 |
| G10 | 별 비율 ≤40% |
| G11 | Overview에 회차 번호 나열 없음 |

| G14b | 기존 장면 활용: 컷별 출처 회차 실재 + `실제 서사:` 존재 |

통과 후 파일을 열어 실제 값을 눈으로 확인한다. **결과를 수치로 보고한다:** 별 비율, ★★★ 개수, 한자 검출 건수, 인물명 불일치 건수, 비운 칸의 개수와 이유.

### 기계로 못 잡는 정밀도 오류

회차 카드를 쓴 뒤 직접 대조한다.

| 오류 | 실제 사례 |
|---|---|
| 속마음(OS/독백)을 대사로 처리 | EP7 바엘의 OS 독백을 그가 말한 것으로 씀 |
| 행위 주체 뒤바뀜 | "바엘이 옷을 입혀두겠다" ← 실제는 이솔데에게 입고 있으라는 말 |
| 대본에 없는 대사 창작 | "다시는 다치게 하지 않겠다" — 대본에 없음 |
| 대본에 없는 동작 추가 | "발로 밟으며" ← 실제는 발로 차고 머리채를 잡음 |
| 대사 오귀속 | EP7 대사를 EP5에 인용 |
| 수위 깎기 | 젖어 달라붙은 실크 묘사를 "몸을 맞댄 채"로 |

## 6. 작업 전 확보할 정보

대본에서 나오지 않는다. 없으면 비워 두고 무엇이 없는지 적는다.

프로그램 코드 / 기획 담당 / Drive 경로 / 론칭일 / 제작 형태 / 총회차·무료회차·페이월 회차 / 공개 방식(동시·순차) / 한국어 공식 타이틀 / 타깃 권역

**공개 방식이 소재 범위를 정한다.** 동시 공개면 회차 제한이 없다. 후반부라는 이유로 제외하지 않되, 후반부 컷은 결과를 그대로 보여주지 않고 직전에서 자른다. 순차 공개면 미공개 회차를 소재로 쓰지 않는다.

## 7. 쓰지 않는 것

- 대본에도 없고 전달받지도 않은 정보. 모르면 비워 두고 무엇을 모르는지 적는다
- 원작 IP 성과, 배우 인지도, 유사작 흥행 데이터, 경쟁작 광고 성과
- 추정한 값을 사실처럼. 영어 원제를 직역해 한국어 타이틀을 지어내지 않는다
- 업계 관행이나 용어의 정의를 스스로 정하는 것. 모르면 묻는다
- **내가 만든 제한.** "쓰지 않는다", "빼고 쓴다" 같은 문장을 전부 찾아 전달받은 지시인지 내 판단인지 가른다. 내 판단이면 지운다

장르 문법은 예외로 쓴다. 대본을 분석해서 나오기 때문이다. "이 작품이 특정 게임의 액션 문법을 차용했다"는 대본에서 나오고, "그 게임의 판매량"은 안 나온다. 앞의 것만 쓴다.
