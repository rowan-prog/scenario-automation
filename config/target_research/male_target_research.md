## 1. 핵심 결론

> **북미 남성향 paid content = 게임적 성장 루프를 가진 남성 주도 상승 서사.**
> **= 무시당하던 남자가 자기 실력으로 시스템을 이해하고, 장비·거점·크루·랭크를 키워, 강자들과 위험한 여자들에게 인정받는 이야기.**

**작품 기획 시 첫 질문:**
> **"이 남자는 매 3~5화마다 무엇을 얻는가?"**

답: 새 스킬 / 새 랭크 / 새 장비 / 새 기지 / 새 동료 / 새 여자 / 새 권한 / 새 이름값 / 새 적의 인정 / 새 시장·구역·영역

답 없으면 광고 스낵으로 끝남. 답 있으면 paid serial.

## 4. 보상 루프 본질 (필수 — 모든 남성향 작품 적용)

> **강해진다.
> 해금된다.
> 장비가 좋아진다.
> 내 거점이 커진다.
> 내가 판을 읽는다.
> 나를 무시하던 강자들이 인정한다.
> 위험하고 유능한 여자들이 내 실력을 보고 붙는다.**

**남성향 승리의 형태 (2026-06-02 사용자 명시 · TITAN BORN 검토 학습):**
- **막는 건 박살, 뺏는 만족은 여자만.** 가로막는 적·군대·벽·신은 줘패서 부수고 굴복시키는 게 쾌감이다. "적의 군대·지위·명령권을 접수하거나 지휘하는 승리"는 전략 시뮬·세이넨식 *얻는* 그림이라 오히려 남성향 쾌감이 빠진다. 군대·왕좌는 박살내고 지배한 *결과*로 따라오는 거지, 그걸 *얻어서* 만족시키는 게 아니다. 얻어서 만족스러운 유일한 대상은 매력적인 여성(선택·소유)이다. → 검토할 때 "적 세력을 접수·지휘하는 승리"를 중반 변주안으로 권하면 오답.
- **중반이 지루한 건 같은 승리를 *반복*해서가 아니라 같은 *모양*으로 이겨서다.** 무대만 키우면(아레나→금고→하늘→옥좌) "같은 화를 더 크게"로 느껴진다. 변주는 부수는 *상대의 격·규모·공개적으로 쫄게 만드는 정도·방식*을 바꾸는 것이지, 승리를 *획득형*으로 바꾸는 게 아니다.
- **보스만 새로 그려도 같은 장면을 다시 쓰면(re-skin) 복붙·설정 충돌만 생긴다.** 한 회차에서 인물·소품·설정을 바꾸면 그게 나오는 다른 회차 전부를 같이 손봐야 한다 — 안 그러면 옛 상태 참조가 남아 모순(TITAN BORN v117 보스 리빌드 때 EP24=EP33 복붙·죽은 캐릭터 위치 충돌 발생).

## 22. 남성 유료결제 패턴 10개 (필수 — 작품 설계 시 1-3개 적극 작동)

5대 엔진을 확장한 세부 패턴. 작품 기획 시 본 10개 중 **최소 3-5개 작동**해야 결제.

### 1. Progression 결제 (가장 중요)
남성은 "다음 화가 궁금해서" X / **"다음 화에서 뭘 얻는지 알고 싶어서"** 결제.
획득: 새 스킬·랭크·장비·기지·동료·구역·적·칭호·권한·정체
- 웹소설 → 다음 챕터·Patreon advance·KU 다음 권
- 게임 → 레벨업·배틀패스·DLC·시즌·장비 해금
- **vertical → 회차 보상표**

### 2. Competence Porn 결제
남성향 매우 중요. 여성향이 "나를 선택해주는 남자"라면 남성향은 **"내가 남들보다 잘하는 걸 증명하는 장면"**.
- 모두가 못 푼 문제를 주인공이 풂
- 모두가 못 쓰는 장비를 주인공만 씀
- 모두가 무시한 약점을 주인공만 봄
- 모두가 죽는다고 한 루트를 주인공만 통과
- 모두가 비웃던 폐급 빌드가 사실 사기 조합이었다

### 3. Buildcraft 결제
게임에서 매우 강한 패턴. "강해짐"보다 **"어떻게 강해졌는지"**를 좋아함.
- 스킬·장비·클래스·파티·베이스 기능 조합
- 약한 능력의 사기 응용 / 룰의 허점 이용
→ 주인공은 그냥 센 놈 X / **남들이 쓰레기라고 버린 능력·장비·동료를 조합해서 상위권을 이기는 남자**

### 4. Ownership 결제 (남성향 핵심)
여성향 = "관계가 깊어진다" / 남성향 = **"내 것이 커진다"**.
내 무기·차·배·가게·기지·팀·길드·부대·영지·랭킹·이름값

### 5. Rank/Status 결제
랭킹 강함. Bronze→Silver→Gold / F→S / Rookie→Veteran→Legend / 무명→현상금 진입 / 지역→전국 리그 / 하위→상위 던전 / 무자격→공식 라이선스
→ paid vertical에 매우 잘 맞음. 매화 끝 상태 상승.

### 6. Mission Loop 결제
여성향 = "관계 다음 단계" / 남성향 = **"다음 미션"**.
좋은 구조: 목표 제시 → 제한 조건 → 주인공 독특한 해결 → 보상 → 다음 미션 잠금
예: 오늘 밤까지 금고를 열어라 / 이 장비로 보스 잡아라 / 3명만 데리고 기지 방어 / 불법 경기 5분 버텨라 / 적 시스템 역이용

### 7. Collection 결제 (단순 여캐 수집 X)
동료 / 능력 / 무기 / 파츠 / 몬스터 도감 / 진영 카드 / 베이스 시설 / 희귀 자원 / 스킨 / 칭호 수집
**HaremLit도 표면은 여성 관계지만 구조는 파티·능력·영역 확장.**
→ 여성 캐릭터를 "예쁜 여자 추가"로 쓰면 약함. **각 여성이 능력·진영·자원·정보·전투 기능·감정 보상 하나씩** 가져와야.

### 8. Faction Identity 결제
tabletop·Warhammer·전략 게임 출처. 진영·문장·부대·색·적·철학·유닛·계급에 돈 씀.
vertical 적용: **주인공이 몰락한 진영의 마지막 생존자. 매회 동료·장비·기지를 복구하면서 사라진 faction 부활.**

### 9. Challenge/Proof 결제
"보상" 이전에 **"시험"** 필요. "이걸 해내면 네가 진짜다."
- 1대1 결투 / 랭킹전 / 장비 테스트 / 기지 방어 / 보스전 / 시간 제한 미션 / 공개 시연 / 배신자 색출 / 구조 작전

### 10. Respect 결제 (남성향 로맨스 핵심)
사랑보다 **respect.** "여자가 남주를 좋아한다"보다 **"능력 있는 여자가 남주의 실력을 인정한다"**.
- "네가 운 좋은 줄 알았는데, 아니었네"
- "그 장비를 그렇게 쓰는 사람은 처음 봤어"
- "넌 폐급이 아니야. 룰이 널 못 따라온 거야"
- "이제 알겠어. 왜 저들이 널 두려워하는지"
→ **인정이 로맨스보다 먼저 와야** 싸구려 하렘처럼 안 보임.

- 핵심: **주인공이 시스템을 얻는다. 시스템이 사기라서가 아니라, 주인공이 시스템을 남들보다 잘 이해해서 올라간다.**

### C. KU/Audible → vertical 변환 (binge 구조)
**나쁜 구성:** 1화 사건, 2화 사건, 3화 사건...
**좋은 구성:**
- 1-5화 튜토리얼 티어
- 6-12화 첫 랭킹 진입
- 13-20화 중간 보스·첫 기지
- 21-30화 상위 구역 진입
- 31-40화 진영전
- 41-50화 시즌 보스·정체 공개

### D. HaremLit → vertical 변환 (조심)
**뽑아올 것:** 남주 중심 파티·여성 역할 분화·여성이 남주 상승에 기능적 기여·위험한 여자가 인정·관계 깊어질수록 base·team 커짐·남주가 보호자·리더·핵심 전력
**그대로 가져오면 안 되는 것:** 여자들이 이유 없이 달라붙음 / 노골적 소유 판타지 / 관계만 늘고 미션·성장이 없음 / 여성 캐릭터가 기능 없이 보상으로만
**핵심:** **"여자 수집" X / "진영·능력·자원·위험을 가진 여성 동료 영입" O**

### E. Military SF / Action Thriller → vertical 변환
**핵심 = operator competence.** 작전·전술·장비·퇴역/추방 전문가·삭제된 과거·상관보다 현장을 잘 아는 남자·제한 조건 속 임무 성공·적보다 한 수 앞선 판단
**기본 구조:** 무능한 조직이 실패 → 주인공 퇴물 취급 → 현장에서 그만이 진짜 위협 읽음 → 규정 어기고 사람 살림 → 마지막에 그의 삭제된 기록 열림

### F. Survival / Base-building → vertical 변환 (paid vertical 매우 유망)
자원·방어·제작·거점·직원·동료·무기고·시설·외부 위협·거래·지도 확장
**vertical 변환:** 버려진 주유소·폐광·벙커·가게·섬·우주기지·감옥·호텔·던전 입구 등을 주인공이 얻음 → 매회 하나씩 고치고, 방어하고, 확장.

## 24. paid vertical 핵심 설계 룰 4개

### 룰 1: "클리프행어"보다 "잠긴 보상"
**여성향 클리프행어:** 키스 직전 끊기·정체 공개 직전·남주 선언 직전
**남성향 클리프행어:** 보스전 입장 직전·새 장비 테스트 직전·랭킹전 시작 직전·금고 개방 직전·기지 방어 시작 직전·새 스킬 선택 직전·새 동료 능력 공개 직전
→ **감정 cliffhanger보다 reward cliffhanger가 강함.**

### 룰 2: 매화 끝 상태 변화 필수
남성향 vertical은 매화 끝에 뭔가 달라져야:
- RANK: F → E
- BASE LEVEL: 1 → 2
- DEBT: 90% → 72%
- BOUNTY: UNLISTED → TOP 500
- CREW: 1/5
- GEAR UNLOCKED
- MAP AREA REVEALED
- SKILL ACQUIRED
- FACTION REPUTATION +15

→ 단순 UI X / **결제 감각.** 다음 회차 진전 없으면 남성향 즉시 이탈.

### 룰 3: 주인공 = "선택받은 자" X / "시스템을 잘 쓰는 자" O
혈통·운명·선택받음만으로 가면 약함.
**강한 구조:**
- 남들은 이 능력을 쓰레기라고 생각한다 → 주인공은 진짜 사용법을 알아낸다
- F급 스킬이지만 특정 조건에서 사기 / 고장난 장비지만 구식 시스템과 호환 / 저평가 클래스지만 보스전 필수 / 약한 동료지만 특정 조합에서 핵심 / 폐급 기지지만 숨겨진 지하 시설

### 룰 4: 여성 캐릭터 = "인정 보상 + 기능 보상"
**가장 좋은 방식:** 처음 무시한다 → 남주가 증명한다 → 그녀가 인정한다 → 그녀의 능력·자원·정보가 남주 세계를 확장한다.
**여성 캐릭터 = 업그레이드 모듈 + 감정 보상:**
- 엘리트 여성 장교 → 전술·공식 권한
- 해커 → 정보·시스템 우회
- 의사 → 회복·생체 강화
- 전투원 → 보스전 파티
- 상속녀 → 자금·상류층 접근
- 라이벌 → 공개 랭킹전 긴장
- AI → 상태창·기지 관리

## 26. 남성향 paid vertical 이식 7개 모델 (1위-7위)

### 1위: System Progression Action

**왜 좋은가:** 웹소설·게임·animation·vertical 모두 매칭

**핵심:** 남주가 버려진 거점·가게·기지 획득 후 확장
**왜 좋은가:** 소유 + 성장 판타지 결합

**핵심:** 퇴물 취급 전문가가 매 미션 해결하며 과거·명성 되찾음

**회차 보상:** 작전 성공·적 격파·새 장비·과거 기록 해금

### 5위: Gear/Mecha/Vehicle Upgrade
**핵심:** 고물 장비 가진 남자가 파츠 모아 최강 장비로
**왜 좋은가:** 남성향 시각 보상 강함
**회차 보상:** 엔진·무기·장갑·AI·변신·테스트 주행

**핵심:** 남주가 미션 해결하며 위험한 여성 동료 영입
**왜 좋은가:** 직접적 남성 판타지. 잘 포장 필수
**회차 보상:** 여성 동료·능력·진영·로맨스 인정·파티 기능

### 7위: Faction Rebuild
**핵심:** 몰락한 가문·길드·부대·진영을 주인공이 재건
**왜 좋은가:** Warhammer·TTRPG·전략 게임 유저 소유·로어 욕망과 매칭
**회차 보상:** 문장·부대·기지·유물·계급·전쟁

## 27. 이식 시 버려야 할 4가지

1. **"남자도 로맨스 cliffhanger로 결제하겠지"** — 아님. 로맨스는 있어도 중심 결제 엔진이 되기 어려움
2. **"여캐 많이 넣으면 남성향이다"** — 아님. 기능과 인정 없이 많기만 하면 싸 보임
3. **"우주/SF/액션이면 남자들이 본다"** — 아님. 좋아하지만 돈 내려면 성장·보상·증명 루프 필수
4. **"설정이 크면 유료성이 강하다"** — 아님. 1화에서 중요한 건 **"내가 뭘 얻었고, 다음에 뭘 얻을 수 있는가"**

## 36. 리스크 평가 4가지

### 리스크 1: SF 제작 퀄리티 기대치 높음
북미 남성은 우주 SF 많이 봐서 눈이 높음. 싸구려 3D·빈 조종석·의미 없는 우주 배경 → 즉시 이탈.
**해결:**
- 우주전 짧고 강하게
- 함선 외관·조종석 반복 세트 고급화
- UI·랭킹·함선 업그레이드 적극 활용
- 캐릭터 클로즈업·조명으로 밀도 보강

### 리스크 2: 스페이스 오페라 무거워질 수 있음
제국·황제·가문·혈통·공주·왕위계승 너무 많이 넣으면 진입장벽.
**해결:** 초반 목표 작게. "이 배를 지켜라" / "이 미션을 완료하라" / "이 파츠를 얻어라" / "이 여자를 살려라" / "이 현상금을 피하라." 큰 세계관은 뒤에서 열림.

### 리스크 3: 여캐 많으면 하렘 냄새
북미 남성향 soft harem 가능하나 동아시아식 노골적 하렘은 싸 보임.
**해결:** "히로인 수집" X / "위험한 크루 영입" O. 각 여성에게 진영·능력·목표. 로맨스보다 인정 먼저. 감정선은 유료에서 천천히.

### 리스크 4: 남주 수동
함선이 다 해주고·여자가 다 설명하고·혈통이 다 해결하면 남성향 쾌감 죽음.
**해결:** 매화 남주가 반드시 직접 — 고친다·조종한다·속인다·계산한다·위험 감수·선택·남들 못 보는 약점 봄.
