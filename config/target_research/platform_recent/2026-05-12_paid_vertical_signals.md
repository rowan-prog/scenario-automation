## 4. 남성향 vs 여성향 공식 분리

### 여성향 공식
> **Humiliated → Chosen → Protected → Revealed → Vindicated → Desired**

대표 후킹 소재:
CEO / mafia / alpha / forbidden stepbrother / silver fox / secret baby / hidden heiress / contract wife / playroom·high intimacy

### 남성향 공식
> **Mocked → Hidden Power → Public Trial → One-Move Reversal → Rank/Status Rise → Next-Tier Quest**

대표 후킹 소재:
god mode / system activate / bastard son / wolfless loser / village fool / damaged dantian / rejected SSS trap / divine beast collection / apocalypse leveling / God of War / hidden master / God of Gamblers

## 5. 5 핵심 실전 인사이트

### 1. 남성향 AIGC·애니형에서 "God Mode"가 매우 강함
**One Move God Mode**·**God Mode: Apocalypse!**·**System Override: I Slay Gods**·**Titan Era**·**Rebel God** 계열 반복.
→ 북미 남성향 vertical·animation에서 **"즉시 이해되는 압도적 힘의 판타지"**가 후킹 언어로 작동.

### 2. "가난한 놈·멸시받는 놈·쓰레기 취급받는 놈"이 출발점
NetShort·GoodShort 남성향 반복 출발점: farmer / bastard son / wolfless carpenter / village fool / discarded ace / midlife failure / weak Rebel God / Godforsaken class / damaged dantian
→ **모욕의 강도가 후킹 / 반전의 강도가 결제.**

### 3. 북미 남성향 = 실사 realistic 필수 X
NetShort·GoodShort traction은 **애니형·AIGC형·시스템형·과장형**에서도 나옴.
→ "북미 남성 = 실사 액션만" X.

### 4. paid vertical 남성향 = "드라마" X / "시청 가능한 웹소설·게임 루프" O
회차마다 다음 중 하나 필수:
스킬 해금 / 신분 반전 / 공개 시험 / 랭크 상승 / 무기 각성 / 혈통 공개 / 보스 격파 / 다음 스테이지 / 강한 여자·가문·조직 인정

### 5. 제목이 곧 광고 카피
설명형 제목이 paid vertical 광고에 강함. 시청자가 1초 안에 보상 구조 이해.

대표:

- God Mode: Apocalypse!
- The Legend of A Bastard Son

## 7. 최종 결론

> **북미 남성향 paid vertical·AIGC 애니 쪽에서도 이미 "남성향 progression 후킹"은 작동 중. ReelShort급 메가 플랫폼의 여성향 실사 vertical과 다른 생태계에서 보임.**

핵심 공식:
> **Trash identity → Hidden power → Public humiliation reversal → God-mode reveal → Rank·status rise → next quest.**

> **Hook them with the fantasy. Make them pay for the progression.**

"fantasy"의 정의:
- 여성향: CEO·mafia·alpha
- **남성향: God Mode·System·Hidden Heir·Rejected Class·Divine Beast·Bastard Son·Village Fool·Discarded Ace**
