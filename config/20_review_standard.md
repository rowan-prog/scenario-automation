## 0. 대원칙

1. **검수는 '확인'이지 '발견'이 아니다.** 집필 표준 §E(State Ledger)를 지킨 대본의 LOCK 검수 진성 오류 = 0~2건이 정상. **LOCK에서 논리 HARD가 5건+ 나오면 = 검수가 잘한 게 아니라 집필 공정이 실패한 것** — 그 시점에 piecemeal 패치를 멈추고 §6(집필 빚 처리)로 간다.
2. **오류 ≠ 재미. 트랙 2개 분리.** Track A = 재미/엔진(쇼러너 판단·수용/기각 가능) / Track B = 오류 게이트(쇼러너 권한 밖·분모+카운트 기반·FLAG 있으면 LOCK 불가). 재미 좋아도 오류 통과 X·쇼러너 마음에 들어도 오류 통과 X.
3. **"AI들이 괜찮다" 금지.** 반드시 `분모 + 라인번호 + 판정 + 0 카운트`로 증명. 분모 없는 "문제 없음" = 무효·재실행.
4. **⚖️ 천박함 ≠ 싸구려 (검수 언어 절대 규칙).** 싸구려 = 틀렸을 때(공간 논리·연속성·정합성·기초 논리·지식 위반) — 잡는다. 천박함(막장 직설·저속 빌런·과잉) = paid vertical 자산 — 절대 싸구려 아님. 천박함을 "싸구려/저렴/품위" 언어로 깎는 의견 = 즉시 기각. 교체 제안은 항상 더 천박/직설 쪽.
5. **렌즈 순서 고정:** ①장르 쾌감 엔진 판정 → ②구조/쾌감 → ③대사 → ④정합성/포맷. 엔진 미확정 상태에서 line 렌즈 투입 금지. 집행도 같은 순서(엔진 충돌 먼저·line 마지막).
6. **단계별 중심:** 쾌감/재미 = 개발·집필 단계의 중심 / 최종고·LOCK = 오류 조정과 엔진 보호. LOCK에서 "재미있게 만들자" = 늦었고, 다림질(세련화)도 금지 — 이미 재미있는 원고가 무너지지 않게 잠그는 단계.

## 1. 검수 강도 = 2모드 (기본값 = 경량)

### ① 경량 모드 (기본) — 집필 중·incremental 수정·"어떻지?/검토" 일상 점검
- **바뀐 diff + 그 파급(연결 setup/payoff·thread) + 기계 게이트**(voice_lint·continuity_lint·char·HC·END·Korean)만.
- 전 회차 재독·다중 cold-read·풀 병렬 검수단 = **안 돌린다.** 필요하면 fresh-eyes **1개를 바뀐 구간 한정**으로만.
- 집필 단계 자체가 1차 방어선(집필 표준 §E) — 검수단으로 집필 빚을 메우려 하지 마라.

### ② 풀 LOCK 모드 — 최종 LOCK 직전 / "철저 검토·외부 완성 대본" 명시 / 새 정본 첫 풀검수 / 큰 리라이트 후 첫 게이트
- 아래 §2~5 전체. **작품당 원칙 1회** — 통과 못 하면 §6.

### 토큰 회계 (🚨 2026-06-10 제정)
- **풀 LOCK 1회 표준 belt = agent 호출 ≤6:** final-consolidator(기계 게이트) 1 + fresh-eyes(holistic ledger 패스) 1 + funnel-cold-reader 3 + native-ear 1. per-line 전수는 메인(쇼러너)이 직접(분모 grep 추출 → 한 줄씩 판정 — agent 위임 시에도 1개로).
- 10-agent 적대 함대·다회 적대 라운드 = **사용자 명시 요청 시만.** 적대 재감사 반복은 비싸고 asymptotic(매 패스 동급 nitpick 신규 생성) — 기본 금지.
- 재게이트는 **델타만**(수정 EP × 해당 렌즈). 전량 재라운드 금지.
- 검수 보고 = 인용+라인·compact 표. 산문 리포트·검증 테이블 메타 산출 금지.

## 2. Track B — 오류 게이트 (쇼러너 불가침 · 전부 0이어야 LOCK)

### 2A. 기계 게이트 (LLM 0 · 매번 공짜로)
`tools/voice_lint.py --full` + `tools/continuity_lint.py` + grep. 항목: EP수·S#수·`[END HOOK]`수·`Hard Cut.`수(=EP-1·마지막 화 금지)·Korean 0·깨진문자 0·금지/회귀 문구 0·action-line 모호 대명사 0·고아 태그 0·이중 separator 0·char count 스펙 내·METAPHOR/ANAPHORA/TRICOLON/MICRO_ACTING baseline 내. 출력 = 숫자.

### 2B. Per-line 전수 (LOCK 전용 · 샘플링 절대 금지)
grep으로 모든 Dialogue + VO + △ 번호 매겨 **완전 추출(분모 확보)** → `line# | PASS/FLAG | 사유` 판정.
- Dialogue/VO: spoken인가 · 보이스 맞나 · 연극/소설/일기 골격 아닌가 · 톤-독립인가(집필 표준 §D 기준 그대로 적용 — 예문 블랙리스트 금지·5기준 판정).
- △: 깨끗한 동작인가(감정 덧칠 X) · 1컷인가 · drawable인가 · 인물 명시 규칙.
- **분모 의무:** `393/393 checked` 식.

### 2C. State Ledger 정합 게이트 (제일 큰 사고 차단)
모든 △를 순서대로 밟으며 ledger 갱신 + 직전 상태 대조(위치·의상 on/off·소품·상처·문/창·지식·시간·Continuous). 출력 = 충돌 `라인A ↔ 라인B` + 유형 + 수정방향.
- **집필 ledger가 있으면 이 게이트는 대조 확인(싸다). 없으면 여기서 1회 holistic 구축(전 상태 → 전 충돌 동시 enumerate) — 그리고 그 사실 자체를 집필 빚으로 보고(§6).**

### 2D. 적대 프레임 (각 검수 프롬프트 의무)
❌"정합성 괜찮아?" → ✅"오류 최소 1개 있다고 가정하고 찾아라 · 불확실하면 FLAG · 분모 없는 CLEAN 무효." + fresh-context·사전 결론 비공유 + **가드레일 동봉**(엔진 요약 + 의도된-설계 목록 + 시그니처 보존 목록 — 없으면 의도 설계를 결함으로 오보).

## 3. Track A — 재미/엔진 (쇼러너 중심 · 단 Track B 못 덮음)

- 패스 0 캘리브레이션: 타깃·장르·트롭·수위 약속·쾌감 엔진·set-piece 정의를 먼저 고정. set-piece = 장르 캘리브레이션(로맨스에 보스전 요구 금지 — 공개 모욕/신분 반전/claim/intimacy payoff/라이벌 몰락이 set-piece). 보고 언어도 장르 기준("보스전 약함" ❌ → "공개 반전 권위 proof 약함" ⭕).
- 검사 축: 초반 락인(EP01 15초·EP01-03 전수) · 상업 가중치 순서(EP01 → 마지막 무료 → EP02-03 → 페이월+5 → …) · 무료 결제 유도·첫 유료 보상 · 모욕 강도(집필 표준 §F) · 장르 쾌감 실터짐 · 광고 4~10분 assembled packet 후보 · **연속극 구조(집필 표준 §C — 닫힌 EP·단발 공간·감정 리셋 체크)**.
- **cold-read 1회 = 노이즈 → 독립 3회 수렴**(funnel-cold-reader). 저점은 "수술 가능" vs "엔진 고정비용" 분리. 점수 해석 = 이탈 화수(어디까지 보고 끄는가) > 점수.

## 4. Showrunner Merge (마지막 판단 — 무조건)

1. 각 의견을 그대로 반영하지 않는다 — **원문 1:1 대조 후 진성만** 선별. 수용/부분수용/기각/보류 4분류·기각엔 근거.
2. 기각 기본값: 논리 닫기형·세련화형·증거 기계 강화형·"싸구려" 운운형·장르 비매칭 set-piece 요구형·천박→점잖 교체형.
3. **쇼러너 증명 의무:** Track B FLAG를 "오류 아님"으로 기각하려면 ①앞뒤 지문으로 물리 가능 ②지식 선후 맞음 ③AIGC 생성 가능 ④spoken으로 실제 들림 ⑤장르 허용·오독 무 — 중 하나로 증명. "재밌으니까" = 기각 사유 불가.
4. Fix 순서: Track B HARD → FIX → spoken/VO·drawability hard → Track A 수용분 → 효율 좋은 WATCH. **수정은 holistic**(집필 표준 §E-5 — thread map·연결 비트 동시).
5. 델타 재게이트: 기계 게이트 전체(공짜) + per-line·ledger는 수정 EP/씬 중심 + 연결 EP. 새 오류 → fix로.

## 5. LOCK Certificate · 수렴 기준

**Track B 전항 0(분모 증명) + Track A(엔진 무손상·초반/무료/보상 기능·광고 packet·cold-read 3회 안정) 동시 만족 = LOCK.**
Certificate = 전항 카운트 + 잔존 WATCH 내역 + 왜 비차단인지.

**🚨 수렴 기준 — 주관적 스타일 렌즈는 0으로 수렴 안 한다:** 루프 종료 = ①HARD/에러 0(반드시) + ②엔진 무손상 + ③기계 게이트 PASS + ④스타일은 진성 처리 + diminishing returns 도달. "스타일 nitpick 0"은 LOCK 기준이 아니다 — 끝까지 쫓으면 대본을 밋밋하게 다림질(역방향). 잔존 long-tail = 문서화·비차단.

## 6. 집필 빚 처리 (LOCK 수정량 = 집필 품질 메트릭)

LOCK에서 논리 HARD 5건+ 또는 수정이 새 seam을 낳는 패턴(whack-a-mole)이 보이면:
1. **추가 적대 라운드 금지** (비싸고 수렴 안 함).
2. **1회 holistic ledger 패스로 전환:** 전 상태 한 번에 구축 → 모든 충돌 동시 enumerate → 연결 비트 포함 일괄 수정 → 델타 재게이트 1회.
3. **공정 회귀 보고:** "집필 시 ledger 미준수/아크 설계 부재"를 작품 meta에 기록 — 다음 집필에서 §E 강제.
