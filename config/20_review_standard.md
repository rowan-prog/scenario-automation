## 0. 대원칙

1. **검수는 '확인'이지 '발견'이 아니다.** 집필 표준 §E(State Ledger)를 지킨 대본의 LOCK 검수 진성 오류 = 0~2건이 정상. **LOCK에서 논리 HARD가 5건+ 나오면 = 검수가 잘한 게 아니라 집필 공정이 실패한 것** — 그 시점에 piecemeal 패치를 멈추고 §6(집필 빚 처리)로 간다.
2. **오류 ≠ 재미. 트랙 2개 분리.** Track A = 재미/엔진(쇼러너 판단·수용/기각 가능) / Track B = 오류 게이트(쇼러너 권한 밖·분모+카운트 기반·FLAG 있으면 LOCK 불가). 재미 좋아도 오류 통과 X·쇼러너 마음에 들어도 오류 통과 X.
3. **"AI들이 괜찮다" 금지.** 반드시 `분모 + 라인번호 + 판정 + 0 카운트`로 증명. 분모 없는 "문제 없음" = 무효·재실행.
4. **⚖️ 천박함 ≠ 싸구려 (검수 언어 절대 규칙).** 싸구려 = 틀렸을 때(공간 논리·연속성·정합성·기초 논리·지식 위반) — 잡는다. 천박함(막장 직설·저속 빌런·과잉) = paid vertical 자산 — 절대 싸구려 아님. 천박함을 "싸구려/저렴/품위" 언어로 깎는 의견 = 즉시 기각. 교체 제안은 항상 더 천박/직설 쪽. **상위 근거 = `00_vertical_dna.md` 조건 0(가격이 규격을 정한다) — 고급감은 우리가 이길 수 있는 축이 아니다. 영화·OTT는 1/10 값에 100배 스케일을 주고, 우리 가격은 '잘 만들었다'로 정당화되지 않는다.**
5. **렌즈 순서 고정:** ①장르 쾌감 엔진 판정 → ②구조/쾌감 → ③대사 → ④정합성/포맷. 엔진 미확정 상태에서 line 렌즈 투입 금지. 집행도 같은 순서(엔진 충돌 먼저·line 마지막).
6. **단계별 중심:** 쾌감/재미 = 개발·집필 단계의 중심 / 최종고·LOCK = 오류 조정과 엔진 보호. LOCK에서 "재미있게 만들자" = 늦었고, 다림질(세련화)도 금지 — 이미 재미있는 원고가 무너지지 않게 잠그는 단계.

### ⓞ 숏폼 7문 — 모든 모드 공통·엔진 확인 직후 (🚨 2026-08-26 사용자 · ⑦ 시청자 전지 = 같은 날 추가)

> **사용자:** *"1화 인트로 후킹력, 락인 능력, 자극적인 클리프행어, 마지막 무료회차 클리프행어의 유료결제 유도력, 직관적이고 2번 생각할 필요 없이 바로 이해되는 대사 등이 구현 되었는지? 구구절절에 암시적이고 시적인 대사들로 구성되진 않았는지? 과도하게 돌려말하진 않는지?"*

대본이든 기획 문서든 **어느 모드로 들어와도 엔진 확인(§0.5 ①) 직후, 다른 렌즈보다 먼저 이 일곱 줄을 적는다.** 근거 = `00_vertical_dna.md` **조건 0(가격이 규격을 정한다)** + S0. 일곱 개 다 "그럭저럭"이면 PASS가 아니다 — **그럭저럭 만족으론 비싼 돈이 안 나온다.** 각 문항은 판정 + 근거 인용 1개(형용사 금지·원문 인용).
사용자가 같이 부른 **몰입감**은 별도 문항이 아니라 이 일곱의 결과다 — 몰입 = 시청자가 주인공 자리에 앉아 있는 상태이고, 깨는 건 셋뿐이다: **이해 지연**(⑤ 되감기) · **압력 0 씬**(§C-5-1) · **관객 들으라고 하는 말**(§D-2-2 ⑨). "몰입이 약하다"는 판정은 이 셋 중 어느 것인지로 바꿔 적는다.

1. **1화 첫 컷이 스와이프를 막나?** — 대립 구도가 첫 프레임에 보이고 · 갈등이 말·행동으로 밖에 나와 있고 · 한 컷 안에서 동작이 완결되는가(S0-3). 기계 = `tools/opening_lint.py`(**1화 FLAG는 예외 없음**).
2. **첫 씬에서 락인되나?** — 1화 첫 1분 안에 **파는 것이 실물로 한 번 실행**됐는가(S1 — 예고·암시·설정 아님) + 첫 씬 안에 **권력 역전 1회** + 첫 대사에 판돈이 내장됐는가(`hit_dna_priority8.md` §0-1 ①② · §D-0 첫 킥). 판정 = 첫 씬이 끝난 자리에서 시청자가 **"이 작품이 나한테 뭘 줄지"를 한 문장으로 말할 수 있는가**(S0-6 ②). "무슨 일이 벌어진 거지?"(수수께끼)·"세계관 흥미롭네"(설정)면 실패. **가중치 = 첫 컷 > 첫 씬 > 1화 엔딩** — 1화 엔딩(계약서 확정·`hit_dna` §0-1 ③)과 2~3화 첫 이행은 보조 항목으로 뒤에 적는다. 첫 씬이 약하면 엔딩까지 안 온다.
3. **매 화 엔딩이 자극적으로 끊기나?** — 마지막이 **입에서 나오는 말**인가, 지문·분위기·요약인가(S4·§C-2-2). 해소 직후 절단은 아닌가(§C-2). **자극적 ≠ 물리 위기** — 히트작 50화 클리프 중 물리 위기는 6개뿐([[cliff-types-are-mostly-not-danger]]). 자극은 마지막 대사가 **판돈을 올리는가**(모욕·선언·금기 한 줄)로 잰다. 매 화 위기를 발명하면 공간 순회로 간다.
4. **마지막 무료 엔딩이 비싼 돈을 뽑나?** — "궁금하다"가 아니라 **"여기서 끄면 내가 못 견딘다"**인가. 행위 직전 + 금기 + 위협이 한 컷에 겹쳤는가(S4 페이월 컷·S0-6 ③). 정보를 아끼는 것과 자극을 아끼는 것을 혼동하지 마라(§C-4-2).
5. **대사가 한 번에 들어오나?** — 되감기 0·두 번 생각 0(§D-2-1 ⑦). 암시·시적 대구·압축 은유·에피그램·돌려말하기·구구절절 경위 설명이 **기본값**이 아닌가(§D-2-1 ①②③). ⚠️ **유창해서 통과시키지 마라** — 판정 질문은 "잘 썼나"가 아니라 "한 번에 오나"다.
6. **맥락 0으로 잘라 광고로 틀 컷이 실물로 있나?** — 무료 8화 중 ★ 받을 컷이 없는 화 = FLAG, 1·2·3·마지막 무료 = ★★★급(S0-5 · 등급 규격 = `40_selling_point_standard.md` §3-4). 그 컷이 광고용 신설 씬이 아니라 **그 화의 최대 상품 지점에서 나오는가.** 반전·정체·복선·회상·감정 해소는 광고 컷이 못 된다(6화를 봐야 아는 건 맥락 0에서 0).
7. **시청자가 관계·목표·동기·정체를 아나?** — 인물끼리는 몰라도 **시청자는 그 인물의 첫 유효 행동 전에** 안다(DNA 조건 1-1 · §C-5-3). 어느 채널로 왔는지 적는다: 네임카드 / 밀담(주인공 몰래) / VO·독백 / 회상·INSERT. "쟤 누구지?"·"쟤 왜 저래?"가 생기는 씬 = FLAG. 미스터리화(인물이 모르니 시청자도 모르게)는 서스펜스가 아니라 추리극(§C-1-1). 예외 = 엔진 브리프 §5 봉인 카드에 적힌 대반전 내용·한쪽 내면뿐, 그것도 존재는 알린다.

**이 7문의 기각 기본값 = "고급감·완성도·품위·세련·정제" 방향 제안.** 그 축에선 영화·OTT를 절대 못 이기고(조건 0) 우리 가격은 그 축으로 정당화되지 않는다. 교체 제안은 언제나 **더 원초적·더 직설·더 센 쪽**(§0.4). 7문 위반은 '스타일 지적'이 아니라 **매체 조건 위반(하드)**이다 — §4.2 직관성 위반과 같은 급.

### 모델 분담 원칙 (2026-06-12 제정 · 2026-07-02 3-tier 재편)

**대원칙: 티어는 '중요도'가 아니라 '업무 성격'이 정한다.** 특히 — **naive-proxy 역할(뇌오프 시청자·flat-TTS 낭독기·무맥락 이미지 생성기)은 작은 모델이 *더 정확한 계측기*다.** 이 역할들의 핵심은 "덜 이해하는 것"이고, 똑똑한 모델은 "네가 의도한 걸 알아채 줘서" 실제 소비자(시청자·TTS·이미지툴)가 절대 안 해주는 보정을 해버린다 = 프록시 오염. 여기선 똑똑함이 버그다.

- Agent 호출 시 `model` 파라미터로 명시(미지정 = 메인 모델 상속 = 비싼 기본값). **Fable 상시 운용 금지(2026-07-06):** 평시 세션 = opus 이하로 완결되게 설계됨 — Fable 투입 = 구조·룰·워크플로우 자체를 개정할 때만(1회성 아키텍트). **예외(2026-07-22 사용자): 세션 모델이 Fable이면 subagent 배분에 fable 티어 포함 — 메인이 fable/opus/sonnet 자율 배분.** 승격 후보 = 단독 정밀 발견·최상급 프로스 집필/수술(OPUS 행 업무 중 판돈 큰 것)·나머지 티어맵 불변·naive-proxy 는 여전히 haiku 고정(프록시 순도). agent frontmatter 핀은 호출 `model:`이 우선. **실증 누적(같은 날): phase_p 기획안 유닛 = fable 불요 확정** — fable 트리트먼트가 보강 0 반환(가드레일이 일하지 티어가 일하는 게 아님)·로드베어링 판정은 사용자 문답 산물이었고 메인 단독 감-판정은 오히려 오판. 승격은 "가드레일·선행 문답으로 환원 안 되는 단독 창작 정밀도"가 증명된 업무에만 — 기본값은 여전히 opus 이하, 티어를 올릴 돈으로 선행 문답을 산다.
