| 독자 | 읽는 법 | 이 독자가 통과시키는 문장 |

## 2. 한눈에 보여야 하는 7요소

**관계 / 쾌감 / 핵심 트롭 / 갈등 구조 / 위기 / 능력 / 사이다.**

- 각 요소는 **이름으로**(명사·동사) 박힌다. 라벨로 박는 게 아니다 — "사이다"라는 단어 ✗ → 사이다인 **사건** ○ (*"억만장자가 된 아들이 나타나기 전까지"*).
- 작품에 없는 요소(로맨스물의 능력)는 비운다. **있는데 안 보이면 FAIL.** 엔진에 해당하는 요소(관계·핵심 트롭·쾌감)는 항상 있어야 한다.
- 코퍼스 실물 대조:

| 요소 | 코퍼스에서 이렇게 박혀 있다 |
|---|---|
| 관계 | *전 남자 친구의 삼촌* · *의붓언니의 약혼자* · *아빠의 절친* · *아들의 약혼녀* · *전 남편의 친구를 콜보이로* |
| 쾌감 | *억만장자가 된 아들이 나타나기 전까지* · *그 남자가 왕좌에 앉아 있었다* · *남편은 제국의 진짜 지배자였다!* |
| 핵심 트롭 | *위장 결혼* · *삼 년 전으로 회귀* · *하룻밤* · *정체를 숨긴* · *계약 결혼* · *대리 신부로 팔려간* |
| 갈등 구조 | *다섯 남자를 한 명씩 공략하며 매혹해야 한다* · *일주일 안에 … 뱀파이어냐 늑대인간이냐 선택해야 한다* |
| 위기 | *살아남으려면* · *들키는 순간 끝장인* · *그녀의 빛이 꺼지기 전에* · *죽어가는 알파* |
| 능력 | *시간을 되돌리는 억만장자* · *유령을 보는 저주* · *자신의 피가 그의 유일한 치료제* · *용의 알을 낳는다* |
| 사이다 | *가짜를 폭로해 모든 것을 되찾는다* · *자신을 짐승으로 만든 신들을 도륙한다!* · *놈들의 세계를 빼앗는다* |

| **P2 당한 것 + 반격** (2문장) | [당한 것 관형절] + 주인공 명사구. [조력·수단]으로 [사이다]. | *절친에게 얼굴도 약혼자도 인생도 빼앗긴 레나. 억만장자 노아와 손잡고 가짜를 폭로해 모든 것을 되찾는다.* |
| **P3 한 문장 + 대시 반전** | [처지]가 [수모]를 당한다 — [반전] 전까지. | *가난 속에서 아들을 키워낸 싱글맘이 아들의 약혼녀에게 수모를 당한다 — 억만장자가 된 아들이 나타나기 전까지.* |
| **P4 처지, 선택 + 하필 반전** (1문장·!) | [처지] 그녀, [선택]한 [대상]이 하필 [정체]였다! | *동생에게 죽고 삼 년 전으로 회귀한 그녀, 조용히 살려고 고른 거지 남편이 하필 예언자 모세였다!* |
| **P5 규칙형** | [능력·저주]를 받은 주인공은 [목적] 위해 [매일·기한] [해야 한다]. | *유령을 보는 저주를 받은 그녀는 살아남기 위해 매일 밤 유령 호텔의 미스터리한 주인과 키스해야 한다.* |

참고 5형 공통(카탈로그 슬롯 감각): 첫 어절에 처지 · 반전은 끝 · 연결어 살림 · 두 문장이면 길이가 다르다. **단 우리 페이지 로그라인은 4-1 정본 2형으로 쓴다** — P1~P5의 "사건 하나·반전 하나"는 카탈로그 소개문의 길이에서 나온 것이고, A 아크형은 결말까지 4~5절을 쓴다.

## 5. 어휘 — 허용과 금지

**허용 = 코퍼스에 있는 굳은 말(0.1초에 읽힌다):** 사랑이 싹튼다 · 불이 붙는다 · 시험대에 오른다 · 휘말린다 · 판을 뒤집는다 · 소용돌이 · 갈림길 · 발이 묶인 · 민낯 · 얽히다 · 목줄 · 무덤에 묻는다 — 그리고 **국어사전에 비유 뜻으로 올라 있는 일상어**(짓밟다·밟다·잘리다·터지다·갈아타다·물 먹이다). **코퍼스에 없는 새 비유는 만들지 않는다.** 판정 우선순위 = plain-reader 재진술 성공이 어휘표보다 위 — 재진술이 되면 굳은 말이다(29 실증: sonnet 판정이 "짓밟힌·밟는다"를 신조 은유로 떨궜으나 haiku는 즉시 재진술함 → 판정 무효).

**금지 (하나라도 있으면 FAIL):**
1. **신조 은유·은유 동사** — 침대를 사수 · 기득권을 매장 · 정조준 · 삼키다 · 튀겨내다 · 박살. 판정 = *그 동사를 문자 그대로 그림으로 그리면 틀린 그림이 나오는가.*
2. **개념 라벨** — 욕망의 증명 · 각성 사이다극 · 보험 왕조 · 안목 쾌감 · 히든 아이덴티티극. 판정 = *중학생이 그 단어를 아는가.*
3. **원관념 숨기기** — *"그 말의 진짜 의미를 알게 된다"* · *"모든 것을 바꿀 비밀"* · *"그의 최고 걸작이지만 마지막 장이 될 수도"* — 무엇인지 안 쓰고 **있다고만** 하는 문장. 코퍼스에도 몇 건 있으나(#38·#169·#20) 약한 예다 — 우리는 안 쓴다. 반전을 봉인해야 하면 반전의 *존재*를 말하지 말고 **앞 사건에서 끝낸다**(P1: 하룻밤 → 왕좌).
4. **내부 작업어** — 엔진·구조·컨테이너·비트·훅·락인·결제·무료런·레지스터·트롭·쾌감 (lint 금지어).
5. **관형절 더미** — 40어절 들고 있다가 끝에서 동사 받기. 두 문장으로 쪼갠다.
6. **인용 대사로 시작** — 금지. 모욕 대사는 트리트먼트에서 간접 인용(`~라며 비웃는다`)으로 쓴다(`50_t1_page_exemplars.md` C-4-8).
7. **장르 라벨어**(사이다·리벤지극·권선징악) — 라벨 대신 그 사건.

**"세련·품위" 방향 교체 금지** — 코퍼스는 천박하다(*"놈들은 내 찾아낸 벙커를 통째로 빼앗았다"*·*"양아치 의붓오빠가 하필 늑대인간이라고?"*). 그게 규격이다(`00_vertical_dna` 조건 0).

## 6. 되감기 0 테스트 — 판정의 본체

**맥락 0인 사람이 한 번 읽고 "누가 / 누구에게 / 무엇을 해서 / 어떻게 됐다"를 자기 말로 다시 말할 수 있는가.** 못 하면 FAIL. 두 가지로 읽히면 FAIL. 사용자 정의: *"1번 더 그 의미, 원관념 등을 파악해내야 하는 문장"* = FAIL.

- 프록시 = **`plain-reader`(haiku · effort low)**. 똑똑한 모델은 내가 의도한 걸 알아채 줘서 계측기가 못 된다(`20_review` §7 naive-proxy 원리 — 덜 이해할수록 정확). 메인·opus의 "직관적이다" 자가 판정은 **무효**.
- plain-reader 출력 = 문장별 재진술 또는 `못 함(사유)`. 재진술이 원문과 다른 이야기면 그것도 FAIL(두 갈래).
- 이 게이트는 로그라인만이 아니라 **한국어 산출물 전부**(기획안 전 문장·트리트먼트·셀링포인트·작가 코멘트·반박서)에 발송 전 필수(CLAUDE.md 룰 7 · skill `/plain-gate`).

## 7. 절차 — 경량 (2026-08-27 예산 개정 · 사용자: "1/10로 줄여도 모자라다")

메인은 후보를 **직접 쓰지 않는다**(생산↔판정 분리). 그러나 절차 크기는 산출물 크기에 맞춘다 — **한 문장에 agent 2기·40k 토큰·2분이 상한**이다. agent에 이 문서를 정독시키지 않는다 — §4 골격 5형과 §5 금지 7종을 지시서에 그대로 붙여 넣는다. (첫 설계의 "3프레이밍 × 15 = 45후보 → haiku 되감기 → sonnet 7요소 판정(130k) → 재라운드"는 29번에서 로그라인 하나에 126후보·40만 토큰을 태웠다 → 폐기.)

| 단계 | 유닛 | 모델·effort | 입력 → 출력 |
|---|---|---|---|
| 0 캐논 | 메인 | — | 엔진 한 줄(**사용자 문장**) · 관계 · 능력 한 줄 · 허용선 · **이 작품의 필수 3요소를 이름으로**(예: 창구 굴욕 / 남은 수명이 보임 / 하필 그 보험사 회장 — 하나만 주면 나머지가 빠진다, 29 실증) |
| 1 생성 | `copy-candidate-generator` **1기** | opus · low | 후보 **10**(A 아크형 6 + B 오해형 4, 장르에 따라 조정). 정독 = **`50_t1_page_exemplars.md` Part A 세 편의 로그라인 3개(verbatim)** + 지시서에 붙인 §4-1 골격·§5 금지 7종. **코퍼스 179건·표준 문서 정독 금지** |
| 2 기계 | `tools/logline_lint.py --file` | — | FAIL 제거 |
| 3 되감기 | `plain-reader` 1기 | haiku · low | 후보 목록만·맥락 0 → `못 함` 제거 |

## 8. 기획안 안에서의 자리 (2026-09-02 · 러프 기획안 = T1 페이지 1:1)

- **러프 기획안(`_p0_rough.md`) = T1 페이지에 그대로 붙여 넣을 수 있는 형태.** 필드 = 담당자 / 상태·제작 등급 / 제작 형태 / 발화 언어 / 타깃층 / 장르(**여성향·남성향 한 단어**) / 키워드(**영문 트롭 2~4개** `#Hidden Identity, Revenge, All Too Late`) / **로그라인** / **⭐ 핵심 셀링 포인트** / **무료회차 줄거리** / 레퍼런스 작품(`플랫폼명 <영문 원제>`). 양식 = `50_t1_page_exemplars.md` Part D. 페이지에 안 실리는 것(한눈에 표·인물 소개·컨테이너·설계 메모)은 쓰지 않는다 — 캐논·치환표는 meta 파일.
- **로그라인 = §4-1 정본 2형.** 플랫폼 기획안·피칭덱·T1 페이지·CD1 시트 Overview의 로그라인 = **같은 문장 그대로**(옮길 때 줄이거나 늘리지 않는다). 예외 = S급 피칭 페이지(`60_pitch_page_standard.md` G13 120~220자 정지 컷 — 2026-09-01 사용자 확정) — 규격이 겹치니(110~175 ⊂ 120~220) 대개 같은 문장이 그대로 간다.
- **셀링포인트 = 2~4개 · 명사형 한 줄.** 종류 = 핵심 아이러니(`죽은 아들을 지키는 엄마, 그 아이를 모른 채 짓밟는 친아버지`) / 감정 엔진(`자식 잃은 부모의 분노, 슬픔, 고통이 강하게 몰입하게 만듦`) / 트롭·장르 라벨(`후회물의 정석` `언더독의 신분 역전` `남성형 신데렐라 판타지`) / 각색 델타(`엘프 ㅡ> 웨어울프 치환` `SF 장르를 현대물로 전환하여, 접근성 UP`). **이 칸의 독자는 기획자·현업자** — 로그라인·트리트먼트에서 금지인 라벨이 여기서는 규격. 장면·숫자·대사 실물은 트리트먼트 몫(30번 p0 셀링 7개 → 페이지 2개로 사용자가 줄임).
- **무료회차 줄거리(트리트먼트) = 화당 200~550자 · 1~3문단 · 현재형 · 직접 인용 0~2 · 마지막 문장 = 엔딩 7유형 중 하나**(대사 절단 / 조우 / 다음 판으로 이동 / 행위 직전 정지 / 판돈 갱신 / 몸의 신호 / 폭탄 심기 — 전수 = `50_t1_page_exemplars.md` C-4-9). 첫 문장 = 인물 카드(1화) / 앞 화 다음 프레임 + 상태 요약(2화~). 인물 첫 등장 = 관계·직함 인라인. 시청자 전지 = 누가 무엇을 모르는지 문장으로. 급소 대사 뒤 반응 동작 붙이지 않는다. 마지막 무료 화는 결과를 보여주지 않는 자리에서 끊는다.
- 전 문장 = `10_writing` §D-2-1 ⑧ + 독자 3종 게이트(`/plain-gate`). 검수 = `20_review` §1③(체크리스트 = `proposal-spec-auditor`).
