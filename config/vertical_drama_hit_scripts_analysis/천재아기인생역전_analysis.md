# 천재 아기의 인생역전(가제) — 3축 분석

## 기본 메타

- **제목:** 천재 아기의 인생역전 (가제)
- **회차:** 미확인 (대본 미완 / 30화 이상 추정)
- **1차 페이월 위치 (확정):** **7화 명시**
  - 7화 끝 = "운미사이언스" 주식 상한가 + 강지윤·한민철 패닉 + "Paywall 엔딩"이라고 대본에 명시
  - 7화 = 작품에서 시청자가 첫 번째 사이다 폭발을 받는 정확한 지점
  - 무료 회차 = EP1-7 (다른 작품 대비 짧음 — 매우 압축 효율)
- **장르:** 회귀 + 천재 아동 + 효도 판타지 + 복수 + 가족 회복
- **타깃:** 여성향 (30-50대 어머니층 강함) / 한국 시장 강함 (`feedback_clip_reward_loop.md` 등재 사례)
- **매출:** 사용자 검증 히트작 / 기존 메모리에 핵심 인사이트 등재 (효도 판타지가 진짜 엔진)

## 1축. 캐릭터 (3 인물)

### 메인 빌런 — **명료한 단일 빌런 + 보조 다수 (모범 정합)**
- **메인 빌런 1명 (50화 전체):** **한민철 (도혁의 친아빠)**
  - 얼굴·이름·말투·습관·구체 행동 완비
  - 첫 화 = 도혁을 자살로 위장 살해 + 양육비 횡령 + 엄마 고독사 방치
  - 끝까지 가치 모름·끝까지 오만 ("지 엄마 닮아서 꽉 막혀가지고는")
  - **회귀 전후 동일 인물 = 메인 빌런 절대 정합**
- **보조 빌런 다수:**
  - 강지윤 (한민철의 내연녀·재혼녀) — 입주 가정부 모욕·식모살이 비웃음
  - 강민선 (강지윤 딸·도혁의 이복 동생) — 미래 빌런
  - 백화점 매니저 (1회 등장 비싸구려 무시)
  - 복덕방 주인 (꼬마 무시)
  - 학교 친구·교사 (미래 빌런)
- **환경 압박:** 가정·은행·백화점·부동산 = "초라한 모자에 대한 사회 전체 무시" 누적

→ **`feedback_concrete_villain_humiliation_loop.md` 모범 정합** — 메인 1명 + 보조 다수 + 환경 압박 완비. OFFERING이 본받을 패턴.

### 주인공 — **회귀 어른×어린 도혁 (이중성)**
- **1화 처지:** 5년 옥살이 후 친아빠에 의해 자살 위장 살해 → 회귀하여 10살 몸으로 깨어남.
- **이입 트리거:** 1화 옥중 모욕 + 자살 + 회귀 어머니 비참 + 아빠 폭력 = 비참 정점
- **이중성:** 어른 도혁(NA) + 아기 도혁 = 시청자가 동시에 이입 (어른 = 분노 / 아기 = 귀여움) 
- **반항 + 무시 패턴:** 
  - 어른 도혁의 독기 ("내 손으로 다 찢어 죽일 수 있게!")
  - 아기 도혁의 거침 ("거지 같은 아빠 밑에 있는 것보단, 엄마랑 있는 게 훨씬 나아요")
  - 강지윤의 "꼬마야 한글은 떼고 주식 하니?" → 도혁의 응수 "아줌마 감은 완전 썩었나봐요"

### 여주(보조 주인공) — **이서연 (엄마·바닥)**
- 1화 처지: 가장 비참한 약자 — 이혼 강요·발길질·전 재산 통장 하나 / 시한부 신장 이식 필요
- 도혁이 보호자 역할 (회귀 후 어린 아들이 엄마 보호) = 효도 판타지 핵심
- "엄마, 엄마, 엄마" 호명 매우 자주 = 청각 정합

### 사랑 라인 — **차현준 (KS 그룹 막내·전 자살자·서연의 옛 첫사랑)**
- 회귀 전 자살 미스터리 → 회귀 후 도혁이 그를 살리고 + 엄마와 재결합 시킴
- 신데렐라 + 백마탄 왕자 직접 만남 + 효도 판타지 + 사랑 회복 = 보상 다중

## 2축. 이야기 구조

### 압력축 1개
**핵심 질문:** "도혁이 회귀해 엄마를 무시한 모든 인간들을 어떻게 박살내고 엄마를 행복하게 만드는가?"
- 회귀·천재 아동·주식·부동산·재벌가 = 다중 사건이나 **모두 "엄마를 위한 효도 판타지" 압력축에 수렴**
- `feedback_pressure_axis_stacking_vs_dispersion.md` 모범 정합

### 무료 회차 구조 (1-7화 — 매우 짧고 압축)
- **EP1:** 옥중 살해 + 회귀 = 강력한 1층 보상 (회귀 판타지 + 분노 트리거)
- **EP2:** 이혼 + 아빠 발길질 + 도혁이 엄마 보호 = 효도 트리거 첫 발동
- **EP3:** 은행 + 주식 매수 + 차현준 첫 만남 + 내기 = 텐션 시작
- **EP4-5:** 강지윤·한민철 등장 + 내기 키움 + 무시 누적
- **EP6:** 시간 초과 위기 + 강지윤 식모살이 강제 직전
- **EP7:** **상한가 폭발 + 강지윤·한민철 패닉 + 차현준 등장 = 1차 페이월** (대본 명시 "Paywall 엔딩")

### 보상 단계 설계 — **모범 정합**
- **1층 즉시 (EP1-2):** 회귀 판타지 + 효도 시작 = 즉시 강력
- **2층 누적 (EP3-6):** 주식 매수 + 모욕 누적 + 시청자 분노 게이지 차오름
- **3층 페이월 (EP7):** 상한가 폭발 + 빌런 무릎 + 첫 사이다 정점 = 결제 트리거

### 클립 보상 루프 — **모범 정합**
**원초 쾌감 (사용자 분석 등재):** "엄마를 무시한 세상 앞에서, 회귀한 아들이 돈·정보·재벌 인맥으로 계속 이겨준다"
- 무시 → 회귀 정보로 응징 (사이다 1)
- 매장 무시 → 차현준 등장 → 매니저 해고 (사이다 2)
- 가족 무시 → 차현준 = 친아빠 = 진짜 친자 (사이다 3 — 추정)
- 사회 무시 → 재벌 회장 친자 인정 (사이다 정점)
- `feedback_clip_reward_loop.md`에 이미 등재된 모범 사례

### VO·플래시백
- 어른도혁(NA) = 매 화 활용 / 시청자가 사건 즉시 이해
- 플래시백 매우 효율적 사용 — 1화 옥중·고독사 회상 / 16화 첫사랑 회상 = 분노 + 감정 트리거
- `feedback_vo_flashback_pressure_tools.md` 5조건 모두 충족 — **모범 정합**

## 3축. 대사 스타일

### 짧고 직관 + 코믹
- "내가 엄마 호강시켜 줄게" (아기 도혁) = 한 줄에 욕망·관계·약속 + 코믹 비주얼
- "거지 같은 아빠" / "감은 완전 썩었나봐요" / "아저씨, 저 촉 되게 좋아요" — 도혁 시그니처
- 시적·연극톤 0건

### 시그니처 호칭
- "엄마" "아저씨" "꼬마야" "도련님" — 한국 영혼 호칭 자주 사용
- 권력·관계 즉시 인식

### 모욕 교환 5-8턴 — **모범 정합**
EP4-7 강지윤·한민철 vs 도혁·서연 모욕 교환:
- 강지윤 "오빠가 돼서 그 정도는 해줄 수 있잖아?" (3턴 후 도혁 응수)
- "한글은 떼고 주식 하니?" / "아줌마 감은 썩었나봐요"
- "내가 미쳤니?" / "변기물을 아주 마셔도 될 정도로~"
- "(약속 어김) ㅇㅁ미안해 됐지?" / "잘 안들려요" / "다시 제대로"
- = 5-8턴 모욕 누적 → 폭발 → 공개 사과·박살
- `feedback_concrete_villain_humiliation_loop.md` Step 1-8 모범

### 페이월 직전 대사
- "딩-동! 긴급 속보입니다. 운미사이언스가 미국 일라릴리와 7,800억 원 기술 수출 계약"
- "뭐, 뭐야? 말도 안 돼!" (강지윤) / "허억! 오른거야?" (한민철)
- = 객관적 사건 (뉴스) + 빌런 패닉 발화 = 시청자 사이다 폭발

### 멀티태스킹 청각 정합
- 모든 사건이 대사·VO로 명확히 청각 정보화
- 화면 안 봐도 사건 흐름 따라옴
- `feedback_paid_vertical_dialogue_rules.md` Section 24 모범

## 종합 평가

### 강점
1. **메인 빌런 1명 + 보조 다수 + 환경 압박** = 모범 정합 / OFFERING이 본받아야
2. **압력축 1개 (효도 판타지)** 끝까지 유지 — 모범
3. **무료 회차 7화 압축** — 매우 효율적 결제 트리거
4. **클립 보상 루프 모범 정합** — `feedback_clip_reward_loop.md` 직접 등재 사례
5. **VO 매우 효율** — 어른 도혁의 분노·이서연의 비참 즉시 청각 전달
6. **모욕 교환 5-8턴 모범**
7. **사이다 빌드업 6화 + 폭발 7화** = 시청자 결제 동기 완벽

### 약점·특이점
1. **여성향 작품이나 로맨스 매우 약함** — 효도 판타지가 본질 / 로맨스는 부차
2. **아동 주인공 = AIGC 어려움** — 한국 실사 vertical 패턴 (AIGC 이식 시 어려움)
3. **회귀 설정 = 한국 시장 특성** — 북미 시장에서는 변형 필요

### OFFERING·다크 로맨타지 적용 인사이트
1. **메인 빌런 단일 + 보조 다수 + 환경 압박** = OFFERING에서 절대 필수 / 의붓남매·토깽이는 시기별 빌런 교체였음 — **본 작품의 단일 메인 빌런이 가장 강한 모범**
2. **무료 회차 짧고 압축 (7화)** = OFFERING도 8화 페이월 유지 / 더 짧게 가능
3. **사이다 빌드업 6화 + 폭발 7화** = OFFERING EP1-7 압력 누적 + EP8 폭발 패턴과 정합
4. **클립 보상 루프 = 원초 쾌감 1개 정의** → "엄마 무시한 세상이 끝까지 박살난다" = OFFERING은 "이졸데를 폐품 취급한 환경이 끝까지 박살난다"로 동일 패턴 이식
5. **VO·플래시백 5 조건 모두 충족** = OFFERING 무료회차 재설계에 동일 패턴 적용 권장
