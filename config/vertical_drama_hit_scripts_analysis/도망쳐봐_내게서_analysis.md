# 도망쳐봐, 내게서 — 3축 분석

## 기본 메타

- **제목:** 도망쳐봐, 내게서 (Run From Me)
  - **제목 = 남주의 소유욕 선언.** 희원이 저택에서 반복적으로 "도망"치려 하고, 남주가 매번 붙잡는 모티프가 작품 전체를 관통.
  - **마지막 대사로 직접 회수:** EP61 "도망칠테면 도망쳐봐, 내게서" → 제목이 첫사랑·소유·집착을 한 문장에 묶고 엔딩.
- **회차:** 61화 (평균 ~55줄/EP — 한국 vertical 히트작 scale 정합)
- **장르:** 조폭 보스 × 간호사 / 계약결혼 / 운명적 첫사랑(숨김) / 히든 일러스(혈우병+희귀혈액) / 가족·기업 후계 복수
- **타깃:** 여성향 (20-40대) / 한국·아시아
- **매출:** 사용자 검증 히트작 (대본 등재 / 매출 데이터 미확인)
- **1차 페이월 위치:** **EP11 명시 (`Paywall 엔딩` 마커)** — 결혼식 난입 → 신랑 가격 → 신부 들쳐업기 → 퇴장. EP12-13 끝에 유료 훅 마커(`$`).
- **수위:** **중(中).** 키스·취중 암시 정사(EP28-29)·페이드아웃 베드씬(EP40, 벽→깊은 키스→침대). 직설 T4 아님. 계약상 "약속한 날짜"는 깔아두되 실제 합방은 계약이 아닌 감정으로 처리.

## 1축. 캐릭터 (3 인물 + 빌런군)

### 메인 빌런 — **단일 메인(후반) + 보조군(무료·초반 유료) 2단 설계**

**보조 빌런군 (EP1-50 회전·즉발 응징용):**
- **서민준 (전 약혼남·의사):** 7년 연인이지만 도예린과 양다리. 희원과 결혼 = 식물인간 부친 사망보험금 노린 쇼윈도. EP24 블랙박스 영상으로 공개 박살.
- **도예린 (원무과 직원·내연녀):** 민준의 정부. 병원에서 희원 공개 모욕("결혼식 깽판" 프레임).
- **윤미정 (의붓엄마)·유찬 (의붓오빠):** 희원을 ATM 취급. 부친에게 몰래 수면제 먹여 보험금 노림(EP26·43). EP44-45 창고에서 결박당하고 살인미수·보험사기로 경찰행.
- **공통 패턴:** 얼굴·이름 명확, 끝까지 가치 모름, 천박·즉발·뻔뻔. 환경 압박(병원 간호사들 수군·가정부들 일진놀이)도 별도 배치.

**메인 빌런 (후반 = EP46~59):**
- **강태민 (태영의 친형·HS그룹 대표):** 진짜 흑막. 부친(강태환 회장) 살해 + 유언장 인멸로 후계 강탈. 동생 태영 견제 → 민준 매수(10억)로 태영 약점 캐기 → 희원 납치 → "혈우병이니 피만 흘리면 죽는다"며 태영 살해 시도(사고사 위장).
- **회수:** 식물인간이던 **희원 부친 고만석(부친 살해 사건 유일 생존 증인)**이 깨어나 자백 녹음 → 뉴스 폭로 → 이사회 해임 → 살인+살인교사 체포(EP58-59).

→ `feedback_concrete_villain_humiliation_loop.md` 모범. **2단 빌런 = 무료~초반 유료엔 즉발 응징용 잡빌런 회전, 후반엔 판을 거는 단일 메인.**

### 여주 — **고희원 (간호사·약자 → 보호받는 첫사랑 → 능동 구원자)**
- **1화 처지:** 응급실 간호사. 총상 환자(태영)에게 **자기 피 직접 수혈**(희귀 RH-O). 의붓가족 ATM·식물인간 부친 병원비·바람둥이 약혼남 = 4중 결핍.
- **상승 호:** 약자(EP1-10) → 계약 신부(EP11-) → 보호받음(가정부·가족·민준 응징) → **능동 전환**: 혈우병 의학 공부로 EP56 직접 응고인자 주사로 태영 살림 / EP58 부친 자백으로 빌런 박살의 결정타 제공.
- **주체성:** 빌런 처분 권한을 받지만 "그러면 똑같은 사람 된다"며 사적 보복 대신 **확실한 법적 처벌** 선택(EP45) — 약자쇼가 아니라 선 긋는 능동.
- `feedback_female_lead_rise_arc.md` 정합 — 1화 완성형 X·약자 인내 → 능동 구원자.

### 남주 — **강태영 (조폭 보스·obsessive·모두엔 짐승/그녀에만 지극)**
- **이중 톤의 교과서:** 적에겐 차갑고 잔혹("주인을 몰라보는 개는 필요없어. 치워." / "개돼지들이랑은 대화가 안되거든") / 희원에겐 능글·집착·서툰 다정("화내는 것도 예쁘네" / 간식·쿠션·의학서·금붕어를 말없이 다 준비).
- **숨긴 동기 = 첫사랑:** 비밀의 방에 희원 사진 도배(EP18). 표면 명분("내 피에 필요한 여자")으로 가리지만 진실은 어릴 적 병실에서 도망다니던 자신에게 희원이 꽃반지를 주며 "도망치지 말라"한 첫사랑(EP60 회수). **희원의 "피뽑이" 오해 ↔ 시청자가 의심하는 진짜 마음**의 간극이 유료부 감정 엔진.
- 짐승 직진 X / 위압+소유+서툰 순정. 지훈 대사로 "다른 사람과 깊은 관계 맺어본 적 없다"(EP38) = 그녀에게만 순정 보강.

## 2축. 이야기 구조

### 압력축 (2개가 한 방향으로 수렴)
1. **감정축:** "피뽑이로 오해받는 약자 간호사가, 언제 '사실은 어릴 적 첫사랑이자 목숨 걸고 지키는 여자'로 밝혀지고 진짜로 사랑받는가."
2. **사건축:** "누가 태영의 아버지를 죽였고, 태영은 빼앗긴 후계를 되찾는가." → 희원 부친이 유일 증인이라 **두 축이 한 인물(부친)에서 합류.**
- `feedback_pressure_axis_stacking_vs_dispersion.md` 정합 (분산 X·수렴).

### 무료 회차 구조 (EP1-11)
- **EP1-2:** 총상 보스 + 직접 수혈 + **혈우병 펜던트 마크 발견**(보증 #1 장전) + 조직원 난입.
- **EP3-5:** 보스의 병원 점거(돈다발로 환자 내쫓기)·집착 시작 / 약혼남 정체 = 식물인간 부친 보험금 노린 쇼윈도(EP6) 폭로.
- **EP6-8:** 의붓가족 ATM 학대 + 약혼남 양다리 현장 목격 + 골목 보스 재등장.
- **EP9-10:** 병원 난동 의붓엄마 + "고작 이딴 새끼랑 결혼?" 보스 분노 퇴장.
- **EP11:** **결혼식 난입 → 신랑 한 방 → 신부 들쳐업기 → "내 신부는 내가 데려가려고" = 페이월.**

### 첫 유료 보상 (EP12-16)
- EP12: **30억 계약결혼서** + "1년 안에 나를 사랑하게 될지도."
- EP14-16: 가정부 3인의 일진놀이(칼로 얼굴 위협) → 보스 등장 → **가정부 손을 우드득 밟고 "치워"** = 첫 공개 응징 폭발.

### 반복 보상 루프 (유료 동력 3-5비트)
1. **공개 응징:** 희원을 모욕·이용한 자를 보스가 즉시·물리로 박살 (가정부 손밟기 → 블랙박스 양다리 공개[EP24] → 창고 야구방망이[EP44] → 형 체포[EP59]).
2. **무한 공급 다정:** 희원이 무심코 흘린 것(간식·쿠션·의학공부·금붕어)이 다음 씬에 다 준비됨 = 소유형 순정.
3. **도망 → 붙잡힘 코미디(EP18-20):** 탈출 시도 → 지훈이 간식·쿠션으로 무력화 → 문 앞에 보스가 서 있음. 가볍고 쉬운 도파민. (제목 모티프의 코믹 변주)
4. **"피뽑이" 오해 엔진:** "날 데려간 건 피 때문" 의심이 유료부 내내 관계에 쐐기 → 진실(첫사랑)로 해소.
5. **공개 신분 역전:** 무시당하던 간호사 → 한성회 보스 사모님 → HS그룹 후계자의 아내.

### 보증 장치(물증형) — 초반 장전·후반 회수
- **#1 혈우병 펜던트 마크 (EP1-2):** 표면 명분("피 필요") → 후반 살해 흉기(태민이 혈우병을 죽이는 수단으로 악용, EP55).
- **#2 꽃반지·병실 도망 기억 (EP60 회수):** 진짜 동기 = 첫사랑. 단 **물건이 reveal을 트리거하지 않고 태영의 대사로 직접 폭로**("너랑 내 얘기지") — 소품에 reveal 안 걸침.

### VO·플래시백·INS
- 희원 VO 빈번(내적 오해·결심·"피뽑이?"). 태영 VO는 결정 순간만("내가 널 얼마나 찾았는지").

## 종합 평가

### 강점 (우리 시스템에 직접 이식 가능)
1. **제목=소유 선언, 마지막 대사 회수** — 제목 설계의 모범. "도망" 모티프가 코미디(EP18-20)→집착→엔딩으로 일관.
2. **"피뽑이" 오해 엔진 = impostor-believed의 사촌.** 여주가 최악(이용당함)을 *믿고*, 시청자는 진실(첫사랑)을 의심하며, 진실은 후반에 *대사로* 폭로. SHE STOLE의 "세상은 가짜를 믿는다" 구조와 같은 계열의 *오해-지속 동력*.
3. **물증형 보증 2자루 초반 장전·후반 회수** (혈우병 마크 / 꽃반지). 단 reveal 트리거는 소품 X·대사 O — `vertical-protagonist-voice-ownership` 룰 정합.
4. **응징이 전부 물리·즉발·천박** (손밟기·블랙박스·야구방망이) — `easy-dopamine-over-logic`·"천박>세련" 정합. 살인 음모·후계 분쟁조차 정교 수사 X·증인 자백 한 방으로 해소.
5. **2단 빌런 설계** — 무료~초반 유료 = 즉발 잡빌런 회전 / 후반 = 판 거는 단일 메인(형).
6. **남주 이중 톤** — 적엔 clinical-cruel, 그녀엔 능글-순정. `compound-tone-parentheticals`·보이스 차별화 교과서.

### 약점·특이점
1. **남주 직업 = 조폭 + 후계 분쟁(이사회·체포·살인교사).** vertical-no-admin-power 관점에선 후반이 "기업 후계/법" 비중 큼 — **이식 시 후계 분쟁은 배경으로 압축하고 감정·공개응징 비트로 번역 필요**(이 작품은 증인 자백 한 방으로 단순화해 그나마 vertical 친화적이나, 우리 작품엔 default 금지축).
2. **혈우병/희귀혈액 = 정합 부담.** "피만 흘리면 죽는다" 류 의학 설정은 매력적이나 정확도 요구. 우리는 `easy-dopamine` 기조상 한 줄로만 다룰 것.
3. **수위 중(中).** 직설 T4 작품엔 베드씬 강도 미달 — heat 캘리브레이션은 별도 reference 필요.

### SHE STOLE / 여성향 obsessive-ML 작품 적용 인사이트
1. **오해-지속 동력:** "피뽑이" = 여주가 자신의 가치를 *깎아서* 오해하는 엔진. SHE STOLE의 impostor-believed와 결이 같음 — *여주/시청자 인지 간극*을 유료부 내내 끌고 가는 동력으로 재확인.
2. **응징의 결:** 손밟기·블랙박스 공개·야구방망이 = 모두 *눈에 보이는 물리 한 방*. 모욕은 4+비트 누적 후 반격. 우리 모욕·응징 비트 설계에 그대로 적용.
3. **물증형 보증 = 트리거 아닌 *정서 회수*:** 소품은 감정의 닻일 뿐 reveal은 대사로. SHE STOLE의 흉터·각인 운용과 동일 원칙.
4. **제목 회수:** 마지막 대사로 제목을 회수하는 닫기 = 강력한 엔딩 훅 표준.
5. **부친(증인) 단일 인물에 두 압력축 합류** = 압력축 수렴 설계 참고.
