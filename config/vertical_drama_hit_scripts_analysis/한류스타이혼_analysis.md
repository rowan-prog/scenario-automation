# 오늘 한류스타와 이혼하겠습니다 — 3축 분석

## 기본 메타

- **제목:** 오늘 한류스타와 이혼하겠습니다
- **회차:** 60+ 화 (정확 수 미확인)
- **1차 페이월 위치 (추정):** **약 9-10화**
  - 9-10화 = 이혼 선언 + 결혼반지 쓰레기통 버림 + 친정 회귀 + 백마탄 왕자(주헌) 등장 + 친정 재벌 회장 환영
  - 시청자가 받는 결제 트리거 = "이제 진짜 역전 시작" / "당당한 새 출발 + 진짜 멋진 남자 + 진짜 재벌 친정"
  - 단 16-18화 (노아 강 = 혜인 정체 노출 + 최현·리나 박살) 도 강력한 페이월 후보
- **장르:** 출생의 비밀 (재벌 친딸) + 이혼 + 재결합 + 한류 스타 + 백마탄 왕자 (연하 배우)
- **타깃:** 여성향 (20-40대) / 한국·아시아 시장
- **매출:** 사용자 검증 히트작 (INDEX 등재 / 매출 데이터 미확인)

## 1축. 캐릭터 (3 인물)

### 메인 빌런 — **명료한 단일 메인 + 보조 명료**
- **메인 빌런 1명 (전체):** **박리나 (소속사 대표)**
  - 얼굴·이름·말투·계속 등장
  - 1화부터 정체 명확 (최현 노린 여자)
  - 끝까지 가치 모름 (혜인 = 노아 강 정체 들통 후에도 멸시 유지)
  - 환경 압박 = 항상 최현 곁에 붙어 혜인 위장·괴롭힘
- **보조 빌런 다수:**
  - 최현 (남편) — 1화 정체 = 좋은 남편 위장 → 5화 곤장 변신 = 사실 배신 남편
  - 미란 (시어머니) — "이 못 배워먹은 년" 모욕 일상화 / 가부장 시댁 권력
  - 최은지 (PRESS 기자·리나 친구) — 리나와 함께 혜인 모욕
  - 산업 동료·기자 = 환경 압박

→ **`feedback_concrete_villain_humiliation_loop.md` 모범 정합** — 메인 빌런 1명 + 보조 다수 + 환경 압박

### 여주 — **강혜인 (이중 신분 + 약자 → 강자 정체 폭로)**
- **1화 처지:** 한류 스타 최현의 비밀 결혼 아내 / 임신 / 시상식 객석 구석에서 박수 / "비밀이라 속상해"
- **이입 트리거:**
  - 5화 리나의 뺨 때림 + 최현의 묵인
  - 6화 유산 + 최현의 "내 애 맞고?" 의심
  - 7화 최현의 폭언·뺨 맞기 직전
  - 8화 시어머니 "이 식충아" 식모 취급
- **반항 + 무시 패턴:**
  - 1-7화: 인내·참고 노력 (약자 처지)
  - 8화 폭발: "제 발로 나가요"
  - 17-18화: 노아 강 정체 폭로 + 커피 뿌리기 = 직접 반격
  - `feedback_female_lead_rise_arc.md` 정합 — 단 처음부터 완성형 X (1-7화 약자) → 8화 거래 → 후반 정상
- **8화 거래:** "이혼하자" 발화 + 결혼반지 버림 = 거래 정점
- **이중 신분 카드:** **노아 강 (글로벌 영화 감독) + 글로리 미디어 회장 친딸** = 후반 매번 사이다 핵심

### 남주 (구원자) — **이주헌 (연하 배우 + 백마탄 왕자)**
- 1화 등장 / 혜인 향한 옛 마음 표현 / "누나 얘기 했었는데" 시그니처
- 10화 최현의 손목 잡기 폭력 → 주헌이 차에서 등장 + "그 손 놔. 죽여버리기 전에" = 구원 정점
- 13화 본인 마음 직접 고백 "감독님 좋아해요"
- 짐승 직진 X / **다정한 보호자 + 결정적 순간 폭발 톤**
- 다크 로맨스 남주 X / 신데렐라 + 자상 + 강력 = 별도 톤

## 2축. 이야기 구조

### 압력축 1개
**핵심 질문:** "이 약자 비밀 아내가 언제 당당히 정체를 드러내고 모든 배신자를 박살내는가?"
- 사이드 사건 (한류 스타·헐리우드·미스 캐스팅·리나 정체) 등장하나 **모두 "혜인이 당당해질 때까지" 압력축에 수렴**
- `feedback_pressure_axis_stacking_vs_dispersion.md` 정합

### 무료 회차 구조 (1-9화 가설)
- **EP1:** 시상식 + 비밀 결혼 + 임신 = 1층 보상 (멋진 남편 + 비밀 + 임신 떡밥)
- **EP2-3:** 리나의 위장 + 사진 조작 + 계단 추락 사고 = 시청자 분노 트리거
- **EP4-5:** 유산 위기 + 최현의 무시 + 리나 본색
- **EP6-7:** 유산 + 최현의 "내 애 맞고?" + 뺨 맞기 직전 = 비참 정점
- **EP8:** 시어머니 식모 취급 + "이혼하자" 폭발 = **1차 거래**
- **EP9:** 결혼반지 버리기 + "너랑 결혼한 건 최악의 실수" = **페이월 후보**
- **EP10:** 주헌 등장 + "그 손 놔" + 친정 회장 환영 = **페이월 정점 후보**

### 보상 단계 설계
- **1층 즉시 (EP1-3):** 한류 스타 비밀 결혼 + 임신 + 시상식 객석 = 즉시 보상
- **2층 누적 (EP4-7):** 유산·뺨·시댁 = 분노 게이지 폭발 직전
- **3층 페이월 (EP8-10):** 이혼 + 친정 회복 + 백마탄 왕자 + 노아 강 정체 (16-18화)

### 클립 보상 루프
**원초 쾌감:** "약자 아내로 무시당한 여자가 진짜 정체(재벌 친딸 + 글로벌 감독)로 매번 더 큰 무대에서 박살낸다"
- EP1 약자 객석 → EP15 노아 강 단상 메인 자리
- EP5 리나 뺨 → EP18 리나 커피 + 신발 뺐기기
- EP7 시어머니 식모 → EP14 친정 회장 다이아몬드 목걸이 선물
- = `feedback_clip_reward_loop.md` 정합 (공개성·지위 점진 확장)

### VO·플래시백
- 혜인 VO 자주 활용 (내적 인내·결심)
- 플래시백 비중 적음 — 사건이 빠르게 진행

## 3축. 대사 스타일

### 짧고 직관
- "이혼하자" / "닥쳐. 애기 얘기 꺼내지 마" / "더러운 손 치워" — 짧고 강함
- 시적·연극톤 0건
- 작가 자아실현 톤 0건

### 시그니처 발화
- 미란 "이 못 배워먹은 년" — 반복 시그니처
- 최현 "주제 파악을 좀 해" — 권력 발화
- 혜인 "박리나 너 결국 본색 드러내네"

### 모욕 교환 5-8턴
EP5-7 모욕 누적:
- 리나 "최현이랑 나, 단순히 비즈니스 관계라고 생각하는건 아니지? 우린 꽤 자주 같이 밤을 보내는 사이거든"
- 혜인 "거짓말. 그딴 거짓말에 안 속아"
- 리나 "어차피 최현은 또 날 찾아올거니까"
- 혜인 "그만!"
- 최현 등장 → 리나 넘어진 척
- 혜인 "최현, 박리나랑 도대체 무슨사이야?"
- 최현 "꾀병 부리지 마" → 혜인 밀치기 → 유산
- = 5-8턴 모욕 누적 + 폭발

### 페이월 직전 대사
- "너랑 결혼한 건 내 평생 최악의 실수였어" — 거래 종결
- 결혼반지 쓰레기통 버림 = 행동
- "그 손 놔. 선배고 뭐고, 죽여 버리기 전에" (주헌) = 구원 정점

### 멀티태스킹 청각 정합
- 모든 사건이 명확한 대사로 청각 전달
- 화면 안 봐도 사건 흐름 따라옴

## 종합 평가

### 강점
1. **메인 빌런 1명 (박리나) + 보조 명료** = 모범 정합
2. **여주 1화 약자 → 8화 거래 → 후반 정상** 상승 호 명확
3. **이중 신분 카드 (노아 강·재벌 친딸)** = 후반 클립 보상의 강력 트리거
4. **백마탄 왕자 (주헌)** = 자상 + 결정적 폭발 톤 = 여성향 정합
5. **무료 8-9화 페이월 + 16-18화 후속 폭발** = 2단 결제 트리거
6. **대사 짧고 직관·5-8턴 모욕 누적** = 모범 정합

### 약점·특이점
1. **남주 짐승 직진 톤 X** — 다크 로맨스 X / 자상한 보호자 톤. 다크 로맨타지·OFFERING과 톤이 다름
2. **여주 1화 처지 인내 위주** — 의붓남매·천재 아기보다 처절함 강도 약함. 약자 인내 → 폭발 패턴
3. **이혼 + 친정 회귀 + 정체 폭로** = 한국 신데렐라 + 출생의 비밀 정형 — 다크 로맨타지에 직접 이식 어려움

### OFFERING·다크 로맨타지 적용 인사이트
1. **메인 빌런 1명 (박리나) 끝까지 등장** = OFFERING 메인 빌런 (이복오빠·또는 단일 인물) 단일 유지 모범
2. **이중 신분 (약자 → 진짜 정체)** = 이졸데가 단순 제물이 아니라 진짜 정체가 있다는 후속 보상 트리거로 적용 가능
3. **5-8턴 모욕 교환 + 컵 뿌리기 등 행동 응수** = OFFERING에서 이졸데가 빌런에게 직접 행동 응수하는 비트로 이식 가능
4. **9-10화 페이월 후 16-18화 후속 페이월** = OFFERING 8화 페이월 후 유료 EP9-15에 추가 폭발 페이월 설계 권장
5. **백마탄 왕자 등장 시점** = OFFERING에서 Vael의 결정적 등장 (예: 모욕 직후 폭발) 타이밍 참조
