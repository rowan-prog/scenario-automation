# 나의 토깽이 아가씨 — 3축 분석

## 기본 메타

- **제목:** 나의 토깽이 아가씨
- **회차:** 65화
- **1차 페이월 위치 (추정):** **약 13화**
  - 13화 호텔 = "한 번 더 해요" 거래 + 두 번째 동침 + 새 권력 관계 시작 (넥타이 묶임)
  - 12화 + 13화에 걸쳐 사적 욕망·소유 강도 폭발 → 결제 트리거
- **장르:** 차도남 재벌 CEO + 우연한 원나잇 → 계약 동침·집착 / 신데렐라 + 코믹 + 재벌 집안 갈등
- **타깃:** 여성향 (20-30대) / 한국·아시아 시장
- **매출:** 사용자 검증 히트작 (INDEX 등재 / 매출 데이터 미확인)

## 1축. 캐릭터 (3 인물)

### 메인 빌런 — **다층 환경 압박 구조 (의붓남매 유사 패턴)**
- **EP1-11 단기 빌런:** **허만석 (부장)** — 직장 성희롱·정규직 미끼·강압 / EP12 선우에게 박살 (멱살·경고).
- **EP1-끝 지속 빌런:** **백진우 (이복동생) + 송유라 (그의 여친·소속사 직원)** — 상속 가로채기·서현 위협·임신 사기.
- **장기 메인 빌런:** **백 회장 (아버지)** — 선우 무시·진우 편애·결혼 강요 / 후반 인정으로 회복.
- **환경 압박:** 회사·재벌 집안·소속사 / "초라한 인턴이 재벌가에 어떻게 어울리나" 무시 누적.

→ `feedback_concrete_villain_humiliation_loop.md`의 "메인 1명 + 보조 다수" 룰을 일부 변형 — **시기별 빌런 교체** + **장기 보조 다수 (진우+유라+회장)**.

### 여주 — **진서현 (코믹·천연·인턴)**
- **1화 처지:** 23세 화장품 회사 인턴 (최저시급) / 만취해 모르는 남자 방에 잘못 들어가 첫경험 사고. 도망쳐 나옴.
- **이입 트리거:**
  - 1화 만취 사고 (수치) + 키스 자국 (몸의 흔적)
  - 3화 산부인과 검사 (수치 정점) + 알고 보니 선우가 의사 행세 (멸시)
  - 11화 부장 강제 키스 (직장 성희롱)
  - "처녀라 처음" "최저시급 인턴" "수술도 못 끝났는데" 등 약자 처지 명시
- **반항 + 무시 패턴:** 
  - "그쪽처럼… 잘생기고, 그… 능숙한 사람은 분명…" (어색하게 저항)
  - "당신은 짐승이야!" (직접 반격)
  - "이거 놔요!" 부장 거부 + 뺨 때리기
  - 처지는 약자지만 입은 살아있음 — `feedback_female_lead_rise_arc.md` 정합
- **8화 거래 안 함:** 8화 = 차 안 + 보상 의미로 한 번 더 약속 (간접 거래) — 13화에 실제 거래 완성
- **65화 정점:** 본인 입으로 "사랑해요. 우리 사귀어요" 직접 발화 + 회사 정규직 + 재벌가 며느리 수락

### 남주 — **백선우 (재벌 CEO + 능청 + 짐승 직진)**
- **포지션:** 백승 그룹 상속자 / MIT 졸업 / 의대 박사 어머니 (병원 운영) / 차도남 + 능청형 + 첫경험 동지
- **빌런-남주 패턴:** EP1 만취 강제 키스 응수·바닥 차게·도망 후 직접 추적
- **짐승 직진 vs 절제:** 
  - **짐승 직진 비중 높음** — 정체 안 밝힘 + 의사 행세 + 산부인과 진료 시도 + "보상 한 번 더" 강요 + 호텔 강제 + 넥타이 결박 + "내 거" 선언
  - **절제 매우 적음** — 첫 키스 직접·두 번째 키스 직접·동침 직접·이후 가차없는 소유
  - 단 — 가끔 토깽이를 "어린애" 취급해 보호하는 면 (의붓남매 주환과 유사한 양면)
- **voice:** "토깽이" / "착한 토깽이네" / "잘 때렸어" — 사물화 + 사육 톤. 시그니처 호칭 강함.

## 2축. 이야기 구조

### 압력축 1개
**핵심 질문:** "이 코믹 인턴이 재벌 CEO를 통제할 수 있는가? + 둘이 진짜 사귈 수 있는가?"
- 사이드 사건 (재벌 상속 갈등·이복동생·전 약혼녀·회사 정치) 등장하나 **모두 "이 두 사람 관계가 어디까지 가는가" 압력축에 수렴**.
- `feedback_pressure_axis_stacking_vs_dispersion.md` 정합 — 단 (의붓남매 대비) 재벌가 정치 사이드 비중 약간 더 큼.

### 무료 회차 구조 (1-13화 가설)
- **EP1-2:** 만취 첫경험 사고 + 도망 (강력한 1층 보상 = 차도남 잘생긴 남자랑 우연히 잤음)
- **EP3-5:** 산부인과 들통 + 의사 행세 + 진료 굴욕 + 어머니 등장 (코믹 정점)
- **EP6-8:** 정체 노출 + 차 안 + "보상 한 번 더" 거래 / 백승 CEO 정체 알게 됨
- **EP9-10:** 재벌가 정치 (이복동생 등장·상속 갈등) + 친구 한승우 등장
- **EP11-12:** 부장 성희롱 → 선우의 구원 (구원자 트리거)
- **EP13:** 호텔 두 번째 동침 + 넥타이 결박 + "오늘 밤은 철저하게" = **1차 페이월**

### 보상 단계 설계
- **1층 즉시 (EP1-2):** 첫경험 코믹 사고 + 차도남 비주얼 = 즉시 보상
- **2층 누적 (EP3-12):** 우연 재회 → 정체 폭로 → 직장 위기 → 구원 = 텐션 증가
- **3층 페이월 (EP13):** 자발적 두 번째 동침 + 결박 + 소유 = 큰 보상

### 클립 보상 루프
**원초 쾌감:** "초라한 인턴 토깽이가 잘생기고 부유한 차도남의 유일한 사육·소유 대상이 된다 + 모욕한 인물 공개 박살"
- 매 화 클립 보상 (`feedback_clip_reward_loop.md` 정합):
  - 부장 성희롱 → 선우 박살
  - 매장 무시 → 선우 정체 노출 → 매니저 해고
  - 진우·유라 모욕 → 선우 박살
  - 재벌 회장 무시 → 선우 자기 정체 입증

### VO·플래시백
- VO 자주 활용 (서현·선우의 내적 코미디)
- FLASHBACK 자주 활용 (각 인물 회상)
- 5조건 충족 비중 중간 — 빌런 직접 발화는 약함

## 3축. 대사 스타일

### 코믹 톤 + 직관
- "토깽이" 시그니처 호칭 = 사물화 + 권력 표지
- "착한 토깽이네" / "꾀병 부리지 마" / "나 말고 다른 남자랑 키스해 본 적 있어요?" — 짧고 강함
- 서현의 코믹 VO ("나 이제 막 졸업했는데… / 못 해본 게 얼마나 많은데…") = 시청자 이입 강함

### 시적·연극톤 = 0건
- `feedback_no_theater_tone.md` 절대 정합
- 분위기 단어 0건
- 작가 자아실현 톤 0건

### 5-8턴 모욕·도발 교환
- EP12-13 호텔 시퀀스:
  - 선우 "한밤중에 내 방에 들어와 내 처음을 가져갔잖아요"
  - 서현 "처녀라 처음이라 아무 문제 없었을 거고요"
  - 선우 "재밌네"
  - 선우 "보상 의미로… 한 번 더 하는 건 어때요?"
  - 서현 "또요?" + "어머니 말씀이 맞네요. 당신은 짐승이야!"
  - 선우 "싫으면 거절해도 돼요. 대신 변호사 통해서 얘기하죠"
  - 서현 "알았어요! 잘게요!"
  - 선우 "착한 토깽이네"
  - = 5-8턴 권력의 춤 / `feedback_paid_vertical_dialogue_rules.md` Pattern B 정합

### 멀티태스킹 청각 정합
- 코믹 대사 + 직관 사건 흐름 / 화면 안 봐도 사건 이해
- "토깽이가 도망갔네" / "기억해 둬요. 내 이름은 백선우입니다" / "이젠 나한테 어떻게 보상할 건지 얘기해 볼까요?"

### 페이월 직전 대사
- "오늘 밤은 아주 철저하게 해야겠네" — 다음 사건 즉시 보임
- "오늘은 조금 색다르게 해볼까요" + 넥타이 묶기 — 시청자가 다음 씬 상상

## 종합 평가

### 강점
1. **압력축 1개** ("두 사람 관계 어디까지") 65화 끝까지 유지
2. **여주 약자 처지 + 반항 + 무시 + 코믹 회복** = 이입 트리거 강함
3. **남주 짐승 직진 비중 매우 높음** — 다크 로맨스 본격급 / 절제 매우 적음
4. **시그니처 호칭 ("토깽이")** = 권력 관계·소유 즉시 인식
5. **코믹 + 짐승 직진 동시 운용** = 여성향 paid vertical 매출 핵심 정합
6. **대사 짧고 직관·5-8턴 권력 춤** = `feedback_paid_vertical_dialogue_rules.md` 모범 사례

### 약점·특이점
1. **메인 빌런 단일성 약함** — 시기별 빌런 교체 (의붓남매와 동일 패턴)
2. **여주 1화 처지 약함** — 사고 + 코믹이라 처절함 강도는 의붓남매보다 낮음. 그러나 코믹 톤이 이를 보완.
3. **재벌 상속 사이드 비중** — 약간 분산 위험이나 짧게 처리

### OFFERING·다크 로맨타지 적용 인사이트
1. **시그니처 호칭 ("토깽이" / "꼬맹이")** = 사물화·소유·권력 표지로 매우 강력. 이졸데를 부르는 Vael 시그니처 호칭 도입 권장
2. **코믹·짐승 직진 동시 운용** = 톤 균형이 매출 강화. 다크 로맨타지에서도 일부 코믹 비트 유효
3. **차 안 / 호텔 = 사적 공간 페이월** 패턴 — 다이닝·궁정 외부 공간 보상 + 사적 공간 폭발 페이월
4. **5-8턴 권력 춤 대사 Pattern B** 직접 이식 가능
