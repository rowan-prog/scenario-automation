# Vertical Drama 검증 성공작 5개 — 공통 패턴 분석

> 분석 작품: 의붓남매의 은밀한 비밀(62화·한국) / 나의 토깽이 아가씨(65화·한국) / 천재 아기의 인생역전(가제·한국·효도 판타지) / 오늘 한류스타와 이혼하겠습니다(60+화·한국) / 陷入她的热恋(62화·중국 원작)
> 
> 모두 사용자 검증 히트작 (INDEX 등재). OFFERING·다크 로맨타지·여성향 paid vertical 재설계 baseline.

## 1차 페이월 위치 비교 표 (절대 수치)

| 작품 | 회차 | 1차 페이월 추정 | 무료 비율 | 트리거 사건 |
|---|---|---|---|---|
| **천재 아기 인생역전** | 미확정 | **7화 (대본 명시)** | ~14% (50화 기준) | 운미사이언스 상한가 + 강지윤·한민철 패닉 |
| **오늘 한류스타와 이혼** | 60+ | **9-10화** | ~17% | 이혼 선언 + 결혼반지 버리기 + 친정 회귀 + 주헌 등장 |
| **陷入她的热恋** | 62 | **8-10화** | ~16% | 시한부 정체 깨달음 + 자발적 보호자 전환 + 10억 시주금 |
| **나의 토깽이 아가씨** | 65 | **13화** | ~20% | 호텔 두 번째 동침 + 넥타이 결박 + 권력 관계 시작 |
| **의붓남매 은밀한 비밀** | 62 | **13-15화** | ~22% | 박상현 박살 + 욕실 첫 키스 (금기 위반) |

### 핵심 인사이트
1. **1차 페이월 = 7-15화 사이** (작품마다 다름) — "1-8화 무료 = 우리 시스템 룰" 가정 X
2. **여성향 가장 짧은 페이월:** 천재 아기 (7화) = **6화 빌드업 + 7화 폭발** = 사용자 결제율 가장 높을 가능성
3. **다크 로맨스·짐승 직진 작품일수록 페이월 늦음** (의붓남매·토깽이 = 13-15화) — 텐션 누적 시간 필요
4. **신데렐라·이혼·운명 작품일수록 페이월 빠름** (한류스타 9-10화·천재 아기 7화) = 폭발 이벤트가 명확
5. **OFFERING의 8화 페이월은 평균 이내** — 단 본 5작 모두 "8화 = 결단·폭발" 트리거 강함 → OFFERING 8화 "Yours" 발화는 정합 / 단 더 큰 행동 트리거 (시한부·이혼·폭로) 결합 권장

## 1축 캐릭터 — 공통 패턴

### 1.1 메인 빌런 패턴 (2 종류 발견)

**Type A — 명료한 단일 메인 빌런 + 보조 다수 (모범 정합):**
- 천재 아기: 한민철 (친아빠) — 1화부터 끝까지 단일
- 한류스타 이혼: 박리나 (소속사 대표) — 1화부터 끝까지 단일
- **OFFERING이 본받아야 할 패턴.** `feedback_concrete_villain_humiliation_loop.md` 모범

**Type B — 시기별 빌런 교체 + 환경 압박 다중:**
- 의붓남매: 박상현 (단기) → 한아라 (중기) → 송미란 (중기) → 강성진 (보스)
- 토깽이: 허만석 (단기) → 진우+유라 (중기) → 백 회장 (보스)
- 陷入她的热恋: 여러 환경 빌런 → 할아버지 가족 (보스)
- 단 — 환경 압박이 절대 다수 / 시청자 압력축 유지

**판단:** Type A가 단순·강력 / Type B가 변화·다양. OFFERING 같은 다크 로맨타지 = Type A 권장 (메인 빌런 1명 = 시청자 분노 게이지 집중)

### 1.2 여주 호 (모든 작품 공통 — 절대 패턴)
**모두 1화 약자 처지 + 반항·저항 시도 + 무시·모욕 받음** = `feedback_female_lead_rise_arc.md` 절대 정합
- 의붓남매 윤지안: 가난한 정비사 딸 + 새 가족 모욕 받음 + 입은 살아있음
- 토깽이 진서현: 인턴 + 만취 사고 + 부장 성희롱 + 코믹 반격
- 천재 아기 (이서연·도혁): 시한부 엄마 + 발길질·고독사 + 회귀 아들이 보호
- 한류스타 강혜인: 비밀 아내 + 유산 + 시댁 식모 + 8화 폭발
- 陷入她的热恋 임서윤: 배달원 + 시한부 엄마 + 강제 키스 + 와인병 저항

→ **1화 완성형 0건** / **1화 매달림·울음 0건** / **반항 + 무시 모범** (사용자 정정 정합)

### 1.3 남주 패턴 (3 종류 발견)

**Type 1 — 짐승 직진 + 절제 약함 (다크 로맨스 본격):**
- 토깽이 백선우 — 정체 안 밝히고 행세·강요·넥타이 결박
- 陷入她的热恋 배태환 — 강제 키스·계약결혼·침대 강제

**Type 2 — 짐승 직진 + 절제 비중 균등 (혼합형):**
- 의붓남매 강주환 — 도발·강제 / "성인 되기 전 안 돼" 절제

**Type 3 — 자상 보호자 + 결정적 폭발 (백마탄 왕자):**
- 한류스타 주헌 — 다정 + "그 손 놔. 죽여 버리기 전에" 폭발 톤

→ **OFFERING = Type 1 (다크 로맨스 본격) 모범 / 절제 0건 권장** — `feedback_dark_romance_male_predator.md` 정합

### 1.4 시그니처 호칭 (모든 작품 매우 강력)
- 의붓남매: "꼬맹아" (주환→지안)
- 토깽이: "토깽이" (선우→서현) / "착한 토깽이네"
- 천재 아기: "엄마" "아저씨" 반복
- 한류스타: "이 못 배워먹은 년" (시모→혜인)
- 陷入她的热恋: "사모님" (장 여사·태환→서윤)

→ **시그니처 호칭 = 권력·관계·소유 즉시 인식 = paid vertical 핵심.** OFFERING에서 Vael→이졸데 시그니처 호칭 (예: "petal" / "petalmark" / "mine" / "Yours") 1개 정착 필수

## 2축 이야기 구조 — 공통 패턴

### 2.1 압력축 1개 (모든 작품 정합) — `feedback_pressure_axis_stacking_vs_dispersion.md` 모범
- 의붓남매: "이 의붓남매가 언제 선을 넘는가?"
- 토깽이: "두 사람 관계 어디까지?"
- 천재 아기: "엄마를 위한 효도 판타지 완성?"
- 한류스타: "약자 비밀 아내가 언제 정체 폭로하고 박살내는가?"
- 陷入她的热恋: "강제 결혼이 언제 진짜 사랑·시한부 회복?"

→ **OFFERING 압력축 정정 권장:** "이졸데가 언제 Vael과 진짜 거래 + 짓밟은 환경을 박살내는가?" — 단일 명확

### 2.2 보상 단계 3층 (모든 작품 정합)
- **1층 즉시 (EP1-3):** 장르 진입 보상 (사고·운명·만남·비주얼) — 안 주면 즉시 이탈
- **2층 누적 (EP4-페이월 직전):** 환경 적대·분노 게이지·텐션 증가
- **3층 페이월 (7-15화):** 큰 보상 폭발 (이혼·동침·운명·금기 위반)

### 2.3 클립 보상 루프 — 원초 쾌감 1개 + 점진 확장 (모든 작품 정합)
- 의붓남매: 사적 끌림 → 공적 무시 → 사적 폭발 (반복 + 강도 증가)
- 토깽이: 모욕 → 차도남 박살 (공개성·지위 점진 확장)
- 천재 아기: "엄마 무시한 세상이 회귀 도혁에게 박살난다" (사적 → 매장 → 가족 → 사회)
- 한류스타: 약자 객석 → 노아 강 단상 (정체 점진 폭로)
- 陷入她的热恋: 강제 → 운명 깨달음 → 보호자 전환

→ **OFFERING 원초 쾌감 1개 정의 권장:** "폐품 취급당한 이졸데가 괴물의 유일한 통제자로 매번 더 큰 무대에서 박살낸다"

### 2.4 무료 회차 끝 = "결단·폭발" 이벤트 (모든 작품 정합)
- 천재 아기 7화: 상한가 폭발 + 빌런 무릎
- 한류스타 9-10화: 이혼 선언 + 결혼반지 버리기 + 백마탄 왕자 등장
- 陷入她的热恋 8-10화: 시한부 깨달음 + 자발적 전환
- 토깽이 13화: 두 번째 동침 + 결박 + 권력 관계
- 의붓남매 13-15화: 박상현 박살 + 첫 금기 위반

→ **OFFERING 8화 "Yours" 발화 = 정합. 단 더 큰 사건 트리거 결합 권장:**
- 1차 빌런 (이복오빠) 공개 박살
- 또는 운명·시한부·구원 깨달음
- 또는 친정 회귀·정체 폭로
- 단순 발화 < 발화 + 행동 + 결과

### 2.5 VO·플래시백 (모든 작품 적극 활용) — `feedback_vo_flashback_pressure_tools.md` 정합
- 모든 작품이 VO·FLASHBACK을 청각 정보 보강·분노 게이지 누적·시청자 인지 트리거로 활용
- 사용자 멀티태스킹 청각 정합 = 필수
- **OFFERING 무료 회차 = VO·플래시북 적극 도입 권장** (옛 v3-v8에 0건 = Demon Lord 함정)

- 모든 작품 매 화 1-2회 등장
- **OFFERING 옛 v3-v8 = 2-3턴 인장 대사로 자름 (Demon Lord 함정) → 5-8턴 누적 정정 필수**

### 3.3 좋은 긴 대사 3 Pattern (모든 작품 정합) — `feedback_paid_vertical_dialogue_rules.md` Section 12
- **Pattern A 사실 나열:** 陷入她的热恋 태환 "오늘 밤 내 방에 와. 그럼 내일 바로 이혼해 줄게"
- **Pattern B 조건부 거래:** 토깽이 선우-서현 호텔 권력 춤
- **Pattern C 최후통첩:** 의붓남매 주환 "처신 잘 해. 다음엔 더 세게 가르쳐줄 테니까"

- 陷入她的热恋 "벗으라고" / "거래일 뿐이야"

→ **OFFERING Vael 시그니처 발화 1-2개 정착 권장** (현재 "Only I leave a mark here" = 시적 트리거 위험 / 단순 직진 발화로 정정)

### 3.5 멀티태스킹 청각 정합 (모든 작품 정합) — `feedback_paid_vertical_dialogue_rules.md` Section 24

- 텐션 구간 짧고 강함

## OFFERING·다크 로맨타지 직접 이식 권장 사항 (요약)

### 즉시 정정 (Demon Lord 9 함정 회피)
1. **메인 빌런 1명 단일 (천재 아기·한류스타 모범)** — 옛 OFFERING의 "왕국·사절단·집단" 폐기 / 이복오빠·전 약혼자 중 1명 단일 메인
2. **시그니처 호칭 정착** — Vael→이졸데 한 단어 호칭 (예: "petal" / "mine") 매 화 반복
3. **VO·플래시백 적극 도입** (옛 v3-v8 = 0건) — EP1·EP7·EP8 분노 게이지 누적용
4. **5-8턴 모욕 교환** (옛 = 2-3턴 인장) — 빌런·하인·후보녀·사절 5턴 모욕 매 화 1-2회
5. **남주 절제 0건** (옛 = "Because if I don't stop") — 짐승 직진 / Type 1 (토깽이·陷入她的热恋 모범)
6. **여주 1화 반항 + 무시 + 폭력** (옛 = 셈하는 여자) — 사슬·욕설·반항 시도·무시 받음
7. **EP8 페이월 = 발화 + 행동 + 결과** (옛 = "Yours" 단순 발화) — 빌런 박살 + 폭로 + 운명·시한부 + 친정 회복 등 행동 트리거 결합 권장

### 후순위 검토
8. **남주 시한부·운명 트리거 결합** (陷入她的热恋 모범) — Vael의 양독·저주·시한부 등 결합 가능
9. **사적 vs 공적 공간 분리 강화** (의붓남매 모범) — 다이닝룸 = 공적 위장 / 침실 = 사적 폭발
10. **회상 자주 활용** (陷入她的热恋 모범) — 매 EP 시청자 인지 트리거 회상 1회
