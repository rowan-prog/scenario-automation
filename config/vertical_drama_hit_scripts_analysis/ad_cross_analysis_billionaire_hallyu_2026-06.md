## 1. 광고 = 4-10분 미니 드라마라는 전제의 검증 결과

- 광고 고효율 비트는 **거의 전부 본편 실비트에서 잘려 나옴** (전수 매핑 완료). 본편에 없는 광고 결 2건 발견: ①Billionaire "회상 기반 배신 서사" — **실대본 flashback 0건** (대사 retro-telling만: "For seven years, I paid your rent..."를 광고팀이 회상풍으로 재편집한 것으로 추정) ②한류스타 "ES 가스라이팅" — 본격 가스라이팅 시퀀스 없음 ("피해망상"·"꾀병" 단발 대사뿐).
- → **함의: 광고팀은 본편 컷 재조합 + 약간의 재편집 창작까지 한다. 그래도 원료의 95%는 본편.** 무료부 = 광고 원료 창고 가설 유지·강화.
- **마스터 비트 발견:** 한 장면에 여러 권역 결이 공존하는 허브 — Billionaire EP42(회장이 딸 뺨 SMACK → 무릎 → "Chairwoman Sinclair, welcome" = ES 응징 + EN 신분반전 + ROW 권한 인정이 한 비트) / 한류스타 EP47-49(병원 로비 집단가해 → 후계자 폭로 → 막내딸 = US 사이다 + ROW 가족권력). **권역 광고 전부를 먹이는 건 이런 "겹결 한 방"이다 — 집필 시 클라이맥스급 비트는 의도적으로 겹결 설계.**

## 2. 실대본 공통 문법 (두 작품 모두에서 검증된 것)

1. **EP1 전제 VO 전량 선공개.** Hannah "I'm the CEO of Zena Group. He's going to be so surprised!" / 혜인 "글로리 미디어가 바로 우리 아빠 회사라는 것." — 정체 비밀을 1화 1분 안에 시청자에게 깐다. 미스터리 0·"언제 터지나"의 극적 아이러니가 장르 표준 (우리 엔진 룰과 일치·재검증).
2. **본인 선언은 좌절시키고, 확정은 제3자·권위자·물증이 한다.** 한류스타 4단(EP19 "내가 노아 강" → 목걸이 끊겨 좌절 → EP33 오빠 → EP35 헐리우드 배우 → EP36 확정) / Billionaire(EP18 남편 선언 → EP42 회장 무릎+호칭 → EP58 카드 스캔). **반전 순간 여주의 자기 설명 독백 = 없음. 호칭 한 줄 + 무릎/절이 전부.**
3. **사이다 = 부메랑 반사.** 가해에 쓰인 단어·도구를 그대로 되돌려준다 — "kneel/beg" 5회 요구 → EP42 가해자측 무릎 / 앞치마 되던짐·구두에 커피·수표 찢어 얼굴에·꽃다발로 가격. 새 무기가 아니라 **받은 것의 반사**가 직관 카타르시스.
4. **모욕 어휘 = 신분·돈·몸 직격 구체어.** "high school drop out"·"whose bed did you crawl out of"·"기생충"·"식충아"·"싸구려 몸"·"몸이라도 판 건가". 추상 비난 0. 같은 모함(성적·학력)을 모티프로 반복해 가해자 천박함 각인. 여주는 침착 단문 반격 ("I came with Mr. Kane." / "이제 남이죠, 저희는.").
5. **가해자 권위 계단.** Victoria→Sabrina→Sloane→Margaret→Ava / 리나→리나+최현→+미란→+군중→+팬클럽. 모욕 주체가 격상될 때마다 여주의 응수 카드도 격상 — 대형 보상은 ~14화(B)/4-6화(H) 주기·사이에 소형 반격 박기.
6. **극단적 공간 milk.** Billionaire = 36씬/64EP(0.56씬/EP) — **연회장 하나가 EP8-44 약 30화** 지속. 한류스타 = 86씬/60EP(1.43). EP 경계가 씬 중간(질문·뺨 직전·새 인물 O.S. 호명)에서 끊김. 새 권력자 등장은 "O.S. 호명 → 타 공간 컷(달려오는 차) → red carpet 난입" 사다리.
7. **직전 컷 법칙 = 정보 공개와 반응 사이를 절단.** "This is my wife, Hannah Kane." 선포 순간 컷·상대가 stunned/frozen으로 굳는 순간 컷·"놀라는 세 사람에게서 엔딩". 다음 화 = 그 표정에서 시작.
8. **VO 3기능: 전제 까기(EP1 장문 허용)·억울함 속내(1-2줄)·빌런 야욕 예고("최현은 이제 내 꺼야" — 다음 악행 예고로 분노 선적재).** 시적/작가 해석 VO = 양 작품 0건.
9. **톤 지문 적극 사용** — 1단어 감정형(`(mocking)`·`(짜증)`) + 수신자 지정(`(to Ethan)`) + 복합형(`(당당한 미소)`·`(sweet, cruel)류`). EP당 2-4개. 문학 묘사형 0.
10. **물증의 역할 구분:** 신분 *증명* 물증(카드 스캔→경비 절·계약서·수표)은 적극 — 단 **진실 공개 자체는 항상 사람(호칭·무릎·증언)이 한다.** 물증 = 굴복 장치이지 reveal 트리거가 아님 (우리 소품 룰과 양립).

## 5. 검수 체크 후보 (측정 가능)

1. **VO 검사:** 정보/속내/예고형만 — 은유·작가해석 VO 1건이라도 = fail (양 히트작 0건 기준).
2. **반전 길이:** 정체 공개 순간 여주 자기 설명 5줄+ = 수술 (기준 = 호칭+무릎 2줄).
3. **모욕 구체성:** 추상 비난 비율 — 빌런 막말이 신분/돈/몸 구체어인가. "글처럼 잘 쓰인" 빌런 라인 = 감점.
4. **사이다 지연 단수:** 본인 선언→불신→제3자 확정 최소 2단 이상 (한류스타 4단 기준). 단발 폭로 = 감점.
5. **부메랑 회수율:** 가해 단어/도구가 보상 비트에서 반사되는가 (kneel→무릎·수표→찢기).
6. **광고-절단 테스트:** 무료부 각 핵심 비트가 맥락 없이 0.1초에 부당함 읽히는가 + "갈등→고조→직전컷" 미니 아크 2-3개 존재.
7. **엔딩 절단점:** 정보 공개와 반응 사이에서 끊겼는가 (반응까지 보여주고 끝나면 훅 약화).
8. **겹결 비트 유무:** 클라이맥스가 응징+신분+로맨스 인정 중 2결 이상 겹치는가.

## 6. 우리 시스템과의 정합/긴장

- **일치 (방향 일치 — 단 "재검증" 아님·§7 참조):** 극적 아이러니 선공개·증거 안 통함·천박 빌런·권위 계단·묶음 milk·직전 컷 훅·부메랑(princess) — SHE STOLE 엔진이 두 히트작 문법과 정합. 대시보드는 정성 자료라 이 문법들을 "입증"하진 못함 — 대본 발견에 대시보드가 같은 방향을 *약하게* 가리키는 것.
- **긴장 1 — VO:** 히트작은 EP1 전제 VO 장문 + 빌런 야욕 VO를 우리 룰보다 훨씬 적극 사용. 특히 **빌런 야욕 VO 예고**는 우리가 안 쓰는 도구 (SHE STOLE는 INTERCUT으로 대체 중). 채택 검토 가치.
- **긴장 2 — 물증:** 신분 증명 소품(카드·계약서)의 반복 사용은 우리 소품 최소화 룰과 표면 충돌 — 단 reveal 트리거는 항상 사람이므로 "증명/굴복 물증 허용·공개 트리거 금지"로 정밀화하면 양립.
- **긴장 3 — milk 강도:** Billionaire의 30화 단일 공간은 우리 4-8화 묶음보다 훨씬 김 — 우리 룰이 보수적임을 시사 (단 60-90초/화 초단척 포맷 차이 감안).

## 7. 대시보드 원본 1:1 대조 결과 (2026-06-05 보강 — `ad_dashboard_inventory_audit_2026-06.md` 동반 정독)

**근거 출처 라벨 (룰 후보 ①~⑩):** 대시보드 직접 지지 **강** = ⑩직전 컷 하나뿐 (4타이틀 전부 명시). **중** = ②③ (1단 점프까지만 지지·4단 계단은 대본 발견). **약** = ①④⑤⑥⑦. **무** = ⑧⑨ (100% 대본 발견). → 등재 시 "광고 데이터 입증"으로 라벨 금지 — ①④⑤⑥⑧⑨는 실대본 2편 발견·⑦겹결은 대시보드가 오히려 권역별 *다른* 크리에이티브 상위라는 정반대 그림이라 긴장.
**검수 체크 라벨 (1~8):** 강 = #6 광고-절단·#7 엔딩 절단 (대시보드 최강 신호와 일치 — 우선순위 최상위로). 중 = #4. 나머지 = 대본 발견.

**격하 2건:**
- §1 회상 결 — 대시보드 T3 EN/US에 "회상 기반 배신 서사 워킹" 명문 존재. "flashback 0건"(대본)은 사실이나 "광고팀 창작" 인과는 가설로 격하.
- §1 겹결 마스터 비트 — EP 번호·겹결 이론은 대본+해석. 대시보드 데이터(ROAS 상위 = 권역별 분기)와는 긴장. 매력적 가설로 유지하되 입증 주장 금지.

**기존 분석이 놓친 대시보드 발견 (수확):**
1. **CTR(글로벌 공통 자극) vs ROAS(권역별 payoff 분기) 분리** — CTR 상위는 4-5권역 동시 점등·ROAS 상위는 공통 2 일관. 이 대시보드의 가장 단단한 데이터. → 집필 함의: 무료부 비트를 *클릭용(보편 자극·맥락 무관)*과 *결제용(권역 payoff·관계 누적)* 두 종으로 의식 설계. **검수 후보 #9 신설: CTR요소/ROAS요소 분리 점검.**
2. **T2(구원로맨스)·T4(초자연/AIGC) 누락분** — §4 룰 10개는 사실상 신분반전 복수 장르 룰. T2 = "단순 섹슈얼 후킹 X·서사+payoff 결합"·관계/거래 직설 대사 축("얼마면 돼?"). T4 = 4-step(금기→심판→보호→각성)·"CG 단독 노출 금지·세계관 풀 구조"·초자연 액션을 AI 실사화 볼거리로 = AIGC 직결. **US 데이터 "남주 보호보다 여주 원탑이 고성과"** = 우리 주인공 주체성 룰을 외부 데이터가 지지하는 드문 사례.
3. **의존-역전 KEY HOOK** — T1·T3 공통 공식 = "가해자들이 가장 *필요로 하던/갈망하던* 권력의 중심 인물". 반전의 핵심은 정체 비밀이 아니라 **가해자가 의존하는 대상이라는 종속관계** — 빌런의 욕망 대상 = 여주의 숨은 권력으로 설계하라는 룰 후보 ⑪감.
4. **TXT 한 줄 요약성** — "TXT 카피 붙은 신분 반전 소재 효율↑" → 무료부 핵심 비트는 자막 한 줄로 요약 가능해야 (비트가 한 문장으로 안 잡히면 광고 원료 부적합).
5. **경비원 비트 직접 지지** — T3 ES INTRO "경비원이 여주를 끌어내리려는 순간" = 우리 엔진의 "경비·카메라로 뒤집기"와 대시보드의 드문 직접 접점.
