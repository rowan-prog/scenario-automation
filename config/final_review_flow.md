## ⚖️ 절대 규칙 — 검수 언어 (2026-06-05 사용자 명시)

**"싸구려"는 '틀렸을 때'다. 천박함은 싸구려가 아니다.**
- 싸구려 = 공간 논리 오류·연속성 오류·정합성 붕괴·기초 논리 오류·캐릭터 지식 위반. 이건 잡는다.
- 천박함(막장 직설·저속한 빌런·과잉 감정·뻔뻔함) = paid vertical의 **자산**. 필수는 아니지만 **절대 싸구려가 아니다.**
- 검수 의견이 천박함을 "싸구려/저렴/품위" 류 언어로 깎으면 = **즉시 기각.** 교체 제안은 항상 더 천박/직설 쪽으로만.

## 검수 강도 — 🚨 기본값 = diff 경량 (2026-06-08 사용자 명시·과검토 교정)

**기본값 = diff 위주 경량 검토.** 일상 incremental 수정(턴 단위 패치·"어떻지?"·"검토" 류 점검)은 **바뀐 diff + 그 파급(연결된 setup/payoff·thread) + 기계 게이트(voice_lint·char·HC·END·Korean·MICRO_ACTING)** 만 본다. 전 회차 재독·다중 cold-read·풀 병렬 검수단은 **돌리지 않는다.** 멀티에이전트 검수단을 매 점검마다 돌리는 것 = 과검토(토큰·시간 낭비·사용자 명시 금지).

**무거운 병렬 검수단(sub-agent + showrunner·아래 10+3 패스 전부) = 최종 LOCK 직전, 또는 "철저 검토/매출 고점/광고소재력/외부 대본" 명시, 또는 새 정본의 *첫* 풀 검수일 때만.** 그 외 = 기본 경량.

### 모드 선택 (요청 받으면 메인이 스스로 판단)

**① diff 경량 패스 (기본)** — incremental 패치 후 재검증 · 한 줄/씬/회차 문제 · 기계 카운트/정합성 확인 · 특정 대사/paywall/reveal 질문 · "어떻지/검토" 일상 점검 · 최근 full 검토 통과 후 변경이 작을 때:
- 바뀐 구간과 그 파급만 원문 대조 + 기계 게이트. 필요하면 fresh-eyes **1개를 *바뀐 구간 한정*** 으로만 (전수 X). cold-read/native-ear는 LOCK 때로 미룬다.

**② Sub-agent 병렬 + showrunner (무거움) — LOCK 직전·"철저 검토" 명시·새 정본 첫 풀 검수일 때만:**
- 최종고/production lock · 외부 완성 대본 · 전 화수 첫 검토 · 큰 리라이트 후 *첫* LOCK 게이트 · 타깃/장르/트롭 판단 애매 · 피드백 충돌 대량 판정 · paywall/첫 유료 보상/reveal/intimacy/공개 굴욕/최종 payoff가 핵심 · 이전 검토 누락 반복.

## 검수 패스 순서 (10 + 보강 3)

### 0. 기본 캘리브레이션 (여기서 틀리면 뒤 전부 틀어진다)
타깃·장르·트롭·플랫폼·무료/유료 구조·제목 약속·수위 약속·핵심 쾌감 엔진을 먼저 잡는다.
**+보강: 시그니처/엔진 앵커 보존 목록 + 엔진 고정 비용(의도된 저점) 목록을 이 단계에서 작성해 모든 sub-agent 프롬프트에 복붙** — 가드레일 없이 보내면 의도된 설계를 결함으로 보고한다 (SHE STOLE EP9-12 = 6점 고정 비용 전례).
**+이 단계에서 set-piece의 정의도 확정** (패스 9 장르 캘리브레이션) — 장르에 따라 "보스전"이 아니라 결혼식·공개 폭로·intimacy payoff가 set-piece다. 수위 기대치도 여기서: 장르에 따라 극단적 성적 직설성/천박함이 *강해야만* 하는 작품군 존재 — 그 수위를 깎는 방향의 검수 = 결함.

### 1. 소스 패킷 확인
내부 = 최종 대본·청사진·비주얼락·핸드오프·상태문서. 외부 = 대본 + 사용자 제공 메타 중심 — **청사진/비주얼락 없다고 실패 처리하지 않는다.**
+보강: 내부 작품은 정본 버전·meta 일치 확인 (파일 시스템 우선). 검수 진입 전 **버전 앵커** — 수술이 예상되면 새 v{N} 분기 먼저.

### 2. 기계/정합성/논리 패스
EP 수·[END HOOK]·Hard Cut.·씬 순서·시간·공간·출입·소품·부상·권한·정보 공개 순서·reveal 논리·인물 지식·행동 동선·연속성.
+보강 수치 게이트: 한국어 0 · Hard Cut = EP-1 · END 1 · 깨진 패턴 grep(빈 블록·이중 separator·고아 태그) 0 · char count 스펙 내 · voice_lint baseline.
**+🚨 LOCK 전수 동작 정합성 (2026-06-08 사용자 명시·필수): 지문/동작이 *앞 동작과 모순*되는 경우가 허다하다.** "읽다가 눈에 띈 것만" 금지. 씬 순서대로 **모든 [VISUAL/ACTION]·[KEY CAMERA] 비트를 하나씩 추적하며 직전 상태와 대조**한다 — 위치(누가 어디)·자세·소품 위치/소유·부상·인물 지식·시선·연속 태그(Continuous인데 두 장소 동시?). 예: v46까지 잔존한 EP07 "머리채 잡기 삭제했는데 'releases the hair' 잔존"·EP02 S#3 "Continuous"인데 Mara가 차 안+생중계 동시. 동작 A → 동작 B로 넘어갈 때마다 "B가 A와 모순 아닌가" 1줄 점검. 집필 시에도 동일(직전 동작 확인 후 다음 동작).

### 3. 초반 락인 패스
EP01 첫컷~15초 별도 검토. EP01-03 전수(첫씬~마지막씬). 시청자가 붙는지·설정놀이가 앞서는지·주인공 상처/욕망/힘/관계 약속이 보이는지.
+보강: cold-read는 **독립 다회 수렴 의무** — 1회 점수는 노이즈 (최소 3회·funnel-cold-reader).

### 4. 상업 리스크 가중치 패스 (검토 가중치 순서)
**EP01 → 마지막 무료회차 → EP02-03 → 마지막 무료회차+5 → EP04-07 → EP09-12 → EP14 → 나머지.**
결함 위치에 따라 매출 리스크를 다르게 본다.

### 5. Commerciality / 광고소재 패스
무료 유지·paywall·첫 유료 보상·EP13 재후킹·EP14 만족감·**4~10분 assembled story packet 후보** (비연속 컷 재조합 — 실제 대본 장면에서 뽑혀야 함). CTR형(보편 자극)/ROAS형(payoff 구조) 분리 — `feedback_na_vertical_ad_creative_principles.md` 2026-06-05 환류 7항.

### 6. Genre Pleasure 패스
장르가 팔아야 하는 쾌감이 실제로 터지는가. 여성향 = 상처·욕망·선택받음·지위상승·관계 보상·intimacy / 남성향 = 압도·권한·복수·획득·적 굴복·세계 확장. 장르별로 다르게.
**+모욕·폭행 기준 (2026-06-05 사용자 명시):** 모욕 씬 = 토큰("아무튼 모욕씬") 금지 — 시청자 몰입 분노 수준·비트 4+·길이 확보. **폭행 성별 룰: 남→여 = 강한 언어폭력+애매모호 저강도 물리까지만·고수위 물리 폭행 = 여→여만** (`memory/feedback_humiliation_violence_standard.md`).

### 7. Spoken English / 보이스 패스
문법이 아니라 **실제 배우가 말할 수 있는 영어**인가. 캐릭터별 말투(name-cover test)·반복 단답·연극톤·번역투·기능성 대사·갑작스러운 보이스 붕괴. 톤 큐 = 오독 쉬운 층위 중심 (비아냥·음흉함·통제된 욕망·상처 숨긴 말투·장난+위협·섹시/요염 — 기본 감정은 오독 어렵).
**+🚨🚨 LOCK 전수 per-line 방식 (2026-06-08 사용자 명시·필수·샘플링 절대 금지): vertical spoken-english(시적 대사 금지·연극적 금지·소설적 금지) 여부는 *단 한 개의 대사도 놓치지 않고* 검사한다.** 방법 = **enumerate-then-verdict**: 모든 [DIALOGUE] 라인 + 모든 VO를 *전부 열거*한 뒤(grep `^[A-Z][A-Za-z ]*(\(.*\))?:` + `(V.O.)`로 완전 목록 추출 → 빠진 줄 0 보장), 한 줄 한 줄 **PASS / FLAG** 판정한다. "읽다가 눈에 띈 것만 flag" = 금지(라인 누락의 원인). FLAG 기준: 시적/은유·연극톤·소설 서술체·낭송 cadence(tri-colon/anaphora)·번역투·톤 의존 의미·미세 표정 의존 지문. 시그니처/엔진 모티프는 보존 표기. 1차 기계 = `voice_lint.py --full`(전 카테고리, 단 패턴 미탐지분은 per-line 인간 패스가 메움).
**+🎙️ AI 더빙 톤-독립 검사 (2026-06-08·`feedback_ai_dub_tone_independent_dialogue.md`):** 모든 대사 = flat(무표정 TTS)하게 읽어도 한 가지 의미로 수렴하는가. 의미가 *톤*에서만 나오는 대사(반어·이중의미·의미심장·애매·withheld subtext) = 결함 → 톤-독립 단일 의미로 수술 또는 진의를 V.O./다음 대사/행동으로 외화. **cue로 톤 의존 문장을 구제한 패턴도 결함**(문장 자체를 고칠 것). 짧음≠한의미(길어도 직설이면 OK·짧아도 암시면 fail). 1차 기계 = `voice_lint.py`.

### 8. AIGC / 제작성 패스
핵심 장면이 세로 화면·AIGC 제작에서 읽히는가. **작은 소품·미세 표정·복잡한 텍스트·애매한 동선에 핵심 정보가 걸려 있으면 결함.** 회귀 단역 = 동일 배우 연속성 표기 확인.
**+🎭 미세 표정연기 의존 지문 검사 (2026-06-08):** AI 영상은 베테랑급 미세 표정을 못 낸다. "묘한 표정/복잡한 얼굴/의미심장한 미소/unreadable/faint smile"에 *핵심 의미*가 걸린 지문 = 결함 → 무성 facial insert + V.O.로 외화하고 특정 샷(ECU·crash zoom·insert)으로 귀결. 큰·명료한 표정(경악·분노·오열·조소)은 OK. 기계 1차 = `voice_lint.py` MICRO_ACTING.

### 9. Set-Piece 패스 (🚨 장르 캘리브레이션 — 기계 적용 금지·2026-06-05 사용자 명시)

**"전투씬/보스전 검토"라는 표현이 요청문에 있어도 모든 장르에 기계적으로 적용하지 마라.** 패스 0에서 판정한 타깃·장르·트롭·제목 약속·쾌감 엔진이 set-piece의 *정의 자체*를 결정한다.

- **액션·전투·던전·남성향 progression·전쟁·생존·무협·보스전 구조를 실제로 파는 작품** → 전투씬/보스전/액션 set-piece 검토 (combat-read 데코보코·god-reveal 머니샷 등 — `feedback_vfx_male_power_fantasy_engine.md`).
- **로맨스·로코·멜로·여성향 status revenge·재벌·아이돌·가족극·high-heat romance** → 전투/보스전 결말을 억지로 요구하지 마라. set-piece = **그 장르의 핵심 판매 장면**: 공개 모욕·신분 반전·관계 claim·고백·이별·키스/섹스/intimacy payoff·라이벌 몰락·가족 대립·결혼식·기자회견·연회·공개 폭로·HEA 보상.
- 공통 검사 축은 동일: **공간·판돈·승패 변화·타깃 보상·다음 회차 동력** + 9:16 키 컷 성립.
- **보고 언어도 장르 기준 강제:** "보스전이 약하다" ❌ → "최종 관계 payoff가 약하다"·"공개 반전 장면의 권위 proof가 약하다"·"intimacy payoff가 부족하다"·"라이벌 붕괴가 덜 터진다" ⭕. 장르 비매칭 결말을 요구하는 검수 의견 = 쇼러너 기각 기본값.

## Showrunner merge (마지막 판단 — 무조건)

1. 각 sub-agent 의견을 **그대로 반영하지 않는다.** 원문 1:1 대조 후 진성 선별.
2. 충돌 정리 → **수용 / 부분수용 / 기각 / 보류** 4분류 — 기각엔 근거 명시.
3. **작품 엔진을 해치는 의견은 걸러낸다** — 논리 닫기형·세련화형·증거 기계 강화형·"싸구려" 운운형(절대 규칙)·**장르 비매칭 set-piece 요구형(로맨스에 보스전 결말 등)** = 기각 기본값.
4. 집행 순서 = 렌즈 순서 그대로: 엔진 충돌 지적 먼저·line 지적 마지막.
5. 집행 후 기계 게이트 재검증 (패스 2 수치) + meta/CLAUDE.md 갱신.
