# Subagent B — 한국 vertical drama 검증 성공작 4편 공통 패턴 분석

## 분석 대상

1. **대표님의 벙어리 아내** (100화) — 양녀·벙어리·통제남·이중 빌런(남편+내연녀)
2. **달래기 쉬운 그녀** (101화) — 양녀·신데렐라·가족 박살·보호자 알파
3. **지독한 사랑** (80화) — 6년 전 첫사랑·비밀 아이·후회남·룸살롱 굴욕
4. **사랑은 다시 당신에게로** (87화) — 절름발이·대나무 숲 합궁·외삼촌 학대·시댁 보호

## 🔥 1차 페이월 회차 위치 비교 (절대 핵심)

| 작품 | 1차 페이월 위치 | 페이월 사건 | 패턴 |
|---|---|---|---|
| 벙어리 아내 | **11-12화** | 클럽 무릎 꿇기 → 민재 폭발 + 안고 나옴 + 본가 침실 통제 | 강력 사이다 + 다시 통제 (미해결) |
| 달래기 쉬운 그녀 | **7-8화** | 가죽 벨트 폭행 → 민섭 도착 + "내 사람" 선언 + 가족 응징 | 강력 사이다 + 약혼식 미해결 |
| 지독한 사랑 | **8-9화** | 룸살롱 양주 + 돈 뿌리기 + 6년 전 교통사고 진실 폭로 | 큰 굴욕 + 큰 진실 동시 작용 |
| 사랑은 다시 당신에게로 | **11-12화** | 정신 모자란 셋째 결혼 강요 → 태환 발차기 + "내 사모님" 선언 | 강력 사이다 + 비밀 아이 임박 |

### 🚨 핵심 발견: "EP1-8 무료" 가정은 한국 vertical에 부분적으로만 맞음

- **한국 vertical 표준 = 1-12화 무료 + 13화부터 점진 페이월 모델**
- 단 위 4작품 모두 **8-12화 부근에 강력 1차 페이월 후킹 사건 배치** (시청자가 "여기까지 봤으니 계속 봐야" 결제 동기 강화)
- 가장 빠른 1차 페이월 = **달래기 쉬운 그녀 7-8화** (남주 즉시 보호자 모델 — 가장 직접적 사이다)
- 가장 늦은 1차 페이월 = **벙어리 아내·사랑은 다시 11-12화** (큰 사이다 + 후속 위기 보장)

### 시스템 baseline 갱신 권장

> **무료 1-8화 고정 룰 (한국·미국 짧은 vertical 기준)은 한국 일반 vertical (80-100화)에는 약간 다른 적용** — 한국 vertical은 12화 무료 + 13화부터 점진 페이월이 표준일 수 있음. 단 OFFERING 같은 미국 타깃 50화 모델은 1-8화 무료 + 9화부터 페이월이 적합.

## 4 작품 공통 패턴 (paid vertical 한국 모델 절대)

### 1. 메인 빌런 = 구체적 개인 1명 + 보조 빌런 다수 (장르 불문)
모든 4작품에서 메인 빌런 1명 + 보조 빌런 5-7명이 같은 계통 환경 압박:
- 벙어리 아내: 정민재(통제남) + 하수연(내연녀) + 어머니·누나·가정부·경호원·내연녀 SNS
- 달래기 쉬운 그녀: 고수아(가짜 사촌) + 아빠·엄마·큰오빠·작은오빠·황 대표·진성그룹·유라
- 지독한 사랑: 서영태(친아빠) + 박성민·박민석·채린·유라·면접관
- 사랑은 다시: 조귀숙(외숙모) + 외삼촌·사촌·유성그룹 첫째·셋째·황 대표·여학생·유 팀장

→ **시스템 메모리 `feedback_concrete_villain_humiliation_loop.md` 완벽 검증**

### 2. 여주 1화 = 처절 바닥 + 저항 + 무시 패턴 (시네마틱 함정 6 0건)
4작품 모두 1화 여주:
- 신체적·사회적 결함 (벙어리·양녀·미혼모·절름발이)
- 매번 저항 (수어·언어·행동)
- 그 저항이 무시·체벌·모욕·억압 받음
- 매달림·울음 1-2회 (배제 X / 정직한 처지 표현)
- **완성형 X / 셈하는 여자 X / "이러지 마세요" 무력 X**

→ **시스템 메모리 `feedback_female_lead_rise_arc.md` 정확 매칭**

### 3. 1화 바닥 → 8-12화 거래 → 30-50화 진실 → 80-100화 회수 (상승 호 표준)
4작품 모두 4 페이즈 구조:
- EP1-12 = 바닥 + 첫 보상 (남주 도착 + 사이다 첫 정점)
- EP13-30 = 거래 + 새 위기 (시댁 보호 + 외부 위기)
- EP30-50 = 진실 + 트위스트 (큰 폭로·새 빌런·새 결제 동기)
- EP50-100 = 회수 + 정점 (가족 박살 + 결혼 + 출산)

→ 상승 호의 절대 거리 (1화 바닥 ↔ 정점)가 결제 동력

### 4. 5-8턴 모욕 교환 + 클립 보상 점진 확장 (반복 X / 다른 상황 O)
4작품 모두 매 사건 5-8턴 누적 패턴:
- 빌런 도발 → 여주 침묵·저항 → 보조 빌런 동조 → 더 강한 모욕 → 여주 한계 → 남주 도착 → 폭발 → 후처리
- 같은 쾌감(여주 가치 인정·빌런 박살) 다른 공개성·지위·범위로 점진 확장
- 매 EP 독립 작동 (상징 누적 X / 4화부터 들어와도 즉시 이해)

→ **시스템 메모리 `feedback_clip_reward_loop.md` + `feedback_pressure_axis_stacking_vs_dispersion.md` 정확 매칭**

### 5. 알파 보호자 / 통제 / 후회 = 한국 vertical 남주 표준
4작품 모두 남주:
- 다크 직진 짐승 X (서양 다크 로맨스와 다름)
- 한국식 알파 보호자 (즉시 보호·즉시 응징·통제 + 후반 사랑 회수)
- voice = 단답·통제·즉시 행동 ("내 사람 / 알아서 처리해 / 가자 / 응")
- 시적 cadence·연극톤 0건
- 끈 풀어버리는 짐승 X / 단 즉시 응징·통제는 멈춤 X

→ 한국 vertical = 다크 로맨스의 **한국형 변형** (보호자 + 통제·후회·회수)

### 6. VO + 플래시백 + 청각 브릿지 = 멀티태스킹 시청자 청각 최적
4작품 모두:

### 7. 시적 대사·연극톤·은유 0건 / 직관 행동·즉시 이해 100%

### 8. 한국형 가족 빌런 트로프 (서양 다크 로맨스와 차이)
4작품 모두 가족·양녀·외삼촌·시댁 구조가 핵심:
- 양녀·미혼모·절름발이 등 가족 차별의 원인
- 메인 빌런이 가족인 경우 많음 (서영태·조귀숙)

## 시스템 baseline 보강 권장 사항

### 1. 한국 vertical 1차 페이월 위치 룰 (신규)
> **한국 일반 vertical (80-100화 모델) = 1차 페이월 7-12화 위치 / 12화 무료 + 13화부터 점진 페이월 / 미국 타깃 50화 모델 = 1-8화 무료 + 9화부터 페이월**

### 2. 한국 vertical 남주 = 알파 보호자 + 통제·후회·회수 (한국형 다크 로맨스 변형)
> 다크 로맨스 짐승 직진 (`feedback_dark_romance_male_predator.md`)은 OFFERING 같은 서양 모델에 적합 / 한국 vertical 모델은 즉시 보호자 + 통제·후회·회수 모델 표준 / 둘 다 시적·은유 0건 절대

### 3. 보조 인물 = 청각 브릿지 적극 활용 (멀티태스킹 청각 최적)
> 할머니·시어머니·비서·아이·친구 등 보조 인물이 청각 브릿지 역할 — 시청자가 화면 못 봐도 즉시 이해 + 정서 보강 + 분노 트리거 / 매 작품 2-3명 권장

### 4. 가족 빌런 + 외부 빌런 + 시댁 보호자 = 한국 vertical 정통 3축
> 한국 vertical 청취자 가장 좋아하는 3축 — 가족(나쁨) → 남주(보호) → 시댁(인정) 클립 보상 무한 재포장

### 5. 비밀 아이·기억 상실·계약결혼 = 한국 vertical 클래식 트로프
> 검증 4작품 중 3작품이 이 트로프 활용 — 한국 시장 검증 / 신규 한국 타깃 작품에 적극 차용

## 시청자 결제 동력 정수

> **한국 vertical 시청자가 결제하는 가장 큰 이유 = "여주가 양녀·미혼모·결함 있는 처지에서 시댁·재벌 보호자에 의해 정식 안주인 위치를 공개적으로 받고, 모욕한 가족이 공개 박살나는 모습을 보고 싶다."**

3 요소:
1. **여주 정식 안주인 공개 인정** (시댁이 직접 발화·외부 모두 인정)
2. **가족 공개 박살** (직접 폭력·재산 잃기·체포·사망 4단계)
3. **남주 후회·집착·통제·보호** (다크 직진 짐승 X / 한국형 알파 보호자)

이 3 요소가 매 EP 클립 보상 루프로 무한 재포장되며 80-101화까지 끌어가는 = 한국 vertical 정수
