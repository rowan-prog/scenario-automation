## 1축 — 캐릭터 분석

### 듀얼 여주 패턴 — 예슬 (피해자) + 나은 (구원자) — 한국 vertical 특수 구조

**예슬 (1화 어린 시절 바닥):**
- 보육원에서 동생 나은에게 입양 기회 양보 → 자신은 폭력적 계부 + 계모 가정으로
- 흉터·굶주림·매질 받으며 성장
- 결혼 후 시댁(시어머니·시누이)의 핍박 + 남편 태환의 외도
- 딸 지아 출산 → 시댁은 "딸 = 대 끊어진다" 멸시
- 유산 + 남편 외도 발각 + 계단 추락
- **1화부터 9화까지 = 끝없는 바닥 + 저항 시도 + 무시·멸시**

**나은 (1화 → 점프 → 현재 = 정상에서 시작):**
- 어린 예슬과 보육원에서 헤어짐 (이름 바뀜 사고로)
- 회장 양딸 = 오성그룹 상속자로 성장
- 1년 후 보육원 철거 → 동생 행방 모름
- 현재: 회장 사망 → 친척들이 회사 노림 → 1손 사인 + 경호원 등장 = 즉시 권력 행사
- **1화에서 어린 모습 → 2화 점프 + 어른 = 카리스마 100% 완성형**

**듀얼 여주 갭 메커니즘:**
- 예슬 = 끝없는 바닥
- 나은 = 끝없는 정상
- 두 자매가 만나는 순간 = 권력의 비대칭 해소 + 시청자 대리 보상
- **1화부터 9화까지 = 만남 약속 + 만남 지연 → EP10 본격 만남**

### 남주 (자매극 = 남주 비중 낮음 / 강태환은 빌런)

**남편 강태환 = 메인 빌런 1명:**
- 시댁 결혼 7년 + 외도 + 폭력 + 회사 30% 지분 노리는 결혼
- "그 여자 가슴은 처지고, 요실금까지 있어. 여자 구실도 거의 못 한다고" (외도녀 앞 본처 멸시)
- "넌 또 왜 아들을 못 낳는 거야?" + 목 조름
- EP9: 녹음펜 빼앗으려다 예슬 계단 추락 → 사고로 위장하려 함

**시댁 보조 빌런 다수:**
- 시어머니 김혜경 ("우리 집안 대를 끊어 놓지 마! / 딸이 무슨 소용이야!")
- 시누이 강유리 (빨래 강요 + 비꼬기)
- 외도녀 오수진 (회사 30% 지분 + 결혼 약속)

**환경 압박:** 시댁 전체 + 회사 + 사회 = "딸 낳은 며느리는 가치 없음" 통념 = 한국 여성 시청자 즉시 분노 트리거.

**메인 빌런 가치 모름 검증:**
- 태환·시댁 모두 예슬의 진짜 자매(나은 = 재벌 상속자)를 모름
- 끝까지 멸시 → 나은 등장 시 충격
- `feedback_concrete_villain_humiliation_loop.md` 정합

## 2축 — 이야기 구조 분석

### 압력축 1개

**핵심 압력축:** **"평생 바닥 추락한 자매(예슬)를 친자매(나은 = 재벌)가 언제 찾아내고 시댁·남편을 박살하나"**.

**복합 압력이지만 같은 축:**
- 시댁 핍박 (예슬 라인)
- 외도 + 회사 지분 음모 (예슬 라인)
- 나은의 동생 찾기 (나은 라인)
- 두 라인이 EP9-10에서 합류

### 페이월 위치 (EP9 끝 / EP10 도입) — 핵심 분석

**EP9 페이월 정확한 위치:**
- EP9 마지막: 예슬 계단 추락 + 시댁 모두 자리 뜸 + **나은이 위에서 모든 걸 봄 + 천천히 계단 내려와 쓰러진 예슬 앞에 멈춤 + "충격과 차가운 분노"**
- EP10 도입: 나은이 본격 등장 + 예슬 구함 시작

**페이월 왜 EP9-10 위치인가:**
1. **모욕·핍박 누적 8화 분량** — 시댁 멸시 + 외도 + 유산 + 폭력 + 추락 = 시청자 분노 정점
2. **자매 재회 직전 = "두 라인이 만나는 순간 = 결제 보상"** — 8화까지 평행으로 진행 → 9화 끝 1m 거리에서 만남 직전
3. **나은의 "차가운 분노"가 폭발 직전 = `feedback_pressure_axis_stacking_vs_dispersion.md` "paywall = 행동 직전" 정합** — 박살 직전 cliffhanger

### 클립 보상 루프

**원초 쾌감 1개:** "평생 바닥의 예슬을 친자매 나은이 모든 영역에서 차례로 구원하고·가해자들이 차례로 굴복".

**점진 확장:**
- EP10+: 시댁 멸시 → 나은 진입 → 시댁 굴복
- 회사 30% 지분 → 나은의 오성그룹 압도
- 외도녀 오수진 → 굴욕
- 같은 쾌감 다른 상황·다른 가해자

### 보상 단계 (3층 구조)

- **1층 (EP1-3 즉시):** 어린 예슬-나은 자매 정 + 헤어짐 = "언젠가 만난다" 약속 / 어른 나은의 카리스마 1손짓 권력 즉시 시연
- **2층 (EP3-9 누적):** 시댁·외도·유산 = 분노 게이지 누적 / 나은의 동생 찾기 평행 진행
- **3층 (EP10+ 유료):** 자매 재회 + 가해자 차례 박살

### 클리프행어 설계 핵심

- 1-2화: 보육원 헤어짐 + 시간 점프 + 점프 후 카리스마 등장 (이중 갈고리)
- 3-6화: 시댁 핍박 + 부녀 등장 가능성 시사
- 7화: 병원에서 나은이 지아 만남 (자매 거리 = 1m)
- 8화: 나은이 예슬의 외도 정보 듣고 차가워짐
- **9화: 계단 추락 + 나은 직접 목격 = 만남 직전 정지**

## 3축 — 대사 스타일 분석

### 시적·연극톤 0건 검증

**대사 패턴:** 모두 직접·기능·사건. 한국 vertical 시장의 표준 톤.
- "쟤가 나 때린 거 봤지? 빨리 똑같이 갚아줘!" (선동·즉시 이해)
- "그 여자 가슴은 처지고, 요실금까지 있어" (멸시 + 즉시 분노 트리거)
- "내가 선동한 건 아니야. 근데, 난 꽤 마음에 들던데" (회사 작품 - 정밀 통제)

### 멀티태스킹 시청자 친화

**브릿지 청각 정보 풍부:**
- 시어머니 혜경의 호통 = 화면 못 봐도 사건 흐름 즉시 파악 ("어디서 저런 재수 없는 걸 우리 집에 들여와가지고")
- 외도녀 오수진의 비웃음 = 외도 상황 즉시 인지 ("말해 봐요. 날 사랑해요? 아니면 아내를 사랑해요?")
- 시댁 가해자들이 음모 모의 = 시청자만 들음 ("저 여자가 죽으면 지분은 우리 아들 거야")

**텐션 구간 단답:**
- "지아는 내가 데려갈 거야. 여기서 끝내자" (예슬 결단 — 짧고 직접)
- "이거 놔!" (계단)
- 나은의 1손 사인 (말 없이 경호원 진입)

### 캐릭터별 voice 차별

- **예슬:** 무력 + 점진 분노 ("당신이 한 약속 기억나?")
- **나은:** 차갑고 정밀 통제 ("회장님이 생전에 정이 많으셔서 제가 늘 그분을 생각하며 움직였죠. 하지만 이제는 달라요. 그럴 필요가 없거든요. 회장님을 따라가게 만들 수도 있습니다.") = Pattern A 사실 나열 + 위협
- **태환:** 위선·외도·폭력 ("내가 얼마나 스트레스 받는지 알아? 넌 또 왜 아들을 못 낳는 거야?")
- **시어머니 혜경:** 직설 멸시 + 음모 ("저 여자가 죽으면 지분은 우리 아들 거야")
- **시누이 유리:** 비꼬기 + 비웃음
- **외도녀 수진:** 비웃음 + 자기 우월 ("어머? 저 아줌마가 여긴 어쩐 일이야")

### 4 요소 정합 (욕망·상황·선택·다음)

나은 "회장님을 따라가게 만들 수도 있습니다" =
- 욕망: 친척들 굴복
- 상황: 회사 인수전 직전 + 회장 사망 직후
- 선택: 위협
- 다음: 경호원 진입

## 종합 평가

### 강점

1. **듀얼 여주 평행 구조 = 한국 vertical 시장 특수 트로프** — 바닥 + 정상 평행 진행 → 만남 직전 결제
2. **메인 빌런 (남편) + 보조 빌런 다수 (시댁·외도녀) = 환경 압박** 정합
3. **시청자 정보 비대칭** — 나은이 친자매라는 사실을 가해자들 끝까지 모름
4. **여성 시청자 즉시 분노 트리거** — 시댁 핍박·아들 강요·외도 = 한국 30-50대 여성 핵심 결제 동기
5. **시적·연극톤 0건** = 정합

### 약점·OFFERING 적용 시 주의

1. **듀얼 여주 = 북미 paid vertical에서 일반적 X** — OFFERING은 단일 여주 (이졸데)
2. **30-50대 여성 타깃 = OFFERING (30-40대 다크 로맨타지)과 다름**
3. **딸 출산·아들 강요 = 한국 카테고리** — 북미는 다른 핍박 동기

### OFFERING / 06 SHE STOLE MY FACE 적용 가능 인사이트
