- **EP5**: 윤 여사가 의류 매장 데려감 → **점장의 모욕 (소독 스프레이) 누적** → "가난뱅이는 가난뱅이를 낳지" → 윤서아 임신한 상태로 폭언 → 윤 여사 분노 → "건방진 놈! 내 며느리한테 무슨 일이라도 생기면, 넌 죽을 줄 알아!"
- **EP6 페이월 후크**: **윤상현(시동생) 등장 + "나는 그렇게 생각 안 하는데"** → 최 실장이 점장 뺨 때림 → 점장 무릎 꿇음 → 윤상현: **"저놈 다리 부러뜨려서 내쫓아!"** = 첫 시동생 정체 공개 + 권력 폭발
- **EP7 핵심 후크 추가**: 윤서아가 하얀 드레스로 갈아입고 등장 → 윤상현 "눈부시게 변한 그녀의 모습에 순간 넋을 잃고 바라본다" → **금기 끌림 첫 트리거** → 윤 여사가 윤상현 번호 저장해줌 = 시동생-형수 거리 좁힘

→ **EP6-7 = 시동생 정체 공개 + 금기 끌림 시작 paywall** — 시청자가 "냉혈한 시동생이 임신한 형수에게 어떻게 빠지나?" 결제

## 1축 — 캐릭터 분석

### 여주 — 윤서아 (임신한 형수, 백화점 신발 매장 직원)

**상승 호 (`female_lead_rise_arc.md` 정합):**
- **1화 바닥**: 남편(윤태환) 교통사고 사망 → 임신 사실 + 의붓가족 학대 누적 → 양어머니 무릎 꿇음·의붓오빠 뺨 폭행
- **1-4화 = 처절·이입 트리거**:
  - 의붓오빠가 뺨 때림
  - 의붓 가족이 "낙태해" 강요
  - 가짜 뇌졸중 거짓말로 납치 시도
  - 다른 남자에게 3억에 팔려고 함
- **단 — 사용자 정정 룰 정합**: 매달림 X / **반항 + 무시** ("미쳤어? 나 임신했어!" / "내 아이는 윤성 그룹의 손주야")
- **5화 = 거래로 발화**: 윤 여사와 함께 의류 매장 → 시동생 정체 첫 공개
- **8-9화**: 의붓 가족이 다시 납치 시도 → 윤상현이 다리 부러뜨림 명령
- **20화+**: 점진 시동생과 거리 가까워짐 (매실차 + 비밀 카드)
- **50화+**: 정상 (윤성 그룹 안주인·시동생과 정식 관계)

### 남주 — 윤상현 (냉혈인간 도련님)

**다크 로맨스 정합 + 금기 트로프 (`dark_romance_male_predator.md` 부분 정합):**
- **냉혈한 = 일반 다크 로맨스 패턴 (절제 X 측면)**
- 단 — 한국형 절제 일부 유지 (직접 키스 → 후반)
- **금기 (시동생-형수) = 다크 로맨스 핵심 매력**
- 매력 = **외부 압도 (윤성 그룹 차남·압도적 자산·권력)** + **내부 집착 (매실차 직접 끓임·매일 선물·다리 부러뜨림 명령)**

**핵심 패턴:**
- 처음 = 금전 목적 의심 → 빠른 의심 풀림 (조사 결과 = 의붓가족 학대 + 헌신적 사랑)
- 점진 = "왜 자꾸 백화점 가나" / "박 여사가 끓였어요" (자기 마음 인정 X)
- 집착 표지 = 직접 매실차 끓이기·신용카드 비밀번호 없이 주기·매일 선물

**`dark_romance_male_predator.md` 멈춤 X 패턴:**
- 사적 = 점진 직진 (매실차·카드·소유욕)
- 공적 = 멈춤 0건 (점장 다리 부러뜨림·의붓오빠 다리 부러뜨림)
- **표현 방식만 다름 / 본질 = 멈추지 않는 포식자**

### 빌런 — 다층 구조 (메인 1명 + 다수 보조 = 다크 로맨스 변종)

**메인 빌런 = 오정민 (의붓오빠)**
- 다리 거짓말로 20년 윤서아 착취
- 임신한 윤서아 뺨 폭행·납치
- **끝까지 가치 모름** → 후반 다리 부러뜨림 응징

**보조 빌런 다수:**
- 오미숙 (양어머니) — 무릎 꿇으며 압박 / 가짜 뇌졸중 거짓말
- 오정민의 아내 — 가짜 임신 / "낙태해" 강요
- 의류 매장 점장 — 외모 차별 모욕 (EP5)
- 피오나 한 (가수) — 여성 라이벌·윤상현 좋아함
- 백화점 강 부장·신발 매니저 — 임신 차별 (EP18-19)

→ **다수 보조 빌런 = 같은 계통 환경 압박** (`concrete_villain_humiliation_loop.md` 절대 정합)

**남주 = 빌런 역할 겸직 X** (전형적 다크 로맨스와 다름)
- 처음엔 의심·냉혹 / 단 폭력 X
- 외부 빌런이 진짜 위험 / 남주 = 보호자
- → **다크 로맨스 변종 (금기 트로프·외부 빌런 진짜)**

## 2축 — 이야기 구조

### 압력축 1개

> **핵심 질문 = "냉혈한 시동생이 임신한 형수에게 언제 사랑 인정하나? + 의붓 가족이 언제 박살나나?"**

**기본 구조:**
- 다크 로맨스 + 금기 (시동생-형수) + 임신 트로프
- 압력축 = 거리 → 점진 좁힘 → 사랑 인정
- 52화 = 다크 로맨스 정상 분량

### 모욕 루프 패턴

**EP1 — 의붓 가족 누적 모욕:**
1. 의붓오빠: "고작 계약직 하나 죽었다고 누가 관심이나 가져?"
2. "어쩌다 그런 놈 자식을 가졌어?"
3. "네년 때문에 내 다리가 불구가 됐어. 평생 우리 가족을 먹여 살려야지"
4. 의붓오빠의 아내: "나는 오씨 가문의 9대 독자를 임신했다고요. 정 돈을 못 주시겠다면, 나 이 애 지울 거예요"
5. 양어머니가 무릎 꿇음 (감정적 압박)
6. 의붓오빠 뺨 폭행 → "네 뱃속 그 애부터 당장 죽여줄게"
7. → **윤 여사 등장 = 페이월 보상 (EP2)**

**EP5 — 의류 매장 점장 모욕:**
1. "혹시 전에 아래층에서 신발 팔던 사람 아니에요?"
2. "가난뱅이 냄새가 여기까지 풀풀 나네"
3. 소독 스프레이 뿌림
4. "가난뱅이는 가난뱅이를 낳지"
5. "어차피 네 애도 평생 밑바닥에서 개처럼 일할 운명이야!"
6. 임신한 윤서아 얼굴과 몸에 스프레이 뿌림
7. 윤 여사 분노 → 점장 비웃음 → **윤상현 등장 = 페이월** (EP6)

→ **5-8턴 모욕 누적 + 페이월 폭발** (`concrete_villain_humiliation_loop.md` 절대 정합)

## 3축 — 대사 스타일

### 직관·기능 100%

**채택 패턴:**
- 윤 여사: "감히 내 며느리를 괴롭혀? 저놈의 손을 부러뜨려!" → 한 줄에 모욕·권력·결과 (Pattern A)
- 윤상현: "나는 그렇게 생각 안 하는데." → 첫 등장 한 줄로 권력 우위
- 윤상현: "저놈 다리 부러뜨려서 내쫓아! 다신 여기 얼씬도 못 하게 해." → Pattern A 사실 나열 (결과·이미지·다음 보임)
- 점장: "엿이나 먹어, 이 할망구야! 살날이 얼마나 남았다고? 내가 당신보다 훨씬 오래 살아!" → 모욕 정점·도발 (페이월 직전 분노 정점)
- 윤상현: "매실차예요." (퉁명) / "박 여사님이 끓였어요." (시선 피함) → 부정적 voice → 시청자가 "거짓말이지?" 즉시 추론 가능

### 시적·은유·연극톤 0건

- 모든 대사 = 사실·욕망·결과 직접
- 한국 다크 로맨스 정공법

### 다크 로맨스 대사 특수 — 부정형 voice

- 윤상현 = 자기 감정 인정 X / 부정으로 표현
- "박 여사님이 끓였어요" / "고마워할 것 없어요. 어머니가 시키신 거니까"
- → **부정형 voice = 다크 로맨스 매력 = 시청자가 즉시 진심 추론**

### 임신 + 금기 트로프 정합 대사

- 윤상현: "매실차예요" → 입덧 케어 + 부정형 정합 + 집착 표지
