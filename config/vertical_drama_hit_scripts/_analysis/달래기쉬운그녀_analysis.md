## 2. 1축 캐릭터 분석

### 주인공 (고유경)
- **1화 바닥 (이입 트리거):** 양녀 / 시골 할머니 손에 자람 / 본가 호적 복귀 후 가족이 음모로 정략결혼 추진 + 약 탄 우유 + 황 대표 호텔 함정 → 잘못된 방 들어가 민섭과 하룻밤 → 가족이 키스마크 폭로하며 가족 식탁에서 공개 모욕
- **저항 + 무시 패턴:** "전 그 결혼 안 해요" "엄마, 저 매일 아침 4시에 일어나" — 매번 저항하지만 가족이 무시·억압·체벌·내쫓음 → 시청자 이입 폭발
- **8-13화 거래:** 민섭 할머니 보호 → 결혼 계약서 → "돈은 안 받아요 / 학교만 다니게 해주세요" → 약혼식 → 다시 가족 난입 → 수아 결혼 양보 시도
- **30-50화 상승:** 진성그룹 면접 → 자기 능력 입증 → 가족 복수 → 선배 강간 시도 → 트위스트
- **80-101화 정점:** 가족 비참한 최후 + 부와 사랑 + 출산
- **paid vertical 정합:** 완벽한 상승 호 (1화 바닥 → 7화 첫 보상 → 50화 정점 → 101화 회수)

### 메인 빌런 — 가족 다층 구조 (정확한 1+다수 패턴)
- **메인 빌런 = 고수아 (양녀이자 가짜 가족·사촌):**
  - 끝까지 가치 모름 — 유경 = 결혼 양보 도구·예물 약탈 도구·할머니 유골 협박 도구
  - 끝까지 오만 — "언니가 시집가는 게 어울리지 / 내가 가야 해"
  - 마지막 100화 = 약품으로 유경 납치·총상으로 박살 (메인 빌런 박살 정점 패턴 교과서)
- **보조 빌런 다수 (같은 계통 환경 압박):**
  - 큰오빠 고윤환 — 음모 설계·결혼 협박
  - 작은오빠 고윤성 — 욕설·할머니 사진 찢기·강간 음모
  - 아빠 고태철 — 부양비 협박·체벌
  - 엄마 허혜란 — 머리채 잡기·식탁 차별·예물 약탈
  - 황 대표 (외부 보조) — 호텔 함정·매춘 알선
  - 진성그룹 면접관·유라 (학교) — 외부 모욕 확장

→ **전체가 환경으로 작동** — "절대 다수가 무시·거절·거부·가치 못 알아봄" 패턴 정확

### 남주 (신민섭)
- **알파 보호자 모델 (한국 vertical 표준):**
  - 즉시 인정 ("내 사람" 7화) → 가족 응징 (벨트 던지기) → 결혼 계약서 → 가족 모두 응징
  - 끈 풀어버림 패턴 — 11화 침실 키스 직진 (단 알레르기 정합 + 유경 보호로 절제 X 단 거리 유지)
- **voice 한 줄:** "내 사람 건드리는 겁니까? / 알아서 처리해 / 학교 다녀도 돼 / 자, 봐 / 너야말로 / 따라와" — 단답 통제형, 시적 cadence 0
- **다크 로맨스 짐승 직진은 아님** — 보호형 알파메일 변형 (한국 가족극 모델)

## 3. 2축 이야기 구조

### 압력축 1개
> **"양녀 출신 + 가족 학대 받은 유경이 언제 정식 안주인·정식 가족 위치를 받고, 가족이 언제 공개적으로 무너지는가?"**

→ 101화 끝까지 단일 축. 분산 0건. 모든 사건 (호텔 사건 → 약혼 → 결혼 → 학교 → 가족 복수)이 이 축을 키움.

### 페이즈 4 구조
- **EP1-8 (페이즈 1 — 가족 지옥 + 첫 보상):** 음모 → 호텔 사건 → 가족 폭로 → 민섭 도착 → 가족 응징
- **EP9-30 (페이즈 2 — 알파 보호와 학교):** 할머니의 사랑·옷·가방·식사 → 약혼식 → 가족 난입 → 학교 시작
- **EP31-60 (페이즈 3 — 복수와 트위스트):** 진성그룹·강간 음모·할머니 유골 협박 → 가족 직접 응징 → 사회적 박살
- **EP61-101 (페이즈 4 — 완전 회수):** 수아 사기·황 대표 살해 → 가족 최후 → 출산·평화

### 페이월 패턴 (강력 사이다 + 새 위기)
- **EP8 페이월:** "가죽 벨트 휘두름 → 민섭 도착 + '내 사람' 선언 + 비서 응징 + 할머니 보호" — 첫 강력 사이다 + 약혼식 미해결 위기로 결제 유도
- **EP12-13 페이월:** "약혼식 입장 + 가족 난입 + 수아 결혼 양보 강요 + 유경 위기" — 다음 화 회수 보장
- **EP50 페이월:** "선배 강간 시도 + 수아 음모 노출 + 친아빠 부양비 협박" — 큰 트위스트
- → **행동 직전 페이월** 정확 (사건 직전 / 정보 X)

### 모욕 루프 (클립 보상 점진 확장)
- **사적 모욕 (EP1-5):** 집안에서 차별·체벌·매 / 어머니 머리채·욕설
- **공개 모욕 (EP5-8):** 가족 식탁 공개 폭로 + 키스마크 공개 + "방탕한 년"
- **사회 모욕 (EP9-12):** 약혼식 가족 난입 + 결혼 양보 강요
- **학교 모욕 (EP30-50):** 진성그룹·유라·선배 강간 음모
- **사회적 박살 (EP50+):** 가족 사업 망함 → 부양비 협박 → 마침내 응징
- → 같은 쾌감 (가족·외부 빌런 박살) 다른 공개성·지위·범위 점진 확장 = **클립 보상 루프 교과서**

### VO/플래시백 도구
- **속마음 VO 빈도 중간:** "큰오빠가 이렇게 잘해준 건 처음이야" / "잘됐다" — 유경 내적 변화 청각 전달
- **플래시백 적극 사용:** EP3 가족 음모 설계 (큰오빠가 우유 줬던 진실) / EP12 가족 학대 회상
- → **5 조건 충족도:** 구체적 인간·짧은 압축·결정 직전·청각·구체 발화 모두 충족

## 4. 3축 대사 스타일

### 톤 (paid vertical 직격)
- **시적·연극톤 0건:** 단답·일상 가족 어휘 — "엄마, 4시에 일어나 / 죄송해요 / 갈게요 / 결혼 안 해요"
- **분위기 단어 0건:** 영혼·운명 류 X
- **민섭 voice:** 단답·통제·"내 사람" 류 강한 선언 — 시적 X
- **할머니 voice:** 자연스러운 노년 어휘 — "아가야 / 우리 손주며느리 / 짐승 같은 것들!" — 정서 보강

### 티키타카 (5-8턴 표준)
- **EP3 가족 식탁 공개 모욕 시퀀스:** 수아 머리 넘김 → 키스마크 노출 → 윤성 "부끄러움도 없어?" → 어머니 "쓸데없는" → 아빠 "맞아 죽을 줄 알아" → 유경 숙임 → 큰오빠 "결혼해야지" → 7턴 + 황 대표 통화 (정확한 패턴)
- **EP6 가족 + 수아 + 유경 + 모욕 시퀀스 + 큰오빠 본색 (정확한 8턴 누적):** 욕설 → 가족 차별 → 수아 사진 빼앗기 → 윤성 사진 찢기 → 유경 절규 → 아빠 벨트 → 민섭 등장 폭발 시퀀스
- **티키타카 거래 패턴 (EP11 침실):** "약혼하지 않아도 돼요 / 자, 봐 / 결혼 계약서? / 약혼하면 / 도움 필요해 / 보상은 / 액수 더 / 돈은 못 받아요 / 학교만 / 자, 좋아 / 원하는 게 있으면" — 권력의 춤 완벽

### 브릿지 직관 청각 (멀티태스킹)
- **상황·관계 즉시 청각 전달:** "약혼식에서 우리 민섭이랑 결혼 소식 발표할 거다" — 1줄에 4 요소
- **할머니가 청각 브릿지 역할 적극 수행:** 유경 상태·가족 학대를 즉시 청각 정보화 ("짐승 같은 것들! / 일회용 그릇과 젓가락도 여러 번 쓰게 했습니다") → 시청자가 화면 못 봐도 즉시 분노
- **paid vertical 대사 룰 정확 적용**

### 차용 패턴 (OFFERING·신규 작품 적용)
