## 분석 대상 5 작품

1. **차도남 아빠는 히든 재벌** (60화 / 비밀 재벌 + 미혼모 + 재회)
2. **황후는 못말려** (62화 / 동양 사극 + 빙의 + 복수 + 코미디 — 별도 카테고리)
3. **울지마 언니가 왔어** (60화 / 자매 + 시댁 + 외도 + 복수)

5. **회사도 남편도 다 내 것** (76화 / 직장 + 외도 + 콜드 오프닝)

## 🔥 핵심 인사이트 1 — 1차 페이월 위치 비교 (절대 룰 정정)

> **"EP1-8 무료 = 우리 시스템 룰" → 실제 시장 = 5-9화 다양**

| 작품 | 회차 | 1차 페이월 위치 | 페이월 직전 핵심 사건 |
|---|---|---|---|
| 차도남 아빠는 히든 재벌 | 60화 | **EP8 끝 / EP9 도입** | 신서연 친정 매질 + 강현우(재벌) 진입 직전 |
| 황후는 못말려 | 62화 | **EP5 끝 / EP6 도입** (또는 EP8) | 황제 검 + 별궁 유배 직전 (또는 태상황 귀환 직전) |
| 울지마 언니가 왔어 | 60화 | **EP9 끝 / EP10 도입** | 예슬 계단 추락 + 나은(친자매) 직접 목격 |
| 크리스마스의 기적 | 71화 | **EP6 끝 / EP7 도입** (또는 EP8-9) | 도훈 정체 시각 노출 (욕실 후 / 공항 선언) |
| 회사도 남편도 다 내 것 | 76화 | **EP8 끝 / EP9 도입** | 정우 결정타 + 모든 권한 박탈 (콜드 오프닝 + 합류) |

**페이월 위치 결정 요인 분석:**

### 1. 회차 수와 무관 X — 핵심 보상 직전이 우선
- 60-76화 작품들 모두 **5-9화** 사이에서 1차 페이월
- 회차 수 길어도 페이월 위치는 일정 (5-9화)
- → "총 회차 50화 / 무료 8화" 우리 시스템 룰 = 시장 표준과 큰 차이 없음

### 2. 페이월 직전 = 외부 강자 진입 직전 패턴 (60% 작품)
- 차도남: 강현우 진입 직전
- 울지마: 나은 등장 직전 (자매 재회)
- 크리스마스: 도훈 정체 노출 직전

### 3. 페이월 직전 = 권력 박탈 정점 (40% 작품)
- 황후: 별궁 유배 직전 (자리 박탈 = 권력 0)
- 회사도: 권한 박탈 정점 ("권한은 없습니다")

### 4. 페이월 = `feedback_pressure_axis_stacking_vs_dispersion.md` "행동 직전" 정합 100%
- 모든 작품 페이월 = **정보 노출 X / 행동 직전 cliffhanger**
- 강현우 막는 손 직전 / 나은 내려오는 모습 / 도훈 정체 시각 노출 / 황후 별궁 진입 / 송하연 결심 직전

### 5. 페이월 위치 = 분노 정점 + 약속 보상 직전
- 모든 작품 = "7-8화 분량 모욕·핍박 누적 + 9화 첫 박살 시작 직전"
- 시청자 결제 동기 = "기다린 보상 = 1초 거리 + 못 보면 답답해 죽음"
