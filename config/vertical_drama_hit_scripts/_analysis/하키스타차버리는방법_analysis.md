## 1축 — 캐릭터 분석

### 여주 — 강서윤 (진성 그룹 구단주의 딸 + 천재 하키 코치, 신분 위장 결혼)

**상승 호 (`female_lead_rise_arc.md` 정합):**

- **1-6화 = 처절·이입 트리거**: 시모 학대 / 윤채린이 강서윤의 공을 가로챔 (3년 전 차태환 혼수상태 시 강서윤이 자기 몸으로 전류 자극) / 조작 사진으로 외도 누명
- **단 — 사용자 정정 룰 정합**: 매달림 X / **반항 + 무시** ("당신 정말 후회할 거야") + 차태환에게 뺨 폭행
- **6-7화 = 유산 → 결심 트리거**: 임신 사실도 모른 채 유산 → "이 결혼, 내 인생에서 가장 큰 실수야"
- **8화 = 거래로 발화**: 변신 등장 + 이혼 서류 + 정체 폭로 직전
- **11화+**: 박도운(제자)·강서준(오빠)과 함께 복수 시작 → 팰컨스 헤드 코치 복귀
- **30화+**: 천재 코치 정체 공개 + 차태환 박살
- **50화+**: 진성 그룹 상속녀 공식 발표 + 정상

### 남주 — 차태환 (NHA MVP 수비수, 시걸스 선수)

**일반 로맨스 변종 — 후회·재집착 남주 패턴:**
- 다크 로맨스 X / 일반 스포츠 선수 알파
- 처음 = 강서윤 사랑 표명 (1화 기자회견) → 윤채린에게 속음
- 4-7화: 강서윤 의심·외도 누명 → 강서윤 박대
- 8화+: 강서윤 이혼·사라짐 → 의심 시작 → 후회 시작
- 후반: 모든 진실 알게 됨 → 후회·재집착·되찾으려 노력 (단 → 윤채린 총격 위기)

**핵심 — Mommy Don't Cry 권태환과 유사 패턴:**

- 단 — 후회·재집착 패턴은 한국 paid vertical 클래식

### 박도운 (서브 남주, 팰컨스 센터 포워드 + 강서윤 제자)

**보조 빌런:**
