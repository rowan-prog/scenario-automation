## 2. 1축 캐릭터 분석

### 주인공 (서수진)
- **1화 바닥 (이입 트리거):** 6년 전 = 첫사랑 태환 사랑하지만 아빠 경제 사범으로 감옥 + 가문 빚 → 어쩔 수 없이 박성민에게 가는 척 + 태환 길에서 차사고 (오해 출발점)
- **6년 후 (EP2) — 변경된 처지:** 아이 민준 미혼모 / 가난 / 민준 심장병 수술비 4천만원 / 의사 시우의 가짜 여자친구 알바
- **저항 + 무시 패턴:** "전 고정적 직업이 없어요 / 옛 일이에요" / "그 사람관 상관없어요" — 진실 숨김 + 자기 처지 부정 = 멈춤 시도 + 무시당함
- **8-12화 거래:** 룸살롱 양주 디캔터 한 번에 마심 (떨면서도 선택) → 진성그룹 면접 입사 (자기 능력 입증)
- **30-50화 상승:** 친아빠 도박 협박 → 민준 친아빠가 태환 임을 시청자만 안 → 50화 매운 죽 시퀀스 (관계 변화)
- **80화 정점:** 진실 폭로 → 결혼 + 평화
- **paid vertical 정합:** 완벽한 상승 호 + 후회남 + 비밀 아이 트로프 효과 극대

### 메인 빌런 — 다층 구조 (정확한 1+다수 패턴)
- **메인 빌런 = 친아버지 서영태 (혈연·경제 사범 + 도박 + 협박):**
  - 끝까지 가치 모름 / 끝까지 자기 욕망 (도박·돈) — "민준이 친외손자! 그런 애를 데리고 협박을!"
  - 작품 후반 80화에서야 비로소 반성 편지 → 마지막 회개 (메인 빌런이지만 완전 박살은 아닌 변형 — 한국 가족 가치 정합)
  - 메인 빌런이 가족이라는 점이 한국 vertical 특유 (외부 살의보다 가족 압박이 핵심)
- **보조 빌런 다수:**
  - 박성민 (옛 약혼자) — 6년 전 도구 + 룸살롱 모욕 가담
  - 박민석 (외부 빌런) — 룸살롱 8화 공개 폭로·돈 뿌리기 가담
  - 김채린 (태환 약혼녀) — 면접 압박·견제·연적
  - 유라 (면접 동료) — 학력 위조 + 모욕
  - 진성그룹 면접관·동료 (외부 환경 압박)

→ **메인 빌런 = 가족 / 보조 빌런 = 외부 + 가족** = 한국형 변형

### 남주 (강태환)
- **6년 전 가난 → 후 재벌 회수형 (한국 vertical 표준):**
  - 6년 전 = 약자 / 6년 후 = SJ 그룹 대표 + 차가운 통제형 + 옛 사랑 복수 의지
  - 룸살롱 8화 양주 강요 = "통제 + 욕망 + 복수" 합치 — 다크 로맨스 가까운 결
- **멈춤 X 패턴 (한국형 변형):**
  - 호텔 비상구 (6화) = 입술 피 + 키스 직진 / 룸살롱 (8화) = 팔 잡기·돈 뿌리기·자존심 긁기
  - 단 후반부 — 민준 사랑 → 보호자 알파메일로 변형 (한국 가족극 결)
- **voice 한 줄:** "이리 와 / 굳이 소리내서 빌지 않아도 돼 / 죽 좀 마실게 / 매워하지마" — 단답·통제·관심 우위, 시적 cadence 0
- **다크 통제 + 후회 + 보호자 결합** — 한국 vertical 시청자 가장 좋아하는 한국형 vertical 남주 표준

## 3. 2축 이야기 구조

### 압력축 1개
> **"6년 전 오해로 헤어진 두 사람이 언제 진실을 알고, 비밀 아이 민준의 친부가 누구임이 공개적으로 드러나고, 옛 사랑이 회수되는가?"**

→ 80화 끝까지 단일 축. 분산 0건. 모든 사건 (의사 알바 → 면접 → 룸살롱 → 친아빠 협박 → 민준 친부 → 결혼)이 이 축을 키움.

### 페이즈 4 구조
- **EP1-12 (페이즈 1 — 재회와 첫 오해 깊어짐):** 6년 전 헤어짐 → 6년 후 재회 → 룸살롱 모욕 → 면접 입사 → 비밀 아이 폭로 미루기
- **EP13-32 (페이즈 2 — 깊어지는 오해와 친아빠 위기):** 회사 적응 → 친아빠 출소 → 도박 협박 → 민준 친부가 태환임을 인지하기 시작
- **EP33-50 (페이즈 3 — 진실 가까워짐):** 민준-태환 부자 자연 만남 → 50화 매운 죽 시퀀스 → 관계 변화
- **EP51-80 (페이즈 4 — 회수와 결혼):** 진실 폭로 → 친아빠 회개 → 결혼 프로포즈

### 페이월 패턴 (강력 사이다 + 큰 미스터리 폭로)
- **EP9 페이월:** "양주 디캔터 마심 + 돈 뿌림 + 박민석 6년 전 교통사고 진실 폭로" — 큰 굴욕 + 큰 진실 동시 작용 = 결제 절정
- **EP12 페이월:** "진성 그룹 면접 + 채린·태환 등장 → 비밀 아이 압박 시작"
- **EP31-32 페이월:** "친아빠 도박 협박 + 민준이 친아빠 강태환 폭로 직전" — 큰 트위스트
- **EP50 페이월:** "매운 죽 시퀀스 = 태환·시우 견제 + 수진 관계 변화 직전"
- → **행동·진실 폭로 직전 페이월** 정확

### 모욕 루프 (클립 보상 점진 확장)
- **개인 모욕 (EP1):** 6년 전 박성민·태환 앞에서 차가운 척 + 도망
- **공개 모욕 (EP8-9):** 룸살롱 박민석 + 태환 돈 뿌리기 + 첫사랑 진실 폭로
- **사회 모욕 (EP11-12):** 면접 + 채린·유라 학력 차별
- **가족 모욕 (EP31-32):** 친아빠 도박 + 민준 위협
- **관계 회수 (EP50+):** 죽·매운 음식 = 관계 변화 시작
- → 같은 쾌감 (수진의 진실·사랑·자존심 인정) 다른 공개성 점진 확장 = **클립 보상 루프 정확**

### VO/플래시백 도구
- **VO 빈도 매우 높음:** 수진 / 태환 / 민준 모두 VO 활용 — 수진은 자기 처지·진실 / 태환은 옛 후회 / 민준은 친부 인지 트리거
- **플래시백 빈번:** 6년 전 호텔·도로·사고 / 결혼식 / 임신
- **5 조건 충족도:** 구체적 인간·짧은 압축·결정 직전·청각·구체 발화

## 4. 3축 대사 스타일

### 톤 (paid vertical 직격)
- **시적·연극톤 0건:** 단답·구체 행동 어휘 — "이리 와 / 다 마셨어요 / 그쪽 잘못 아니니까"
- **분위기 단어 0건:** 영혼·운명 류 X
- **태환 voice:** 단답·통제·복수 의지 — "내가 어떻게 약속을 어기겠어 / 안 뜨겁네 맛있어 / 네 여자친구를 내가 어떻게 알아"
- **민준 voice:** 어린이 자연체 — 청각 브릿지 역할 (옆사람 정보 전달)

### 티키타카 (5-8턴 표준)
- **EP3-4 호텔 연회장 첫 대면:** 시우 소개 → 채린 견제 → "오해" → 수진 회피 → 태환 "그저 아는 사이 정도가 아닐 텐데" → 시우 "사이좋게 풀길" → 태환 "뒤끝 있어" → 채린 등장 8턴 시퀀스
- **EP8 룸살롱 시퀀스 (5-8턴 표준):** 박민석 폭로 → 태환 비웃음 → 박민석 "구걸하러 나오셨군" → 여자 "강 대표 뒷바라지" → 수진 침묵 → 태환 "이리 와" → "이 술 다 마시면 이 돈" → 수진 마심 → 태환 돈 뿌리기 → 박민석 진실 폭로 (9-10턴 누적·압력 정점)
- **EP12 면접실:** 채린 견제 → 면접관 "낙하산" → 수진 답변 → 유라 모욕 → 수진 반박 → 5-7턴

### 브릿지 직관 청각 (멀티태스킹)
- **민준 발화 적극 브릿지:** "엄마, 강 아저씨랑 결혼해 / 저 잘생긴 삼촌이 장난감 사줬어 / 내가 좋아하는 것들이잖아!" → 시청자가 화면 못 봐도 관계 흐름 즉시 청각화
- **VO 적극 활용:** 수진 "방금 뒷모습이... 잘못 봤나 봐 / 다행히 시우 씨네" — 멀티태스킹 청각 최적
- **paid vertical 대사 룰 정확 적용**

## 5. 종합 평가

### paid vertical 정합도: 95%
- 상승 호 완벽 (1화 바닥 → 50화 정점 → 80화 회수)
- 비밀 아이 + 후회남 + 룸살롱 굴욕 = 한국 vertical 클래식 콤보
- 메인 빌런(가족) + 보조 빌런 다수 정확
- VO·플래시백 적극
- 시적 대사 0건

### AI 시네마틱 함정 6 점검
1. 부서진 후 미학 — **0건** (실제 울음·돈 뿌리기 직접 노출)
2. 환경 진동으로 위협 — **0건**
3. 절제 에로스 — **0건** (호텔 비상구 키스 직진·룸살롱 통제)
4. 상징 누적 의미 — **0건** (반지·시계·죽 1회 도구만)
5. 2-3턴 인장 — **0건** (5-10턴 누적 표준)
6. 1화 완성형 여주 — **0건** (1화 수진 어쩔 수 없이 떠나는 모습·6년 후 미혼모로 진짜 바닥부터)

### 차용 패턴 (OFFERING·신규 작품 적용)
1. **6년 전 → 현재 점프 모델:** 1화 = 빠르게 바닥 트라우마 / 2화 = 현재 시점 점프 → 시청자 즉시 이입 보장
2. **비밀 아이 (Secret Baby) 트로프:** 시청자만 아는 친부 구조 → 매 EP 부자 자연 만남 = 클립 보상 무한 재포장
3. **룸살롱·클럽 공개 모욕 시퀀스 (EP8):** 강한 사회적 굴욕 + 진실 폭로 동시 작용 = 페이월 최적 결합
4. **친아빠 메인 빌런 + 외부 보조 빌런:** 가족 = 깊은 모욕 / 외부 = 사회 모욕 → 양쪽 클립 보상 가능
5. **아이 시점 청각 브릿지:** 아이 발화 = 자연 정보 전달·시청자 즉시 이해 + 정서 보강
6. **6년 전 사고·오해 = 큰 미스터리 페이월 카드:** "사실 너 때문에 사고 났어" 류 — 한국 vertical 클래식 페이월 패턴
