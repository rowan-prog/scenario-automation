## 1축 — 캐릭터 분석

### 여주 송하연 (1화 콜드 오프닝 정상 → 2주 전 바닥 점프 → 50화+ 정상 복귀 호)

**1화 콜드 오프닝 = "결과 = 강한 여주" 노출:**
- 이사회 상석 + 흰색 정장 + 차가운 명령 "오늘부로 YJ테크는 김정우 대표를 대표이사직에서 해임합니다"
- 시청자 첫 인상 = "이 여자가 어떻게 이 자리에 왔나" 호기심 트리거
- (VO) "결혼한 지 7년. 난 내 손으로 직접 남편을 무너뜨리기로 했다" = 즉시 작품 본질 청각 전달
- **`feedback_pressure_axis_stacking_vs_dispersion.md` "결과 보여주고 시작 → 어떻게 거기까지 갔나" 변형** — 한국 vertical 시장 핵심 구조

**1화 후반 ~ EP9 = 2주 전 바닥:**
- 출장 귀국 직후 회사 진입 → 남편 김정우와 비서 윤지수의 외도 발각
- 자기 자리에 비서가 앉음 + 자기 목걸이를 비서가 착용 + 결혼 사진을 쓰레기통에 버림
- EP4: 비서 해고 명령 → 남편이 거부
- EP5: 직원들이 단체 시위 응원 (서연 편) → 정우 분노
- EP6: 정우와 함께한 추억 물건 다 부숨 + "다시 한 번 내 마지노선을 건드리면" 최종 통첩
- EP7: 비서 다시 채용 + 모든 권한 이전 → 직원들 비서 머리채
- EP8: 액자 부서져 있음(아버지 사진) + 정우 진입 + 위협 + 통증 (병 암 진행 중) + 정우 "넌 선함이라고는 윤 비서의 만분의 일도 못 돼" 결정타
- **EP8 끝: 정 비서 "대표님께 남아 있는 권한은 없습니다"**

**여주 voice:** 1화 콜드 오프닝 = 차가운 통제 + 결단 / 2-7화 = 분노·배신·점진 단호 / EP9+ = 완전 결단 후 복수.

**이입 트리거:** 외도 + 결혼 7년 + 자기 자리 박탈 + 가족 액자 부숨 + 암 (시청자는 EP7 의사 진료 회상으로 알고 남편 모름) = 한국 30-50대 여성 직장+결혼 양면 압박 즉시 분노.

### 남주 (애매 — 김정우는 빌런 / 진짜 남주는 EP9+ 등장 예정)

**김정우 = 1차 메인 빌런:**
- 7년 결혼 + YJ테크 공동 대표
- 비서 윤지수와 외도
- 신혼여행 사진을 쓰레기통에 버림
- 아내 자리에 비서 앉힘 + 목걸이 선물
- 권한 박탈 + 비서에게 모든 업무 이전
- "넌 선함이라고는 윤 비서의 만분의 일도 못 돼" 결정타

**진짜 남주 후보 = 이재한 (등장 예고 - 캐릭터 목록 4번):**
- 아직 EP1-8 등장 X / EP9+ 등장 예상
- 한국 외도 복수극 표준 = "버려진 아내가 새 강자를 만나 전남편 박살" 트로프

### 빌런 (다층 구조)

**1차 메인 빌런:** 김정우 (남편 + 외도자 + 권력 박탈자)

**2차 메인 빌런 (실제 음모자):** 윤지수 (비서 + 외도녀 + 자리 강탈 + 추후 음모 누적)
- 윤지수의 "미세한 승리의 미소" (EP4 끝)
- 직원들 머리채 자작극 (EP7) = 음모 능동
- 인스타그램 "충성! 나의 대표님" = 도발 + 멸시

**보조 빌런:** 시댁 (정우 부모 - 향후 등장 예고)

**환경 압박:** 회사 임원진 + 외도녀 + 시댁 + 남편 전체가 한 편 → 송하연 고립.

**빌런 가치 모름 검증:**
- 정우 + 윤지수: 송하연의 진짜 능력·정신그룹 협력 인수·암 진행 모름
- 끝까지 멸시 → 복귀 시 충격
- `feedback_concrete_villain_humiliation_loop.md` 정합

## 2축 — 이야기 구조 분석

### 압력축 1개

**핵심 압력축:** **"7년 결혼 + 회사 공동 대표 자리에서 외도·권력 박탈 받은 송하연이 언제 어떻게 남편(정우)·외도녀(지수)·회사를 다 자기 것으로 되돌리고 박살하나"**.

**제목 자체가 압력축:** "회사도 남편도 다 내 것" = 시청자에게 약속 + 결말 직접 명시 → 1화 콜드 오프닝으로 결과 일부 보여줌 → "어떻게?" 결제 동기

### 페이월 위치 (EP8 끝 / EP9 도입) — 핵심 분석

**EP8 페이월 정확한 위치:**
- EP8 마지막: 정우가 "넌 선함이라고는 윤 비서의 만분의 일도 못 돼" 결정타 + 통증 + 정 비서 보고 "윤지수를 다시 채용하셨습니다. 그리고… 대표님 부서의 모든 업무를 윤지수에게 넘기셨습니다. 대표님. 현재 대표님께 남아 있는 권한은 없습니다"
- EP9 도입: 송하연이 모든 결심 + 복수 시작

**페이월 왜 EP8-9 위치인가:**
1. **모욕·권력 박탈 누적 7화 분량** — 외도 + 목걸이 + 자리 + 액자 부숨 + 비서 머리채 자작극 + 권력 박탈 = 분노 정점
2. **EP1 콜드 오프닝 결과 = "이 여자가 다 이긴다" 약속이 이미 청각으로 전달됨** → EP8은 "어떻게 시작했나?" 정확한 결제 보상 직전
3. **`feedback_pressure_axis_stacking_vs_dispersion.md` "paywall = 행동 직전" 정합** — 송하연 결심 = 복수 시작 직전
4. **시청자 정보 비대칭 = 시청자는 결과 알고 빌런들은 모름** — 1화 콜드 오프닝의 핵심 기능

**대안 페이월 = EP3-4 가능성:**
- EP3 = 결혼 사진 쓰레기통 발견 + 비서 해고 명령
- EP4 = 정우 거부 + 비서 응원
- → 한국 시장은 EP4-5 페이월도 빈번. 본 작품은 8화 패턴 더 적합

### 클립 보상 루프

**원초 쾌감 1개:** "버려진 7년 차 아내가 회사도 남편도 다 자기 것으로 되돌리고 빌런들을 차례로 박살".

**점진 확장 (EP9+ 예상):**
- 회사 권한 회복 → 정우 해임
- 외도녀 윤지수 사회적 매장
- 새 남주 등장 → 정우 질투 폭발
- 시댁 굴복
- 같은 쾌감 "회수 + 박살" 다른 영역·다른 가해자

### 보상 단계 (3층 구조)

- **1층 (EP1 콜드 오프닝):** 결과 = "다 내 것" 즉시 약속 + 사이다 비주얼 (흰색 정장 + 이사회 상석 + 차가운 통제)
- **2층 (EP2-8 누적):** 분노 게이지 누적 + 작은 사이다 (EP5 직원 단체 응원 + EP6 추억 부숨 + EP7 비서 머리채 등)
- **3층 (EP9+ 유료):** 완전 복수 + 새 남주 + 모든 박살

### 콜드 오프닝 구조 = 한국 vertical 표준

**구조:**
- EP1 #1 (현재): 결과 = 정우 해임
- EP1 #2 ~ EP8 (2주 전 ~ 결심): 이유 + 과정
- EP9+ (현재 + 미래): 본격 복수

→ **한국 30-50대 여성 시청자 = "결과 알고 시작 → 어떻게 거기까지 갔나?" 호기심 결제 동기 강력**

- "한낱 비서가 무슨 자격으로 대표 자리에 앉아?" (Pattern A 직설)

- "더러워졌어. 더러워진 건 절대 안 가져. 아. 너도 마찬가지야" (Pattern A + 최후통첩)

### 멀티태스킹 시청자 친화

**브릿지 청각 정보 풍부:**
- 송하연 (VO) 1화 = 7년 결혼 + 남편 무너뜨림 결심 즉시 청각 설명
- 정우 "이번 정신그룹 협업 발표, 윤 비서가 정말 많이 도와줬어. 목걸이는 지수씨가 가져" = 외도 + 가식 즉시 인지
- 직원들 단체 인스타 + 정 비서 "대표님이 우리한테 이렇게까지 해주시는데, 어디서 굴러온 여우 하나가 대표님 속을 이렇게 긁고 있잖아요" = 직장 정치 즉시 청각

**텐션 단답:**
- "넌 해고야" (EP3 끝)
- "옮길 필요 없어. 바로 인사과 가서 퇴사 처리해" (EP3 - Pattern A 사실 + 통제)
- "이거 아직 기억나?" + 화병 부숨 (EP6 - 짧고 행동)

### 캐릭터별 voice 차별

- **송하연:** 차가운 통제 + 분노 누적 + 결단. 사극·다크 톤 X / 현대 직장+결혼 톤 정합
- **김정우:** 위선 + 변명 ("나는 너 하나만 사랑해. 하지만 윤 비서가 있어야 정신그룹과의 핵심 협력 사업을 마무리할 수 있어")
- **윤지수:** 가식 + 음모. 표면 = 울먹임 + "죄송합니다" / 이면 = "기회다" + 머리채 자작극
- **정 비서:** 충직 + 분노 ("대표님이 우리한테 이렇게까지 해주시는데, 어디서 굴러온 여우 하나가")

## 종합 평가

### 강점

1. **콜드 오프닝 구조 = 한국 vertical 표준 + 매출 강화** — 결과 보여주고 시작 → 시청자가 "이 결과로 어떻게?" 결제 동기
2. **메인 빌런 (남편) + 핵심 음모자 (외도녀) + 보조 빌런 (시댁) = 환경 압박** 정합
3. **현대 직장+결혼 양면 압박 = 한국 30-50대 여성 핵심 결제 동기**
4. **클립 보상 루프 = 회수 + 박살** 점진 확장 약속
5. **시적·연극톤 0건** = 정합
6. **시청자 정보 비대칭 = 결제 동력** — 송하연의 결과·암·정신그룹 인수 모두 시청자만 알고 빌런들 모름

### 약점·OFFERING 적용 시 주의

1. **현대 직장 = 다크 로맨타지 OFFERING과 카테고리 다름** — 단 구조적 인사이트는 적용 가능
2. **결혼 7년 + 외도 = 한국 30-50대 핵심** — 다른 작품 (OFFERING - 20-30대 다크 로맨타지)에는 부적합
3. **콜드 오프닝 결과 노출 = 강력하나 OFFERING의 미스터리 + 점진 노출 구조와 충돌 가능**

### OFFERING / 06 SHE STOLE MY FACE 적용 가능 인사이트

- **콜드 오프닝 결과 일부 노출 = 06 SHE STOLE MY FACE에 직접 적용 가능** — "이 여자가 어떻게 정체를 빼앗긴 자에게 복수했나" 결과 일부 + 과정

- **"내 마지노선 건드리면 단 1초도 망설이지 않을거야" 류 최후통첩 대사** = 4 요소 정합 + Pattern A·C = OFFERING 이졸데 EP6+ 직접 활용 가능
