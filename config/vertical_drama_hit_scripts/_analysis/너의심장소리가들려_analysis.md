## 1축 — 캐릭터 분석

### 여주 — 서시연 (가난한 시골 대학생 → 7년 후 실명한 채 딸 키움)

**상승 호 (`female_lead_rise_arc.md` 정합):**
- **1화 바닥**: 가난한 시골 / 대학 등록금 X / 할머니 병원비 X / 차에 치임 직전 + 자기 신체에 백만분의 일 확률 표식 무지
- **2-3화 = 처절·이입 트리거**: 차상현이 "옷 벗어" 강요 → 정체 모르고 두려움
- **단 — 사용자 정정 룰 정합**: 매달림 X / **반항 + 무시** (정체 폭로 후 받아들임 = 거래)
- **7-8화 = 거래로 발화**: 1조 카드를 평화·남편 건강 위해 사용 → 결정 트리거
- **9-10화 = 변신 등장**: 무도회 우아 강림·차상현 첫 시선 흔들림
- **11-15화**: 차상현 30살 생일·죽음 위기·서시연이 살리기 위해 모든 것 바침
- **7년 후 + 후반**: 실명한 채 딸 키움 (또 다른 바닥) → 진실 폭로 → 차상현 재회 → 정상 회복
- 50화+ = 진정한 사랑·가족 회복

**핵심 패턴 — 2번의 바닥 (다크 로맨스 변종):**
- 1화-1차 바닥: 가난·신체 모름
- 7-8화: 진실 폭로 + 거래
- 7년 후-2차 바닥: 실명·홀로 딸 키움 (페이월 후반 대형 보상)
- 30화+: 재회 + 진실 폭로 + 정상

### 남주 — 차상현 (W그룹 냉혈 총수, 태양독 환자)

**다크 로맨스 + 운명 정합 (`dark_romance_male_predator.md` 정합):**
- **냉혈 + 운명 = 일반 다크 로맨스 변종**
- 매력 = **외부 압도 (W그룹 총수·압도적 권력·1조 카드)** + **죽음 위협 (30살 못 넘김)** + **내부 집착 (정상회담 취소·옥 펜던트 받음·서시연 시선)**

**`dark_romance_male_predator.md` 절제 X 패턴:**
- 첫 만남: "옷 벗어" → 강압 직진 (멈춤 X)
- "그 여자 목숨 값으로 준 1조" → 통제 언어 명확
- "어차피 죽을 여자야. 죽기 전에 후회하게 만들고 싶지 않아" → 짐승 같은 통제 + 절제 X

**`female_target_master.md` 알파 조건:**
- 압도적 능력·지위·재력 ✅
- 여주에게만 홀딱 빠짐 ✅ (수십 명 여자 거부 → 서시연만)
- 다크 로맨스 짐승 직진 ✅

### 빌런 — 다층 구조

**메인 빌런 = 차 회장 (할아버지) + 한 여사 (새어머니) + 차상우 (이복동생)**

**보조 빌런:**

- 7년 후 = 더 큰 빌런 추가 (라이벌 후보)

**기본 구조:**

→ **다크 로맨스 강압 패턴 (멈춤 X)**

**EP7 — 1조 카드 + 진실 폭로:**

4. "사모님께서 바로 그 백만 분의 일 확률의 태음신체"

→ **`vo_flashback_pressure_tools.md` 5 조건 완벽 충족** (구체적 인간·압축 플래시백·페이월 직전·인지 가능·구체 VO)

## 3축 — 대사 스타일

### 직관·기능 100%

**채택 패턴:**
- 차상현: "옷 벗어." (3 단어 단답 = 다크 로맨스 강압 정점)
- 무량대사: "허리에 검붉은 복숭아꽃을 지닌 여인... 그 여인이 바로 세상에 유일한 태음신체의 주인일세. 차 대표, 자네는 지독한 태양의 기운을 타고났어." → Pattern A 사실 나열 (운명 설정 = 직접 풀이)
- 차상현: "그 여자 목숨 값으로 준 1조, 그거 받았나?" → 사실 나열 + 통제 언어
- 차상현: "어차피 죽을 여자야. 죽기 전에 후회하게 만들고 싶지 않아." → 통제 언어 + 자기 부정 + 다음 사건 보임 (집착 표지)
- 윤 이모: "사모님께서 바로 그 백만 분의 일 확률의 태음신체를 가지셨다고 들었어요. 대표님께서 살아남으시려면, 사모님의 도움이 필요해요." → Pattern A 정보 전달 + 정합 (긴 대사 OK)

### 시적·은유·연극톤 0건 (절대)

- 운명·태양·태음·신체·복숭아꽃 = 설정 단어 (시적 X / 직접 정의)
- 모든 대사 = 사실·욕망·결과 직접

### 다크 로맨스 대사 특수 — 부정형 + 통제 voice

- 차상현 = "필요 없어" / "어차피 죽을 여자야" → 부정형 자기 보호
- 자기 마음 인정 X / 행동으로 보임 (정상회담 취소 = 서시연 무도회 파트너)

### VO 활용 최강

- 서시연 V.O.: "(그래서... 나랑 결혼한 거였어. 살기 위해서...)" → 진실 인지 즉시 청각 전달
- 차상현 V.O.: "(같잖네. 내가 지금... 고작 저런 놈들한테 질투하고 있는 거야?)" → 자기 마음 인정 부정 + 시청자 추론 즉시
