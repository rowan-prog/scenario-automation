## 1축 — 캐릭터 분석

### 여주 윤지원 (1화 바닥 → 4화 거래 → 50+화 정상 호 변형)

**1화 바닥 정의:**
- 햄버거 가게 엘프 복장 알바 (직업 멸시 트리거)
- 노숙자(도훈)에게 햄버거 봉투 챙겨주는 선한 마음
- 약혼자 송재민의 외도 발각 (드라이브스루 창구 = 공개 굴욕)
- 친척(이복 친척) 윤정아와의 외도 발견 → 이중 배신
- 할머니 임종 직전 + 가짜 결혼 약속 + 평생 모은 돈 결혼식 비용 사용
- **이입 트리거 = 외도 + 친척 배신 + 가난 + 효도 압박** (한국 30-40대 여성 즉시 분노)

**4화 거래:** 노숙자 도훈에게 "가짜 결혼" 거래 동의. 메모리 `feedback_female_lead_rise_arc.md` 의 "1화 바닥 → 8화 거래" 호의 변형 — **4화로 압축 + 가짜 결혼 트로프**.

**여주 voice:** 천진 + 일상 + 가난 + 효도 ("우리 집 가자. 난 뜨거운 물로 샤워부터 하고 싶어"). 무력 매달림 X — 적극 대응 (재민 멱살 잡음·정아 뺨치기).

### 남주 권도훈 (다크 로맨스 X / 알파 + 비밀 정체 + 즉시 매료)

**1-2화 = 위장 노숙자:**
- 회사 부정 조사 위해 3개월 숨김 (`feedback_compressed_setting_paid_vertical.md` 정합 - 새 인물 도입 X / 같은 인물의 다른 면)
- 지원의 일관된 친절에 매료됨 ("당신을 위해서라면 전 뭐든 할 수 있으니까요")
- EP3에서 재민의 손을 막아 지원 보호 = **즉시 알파 진입**

**4-6화 가짜 결혼 + 정체 노출 단계:**
- EP4 무릎 꿇고 "임시 결혼" 제안
- EP5 시청 혼인신고 + 담당관이 "권도훈… 킹스그룹 대표 이름이랑 같잖아?" 의심 → 의심 풀고 신고
- EP6 욕실 샤워 후 정체 일부 노출 (몸 + 얼굴) → 지원 충격
- EP7 영상통화로 엄마에게도 비주얼 노출 → "잠깐만… 너무 잘생겼잖아"

**남주 voice:** 침착·통제 + 즉시 사랑 표시 ("법적으로는 이제 네 남편인데. 넌 내 알몸을 봐도 상관없지"). 짐승 직진 X (한국 톤 = 부드러운 알파).

### 빌런 (다중 빌런 다층 구조)

**메인 빌런 1명 (1차 아크):** 약혼자 송재민 (외도 + 평생 돈 갈취 + 공개 굴욕). 얼굴·이름·구체 행동 명확.

**보조 빌런 다수:**
- 윤정아 (친척 + 외도 상대 + 비웃기 — "언니는 그냥 여전히 촌스럽고 한심해. 차라리 시골로 돌아가서 다시 소나 키우는 게 어때?")
- 향후 진행: 시댁·라이벌 등 등장 가능

**메인 빌런 가치 모름 검증:** 재민·정아 모두 노숙자 도훈을 멸시 → 정체 노출 직전까지 끝까지 모름. 후회 → 매달림 → 일정 정도 후회물 클리셰 진입 가능성 있으나 (한국 회귀·신분 위장물 패턴) 압도 패턴 유지.

## 2축 — 이야기 구조 분석

### 압력축 1개

**핵심 압력축:** **"평생 가난·외도 굴욕 받은 지원이 비밀 재벌(도훈)과 가짜 결혼 → 진짜 정체 노출 → 외도자·친척·사회가 차례로 굴복"**.

### 페이월 위치 (EP6 끝 / EP7 도입) — 핵심 분석

**EP6 페이월 정확한 위치:**
- EP6 마지막: 도훈이 욕실에서 샤워 후 수건만 두른 채 등장 + 지원이 "완전히 다른 사람처럼" 그를 봄 + **얼어붙은 채 응시**
- EP7 도입: 비주얼 노출 정점 + 엄마 영상통화로 "어머머! 세상에!" 공개 노출

**페이월 왜 EP6-7 위치인가:**
1. **EP5 시청 혼인신고 = 법적 결속 완료** — 1차 약속 달성
2. **EP6 비주얼 노출 = "노숙자 사실 비밀 재벌" 첫 시각 증거** — 가짜 결혼 트로프의 핵심 보상 직전
3. **`feedback_pressure_axis_stacking_vs_dispersion.md` "paywall = 정보 X / 행동·결과 O" 정합** — 단순 정체 정보가 아니라 시각화된 매력 충격

**대안 페이월 가능성 = EP8-9:**
- EP8 = 도훈 결혼식 준비 명령 (정체 공식 노출 시작) + 8호 다이아 반지 주문
- EP9 = 도훈이 재민 면전에서 "이제 결혼했어. 내가 남편이고" 선언
- → 공개 굴욕 직전 = 더 강한 페이월 후보. 단 한국 시장 표준은 6-8화 페이월 패턴이 일반적

### 클립 보상 루프

**원초 쾌감 1개:** "가난·외도 굴욕 받은 지원이 비밀 재벌과 결혼·재민·정아·시댁 차례 굴복".

**점진 확장 (장르 컨벤션):**
- EP6 정체 일부 노출 (몸·얼굴) - 사적 노출
- EP10 공항에서 재민 + 정아 앞 노출 - 공개 노출 1단계
- 이후: 시댁 만남·사회 만남·회사 만남 - 공개 노출 확장
- 같은 쾌감 "정체 노출 → 빌런 충격" 다른 공개성·다른 가해자

### 보상 단계 (3층 구조)

- **1층 (EP1-3 즉시):** 도훈이 재민의 손 막음 = "이미 보호자 등장" 즉시 안도
- **2층 (EP4-6 누적):** 가짜 결혼 + 정체 시각 노출 시작 = 매력 약속
- **3층 (EP7+ 유료):** 공개 굴욕 + 진짜 사랑 + 재벌 와이프 자리 차례 회수

### 트로프 분석

**핵심 트로프 ("fake marriage / hidden billionaire / boss next door"):**
- 위장 노숙자 + 비밀 재벌 (북미 paid vertical 핵심 트로프 — `feedback_core_tropes.md` 정합 가능)
- 가짜 결혼 → 진짜 사랑 (한국·북미 공통 검증)
- 외도자 굴욕 + 빌런 가족 굴욕 (한국 30-40대 여성 핵심)
- 효도 (할머니 마지막 소원) = 한국 정서 강화

## 3축 — 대사 스타일 분석

### 시적·연극톤 0건 검증

대사 모두 직접·기능. 한국 vertical 시장 표준 톤.

- "고작 이런 싸구려 반지 하나에 의미 부여하고 있었냐?" (재민 멸시 = 즉시 분노)
- "이제 결혼했어. 내가 남편이고." (도훈 단답 알파 선언)
- "네가 필요하다면 뭐든." (Pattern A 변형 - 짧고 직접)

### 멀티태스킹 시청자 친화

**브릿지 청각 정보 풍부:**
- "오빠는 이제 킹스 그룹 다녀" (정아의 자랑 = 외도 + 신분 상승 즉시 청각화)
- 엄마 미옥 영상통화 = 모든 상황 청각 중계
- 담당관 (VO) "6개월 전에 비행기 추락 사고로 사망했다고 알려진… 킹스 그룹 대표 이름이랑 같잖아?" = 시청자에게 핵심 정보 직접

**텐션 단답:**
- "그녀에게 손대지 마" (도훈 알파 진입)
- "이거 놔" (예슬 류는 아니지만 짧고 직접)

### 캐릭터별 voice 차별

- **지원:** 천진 + 일상 + 약함 + 점진 단호 ("그럴 가치도 없는 사람인데… 근데 엄마랑 할머니가 이미 결혼식 준비를 다 해놓으셨어요. 평생 모은 돈까지 쓰셨는데…")
- **도훈:** 침착 + 통제 + 즉시 사랑 ("당신을 위해서라면 전 뭐든 할 수 있으니까요")
- **재민:** 비웃음 + 가난 멸시 ("아직도 햄버거 가게에서 일이나 하고 있잖아. 맨날 촌스러운 옷에 그 카우보이 부츠까지")
- **정아:** 비꼬기 + 자기 우월 ("결국 나 같은 사람이랑 어울리는 거지. 언니는 그냥 여전히 촌스럽고 한심해")
- **엄마 미옥:** 따뜻 + 효도 압박 ("의사 선생님이 할머니가 이번 크리스마스는 넘기기 어려우실 수도 있대")

### 4 요소 정합

도훈 "제 생각엔… 저랑 결혼하는 방법도 있는 것 같은데요. 물론 진짜 결혼은 아니고요. 임시로요. 그러면 할머님께서 웨딩드레스 입은 모습은 보실 수 있잖아요" =
- 욕망: 지원 곁에 있기 + 보호자
- 상황: 약혼자 파혼 직후 + 할머니 임종 임박
- 선택: 가짜 결혼 제안
- 다음: 시청 혼인신고

## 종합 평가

### 강점

1. **위장 노숙자 + 비밀 재벌 = 한국·북미 공통 검증 트로프** — fake marriage + hidden billionaire 결합
2. **EP1 즉시 사이다 보상** (재민 멱살 + 정아 뺨치기 + 도훈 진입) = `feedback_paid_vertical_4_levers.md` "L1 외부 보상 빠르게" 정합
3. **메인 빌런 (외도자) + 보조 빌런 (친척 + 향후 시댁) = 환경 압박** 정합
4. **효도 (할머니) + 친절 (햄버거 챙김) = 여주 호감 즉시 형성**
5. **시적·연극톤 0건** = 정합
6. **EP9 공항 공개 굴욕 = 클립 보상 루프 첫 정점**

### 약점·OFFERING 적용 시 주의

1. **위장 노숙자 = 한국 시장 인기 / 북미는 다른 변형 (Hidden CEO / Mafia Boss 위장) 필요**
2. **부드러운 알파 톤 = 다크 로맨타지 OFFERING과 부적합** — OFFERING은 짐승 직진 알파 필요
3. **효도 압박·할머니 임종 = 한국 핵심** — 북미는 다른 동기 (이혼·고아·자녀 양육 등)

### OFFERING / 06 SHE STOLE MY FACE 적용 가능 인사이트

- **위장 정체 + 진짜 정체 시각 노출 = 강력한 페이월 메커니즘** — OFFERING Bael의 진짜 권력·드래곤 변신 시각화 = 동일 효과
- **EP1 즉시 사이다 (외도 발각 + 보호자 진입)** = 06 SHE STOLE MY FACE에서도 동일 패턴 가능
- **메인 빌런 (외도자) + 친척 (배신자) + 시댁 (향후 빌런)** = 한국 외도극 표준 = 06 적용 가능
- **시청자 정보 비대칭** — 시청자가 도훈 정체 알고 빌런들 끝까지 모름 → 노출 직전 결제
- **공개 노출 = 클립 보상 점진 확장** — EP6 사적 노출 → EP10 공항 공개 → 이후 사회 → 회사 등 (점진 공개성 확장)
